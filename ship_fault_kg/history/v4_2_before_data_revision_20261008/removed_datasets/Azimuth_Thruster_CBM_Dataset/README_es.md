# Paquete para Zenodo - dataset anonimizado IM-CBM / RESS

Este paquete esta preparado para crear el deposito de Zenodo asociado al articulo RESS sobre soporte de decision CBM multimodal en sistemas de propulsion de remolcadores. Incluye tablas anonimizadas, figuras finales, scripts Python basicos, metadatos y licencias.

Importante: los arreglos FFT crudos punto a punto no se incluyen por restricciones de confidencialidad y propiedad de datos. El paquete contiene caracteristicas espectrales representativas, indices procesados, variables de validacion cruzada, figuras y scripts de analisis.


Nota final: paquete alineado con la version de envio; conserva etiquetas anonimizadas por familia de motor y no incluye nombres ni codigos de embarcaciones.
