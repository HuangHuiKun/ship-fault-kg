# 导读

在航运市场持续低迷、环保节能减排公约要求和燃油成本居高不下的背景下，采用主机降速航行并燃烧特高粘度燃油进行降本增效是航运企业进行节能减排的重要举措之一。

船舶节能减排是综合性问题，最终目标是获得“最佳赢利航速”。

在既保障船舶使用寿命又降速节能的两者之间存在一个最佳结合点；

另一方面，主机燃烧特高粘度燃油会影响主机进一步降速，这两者之间也存在一个最佳匹配点；

采用主机降速航行及燃烧特高粘度燃油已成为提高航运经济效益的最佳实践之一。

但船舶主机超低速及燃烧特高粘度燃油进行降本增效也带来了一系列不容忽视的风险问题，必须研究相应的控制措施来有效防控风险。

# 一、主机降速航行产生的风险

主机长期降速低负荷运行在10% -40%额定功率，将产生以下风险：

## 主机自身风险

主机长期降速低负荷运行，扫气压力以及过量空气系数下降，主机燃油喷油压力下降以及雾化变差，导致燃烧条件恶化，降低柴油机热效率，增加耗油率，燃烧产物污染燃烧室、增压系统和排气系统部件,造成异常磨损。

主机长期超低速运转，致使主要运动部件液体动压润滑不良，腐蚀及异常磨损风险增加。

主机长期超低速运转，气缸润滑调节难度加大，润滑不良，汽缸油消耗率增加。

若气缸过渡润滑，会导致活塞头结垢，破坏油膜，磨损缸套；

若气缸润滑不足，会导致气缸异常磨损，甚至拉缸。

因主机超低速造成主机各缸供油不均，极易发生间歇发火、后燃和爆燃，出现现象,甚至导致机损事故风险。

## 辅助设备风险

主机长期超低速运转，使排气管通道、增压器、空气冷却器、废气锅炉、烟囱等发生严重脏堵，引起增压器排气背压高，同样会导致柴油机扫气压力降低，燃烧不良恶性循环，排气温度升高，运转性能下降，耗油率增加，甚至扫气箱着火和不能恢复其正常负荷运行。

主机辅助鼓风机长时间持续运转或不断的起停切换，影响风机寿命。

## 安全航行风险

主机减速运转可能出现轴系共振并引起住舱振动，影响船舶使用寿命和船员的工作生活环境,影响船员航行值班。

船舶降速航行,将使舵效下降,降低船舶操作性能,增加船舶安全航行的风险。

## 维修成本增加风险

船舶降速航行，将会增加备件物料的损耗。

增多轮机人员维修管理工作量，提高劳动强度,进而增加公司的维修管理成本等。

# 二、燃烧特高粘度燃油的风险

燃用特高粘度燃油的风险包括:

## 主机风险

粘度大的燃油喷射形成的油滴大，喷射深度也大,导致燃油雾化效果不良,燃气混合不均,燃烧条件恶化。

燃油粘度越高,其进机温度越高。

高含硫量致使燃烧过程中会产生更多的酸性物质,会对主机缸套、活塞、活塞环表面造成低温腐蚀磨损。

高含杂量,导致气缸产生固体颗粒磨损，积炭增多以至引起活塞环胶着、气口堵塞以及排气流经通道因积炭加剧,钒、钠对排气阀高温腐蚀。

密度较大致使燃油净化和喷射雾化困难,油滴初燃时,易热裂,使机件结炭增多。

十六烷值低,着火性能差,可能造成主机启动困难;燃烧时的滞燃期长,燃烧后延,造成排气温度高。

特殊区域换油对燃油喷射设备产生热应力的风险大。

主机降速后换油因燃烧品质不稳定,严重时可导致主机停车,造成意外事故发生的风险大。

## 辅助设备风险

燃油加热使用蒸汽耗量大，增加锅炉负荷,甚至增加耗油量;

燃油加热温度高,增加油分子分解的风险、形成沉淀的风险、高于闪点的风险,产生的油气增多;

燃油日用柜透气孔会产生大量油蒸汽,造成污染船舶,浪费资源以及引发爆炸的风险。

特高粘度燃油对粘温控制系统的要求也高，需要人工参与调节。

一旦粘温控制系统故障造成特高粘度燃油温度过高或过低，对燃油系统造成的堵塞、卡死、热膨胀、烫伤、爆炸的风险都很大。

## 储存、驳运、净化风险

特高粘度燃油的储存、驳运、净化和雾化过程中对主副机、锅炉、分油机和燃油加热器工作影响的风险高。

燃油粘度越高,为了防止汽化,要求其工作压力相对提高,这对管路和设备的材质、设计制造要求也相对提高，同时其操作的风险系数也提高。

存储、驳运、净化及雾化过程中引起储存柜脏污加剧和油路阻塞。

# 三、主机降速及燃烧特高粘度燃油风险叠加

主机超低速及燃烧特高粘度燃油，主机工作状况会更恶劣,致使燃烧恶性循环,会出现如下严重的问题:

## 主机风险

不稳定的爆压导致活塞环断裂而漏气。

船舶柴油机转速不稳定及功率损失。

港内机动用车燃烧特高粘度燃油时,主机启动困难。

主机超低速慢转,燃油喷射雾化状况差，加上扫气压力因增压器转速降低而相对下降，结果造成燃烧不良。

主机超低负荷运转时，气缸油注油量随主机转速成比例减少,但负荷增减和主机转速变化的三次方成比例,因此,若不调整气缸油注量,则每次喷出的气缸注油量相对过多,造成浪费且污染活塞环、扫气口或排气阀及其系统。

## 辅助设备风险

燃烧室和废气系统内部积碳、垢物增加，废气锅炉二次燃烧风险加大。

净油处理过程中因频繁排渣而使燃油泄放多,油渣柜液位升高快,高位报警次数增加。

由于燃烧不良,加速扫气口、排气阀及增压器污染,如此恶性循环,更促使燃烧恶化,发生故障的风险大,如活塞环断裂、辅助鼓风机烧毁,活塞头烧损,缸套龟裂,排气管着火及增压器损坏等风险。

主机超低速(低于50%负荷时)并燃烧特高粘度燃油时，废气锅炉产生的蒸汽量不足，需要启动辅锅炉，此临界点若把握不当，主机运转不稳定和成本增加的风险大。

针对以上三大类的风险对船舶降速及燃烧特高粘度燃油的风险进行控制。

# 四、风险控制措施

主机降速及燃烧特高粘度燃油风险控制措施设计的主要内容:

## 主机运行技术优化

调整主机运行参数，包括适当提高压缩比,增大喷油提前角,提高喷油压力,适当提高冷却水温度,提高扫气空气温度。

选用滑阀式喷油器,消除喷油器油嘴由于密封不严发生的滴漏问题,提高了喷射性能和雾化效果，改善燃烧状况维持更加清洁的燃烧室和废气通道。

配备滑阀式主机油头(SLIDEVALVE)的船舶主机负荷可降至40%。

提高扫气压力,包括T/C CUT-OUT技术，在低负荷运行时,停掉其中一台增压器,可提高其它的效率,可以降低该负荷下的燃油消耗率。

或者采用辅助鼓风机与涡轮增压器串联运行以提高扫气压力。

加强主机扫气箱残留气缸油检测分析。

采用一种对缸套操作状态的监控方法来确保对营运及备件成本的控制,确保降低成本的可行性。

化验分析扫气箱刮落的气缸油中的含铁量、BN值以及含水量，以此作为调整气缸注油因子的依据。

主机各缸负荷平衡的控制措施。

对油门杆和调速器加以限制,进行各缸负荷平衡调试,各缸排烟温度差控制在30℃以内，特别检查排烟温度最低缸和最高缸的原因和燃烧状况。

## 主机各系统优化管理

燃油系统。

强化特高粘度燃油管理,包括特高粘度燃油添加和储存管理、预处理管理,适当提高燃油加热温度，加强燃油系统滤器清洗等。

扫气系统。

加强废气涡轮增压器的清洗保养,加强进排气系统的清洁,提升增压器效率;

加强对扫气箱和各缸扫气室放残，定期打开检查,清扫疏通;

缩短空冷器清洗周期,脏污严重时应考虑解体浸泡清洗，保持进出空气压差正常。

滑油系统。

特别关注滑油压力的变化,主机滑油自动反冲洗滤器的冲洗次数，增加对检查滤器的检查清洗频率。

冷却水系统。

按主机说明书调整缸套冷却水和活塞冷却液的温度设定值,注意空冷器冷却水温度,防止扫气过冷。

注意空冷器前后的压差,超过说明书允许值时应择时进行化学清洗。

主机负荷程序管理措施。

主机长期降速运行期间的短暂高速运转要尽量手动缓慢加车，当到达主机临界转速(发生船舶共振现象)时，要尽快避开。

主机负荷的增加/减少应严格按照说明书、制造商服务通函和负荷程序的要求执行(紧急情况除外)。

主机完车后的管理措施。

每个航次主机完车后,都要对扫气箱和扫气室打开检查、及时清扫。

检查活塞环状况,检查缸套润滑油膜的状态和活塞上污物沉积等情况;

检查缸套、活塞组件的磨损情况并对比分析。

酌情缩短吊缸、排气阀等的检修周期，及时检修或更换异常磨损的部件。

主机短暂高转速冲车。

在实行降速航行期间,对主机进行短暂高转速冲车,做好增压器、废气锅炉的冲洗工作。

## 辅助设备优化管理

加强锅炉系统的管理。

主机短暂高转速运行冲刷排气通道及锅炉烟道，添加化学药水和排污,定期保养锅炉燃烧器,定期检查测试锅炉安保系统以及自动控制系统，定期检查锅炉给水泵的工况,加强日常备件管理,将燃油副锅炉的控制系统改为高低火自动切换系统。

控制蒸汽的使用。

注意节约蒸汽,包括消除蒸汽泄漏,合理控制并分配加热舱柜的数量及温度等。

预防船舶航行阻力大的措施。

船体应及时清污,选择使用质量上乘的船底防污漆。

监控船速及船底脏污的变化情况。

# 五、结论

通过对主机采用滑阀式喷油器、增压器T/CCUT-OUT技术、电子气缸油注油器Alpha ACC(注油因子)、特高粘度燃油等进行优化处理,并辅以科学的管理，可以规避或降低主机超低速航行及燃烧特高粘度燃油带来的一系列风险，从而达到降本增效的目的。
