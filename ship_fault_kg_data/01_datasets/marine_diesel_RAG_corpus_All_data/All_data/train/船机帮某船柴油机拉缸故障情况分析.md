# 导读

此文介绍某船主柴油机（下述简称主机）在航行试验过程中发生的拉缸问题，针对该问题进行原因分析，提出问题的解决措施和今后的注意事项，以确保柴油机正常、安全、可靠的工作。

# 一、故障情况概述

某船系泊试验结束后进行修后航行试验，暖机备航完毕后离码头开始试验，该船两台主机机型为12V20/27，制造厂家为上海新中动力机厂，随船试验人员按照试验大纲要求开展修后航行试验。

试验大纲要求该船主机需要完成进一工况（450 r/min），进二工况（630 r/min），进三工况（840r/min），进四工况（930 r/min），进五工况（950 r/min）五种工况的航行试验。

两台主机按照试验大纲要求的试验时间完成了进一工况、进二工况、进三工况三种工况的试验，主机运行状态良好，滑油温度、淡水温度、海水压力、淡水压力、滑油压力等其它参数均正常。

主机开始加速进行驾控双车进四工况（930r/min）试验，运行约15min 时，左主机增压器出现喘振现象，航行试验人员立即开展检查，检查发现海水系统的压力表无压力显示，分析判断可能是海水失压造成的压力表无显示，逐打开机带海水泵放气阀检查有无海水溢出，检查发现该海水泵放气阀排出的均是空气无海水流出，此时主机淡水系统温度急剧升高，问题发生后随航试验人员采取紧急降速停车，在停车操作过程中发现该主机的淡水从膨胀水箱通气口处沸腾溢出，左主机曲柄箱出气口及输出端也出现大量烟雾等现象。

主机停车后，立即启动了预供滑油泵对左主机进行充油，并手动盘车。

大约5 min后打开曲柄箱检查孔盖，通过目视检查发现A3、A4缸出现了明显拉缸现象，其他各缸无明显损伤，因故障原因该航行试验计划取消，并迅速开展拉缸问题的排查。

返厂后，针对此故障现象，首先对该柴油机进行了拆卸检查，主要对主机的气缸套、活塞连杆组、增压器和海水冷却回路进行了拆卸检查。

通过综合排查该主机的拆卸检查状态和航行试验前该主机的维修情况，并参考了系泊试验期间的主机空车运行状态参数，逐对该主机产生拉缸的故障原因进行了最终的问题定位，同时也制定了下一步修理措施来排除故障问题进而完成航行试验检验左主机的维修情况。

# 二、问题定位

根据前期故障情况的描述，对比检查了左、右主机的海水系统，重点检查左主机机带海水泵进出口、淡水冷却器、海水管路、海水滤器及海水进出口阀门是否有脏堵情况，检查海底阀箱和海水滤器通气管的畅通性，在检查过程中发现两个海底阀箱通气管经各自的截止阀后汇合在一起，并经甲板透气帽进行排气，左主机海底阀箱通气管路上的阀门在航行试验期间没有完全开启，该阀的未完全开启不利于海底阀箱上部的空气排出，且海水滤器上通气管存在返水弯情况，导致滤器内的空气更不能及时的排出，其它各检查部位均正常，无堵塞情况。

通过现场分析可以看出，造成本次问题的直接原因为左主机海底阀箱通气管路上的阀门在航行试验期间没有完全开启，致使海水系统中空气聚集，空气排出不及时，促使机带海水泵进口水量不足，造成海水失压，淡水无法进行热交换冷却，造成机温过高，使机体内的淡水高温汽化，气缸套无法正常冷却，左主机A3、A4缸较其它气缸温度先升高，破坏了活塞与气缸套之间的润滑油膜，因干摩擦使气缸套工作表面周圈严重拉伤，活塞周圈严重拉伤、活塞裙部产生裂纹、活塞环严重磨损，活塞销与销座黏连，造成了A3、A4缸的拉缸故障。

同时空冷器因海水冷却不足使吸入的空气温度急剧升高、气体膨胀造成了增压器的喘振。

柴油机拉缸后废气进入曲柄箱，通过曲柄箱通气孔及曲轴输出端迷宫密封处冒出。

上述分析均印证了问题发生时的现象描述：

左主机增压器出现喘振现象，停车操作过程中发现该主机的淡水从膨胀水箱通气口处沸腾溢出，左主机曲柄箱出气口及输出端也出现大量烟雾等现象。

# 三、机理分析

## 1、柴油机修理情况分析

本次修理该船两台主机修理范围为：24只气缸盖全部分解检修。

左、右机共抽检8组活塞连杆组。

对两主机的全部主轴承、连杆轴瓦及曲轴进行检查。

增压器、空冷器、海淡水冷却水泵、滑油泵、燃油泵、高压油泵、喷油器、淡水冷却器、海水滤器、滑油冷却器、滑油滤器全部检修，油底壳进行清洁。

对拆检的设备部件按照标准及工艺要求进行检修、清洁，对腐蚀、磨损严重的部件经鉴定进行更换。

主机检修更换的主要部件为：更换了部分磨损超标的进排气阀。

抽检的左机A2、A5、B3、B6缸及右机A1、A6、B1、B2缸共8组活塞连杆组均无异常，对抽检缸的气缸套进行珩磨处理，对其余各缸活塞顶及气缸的积碳进行了清洁。

对两机全部的主轴承及连杆轴瓦进行了检查，更换了左机连杆轴瓦A6、B3、B5缸，右机A1、A2、A3、A4、A5、A6、B1、B2、B3、B4、B5缸；

两主机16付主轴承除左主机6#、7#主轴承留用外，其余14付主轴承全部换新。

活塞连杆组安装前对抽检缸的缸套、活塞连杆组用麂皮擦拭干净，表面涂抹滑油；用麂皮擦拭油底壳，擦拭干净后再用面团进行清洁。

柴油机安装完毕后，对机体冷却水腔进行了磅压检查，各部无渗漏。

用预供滑油泵对主机进行充油，检查了各部位的供油情况，供油检查正常。

系泊试验时，初次起动柴油机5min后停车检查了连杆轴承和主轴承温度及连杆螺栓紧固情况，无异常。

两主机开始空车运行试验，试验转速分别为450r/min、630 r/min、840 r/min、930 r/ min、1000r/min共运转了约2.1h，运转过程中滑油压力、海水压力、淡水压力、淡水温度、滑油温度等其它参数均正常，空车磨合完毕后，停车检查了连杆轴承和主轴承温度及连杆螺栓紧固情况，两主机无异常现象。

## 3、拉缸原因分析

根据航行试验时出现的左主机增压器喘振、海水压力失压、淡水温度升高从膨胀水箱通气口处沸腾溢出等现象直观判断是由于主机冷却海水供给不足、淡水冷却不够、活塞温度升高造成的拉缸。

通过进一步分析，参照本次主机的修理范围造成拉缸还可能有以下几点因素：

a）进气系统有异物；

b）燃油供给系统工作不良；

c）柴油机超负荷运转；

d）润滑不良及润滑油供应不足；

针对上述可能造成柴油机拉缸的四点因素，采取措施对各个相应的系统及部件进行了排查，排查情况如下：

1）怀疑进气系统有异物造成拉缸，检查了柴油机进气管、进气空气滤芯及增压器，没有发现杂质及异物等异常现象。

2）怀疑燃油供给系统工作不良及柴油机超负荷运转造成拉缸，表１为左主机在航行试验过程中进一至进四工况时排温情况。

通过表１中数据可以看出，航行试验时左主机各缸排气温度是正常的。

喷油器、高压油泵工作状态良好。

说明造成本次 Ａ３、Ａ４缸拉缸故障不是由于燃油供给工作不良或柴油机超负荷造成的。

3）柴油机在进一至进四工况时，海水压力、淡水压力、淡水温度见表２。

通过表２中数据 可 以 看 出，航行试验时海水压力、淡水压力、淡水温度均是正常的，符合试验大纲中参数要求。

4）怀疑主机润滑不良及润滑油供应不足造成拉缸，柴油机在进一至进四工况时，滑油压力及温度见表３。

通过表３中数据可以看出，航行试验时滑油压力与滑油温度是正常的，符合试验大纲中参数要求。

通过分析，上述四种可能造成此次柴油机拉缸的因素均被排除，综上所述，造成本次拉缸问题发生的根本原因为左主机海底阀箱通气管路上的阀门在航行试验期间没有完全开启，导致海水系统中空气聚集，海水吸空，淡水系统无法进行海水冷却引起的。

# 四、制定修理措施

针对问题检查情况和原因分析，制定修理措施如下：

1）将左主机气缸盖、活塞连杆组、气缸套拆出，清洁检查，更换Ａ３、Ａ４缸气缸套、活塞、活塞销、气阀等损坏件，鉴定更换连杆大端轴瓦、主轴瓦、活塞环，部分小端衬套及其它损坏件、密封件，清洁检查滑油系统滤器。

2）检查海水系统、淡水系统，航行试验时，保持左、右主机海底阀箱、滤器通气管路上的截止阀为开启状态，保持通气管路及甲板透气帽的通畅性。

3）优化左舷海底阀箱滤器通气管路，消除返水弯，降低排气阻力，保证通气管路内气体排出时的顺畅性。

4）利用预供滑油泵对左主机滑油系统进行串油，清洁滑油系统，串油完毕后更换使用过的滑油，清洗滤器，排除系统内的杂质隐患。

# 五、举一反三情况

1）针对左主机发生的拉缸问题，对该船右主机海水系统进行隐患检查，消除故障隐患。

2）召开质量分析会，将故障情况进行全员警示，提醒工厂全部参修人员，如该型船后续进厂进行修理时，应重点对海水系统进行重点检查，确保系统畅通，状态正常后才能开展后续航行试验。

# 六、结束语

举一反三检查完毕后，该船进行了修后航行试验，按试验大纲要求两主机进行了进一、进二、进三、进四、进五五个工况的航行试验，试验过程中各项参数性能指标均符合了试验大纲要求，左主机拉缸故障得到了排除，质量隐患得到了消除。

通过对该船左主机拉缸故障问题的原因分析和维修排查，不仅提升了工厂职工的修理技能和维修水平，同时也提高了职工的质量意识，为工厂后续承修同型号柴油机打下了良好的基础。
