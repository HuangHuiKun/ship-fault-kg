# 导读

柴油机排气高温造成的危害很多，如果处理不及时，可能造成机损事故，产生的危害有以下4个：

1. 排气高温易造成排气阀、排气道烧蚀，金属熔渣易进入废气涡轮增压器，造成涡轮喷咀、叶片损坏；
2. 高温排气吹扫排气阀与阀座密封面，极易造成密封面蠕变烧损，引起气缸密封性严重下降，进一步导致燃烧恶化；
3. 冷取水套式排气道内的高温气体，会加速冷却水系统内淡水高温汽化，继而引发冷却水系统循环故障；
4. 气阀烧蚀和高温淡水、缺水，容易导致拉缸事故的发生等。

国内张现伟在《TBD620V12柴油机排气温度高的原因分析与排除》一文中，最终分析得出原因是“配气相位齿轮发生位移”导致；蒋凌杰在《备用柴油机排气温度高的问题分析和处理措施》中，得出原因是进气过滤棉脏堵、废气涡轮增压器废气侧和压气端密封垫损坏贯穿；叶伟强在《柴油机排气温度高故障实例浅析》文中分析，最终得出的原因是“增压器脏堵”；蒙绪武在《柴油机排气温度过高的原因分析和解决措施》中分析了排气温度高的很多原因，最大的实际原因还是“一只排气阀关闭不严”；修安思成在《船舶二冲程柴油主机排气温度过高原因分析》，共得出11条引起排气温度高的原因，所以说影响因素很多，但未能重点阐述空冷器的影响；尹晓科在《关于MTU4000系列柴油机排气温度高的故障分析及其排除》文中针对实际故障，着重分析排除了喷油系统的问题，提到中间空冷器问题但未能重点剖析，该机故障重点也不在此。

上述学者专家各有侧重论述其他影响柴油机排气温度过高的原因，或者笼统全面的分析，未能针对特定故障现象和特定机型进行分析，未对快速判断处理同类故障现象起到明确的方向性指导作用。

基于上述因素考虑，为解决生产急需，尽快排除实际工作可以证实的非故障原因，从实际管理和操作人员的工作特点出发，选取扫气道压力作为参考参数，通过安装临时观察用的扫气压力表，继而锁定空冷器虽经厂修清洗，但未能解决脏堵，验收不严谨，试车阶段愈发加剧堵塞是进气通道的故障原因。

# 一、故障描述

国内某大型船舶修理企业所属主力生产拖轮，主柴油机型号瓦锡兰8R22MD，额定转速900 r/min，功率1300 kW，左右各一台，通过中间轴连接舵机间的全回转舵浆装置（图1）。

图1 瓦锡兰8R22MD型船舶柴油主机

该轮在完成最近一次特检修理后，已完成主机磨合、系泊试验，在进行航行试验过程中，主机加速到前进二（约650r/min），左右主机排温相差不算大，大约左机比右机高20~30℃，但再往上加速到750~800 r/min时，左机排气温度上升非常明显，因增压器介入作用强烈，右机排气温度上升不明显，在300℃左右，但左机各缸很快上升到400℃以上，这就意味着无法继续加速，左机不能承载高负荷。

由于该轮是25年船龄以上的老船，主机一些附属元器件和仪表缺失，如增压器转速表、扫气道扫气压力表，该机型未能设置空冷器空气进出口压差计，不能借助于仪表进行增压器、空冷器的工作状态的比对判断。

# 二、故障原因排查

柴油机排气温度过高，一般情况燃油系统故障、配气不足、负荷过高等是主要原因，根据该机先前修理项目和试车实际情况，分析如下：

## （1）燃油系统

左右主机喷油泵是轮机人员在机舱现场用专用试验台泵压调试，每次喷油器本体和喷油咀保养是同样的流程和工序，维护人员对主要部件并未更换，右机工作状态正常显示喷油嘴状态良好，左机上此原因基本可以排除；高压油泵保养及喷油正时校正过程，并经过严格的验收试验阶段，可以基本排除。

为了验证并彻底排除，通过查看示功阀发火情况、测定燃烧爆炸压力证实燃油系统没有异常。

## （2）配气系统

左右两只空冷器在修理期间拆下，送到专门化清车间内进行化学药剂泡洗和空气吹净、冲水试验；左右增压器部分，因机电长担心拆检修理后，只能配供国内仿制件，国内仿制轴承运行寿命堪忧，以前保养更换的进口轴承，运行时间和保养间隔远未到说明书规定的时间限定，修前也未发现明显异常，本次修理未安排保养。

## （3）负荷等其他因素

考虑到中低转速时，左右机排温相差不多，主柴油机轴系未见异常振动，应可排除系泊试验期间螺旋桨缠绕异物等导致负荷过高的可能；通过测定缸内纯压缩压力，缸内密封状态左右机没有大的差异，说明进排气阀和活塞环状态良好。

技术人员怀疑左增压器工作状态不佳。

拆下左增压器送车间内进行拆检保养，在拆开增压器零部件之后，仅在叶片、喷咀发现有少许脏堵外，并未发现有严重的异常情况，与在机旁用经验测听声音，初判断没有大问题相印证。

清洁保养更换常规备件后回装，试车后发现排气温度有少许降低，但效果并不明显，拆开之前众人推测的原因未能得到佐证。

增压器回装之后，没能排除故障点，考虑在进气管道上找一处闷头、管口，设法外接压力表检测主机运行时进气（扫气）压力，用以判断进气情况。

在进气管与中冷器弯接头靠机体侧，发现有一闷头（整管上未有对外连通考克），旋松准备。

再次开启柴油机加速到700r/min，旋开该闷头发现此处气流在往内吸，管内俨然呈负压状态。

至此原因确定，增压器排出的新鲜空气输送管路不畅通，可能原因是空冷器脏堵。

然而，空冷器是经过厂里车间专业人员泡洗吹净过的，曾派轮机人员到车间进行过验收。

重新拆开空冷器送车间试验，进气侧（接增压器出气端）朝上将空冷器悬吊于车间水池上方，从进气侧往中冷器里灌水，发现进气侧满溢而出气侧无水流下，证明空冷器堵死，无法顺畅出气。

装在柴油机上的空冷器（增压器后进气道前）如图2所示。

图2 装在柴油机上的空冷器

故障现象可以解释为：

进气总管内新鲜空气供给不足是造成排气温度过高的主要原因。

至于为何没有在出厂验收时发现，轮机人员也确实到现场验收查看，有记录签字为证。

但空冷器维修人员仅是连接好空冷器海水冷却管进出口端，在海水管内加压并封堵保持，做规定的4 kg/cm2水压试验合格，轮机人员未提要求就进出气通道的畅通性做试验，水压试验合格后就签字认可；修理人员认为药剂泡洗24h，气侧外表面散热片看起来很干净，认为清洗合格，车间质检人员也未能认真履行试验检查职责，就予以签单放行送现场安装。

该起事故后，对相关人员失责行为进行了通报处罚。

经过重新添加适度化学药水，要求泡洗池水加热煮沸，并落实轮机人员盯在现场监工查看，将空冷器气侧彻底清洗吹刷，保证进出气完全畅通后。

回装试车，主机排气温度完全正常，该故障排除。

# 三、结束语

柴油机排气温度过高原因很多，要根据现场实际情况，辅助用测定技术参数的手段，才能比较快速锁定大致的原因，以免耽误生产使用；该起故障排查过程得出的启示，柴油机空冷器送车间清洗，务必在现场做清洁效果试验，进出气侧是否完全通畅是主要验收标准，海水管路水压试验是其次要求；主柴油机的主要参考参数仪表必须保证状态良好，读数校准，这有利于故障出现时的迅速排查；主柴油机大修理后进排气管须清洁除灰除垢，因修理后的系泊试验正倒车时机体振动普遍较大，容易将保养后残留的漆皮垃圾等异物吹扫进增压器叶片、喷咀和空冷器气侧，从而造成增压器损毁和配气故障。
