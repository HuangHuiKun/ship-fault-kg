# 导读

全回转港作拖轮在大型船舶靠、离港口过程中起着重要的作用。

拖轮的主机更是其安全行驶的“心脏”,来不得半点弊病和闪失。

现以某全回转港作拖轮为例,说明主机排气及冷却水温度异常的故障排除方法。

## 一、故障现象

烟台港某全回转港作拖轮其中一台主机 (日本 DAIHATSU 6DL-28)在运行中，轮机人员发现该全回转拖轮在右主机满负荷运转时出现个别缸排气温度和冷却出水温度异常现象。

具体见表1:

该柴油机输出功率为1900hp,采用独立高压油泵供油,涡轮增压。

排气管排烟颜色正常,冷却水、润滑油压力表指示均正常。

纵观上表各缸排气温度及气缸冷却水出水温度,发现第2缸、第5缸排气温度和冷却水温度均偏高。

(正常值是排气温度在450℃左右,冷却水出水温度在50℃左右)

## 二、故障存在的危害

排气温度高对于船用主机将产生非常大的危害,尤其在以下几个方面:

1)造成气阀烧蚀 (尤其是排气阀 ) ,降低气缸 的密闭性,使气缸燃烧状况恶化,降低气缸的工作效率。

2)增加气缸的热负荷。

容易因气缸过热而造成活塞卡滞,进而造成拉缸甚至连杆断裂等重大事故发生。

3)过高的气缸温度,伴随着柴油机长时间大 负荷运转,造成气缸早燃,导致气缸工作粗暴 ,影响柴油机工作平稳性,对连杆及曲轴等运转部件将产生极大危害。

## 三、排气温度高原因

结合柴油机的工作特性,分析认为,造成气缸 排气温度高的主要原因大致包括以下几个方面:

1)该气缸的测温热电偶损坏,造成数据失真。

2)油泵供油量偏大, 该柴油机在上一年度船厂修理时,对各缸油泵进行过检修,主要是更换柱塞和密封圈。

如果油泵在安装过程中,油尺齿条安装位置出现偏差,则造成该油泵在同样供油调整臂行程条件下,较其它油泵产生较大的供油行程,从而导致该油泵较其它油泵供油量增加。

在柴油机同一转速及进气条件下,该缸由于过多的燃油参与燃烧,产生的热量也较多,并且未能充分燃烧的燃油在排出气缸进入排气歧管的过程中会继续燃烧,释放出更多的热量,最终导致该缸排气温度过高。

3)进、排气阀间隙调整不当。

如气阀间隙过小,造成排气阀关闭过迟,形成排气不彻底,过多的废气残留在气缸中,占据了有效空间,阻碍了更多的新鲜空气进入气缸参与燃烧,致使燃烧不充分;如气阀间隙过大,造成进气阀开启过迟,导致进气不充分,由于缺乏足够的新鲜空气参与燃烧, 使该气缸燃烧不充分。

未能充分燃烧的燃油随排气阀的打开进入到排气歧管中,在高温条件下继续燃烧,从而造成排气温度过高。

4)喷油提前角过大,使供油时间滞后,造成柴油机热负荷增加。柴油机工作粗暴,排气温度升高。

5)由于该气缸燃烧不良,造成排气门出现积 碳、烧蚀等现象,致使排气门关闭不严,导致气缸在燃烧过程中,高温高压燃气未能完成作功减压,而是经排气阀进入排气歧管,造成排气温度高。

另外,燃烧室内过多的积碳,也降低了气缸盖的热传导效率,影响了冷却效果。

6)该气缸喷油器工作不良 (雾化效果差 ) ,造 成燃油在气缸中未能充分燃烧。

未能燃烧的燃油经排气门排出后在高温条件下继续燃烧,导致排气温度升高。

7)该气缸盖示功阀关闭不严,导致气缸压缩 比降低,在同样供油量情况下,出现燃油未能充分燃烧现象。现场检查,该原因予以排除。

## 四、冷却水温度高原因

气缸盖冷却水温度基本上是成逐缸递增趋势 的,这是由于发动机循环系统的工作特点所决定的。

冷却水经机体循环水泵进入柴油机机体循环 水道,由于淡水水泵位于发动机的前端,因此距离水泵越远的气缸吸收的热量越高。

自然其出水温度较其它距离循环水泵较近的气缸温度要高。

但是第2缸和第5缸出水温度要高许多。

造成气缸出水温度高的原因大致包括以下两个方面:

1)水垢过多或由于其它杂物堵塞气缸盖冷 却水套等原因,造成该气缸冷却不良,出水温度较高。

该柴油机的冷却方式为闭式循环 (即以热交 换器的方式用海水来冷却淡水 ) ,故以上原因基本上可以排除。

2)气缸燃烧情况差,造成气缸热负荷高,导致气缸冷却不良。

该原因造成排气温度高的同时出水温度也相对提高。

第2缸和第5缸的情况基本上是与此相符的。

## 五、测温热电偶损坏原因

根据由简到繁,由易到难的故障诊断原则进行综合分析。

对于热电偶工作灵敏度、可靠性的检测,若按常规维修经验,可以采用调换法或更换备件法进行判断,但是热电偶安装于排气歧管中 (靠近于气缸盖排气口 ) ,由于长期承受高温且缺乏有效的润滑,拆卸十分困难,稍有不慎即可造成热电偶损坏。

为此采取了改变热电偶接线的方法进行判断 ,证明热电偶工作正常。

由于检测手段和方法受现场条件限制,同时为避免因维修带来的损失,采取尽量减少和避免进行局部解体检测维修项目。

在柴油机未起动前,将各缸油泵的油尺拉杆与调速器油量调整臂逐个断开,用手动方法进行加减油,发现第2缸和第5缸的油尺拉杆 存在“卡滞 ”现象 (油尺杆部被喷涂了大量的油漆,该机上一年度保养时进行过整机油漆喷涂 )。

将油尺表面进行可靠处理之后,起动主机进行负荷试验,结果第2缸和第5缸的排气温度和出水温度明显下降。

排气温度达到了450℃左右 ,冷却出水温度也在50℃左右 ,达到了正常值。

由此认为 ,第2缸和第5缸的排气温度及冷 却水出水温度高的直接原因是油泵供油量过大。

造成油量过大的直接原因喷涂油漆时不小心 ,将油漆喷到了油泵的油尺拉杆上,由油尺拉杆的 “卡滞”引起的。
