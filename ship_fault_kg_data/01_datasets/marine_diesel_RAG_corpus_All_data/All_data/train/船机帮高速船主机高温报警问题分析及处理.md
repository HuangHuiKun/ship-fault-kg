# 导读

某20米级高速巡逻船在试航过程中主机发生高温报警的现象，通过现场检查及与相关各方研讨分析，找出了问题的原因，并制定了解决方案。

通过对海水阀箱结构的优化改进，解决了相关问题，并且积累了相关设计及制造经验，也为以后处理类似问题提供了参考依据。

# 一、引言

本文介绍的某20米级巡逻船为海事公务船，主要负责行政执法,控制水域污染,维护水上安全航行秩序,水上交通事故调查处理,组织水上人命施救等工作。

本船按航行于内河A级航区的高速船进行设计。

主要参数如下:

1)船舶总长22.56m,型宽4.5m,型深2.4m,设计吃水1.24m,设计航速20kn。

2)动力装置组成:两台船用柴油机，左右对称布置,额定功率/转速: 441kW/ 1900r/min;两台齿轮箱,减速比2.192。

3)发电机组:该船采用1台柴油发电机组。发电机额定功率:22.5kW, 3ph/380V/50Hz。

4)机舱布置图如图1所示。

图1 机舱布置图

该船机舱位于船的后部，即#4~#15肋位之间，全长为5.5m,宽度为4.5m。在机舱顶蓬前部#15开有舱口盖,通过直梯通往机舱花钢板平面,在机舱后部#6开有机舱门,并有扶梯通往机舱花钢板平面。主机组位于#10~#14肋位之间，对称并列布置。两台主机轴中心线间距为1.8m,柴油发电机组位于左舷#5~#8肋位之间纵向布置,其它设备沿机舱四周布置。在#7~#8肋位之间设有海水阀箱,用海水总管相连，可供主机、辅柴油机的海水泵及消防总用泵吸水。

该船的设计、建造、检验,满足中华人民共和国海事局《内河船舶法定检验技术规则》(2019) 以及中国船级社《内河高速船入级与建造规范》(2016)及其修改通报的要求 [1-2]。

# 二、主机高温报警问题及原因分析

该船在完工后在相关水域进行了系泊及航行试验,在进行航行试验的过程中发现当主机转速达到1750r/min时，左右主机均出现主机高温报警的现象，此时船舶航速大约17kn。

为了快速地找出问题的原因,设计院、主机厂家以及船厂等各方人员进行了研究讨论,决定采用人工检查的方法，从以下三个方面进行现场勘验。

第一,检查主机是否存在故障。由于该船在系泊试验过程中,对主机的性能进行了充分的验证,因此可以排除主机本身在这一阶段对主机高温报警的影响。

第二，检查管路系统是否存在密封不严及堵塞等问题。通过对主机冷却水管路包括海水滤器进行检查,并没有发现管路泄漏及滤器堵塞等现象。

第三，利用冷却水备用管路,复查主机是否能正常运行。通过查阅主机冷却水系统图，了解到消防总用泵可作为主机冷却水备用泵使用，消防总用泵出水总管有一路接至主机,作为主机冷却水的备用管路。利用消防总用泵打水作为主机冷却水泵使用，重新试航，在航行过程中也同样出现主机在高转速时发生高温报警的情况,同时总用泵进口出现压力低的现象。

通过，上述检查和试验,可以推断出，主机发生高温报警的故障是水泵在高速情况下出现供水不足导致的,并且是供水的源头出了问题。初步定位引起主机高温报警的问题出在海水阀箱上，接下来对海水阀箱作重点分析。

# 三、海水阀箱的结构

本船采用的海水阀箱是一种适用高速船的海水阀箱。经过多年的实践，已经在多艘高速公务船,高速客船上使用 [3]。

海水阀箱结构图如图2所示。

图2 海水阀箱结构图

本船的海水阀箱距中对称布置,中间由海水总管相连，上图为单只海水阀箱侧视图。

海水阀箱主要由以下部分组成:格栅、海水进水管、蝶阀、滤筒、本体、海水总管、压盖、防腐锌块、透气阀等。

进水格栅采用φ5mm不锈钢圆钢制成,格栅条沿纵向布置,格栅条之间间隙10mm,满足规范要求。海水进水管采用φ219X6.5mm无缝钢管制成并做成喇叭形状，加大了进水面积;海水进水管与本体之间采用蝶阀联接,在检修海水阀箱或清洗滤器时可将此蝶阀关闭，蝶阀上的连接螺栓采用不锈钢材质。本体采用φ219X6.5mm无缝钢管制成,并在本体上加工好了海水总管接管，接管与海水总管均采用φ140X4.5mm无缝钢管制成，接管与海水总管之间采用蝶阀联接。本体与滤器可以分开,本体内部设有不锈钢上下支承圈,用于固定滤筒，同时可以将本体的内部隔成两个腔体,方便海水的过滤。滤简用0.5mm厚不锈钢孔板卷制而成,滤筒上均匀钻φ2mm孔，上下用不锈钢圈加强，滤筒上部焊一圆条,可作为拉手，在清洗滤筒时，方便拉起和抽出本体。本体上方的压盖采用Q235钢制成，压盖法兰与本体法兰之间采用活结螺栓进行联结,压盖法兰与本体法兰之间夹垫5mm厚橡胶垫圈。压盖下方用不锈钢螺柱和螺母固定防腐锌块，对海水阀箱起到保护作用，避免被海水腐蚀。压盖顶部中间装设截止阀,与阀箱透气管相连,防止海水阀箱内形成气囊。海水阀箱的高度高于设计水线上50mm,避免拆开压盖检修海水阀箱时海水灌入机舱。海水阀箱零件加工完毕后均作镀锌处理。通常情况下，在船舶下水后或者清洗滤器后,在首次使用时,开启顶部截止阀放气,待海水充满海水阀箱后即可关闭截止阀,使得用水设备抽吸水时不会吸入空气、更加顺畅引。本船海水阀箱上的截止阀在试航时是关闭的,因此也排除了海水阀箱吸入空气引起主机冷却水供水不足导致主机高温报警的可能性。实船海水阀箱如图3所示。

图3 实船海水阀箱图

通过对海水阀箱结构的详细介绍，我们可以看出本船设计的海水阀箱有以下几个特点:

1)结构紧凑,体积小巧。传统的海水阀布置在船舷的两侧，通过海水总管、粗水滤器、闸阀相连接。整个系统尺寸大，横跨整个机舱,同时机舱尾部又布置有轴系,需要额外给海水阀箱和海水总管腾出位置,因此占用了机舱很大的空间。高速船为了给乘客和船员留出更大的使用腔间,机舱容积一般控制在比较小的范围。本船采用的海水阀箱,体积小,重量轻,并且巧妙地将其布置在两主机轴系的中间,机舱楼梯的下方,不占走道位置,也不影响其它设备的维修空间。

2)靠近船中,方便取水。高速船的吃水一般都很浅,采用传统的布置在两舷侧的海水阀箱系统,会造成取水困难。本船海水阀箱布置在机舱靠近纵中剖面的两侧，这里吃水更深,方便取水 [3]。

3)结构合理,便于维修。传统的海水阀箱，防腐锌块安装于箱体结构内部，很难安装与取出。而本船海水阀箱防腐锌块采用螺柱与螺母的安装方式，方便安装与更换。海水阀箱滤器采用垂直的装配形式,海水里的泥沙会下沉到底部,被底部进水管里的海水逐渐淘走,减少了滤器的清洗次数。而传统的海水粗水滤器,如不经常清洗，海水里的泥沙会堆积，使滤器堵塞,造成水泵供水不足,影响机器设备的使用。

既然海水阀箱的布置是合理的,为了弄清楚发生故障的原因，将进一步对海水总管大小及格栅流通面积进行校核。

1)海水总管直径计算。海水总管的总流量:Q=2Q₁+Q₂+Q₃=2×28+3.4+25=84.4m³/。式中:Q₁-主机海水泵流量,取28m³/h。Q₂-辅机海水泵流量,取3.4m³/h。Q₃-总用泵流量,取25m³/h。海水总管的通径:海水格栅采用φ5mm不锈钢圆钢制成，格栅条沿纵向布置,格栅条之间间隙10mm,单个海水格栅所有间隙相加，得到海水格栅有效流通面积约0.0975m²,大于3倍海水总管截面积,满足规范的要求。

通过上述计算可以看出，海水阀箱的设计是满足使用和规范要求的,系泊试验也证明了这一点。从而可以推断主机出现的高温报警是跟船速有一定关系的,进一步分析发现船在高速航行时，船底特别是尾部型线变化处会产生较大负压力,海水阀箱刚好布置在此处,导致海水进水管兜水能不足,不能通过得到动压头来降低格栅吸入口处的负压力,主机海水泵吸空,冷却水量不足，导致主机产生高温报警 [5]。因此,需要增加海水进水管的“兜水”能力,增大进水量。

# 四、海水阀箱的优化改进

为了增加船舶高速状态下海水阀箱的“兜水”能力，对海水阀箱进水管结构进行改进,增加挡水板高度,挡水板末端至船壳板垂直高度为100mm,挡水板与船壳板夹角45°。优化后的海水阀箱海水进水管处结构图如图5所示。

图5 海水进水管结构图

以主机发生高温报警时的航速来核算进水量是否满足使用要求。主机发生高温报警时，船舶航速约17kn，水流速度v=8.5m/s，利用CAD软件计算出挡水板在水流方向的投影面积S=16209mm²。挡水板在水流方向上的投影如图6所示。

图6 挡水板在水流方向上的投影图

此时兜水流量Q=v×S=8.5X0.016=0.136m³/s=489.6m³/h。从理论计算来看,其兜水量远大于船舶用水设备所需排量(84.4m³/h)。海水进水管改进后实船照片如图7所示。

# 五、试航验证

船舶重新下水试航，船舶在高速状态下运行平稳，主机再也没有发生高温报警的问题,并且在倒车靠岸和全满舵情况下运行,船舶性能均能达到航行试验大纲的要求。证明海水阀箱的改进措施是有效的。

# 六、结论

本文通过对主机冷却水高温报警问题的分析及处理，对适用于高速船的海水阀箱进行了改进,达到了良好的效果。在后续的高速巡逻船,高速客船的海水阀箱设计中均可采用此结构型式。但是在海水阀箱的优化改进过程中还存在着不足，挡水板与船壳板之间的夹角是有一定要求的,角度不能太大，太大可能会导致主机倒车时冷却水泵吸入空气的现象;角度也不能太小，太小则会导致进水量无法满足要求 [4]。本船是通过经验来设置挡水板的高度和角度的,在后续的工作中可以利用CFD (计算流体力学)仿真工具模拟船舶尾部流体情况,推算出挡水板合适的高度和角度,并通过航行试验验证，不断总结相关数据，可以进一步提高设计的准确性。
