# 导读

某船，主机为宁波中策GN8320柴油机，主机采用上海HELICE遥控系统和主机自带安保控制系统建立通讯配合使用，实现柴油机的启动、停车控制以及远程速度设定、监控报警、应急停车等功能。

其采用WOODWARD723PLUS数字式转速控制器输出0~200mA控制电流，与UG-ACTUATOR连接主机高压油泵油门控制杆实现主机负荷和速度控制。

# 一、故障概述

某船在海上油田矿区长期进行货物运输作业，航次频繁，主机平均每月运转360h，月均航行里程2080海里，月均靠离平台及码头次数184次。

该船在一次码头靠泊中多次出现额定转速无报警停车现象。

停车后，再次启动时，主机可以正常使用，而且停车时间间隔不固定，故障现象时有时无，给故障查找带来很大困难，也给靠离泊作业造成重大安全隐患。

## 1、汉力士遥控系统

采用汉力士遥控系统实现主机遥控。

该系统以SIEMENS S7-200 CN 中央处理器（cpu）为中心，实现前后驾控台、集控室去主机的启动、停止、速度设定及警报显示，并建立起主机遥控、CPP控制及齿轮箱的通讯连接。

应急停止和正常停车可以通过遥控系统操作实现。

## 2、中策主机系统

### （1）中策主机系统简介

中策主机系统为主机厂家提供，以浙江中控逻辑控制器U6-PLC、LOGO!和WOODWARD为核心，通过软件控制，对输入信号进行处理后输出命令信号，从而对柴油机的运行进行控制、监视、报警和保护。

系统进行主机运行数据的采集，与集中监控系统建立通讯，能够集中显示运行中主机运行中的参数，实现监控报警功能，同时主机安全保护功能由此控制部分实现。

电路工作过程为通过开关、按钮、外界报警触点、传感器、遥控等输入信号至U6-PLC、LOGO!或WOODWARD，通过程序进行逻辑处理后输出，通过外接继电器驱动，来执行各对应的执行元件。

### （2）中策主机系统停车功能

分析发现，GN8320型主机停车分为停车和紧急停车两个回路组成。

当柴油机进行电控正常停车时，停车信号从LOGO!的I3端输入，停车命令将从Q3端输出，见图2。

图2 中策系统LOGO原理

为避免柴油机在额定转速状态下突然停车，程序设定了通过PLC的I3端控制Q3端时柴油机必须在怠速，否则，I3端将不起作用。

停车回路控制电子调速器关闭执行器输出停车信号，紧急停车回路控制气控阀推动油门杆实现停车。

当二类报警保护停车或按下停车按钮时，主控制电路先输出停车信号，使电子调速器输出停车给机旁执行器。

同时，程序检测转速传感器脉冲信号以确定柴油机是否降速，若检测转速没有下降或下降不多时，Q4端紧急停车信号输出，控制气控阀通路，启动活塞顶出，使油门杆断油，见图2。

按下紧急停车按钮，停车回路和紧急停车回路同时动作。

## 3、从原理上看，主机停车原因分析

### 紧急停车：

超速115%额定转速；淡水出机温度过高85℃；滑油进机压力过低0.15mPa；手动应急停车。

主机在紧急停车状况下停车，集中监控报警系统会显示“主机紧急停车”报警，而此次自动停车时无任何报警，排除这种停车可能。

### 停车：

遥控/机旁手动停车，柴油机在转速﹥350rpm，停车按钮无效，排除汉力士遥控停车在主机额定转速工况下遥控停车误动作原因。

确定为723数字式转速控制器系统故障导致停车。

# 三、故障分析与处理

723PULS控制器安装在金属底盘上的一个电路印刷板。

用于各种转速的船舶推进系统，用来控制中高转速发动机的速度和负荷。

控制器包括感知转速的两路磁性捡拾器，一路润滑油压输入，一路水压输入，一路远程速度设定输入，还有一路根据进气压力限油功能的输入。

## 1、滑油压力与冷却水压力

### （1）润滑油油压

润滑油油压输入信号（润滑油油压信号）需要是高质量的绝缘信号。

使用屏蔽双绞线将420mA电流变送器连接到端口42（+）和43（-）上，见图4。

图4 723PULS 数字式转速控制器模拟量输入接口

此输入并不与其他的控制输入和输出绝缘，所以如果变送器不绝缘的话就需要安装绝缘器件。

如果输入电压小于2.0mA或者输入电压超过21mA，将会检测到输入信号故障。

检测到故障会导致状态指示信号持续报警直到检测到输入信号为止。

从配置上看，输入信号允许报警保护、停机保护。

发动机报警和停机都可以显示在手持编程器上。

停机时激活继电器输出 #1 。

继电器输出 #1连接到执行发动机停机的停机系统和警报系统 。

### （2）水压输入

将水压变送器连接到信号输入 #2 。

水压输入信号必需是高质量的绝缘信号。

使用屏蔽双绞线将4~20mA电流变送器连接到端口45（+）和46（-）上，见图4。

此输入并不与其他的控制输入和输出绝缘，所以如果变送器不绝缘的话就需要安装绝缘器件。

如果输入电压小于2.0mA或者输入电压超过21mA，将会检测到信号故障。

停机时激活继电器输出 #1 。

因此，排除滑油压力和冷却水压不稳定停车。

## 2、转速脉冲故障停车

### （1）速度传感器作用

发动机转速由被动的磁电拾取器（MPU）提供信号给723PLUS控制器，见图5。

图5 转速传感器安装接线

转速传感器必须能够准确的感知发动机的转速。

发动机转速在600rpm。

使用第二个转速传感器用作备用。

当第一转速传感器故障时候第二转速传感器用作替代。

倘若同时使用两个传感器，必须保证它们接收的信号是完全相同的。

两个传感器安置在飞轮盘的上半部分。

转速传感器输入的硬件出厂配置为MPU。

此时输入阻抗低于200H。

转速传感器输入可以通过软件配置成数字信号采集或模拟信号采集。

所有的转速传感器连接都需要屏蔽。

将屏蔽线接地。

确保连接转速传感器的整条屏蔽线是连续不间断的，同时保证与其他所有的导体绝缘。

### （2）执行器停车指令

图6 723数字式转速控制器输出到执行器接线

如图6所示，模拟输出 #3为一个专门为执行器提供电流信号 ，这个电流信号是由端口19（+）和20（-）提供。

通过软件，调节执行器行程的最大和最小值，也就是柴油机的最大油量和怠速油量。

通过硬件，输出电流配置为0~200mA，这种配置允许200mA电流通过40H阻抗，使用屏蔽双绞线连接执行器与控制器。

在任何时候出现速度传感器的输入频率低于额定转速的5%时，控制器会检测到转速丢失。

任何一个速度传感器转速丢失都会导致报警。

如果一个速度传感器转速丢失，发动机仍然继续运行。

倘若两路转速信号同时丢失，开关量输入Speed Fail Ovrd的状态设置为FALSE，控制器将燃油需求降为0，柴油机将自动停车。

对右主机飞轮上端两只用于723数字式转速控制器的转速传感器进行检查，发现其中一只针孔式插头内油污严重，存在接触不良，另一只插头连接良好；

两只传感器脉冲信号传输线正常连接，但导线连接屏蔽线处于中间断路。

经检查确认后，更换备用转速传感器一套，拆下来的传感器进行清洁、除油、备用，并两只转速传感器重新接线，屏蔽线可靠连接，调节传感器到飞轮齿间隙到1mm。

在随后观察的故障期内，无故障报警停车现象未再出现。

# 四、结束语

中策GN8320柴油机无故障报警而自动停车的现象具有典型思考意义。

通过研究，可以总结出以下经验：

（1）中策GN8320柴油机振动比较剧烈，而且飞轮时有甩油现象，要定期对转速传感器进行检查，检查项目至少包括：接线紧固情况、传感器固定螺栓、传感器齿间间隙、传感器油污清洁。

（2）两只转速传感器互为备用，当一只传感器出现问题时不会导致停车。

平时检查传感器状况可以用万用表频率档测量脉冲：额定转速600rpm时脉冲信号在1.865Hz左右为正常。

（3）根据不同的故障停车现象，寻找故障的源头。

无故障报警停车可以在三个方面进行排查：

气路方面，气动电磁阀7有无漏气现象；主机转速低于额定转速时，考虑HELICE遥控系统给定转速信号是否正常，可以测量723数字式转速控制器51/52接口给定电流确认；主机转速传感器工况。
