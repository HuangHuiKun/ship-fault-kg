# 一 我们需要调速器达到的要求包括
- 手动调速、停车
- 遥控调速、停车（电控、气控等）
- 启动转速要求
- 升速时间要求
- 转速限位要求
- 性能指标要求
- 特殊要求（电子或电液调速器才能达到）

# 二 调速器的基本使用要求
这项工作主机厂已经帮我们选择了最佳匹配方案。
如果我们的调速器故障换新，就按原机原厂相同型号采购即可。

## 1. 选择合适的调速器
- 正确的计算调速器工作能力，克服柴油机油门机构的阻力，是选择合适调速器的前提。
- 调速器的工作能力应比移动被调节发动机的调油机构所需要的工作能力约大50%。
- 为了获得较好的调速性能，在设计调油机构时，要适当选择燃油泵齿条与调速器输出轴之间的传动杠杆比。
- 同时要注意输出轴的角位移与油泵齿条的位移成线性关系。
- 应使输出轴的加减油方向与燃油泵齿条的加减油方向一致，并应设置作用于减油方向的复位弹簧。

## 2. 正确选择传动速比
应使柴油机的标定转速接近或等于调速器工作转速的上限。

## 3. 调油机构配置合理、间隙尽量小
- 调速器输出轴的全部转角范围内，燃油泵齿条能否断油、能否提供所需的燃油量。
- 调速器工作油的油面应处于游标刻度线之间。

# 三 使用前必须阅读调速器使用说明书
- 调速器外观检查(油漆、密封)
- 检查调速器型号是否与柴油机相匹配
- 检查调速器转速是否与柴油机相匹配
- 检查调速器停车按钮是否正常
- 检查调速器输入传动轴是否灵活无卡滞
- 检查输出轴、调速轴转动是否正常
- 检查调速旋钮是否能旋动（阻力均匀）

# 四 安装时必须要对中，防止调速器咬卡
- 柴油机与调速器连接的花键套回转中心线，应与调速器的传动轴回转中心线保证同心。
- 调速器与柴油机的安装结合面之间必须放置软质垫片。
- 传动轴花键处的配合间隙要适当，以调速器传动轴能否靠自重滑入内花键为准，不宜过松或过紧。
- 过紧时，切勿敲打，必须拆下有关零件，检查修整装配间隙。
- 调速器在柴油机上紧固前，必须进行盘车或低速运转，使其传动轴与有关驱动系统自行对中，防止咬卡，损坏调速器。
- 正确选择传动速比。
应使柴油机的标定转速接近或等于调速器工作转速的上限。
- 柴油机的调油机构必须灵活无阻，传动精确。
间隙过大或过小均会造成柴油机转速不稳。应进来减少杆件的数目，建议能采用球铰链结构。
杆件与连接销的配合间隙保持在0.02毫米为宜。
- 调速器工作油的油面应处于油标刻度线之间。
