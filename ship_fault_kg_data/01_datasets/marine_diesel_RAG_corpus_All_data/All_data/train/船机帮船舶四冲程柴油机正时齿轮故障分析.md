# 导读

在对安庆大发6PS－26H型船舶四冲程柴油机出现的齿轮故障原因进行分析的基础上，对船舶柴油机正时齿轮拆检修复过程中遇到的一些技术问题进行了探讨研究，并从机务管理的角度提出了一些管理建议，供船舶轮机人员参考。

# 故障发生

安庆大发柴油机累计运转26548h，上次吊缸后累计使用2612h，当运转使用2580h 时，按检修计划将6只缸头悉数吊下清洁，进排气阀研磨。

检修调整后测试显示该机运行状况良好，工况平衡。

在未查明异响来源而主观盲目启动的行为，虽然未导致直接的后果，但无疑是很危险和错误的。

# 故障检查

检查中，发现曲拐箱轴系均正常。

但是从No.6缸底部拾到一些金属碎块，其中最大一块约15mm长，成齿形，初步怀疑是某齿轮的齿崩块，后经证实是螺尾锥销的头部圆柱体断块，被运行中的齿轮趴合压出的模型。

这些螺丝断块，带有明显被压过的痕迹，后证实是螺尾锥销的尾部螺纹部分，其他皆是小碎块。

拆惰齿轮轴座盖3时，发现其4只螺丝2均被 剪切并已变形，其中一只已发生断裂。

# 拆卸过程注意事项

说明书提供正时齿轮的拆卸程序，不妨参照执行。

由于受空间限制，说明书上 “拆开一只飞轮螺栓并将其移到联轴节上”拆卸程序，实际操作起来很费劲。

飞轮螺栓是过盈配合的，受诸多限制，只 能用恰当的螺栓来顶退，惰齿轮1#可作支撑面，将飞轮螺栓慢慢顶移至联轴节上，注意不要顶偏，当仅露出销孔时就算到位，惰齿轮正好能取出。

禁止盘车，在拆卸过程中曲轴不得有任何转动位移变化。

凸轮轴同样禁止转动，不得改变其与曲轴的相对位置。

因此拆卸凸轮齿轮前要自制专用工具来卡住 ( 厂家未提供专用工具) ，防止在拆卸齿轮过程中产生任何位移。

凸轮齿轮与凸轮轴是靠键传动，紧配合，轴位上有一定的锥度，厂家未提供专用拉码工具来拆卸，也需自制。

若太紧，平衡拉紧后用铜锤敲击，使之松动，切不可强拉，以防损坏部件。

# 故障分析

正时齿轮机构是由曲轴齿轮通过惰齿轮带动凸轮轴齿轮。

惰齿轮则由惰齿轮1#和惰齿轮2#用铰制螺栓4紧固在一起组成，而支撑它的惰齿轮轴7的 一端是由4只螺栓5 ( Bolt M16 × 2.0 × 38) 固定在机体上，且由2只螺尾锥销 ( Knock bolt 10 ×35) 来定位，而螺尾锥销则是由螺母 ( Nut M8 × 1.25) 锁紧固定在防松垫片上，另一端由安装在正时齿轮箱壳的惰齿轮座3来牢固支撑，并由油孔螺栓1注入滑油。

惰齿轮轴是正时齿轮传动的关键和保证，除维系惰齿轮外，还承受着两对齿轮啮合传动产生的推力，以及由此而产生的剪切力，当然还有机体固有的震动。

从拆下的惰齿轮轴来看，锁紧螺栓5的防松仅靠垫片简单地折边，螺母6却毫无防松措施。

柴油机运行产生的震动。当功率不平衡、轴承间隙变大等引起震动加剧，在长期作用下，使惰齿轮轴防松装置逐渐失效，导致螺栓5逐渐松动，引起防松垫片松动而不断剧烈震动，也使得螺尾锥销的螺母6逐步松动并最终脱落。

惰齿轮轴和防松垫片一旦产生震动，就使螺尾锥销不断被剪切，长期作用的结果终使其头部圆柱体被磨切分断而掉落到惰齿轮2#上，并被高速传动的齿轮压扁，从而引起啮合齿轮的损伤。

而锥销插埋在机体上的头部尚断留在其孔洞里，最细的螺尾颈部 (D5.8) 更是早被防松垫片剧烈的来回震动而生生切断。

上述现象的存在，终使惰齿轮轴不紧凑，啮合间隙变大，运转声音变大，震动加剧，由此形成恶性循环，导致故障发生。

# 故障原因

早期那次拆检未按要求进行或有所忽略而留下隐患，惰齿轮轴防松装置设计过于简单，甚至不合理，保险系数不够。

1) 螺尾锥销的作用是为惰齿轮轴定位，应有足够的防范措施来保证。

一是防松垫片上留有的孔过大，该孔应是 10mm＞D＞8mm，并以稍大于8mm为宜，这样即使螺母6松脱，也不至于让螺尾锥销轻易掉出;

二是螺母6要有有效的防松措施，对螺栓5的防松不够。

2) 整机设计欠缺，没有留有正时齿轮室检修的空间。

尤其是常规例检太麻烦，仅能从 No.6 缸主轴承撑杆空隙来观察，且受限制太多，也无法看到齿轮的啮合处，因而这一重要工作很容易地被疏忽甚至废弃。

3) 轮机管理人员重视不够，使用说明书之维护保养 “正时齿轮2年拆检一次，检查齿面并作比色检查”的要求形同虚设。

# 故障排除

用1mm 厚薄钢板做惰齿轮轴的防松垫片。

螺母6及螺栓5采用钻孔钢丝“8”字串联在一起和垫片折边贴紧两种防松措施。

图   5   惰齿轮轴修理示意图

惰齿轮2#及凸轮经精密修锉后，传动正常。

检查齿隙正常、齿间啮合情况良好，考虑传动摩擦副的配合及经济性，决定仍然继续使用。

装配时绝不改变凸轮轴与曲轴的相对位置。

需做一把由三角锲块焊接加长铁杆的专用工具来顶回那只飞轮螺栓。

# 若干建议

1) 管理大发柴油机一定要细致认真，严格要求，不抱侥幸心理，不放过任何异常。

事发前端盖螺丝松动，滑油外泄飞溅，实际就是故障征兆，但重视不够，没有作更细致深入的检查。望同仁引以为戒、提高警惕。

2) 虽然难以做到拆下正时齿轮箱壳来检查齿轮传动机构，但只要认真对待，在每次内部例检中从第6缸位盘车仔细检查齿轮接触面还是可以做到的，建议至少每3个月检查一次。

3) 保持良好工况，更重要是功率平衡，减少震动。

运行中经常倾听声音是很有必要的，在机房对于逐渐而缓慢变差的声音有时是难以察觉，当时听该机的声音之所以无觉不妥，其实是习惯和错觉的延续，现在听之方知差别。

4) 船舶上备一套正时齿轮机构备件。

5) 对正在大修或厂修的机器，不妨增加正时齿轮的检修。
