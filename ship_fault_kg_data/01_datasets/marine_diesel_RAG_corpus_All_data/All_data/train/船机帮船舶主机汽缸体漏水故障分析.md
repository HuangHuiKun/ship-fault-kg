# 导读

从一起MAN B&W 5S60MC型主机汽缸体漏水故障出发，分析主机汽缸体漏水故障原因，提出主机汽缸体漏水故障预防措施及管理对策。

# 一、故障情况

某船是一艘载重吨为73601t的巴拿马型远洋散装货船，2004年江南造船有限责任公司建造。

配备上海沪东重机制造MAN B&W 5S60MC型主机1台，主机汽缸5只，缸径600mm,额定功率10200kW,额定转速105 r/min,二冲程直流扫气。

某年4月12日19:20,该轮空载抵青岛锚地加油，辅助燃油锅炉工作。

4月12日23: 45,接班机工在交接班过程中，发现辅锅炉炉膛靠近吹灰阀附近面积大约40cmx80cm的钢板烧红。

船舶轮机人员紧急停炉扫风，进入炉膛检查，发现耐火泥脱落，固定耐火泥的钢板崩裂突起。

于是停止辅助燃油锅炉工作保压备用，主机、副机换轻油，并联系公司紧急供船铝硅酸盐水泥及耐火沙，由船员自修。

4月13日20: 25，该轮加油结束，驾驶台通知机舱备车。

20: 30主机淡水膨胀水柜补水至正常水位,21: 30主机淡水膨胀水柜再次低位报警，同时，三管轮发现主机曲拐箱玻璃窗内滑油油流有水雾。

轮机长认为问题严重危及主机安全,迅速将情况报公司，请求通知代理中止办理开航联检手续，推迟开航，查找主机漏水原因。

公司机务分析认为上述现象应该是船舶停止辅助燃油锅炉工作，主机暖缸水温度低，主机构件漏水造成。

慎重起见，要求船舶尽快打开主机扫气道道门检查，首先确认主机各缸缸盖、缸套是否裂纹漏水。

若检查扫气道未发现异常，则可以判定主机滑油系统内淡水应该是主机缸盖、小水套、水套、冷却水接头漏水，通过汽缸体的前后结合面漏入曲拐箱导致(汽缸体水腔厚壁裂纹可能性很小)。

并建议船舶:

1、打开曲拐箱查看漏水量。

2、辅锅炉小火升汽供汽，主机暖缸。

3、继续观察主机膨胀水柜水位是否下降。

4、尽快开滑油分油机分油。

5、主机开航，开始时降速航行，至分油机出水口无水，主机滑油颜色恢复正常后再加速。

22: 00轮机长报告:"打开主机扫气道道门检查，未发现异常;打开曲拐箱，在No.4曲拐箱内发现No.3~4缸间机架上部与汽缸体的结合面漏水。

现在，辅锅炉蒸汽压力0.18 MPa，主机缸套水温度53℃(辅锅炉升汽前缸套水温度41℃)，漏水未见明显改观。

将继续暖缸，有关情况后告。

4月14日02：00，主机暖缸水升温至75℃，主机No.3～4缸间机架上部停止漏水 ，主机淡水膨胀水柜水位也不再下降。

02：20该轮上引水顺利开航。

持续分油30天后，主机系统滑油化验品质 良好。

# 二、故障分析

图1 十字头柴油机汽缸体、机架、机座连接

如图1所示，在十字头式柴油机中，汽缸、机架和机座分开制作，然后由贯穿螺栓连成一刚性整体。

这一刚性整体构成了柴油机的主体部分。

汽缸体 、机架和机座构成的箱体内部安装运动部件的导承和支承——汽缸套、导板 、主轴承等。

整个机架为一刚性整体，由上面板、底板 、横隔板和左、右侧板焊接而成，横隔板上有与机架高度一样的导板。

汽缸由汽缸体和汽缸套组成。

图2 主机汽缸体结构

如图2所示，MAN B&W 5S60MC型主机为了制造、拆装和维修方便，将汽缸体做成3个汽缸的缸体和2个汽缸的缸体铸成一体的分组式。

汽缸体采用灰铸铁制造，下部有底板将汽缸与曲轴箱隔开。

汽缸体安装于机架之上，2只分组式汽缸体与机架结合面保持密封相对良好。

3个汽缸的缸体和2个汽缸的缸体通过紧配螺柱、螺栓、螺母连接为一体。

如图2中，2只汽缸体的结合面没有采用开槽安装橡皮令密封设计，而是依靠高光洁度和平整度接触平面涂胶用螺栓把紧水密，顶部安装密封压条、垫床辅助密封，防止主机缸盖、小水套、水套、冷却水接头漏水漏入2只缸体的结合面。

发生故障的原因：

暖缸水温度低，主机缸盖、小水套、水套、冷却水接头漏水；

3个汽缸的缸体和2个汽缸的缸体温度降低冷缩，2只缸体的前后结合面间隙变大水密性变差；

2只缸体顶部安装的密封压条下垫床密封老化；

主机缸盖、小水套、水套、冷却水接头漏水漏入2只汽缸体的前后结合面，从No.3-4缸间机架上部与汽缸体的结合面漏出，因船舶空载翘头，吃水差大，所以出现主机No.4缸机架上部漏水现象。

上述故障现象多见于10年船龄左右或以上船舶主机。

某拥有35艘远洋船舶的航运公司，曾发生过主机汽缸体漏水故障的船舶有4艘。

# 三、管理对策

东京备忘录秘书处2013年1月28日发布通告 ，2013年9月1日一11月30日东京备忘录将与巴黎备忘录共同开展关于推进和辅助机械的集中大检查。

机舱设备漏油、漏水、漏气现象将不再仅仅定性为维护保养不到位的问题，而是将直接导致船舶被PSCO滞留的严重事件。

此前，已有世界某知名航运公司所属2001年制造 、悬挂巴拿马旗的散装货船因主机漏水一项缺陷于2013年2月23日被西班牙PSCO滞留。

报告批注为：

1、主机No.5缸缸头水套漏水；

2、上述滞留缺陷表明ISMCODE运行失效。

船舶主机性能与辅助装置的技术状态息息相关，轮机管理是一项系统工程。

轮机管理人员只有在日常检修中，对主机及相关装置全面统筹，精心维护，严格管理，才能有效地保证船舶主机始终处于安全可靠和经济的运行状态。

为避免主机汽缸体漏水应考虑采取如下措施:

(1)临时措施为主机缸体前后结合面上部缝隙清洁涂玻璃密封胶。

(2)结合面密封压条下垫床定期换新。

(3)切实做好辅助燃油锅炉维护保养工作，确保锅炉处于随时可用和正常工作状态。

(4)主机暖缸水保持75-80℃。

(5)加强冷却水处理，按要求化验投药，主机补水同时投处理剂，减少水垢生成，减缓密封圈老化。

(6)避免主机加减速过快，加减速过快后导致调节器来不及动作，冷却水温波动大;控制主机热负荷不要太高，尤其单缸负荷大，调整各缸负荷均匀。

(7)缸头水套、水套、冷却水接头橡皮圈定期更换，环槽清洁要彻底;安装密封圈不可扭曲，涂抹软肥皂，减少摩擦。

(8)主机贯穿螺栓、分组汽缸体连接螺栓定期检查有无松动。

# 四、结束语

轮机长、大管轮等高级轮机管理人员应该对本船诸如主机、副机、锚机、舵机、锅炉“四机一炉”等轮机关键设备的原理、结构、性能做到了如指掌，烂熟于心，以便在船舶营运中关键设备出现故障时，能够快速做出正确判断，准确分析、查找和排除故障。

远洋船舶70%的时间航行在茫茫大海上，经常处于一种前不着村后不着店的状态，并会遭遇各种恶劣气象条件。

轮机关键设备发生故障时，完全依赖岸基支持指导是远远不够的，毕竞岸基支持远离现场，做出的判断往往相对迟缓，与实船现场发生的事件有一定差距。

作为一名现代化船舶的轮机管理人员，应提高自身业务素质，练好内功是根本。

船舶轮机管理人员应当积极做好船舶推进和辅助机械的维护保养，采取有效措施杜绝机械设备存在的“跑冒滴漏”现象，顺利通过港口国、船旗国检查及船级社各类检验，防止船舶滞留等雪上加霜事件发生，确保船舶安全营运。
