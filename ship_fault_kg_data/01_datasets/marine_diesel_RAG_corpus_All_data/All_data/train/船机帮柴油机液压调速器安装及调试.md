# 导读

调速器是维持柴油机稳定运转和保证安全的重要部件，相当于人体大脑，其功能表现在：

在启动和停车时能保证安全启动和快速停机；在运转中能根据负荷变化自动改变高压燃油泵燃油供油量，确保柴油机稳定运转。

所以正确安装和调试修理后的调速器至关重要，也是保证以后能否正常使用的基础。

随着使用时间增加，柴油机各项性能会逐渐发生变化，为了使用需要，机器使用者会通过稍微调整单缸高压燃油泵供油量来改变工况，以满足安全和使用要求。

由于单缸调整或机器修理后，调速器和燃油总杆的连接位置会产生变化，如果一直按照原来位置安装调试，将会因为使用范围位移而使整台柴油机无法正常合理使用。

只有了解调速器的安装要求和调试原理，随时加以调整调试，才能使柴油机发挥出最佳的使用效果和性能。

在修理后的调速器在上机安装调试和后期的使用维护上，如果使用者对柴油机和调速器的匹配使用机理不能全面了解，一旦出现安装或调试错误，轻者会造成无法启动、运转和无法达到所需性能，严重的会引起飞车等重大安全和设备损毁事故。

本文有针对性的就常用的调速器修理后的安装和调试分别进行实际操作阐述。

# 一 理论安装原理和依据

目前船用中高速柴油机最常用的进口液压调速器大致有美国伍德沃德(WOODWARD) 的 UG系列 (UG8、UG10、UG15、UG40等 ) 和SG、PSG 系列，日本的RHD系列 (RHD6、RHD10)、NZ系列(NZ51、NZ61)，其中数字表示调速器输出的动力参数，其外形和安装调试同类型是相同的。

RHD6型调速器铭牌

无论何种调速器都是通过调速器输出轴的线性或转角变化带动柴油机高压燃油泵的齿条拉杆控制燃油量，以达到控制柴油机转速的目的。

# 二 实际操作修理、调试

依据以上理论原则 ，下面分别对具有代表性的常用调速器UG8、SG／PSG、RHD6／NZ61实际修理后的安装和调试进行说明，其它同系列调速器均可参照，并无区别。

RHD6型调速器拆解维修

所有调速器安装前必须做好安装部位的清洁，确认机座传动部件全部正常，安装平面放置垫片或涂上密封胶后才能将调速器安装到位。

期间需随时盘车，直至调速器下部传动齿自由或稍用力落下至与机座紧密结合后紧固底座螺丝，严禁用螺丝硬紧到位。

如果调速器传动轴是通过伞型齿轮与柴油机啮合传动，则必须保证在调速器安装完毕后啮合间隙在0.20一0.50 mm之间，否则必须通过加减垫片方式调整，以避免由于间隙过小使调速器传动轴偏心运转造成调速器损坏和因间隙过大使柴油机和调速器之间的转速传递产生时间差导致柴油机无法稳定运转。

### (2)调速器安装。

首先将调速器输出轴向减油方向慢慢扳动，同时逆时针转动负荷（油量）限制钮，使负荷（油量）指示的小三角慢慢回到"0"位置；将燃油总杆推至"0"油量，确认各高压燃油泵齿条位置均在"0"油量，期间原则上需拆除燃油总杆上的各种系统保护，以使燃油总杆处于自由活动状态。

调整调速器和燃油总杆的连接杆长度，使其两头连接正好接入固定，顺时针转动负荷（油量）限制钮至最大10格，拉动燃油总杆，确认调速器加减油方向与高压燃油泵加减油方向一致。

接下来通过调整调速器和燃油总杆的连接杆长度调整零位：

标准是当调速器负荷（油量）指示为"0"到"1"格时，高压燃油泵齿条油量指示为"0"格，相当于设置在图1中的A区，以便调速器能安全停车，严禁当负荷（油量）指示为 "0"格时，高压燃油泵齿条油量指示仍在大于"0"的供油位置，而当高压燃油泵齿条油量为最大油量时，负荷（油量）指示应在"9"格以下"8"格左右，即相当于设置在图1中的c区，以保证调速器有充足的油量提供。

调整结束后，必须保证整个连接无大于0.50mm 的累积间隙、活络无阻滞，并在所有活动销上涂上黄油或加上机油等润滑油。

将燃油总杆上的各种系统保护装复。

最后确认：

当柴油机启动后在额定转速、空载无负荷时，调速器负荷 (油量)指示在 "2"～"3"格 左右为最佳。

以上调整确认正确后，可以给调速器加油，确认油品 (T68透平油即汽轮机油)和油位正确 (油位加至油位指示器中心点偏上2mm左 右)。

安装结束，做好调速器周围的环境卫生工作。

### (3)调试。

在初次启动柴油机时，调试人员应就位于调速器旁、观察柴油机启动时调速器与高压燃油泵的连接杆工作状态及动作是否正常。

具体操作：

首次启动前先调节转速加减钮，使转速位置指示三角在最高转速指示的1／2左右的较低转速位置，并将负荷 (油量 ) 限制钮旋至5或 6位置，将供油量限制在最大供油量的1／2，使启动瞬间转速不因为过高而发生机械安全事故。

启动柴油机，负荷 (油量)指示三角会很快 升至负荷 (油量) 限制钮设置的5或6位置，待转速升至设定的转速后，又会迅速返回至 5或6位置以下，此时看转速不再变化后，可将负荷 (油量 )限制钮旋至8到10位置，旋开补偿针阀堵，调节内部补偿针阀 (调整工具只限用一字型螺丝刀，不能使用十字型，且只能放在针阀十字槽的较浅槽内，以免损坏针阀)，打开2圈使机器转速波动，排除调速器内部空气，再慢慢旋回至转速稳定不波动为止，切记不能关闭针阀而使调速器失去作用，针阀开度范围在打开1／8—2圈均可 ，视柴油机稳定性和反应灵敏度而定(特别说明：图2中补偿针阀调整的是转速波动的快慢，而补偿指针调整的是转速波动的幅度大小)。

检查机器正常后，再缓慢调节转速加减钮，使转速慢慢增加至所需额定转速，以上操作 中需随时注意是否有异常，并随时作好紧急停车的准备。

操作中如出现转速超过额定转速的20％时，应立即将负荷 (油量)限制钮旋至0位置，或按下停车操作手柄，若应急停车不起作用，直接推动供油总杆停车。

观察调速器的油位是否改变，是需要再次添加滑油，调速器外是否有漏油现象。

确认正常后，安装调试结束。

## 2.SG／PSG调速器的安装调试

### (1)从外观上看，PSG多一个针阀调整外其它功能均与SG相同。

其输出轴转动角度均为36° (极少 SG调速器也有42°的)。

SG／PSG调速器分2种型式：

调速器失去油压时，调速器内部弹簧回复停车型式和靠调速器外挂弹簧回复停车型式。

### (2)外挂弹簧回复停车型PSG调速器的安装、调试 (SG与PSG相同，不在重述 )。

图3 外挂弹簧回复停车型PSG调速器安装连接图

如图3，先将调速器连接杆与输出轴参照图3位置装妥固定后上机安装调速器，接妥各油管，紧固底座。

外复位弹簧安装到位，调节调节螺纹杆至弹簧间距在2mm左右，此时输出轴位置即是调速器最小零供油位置。

将柴油机燃油总杆拉至最小油量 (确认各高压燃油泵油量必须是"0"格无供油)，期间原则上需拆除燃油总杆上的各种系统保护，以使燃油总杆处于自由活动状态；

调整可调连接杆的长度，使其与调速器输出轴连接杆和与高压燃油泵齿条两端连接正好接入固定；

再将可调连接杆的调整螺丝顺时针压进2—3圈，感觉连接杆的另一端调节螺纹杆处有轻微抬起5°以下，锁紧锁紧螺母，此时相当于设置在图1的A区，以保证安全停车。

向加油方向抬起连接杆确认调速器加减油方 向与柴油机高压燃油泵加减油方向一致，抬起连接杆大约32°时，确认高压燃油泵油量已到最大油量，相当于设置在图1的C区，放开连接杆，自由回复，此时必须保证高压燃油泵油量是最小油量 (各高压燃油泵油量均为0格)，严禁此时高压燃油泵齿条油量指示仍在大于"0"的供油位置，否则重复调整调整螺丝至符合要求并锁紧锁紧螺母，调整结束后必须保证整个连接没有大于0.50mm的累积间隙、活络无阻滞，并在所有活动销上涂上黄油或加上机油等润滑油，最后将燃油总杆上的各种系统保护装复。

以上调整确认正确后，检查调速器下油柜 (使用调速器独立油柜时)，确认油品 (建议 T68透平油即汽轮机油)和油位正确，使用机器系统油时需检查油路是否畅通。

安装结束，做好调速器周围的环境卫生工作。

在初次启动柴油机时，调试人员应就位于调速器旁，观察柴油机启动时调速器与高压燃油泵的连接杆工作状态及动作是否正常。

具体操作指导：

首次启动前视情况先逆时针方向手动调节转速加减钮，使转速设定在较低转速位置 (最低设定转速不能低于启动转速，否则无法启动)，启动柴油机，连接杆会向加油方向转动，待转速升至设定的转速后，又会迅速返回，此时看转速不再变化后，方可放开启动手柄。

检查机器正常后，再缓慢手动调节转速加减钮，使转速慢慢增加至所需额定转速，以上操作中需随时注意是否有异常，并随时作好紧急停车的准备。

操作中如出现转速超过额定转速的20％时，应立即按下停车手柄，若手柄停车不起作用，直接推动供油总杆停车。

观察调速器下油柜的油位是否改变，是否需要再次添加滑油，调速器外是否有漏油现象。

确认正常后，整个安装调试结束。

将燃油总杆上的各种系统保护装复。

最后确认：

当柴油机启动在额定转速，空载无负荷时，调速器FUEL负荷油量指针指示刻度在"2" "3"格左右为最佳。

以上调整确认正确后，可以给调速器加油，确认油品（可以使用柴油机30#和40#机油，但建议使用T68﹟透平油及汽轮机油）和油位正确（油位加至油镜中心点偏上2 mm左右）。

安装结束，做好调速器周围的环境卫生工作。

### (2)在初次启动柴油机时，调试人员应就位于调速器旁，观察柴油机启动时调速器与高压燃油泵的连接杆工作状态及动作是否正常。

具体操作：首次启动前先手动调节转速加减钮，将调速器转速调整在转速较低的位置，使转速指针指示刻度在"4"左右，启动柴油机，此时FUEL负荷油量指针会向增加油量方向转动，待转速升至设定的转速后，又会迅速返回，此时看转速不再变化后，打开调节针阀2圈使机器转速波动，排除调速器内部空气，再慢慢旋回至转速稳定不波动为止。

因此类调速器的针阀顶部有透气孔，在使用中如调节需要可将针阀拧到底，这是和UG8、PSG等WOODWARD调速器的不同之处，故针阀开度范围在0～2圈均可，视柴油机稳定性和反应灵敏度而定。

检查机器正常后，再顺时针缓慢手动调节转速加减钮，使转速慢慢增加至所需额定转速 ，以上操作中需随时注意是否有异常，并随时作好紧急停车的准备。

紧急停车操作和外围检查与SG／PSG调速器相同。

确认正常，安装调试结束。

(2) 电子调速器的性能也比液压调速器有明显的提高，在具有应急手动操作的低速大功率柴油机上得到了广泛的运用。

而目前的中高速柴油机，由于电子调速器的科技性和高维护要求，加上生产厂家的技术保护和电气元器件在恶劣环境中的不稳定性，一旦发生故障，一般机器使用和维护人员都无能力排除，中高速柴油机又无应急手动操作可能，只能停机待修，给船舶航行带来很大的风险，安全问题严重。

所以电子调速器在船舶发电机组等中高速柴油机中推广还有一定困难。

目前使用的调速器还是以成熟安全稳定的液压调速器为主。

所以本文在未来相当时间内还值得推广。

(3) 调速器使用维护要求：

①对于不同型号柴油机所使用的调速器具有严格的针对性，由于各型柴油机性能不同，调速器内部配置是不同的，这些都体现在调速器的设计号(PART NO)上。

也就是说每个型号的调速器虽然外型相同，但根据其设计号不同，内部零配件配置也不同，设计号是针对不同品牌不同型号柴油机而定的，不能乱用。

比如：我们最常见的UG8调速器，根据配置不同有5000多种，分别对应各种不同品牌不同型号柴油机的特性使用，尽可能不要互换，以免引起不必要的故障。

②很多针对柴油机调速器的维护保养说明书，建议调速器换油时可将轻柴油倒入调速器，运转一会儿后，放出轻柴油，换入调速器油，以达到清洗调速器的作用。

根据本人多年修理调速器的经验，建议不采取此方法清洗调速器。

因调速器内部角落较多，不拆下调速器换油不可能放尽内部脏油和清洗的轻柴油，由于轻柴油有分解油污的功能，时间久了，由于剩余轻柴油的作用，会使角落的油污、油垢脱落随调速器油循环流动，一旦流入精密部件，反而会增加磨损和卡死风险。

正确的换油方式是：

拆下调速器倒出调速器内脏油，这样可以放尽内部脏油，装好调速器后再将干净的调速器油加入，运转一段时间后，打开调速器泄油堵放出调速器内脏油，再加入干净的调速器油，这样做虽麻烦，但换油较彻底。

另外不拆调速器也可以用打开泄油堵的方法多换几次调速器油。
