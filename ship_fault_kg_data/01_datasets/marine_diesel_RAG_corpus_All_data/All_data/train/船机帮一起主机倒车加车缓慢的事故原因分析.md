# 一、事故描述

2024年6月15日15:24 LT, 某轮在装载60116吨粉煤的状态下离澳大利亚GERALDTON码头，由于在码头装货时环境温度低，再加上装载粉煤，为了保温及防止粉煤吸入机舱，轮机部人员就将机舱3台通风机关闭，只运行一台供在用副机的风机，所有门及天窗关闭，引水在船，给出第一个车钟指令微速倒车（30RPM), 主机正常启动到微速倒车指令30RPM，间隔2分钟，引水给出第2个车钟指令慢速倒车（38RPM), 主机没有反应，保持在微速倒车的转速上，机舱集控台主机MOP界面及控制及安保面板没有任何报警，接着引水给出第3个车钟指令半速倒车（52RPM),主机还是没有反应，仍然保持在微速倒车的转速上，当时的判断是不是驾控台遥控面板是否有警报没有复位，马上去驾驶台查看，驾控台遥控面板没有报警及要复位的，随后立即去机舱集控室，检查主机MOP面板，发现MOP面板上主机油门（FUEL INDEX LIMITER)LAMADA 限制，主机扫气压力为0.06BAR，询问大管轮，供给主机增压器的机舱供风机（NO.2)有没有开，他说没有开，赶紧启动机舱供主机增压器的风机（NO.2)，启动后大约5秒后，主机转速马上从微速倒车(30RPM)至全速倒车（52RPM)。此时主机油门LAMADA限制值（68）大于实际值（66），主机扫气压力值为0.51BAR.引水就此事电话向港口当局投诉，造成非常被动的局面。

# 四、事故原因分析

## 1、造成此时事故的直接原因是备车时供给主机增压器的机舱通风机（NO.2)没有启动，导致主机加速所需要的供风量及扫气压力不够，主机保护系统激发油门LAMADA限制（FUEL INDEX LAMADA LIMITER),致使主机加不了车，通俗地说，燃烧的三要素(可燃物 - 燃油，助燃物 - 氧气， 着火点 - 压缩达到燃点）中缺少助燃物（氧气），就是风量（氧气）不够，主机就不会加油门，主要目的是防止燃烧（油多气少）冒黑烟。对于本船主机，如果设定转速为slow astern(38rpm), 主机控制系统给出的油门限制值（Limiter)为52， 而此时油门实际值为52时，主机的实际转速此时如果没有达到38 rpm时，主机MOP界面FUEL INDEX LIMITER就会显示 LAMADA限制(参考下图），主机转速就会上不来，另外通过MOP界面查看扫气压力值也能判断，本船主机在微速前进（或后退时)@30RPM，扫气压力为0.07BAR左右，在慢速前进（或后退时)@38RPM，扫气压力为0.16BAR左右,在半速前进（或后退时)@52RPM，扫气压力为0.51BAR左右,在全速前进（或后退时)@63RPM，扫气压力为0.70BAR左右,如果在各种车令转速下，扫气压力满足油门要求，主机机就不会加不了车的。

## 2、造成此时事故的间接原因是驾驶员不熟悉主机燃油限制取消的操作方法。

# 五、应对措施

本船主机是电喷主机，主机安保系统比较全面，尤其是低转速时，主机会有LAMADA油门限制，就是说，主机低转速时，如果扫气压力没有跟得上，主机油门会限制，这样的话，如果引水要加速，主机会加不上速度，为了及时提供给引水要求的车速，就应该取消主机油门(Fuel Limit)限制，这样主机就会马上达到引水所要的车令转速，有时会遇到主机转速禁区（40-50RPM),这时适当的加点油门刻度，使主机转速越过转速禁区。

## 如何取消主机限制？

步骤如下：

1、看驾驶台主机操作板车种设定的车速：TLG BC: xxx rpm,

主机运行实际转速：ME : RUNNING yyy rpm,

如果主机实际转速（yyy)达到车种设定的车速(xxx)

这时LIMITER这一栏会显示No limit,这种状况不要取消限制（LIMITER: NO LIMIT)

如果主机实际转速（yyy)没有达到车种设定的车速(xxx)，这时LIMITER这一栏会显示Governor limit.(LIMITER: GOVERNOR LIMIT), 这时就要进行LIMIT CANCEL.

2、按下驾驶台操作板LIMIT CANCEL按钮，这时驾驶台操作板会报警，没有关系，先消声（STOP HORN),等主机转速（yyy)达到车种设定的车速(xxx)时，再次按下驾驶台操作板LIMIT CANCEL按钮复位，复位后一定要用ALARM ACKN消除警报，先按ALARM LIST,再用ALAM ACKN按钮消除，最后用ESC键返回主菜单，否则主机会启动闭锁，驾驶台启动不了主机，消除警报后，驾驶台操作板应该0 ALARMS.

3、驾驶台操作板主菜单界面如下，如果没有主菜单界面，多按几次ESC键就可到主菜单界面。

# 六、事故预防再次发生的措施

1、对轮机员进行主机MOP界面和遥控系统性能的学习和培训。

2、对驾驶员进行主机遥控系统取消主机限制操作培训。

3、轮机长备车时密切监控主机MOP界面，及时发现问题，及时应对处理。

4、备车时按主机说明书规定的程序和要求进行仔细检查。
