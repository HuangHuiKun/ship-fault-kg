# 导读

德国科隆的道依茨公司生产的道依茨发动机具有外形尺寸小、重量轻、经济性好、使用可靠、安装简便、维修保养方便、对环境污染相对小等优点，加之热效率高、动力性好、安全性高等特点而被广泛使用，尤其适用配套在矿山井下、隧道施工用采掘及工程设备上，但由于其系统结构复杂，使用要求高，因此只有熟悉其结构原理，掌握设备常见故障维修知识，才能充分发挥设备效能，保证设备经济、安全、正常运转，使之更好的为生产服务。

# 一 冷却系统故障

冷却系统最常见的故障就是冷却液温度不正常，造成的原因大致为可以下几个方面：

1. 油底壳油面过高。

分析：

若油底壳油面过高，以致连杆轴颈浸没机油中，柴油机运行时，曲轴、连杆大头搅动机油会因摩擦产生附加热量。

基于以上原因，附加热量在机油冷却器中传递给冷却液，使冷却液温度额外的增高。

2. 不正确的压力盖或失效的压力盖会使冷却液过量损耗和柴油机过热。

3. 空气或燃烧气体进入冷却系统。

分析：

a. 空气进入冷却系统因受热会使冷却液溢出同时空气受膨胀、冷却系统压力高，使压力盖打开，从而造成冷却液损耗增大；

b. 气缸盖垫片泄漏使燃气或压缩空气进入冷却系统也会产生上述相同的后果；

c. 若进入冷却系统的空气或燃气来不及排出，会随冷却液回到水泵进水口，造成水泵流量下降，引起柴油机出水温度升高。

4. 冷却水泵流量减少。

分析：

皮带松动或水泵叶轮损坏也会使其流量减少，但在检查其流量和更换水泵之前，应按排除故障程序先检查其他有关部分。

# 二 润滑系统故障

诊断润滑系统故障，必须检查与机油有关的各个部位，如油压表、机油液、机油污染情况、机油粘度等。

1. 机油消耗过大

首先要判断柴油机是否有外部漏油；

其次，检查柴油机曲轴箱通风系统是否受阻；如果活塞环密封不良，机油进入燃烧室被烧掉或漏气量过大，机油滴随同泄漏的燃烧气体经曲轴箱通风机构吹出机体。

2. 油压过高

在寒冷的天气，柴油机初次起动后，油压通常会过高。

还有可能是机油压力调节阀在高压位置卡死、机油油位过高、机油粘度过高等。

3. 油压过低

许多润滑系统的故障都能使油压降低。

当发现油压过低时应首先确定柴油机油油位、机油滤清器、油压表、机油泵、油质是否正常，然后再检查其他系统部件。

(1) 机油冷却器

可能的部位：

冷却器破裂、进出油法兰松动、垫片损坏 以及冷却器芯子破裂等。

检查办法：

在柴油机运行时，机油压力高于冷却液的压力，若机油冷却器出现上述任何一个毛病，都会使机油混入冷却液中。

打开散热器盖，便可看到冷却液中有机油，且冷却液会从散热器溢出。

(2) 中冷器

分析：

若中冷器泄漏，冷却液漏入进气管后流进气缸内会通过活塞环通道漏入油底壳。

检查办法：

拆下中冷器检查是否有冷却液漏入进气管的迹象。

# 三 燃油供给系统故障

1. 低压油路漏气。

检查输油泵进油管、柴滤进油管及油箱是否泄漏；若柴油机功率不足，首先应该检查、清洗柴滤；检查手油泵（该处发生的问题最多）；检查油箱通风口（排空气用、看是否堵塞）。

2. 调速器损坏。

3. 冒烟限制器故障。

设在冒烟限制器上的限烟器是利用进气管中的空气压力来调节空-燃比以达到控制烟度的目的。

限烟器损坏会造成功率不足和排烟增大。

若进气管至限烟器的空气接管漏气或堵塞也会引起功率降低和排烟增大。

如果冒烟限制器上的真空管断裂，会造成柴油机功率下降。

4. 怠速。

柴油机低怠速调整螺钉可以调整，如果低怠速太低，会使发动机在怠速时游车，千万注意：高怠速调整螺钉不可随意动，否则会引起发动机飞车。

5. 气缸。

判断哪个气缸是否不工作，可采用断缸法进行检查。

确定哪缸后，拆下发生故障的喷油器进行调试，同时检查喷油器是否多装了密封铜垫片，喷油器是否有故障，可以将其接到发动机体外进行试验。

6. 回油。

通过在额定转速状态下，检查柴油机回油量的情况以确定油路是否有问题。

# 四 进、排气系统

进入气缸的空气应保持清洁，若进入气缸的空气带有灰尘和脏物将会造成气缸套、活塞、活塞环的早期磨损，并且也会损坏气门杆和导管，较大的垃圾还会损坏涡轮增压器的叶片。

1. 进气漏气

（1）进气阻力太大造成冒黑烟和功率降低。

（2）增压柴油机烟度过大或功率降低可能是由于进气管的压力段连接松动或橡胶管造成严重漏气引起。

（3）进气系统漏气，除了用肉眼检查外，还可以用肥皂泡沫抹在可能出现泄漏的地方进行检查。

2. 排气部分故障

检查排气管和增压器的排气漏气，垫片泄漏、排气管、消声器的阻力，排气泄漏和阻力增大会引起增压器转速下降、压入气缸的空气量减少，柴油机进气压力降低，排烟增大、功率下降。

（1）增压器发生故障，降低其增压效能引起柴油机功率下降和烟度增加。

（2）柴油机的机油以其工作油压通过进油管供应增压器润滑轴承并提供一些冷却。

回油管连接在增压器中间壳的底部，机油沿着回油管回到柴油机的油底壳。

增压器转子部分的两端均有密封环。

机油从密封环泄漏虽是少见，但仍有可能发生。

检查办法：

以上问题可拆去涡轮排气管和压气机出气管，检查是否有从密封环漏出的机油。
