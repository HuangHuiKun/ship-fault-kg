# 导读

“湛港拖六”轮主机为瓦锡兰6R22/26中速柴油机,2001进厂修理,柴油机装复试机时, 左主机高温冷却水系统水温过高,报警系统报警自动停机,下面就此故障原因进行分析。

# 一、瓦锡兰6R22/26柴油机冷却水系统特点

该机用淡水冷却,分为高温冷却水系统和低温冷却水系统 (如图1) 。

图1

## 1、高温水系统

高温水系统用于气缸、气缸盖和增压器的冷却。

首先由高温水泵对其系统加压 ,冷却水从泵流向进水总管 ,然后一部分水分配到各个气缸水套 ,再通过各个联接管到达气缸盖,由中间板令水流沿着气缸盖底板绕气阀流动直至排气阀座。

接着,冷却水从气缸盖通过联接管路流向出水管,另一部分水则流向并冷却增压器。

两部分水会集到放气水箱后经调温阀流到中央图1冷却器，形成循环。高温水系统的调温阀为有一个设定值的常规阀。

## 2、低温水系统

低温水系统用于空冷器和机油冷却器的冷却。低温水泵对其系统加压 ,低温冷却水经过空冷器进入机油冷却器 ,经调温阀回到中央冷却器 ,形成循环。

低温水系统中有一个二级调温阀 ,该阀的内部串联安装有两个调温元件,因此有两个设定值。

高温冷却系统和低温冷却系统共用一个中央冷却器;该轮由于造船时把主机膨胀水箱放置过低,未能保证主机说明书要求的水压 ,后另增加一个高位膨胀水箱,分别与左、右主机的原低位膨胀水箱用水管联接来保证水压 ,高位膨胀水箱与左、右主机的原低位膨胀箱的联接管上分别装有截止阀 ,各主机水泵补充水管联接其低位膨胀水箱,主机放气水箱的放气管同时与高位膨胀水箱联接。

# 二、故障分析及排除

柴油机装复调整后,起动试机:

右主机运转正常;左主机在相同转速下,油压正常,高温水系统水压力为1. 35kg/ cm²,并且水压不稳定,主机运转15分钟后,高温水达 100℃,左主机报警系统报警自动停机。

因为主机刚完成修理,所以冷却系统高温冷却水温度超高可能有以下原因:

(1) 系统调温阀故障:在修理后,调温阀拆出清洁检查正常,因此该故障也排除。

(2) 水泵故障:该高温冷却水泵在修船时拆装解体更换泵叶及阻水环,全部尺寸都符合说明书要求,安装工艺符合要求,在装复主机运行过程中,水泵检漏孔中的泄漏属正常,因此排除水泵的原因。

(3) 系统有气:主机在该转速下,进厂前记录数据为高温水泵出口水压1.5kg/ cm²,修理后出口水压1.35kg/cm²,并且压力不稳定,可判断系统有气。

可是在动机前加水时 ,已按说明书要求从放气箱把机体内的空气完全排出,水泵吸入管路也没发现有漏气的地方,最后经查找发现低位膨胀水箱上部积聚有气体,经从左主机低位膨胀水箱上放气后,重新启动左主机,高温冷却系统水压力回复1.5kg/cm²,水温正常,可以正常试机出厂。

低位膨胀水箱与高位膨胀水箱直接相连,为什么能聚积气体呢?

因为工人在右主机放气时已把高位膨胀水箱装满水,然后在左主机加水放气时，打开与左主机低位膨胀水箱相连的截止阀，然后从左主机放气水箱放气,这实质上放出的只是机体内部的气体,而低位膨胀水箱及入泵管路内的气体全部聚集到低位膨胀水箱上部,在高位膨胀水箱的水压下,又不能通过与高位膨胀水箱连通的管路排出,而在低位膨胀水箱的四个角落形成气垫。

另外，为什么高温冷却水温度过高呢?

因为高温水泵的补充水直接由低位膨胀水箱补给,所以高温冷却水泵就会吸入低位膨胀水箱中的空气,引起水压不稳,进水量减少 ,结果造成高温水系统水温升高。

# 三、结束语

通过上述故障分析与排除可知,修理柴油机后加水排气时应当具体情况具体操作,应设法把柴油机水系统的气放完,而不仅仅是在柴油机上最高点放气就误认为系统的气体已放完了。
