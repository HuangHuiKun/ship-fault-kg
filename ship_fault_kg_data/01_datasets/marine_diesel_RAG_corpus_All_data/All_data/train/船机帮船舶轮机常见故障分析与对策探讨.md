# 导读

轮机系统组成复杂，设备零件繁多，当船舶运行一段时间后，轮机系统难免会出现各种异常情况。

作为轮机管理人员应该通过正确的方法来判断发生故障的根源，从而高效地解决问题，使船舶尽快投入作业中。

当故障发生首先要做的是分析故障表现，故障的表象一般为机械材料破坏。

而造成这种后果的原因除了正常的材料老化、疲劳断裂外，还与其他介质有关，如冷却水、润滑油等等。

分析这些介质的指标也能快速找到故障的原因。

因此通过科学的方法来排除故障可以让现场的维修人员少走弯路，彻底地消除隐患。

# 一、船舶轮机常见故障的分析及解决措施

## 1、柴油机拉缸的分析与对策

作为轮机故障中最为常见的现象之一，指的是气缸内壁被活塞刮出很深的沟纹。

拉缸会影响轮机的正常运行，如果没有及时发现将进一步对轮机造成更大的损坏。

另外，拉缸还会使得轮机内部油温上升，令曲轴箱内冒烟，水循环受到阻碍。

发动机拉缸的原因有很多，一般从冷却系效能、润滑系效能来进行分析。

如果冷却水温度过高，使得柴油机的金属零件长时间暴露在高温环境下，其强度、弹性、耐磨性都会有所下降，而且零件膨胀变形，会影响零件间的配合间隙，严重的情况甚至会造成卡死。

而造成冷却水温度过高有以下几种可能：

（1）冷却水在日常消耗后没有得到及时补充，每隔一个使用周期应检查冷却水储存量，少于最低值应给予补充；

（2）冷却水密封性被破坏，发生渗漏，应及时查出渗漏点，更换水封或修补破裂的缸体；

（3）节温器工作失灵，节温器主阀开启温度为76±2℃，全开温度为86℃，阀门升程为8mm。

当柴油机走热后，水温达到76℃±2℃而大循环出水管无水流出时，说明节温器已损坏，应及时修理更换。

除了冷却系外，润滑系的故障也会引起轮机拉缸。

机械润滑不够，会造成机体零件表面处于高温干磨状态，很快就会把零件烧毁。

而造成润滑系统工作不良的原因一般有以下几点：

（1）机油供油量不足。

轮机管理人员应检查滑油管系是否有泄漏，及时修理并补充机油。

（2）机油变质。

在长期高温及氧化作用下，机油会变得发黑及粘度下降，从而机体零件得不到良好的润滑，加速了零件的损耗。所以应及时更换机油。

（3）机油温度过高

机油温度过高，会影响机件表面油膜的形成，运动零件发生干摩擦，润滑油更容易烧焦，形成积碳，使零件磨损加快，如此恶性循环。

所以轮机管理者应检查滑油冷却器是否发生故障并及时排除隐患。

## 2、柴油机爆缸的分析与对策

一般柴油机发生拉缸而没有及时处理，就会进一步发展为爆缸。

其具体表现为活塞膨胀而卡在气缸中而无法活动，造成柴油机报废。

而出现爆缸的原因与拉缸的情况相似，主要是冷却系统与润滑系统出现故障造成。

而且排查方法也基本一样，详细参考上一小节的内容。

如果通过以上方法还未能查出隐患所在，可校验轮机的点火提前角，因为如果点火提前角过大，气缸内的燃油在活塞还未到达上止点就开始燃烧，此时活塞还在持续上升，就会造成气缸内气体压力急剧上升，表现为轮机工作暴躁，噪声大，进一步会演变为爆缸。

针对这种情况引起的爆缸最有效直接的方法就是延后点火提前角。

经过反复调整，找到最合适的点火提前角，才能避免爆缸再次发生。

## 3、轮机高压油泵故障的分析与对策

轮机高压油泵经常会出现柱塞与套筒卡死现象。

此现象会造成个别缸内供油跟不上，轮机运转发生剧烈震动，严重时自动熄火。

发生这种现象可通过拆解高压油泵柱塞与套筒观察，如果柱塞与套筒表面没有明显的刮痕，则油泵咬死多数是因为润滑油通道堵塞。

可以通过清洁疏通润滑通道查看是否能继续使用，如果不行则应该及时更换。

而换油太快、停车太急等操作问题也会造成高压油泵卡住的现象。

其原理是，柴油与重油之间的切换，如果操作不当，使高压油泵骤冷骤热，从而导致摩擦组件卡死。

所以应该加强对轮机操作人员的操作培训，提高其规范操作意识。

# 二、轮机故障的有效解决思路

分析处理船舶轮机故障的时候，维修管理人员需要具备三样内功。

（1）掌握轮机的工作原理。

当了解了机械零部件的构造、性能及其技术参数，弄明白零部件图纸及相关装配工艺，掌握了零部件的工作条件与环境，如此就能够在分析轮机故障的时候提供有力的理论依据。

（2）丰富的维修经验。

当具备充足的现场维修经验，对故障的具体表现进行观察，就能通过异常的声音、变化的参数或振动进行快速判断，发生的故障是轮机的主体部位还是辅助部位，是简单的结构还是复杂的结构，是渐进性的故障还是突发性的故障。这样就能对症下药，有效排除故障。

（3）掌握设备检修记录。

平日轮机管理过程中应该对设备检修情况进行详细的记录，通过分析以往的数据，就能基本掌握轮机的运行特性，甚至是一些平日的小毛病，进而推断出来故障的原因，这样也能够为故障分析及排除提供有效依据。

# 三、结束语

船舶轮机是由各个系统相互协调配合才能正常运行的设备。

机械元件复杂加之海上运行环境恶劣，长期以往难免会出现各种各样的故障。

在分析故障原因的过程要注意各个机件与介质是有紧密联系且相互影响的。

所以船舶轮机管理人员要用心学习相应的维修保养知识，在实际工作中实践摸索，积累更多的经验，在轮机故障发生前才能预防隐患，在遇到故障发生时也能从容应对，为船舶的高效运作与安全航行保驾护航。
