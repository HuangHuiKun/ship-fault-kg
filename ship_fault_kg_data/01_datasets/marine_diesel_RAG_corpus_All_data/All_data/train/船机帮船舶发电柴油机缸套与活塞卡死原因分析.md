# 导读

在船舶发电柴油机故障的中，柴油机缸套与活塞卡死的故障时有发生；轻者造成发生故障的柴油机活塞与缸套报废，重则造成整台柴油机严重损坏，甚至报废。

现在我根据多年工作经验就此故障展开故障发生的原因分析，严防此类故障的发生。

具体的卡死原因很多，大致可分为设备的制造过程中存在的缺陷和管理不善两方面的原因造成。

一般情况下该故障发生由于设备缺陷的第一种原因的可能性不大，原因是设备在设计制造过程中都有充分的考虑，管理方面的欠缺是造成该故障发生的主要原因。

# 一 燃油燃烧不良

燃油的燃烧不良能造成柴油机冒黑烟，燃烧室部件，透平增压器等部件结碳严重。

而燃烧室部件及透平增压器部件结碳更加重了燃烧状况不良，从而造成燃烧状况越来越坏的恶性循环，进而造成柴油机不能正常运转。

部件的结碳，尤其是缸套、活塞、活塞环上的结碳造成的后果更为严重。

轻则造成缸套、活塞、活塞环严重磨损，重则造成活塞环断环，卡死。

进而影响了活塞与缸套之间的润滑，致使缸套与活塞卡住。

我们知道活塞环和刮油环与活塞环槽之间存在着合适的搭口间隙，天地间隙，背隙。

活塞环，刮油环在活塞环槽内能够上下移动，同时也有圆周运动。

当活塞向上运动时，活塞环在槽内向下移动，贴在活塞环槽的下端面上；当活塞向下运动时，活塞环向上移动贴在活塞环槽的上端面上，这就造成了活塞向上运动时，活塞环起布油作用；活塞向下运动时，活塞环起到刮油作用，这样就能使缸套表面形成合适的润滑油膜，从而保证了活塞在缸套内部能够上下运动。

当活塞环由于结碳严重卡死在槽内，这样润滑油不能随着活塞的上下运动布在气缸的内表面上，从而造成缸套与活塞环或者活塞之间的摩擦加剧。

由于摩擦加剧造成局部过热，而发生金属粘着。

小面积的金属粘着进一步加剧了磨损的产生，继而更大面积的金属粘着发生了，这样活塞与缸套就产生了咬着现象，严重者活塞在缸套内部卡住。

我司“M/V H.J”N01A／E NO.3CYL.活塞在缸套卡住就是由于这个原因造成的。

## 具体原因分析

2013年2月,该付机刚刚完成吊缸运转1200h。

在PANAMA抛锚近三个月,由于长期在160KW左右的低负荷运转 (负荷高于145kw时，付机换用IFO380CST的燃油),造成燃油燃烧不良造成结碳严重，将第一、二道活塞环卡死，造成缸套润滑不良，在冲车过程中活塞与缸套卡死。

后来重新将其他缸的活塞吊出检查，发现其他缸也存在同样的结碳现象，只是活塞环在活塞槽内还有活动余地，没有发生严重的故障。

为了防止此类事故的发生，我们将付机负荷调高到180Kw以上运转，再也没有发生此故障。

造成燃烧不良的原因很多，比如：喷油器工作不良，高压油泵的内漏，进，排气道的脏污，进排气阀的密封不佳；活塞环，缸套，活塞过度磨损造成缸套与活塞之间的间隙过大，透平增压器的喷嘴环，压气端叶轮，废气端叶轮脏污；燃油粘度过高等都能造成类似故障的发生。

# 二 缸套冷却水温度过高或者过低

合适缸套冷却水的温度是保证船用发电柴油机正常运转的保证。

过高的冷却水温度容易造成缸套内部润滑油膜的破坏，从而造成缸套或者活塞环表面的局部高温，发生金属粘着，进而使缸套与活塞卡住。

冷却水温度过低也是造成活塞与缸套卡住的原因。

尤其是冷机启动后，由于缸套材料是铸铁，它的膨胀系数较小，而活塞的材料是铝，膨胀系数较大，这样在同样的温度下，由于两者的膨胀系数不一样，缸套与活塞之间的间隙变小，摩擦力增加。

另外，润滑油的温度也较低，不具备良好的润滑条件，发生活塞与缸套的粘着卡住。

# 三 润滑油的选择与使用

润滑油的选择，在通常情况下，如果按照使用说明书选取是不会造成该故障的发生。

润滑油的使用过程中很容易造成外来物质的污染，如重油，轻柴油，碳粒。

如果混入重油容易造成润滑油粘度过高，混入轻柴油会造成润滑油的粘度降低，影响了润滑油的性能，达不到良好的润滑效果，造成缸套与活塞之间的润滑油膜厚度不理想 ，造成活塞与缸套卡住。

润滑油长期使用，不分离或者不更换，能造成活塞与缸套的粘着。

# 四 吊缸后，重新投入使用时

船舶发电柴油机吊缸后，投入使用，也有可能发生类似事故。

因为吊缸后，活塞与缸套之间的间隙变小，如果突然增大负荷运转，由于没有按照说明书要求经过良好的磨合，活塞环与缸套之间的润滑没有良好的建立，致使其发生拉缸，甚至咬缸。

尤其是在缸套，活塞环同时换新后，必须让该付机经过2小时的空载运转，各项参数正常后，再让其承担较低负荷运转12—24小 时(100Kw左右)，然后逐渐增加负荷，让活塞与缸套经过良好的磨合，再投入正常的使用。

# 综合上述

作为轮机管理人员，只有严格按照说明书要求，在定期完成各种维修保养工作以外，时刻注意船舶发电柴油机的运行管理，发现不正常的现象及时查明原因并排除，才能保证该设备的正常使用，进而保证船舶的安全营运。
