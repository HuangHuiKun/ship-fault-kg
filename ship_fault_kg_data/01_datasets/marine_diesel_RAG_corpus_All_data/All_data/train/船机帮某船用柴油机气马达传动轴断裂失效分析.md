# 导读

传动轴作为动力机械主要输出零部件,往往根据应用场所不同,采用不同的原材料制作而成,本次失效的传动轴采用20CrMnTi,渗碳淬火后综合机械性能与表面硬度均能满足气马达的使用要求。

传动轴在驱动装置中的作用至关重要,作为一个高转速、少支承的旋转体,在动平衡中稳定工作是维持整体构件安全运行的前提与保障。

据资料显示,传动轴断裂引起的事故时有发生,通过针对各个不同传动轴断裂的分析可知,主要原因分为多种:齿轮间隙过大、运行工况过载、材料及热处理不合格、超出使用寿命期限、轴肩及键槽处的应力集中、轴表面的加工缺陷等等  [1]  。

本文将针对传动轴断裂时效,进行原因分析,并及时提出改进建议,以确保气马达正常稳定运行,满足柴油机的使用要求。

# 一、工作原理及特点

气动马达是以压缩空气为工作介质的原动机,它是采用压缩气体的膨胀作用,把压力能转换为机械能的动力装置。

各类型式的气动马达尽管结构不同,工作原理有区别,但大多数气动马达具有以下特点:

1)可以无级调速。

只要控制进气阀或排气阀的开度，即控制压缩空气的流量,就能调节马达的输出功率和转速。便可达到调节转速和功率的目的。

2)能够正转也能反转。

大多数气马达只要简单地用操纵阀来改变马达进、排气方向,即能实现气马达输出轴的正转和反转,并且可以瞬时换向。

3)工作安全,不受振动,高温、电磁﹑辐射等影响,适用于恶劣的工作环境,在易燃、易爆、高温、振动、潮湿、粉尘等不利条件下均能正常工作。

4)有过载保护作用,不会因过载而发生故障。

过我时,马达只是转速降低或停止,当过载解除，立即可以里新正常运转,并不产生机件损坏等故障。可以长时同两我连续运转,温升较小。

5)具有较高的起动力矩,可以直接带载荷起动。起动、停止均迅速。可以带负荷启动。启动、停止迅速。

6)功率范围及转速范围较宽。

功率小至几百瓦,大至几万瓦;转速可从零一直到每分钟万转。

7)操纵方便,维护检修较容易气马达具有结构简单，体积小,重量轻,马力大,操纵容易,维修方便。

8)使用空气作为介质,无供应上的困难,用过的空气不需处理,放到大气中无污染压缩空气可以集中供应,远距离输送。

# 二、问题描述

某船用柴油机开发过程中,选用气马达作为驱动零部件。

该驱动传动轴前端是矩形花键,通过带花键孔的驱动齿轮,与柴油机飞轮齿圈啮合。

柴油机发出起动指令时，气马达的传动轴首先伸出,使驱动齿轮与柴油机飞轮齿圈啮合,然后主启动阀打开,气马达传动轴带动驱动齿轮转动,进而带动飞轮齿圈,使柴油机旋转发火转速,待柴油机正常发火后退出。在项目开发初期,该供应商提供了首台气马达,装机试验后仅仅起动了25~30次,就发生了传动轴断裂故障。

# 三、初步原因分析

经粗略分析,该气马达传动轴的断裂为多源性疲劳断裂,首先从使用工况与设计参数角度进行初步原因分析。

## 使用工况

在该柴油机上,气马达安装到飞轮防护罩上,通过驱动齿轮与飞轮齿圈啮合。

由于该发动机为船用大功率柴油机，飞轮直径可达 1400mm 以上,尺寸累计误差较大。

实际装配过程中,驱动齿轮与飞轮齿圈之间的齿侧间隙难于控制到供方所要求的0.5mm~1.0mm以内。

现场实测二者之间的间隙为1.8mm。

驱动齿轮在工作过程中,由于间隙过大,驱动齿轮与齿圈受到异常冲击。

过大的冲击载荷作用到气马达传动轴上,造成传动轴断裂。由此可以初步分析,齿侧间隙过大是造成气马达传动轴断裂的重要原因。

## 材料成分

本文所分析的气马达传动轴的材质为20CrMnTi。

取样并进行材料成分分析,分析结果(见表1)表明该传动轴材料满足要求。

该传动轴精加工完成后,采用渗碳淬火及回火工艺提升其材料性能。

经热处理工艺处理后,传动轴芯部可以得到低碳马氏体组织,具有良好的韧性和强度,表层具有较高的硬度和机械强度,能够满足传动轴、齿轮等结构类零部件的需求。

对于该轴类零件,热处理工艺质量的高低将是决定其能否满足气马达传动轴可靠性的关键因素。

根据金相组织的检查,在位置“1”处的表面金相组织是细小、均匀的渗碳马氏体, 有少的细小颗粒状渗碳体与极少量的残余奥氏体,见图11。

在位置“2”处的表面金相组织是较粗的渗碳马氏体,和断续的、未成网状的粗大渗碳体,残余奥氏体较多  [5]  。

这种现象表明表面的渗碳浓度较高,保温扩散时间不足。

表面粗大的马氏体和断续的渗碳体会降低材料的韧性,尤其在表面硬度较高的时候,可能存在因应力集中发生开裂的风险。

芯部组织是由大量的低碳板条状马氏体和少部分的针状马氏体组成,有少量游离的铁素体。

芯部的硬度约为340HV ,符合片状马氏体的特征。该金相结构为20CrMnTi材料的正常淬火组织,它具有良好的强韧性,适宜于目前的零部件的使用条件。

这种情况也说明当时的热处理工艺是正常的,没有出现超温或欠温的不良状态。

## 硬度检查

气马达传动轴的硬度要求为550HV以上的渗碳硬化层深度为0.6mm~0.8mm。

硬度检测过程中,取断裂齿位置试样,详见图8。

从垂直于齿面方向由齿形表面向下,每隔0.1mm进行维氏硬度测试,检测结果,见表2。

将故障件返回供应商,同步进行分析,硬度分析结果为渗碳硬化层为0.8mm,硬度在图纸要求的上限水平上。

由此也可以得出,该传动轴渗碳淬火后,齿形表面有大块未扩散的碳化物,且表层硬脆分布不均匀。

在异常受力情况下,矩形花键的尖角位置容易形成裂纹源,造成马达轴的断裂。

# 五、结论

综合以上分析,本次气马达传动轴断裂故障的主要原因如下:

1)气马达传动轴受到异常冲击载荷是造成传动轴断裂的主要原因;异常载荷导致传动轴从矩形齿的尖角位置裂纹起源,最终断裂,断裂模式为多源性疲劳断裂;

2)传动轴的渗碳淬火硬化层深度超过标准要求,表层有粗大碳化物分布是造成本次断裂故障的次要原因;

3)对矩形花键的几何结构进行了核查,发现矩形花键的齿顶倒角和齿根圆角过小,存在应力集中的风险,设计改进过程中应尽避免。

针对传动轴断裂故障,应从气马达使用工况、传动轴设计参数以及热处理工艺等几方面进行改进。

1)增加2mm偏心结构,根据发动机装配过程中实际测量的间隙,调整气马达驱动齿轮与齿圈之间的间隙在供方推荐的0.5mm~1.omm 以内;

2)更改花键齿形设计,将齿根圆角由0.5mm 增加到1.5mm,增加齿顶斜角3mm,以避免在齿顶与齿根处出现应力集中。

3)优化热处理工艺,增加热处理保温时间,消除断续的渗碳体,提高材料的强韧性。
