# 导读

船舶柴油机在运行中发生连杆大端击穿机体且连杆伸出机体以外，俗称这种事故为“伸腿事故”。

这种事故是船舶航行重大机损事故之一，给船舶柴油机造成巨大损伤，严重时可使整台机器损坏而至报废；同时有可能引起润滑油油雾燃烧，底部润滑油起火，导致机舱火警恶性事故。

# 对某拖轮发生船舶柴油机“伸腿事故”的分析

## 事故的经过

该拖轮为两台6135型柴油机，于2000年5月25日份大修完工后进行启动试运转，经过4个多小时的运转磨合，柴油机的油压、油温、水温及机器燃烧一切正常，并在正式投入生产前进行了5个小时的试航，柴油机在运转中一切正常。

在 5月30日上午该轮启航投入营运。

航行1小时后，机舱发生巨大声响，值班人员立即停车，发现一台主机连杆大端已击穿机体，从气门处伸出来。

## 拆机检查

发现各缸的气门均打击活塞顶，第四缸严重拉缸，油环出槽，活塞裙下部的1／2处断裂，连杆螺栓全部断掉。

连杆轴瓦、曲轴、活塞销锁片和活塞连杆等都很正常。

## 事故原因分析

机损事故发生后，经过调查，认为这次事故的主要原因是值班人员没有及时打开机器冷却水的止回阀，柴油机冷却水不够用，使机体温度过高所致。

是一次机舱管理责任事故。

# “伸腿事故”的产生与预防

通过以上这起事故来看，虽然说是一责任事故，但也不能排除以下几种因素：

1. 连杆螺栓已使用到疲劳极限，或是连杆螺栓螺帽安装过紧，使螺栓承受过大拉力，再难承活塞上下冲击负荷和拉力，造成连杆螺栓被拉断。

2. 新活塞环与缸套壁压得过紧，缸体因承受过大的磨擦力而发热，使机体温度剧增，严重的破坏了润滑油摸，产生拉缸、咬缸等现象，还可能引起润滑油油雾燃烧。

3. 活塞与缸套空隙过大，使用已失去弹性的旧油环油环脱出了环槽，也能造成严重的拉缸和咬缸现象，使连杆螺栓因超负荷而被拉断。

4. 检修人员技术水平与柴油机装配质量有直接关系，影响到柴油机运转可靠性和使用寿命。应将不合格的零部件换上新的，并严格按照技术要求装配好。

5. 船舶轮机人员不按操作规程正常操作和管理柴油机，值班时疏忽大意，对柴油机运行 中的异常情况发现得迟，急救措施不当等均可造成该机损事故的发生。

综上所述，为预防此类事故的发生，必须做好如下工作：

1. 加强船舶柴油机设备的检验、检测监督工作，由其是对进行大修理的柴油机，一定要全面准确地掌搌好各道维修工序检测、检修技术数据，对存有问题坚决不能放行。

2. 加强对船舶轮机人员的培训和考核，不断提高船员工作技能，严格岗位责任制，以确保船舶机械安全运行。

3. 加强对有船单位的船员配备的监督和管理 ，对不符合要求，没有相应的岗位资质的船舶轮机管理人员不准上岗执班。
