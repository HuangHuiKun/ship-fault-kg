# 导读

柴油机要能够良好运行首先就要拥有良好的启动性能，这样才会保证柴油机的运行效率和柴油机的质量。

柴油机本身不具备自行启动的能力的，需要借助外力的推动才可以使得柴油机转动起来。

本文分析了不同情况下柴油机启动困难的原因，并介绍了柴油机启动故障按照分类别、分步骤的排除方法，可有效解决柴油机启动故障，提高故障排除的效率。

# 一、启动故障所涉及的系统分类

柴油机正常启动需要同时满足四个条件：

①达到最低启动转速；

②具有一定的压缩压力；

③雾化良好的柴油；

④提供充足的空气。

能够正常启动的要求，10s 内顺利启动，有时候需要 2~3 次启动，但是每次启动的时间间隔要在1min，目的是防止启动马达过热、启动齿轮疲劳损坏，柴油机启动 3 次以上仍不着火则视为启动困难，启动困难或不能启动均为启动故障 [1]。

根据启动所需要条件，对涉及柴油机启动所涉及的系统故障可分为五类，分别是启动系统故障、气缸部件故障、燃油系统故障、进排气系统故障及其他故障原因导致的启动困难，再针对每一类易发故障分步骤逐步排除。

# 二、启动系统故障导致的启动困难

启动系统故障，启动马达达不到启动转速，表现为启动转速低甚至不能驱动曲轴转动，特点是比较直观、根据启动装置的实际工作情况能直接判断。

## 1、柴油机气马达启动原理

气马达启动原理如图1所示，箭头表示空气流动的方向，控制空气经过减压阀、启动阀后到启动电磁阀，当要启动设备时电磁阀得电打开，控制空气进入启动马达，马达齿轮伸出，与飞轮齿轮啮合，马达里有个阀，同时空气进入启动阀，启动阀受空气压缩，主启动阀打开，启动空气进入马达，马达带动飞轮旋转。

图1 柴油机空气启动系统原理图

## 2、启动系统故障的原因

（1）蓄电池电压不足或气瓶压力过低。

（2）启动马达故障、马达齿轮与飞轮上齿轮不能啮合、齿轮伸缩故障。

（3）启动电路、气路故障，有断路或元器件损坏的情况。

## 3、启动系统故障排除步骤

（1）当发现启动时明显感觉转速低、启动无力，需要盘车，检查运动件是否正常，排除拉缸、抱轴的情况。

（2）若能正常盘车则判断为启动系统故障，检查电器元件尤其是接触器、继电器的动作情况，并用电压表测量接触器输出端口电压是否为 24V，注意启动电源是虚电的情况，启动时注意观察电压值。

如果是气动马达启动的柴油机应检查气路元件电磁阀、减压阀、启动阀动作情况，并查看减压阀空气压力是否正常。

（3）最后再拆下气动马达检查马达是否正常，主要检查马达轴承、马达或飞轮齿轮及啮合情况。

# 三、气缸部件故障导致的启动困难

气缸部件漏气，无法建立足够的压缩压力，达不到启动温度。

表现为气缸密封不良，漏气现象严重，特点是人工盘车压缩无力，伴有漏气声。

## 1、气缸部件故障的原因

（1）气阀漏气，气阀与气阀座磨损、气阀积炭、阀杆咬死。

（2）气缸垫密封不良，缸头螺母力矩不够、气缸垫损坏。

（3）活塞与气缸之间漏气，活塞环磨损严重、活塞环开口位置重合等。

## 2、气缸部件故障排除步骤

（1）先盘车，若感觉盘车有重有轻，且重的地方有反弹力，表明气缸部件密封良好；

若无压缩气体的感觉，且有吱吱的漏气声，表明燃烧室有漏气的部分，通过盘车查看漏气位置，漏气的地方往往有油渍或烟气冲出，可根据这些现象进一步排查故障点。

（2）若发现气缸、气缸盖之间有“吱吱”漏气声，说明气缸、气缸盖之间密封不良。

可能的原因有气缸盖螺母拧紧力矩不足、气缸垫损坏，通过把气缸盖螺母拧紧到规定力矩，若仍然漏气应更换气缸垫。

（3）打开气缸盖罩检查气阀是否卡死。

通过比较气阀高度判断，盘车至凸轮基圆位置，两个气阀高度一致说明气阀关闭良好。

盘车时有气体流出的声音、基圆位置进排气阀高度明显不同，说明气阀关闭不严，可能的原因有气阀与气阀座磨损、气阀积炭、阀杆咬死，再逐一判断具体的故障点，跟进维修。

（4）活塞与气缸之间漏气。

主要原因是活塞环磨损严重、活塞环开口位置重合，压缩气体进入曲轴箱内，盘车有气体进入曲轴箱内说明活塞漏气，同时结合柴油机工作时的表现，如曲轴箱压力、温度增高、柴油机功率下降，辅助判断是否存在活塞漏气。

# 四、燃油系统故障导致的启动困难

表现为燃油系统不供油或供油不正常（油量少、供油间断），柴油机不着火。

燃油系统上任何一个环节失灵都会导致供油不良，影响柴油机启动。

图2 柴油机燃油系统原理图

油路故障一般应先检查燃油系统中是否有空气，目的是：

①能直接排除系统中的空气；

②能初步判断故障发生在高压油路还是低压油路，为下一步检查提供重要线索。

检查油路是否有空气的方法是拧开精滤上的放气旋钮，观察流出燃油和气泡的情况。

排出燃油系统空气会出现三种情况：

第一种情况：

少量燃油流出或无燃油流出；

第二种情况：

有燃油流出且无气泡产生；

第三种情况：

燃油和气泡都存在 [3]。

下面对三种情况的故障原因及排除步骤进一步分析。

## 1、少量燃油流出或无燃油流出

少量燃油流出或无燃油流出，说明燃油系统不供油，故障发生在低压管路。

原因是滤器脏堵或输油泵损坏，应立即更换滤芯，更换后再检查放气旋塞的燃油和气泡流出情况，如果还是没有油流出，松下输油泵的出口管接头，盘车，若输油泵出口管没有油泵出，说明输油泵供油不正常，应拆下输油泵检修。

## 2、有燃油流出且无气泡产生

有燃油流出且无气泡产生，说明低压管路供油正常，故障发生在高压管路中。

高压管路故障有两种可能，要么高压油泵故障，要么喷油器故障，其中，偶件损坏是最主要的故障，（提问）高压管路中有几对偶件，三对，分别是出油阀和阀座、柱塞和柱塞套筒、针阀和针阀体。

我们先判断高压油泵是否正常，高压油泵故障一般是两对偶件的损坏，一对是出油阀和阀座，一对是柱塞和套筒。

先来判定出油阀和阀座的好坏，拧开高压油管接口，若燃油不断从高压油泵口流出，说明出油阀关闭不严，出油阀弹簧损坏或阀座磨损，锥面密封不良，应更换弹簧或出油阀偶件。

如果出油阀正常，下一步判断柱塞和套筒的好坏，将供油手柄置于供油位置，盘车转动曲轴若出油口不输出燃油表明柱塞卡死或柱塞弹簧损坏，应更换高压油泵柱塞偶件或柱塞弹簧。

若高压油泵正常，进一步检查喷油器起阀压力和雾化情况，若起阀压力低，可能是弹簧损坏或针阀与针阀体间隙过大；

若雾化不良：

喷油孔堵塞或针阀与针阀体密封锥面磨损。

应立即更换弹簧、增加调整垫片或更换针阀偶件。

## 3、燃油和气泡都存在

燃油和气泡都存在，说明燃油系统中有空气，并且证明油柜至供油泵这段管路正常。

这时应将系统内气泡放尽，拧开放气旋塞，直至有成股的燃油流出，表明空气放净，这时可以再试车，启动柴油机同时按压手动供油泵，若仍然不能启动，再检查高压油泵和喷油器。

# 五、其他原因导致的启动困难

由于柴油机的特殊结构，不易被人察觉的故障原因造成的故障。

特点是故障不明显，需要全面分析排查，可能的原因有：

（1）滑油、冷却水温度过低，柴油机运动部件摩擦力较大，柴油温度低也会导致不易启动。

（2）进排气系统有堵塞，如进气滤器、中冷器出现堵塞。

（3）连锁机构未复位，如超速保护装置挡板未打开、滑油或曲轴箱压力检测器损坏、供油齿条卡死、遥控启动与机旁启动不匹配、盘车机未脱开等。

（4）传感设备故障，如转入传感器失灵、松动无法监测转动信号。

# 六、总结

柴油机启动故障是常见问题，首先要认真分析产生该现象的原因，仔细查找故障部位，并及时采取相应措施，寻找解决排除故障的方法 [2]。

步骤为：

①观察柴油机启动时的状态，听发火的声音、漏气声及机械敲击声、启动时相关机构动作情况等；

②根据不能启动的现象初步判断故障属于哪个系统；

③根据各个系统故障排除方法，逐一排查故障点。
