# 导读

随着信息化建设推进，船艇从传统运输勤务保障向联合机动作战转型，这对船员和装备技术性能有新的要求，尤其是船艇机动性对柴油机零部件维修与更换操作要求越来越高。

而在抢修原则中，专业人员与船员相结合在现实中不易实现，所以须将船员培养为专业人员，重视对柴油机的保养和维修，以提高维修效率和质量，提高船艇动力装备的工作效率。

船艇柴油机普遍使用废气涡轮增压，近年来，船艇柴油机涡轮增压器出现问题及故障的几率明显升高。

因此有必要根据对增压器使用的情况进行分析和研究，判断增压器可能产生的主要故障，结合故障机理，探索行之有效的方法降低故障率，延长其使用寿命，增强其可靠性，保障船艇的航行性能。

# 一、增压器结构及工作机理

柴油机废气涡轮增压器主要是由涡轮、压气机和中间轴承组成。

首先涡轮器的进气口与排气管相连，排气口则接在排气管上。

增压器进气口与空气滤清器管道相连，排气口接在进气歧管上，涡轮和叶轮分别安装在同轴的涡轮室和增压器内。

废气涡轮增压器利用排出的废气能量推动涡轮高速旋转，涡轮带动同轴的叶轮旋转并压缩空气，使之增压后进入气缸。

当柴油机转速升高时，废气排量成比例升高，同时涡轮转速加快，叶轮压缩更多新鲜空气进入气缸，进气压力随之升高，进气密度增大，燃烧更多燃料来增加柴油机的输出功率。

离心式压气机由消音器、空气进气壳、压气机叶轮和扩压器组成。

压气机工作过程，废气经进入排气总管和增压器涡轮，作功后从排气口排出，再经出气弯头、波纹管与排气消音器连接。

新鲜空气通过消音器和空滤器进入压气机。

轴承，采用 2 个内置式浮动轴承，装在轴承壳内，滑油从主润滑系统进入，再回流轴承壳底部。

同轴运转的压气机和涡轮，可使进入的气体压力和密度增加，转速不变时有更大的动力输出，达到提高燃油经济性并降低排放的效果。

# 二、常见故障及原因

在废气涡轮增压器中，常出现问题的地方包括压气机、轮轴、轴承以及涡轮机。

在机器的启动前和停止后需重点关注增压器转速变化、温度变化以及运行声音的变化。

增压器在高温的环境下高速运转，其承受的热应力和交变应力很复杂。

在高速运转时，增压器叶轮、轮轴和轴承的振动会破坏配合间隙，影响增压器性能。

且废气中含有硫氮的氧化物及蒸气，化合后的酸会腐蚀增压器，缩短其使用寿命。

经过调查分析，增压器有以下几种常见故障。

## 1、喘振

柴油机突然停车或卸载负荷时，由于惯性增压器的转子不会停止。

此时进气压力仍然很高，但卸荷后的柴油机不需要太多空气，柴油机背压过高引起喘振。

当柴油机超负荷运行时，排出废气能量呈爆发趋势，此时柴油机转速却增加的很少或不增加，也容易出现喘振物理现象，因为进入压气机的空气出现很大程度的摆动，造成其叶轮的振动，这样就会产生粗重的气喘声。

对于离心式压气机来说，处于小流量、排气压力值大于2.5kPa，就会产生这种喘振现象。

喘振起因主要有3点。

正常工况下，增压器的气流流动线路：

空气→压气机进气口空气滤器→消音器→压气机叶轮→压气机扩压器→空冷器→扫气箱→进气口→柴油机汽缸→排气口→排气总管→废气涡轮端喷嘴环→废气涡轮叶轮→废气锅炉→排出。

其中各部分的流通面积都是固定的。

若上述任一环节发生故障，就会影响柴油机气体流通性，造成柴油机增压器喘振、增压器性能效率和增压扫气压力下降，以及主机排温升高等，若主机排温升高到一定值，就可能出现故障报警、自动降速或停车现象。

在气流经过的部件中，滤网、气缸、喷嘴等这些部件变脏是造成喘振的主要因素。

## 2、增压器机械故障

机械故障包括轴承破损以及叶轮叶片损坏。

当故障出现时，先对滤网进行查看，如清洁度良好，考虑增压器部件出现破损，发现问题紧急停车维修。

### （1）增压器轴承损坏

增压器轮轴断裂。

转轴一端是涡轮，另一端与叶轮相连。

高温时若轮轴断开，柴油机会停机。

轴承断裂原因主要有：

外力作用下涡轮外表变化，或压气机固定不紧密，不能正常稳定工作，变形轮轴在应力和转矩作用下断裂。

增压器运行时，轮轴随着增压器转速改变而振动，在交变应力作用下产生疲劳断裂。

转轴缺乏润滑与浮动轴承粘连，高温高压废气冲击固定的轮轴而产生断轴。

若异物掉到管道进口在涡轮箱壳中窜动，螺栓等硬物与轮轴发生刚性碰撞会导致断轴。

增压器润滑不良。

增压器轴承滑油来自润滑系统及油底壳，润滑不良等导致轮轴烧蚀，主要原因有：

滑油不足或油压不达要求，当流量不足或油压低于规定值时，轮轴会因摩擦、高温而烧蚀。

油品不合要求，使用非规定排号或不清洁的杂质较多滑油，轴承温度将增加。

当涡轮密封环磨损过多，产生较多热量，破坏轴承的间隙，涡轮和转轴的中间空隙厚度不均的油膜难以达到较好润滑效果。

当增压器转速大于最高转速时会出现飞车现象。

转速升高，滑油供应不足，冷却效果变差，无法散热而烧蚀轮轴。

当滑油进出口温度偏高时，冷却不及时同样会烧蚀轮轴。

飞车时应降低转速或停车检查，如轮轴破损应进行替换。

轴承常见损伤有过度磨损、拉毛、剥落、裂纹和烧损等。

当油压不足时会出现振动问题、壳体变形甚至轴承的严重磨损。

当新装增压器、更换滑油及滤清器，长期停机未用，未正确启动、滑油质量低等情况易引起进油管路阻力增大或破裂等故障；油底壳中油位低、空气进入润滑管路产生气阻等润滑管路或增压器滑油断供时，会导致轴承表面磨损烧损。

### （2）叶片损坏

涡轮高速运转时，即使很小杂物进入，其导风角也会发生变化，会对叶片或叶轮产生极大影响。

大而硬的物体则会在叶片上留下划痕甚至裂纹。

引起叶片断裂主因是叶片受到反复弯曲应力造成疲劳破坏。

增压器喘振时，涡轮机叶轮的叶梢与壳体碰撞，导致叶片变形，对转速产生巨大影响。

叶轮断裂多出现异常的撞击声。

当振动异常或噪声较大时应停车排查。

在更换或修理叶轮后需做静平衡和动平衡实验。

### （3）增压压力异常

进气不足时可用补气装置将压缩空气送入压气机达到增压目的。

压力表读数在转速接近或达到额定转速时较为明显（如NTA855-M350型柴油机额定转速1800 r/min）。

高转速时机械效率很高，多种原因导致压力会出现较大变化。

压力升高。

负荷不变时，增压器超速常导致压力升高。

原因主要是：

燃油系统故障致使燃烧不良，后燃严重，排温升高。

增压器本身涡轮脏污，流通面积减少，燃气喷出速度加快，使增压器转速上升。

柴油机过载，负荷过大转速较高，废气量增大，废气涡轮转速升高，压气机叶轮转速增加，压缩空气量增大，柴油更充分燃烧。

该工况下，喷油量增加，随时可能飞车，应立即减速卸荷以保证安全。

压力降低。

燃烧不充分，影响功率。

其表现在：

进气管脏污：进气量减少，增压压力不足并伴随啸叫；扩压器、叶轮及涡轮嘴积碳或油污附着，使增压器旋转阻力增大。

供油正时不准：供油时间滞后，造成后燃，柴油不完全燃烧，废气能量减弱，涡轮转速下降。

排气管路漏气：导致涡轮可使用的能量下降，影响其转速，增压器压力也随之下降。

排气阀晚开早关：排气量减少，涡轮机转子转速降低，导致增压压力下降。增压器故障及可能原因对应表如图 1 所示。

# 三、故障案例分析及排除措施

增压器运转时内部有新鲜空气和高温高压的废气，内部有滑油流动。

增压器对中性、平衡性、密封性和清洁度要求较高。

这些与船员管理及维护保养技术关系紧密。

当其正常运转时气流快速流动，最高可达几百米每秒。

当其正常工作时叶轮快速旋转，可达每秒钟几千转。

使用时叶片或轴发生变化都会对涡轮增压器产生影响。

## 1、故障现象

案例：

某型登陆艇使用 NTA855-M350 型柴油机作为主机，该型柴油机为引进美国技术生产的六缸直列、强制水冷、增压空气冷却和废气涡轮增压的四冲程船用柴油机，额定功率 261kW，额定转速 1800r/min。

该型柴油机采用为ST-50型单级径流式废气涡轮增压器，压气机为单级离心式压气机。

该艇在海上航行时，发现右机滑油管路漏油，航行一段时间后，增压器高速运转时喘振，继而外壳烧红。

停车后，拆卸增压器，对其进行检查。

## 2、排除过程

遵循先判后检原则，根据前期分析的柴油机增压器故障原因，结合故障现象，存在滴油现象，气封装置破损，更换油封，滴油现象暂时消失。

航行一段时间后，滴油现象仍然出现。

更换喷油器进行安装并试车，喘振故障依然存在。

冷却系统检查。

如水温过高，不能冷却柴油机，导致排气温度高，增压器中机油蒸发，长时间运行后，机油蒸发后挂油滴。

因该型柴油机中冷器采用舷外水冷却，检查冷却系统压力正常。

因柴油机在其他各个低速能正常运行，检查排烟有轻微蓝烟，检查各缸排温相差不大，排除冷却系统问题，而分析故障由进排气系统或燃油系统引起。

进排气阀检查。

如果气阀间隙不当，进排气阀关闭不严而导致进排气阀积炭严重或者烧蚀，从而引起增压器的喘振。

在靠泊码头后对各缸进排气门的密封情况进行检查，发现阀杆和进排气门底座密封正常，无严重积炭和烧蚀情况，各缸的气门间隙正常。

各缸进排气阀、燃油系统及高压油泵检查，各缸的高压油泵进行了校对、供油正时调整之后，喘振的故障随之消失，但滴油现象仍然存在。

检查仪表发现压力表异常。

进排气、曲轴箱负压不平衡时，压力密封失效，润滑油被吸向压气机，随空气升压后进入气缸。

进气系统对柴油机性能产生影响而导致增压器漏油。

拆开增压器进出气口管，管壁上沾附有机油油污。

考虑缸套和活塞环之间的配合间隙产生磨损，更换活塞环，漏油现象消失。

调节增压器转子动平衡，增压器运转速度非常高的时候，转子会出现不平衡的惯性力，将会对其产生不利影响。

不仅会让磨损变得严重，还会让轴承承受的重量有所增加。

所以在拆除或更换增压器、安装完成后，对其进行动静平衡实验，把不平衡度控制在要求的范围内。

静平衡实验可通过任意转动一个角度，作上记号，松手后记号不动为准，若记号有变动角度，那么在偏重的一边用锉刀稍锉一下以减重。

动平衡需要通过计算，把不平衡量给去掉。

然后再进行尝试，直到达到要求。

## 3、原因分析

该案例滴油现象反映出保养维护漏洞。

废气涡轮增压器的日常管理，主要应注意观察滑油流动情况，留意滑油的压力和温度是否反常。

增压器工作时，滑油压力不可过高，以防滑油被挤入涡轮室。

此时，滑油消耗率升高，极有可能飞车。

调节滑油冷却器将滑油温度控制在合适的范围内，避免因为增压器工作时冷却不充分造成转轴与轴承高温。

另外，高压油泵单缸不供油或者供油不均，主机各缸的负荷不同，导致增压器的喘振。

同时，供油定时不准确，造成后燃现象，排烟管中含有未完全燃烧的燃油，进入增压器中，引起增压器温度过高烧红。

# 四、管理启示与建议

当柴油机长时间运转或超负载工作时难免出现故障，为避免故障发生，需要对其进行维护保养。

停机前应怠速运行3~5min，并对其运转的平稳性进行查看。

如声音不正常，应停机检查。

经常检视气道的气密性，定期对涡轮增压器进行检查。

运行一段时间，增压器内部会锈蚀及出现杂质，轴承也会因升温发生性能改变。

应按船艇保养规定定期对其进行清理，避免可吸入颗粒物堵塞压气机，以保证其处于较好的工作状态。

用酸溶液来去掉铁锈，柴油清洁滤清器。

配置或购买浓度为10%~15%的盐酸或浓度为15%~20%的硫酸溶液清洗水垢，再用碱水中和残余酸液，然后用清水洗净化学试剂，最后压缩空气吹洗并进行干燥。

拆装增压器时，应结合厂商配备的说明书或使用手册了解内部构造，熟悉拆装程序再进行拆装。

当涡轮增压器在运转中损坏，船上无法进行换件修理时，应立即停止运转采取措施，防止增压器发生其他损坏。

如果转子停转，为了防止火灾，必须强制切断对故障增压器的滑油供应，同时降低柴油机输出功率，使其排气温度不超出规定值。

如果废气必定经过增压器输送，则应拆除故障增压器的转子部套并盖上密封盖，否则拆下整台故障增压器，并密封或重新连接相关管路。

维护保养时，小故障由使用人员进行修理。

超出维护保养范围的检查、维修或大故障的修理应送修理所或制造厂。

当转子及轴承损坏，为使柴油机恢复运转，可换备用转子总成。

# 五、结束语

增压技术日新月异，其结构功能也随着柴油机发展而优化。

增压器长期以来存在的问题，直接影响柴油机使用寿命和航行安全。

合理使用增压器、定期进行维护是解决增压器故障的有效措施。

增压器发生故障应根据故障现象成因来逐步检查，以提高故障诊断和排除效率，其他故障如停止运转、燃气通道腐蚀、涡轮漏油以及异响等故障的研究需要在日常使用管理中仔细观察和分析。

船艇部门正处于转型发展阶段，在机器管理使用方面也提出了更高的要求。

目前广泛使用的废气涡轮增压器能大大提高效率，降低油耗。

但废气涡轮增压器常会出现一系列故障，利用故障实例对涡轮增压器的典型故障进行分析，结合船艇柴油机的使用情况以及操作管理相关规定，总结摸索出行之有效的方法，必定能为更好地遂行保障任务提供参考。
