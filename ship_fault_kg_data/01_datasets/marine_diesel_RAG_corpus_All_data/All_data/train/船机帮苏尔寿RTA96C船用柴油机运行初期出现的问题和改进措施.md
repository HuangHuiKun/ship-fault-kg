# 导读

苏尔寿RTA96C柴油机是在充分利用RTA84C和RTA其它系列柴油机在设计开发和实际使用中积累的经验基础上进行设计的,在设计中可靠性贯穿于整个开发过程,因为这也是船东的基本要求。

另一个设计目标是大修周期至少要达到2年,力争3年。

此外,在不增加燃油消耗率的前提下NOx排放完全符合IMO的标准。

实践证明这是一个成功的机型,已越来越多地应用到超巴拿马型集装箱船上,得到船东的广泛认可。

但在投入运行的初期,却出现过技术上的问题。

针对出现的问题,通过采取相应的措施,得到了圆满的解决。

现就有关问题及改进的措施介绍如下。

# 一、主轴承

在特定的船型中发生过主轴承损坏的事例,表现为下主轴瓦白金属局部剥落和局部点蚀。

在采用了被称之为键槽的设计方案并在其它一些方面进行了细小的改进之后,点蚀问题得到了解决。

键槽的主要功能是增大使轴瓦紧贴中间体的径向力。

除了主轴承外,尚未发现白金属剥落与轴承负荷和轴的运转之间有任何关联。

作为一种改进的措施,目前与推力轴承相邻的下主轴瓦与相应的主轴承盖一起加工,以保证轴承的几何形状。

此外,还采取了其它一些措施,例如提出更加严格的轴承盖与轴瓦的对中要求,加上轴承盖和轴瓦之间的键,保证了拧紧时轴瓦在中间体中紧密贴合。

# 二、A机架立板

RTA96C柴油机在投入运行的初期,瓦锡兰公司陆续收到几份有关A机架立板出现裂纹的报告,运行时间在5000～12000h之间。

公司立即组织了一个项目小组来研究此事,并对其它所有正在运行的柴油机进行了检查。

尽管在最初的8台机中有7台发现了裂纹,但都是按早期设计生产的双层A机架立板,而且严重程度也各不相同。

裂纹起始于立板上两组水平肋板的内侧端部,沿十字头导轨方向垂直扩展。

问题的根源在于不合格的焊接质量和稍高于预期值的应力水平。

所有有裂纹的A机架立板均用焊接的方法进行了修补。

同时,截短了相关柴油机上所有水平肋板的内侧端,以限制应力集中,从而消除产生裂纹的可能性。

测量表明,经过改进的肋板使作用在立板上的应力大约降低了一半,焊接质量的敏感性随之下降。

在瓦锡兰公司、柴油机生产商和船东的共同努力下,首批柴油机在短短的几周内就修复完毕,余下的几台情况不太严重的柴油机随后在船舶正常大修时得到了处理。

现在无论是经过修复的还是新造的,所有RTA96C柴油机都已采用改进后的水平肋板。

这种水平肋板由开始使用的改进型肋板再次改进而成,更便于制造。

# 三、空冷器后的水分离器

有几台10RTA96C柴油机曾在非常潮湿的环境中进行了车间试车,结果发现原型号的水分离器不能满足极端运行工况时的要求。

通过进一步的试验和研究,在水分离器生产厂的配合下,设计出了全新外形的分水板并修改了水分离器材料表面的规范,使分水效果得到了提高。

这种外形的分水板已作为一种标准产品予以使用。

为了与新的水分离器相配,扫气箱也做了相应的改进。

# 四、活塞及其它

活塞通过在设计上采取组合措施来达到理想的运行效果。

气缸套采用合适的材料并深度珩磨,缸套壁的温度场进行优化,采用多层气缸注油方式,头道活塞环有镀层,在空冷器后配备了高效水分离器。

然而,部分RTA96C柴油机在某些情况下负荷会低至60%装船功率,使用硫含量为3.5%或更高一些的常规燃油时。

由于柴油机必须具有规定的超负荷能力,因此低负荷时保持可使磨损率降到最低点的气缸套最佳温度场相当困难。

测试结果表明：柴油机功率每下降1%,头道活塞环上死点处的气缸套壁温度将随之下降1.3℃,因此,60%负荷意味着气缸套温度比全负荷时低52℃左右。

首批2台11RTA96C柴油机由于是降功率使用,装船功率为88.25%额定功率,因此在气缸套冷却孔中安装了Teflon绝缘套管,长度为200mm。

气缸套的最大磨损率在0.02~0.03mm/1000h左右。

12RTA96C柴油机气缸套的磨损率一开始较高,头道活塞环上死点处气缸套磨损率达到0.15~0.2mm/1000h,由于这些柴油机以额定功率作为装船功率,气缸套中未装绝缘套管。

事实证明这种做法是错误的,因为柴油机会有较长的时间在低至60%的装船功率处运行。

鉴于这一认识,后来在气缸套中补装了长200mm的绝缘套管并取得了理想的结果,最大磨损率降低到约0.05mm/1000h,但气缸油的注油率依然较高。

首批2台10RTA96C柴油机也补装了绝缘套管,其长度为280mm。

这些柴油机的气缸套最大磨损率约为0.03mm/1000h左右,具体数值与气缸油注油率有关。

余下的10RTA96C和此后生产的其它RTA96C柴油机都安装了320mm长的绝缘套管。

当气缸油注油率为1.4g/kWh时,这些柴油机的气缸套磨损率约为0.02mm/1000h。

随后在RTA系列柴油机上采用了TriboPack组合技术。

除了以前已经采取的措施外,TriboPack还包括减磨环陶瓷镀层活塞环和气缸套中部用于提高该区域缸壁温度的外表面隔热套。

提高气缸套中部温度有利于当气缸油注油率较低时避免中部缸壁受到酸性物质的侵蚀。

中部隔热套非常适合于柴油机长时间在低负荷下运行,同时TriboPack技术还为非常规的运行工况提供了额外的安全裕度,例如可防止活塞头部过多的积炭。

通过采取以上一系列的措施,所有的活塞环经检查都处于良好的状态。

头道活塞环的磨损率约为0.1mm/1000h,其它环约为0.02mm/1000h,所有燃烧室部件的工作状况也都正常,没有出现诸如排气阀热腐蚀或阀座磨损等现象。

气缸盖安全阀曾出现过泄漏,这是由于较短的阀离燃烧室太远而温度过低,导致腐蚀加剧造成的。

已投入使用的柴油机换装了改进设计的阀,而后续生产的则仍然使用原先设计的阀,通过使阀在较高的温度下工作来避免出现这一问题。

有多个扫气箱出现过上下纵向焊缝开裂现象,经查发现是由于隔板共振引起的。

作为对策,相关扫气箱的隔板进行了加强。此外,新柴油机改变了共振频率,从而降低了振幅。

振动也对增压器支架产生了影响。

首台10RTA96C柴油机投入运行仅仅400h,1台增压器的支架就出现了严重的问题。

支架的振动突然加大,排气管半松脱并压在支架上直至紧固螺栓断裂。

测量结果表明,增压器支架的自振频率与增压器后的排气管的激振频率非常接近。

首批2台10RTA96C及后续柴油机都加装了额外的支承件,使振动回到了可接受的水平。

此外,排气管的紧固也得到了加强。

这些措施提高了整个系统的自振频率。

用于新柴油机的一种刚性更好的增压器支架已开始设计。

同样是在第1台10RTA96C柴油机上,排气总管出现了过大的横向位移。通过横向加强排气总管支架,位移量减少了一半。

排气总管过大的位移也导致了冷却水出水管破裂,为此决定将专利生产的弹性管作为标准配置。

实践证明这是一种安全的解决方案。

RTA96C柴油机还发生过多次气缸盖螺柱断裂事故。

绝大多数断在头部第1道螺纹处,也有部分断在根部。

根部断裂的原因经查是由密封不良导致腐蚀引起,而头部断裂的原因是螺柱的材料和螺纹质量偏离了规范的要求。

尽管如此,气缸盖螺柱还是改成了细杆形式并改用了特殊的螺母以降低受力水平,取得更大的安全裕度。

为使RTA96C柴油机满足IMO关于NOx排放的规范,采取了一系列的措施,如提高压缩比,修改可变喷油正时设置,改变喷油正时,延迟排气阀关闭正时和改进喷油嘴等,从而使NOx排放完全符合IMO的标准,而柴油机的可靠性不受影响。

RTA96C柴油机体现了柴油机技术发展的重大进步,它的外形尺寸比RTA84C稍有增加,但功率却有大幅度的提高,完全可以满足船东对可靠性和耐久性方面的要求。
