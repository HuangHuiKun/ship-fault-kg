# 导读

针对船舶主机排气温度过高这一常发故障，根据实际工作经验，从柴油机各个系统出发，对造成这一故障的可能原因进行分析，并给出了对应的解决措施。

# 一、供油系统

## 1、高压油泵

高压油泵齿条脏污、油尺卡死在最大位置或超出最大值，使气缸处于多供油位置；

高压油泵柱塞偶件磨损大、泵油压力下降，使在相同油尺刻度下的实际供油量减少、相应气缸功率下降、其他气缸要分配更多的负荷，造成各缸功率分配不均匀、缸间排气温度差增大；

等压卸载压力阀和卸压阀密封面磨损，弹簧预紧力下降；

压力阀断裂，无法密封，降低高压油管中残余压力，幅度较大时，将影响喷油正时及喷油规律，使实际有效供油量减少、气缸功率下降，这同样会造成气缸功率分布不均匀的情况。

## 2、喷油器

喷油器使用一段时间后，会出现喷油压力下降、雾化质量变差，严重时会导致喷油嘴针阀关闭不严、甚至卡死现象，使喷入气缸的燃油无法完全燃烧或滞燃而使排气温度升高，因此，要定期检修喷油器。

喷油器在检修之前要在试验台上检验其启喷压力和雾化情况，并做好记录。

检修时重点检查针阀偶件，观察其导向面及密封锥面的状态。

导向面出现刮痕、密封锥面出现麻点或偏磨，说明油质不理想，杂质较多，或者前面所提到的高压油泵出油阀压力阀芯断时，断口产生的微小颗粒直接进入油嘴偶件，造成磨损，磨损面要仔细研磨修复，严重时应及时更换偶件；

密封锥面出现麻点或者偏磨程度不大的，可用专用研磨砂人工研磨，同时要检查重油分油机系统及终端滤器；

针阀导向面颜色变为暗黑色，说明针阀过热，要检查机前燃油粘度控制器及油嘴冷却水系统，必要时可用化学溶液循环清洗油嘴冷却腔。

另外，用专用金属针条清洁针阀座喷孔，借助放大镜观察喷孔是否失圆、喷孔周边是否有裂纹，一旦发现，要及时更换。

# 二、气缸气密性

柴油机在使用过程中，气缸气密性将不可避免地随着气缸套、活塞、活塞环、气门及气缸盖等机件的磨损而有所下降，影响气缸内空气的压缩，严重的会使柴油机燃烧恶化、排气温度升高。

造成气缸气密性差的主要原因为：

随着活塞头积炭增多，偏磨现象日益严重，缸套失圆；

进排气门密封面烧损，进排气门杆、气门盘烧穿；

排气门壳体与气缸头之间密封面漏气；

气门间隙调整不当；

排气门杆导套下半部积炭严重，使排气门杆在某种程度上被卡，造成气门漏气。

# 三、配气系统

## 1、空冷器

柴油机排气温度升高的一个重要因素是柴油机进气温度升高。

对于增压柴油机来说，空气进入柴油机之前要在压气机中被压缩，随着空气压力的上升，其温度也升高。

如何降低增压空气温度，对改善柴油机的工况是相当重要的。

有资料显示：

增压柴油机功率的提高，60％来自增压，40％归功于空冷器的冷却作用。

所以空冷器的工作性能对柴油机工况的影响相当明显。

因此对空冷器的冷却效率和阻力系数要求较高。

随着运行时数的增加，空冷器会出现污染问题，即空气侧积灰尘、水侧结水垢，严重的会出现水管堵塞。

所以，当空冷器冷却水进出口温差小、增压空气温度明显上升时，要及时拆洗空冷器。

## 2、增压器

大功率中低速柴油机多采用定压增压系统，工况稳定时，增压器与柴油机的配合运行点设计成较靠近喘振线附近的高效率区，灵敏度较高；

一旦增压器效率有所下降，其配合运行线会偏离高效率区，使柴油机工况变差、排气温度明显升高。

### （1）压气机

随着柴油机的运转，压气机叶轮及扩压器表面上会吸附一层含油灰尘，因此而增加空气与工作轮及扩压器表面之间的摩擦损失、影响压气机的效率。

曾有实验表明单独拆洗压气机叶轮，尽管其表面积尘不多，但清洁后气缸排气温度平均降低15℃左右；

增压器转速虽略有下降，但增压压力却有回升，说明压气机效率有回升、进气量增多、柴油机燃烧改善，表现为排气温度下降。

### （2）涡轮

柴油机来的排气，经柴油机排气管导入涡轮进气壳，流经喷嘴环中进行膨胀，使废气压力和温度下降而流速显著增加。

具有一定高速的气流按一定方向流过工作轮的叶片通道，在其中废气继续膨胀，同时一部分动能转换成机械功，最后，废气经排气壳排出，燃烧残留物，特别是硫化物，使涡轮容易污染，可能导致喷嘴环及工作轮叶片结垢严重，甚至改变了叶片原来的形状，使喷嘴环全圆周进气不均匀，同时气流流经喷嘴环和工作轮叶片通道时产生撞击和分离，导致涡轮效率下降、压气机做功量减少、气缸燃烧不完全、排气温度上升。

# 四、结束语

柴油机排气温度升高是一个系统的问题，有时是某个因素引起，有时是几个因素共同作用的结果。

因此，在日常使用过程中要结合机组的具体参数和结构特点加以判断，逐一排除，以确保机组安全经济运行。
