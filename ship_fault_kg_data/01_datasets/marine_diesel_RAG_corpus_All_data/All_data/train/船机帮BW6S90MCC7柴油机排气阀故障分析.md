# 导读

文章就某船试航过程中排气阀有异响的现象，基于柴油机排气系统及滑油系统的原理，对排气阀不能完全打开及伴有敲击声的故障原因进行分析，并提出了修理方案。

排气阀是组成柴油机燃烧室的重要部件之一。

它的工作状况直接影响换气过程的质量，影响柴油机的动力及燃油的消耗。

在对排气阀的检修过程中，应引起足够的重视。

然而在运行过程中往往会发生一些意想不到的故障，这就需要根据原理进行分析，找出故障原因，并解决故障，从而提高柴油机的动力性能，减少污染。

# 一、故障现象

某船的柴油机型号为B＆W6S90MC-C7，采用液压驱动式排气阀。其在厂区维修后的试航过程中，No.2、No.5、No.6均有排气阀不能完全打开的现象。

No.5、No.6 伴有轻重不一的金属敲击声。

No.2、No.6 有排烟温度高的故障。

# 二、排气阀控制机构及工作原理

## 1、控制机构

1) 液压活塞。

用于开启排气阀，分上、下两部分，凸轮轴控制下部活塞给上方的活塞提供高压油。

2) 汽缸。

用于关闭排气阀，控制空气通过单向阀进入汽缸底部。

同时在汽缸底部安装安全阀(工作压力: 2.1 MPa) 。

3) 放气节流阀。

安装在排气阀液压缸顶部，其作用是当排气阀关闭时，释放液压油内空气的同时不至于让更多的油泄漏。

4) 油密封。

排气阀阀杆与导套之间的润滑作用，同时起到封阻燃气的作用。

与其配套使用的是安装在液压缸上方的密封油控制单元 ( 由单向阀及指示机构组成) 。

## 2、工作原理

0.07 MPa的控制空气通过单向阀进入汽缸底部，使排气阀一直处于关闭状态，随着凸轮轴转动推动液压活塞，将通过单向阀进入腔体内的滑油压缩成高压油，用于开启排气阀，此时汽缸内的空气被压缩。

当压力高于 2.1 MPa 时，安全阀泄压，汽缸下腔被压缩的空气类似于机械结构中的弹簧 ( 气弹簧) 。

当液压活塞不再供油后，该气弹簧将排气阀进行关闭。

# 三、故障查找及原因分析

## 1、No.2 排气阀开启动作迟缓且不能完全打开

1) 初始考虑为滑油压力不够，流量不充足，在确认排气定时符合说明书要求的基础上，对排气阀顶升机构上的进油口单向阀进行检查并试验，确认该单向阀功能正常。

2) 通过打开液压缸上的放气闷堵，观察到滑油内存有大量的空气，对其他的缸进行放气检查并未发现有空气混入滑油内。

故气体的来源为该缸上的某个零部件故障。

图 2 密封油控制单元结构图 

3) 图2 为密封油控制单元结构图，从图2 判断该气的来源为阀杆与导套之间的废燃气。

由说明书可知，正常的工况下出油口应有小股滑油一直流出，由此可断定密封油控制单元的单向阀存在卡阻或损坏现象。

对该备件进行更换修理后，滑油里混有空气的现象消除。

4) 再次运行柴油机，排气阀仍然不能完全打开，故将问题焦点集中于汽缸上。

因汽缸在车间维修时所有密封件全部更换过，并进行了汽缸功能试验。

唯一遗漏的是没有对安全阀进行开启压力测试。

更换船方安全阀备件后，再次试车，故障现象消失，No． 2 缸排气阀工作正常。

此时，可判定安全阀的作用至关重要。

对安全阀的工作原理进行分析，得到如下结论: 

安全阀设定值过高或卡阻时，汽缸内的压力超过设定值，安全阀未能打开，因此气弹簧的力大于液压活塞的力，因此排气阀不能完全打开。

## 2、No.5 排气阀阀座处敲击声

1) 根据 No.2 缸的故障解除经验逐一排除，但没有排除故障现象。

判定该敲击声的原因为排气阀关闭太慢，当该缸达到发火时间时，排气阀还没有完全关闭落座，此时汽缸内燃烧压力急剧增大，强大的燃烧压力迫使该阀急速落座，导致阀杆与阀座强烈撞击。

2) 查阅船方说明书，并了解车间的维修经过，得知该轮的排气阀座与阀杆都做过翻新修理。

说明书中针对该事项有一个注意要点: 

排气阀在修理后，为了防止阀座与阀杆的敲击，必须对缓冲活塞 h 值 ( 测量工具的顶端至缓冲活塞的顶端) 进行检查测量( 见图3) 。

图3 缓冲活塞的测量方法 

测量时应保证汽缸底部与排气阀接触部位间隙为0。

对 No.5 缸排气阀现场进行解体测量读数为 50.6，而说明书中该数据的标准范围为:

51.6～52.1 mm。

故实际测量结果不符合说明书要求，可判定故障原因就在此处。

3) 更换 h 值正常的备用排气阀后。

再次试车，故障得到解决。

## 3、No.6 排气阀液压油缸内部敲击声

通过对声音来源的辨别可判定该敲击声为阀杆顶部敲击液压活塞的声音。

原因分析为排气阀的液压活塞向上移动受阻，气阀关闭阻力变大。

根据原理分析故障点为:

①排气阀顶部的放气节流阀;

②汽缸安全阀。

排气阀顶部的放气节流阀如果被堵住，液压活塞向上移动受阻，气阀关闭阻力变大。

对该节流阀进行解体疏通，故障现象未消除。

再次对安全阀进行检查，内部积碳严重，有卡阻现象。

达到设定值时，安全阀未打开，此时空气控制室内空气容积减小，压缩比增大，排气阀关闭速度过快。

更换压力设定合格的安全阀备件后，再次运行柴油机，故障得到解决。

# 四、柴油机排气阀维护管理要点

1) 主机运行期间，及时监控各部件的运行情况，关注排气温度，仔细倾听各缸是否有异常声音。

2) 严格按照说明书要求对各部件进行修理，尤其是说明书中的注意要点，对各类部件进行精准的数据测量并记录。同时对零部件的清洁尤为重要。

3) 遇到问题及时了解工作原理，列出故障点，逐一排除。
