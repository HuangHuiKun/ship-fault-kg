# 导读

在柴油机工作过程中，主轴承可以保证曲轴的工作轴线，从而减小曲轴在转动中所受的磨损传递动力与摩擦。

然而，由于主轴承承受着很大的曲轴气体力、惯性力及摩擦力，容易发热甚至发生润滑油氧化变质的情况，最终导致曲轴挠曲变形过大甚至折断。

船用柴油机主轴承润滑性能的研究可分为以下几类：

- 对柴油机主轴承最小油膜厚度、主轴承轴心轨迹、最大油膜压力及最小油膜厚度等进行有限元计算，分析主轴承的润滑状况与润滑性能影响因子 [1]；
- 将曲轴设为弹性体，利用弹性流体动力学理论求解船用柴油机主轴承在不同温度、压力下的润滑性能，并提出优化对策 [2-3]；
- 结合弹性流体动力学理论、有限元法、多体动力学多学科理论分析柴油机油膜压力分布、最小油膜厚度、轴心轨迹、偏心距等参数，从而确定最佳主轴承润滑性能方案 [4]。

随着柴油机科技的提升，船用柴油机主轴承的实际应用新工况层出不穷，对主轴承设计参数的计算也需考虑得更全面。

以TBD620V8型高速船用柴油机为例，本文考虑不同工作转速、负荷工况下的主轴承润滑性能与油膜润滑状态，从而为提升主轴承设计提供理论参考。

# 二、船用柴油机主轴承润滑性能的优化

## 1、轴承宽径比的选择

作为轴承设计的重要参数，合适的宽径比一直是极力追求目标。

如图3所示，当偏心率在0.3~0.8范围内时，船用柴油机主轴承在设计中可选择较小的宽径比来促进油量的进入,从而改善船用柴油机主轴承的润滑性能。

图3 油膜轴承起始边进油量 随不同宽径比偏心率的变化关系

选择宽径比为0.4、0.45、 0.5、0.55 及0.6的柴油机轴承进行试验，研究不同宽径比下的应力及应变情况，得出结论如表6所示。

不同宽径比下的柴油机主轴承最大径向应力、轴向应力值基本稳定，而最大剪切应力和最大轴承应变随宽径比的变化出现波动。

其中，柴油机主轴承的最大剪切应力、最大轴承应变都在宽径比为0.4 的时候最小，两者取值分别为4.58MPa和0.00187，可见柴油机主轴承的宽径比选取0.4较为合适。

## 2、轴承合金层厚度的选择

长时间连续运作过程中，船用柴油机主轴承的内表面受到由交变载荷产生的交变应力及应变。

当应力及应变达到承载极限，会导致轴承合金层失效，产生疲劳裂纹甚至断裂 [5]。

为了尽可能提升轴承合金层性能，可从交变应力及应变角度进行优化设计。

选择厚度为0.3mm.0.5mm、0.7mm.1mm及1.5mm的柴油机轴承合金层材料进行试验，研究不同合金层厚度下的应力及应变情况，得出结论如表7所示。

不同合金层厚度下的船用柴油机主轴承在的最大径向应力、轴向应力基本处于稳定状态，而最大剪切应力、最大轴承应变随着合金层厚度的加厚而不断增大，可见减小合金层厚度是减小柴油机主轴承最大剪切应力、最大轴承应变可考虑的要点，然而合金层厚度的减小也需满足0.15~0.2 mm的铝合金主轴承磨损极限，以及0.6‰~1‰的轴承及轴颈的间隙比，以满足柴油机的正常工作需求。

# 三、结论

本文以TBD620V8型柴油机为例，考虑了油膜压力、油膜厚度等参数对主轴承润滑性能的影响，给出主轴承性能优化措施，得出结论如下。

- TBD620V8型高速船用柴油机在转速829 r/min,负荷率100%工况下，柴油机主轴承所受的最大油膜压力最大，尤其是第7主轴承的润滑性能最差。
- 在转速829r/min、负荷率100%工况下，柴油机第7主轴承曲柄转角为360°CA左右时，其轴心轨迹做离心运动，当曲柄转角为450°CA左右时，其轴心轨迹出现向心运动。
- 在转速829 r/min、负荷率100%工况下，柴油机第7主轴承曲柄转角为400~500°CA左右时，其最小油膜厚度已经触碰到了许用值的底线(5μm)。
- 减小合金层厚度是减小柴油机主轴承最大剪切应力、最大轴承应变可考虑的要点，然而合金层厚度的减小也需保证满足0.15~0.2mm的铝合金主轴承磨损极限,以及0.6‰~1‰的轴承及轴颈的间隙比。
- 柴油机主轴承的宽径比选取0.4较为合适，此时的柴油机主轴承的最大剪切应力、最大轴承应变都在宽径比为0.4 的时候最小，两者取值分别为4.58MPa和0.00187。
