# 导读

所谓柴油机的“三滤”，也即机油滤、柴油滤、空气滤，是确保柴油机正常运行的重要外围部件。

它对柴油机的使用寿命、动力性能及工作稳定性都有明显的影响。

# 空气滤清器

空气滤清器的作用是清除空气中的灰尘杂质，将干净的空气送入气缸内。

空气中含有大量的灰尘和杂质，特别是在粉尘作业环境更为严重，柴油机工作时，空气中的灰尘杂质将随着空气一起被吸入气缸内，与机油混合在一起，形成破坏性极大的研磨剂，造成气缸、活塞组及配气机构等严重磨损（俗称磨料磨损），使柴油机使用寿命大大缩短，所以不允许柴油机在没有空气滤清器的情况下工作。

按时检查、清理空气滤清器，不仅能保证进入气缸内的空气清洁，减小进气阻力，还可以通过观察积尘盒内的尘埃，来判断所在地区空气中灰尘的多少，帮助选用合适的空气滤清器。

如风沙粉尘很大，就应选择沙漠滤清器；如果空气湿度很大，就不应选用纸滤芯的滤清器。

# 燃油滤清器

燃油滤清器的作用是滤除燃油中的各种杂质，保证清洁的燃油进入系统内，使其正常工作。

燃料在贮存、运输和加油过程中，往往将一些杂质混入进去，如尘土、砂子、金属细屑等，如果不清除掉这些杂质，使杂质随同燃油进入燃油供给系统各精密偶件（如喷油泵柱塞偶件、喷油器偶件）内，便造成零件磨损加剧，甚至发生卡死现象，导致柴油机发生燃烧不良，功率下降，排气冒烟，更严重的会引起飞车等重大故障。

因此在燃油供给系统中燃油滤清器十分重要。

定时清洗燃油滤清器，能清除附着在滤芯外表面或沉积到壳体底部的杂质污物，防止因滤芯堵塞引起供油不足，使柴油机功率下降，甚至产生供油中断，造成突然停车。

同时，定期清洗燃油滤清器，可根据过滤杂质污物量的多少判断燃油的清洁度，以便采取措施。

对有损坏或严重污染的滤芯，要报废，换新件。

# 机油滤清器（离心滤清器）

机油滤清器的作用是除去机油中的杂质，防止杂质随同机油进入零件摩擦表面，保证机油在使用过程中具有良好的润滑性能，延长柴油机的使用寿命，同时也延长机油的使用期限。

柴油机工作过程中，机油里不可避免地要混入一些杂质，如环境中的尘埃，磨损下来的金属细屑，燃烧产生的积碳等，这些杂质混入机油中，会随着机油带入摩擦表面，从而造成零件的严重磨损，甚至使零件表面产生严重拉毛或划伤，更为严重的会使润滑系统油路堵塞，造成烧瓦等严重事故。

定时清洗机油滤清器、离心滤清器，不仅能清除过滤的杂质、污物，保证机油的清洁，更重要的是，通过观察分析杂质、污物的成分和数量的多少，来判断柴油机潜在的故障隐患，并及时排除，防止柴油机发生重大恶性事故。

# 常见的几种现象和重点关注点

如在正常的保养时间内发现滤前、滤后压差过大（不得超过196 kPa），就要清洗两个机油滤，若发现污堵、油垢很多，就要考虑机油是否过脏，应更换机油，同时更换滤芯。

如果在清洗机油滤清器时，发现铜屑，就应从以下几点判断：

首先撬动曲轴，检查曲轴轴向间隙（12V190B型机曲轴轴向间隙0.28~0.44 mm），如果间隙过大，就是曲轴止推片发生了异常磨损，如果间隙过小或没有，就是传动件顶住了飞轮。使曲轴向前受力，势必造成止推片的严重磨损。

曲轴轴向间隙正常（或略大一点也算正常），就要打开缸盖上罩，检查气门摇臂铜套，有无异常磨损。

发动柴油机，怠速运转，用听棒听传动齿轮是否有杂音，如有杂音，就要考虑传动齿轮铜套是否有异常磨损。

滚轮摇臂铜套和机油泵铜套异常磨损，较少见，如果检查不到其他原因，也要考虑检查这两处。

在清洗机油滤清器时，发现铝屑，就要考虑主轴瓦和连杆轴瓦，这里要重点说明：如果使用的是新柴油或新大修的柴油机或更换主轴瓦、连杆瓦的整修机，第一次开机使用，发现有少量的铝屑，可先清洗滤清器（有条件的同时更换机油），再使用一段时间，铝屑明显减少或消失，就可正常使用（原因是在修理装配时没有清理干净）。

如果是正常使用过一段时间的柴油机，发现铝屑，就要检查连杆瓦、主轴瓦，同时如果发生拉缸、化活塞等恶性故障，机油内也会有铝屑。
