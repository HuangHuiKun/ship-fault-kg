# 导读

某船柴油机型号为MAN B&W 7S60MC-C,2014年发生柴油机主轴承损坏故障,经检修,确认故障为静电腐蚀所致,维修周期长达半年,延误船期并造成较大损失。

同时,由于修理工艺的不同,柴油机 No.1主轴承异于其他主轴承,加装有监控设备,增加管理难度。

# 一、故障发生及修理

## 1、故障发生现象

2014年1月28日1925时,该船在距越南海防港40n mile处突然停车,正、倒车均无法启动;随后进入锚地扩大检查,打开曲轴箱,在No.1主轴承附近发现脱铅及金属粉末。

打开No.1主轴承上瓦盖,发现柴油机第一道主轴瓦和主轴颈有麻窝点凹坑,部分区域呈烧熔状态(见图1),轴瓦和轴严重烧坏,部分烧熔区域呈龟裂状。

图1 柴油机No.1主轴颈受损区

## 2、修理过程

用拖船将该船拖至越南后,越南工人先后进行十余天的修理,但无法完成修复。

经了解,目前全球只有METALOCK公司(丹麦MAN公司的下属子公司)能在不拆出曲轴、活塞等附件的情况下进行现场修理,其修理时间较短,费用相对较少,修理质量也能得到保证。

经过公司积极联系协调,5名工程师历时4个月左右完成主轴颈及相关设备的切削、研磨和抛光等修理工作。

经过海上试航测试、CCS验船师检验,修理后的质量满足要求,柴油机运转至今未发生异常情况。

# 二、事故原因分析

## 1、事故调查

公司成立事故调查组,在修理过程中认真检查拆开的每个部件,并拍照、取样;仔细检查轮机日志中的各项技术参数;检查柴油机的热工报表数据、滑油检验报告以及相关设备的使用情况等。

综合分析各项数据,并结合MAN工程师的调查报告,初步总结此次机损事故的原因可能为:滑油中含有水分等杂质;主轴承螺栓松动;轴系接地装置缺少保养等。

进一步调查分析可知:

(1)事故发生前该船滑油分油机一直处于正常运行中,滑油滤器状况完好,查阅滑油化验报告未发现杂质超标,滑油中含有杂质的可能性可以排除;

(2)查阅轮机日志和主机检修记录簿并咨询主管人员得知,机损事故发生前一个月,大管轮对主机曲轴箱进行常规检查时未发现异常,螺栓松动的可能性也不大;

(3)现场检查娓轴接地装置发现,触头与轴合金环片接触处出现松动,环片背面(与轴面接触)锈蚀(见图2)。

图2 艉轴接地保护装置损坏

查阅坞修记录可知,该船舰轴接地装置在2013年3月进厂前一直处于失修状态,而2013年坞修时也未对其中的任何一道主轴瓦进行拆开抽样检查。

## 2、故障原因分析

该船原船舶所有人有卖船计划,在维护保养方面的投入较少,导致机损事故发生的最可能原因是静电腐蚀,即舰轴接地装置缺少保养而发生的静电腐蚀。

安装在舰轴上的合金滑环片背面锈蚀,导致合金层与舰轴之间无法紧密贴合,产生的静电不能及时消除。

静电会破坏润滑油膜,造成主轴承表面和轴颈表面产生麻点、毛刺,表面粗糙度增大,导致主轴承表面合金层磨损异常,短时间内产生的金属粉会堵塞油孔,从而导致机损事故的发生。

据 MAN主管工程师Hansen先生介绍,舰轴接地装置损坏，产生静电腐蚀导致机损的过程较长,有时潜伏期可达几年。

# 三、静电腐蚀

## 1、机理分析

静电腐蚀的原理是轴瓦与轴颈之间产生的电势未得到有效释放,形成电离子流,击穿油膜,电离子流短时间内对轴颈形成轰击效应,这种轰击会转变成热能,导致轴瓦上的白合金被静电溶解。

在短时间内,这种轰击力局部冲击白合金,产生金属颗粒,表面就会形成凹坑。

部分颗粒被滑油带离,未完全脱离的颗粒粘在轴上,造成轴表面粗涿度增大,加剧磨损,导致损坏。

静电腐蚀时刻存在于柴油机中。

新材料的应用使得柴油机对静电腐蚀更加敏感,主要表现在以下几个方面。

(1)铝、锡材料的使用。

铝、锡材料可以改进衬套的疲劳强度;而一旦产生静电腐蚀,铝、锡材料的衬套比白合金衬套损坏得更快。

(2)主轴瓦厚度。

为改善衬套的疲劳强度,白合金轴承衬套的厚度已从2.5 mm降为1.5mm,静电腐蚀从开始到发生破坏的时间也缩短。

(3)油膜的厚度。

低速大功率柴油机的使用,导致主轴承内最低油膜厚度随之降低。

(4)柴油机降速使用,使得轴承间动力润滑的建立变得困难,运动副之间的润滑形式变得更复杂。

## 2、应对措施

(1)定期认真测量主轴承的间隙。

由于主轴承平时很少打开,无法了解其表面状况,有时即使打开也难以发现和识别静电腐蚀的迹象,故要求定期测量主轴承的间隙(每季度测量)以及曲轴拐挡差,并将测量数据与上一次测量数据进行对比;每次坞修时,必须抽样2~3道主轴承打开检查,发现有静电腐蚀时轴瓦须换新,并对轴颈进行抛光处理。

(2)安装轴系接地装置。

静电腐蚀的预防措施是安装轴系接地装置,将产生的电荷释放至船体。

轴系接地装置由滑环、碳刷、连接船体的电缆以及监测设备等组成。

安装时须注意以下几点:

将滑环固定安装在清洁、已抛光的轴上;将碳刷安装在滑环上,严禁将碳刷直接安装在轴系上;在轴与滑环之间施加防锈蚀保护措施;精确调整碳刷支架的预紧度。

(3)轴系接地装置的维护、保养。

定期检查碳刷,及时更换磨损的碳刷;保持滑环的清洁和干燥;保持滑环与碳刷适当的接触压力,及时调节碳刷预紧弹簧的预紧力;滑环的表面是镀银的,在镀银层磨损前及时更换滑环;每次坞修时,须打开滑环检查，如果滑环背面与轴系接触处锈蚀严重,应换新;坞修舰轴拆检后要及时检查恢复接地装置。

滑环与轴系之间的腐蚀很难被发现,一般采取以下方法:若未安装监控电压表,至少每月测量滑环与轴之间的电阻,若电阻超过5 mQ2,则滑环需要拆检;若安装有监控电压表,可经常检查电压表读数,当电压长时间超过50 mV时,须检修滑环。

# 四、结束语

由于船舶柴油机发生静电腐蚀的案例并不多见,使得大多数船舶管理者、主管人员对轴系接地装置的维护和保养没有足够重视。随着新技术、新材料及大功率柴油机的应用,静电腐蚀发生的概率大大增加,这就需要管理人员加强维护和保养方面的工作。
