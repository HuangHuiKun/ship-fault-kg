# 导读

当前，我国船舶所使用的发动机类型大多是柴油发动机。

从船用柴油机的基本组成与动力构造视角出发，柴油机的修理不仅仅是简单的零部件换装、拆卸组装，更在于对柴油机内部系统的分析。

因此，对船用柴油机常见故障的诊断率直接影响着柴油机的维修效果。

实际情况中，一方面由于维修人员的技术有限，另一方面由于柴油机本身系统故障的复杂、隐蔽性强，造成维修成本高及资源浪费。

文章结合着船用柴油机的系统构成，分析其常见的故障，并寻找有效诊断故障及维修的对策，从而为船舶航行提供动力基础。

# 一 船用柴油机的基本系统组成

## 1. 机体组件与曲柄连杆系统

首先，船用柴油机的基本系统由各个部件与动力结构共同组成，其中机体组件系统是柴油机的基本骨架，是柴油机在船舶上得以运转的骨架基础。

机体组件系统由各个零部件共同组成，是柴油机整体系统的有机统一，如气缸盖、气缸体等部件，均是船用柴油机的机体组件系统的重要部分。

其次，曲柄连杆系统是船用柴油机系统运转的枢纽，在柴油机与船舶其它动力系统之间发挥着纽带式的作用。

曲柄连杆系统的主要工作是负责将活塞的往复运动转换为曲轴的旋转运动，对此，曲柄连杆系统的稳定性，直接影响着整个船舶运行的稳定性。

曲柄连杆系统主要由活塞组、连杆组、曲轴飞轮组等部件共同构成。

## 2. 进排气与燃油供给系统

首先，进排气系统是船用柴油机的呼吸系统，其主要功能机制是为船用柴油机提供充足、干净的新鲜空气，为柴油机内部的动力燃烧提供新鲜的氧气，保证柴油机的基本工作。

同时，进排气系统也负责着将柴油机燃烧后的废气排出，保证柴油机内部系统安全运转。

对此，进排气系统是柴油机经济、高效运行的重要保障，其主要由进排气门等部件构成。

其次，燃油供给系统是船用柴油机的主要内部系统组成，其主要由高压油泵、喷油器等部件组成。

燃油供给系统的稳定性直接关系着柴油机的整体运转，更决定着整个船舶的有效运行。

燃油供给系统的主要作用机制是按照船用柴油机一定的负荷，为船用柴油机提供燃料供给，向柴油机气缸内喷入适当的燃料，从而保证整个柴油机系统的工作。

## 3. 润滑与冷却、启动系统

首先，润滑系统是船用柴油机的运行的系统保障，其主要目的是以一定压力不断的为柴油机各个零部件及系统输送清洁的润滑油，保证柴油机各个部件的动力输出，减少各个部件之间因摩擦带来的材料损耗，同时减少摩擦阻力，确保机器设备的高效运行。

润滑系统主要由滑油泵、滑油管等部件构成。

其次，冷却系统是保证柴油机能够在正常温度下工作，避免因柴油机长时间运行带来的高温损耗，其主要由水泵、水箱等部件组成。

最后，启动系统方面，其主要动力机制是提供外部动力供船用柴油机的安全可靠启动。

# 二 船用柴油机维修的常见故障

## 1. 气缸套故障

气缸套一般是在主机的气缸体孔中发挥作用，是一个像杯子一样的圆筒形器件。

气缸套根据作用其形式不同，一般分为干式缸套式、湿式缸套式和无气缸套式三种。

由于气缸套与缸盖、活塞形成密闭的气缸套工作的空间。

活塞通过气压的作用在气缸内不断进行往复运动发挥气缸的作用。

其工作过程中涉及到大量的系统参与，因此是船用柴油机最容易发生故障点之一。

最常见的故障就是气缸套穴蚀。

由于船舶柴油机在运行的当中，活塞要进行不断的反复运动，造成汽缸内部的温度持续升高，气缸套内部与外部压力不均衡，一旦活塞在运动的过程中容易发生持续冲击缸套外表的现象，造成气缸套外部金属脱落，发生气缸套穴蚀的现象。

一旦气缸套穴蚀，整个气缸套系统将发生变化，柴油机将出现运转故障甚至停止运转。

## 2. 滑动轴承故障

滑动轴承作为船用柴油机主要系统构成之一，是柴油机系统中最容易发生故障的物件。

一方面，滑动轴承始终在柴油机中发挥着枢纽沟通式的作用，只要柴油机运转，滑动轴承就无时无刻不在运动着，由于滑动轴承的持续运转，需要干净的润滑油加入，一旦润滑油中含有异物，直接导致滑动轴承的轴瓦表面有凹槽产生，滑动轴承的寿命将大大降低，极其容易出现运转终止的情况。

另一方面，滑动轴承在运转过程中，将持续的对轴承部件进行损耗，此类损耗是不可挽回的损耗，一旦滑动轴承的损耗过于严重，检修人员在没有识别出故障问题或及时更换部件的前提下，滑动轴承容易发生运转偏向，甚至出现龟裂、断轴等现象，对整个船舶运行的安全性及柴油机稳定性直接造成严重影响。

## 3. 柴油机“三滤”故障

柴油机运转过程中涉及到空气清滤、柴油清滤、机油清滤，在此基础上需要安装空气滤清器、柴油滤清器、机油滤清器，简单称之为“三滤”。

首先，空气清滤方面，柴油机每天运行中，需要大量的空气进入及气体排出，在气体进出的过程中，极其容易造成含有杂质空气物质进入，如尘土、沙粒、污染物等等，一旦含有杂质的空气进入到柴油机系统内部，将直接对柴油机系统运行造成严重影响，其次，柴油机工作运转需要柴油的加入，柴油中含有不同程度的杂质，长期下来对柴油机系统造成侵蚀与破话，是最容易引起柴油机故障的因素之一。

机油清滤方面与柴油清滤类似，需要对机油中的杂质进行剔除，否则将影响柴油机的寿命。

## 4. 安全阀与燃烧室故障

首先，安全阀在柴油机的系统运转中发挥着基础保障性作用，同时也是柴油机最容易发生故障的部位。

实际情况中，安全阀发生故障大多是由于柴油机进行连续的高强度工作，超过一定的额定功率时，气缸内部的压力开始升高，此时安全阀就会发生起跳的现象。

一旦安全阀发生起跳，倘若不及时的进行处理，将会导致船舶运行整体故障的出现。

此外，安全阀发生故障也多由安全阀本身质量不高所引起，一些维修人员进行检修的过程中，没有对安全阀的合格指标进行分析，造成安全阀运转过程中因质量问题发生故障。

其次，柴油机的燃烧室是柴油机工作的主要空间，燃烧室在每次维修后期容积会发生变化，长期以往将造成各种问题的发生。

# 三 船用柴油机维修的有效对策

## 1. 气缸套故障的维修

通过对船用柴油机常见故障的分析可知，气缸套穴蚀是常见的故障源之一。

通过气缸套故障的诊断，在其维修中主要采用几个方面：

其一，采用封闭式冷却方法使冷水温度保持相对的恒定范围值内，从而确保机械零部件的适当热膨胀系数，从而实现避免气缸套穴蚀现象发生。

其二，在冷却液中添加乳化油等防腐蚀剂，通过抗腐蚀剂的加入，在气缸套表面形成保护膜，从而减少气缸套穴蚀现象发生。

其三，在故障维修中可以考虑将冷热交杂的温度差反应更换为冷水与冷水之间的物理反应，从而避免气缸套故障的发生。

## 2. 滑动轴承故障的维修

针对滑动轴承故障所出现的问题，在故障维修中要保证柴油机润滑油的供给状况良好。

首先，对于滑动轴承出现的问题比较大的情况下，可以直接考虑更换新的轴承。

在更换新的轴承过程中，维修人员要对润滑油进行全面的分析与考量，保证润滑油的干净、无污染。

在发现有污染物的润滑油时，要直接丢弃，避免因润滑油问题给新的轴承带来的损坏。

其次，通过计算机检测、实际物理实验、动态观察等方法诊断出滑动轴承故障在维修的范围之内情况下，采用维修、焊接维修、重新填充轴承衬套与喷涂等方法对故障轴承进行维修，从而避免材料资源的浪费。

## 3. “三滤”故障的维修

针对空气污染物、柴油杂质、机油杂质对船用柴油机带来故障现象，需要通过安装空气滤清器、柴油滤清器、机油滤清器的方法给予解决。

首先，空气滤清器、柴油滤清器、机油滤清器的安装过程中，需要注意其安装位置。

空气滤清器安装的过程中，需要将各个零部件的位置一一对应，避免安装位置错位的现象。

纸滤芯两端需要安装上橡胶圈，固定的空气滤清器螺丝切勿拧的太近，以免螺丝太近造成对滤清器表面压力过大而造成变形。

其次，在空气滤清器、柴油滤清器、机油滤清器的维修过程中，需要对滤清器的滤芯进行清洗，同时清理橡胶物圈上的赃物，安装过程中保证滤芯与物件的密封性良好。

## 4. 安全阀与燃烧室故障维修

针对安全阀、燃烧室的维修，首先要对安全阀与燃烧室的故障进行诊断。

其故障诊断方法往往采用直接观察法，传统的诊断方法并不容易全面发现安全阀、燃烧室所出现的问题，不能够对其所出现的问题进行全面深入的分析。

因此，需要采用热力参数分析法、振动分析法、瞬时转速法等方法对安全阀与燃烧室故障进行诊断，同时配合着传统的检测方法，提高故障诊断效果。

通过对安全阀与燃烧室的故障诊断，在此基础上采用安全阀更换、主机重新启动的方式让起跳的安全阀恢复常态。

其中，安全阀的更换上，尤其注重安全阀的质量，确保安全阀产品的合格。

燃烧室发生的故障大多由积碳而引起，由于积碳长时间未清理或清理不干净，导致燃烧室内腐蚀。

对燃烧室的焊接治标不治本，关键在于积碳的清洁。

针对于柴油机燃烧室的积碳，可以采用机械法进行剔除，如采用钢丝刷、刮刀、竹片等工具。

同时，也可以使用化学法，将退炭剂作用于燃烧室金属表面，将软化的积碳进行清理，此种方法除积碳效果好，能够保证燃烧室内的清洁，从而保障燃烧室的正常工作与运转。

# 四 结束语

综上所述，船舶柴油机的安全性是船舶安全、高效运行的基础保障，更是船舶操控人员生命安全的根本。

船用柴油机的日常使用中，其气缸套、滑动轴承、柴油机“三滤”系统、安全阀与燃烧室方面是常见的故障源之一。

对常见故障的维修，需要采用复合诊断法与对应维修法综合的手段对每一个故障点进行维修与预防，从而保障船用柴油机的稳定性、安全性。
