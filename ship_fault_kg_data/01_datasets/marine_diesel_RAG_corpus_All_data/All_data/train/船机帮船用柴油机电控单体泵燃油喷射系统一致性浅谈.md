# 导读

电控单体泵的主要功能是保证燃油系统喷射特性一致，即定时、定量、定压供给燃油。它体现在单只喷油泵循环喷油量波动率，以及各个喷油泵之间喷油量的一致性。

为了实现电控单体泵供油系统喷射特性一致性，可以从两个方面来控制：

一是控制燃油系统各零部件加工制造的一致性；

二是ECU标定策略柔性控制，补偿喷油泵的制造公差。

# 一、引言

为防治船舶大气污染物排放对环境的污染，改善环境空气质量，中国2019年7月1日实施了《船舶发动机排气污染物排放限值及测量方法（中国第一、二阶段）》第一阶段，2022年7月1日实施了第二阶段。

为了降低柴油机的油耗和减少有害排放，满足经济性和排放法规的要求，采用电控技术是必不可少的技术手段，电控技术的应用已是当前船用柴油机发展的重要方向之一。

针对船用中速柴油机，主要的技术路线有两种：

一是电控单体泵路线；

二是共轨路线。

由于共轨系统主要供应商集中在国外，有一定的技术垄断性，使用成本、维修成本相对较高，在国外产品上应用较多，国内应用相对较少，处于起步阶段。

目前大多数主机厂都采用电控单体泵技术路线。

电控单体泵是由高速强力电磁阀计量燃油量的时间控制式喷油泵，具有供油压力高、供油始点灵活可调的特点。

与传统的机械泵燃油系统相比，电控单体泵系统通过ECU控制喷油泵电磁阀通断实现定时、定量、定压喷油，代替了调速器控制喷油泵齿条喷油。

# 二、电控单体泵工作原理

电控单体泵的整个工作循环如图2所示，由充油行程、供油行程、泄油行程组成。

图2 电控单体泵工作原理

当柱塞下行时，ECU不发送驱动信号，电磁阀处于打开状态，低压燃油被吸入柱塞腔（充油行程）。

当柱塞上行进入供油段时，ECU发出脉冲信号，电磁阀关闭，高压区与低压区隔离，柱塞在凸轮的驱动下开始建压，当油压达到喷油器的启阀压力时，喷油开始（供油行程）。

供油持续一段时间，ECU驱动信号消失，电磁阀断电，旁通阀在旁通阀弹簧的作用下回到开启状态，高压腔内的高压燃油泄到低压回路，高压油管内压力下降，针阀落座，喷油过程结束（泄油行程）。

基于电控单体泵的工作原理，在产品开发过程中可能会遇到一些问题，例如：各缸排气温度异常、爆压异常、泵端压力波动、功率不足等。

经过全方位系统分析，最终判定为燃油系统一致性差导致问题发生。

电控单体泵性能开发的一个重点，就是保证系统喷射特性一致（定时、定量、定压供给燃油）。

它体现在单只喷油泵循环喷油量波动率，以及各个喷油泵之间喷油量的一致性。

为了实现电控单体泵供油系统喷射特性一致，可以从两个方面来控制：

一是控制燃油系统各零部件加工制造的一致性；

二是ECU标定策略柔性控制，补偿喷油泵的制造公差。

# 三、燃油系统各零部件的一致性

## 1、电控单体泵油量一致性

电控单体泵供油量一致性影响整机各缸排气温度的一致性和各缸爆压的一致性。

经过试验分析确认，其中计量部分相关要素对电控单体泵油量一致性的影响最大，特别是旁通阀偶件间隙、阀芯流通面积与衔铁气隙、电磁阀中电磁线圈的感抗差异。

目前主要通过与供方签订技术协议，明确各工况下油量一致性要求，供方通过制造工艺和检测手段来确保电控单体泵油量一致性。

## 2、喷油器流量一致性

喷油器流量一致性对整机性能影响也比较大，影响排温、爆压、烟度。

喷油器部分的参数主要有喷油器开启压力、喷油器针阀升程和喷油器流量系数。

喷油器流量一致性的约束条件通常是通过10MPa进油压力时，1分钟或30s的喷嘴流量来表示，例如：3000±3%（mL/30s @10MPa）。

目前的行业标准公差是±3%，绝大多数供应商都能满足。如果要减小流量公差到±2%或±1%，则喷油器的制造成本将大幅上升。

这也是制约电控泵喷油系统一致性的关键因素之一。

## 3、低压油路一致性

低压油路的一致性，主要体现在低压供油压力上。

低压供油压力影响电控单体泵的吸油充分程度，进而影响循环喷油量的稳定性。

喷油系统吸油的充分程度取决于低压供油压力和有效吸油时间。

在多缸电控单体泵供油系统中，由于多缸共用一个低压油路，且各缸供油有一个相位差，当一个气缸的电控单体泵供油系统正从低压油路充油时，另一个气缸的电控单体泵供油系统刚将高压燃油泄到低压油路。

因此在多缸不断的充油放油过程中必然会导致低压油路的波动以及每缸充油时燃油状态的不一致。

高压喷射过程和低压油路的供油过程密切相关。

各缸供油系统中单体泵充油时，低压油路供油压力不一致，会导致电磁阀关闭燃油压缩时的油压曲线差异，且该差异在单体泵充油不足时更为明显。

通过台架试验发现，吸油时间的长短由凸轮转速决定，因此由低压供油压力的变化所导致的循环喷油量波动主要受凸轮转速影响，当凸轮转速升高时，燃油系统的有效吸油时间缩短，供油压力变化对燃油系统吸油充分程度的影响更明显。

例如：高工况、大扭矩点波动较大，如图4所示。

图4 低压油压力波动对对泵端压力的影响

因此低压油路的油压波动是导致多缸供油系统各缸供油不一致性的主要原因。

然而，影响低压油供油压力波动的因素较多，包括进油管路容积大小，单项阀开启压力、回油管路背压（进日用油箱，还是回到输油泵前）、日用油箱高度等。

可以通过液力系统仿真计算，选择合适的边界条件，在通过台架试验来跟踪验证，最终满足低压供油系统的一致性需求。

通过台架试验，给出的建议是：

增大进油管路容积30%，单项阀开启压力提升30%~50%，回油管直通日用油箱。

# 四、ECU标定策略柔性控制

针对电控单体泵燃油系统供油一致性问题，目前硬件上的工艺保证能力已经提高到了一个相对较高的水平，但是在产品的实际使用过程中，仍然会存在各缸均匀性的差异。

为了弥补零部件制造过程中公差范围内的差异（机械泵是通过手动调整齿条刻度实现），可以通过ECU标定策略上的柔性控制来补偿硬件制造上的不足，尽可能地提高供油系统一致性，改善发动机的性能。

这样不仅解决了生产工艺上的瓶颈限制，也可以针对各个转速点的供油一致性作调整，有利于改善电控泵柴油机整个功率范围内的工作平稳性。

目前的市面上的修正策略主要有两种模式。

一是“单点线性修正策略”，采用1个时间量的修正码线性修正。

例如，采用的修正码是额定点脉宽+3%或+5%等。

二是“多点修正控制策略”，支持分段设置修正码，可以灵活配置各转速下修正量，获得最佳的修正效果，尽可能满足不同转速段的非线性修正趋势要求。

这两种修正策略各有优缺点，现在分析如下。

第一种策略的优点是修正逻辑简单，后市场更换单体泵时，只需要更换喷油泵，无需读入相应的修正码，对服务人员的技能要求较低；

缺点是非精确修正，对喷油泵、喷油器等零部件硬件一致性的要求较高。

第二种策略的优点是不同供油量相对精确的修正，对硬件的一致性要求相对较低；

缺点是修正逻辑相对复杂，后市场更换单体泵时，需将相应的修正码读、写入ECU，并与转速点形成映射关系，从而在形成一个修正脉谱，对服务人员的技能要求较高。

# 五、总结

通过总结近几年船用电控泵柴油机项目开发中遇到的问题，主要集中在各缸排气温度一致性、爆压一致性差异较大，低压油管进油压力波动大等问题。

从在解决这些问题过程中实施的措施上看，还是体现在控制电控单体泵燃油系统一致性上。

通过液力仿真计算来确定初始的燃油系统边界条件，再通过台架试验来验证仿真结果的实际效果，这样形成一个闭环，来确定最佳的电控单体泵燃油系统边界。

通过研究发现，电控单体泵燃油系统对低压油的进油压力要求相对较高，达到0.4MPa~0.6MPa，进油管路容积在一定条件下越大越好；

从控制策略上来兼容硬件的一致性差异，采用“单点线性修正策略”，时间量的修正码是额定点脉宽+3%~+5%。

总的来看船用电控泵柴油机作为过度产品，有一定的技术局限性。

对比国外知名公司同类产品，所采用的技术路线都是共轨，还是存在代差，国内船用中速柴油机的发展之路任重道远。
