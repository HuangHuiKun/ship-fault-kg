# 导读

船用柴油机可以根据转速或者活塞平均速度进行划分，通过分析船用高速柴油机的定义，讨论船用高速柴油机润滑技术的性能要求。

由于不同工况下，柴油机润滑性能不尽相同，对几种特殊工况进行分析。

为了更好地讨论高速柴油机润滑性能，以9G32大功率船用柴油机为例，讨论其主轴颈的润滑性能，对于其他类似船用高速柴油机均有借鉴意义。

最后介绍了船用高速柴油机润滑油的选用。

# 一 船用中、高速柴油机概述

船用柴油机有多种形式，相应的划分方法很多，常见的是以下3种：

1. 根据工作循环特点不同，可以分为二冲程柴油机与四冲程柴油机；

2. 根据进气方式不同进行划分；

3. 根据柴油机转速或者活塞平均速度的不同进行划分。

摘自《钢质海船入级规范2018》

本文的讨论对象是中高速柴油机，可以依据内燃机转速或者活塞平均速度进行界定，采用这种方式划分，可以将船用柴油机划分为低速柴油机、中速柴油机与高速柴油机。

高速柴油机在现代船舶中应用越来越广泛 ，并且逐渐采用了涡轮增压等设计。

中、高速柴油机相关技术更新换代很快，经济性越来越高，气缸数量不断增多，同转速发挥的功率越来越大，进而保证了船舶更快的运行速度，提高航运效率。

# 二 船用中、高速柴油机润滑油技术性能要求

船用柴油机每年消耗的润滑油数量很大，全球每年消耗超过300万吨，尽管如此，各个国家对于润滑油技术性能并未形成统一标准 ，船用柴油机机油供应商根据柴油机使用情况与工作特点，使得润滑油具备一定规格，并开展大量船用机油研究与产品开发工作。

尽管当前国际范围内尚未在船用柴油机机油方面形成统一标准，但是各国对润滑油性能的描述大体相同，因此，规格牌号与命名方法相差不大。

船用四冲程高速柴油机结构以及工作循环特点和车用柴油机类似，在其润滑系统中，曲轴箱、缸孔、主轴颈、连杆大小头使用一套润滑系统，采用相同润滑油。

所用润滑油水层大于1，乳化层小于0.6，粘度指数大于95。

# 三 不同工况下主轴承润滑性能

## 1.全负荷各转速下主轴承润滑性能

依照GB/T3475进行试验，在全负荷情况下，取四个不同转速进行试验，进而获得4个情况下的扭矩情况。

GB/T3475规定选用标定转速的63%、80%、91%以及100%，因此对于9G32高速柴油机而言，测试工况转速分别为 380、492、591、600（r/min），其主轴承的扭矩值以此为815、826、1024、1293（N·m）。

主轴颈总共有10个，从前端往后端依次编号为 MB1、MB2……、 MB9、MB10。

10个主轴颈在不同工况下的最大负荷情况如表 1 所示。

从表1不难发现，在全负荷情况下，随着转速由600r/min下降到380r/min，主轴颈承受的最大负荷是不断增加的，而且在 380r/min 时，各主轴颈均达到最大负荷的最大值，这符合柴油机受力情况。

主轴颈所受的力由爆发压力、往复惯性力与旋转惯性力共同组成。

对于某一特定转速，主轴承所受最大负荷是急燃期，这个时候缸内爆发压力最大。

惯性力与转速成正比，因此，转速降低的情况下，往复惯性力与旋转惯性力会减小。

之所以低转速下，主轴承所受负荷最大，是因为柴油通过改变进油量调节转速大小，转速越小，扭矩越大，此时进油量更大，气缸压力增大，随着进油量增加，缸内压力增大，使得主轴颈负荷更大。

为了分析主轴颈的润滑情况，可以使用有限差分法，降低计算量。

将表1所示的轴承负荷作为边界条件，结合轴承参数获得油膜压力分布曲线，基于Holland法可以得到最小油膜厚度。

主轴承最小油膜厚度在不同转速下差别很大，而且不同主轴承随着转速的变化规律不同。

其中 MB1、MB3 与 MB4 所受负荷虽然不是最大，但是油膜厚度小于临界值，可见油膜厚度与轴颈运动直接相关。

偏心角变化率等于0.5时，剪切流等于0，旋转油膜力等于0，偏心率变化率大约等于 0，油膜厚度很小。

随着转速增大，最大油膜压力呈现出上升趋势，各主轴颈的最大油膜压力分布和负荷分布大致相同，这也为预测危险部位提供方法。

## 2.相同转速不同负荷时主轴承润滑性能

维持柴油机在380r/min 的转速下运动，改变负荷率。

各个主轴承随着负荷率的变化规律不同，其中MB4在负荷率为50%时最小油膜厚度最小，而MB5与MB9则在负荷率为75%时最小油膜厚度最小。

对于最大油膜压力而言，当负荷率增大时，各主轴颈最大油膜压力是增大的。

# 四 船用中、高速柴油机润滑油的选用

在评价润滑油是否符合船用高速柴油机使用要求以及基本技术参数以外，还需要综合考虑检验期采用的燃料油是否满足要求。

在明确基本技术参数以后，可以通过查表的方式得到船用高速柴油机所用机油的粘度等级，这一等级往往在柴油机设计阶段就已确定 ，不可更换其他牌号机油使用。

之所以考虑燃料油，是为了获得船用机油的碱值等级。

通常认为，当选择高硫燃料时，虽然有时进行清净度比分，和低硫燃料相比差距不会太大，但是当硫含量超过一定值后，可能会导致活塞环卡死等危险现象。

因此，在明确了机油粘度等级之后，还必须准确得到碱值等级。

船用高速柴油机可以以中速机为参考依据 ，将中速机油用于润滑介质，借助于注油孔将润滑油运送到缸壁与活塞上。

由于润滑油与燃油不可避免地、或多或少地会混合在一起，在压燃过程中生成 SOx，从船舶安全性与可靠性润滑角度来看 ，燃料硫含量也直接影响润滑油碱度，高速机油碱值中心值选择与燃料含硫量的对应 关系如表 2 所示。

高速柴油机是船舶必不可少的动力源，由于工作环境恶劣，必须充分重视高速柴油机的润滑。

润滑分析主要分为润滑油选取与主要部位润滑性能2部分，本文对船用中高速柴油机润滑油性能要求进行分析，以主轴颈为例讨论其润滑性能。

除此之外，船舶高速柴油机还需要考虑粘度等级以及碱值牌号。
