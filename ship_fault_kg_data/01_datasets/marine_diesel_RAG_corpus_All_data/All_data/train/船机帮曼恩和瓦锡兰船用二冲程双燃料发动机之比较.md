# 导读

柴油-天然气双燃料发动机是在原柴油机基础上改装的既可以燃用天然气（以少量柴油引燃）又可以用柴油作为单一燃料的发动机。

天然气的主要成分有甲烷、乙烷、丙烷、丁烷等，其中甲烷占70%~90%，硫化氢及氮气含量微小。

天然气的燃点约 650℃，着火温度较高，以天然气为燃料的发动机在压缩过程中缸内气体温度达不到其自燃点，因此必须依靠电火花点火，或者先喷入少量柴油（柴油燃点一般为 220℃），柴油自燃再引燃天然气。

用 LNG 加柴油混合动力的船舶，可比单独使用柴油动力节约燃料费用 25% 左右，且其尾气中 CO₂排放会减少 25%，NO X 排放减少约 85%，SO X 减排近 99%，颗粒减排近 98%。

柴油 - 天然气双燃料发动机最先应用于 LNG船，由于双燃料发动机具有诸多优点，大有向普通货船转移的趋势。

船用二冲程柴油-天然气双燃料发动机现主要机型有MAN ME-GI 和WARTSILA 2-S DF 两种机型有诸多不同。

对其进行比较能为一般货船的机型选择和管理提供参考。

# 一、工作原理

## 1、MAN ME-GI双燃料发动机

MAN ME-GI 柴油 - 天然气双燃料发动机采用缸内高压直喷式，即在发动机压缩冲程末期，从喷油器喷入少量且油量固定的点火油作为点火燃料，随后向缸内高压喷入天然气，使天然气依靠微量点火油着火释放的能量进行燃烧。

图1 MAN ME-GI缸内高压喷射示意图

## 2、WARTSILA2-S DF双燃料发动机

WARTSILA2-S DF柴油-天然气双燃料发动机采用缸内低压喷射式，即在活塞将扫气口关闭之后，以较低压力向缸内喷入天然气，使天然气和空气混合。

当活塞运动到上止点附近时向缸内喷射少量点火油，利用点火油的着火能量将缸内天然气和空气的混合气点燃，从而进行燃料的燃烧并完成做功过程。

图2 WARTSILA2-S DF缸内低压喷射示意图

# 二、点火油

## 1、点火油来源

ME-GI双燃料发动机在缸盖上安装2个或3个燃油喷射阀及燃气喷射阀。

燃油喷射阀的开启和关闭原理与普通ME柴油机相同，纯燃油模式时用作主喷油器，燃气模式时兼做点火喷油器使用。

WARTSILA2-S DF除主燃油喷油器外，每缸设有单独的点火油喷油器，点火油来自电动点火油泵，主要采用“微点火”和“预燃室”技术。

## 2、点火油量

ME-GI通过燃油喷射阀喷人点火油后，点火油压燃，然后才喷入高压天然气，根据燃油质量不同,按油耗率( g/kW.h )计算,点火油一般在5%~8%。

在100%负荷时，点火油约8g/kW.h,燃油和柴油都可作为点火油。

ME-GI发动机在30%~100%负荷时，需要的点火油量可以恒定。

在20%负荷以下时，燃气模式不能保证稳定运行，此时发动机必须切换到纯燃油模式，所以ME-GI点火油的功能类似于维持最低发火转速。

WARTSILA2-S DF发动机在100%功率时点火油约2g/kW.h, 30%功率时约8g/kW.h，即最大功率时点火油最小，约 1% 左右。

2-S DF 发动机采用“预燃室”技术，也许是“预燃室”空间较小，燃油喷入时，在“预燃室”较小的空间内油气浓度较大，发动机容易着火。

所以与ME-GI 相比，2-S DF 的点火油量较少。

# 三、燃气系统

## 1、燃气压力

ME-GI 是在压缩冲程末端喷入燃气，此时缸内压力很高，所以燃气喷射压力也很大，一般约为3×10⁷ Pa；

而 2-S DF 是压缩冲程中间行程喷入燃气，其时缸内气压不高，所以燃气喷射压力也较低，一般在 1.6×10⁶ Pa。

## 2、双壁管

图4 ME-GI燃气系统

ME-GI 和 2-S DF 发动机的燃气管都采用双壁式设计，内管输送高压燃气，外管起保护作用，以防止内管破裂时高压燃气喷出。

此外，内外管之间机械通风，内外管之间空间的换气能力约为 30 次 /小时，抽出的气体排放至安全区域。

由于采用了抽吸式通风，所以双壁管中间空间的压力低于机舱压力。

在通风管末端安装有 HC（碳氢）传感器，一旦探测到燃气泄漏，立刻给出报警信号，同时自动切换至燃油模式运行。

## 3、惰气系统

ME-GI 的燃气管路上安装了惰气系统。

在其每个工作循环中，供入每个缸的燃气可通过测量积聚器的压降检测出来。

通过这种系统，无论是燃气喷射阀咬死还是燃气阀堵塞，任何非正常的燃气流将会被立刻检测出来，燃气供应将会停止，燃气管线将被惰气清洗，同时发动机切换到纯燃油模式。

# 四、尾气排放

## 1、NOx排放

高温、富氧和高温持续时间是影响柴油机NO x 生成的主要因素。当反应的温度高于2200K时,温度每上升90K,氮氧化物NO x 的生成量会翻倍增加。

MAN 4T50ME-GI- X性能测试表明，与燃油模式相比，燃气模式下低负荷时NO x 减排较小，在75%负荷左右时NO x 减排最显著。

E3循环测试下，燃油模式和燃气模式的NO x 比排放值分别为15.7g/kW .h和11.9g/kW .h, NOx减排达24%，满足IMOTierII的NOx排放要求。

因此，MANME-GI必须配备EGR (废气再循环)或SCR (选择性催化还原)系统才能满足Tier II的NOx排放标准。

ME-GI属于狄塞尔循环，而2-S DF属于奥托.循环。

从图5中可以看出，狄塞尔循环中气缸内的最高燃烧温度明显高于奧托循环，高温持续时间也较长，因此当燃烧室氧气浓度相当时，狄塞尔循环中NO x 的生成量要高于奥托循环。

图5 狄塞尔循环和奥托循环的温度比较

WARTSILA宣称其2-SDF发动机在燃气模式下NO x 排放约2g/kW .h,满足Tier II排放标准。

因此，从尾气NO X 排放方面来说，WARTSILA2-S DF 要优于 MAN ME-GI，这也是 ME-GI 发动机采用狄塞尔循环而产生的弊端。

## 2、CO₂排放

发动机尾气中CO2含量主要与进机燃料和发动机负荷相关。

MAN 4T50ME-GI-X测试表明，与燃油模式相比，不同负荷燃气模式时CO₂减排量基本一致，约为23%。

WARTSILA2- SDF燃气模式时尾气中CO₂排放会减少25%。

因此，从CO₂排放及控制角度来看，两种机型差别很小。

## 3、SO x 排放

低速二冲程柴油机的燃油消耗率一般在160~195g/kW.h，假定两机型的燃油消耗率都为180g/kW .h,燃油含硫量为全球船用燃油平均含硫标准2.7%,根据点火油量大约可计算出尾气中SO x 含量。

MAN ME-GI的点火油量一般在5%~8%之间,最新宣传其点火油量可降低到3%，假如点火油量按5%计算，考虑尾气中SO x 主要是SO, SO₂ 分子量64，比S增加1倍，因此燃气模式下，尾气中SO x 含量约为180x 0.05 x 0.027 x 2=0.486g/kW.h。

WARTSILA2-S DF的点火油量一般在1%~5%，以平均3%点火油量计算，考虑到该机型最大的功率输出为85%，所以在上述同样的燃油含硫量和燃油消耗率下，尾气中SO x 含量约为180x0.03x0.027x 2/0.85=0.343 g/kW.h。

# 五、经济性

狄塞尔循环的热效率随压缩比的增大而增大，ME-GI 发动机与 ME 发动机压缩比相同，缸内平均有效压力几乎不变，因此燃气模式下具有与二冲程柴油机相同的热效率，均达到 50% 左右。

此外，天然气中甲烷值量对 ME-GI 发动机影响甚小，一般情况下，MAN ME-GI 发动机燃气模式时都能100% 功率输出。

WARTSILA2-S DF 的热效率约 47% 左右。

由于爆震 / 预点火的限制，WARTSILA2-S DF发动机最大输出功率较同尺寸柴油机小，在某些情况下，双燃料发动机需要增加1个气缸才能达到同尺寸柴油机的功率。

此外，WARTSILA2- -S DF双燃料发动机的实际输出功率受燃气中甲烷值的多少限制，燃气中甲烷值一般在70%~90%之间，所以WARTSILA2- -SDF的一般工作负荷小于85%CMCR(合同最大持续工况或额定最大持续工况)。

当燃气中甲烷值太低时，WARTSILA2- S DF发动机控制系统自动调整功率输出值至安全水平。

因此MAN ME-GI相较于WARTSILA2-S DF,热效率更高、经济性更好。

# 六、安全性

由于使用MAN ME和WARTSILA RT-felx机型的船舶实践已证明各自的安全性，因此本文仅从天然气对发动机安全性的影响进行讨论。

## 1、空燃比控制

由于甲烷与空气混合物的着火延迟时间要长于柴油，甲烷燃烧的火焰传播速度也低于柴油，所以柴油-天然气双燃料发动机易产生爆燃现象。

根据文献的阐述，WARTSILA 2-S DF的工作过程可分为2个阶段，即点燃和燃烧，可导致3种形式的爆燃:柴油爆燃，柴油燃烧后点燃天然气而产生的爆燃和主燃料自燃所产生的不稳定爆燃。

文献实验表明:爆燃取决于负荷和转速、燃烧温度、点火油与天然气的比例以及缸内紊流情况。

为减少爆燃发生，可采取以下途径:

(1)适当增加点火油量，减少天然气量，低负荷运转时效果特别明显;

(2)提高转速，加强燃烧室内气流运动，提高火焰传播速度，降低燃气终燃温度，减缓爆震;

(3)选取较大的空燃比，稀释燃气，冷却气缸，阻止爆震。

WARTSILA 2-SDF的空燃比较高，如50 DF发动机良好工况时可达2.2。

图7 WARTSILA 2-SDF发动机的空燃比控制

ME-GI双燃料发动机的工作循环采用狄塞尔循环，压缩行程只压缩新鲜空气,燃气不参与压缩过程，点火油压燃后,天然气高压喷入直接燃烧,因此无需空燃比控制，消除失火和爆燃问题，可采用与柴油机相当的压缩比。

由于ME-GI双燃料发动机消除爆燃问题，因此对燃气没有抗爆性能的要求，发动机对燃气的适应性好，可以使用低甲烷值的燃气，甚至可以使用液态石油气LPG作为燃料。

## 2、燃气进入扫气箱

MAN ME-GI发动机的燃油和天然气是在压缩行程的末端喷入，天然气喷入气缸内直接燃烧,因此天然气穿过活塞环到达扫气箱的危险较小;

但是WARTSILA 2-S DF是在压缩中间行程喷入天然气，因此压缩行程中天然气穿过活塞环到达扫气箱的危险较大。

基于上述理解，WARTSILA 2-SDF对活塞环的密封性要求较高，需要监测和安全保护措施。

WARTSILA 2-S DF安装燃气阀传感器检查燃气阀的动作，当燃气阀误动作时，切断燃气供应，发动机切换到纯燃油模式，但仍有可能因燃气喷射阀的阀面/阀座接触不良，致使WARTSILA2-S DF发动机在活塞越过燃气喷射阀后(如图2中右图:点火膨胀做功位置)燃气泄漏进入扫气箱。

# 七、结论

(1 ) MAN ME-GI与WARTSILA 2-S DF相比, 因缸内温度高，点火油量稍多等原因，致使MAN ME-GI发动机尾气中NO较多, SO x 也稍多，因此从尾气排放角度来看，MAN ME-GI劣于WARTSILA2-S DF。

(2) MAN ME-GI采用狄塞尔循环，WARTSILA2-SDF采用奥托循环，因此MANME-GI发动机热效率稍高，功率能额定输出;而WARTSILA2-S DF发动机热效率稍低，最大只有85%的功率输出，因此从经济性角度来看，MAN ME-GI优于WARTSILA2-S DF。

(3) WARTSILA2-S DF发动机要控制空燃比，防止爆燃，此外还存在燃气泄漏进入气箱的危险，因此从安全性角度来看，MAN ME-GI优于WARTSILA2-S DF。
