# 如何根据烟色判断柴油机故障

中医讲究“望、闻、问、切”，给柴油机看病同理。

今天小帮聊聊如何通过排气烟色诊断柴油机故障？

如果您时间宝贵，小帮给您提炼精华：

冒黑烟，燃烧不充分，查点火、燃油、配气系统并减小负荷；

冒蓝烟，烧机油，吊缸检查；

冒白烟，燃油有水，检查气缸垫、冷却系统。

如果您刚好有时间，可以继续往下看……

柴油机在正常工作温度下，其燃料在气缸内可以得到比较完全的燃烧，所排出的废气应该是无色透明的气体或者带点淡蓝色或淡灰色气体。所谓无色不是完全无色，不能向汽油机那样无色。船用柴油机燃料完全燃烧后，正常烟色一般为淡灰色，负荷略重时为深灰色。

柴油机排烟可分黑色烟、蓝色烟、白色烟、和黄黑色烟四种，它们是判断柴油机故障的依据之一。

具体分析如下：

## 一．排气冒黑色烟，也叫碳烟

这说明气缸内柴油燃烧不充分，一部分碳元素悬浮在废气中，出现黑烟现象。

主要特征：

起动困难，排黑色烟；

低速排烟严重，高速排烟减轻或消失；

中低速排烟正常，急加速排烟又严重；

各种转速工况下，连续或断续排烟，伴有异常的金属敲击声。

此时应重点检查：

（1）柴油机负荷过大，排气温度过高，应降低负荷。

（2）个别缸过载。应检查各缸排温，调整供油量。

（3）进、排气阀不密封，压缩压力不够，应研磨气阀，检查气阀密封性。

（4）供油太迟，应调整供油正时。

（5）喷油器雾化不良，检修或更换喷油器。

（6）喷油泵出油阀泄漏，研磨或更换出油阀。

（7）进气空气不足，检查增压系统。

影响生成黑色烟的主要原因：

1. 活塞环、气缸套磨损

气门、活塞环、气缸套磨损后，引起压缩压力不足，以及机油上窜燃烧室，使气缸在压缩形成结束时，混合气比例改变，使燃油在无氧条件下燃烧，燃烧过程容易产生积碳，排出的废气形成大量黑色烟雾。

2. 燃烧室形状改变

燃烧室形状因制造质量或长期磨损导致压缩余隙过大、过小，都会使燃烧室的形状和容积改变，从而使燃油燃烧条件变坏。

3. 喷油器雾化不良

喷油器不雾化、雾化不良或滴油，将使喷入气缸内的柴油颗粒大小分布不均匀，使燃料不能充分地与空气混合，也不能完全燃烧。此因素引起的冒黑烟现象在柴油机低转速运行时较为明显。

4. 供油量过大

供油量过大，使进入气缸内的油量增多，造成油多气少，燃油燃烧不完全。另外，工作负荷过重、燃油质量低劣、工作温度过低也会引起排气冒黑烟。

5. 供油提前角调整不当

供油提前角过大，燃油过早喷入燃烧室内，由于此时气缸内压力温度较低，燃料不能着火燃烧，当活塞上行，气缸内达到一定压力和温度时，可燃混合气燃烧。供油提前角过小，喷入气缸内的燃油过迟，最后喷油结束时活塞已经下行，气缸内的容积增大，压力减小，温度降低，一部分燃料来不及形成可燃混合气就被分离或排出，致使部分在排气管中随废气排出的燃油料受高温分解、燃烧，形成黑色烟随废气一同排出。

## 二．排气冒蓝色烟

冒蓝烟表示过量机油进入气缸，燃烧完受热蒸发成蓝色油气而未燃烧，随废气排出，即烧机油。

主要特征：

低温排烟严重，温度升高后排烟减轻或消失；中小负荷排烟轻微，大负荷高速时排烟严重；各种转速工况下断续或连续排烟。

排气冒蓝色烟，一般情况下是柴油机长期使用，慢慢开始烧机油引起的，随着蓝色烟雾的加重，烧机油越来越多，就应考虑大修了。有时燃油中混有水分，或有水分漏入燃烧室中，引起燃烧的改变，柴油机会冒浅蓝色烟。

此时应检查活塞油环是否损坏，各活塞环搭口是否成一条线，或油底壳油位是否过高，或气阀导管内孔磨损而漏油，或喷油器安装处密封不良而漏油，检查或更换新件。

影响其生成的主要因素：

1. 空气滤清器阻塞，使进入气缸内的气量减少，燃油混合气比例改变，造成油多气少，燃油燃烧不完全，也会引起排气冒蓝烟。

2. 油底壳内润滑油加入过多，曲轴高速转动使机油过量，曲轴高速转动使机油飞溅到气缸壁上，并窜入燃烧室中。

3. 长期低负荷（标定功率的40%以下）运转，活塞与缸套之间的间隙过大，使油底壳内润滑油容易窜入燃烧室，与气缸中的燃料混合气混合，燃烧不完全，引起排气冒蓝烟，同时伴有曲轴箱废气增多现象出现。

4. 活塞环卡住或磨损过多，弹性不足，安装时活塞环倒角方向装反，因各环口处于同一直线上而形成活塞环口，油环回油孔被堵塞，使大量机油上窜至燃烧室燃烧，润滑油燃烧后产生蓝色水气烟雾排出。

5. 在机体通向汽缸盖油道附近的气缸垫烧毁，活塞、气缸套磨损等状况将致使润滑油上窜至燃烧室，并与燃油混合气一同燃烧。

6. 气门和导管间隙过大，摇臂室内机油被大量吸入燃烧室内燃烧，形成蓝色烟。

## 三．排气管冒白色烟

表示柴油雾滴在气缸内未能燃烧，柴油或气缸中有水。

主要特征：

起动困难或起动排白烟或类似水蒸气的白色烟雾；低温低速时排烟严重；随着温度和转速的升高，排烟减轻或消失；各种转速工况下，持续或断续排白烟。

柴油机在寒冷天气运行时，柴油机温度低，排气管温度也低，有水蒸气排气凝结成水汽形成白色排烟，是正常的。若当柴油机温度正常，排气管温度也正常时，仍排白烟，说明柴油机工作不正常，可判断为柴油机故障。

影响其生成的主要因素：

1. 气缸套有裂纹或气缸垫损坏，随着冷却水温度和压力的升高，冷却水进入气缸。排气时形成水雾或水蒸汽。

2. 喷油器雾化不良，喷油压力过低，有滴油现象。在气缸中燃油混合不均匀，燃烧不完全，产生大量的未燃烃，排气时易形成水雾或水蒸汽。

3. 活塞、气缸套等磨损严重引起压缩压力不足，造成燃烧不完全。柴油机刚起动时，个别气缸内不燃烧（特别是冬天），未燃烧的燃油混合气随其它工作缸的废气排出形成水气烟雾。

应检查气缸盖底面、气缸套有无裂纹和空气冷却器是否漏水。

## 四．排气冒黄黑色烟

主要特征：

起动运转初期中速阶段排黄黑色烟；温度升高或负荷增大后，排黄黑色烟现象逐渐减轻或消失，表现为怠速时易熄火，机体抖动；同时，进气管“呛气”，排气管放炮，柴油机动力不足，起动困难。

排气冒黄黑色烟，柴油机还算工作正常，但烟雾颜色加重呈灰色或黑色就不正常了。当取下进气空气滤器后，排气烟色由深变浅甚至变为无色时，就是空气滤清器堵塞了。
