# 一、机油温度过高有什么危害呢？

大家都知道，机油在柴油机中起着润滑、冷却、净化、防锈的作用，如果温度过高，将对柴油机产生严重危害。

1. 机油温度过高会使机油粘度下降，不能保证轴承等运动部件所需的正常油膜厚度，承载能力下降；
2. 易使机油烧损，加速油的氧化变质，生成沥青胶状物堵塞滤清器，缩短换油周期；
3. 柴油机机件产生的热量不能被及时带走，使零件强度大大降低，甚至造成零件破坏；
4. 零件受热膨胀变形，破坏了零件之间的正常配合间隙，造成零件损坏；
5. 润滑条件恶化，加速柴油机的早期磨损，大大缩短了使用寿命。

# 二、机油温度过高产生的原因

1. 机油油量不足或超量，都会导致机油温度过高

柴油机的润滑是通过机油的循环来实现的。（如上图所示）

机油在带走机件磨损产生热量的同时，也带走摩擦所剥落的机械杂质。

机油在形成润滑油膜时，不可避免地会泄露，所以必须要有足够的量补充进来，完成持续润滑。

因此要经常观察油尺有无缺油。

机油油量不足，各摩擦表面的液体摩擦转变为边界摩擦，甚至干摩擦，摩擦的热量急剧增多，造成机油温度升高。

机油油量不足又表现在以下方面：

（1）油底壳本身的机油量不够；
（2）机油泵故障，泵油量小，散热不良，导致油温升高；

机油泵是柴油机润滑系统的动力源泉，

机油泵齿轮的端面间隙或齿侧间隙若磨损超限，出油量便明显下降。

另外，机油泵限压阀开启压力过低，

或调整弹簧折断、机油泵滤网堵塞，

也会使机油泵的出油量下降。

如果机油加的过多，

机油在曲轴箱不停的搅动和激溅，

也会造成机油温度升高。

2. 柴油机冷却水温过高

（老铁们可以点击阅读上一篇推文。）

3. 机油冷却器结垢较多或污物堵塞，使机油散热不良，导致油温过高。

当机油冷却器结垢较多或管路堵塞时，

流经冷却器的水量减少，

不能及时带走机油的热量，

从而使得机油温度过高。

所以要定期拆检清洗机油冷却器，

保证良好的冷却可靠性。

4. 机油滤清器堵塞或机油杂质过多，使油温过高

机油滤清器的作用是将经过机油冷却器冷却后的机油通过滤清，向系统足量输送清洁的机油。

机器“三分修，七分养”！

如果滤清器堵塞或长期不保养，

那你能看到的是机油温度高，看不到的是机器内部运动件增加了很多“研磨料”，出故障是迟早的事儿。

滑油系统主要机构

5. 活塞环窜气严重，直接加热机油

活塞环按功能可分为气环和油环。

气环的作用是密封气缸，

防止燃气窜入曲轴箱，

并传送活塞顶部所吸收的热量；

油环的作用是刮下汽缸壁上过多的机油，

防止机油窜入燃烧室。

因此我们这里讲的窜气后对机油加热的活塞环主要指气环。

若气环自身弹力消失，即环周与缸壁间出现间隙，高温的燃气将直接窜入曲轴箱，从而使机油温度迅速升高。

6. 轴瓦配合间隙过大或过小

轴瓦配合间隙过小，

根本不可能形成完整的油膜，

也就是说运动机件不能形成液体摩擦，

摩擦产生的热量会直接导致机油温度过高；

若轴瓦配合间隙过大，

机油卸油量增多，

使得油膜失去稳定性和承载能力，

摩擦类型改为了边界摩擦或半液体摩擦，

也会造成机油温度过高。

7. 柴油机负荷过重

柴油机的负荷越大，

则需要油膜具有更大的承载能力，

否则机油就不可能进入压力油膜。

最终油膜遭到破坏，

导致机油因非液体摩擦而温度过高。

# 三、处理措施

1. 合理选用机油牌号；

（“船机帮”会陆续推送关于油品知识的推文，敬请关注！）

2. 保证机油量在油尺上下刻度之间；

3. 定期拆检机油泵，清洗机油冷却器、机油滤清器；密切注意机油滤清器进出口油压的变化，及时更换滤芯；

4. 定期检查活塞环与气缸密封性，防止活塞环窜气；

5. 合理使用柴油机，避免超负荷；

6. 找正规公司或经验丰富的技师做大保养。机件内部配合间隙都有严格的要求，这些说明书里都有，各位也不用掌握。咱们把日常维护保养的基础性工作做到位即可。

7. 经常查看是否缺冷却水，避免冷却水空间或机油冷却器堵塞，机油冷却器热交换效率低；

8. 冷却水泵故障；

9. 温度调节器故障；

10. 仪表故障。
