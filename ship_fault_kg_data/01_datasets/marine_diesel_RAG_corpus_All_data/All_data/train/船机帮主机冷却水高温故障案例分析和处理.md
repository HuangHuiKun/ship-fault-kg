# 导读

冷却水高温是船舶主机常见的一种故障现象。

当船舶主机出现冷却水高温时，如不能及时找到原因，排除故障，将会对主机造成很大损害，甚至危及船舶安全。

本文分析某轮主机冷却水高温原因系统，找到故障并排除。

# 一、故障现象

某轮主机采用瓦锡兰公司的 W9L32 型柴油机，双机双桨。

该船舶在主机厂修结束试航时，左主机在加负荷过程中，高温冷却水压力出现波动，温度迅速升高并发出报警，随后主机自动降负荷、降速。

经多次试验观察发现，故障现象多发生在 70%负荷以上。

经查主机说明书，冷却水相关保护设定值：

正常值（91～96）℃，报警值 105 ℃，降负荷、降速值 110 ℃。

# 二、高温水冷却系统工作原理

柴油机高温水泵从冷却器高温部分和膨胀水箱补水管道中吸入冷却水泵入柴油机高温水系统。

冷却水在流经并冷却包括缸盖、缸套、排烟管、增压器后温度升高，升高温度后的热水经由柴油机排水总管、高温水调控阀进入高温淡水冷却器。

# 三、故障原因分析

根据本次主机维修项目，并结合故障现象，引起高温水温度升高的原因主要有 4 种。

（1）高温水泵故障。

水泵效率下降或是吸入管路密封不良，造成高温冷却系统中的冷却水无法实现正常的循环，导致冷却水温度上升发出高温报警。

（2）冷却器。

未及时清洁高温水冷却器散热片表面和冷却水通道，致使冷却器脏污或堵塞，导致冷却效果下降。

这也是实践当中最为常见的导致冷却水高温报警的原因。

（3）调温阀故障。

①调温阀感温原件损坏，无法测量到水温，从而无法及时对冷却水的进行控制调节，导致高温报警。

②调温阀卡死在某一位置，致使冷却水无法回流到冷却器，导致高温报警。

（4）高温水冷却缸体时，水道密封不好，导致主机在大负荷时，高温高压气体串入冷却水系统，导致水温温升过快并使冷却水泵效率下降，冷却水压力波动，产生高温报警。

# 四、故障解决

在确认高温水泵、调温阀、冷却器无故障后，根据压力波动等故障现象，可以确定故障原因为冷却水通道的密封垫片损坏，且为与高温高压燃烧室气体接触的部位，初步断定为缸头垫片或排烟管垫片损坏。

在对这两处垫片进行拆卸检查时发现，缸头螺栓预紧力基本都未达到说明书要求（400±20 Nm），其中以第三缸和第六缸最低。

至此，可以确定故障为缸头螺栓预紧力不足。

在主机大负荷时，随着供油量加大，燃烧室温度和压力逐渐升高，当达到一定程度时，高温高压气体通过缸头垫片进入高温水系统，导致高温水泵压力波动、流量不足，致使水温迅速上升，报警、减速降负荷。

考虑到上次在安装缸头时，采用电动液压装置，液压油压力上升速度快，存在误差。

此次在更换所有损坏缸头垫片后，重新安装缸头时，使用手动液压装置，并多次对预紧力进行了复核。

装复后重新试航，主机90%负荷航行 4 h，高温水压力稳定，水温始终处于允许范围内，无发生报警现象，故障解决。

# 五、结束语

缸头螺栓都是用专用液压工具进行安装，出现问题概率较小，这往往在出现类似故障时障碍了轮机员的分析思路，延长了解决问题的时间，增加了工作量。

为此，在主机大修过程中，要求工作人员严格按照说明书要求，使用船舶配备的专用工具进行拆装、并做好测量和记录，轮机长要做好监督，保证修理工作安全顺利完成。
