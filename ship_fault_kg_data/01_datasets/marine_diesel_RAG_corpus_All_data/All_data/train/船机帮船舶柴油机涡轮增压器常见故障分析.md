# 导读

目前，船舶柴油机广泛采用废气涡轮增压器，利用柴油机排出的废气能量驱动涡轮高速旋转，带动与涡轮同轴的压气机叶轮高速旋转，压气机将空气压入发动机的气缸，增加了发动机的充气量，可供更多的燃油完全燃烧，从而提高了柴油机的功率，还充分利用了柴油机的废气能量，提高了柴油机的经济性。

涡轮增压器安装在柴油机的进排气支管上，处于高温高压和高速运转的工作状况，工作环境恶劣，易发生故障。

涡轮增压器发生故障后，会造成柴油机功率下降、冒黑烟、耗油量增多、噪声大等现象。

因此，对涡轮增压器常见故障进行分析，并由此探索排除故障的方法是十分必要的。

# 一 柴油机增压器的喘振

涡轮增压器工作时，当压气机的排出压力和流量减少，其工作点落在压气机的喘振区时，压气机排出压力忽高忽低，空气流量忽正忽负，引起机器强烈振动，并发出沉重的喘息声或吼叫声。

发生喘振的原因主要有：

## 1. 增压系统流道阻塞

流道阻塞是引起增压器喘振的常见原因，特别是外来杂质，如油气、粉尘等脏物进入进气管道，排气管道积碳，进排气管道变形等，使流道阻力增大，压气机流量减小，背压升高引起喘振。

此外，柴油机长期燃烧不良，涡轮喷嘴、涡轮叶片、轮盘及气封间隙两旁壁面等地方积聚大量未燃尽碳粒的油垢，增压器停车后，油垢会冷却凝固，加大增压器运转时的机械阻力，使涡轮性能下降，最后使增压压力下降而导致喘振。

在日常管理中，应周期性清除气缸进气口和排气口的积炭，并经常对空气滤清器、压气机进气流道、空气冷却器、涡轮喷嘴环和叶轮等进行清洁。

当增压器流道阻塞严重时，须将增压器拆开进行清洗。

而在运行时对压气机和涡轮进行清洗，既可以减少增压器的拆装次数，又可避免此类原因引起的喘振。

## 2. 增压器与柴油机运行匹配失调

柴油机与增压器匹配良好是指：柴油机达到预定的增压指标，增压器在柴油机全部工作范围内能稳定地运行，既不喘振也不超速，并尽可能在高效区工作。

柴油机本身的某些故障或者船舶满载、顶风、大风大浪航行，以及轮机员操作不当等，都可能造成柴油机和增压器匹配不良，引起喘振。

柴油机喷油系统出现故障，会使柴油机燃料燃烧不良，引起严重的后燃；柴油机活塞环断裂或粘着，气阀烧损，气阀间隙过小，都可能导致气缸漏气，热负荷增大，排烟温度升高。

若柴油机供油量不变，因有功功率减小，柴油机转速下降，而排烟温度升高，引起废气能量增加，增压器转速升高，供气量增多，从而破坏了柴油机与增压器的正常匹配关系，导致压气机处于高背压小流量的工作状态，容易发生喘振。

此种情况，排除了柴油机喷油系统故障后，喘振便会消失。

船舶满载、顶风航行时，主机负荷大，柴油机处于高负荷、低转速运行状态，柴油机燃油系统供油量增加，后燃引起废气能量增加，增压器转速升高，而气缸耗气量却因柴油机转速的降低而减少，这同样易引起增压器与柴油机匹配不佳而出现喘振。

针对由此原因引起的喘振，只要减小柴油机油门即可。

## 3. 柴油机各缸负荷严重不均匀

对于多台增压器并联向进气总管供气的柴油机（例如当两组增压器共用一根进气管时），如果其中一组中某缸熄火或柴油机故障导致各缸负荷严重失衡时，会使柴油机负荷增大、气缸喷油量增多，导致废气能量增多，而另一组增压器废气能量减小，涡轮机功率减小，转速降低。

这种情况一方面造成进气管内压力脉冲波动，另一方面易造成压气机背压升高，使流量减小，因而产生喘振现象。

消除方法：排除柴油机故障，使柴油机每一组气缸的供油量趋于均匀。

## 4. 柴油机负荷骤变

如船舶偶遇到大风浪时，螺旋浆出水，柴油机负荷聚然减少，转速升高，各缸供油大量减少，使供给增压器的废气量减少，增压器转速下降，从而使压气机空气流量减少，达到一定程序时便会发生喘振。

防止办法：避免飞车现象的发生。

# 二 轴承烧损

轴承在增压器中很重要，不仅保证转子安全可靠地运行，还保证转子的准确固定。

增压器是在高温、高速和轻负荷条件下工作的，漏油、油量过少或短时间断油均会造成轴承甚至整台增压器损毁的重大事故。

船舶柴油机在长期使用中，由于滑油沉积的脏污在滑油观察镜中形成污痕，造成虚假滑油油位；工作中易因视角上的失误导致增压器滑油量不足、滑油压力过低甚至断油，从而造成轴承烧损。

轴承烧损时，出现声音异常，增压器转速急速下降而失去工作能力。

所以在航行值班时，如发现增压器转速急剧下降、运转声音异常，应及时对增压器停车检查，否则可造成严重事故。

若处理及时，仅轴承烧坏，可更换轴承。

若转子烧损严重无法修复，又处于特殊海况不允许停车时，可采取应急措施把损坏的增压器停掉，让柴油机降低负荷，以较低转速继续运行。

平时维护管理，特别是值班巡回检查时，应注意检查轴承润滑油的压力温度，通过观察镜检查润滑油的流动情况，不允许流量减少和断油，当油量不足时应及时补充。

轴封损坏是轴承箱润滑油快速减少最常见的故障现象，在增压器运行中应经常用螺丝刀或其它专用工具倾听增压器中的声响，以使轴承缺油或轴承损坏能及时被发现而避免造成大的损失。

# 三 增压器压力下降或升高

当增压器压力降低时，柴油机进气量减少，功率大大下降，耗油量增加，冒黑烟，排烟温度升高。

增压压力升高会给柴油机的运行带来不利影响，如柴油机压缩终点压力过高，最高燃烧压力相应升高，柴油机机械负荷增大等。

造成增压压力升高或下降的可能原因有：

## 1. 压气机空气滤器、叶轮、扩压器及涡轮喷嘴因长期使用而脏污

增压器运行时，压气机由机舱吸入空气。机舱空气中油雾和灰尘含量较高，易粘附在叶轮和扩压器上。

柴油机在负荷变化时，会因燃油燃烧不佳、柴油机燃用劣质油或燃油喷射系统工作状况不良而使柴油机排气富含油雾和碳粒，造成涡轮喷嘴环及叶轮积碳而使柴油机积炭、脏污。

其流道脏污会加大流动阻力，降低效率，导致增压压力下降。

因此，要定期对增压器拆开清洗，清除涡轮喷嘴、叶轮及空气滤器上的积炭、脏污，当增压器运行时，要经常对其旋转部件进行运转中清洗，以确保增压器处于较好的工作状态。

## 2. 柴油机供油系统故障

常见的有喷油过迟、燃料后燃现象严重，使废气能量增加，气缸排气温度升高。

这将产生两方面的影响：一方面涡轮进口的能量增大，使增压器转速上升，从而导致增压压力随涡轮转速上升而升高；另一方面涡轮的流量减少，使压气机的运行点向喘振线移动，这会使扫气压力上升，同时导致排气温度过高，甚至使排气管和涡轮管发红，对涡轮机极为不利。

所以使用中应及时排除故障，调整喷油定时，减少甚至消除后燃现象，这样既节约油耗，又能保护涡轮机。

但如果柴油机喷油提前角过大，排气阀开启提前角减少，会使柴油机功率降低，产生废气能量减少，增压器转速下降。

故应对柴油机进行正时调整，使增压器增压压力恢复正常。

## 3. 气阀（口）漏气或开启过早

柴油机排气过早使涡轮进口的压力和温度都升高，会导致通向涡轮机的废气能量增加，涡轮机转速升高，增压压力上升。

对于这种情况，正确的调整方法是推迟柴油机排气正时，使燃气在气缸中多作一些功，降低排气的压力和温度，从而降低增压器的转速和增压压力。

柴油机长时间运行后，由于腐蚀、磨损或是机械故障，会造成柴油机排气阀密封不良，燃气由气缸经气阀的间隙漏出。

由于燃气的压力和温度都较高，实际上提高了涡轮进口的气体能量，所以也会使增压压力上升。

主要预防措施：消除排气阀漏气，避免过早开启排气阀。

## 4. 废气涡轮喷嘴环变形

废气涡轮喷嘴环变形使通流面积增大，涡轮前排气管膨胀接头漏气，导致废气能量不足，增压器转速明显下降。

可根据故障现象，查明原因并排除故障。

## 5. 增压压力调节阀失灵

增压压力调节阀失灵，废气旁通阀不能开启或开度不够，致使增压压力上升。

应及时对压力调节阀进行检修，使废气旁通阀保证有足够的开度，能有效地将过剩的废气旁通。

# 四 轴承箱中润滑油漏失及超温

增压器经长期运行，涡轮机密封衬套间隙增大，机端轴封损坏致使排气漏入轴承箱，造成轴承箱压力过高，箱盖螺栓松动而润滑油漏失。

润滑油漏失造成滑油量减小，一方面增大轴承的磨擦，导致轴承发热，另一方面，又会使散热不佳，均导致增压器超温。

因此，机舱值班人员无论是轮机员还是机工，在机舱巡回检查时，均应将增压器润滑油位、油温及冷却水温度作为巡检的重要内容。

# 结束语

涡轮增压器是船舶主动力装置的关键部件，涡轮增压器工作状况良好，可使柴油机大大提高输出功率，降低燃油消耗，同时也可减少废气中有害、有毒气体的含量。

因此，轮机日常维护管理人员，应重视涡轮增压器的正确使用及日常维护、保养工作，以保证柴油机处于最佳工作状态。
