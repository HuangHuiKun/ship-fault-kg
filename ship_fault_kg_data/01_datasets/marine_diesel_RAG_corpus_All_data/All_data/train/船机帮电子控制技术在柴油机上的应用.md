# 导读

现在对柴油机的动力性能、经济性能、控制废气排放和噪声污染的要求越来越高。

随着计算机技术、传感器技术及信息技术的迅速发展，使电子产品的可靠性、成本、体积等各方面都能满足柴油机进行电子控制的要求。

因此电子控制技术应用于柴油机的调节系统正好可以实现多功能的自动调节，从而保证柴油机动力性、燃料使用经济性、可靠性和操作方便性等性能充分发挥，电控技术在柴油机上的应用将越来越广泛。

经过多年的研究和新技术应用，柴油机的现状已与以往大不相同。

现代先进的柴油机一般采用电控喷射、高压共轨、涡轮增压中冷等技术，在重量、噪音、烟度等方面已取得重大突破。

随着国际上日益严格的排放控制标准的颁布与实施，柴油机面临着严峻的挑战，解决的办法之一是采用电子控制燃油喷射的技术。

现在，柴油机电子控制技术在发达国家的应用率已达到 60%以上。

# 一、电控柴油机的优点

总的说来，优点在于增强可靠性、提高了经济性降低了污染性，确保了安全性、提高了可控性等。

电控柴油机主要具有以下优点：

1. 具有发动机的自动保护功能。当专用传感器向电子控制单元（ECU）指示系统超过正常安全参数运转时，ECU将向操作人员发出警报信号，并减小发动机的功率,甚至使发动机停止运转。
2. 具有发动机故障诊断功能。ECU 对发动机所有传感器、喷油器、连接器和线路进行连续监测，在传感器及电路发生故障时，ECU 将储存诊断故障码。在维修人员诊断和排除发动机故障时，故障码对维修人员确定故障产生的工况和可能部位提供帮助，从而使故障诊断和排除更为快捷有效。
3. 减少了发动机的工作维护量。由于燃油喷射得到了控制，从而改善了发动机燃烧、运行等。
4. 改进了发动机的调速控制。由电控调速器取代了机械调速器中的旋转飞块装置，使转速控制更加精确，电子控制可以通过程序对运行过程中的正常转速降进行设定。
5. 改善了发动机的燃油等经济性。选定发动机工况后，ECU 将按程序对发动机的运转工况进行监测，特别是对喷油过程有重要影响的温度、负载、转速和增压压力等实时数据采集，实时监控发动机运行，有效的改善了燃油经济性，并有效的延长了机械使用寿命。
6. 降低发动机的排气烟度。ECU 能根据负载需要、机油温度和涡轮增压压力精确地控制喷油定时和喷油量，使发动机在稳态及瞬态工况下的烟度能够达到排放法规的要求。
7. 配合多气门、及中冷等技术有效地提高了发动机的效率。有效地降低了柴油机较高的噪声。
8. 减少了发动机的排气污染物。电控系统易操作，维修技术人员可以通过手持式诊断器、台式计算机或便携式计算机向 ECU 输入有关数据，使发动机处于最佳状态。

# 二、电控柴油机的概述

现在世界制造商生产的柴油机，其电控柴油机构造虽有不同，但原理基本相同。

电控柴油机的发动机，实质上就是将计算机优秀的控制能力运用于发动机的运行控制。

电控柴油机主要是燃油喷射系统依据各传感器信号，通过专用计算机控制柴油机运行。

电控最主要的基础知识就是数字电路知识。同时吸收大量的现代科学的方面的知识。

目前，各型电控燃油喷射系统的由三个基本组成部分，如图1所示，分解为四个工作过程，形成闭环控制回路。

图1 电控柴油机（ECU）控制基本原理图

1. 输入：传感器和开关。
2. 控制：ECU（对输入信号进行分析判断并输出控制信号）。
3. 执行：电控喷油器。
4. 反馈：对执行情况进行检查。实质就是再将传感器信号再输入。

ECU 由存储器、微处理器（系统大脑）和按照要求控制执行器，执行器按照计算机输出信号驱动电路执行控制任务。

ECU 接受并处理来自各传感器及开关的数据和信息，将各传感器返回的电压与 ECU 程序数据库中所存储的各开关及传感器的特定数据进行分析、比较，并做出判断，发出控制信号，控制信号经驱动电路控制喷油等动作。

执行器的形式有：电控单体式喷油器，机械执行器，液压执行器，电液执行器，电控单体式喷油泵，液压驱动电控单体式喷油器，电控喷油泵—高压油管—喷油嘴系统和电控分配泵系统等。

存储器的基本类型如图 2 所示。

ROM（只读存储器）、RAM（随机存储器）和 PROM（可编程只读存储器）芯片都与微处理器（MP）相连，RAM 和 PROM 可以被 MP 读入和读出，但 ROM 只能被 MP 读出。

# 三、发动机传感器

传感器可以从被监测发动机接受温度、转速或压力信号等，传感器再将所接受的信号转换为电信号，并传送给信号处理器，信号处理器将接收到的信号放大，既可以传输给一个模拟式数字式显示器，也可以用于驱动发动机上的特定执行器，信号处理可以利用模拟电路或数字电路来完成。

# 四、发动机保护系统

所有的柴油机对都提供有发动机保护系统，一般有三个保护等级，视觉及听觉报警系统、降功率系统和发动机停机系统。

通常情况下，大多数发动机都用下列传感器启动保护功能，具体的参数向触发温度或触发压力值由厂商在程序中设定好。

1. 发动机冷却液温度和压力；
2. 发动机冷却液液位；
3. 发动机机油温度；
4. 发动机机油压力；
5. 气管温度；
6. 发动机超速。

# 五、ECU

电子控制单元（ECU）是电控系统的的大脑，它连续不断地从动机的各个传感器接受信号，得到发动机工作状态，并利用内部存储的各种数据，经过逻辑运算，输出控制信号给执行器，通过执行器控制发动机的工作。

ECU与外部都有一些连接线，一般都有以下几种线束。

1. ECU 与所有传感器和开关的连接线（输入线束）。
2. 与执行机构连接的线束（输出线束）。
3. 与电源供给 ECU 的电源线（供电线束）。
4. 与机组显示屏连接线束（显示线束）。
5. 与侦测故障相连的线束（通常为预留线束接口）。（图 3）

# 六、几个所接触的电控系统在柴油机中的应用

## 1. PCOT（曲柄销油温测量系统）

PCOT 是为检测曲柄销处流出滑油的温度而设计的，它能够预防柴油机的主要零部件（如：曲轴，连杆等）故障的发生。

传感器在柴油机曲柄处安装，信号经过转换，经PLC 也就相当 ECU 设定的程序处理，输出信号到系统安全系统，有停车、报警、系统故障等，有显示设备也可以与计算机通讯。

## 2. 油雾探测器

油雾探测器主要是考虑：如果油雾在早期被探测到，大规模的轴承和滑面破坏将能够被预防。昂贵的修理和停机费用能够很大程度上被避免，如使用的 MSS、MD-9M、CX-9M、MK6、SiCOMS-Mark X、VN115/87 油雾探测器等。

这些探测器原理基本相同，监测都是靠一个或多个光测量部件实现，两个关键步骤分别是：

传输：光源（LED）发出的光经过测量盒被一个半导体接收二极管测量。一旦油雾生成，到达接收器的光会因油滴的反射和折射而减弱，测量盒里的油雾浓度高低将由到达接收器的光亮度计算出来。

接收：LED 发出的光进入测量盒遇到油雾反射，然后被一个光学半导体测量。测量盒里的油雾浓度程度将取决与油雾反射光。

传感器检测到的信号输入探测器经 ECU 处理，当不符合程序本身的值时处理的信号输出给控制台，控制台发出指令给柴油机，形成一个闭环控制电子系统，将停车或者降负荷。

## 3. 发电机控制箱

MAN16/24，MAN21/31 发电机组的电子控制比较高，机组自带一个控制箱，所有的检测传感器信号都传输到控制箱里，然后经过 ECU 设定好的程序处理，控制柴油机以满足发电机的各种特性。

该 ECU 所有信号经过 RS485 或RS422 可通信到控制台，ECU 本身也有数据接口可和计算机连接修改里面的参数。

## 4. L+VMAN32/40 所配的 SaCoSone 控制系统

该系统由控制系统，安全系统，报警预处理系统组成；

接口柜：是 SaCoSone 系统与外部控制系统的接口，并装有网关模块，同时是电源分配系统给柴油机电气设备提供电源的主要连接点；

辅助柜：给柴油机电气设备及 SaCoSone提供电源，并集成了 VIT 的控制，EM300 调速器的控制，气缸润滑泵和温控阀的控制等，此控制集成化比较高。

## 5. PA 机 STC 控制系统

STC 控制系统主要由两大部件组成：STC 控制仪和STC 碟阀检测、机旁手动、电磁阀箱组成。

柴油机上的增压器转速信号，主机转速信号，增压压力信号到达控制仪，根据这些条件判断输出信号进而控制柴油机上的 4 个碟阀从而控制 B 列增压器的投入运行，使柴油机满足各工况达到使用要求。

柴油机正在经历以柴油机电控化为核心的第 3 次技术飞跃，控制精度将越来越好，未来的柴油机将在 ECU 技术、电控高压共轨技术、电控增压中冷技术发展。

随着电子技术，传感器技术、光纤技术、计算机技术、信息处理技术不断发展，这些综合技术在柴油机上的使用将越来越广泛，使柴油机的可控性、可操作性、稳定性、安全性、可靠性将大大增强。
