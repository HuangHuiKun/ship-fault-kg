# 导读

某轮2号柴油副机,干式曲轴箱,与不少老龄船柴油副机一样,曲轴输出端长期漏油(俗称飞轮甩油)。

该副机飞轮甩油的特点是:

- 空载不甩油,负荷越高甩油越严重;
- 滤器易脏堵,滑油压力偏高;
- 曲轴箱透气管透气量较大,透气温度偏高。

飞轮端甩油;原因甚多,必须花气力才能查出原因彻底解决。

因不影响柴油机正常运行,不少轮机员不重视,认为是“小问题”。

然而“小问题”可能是柴油机某缺陷的征兆,其它影响也不小:

- 浪费滑油;
- 破坏副机表面清洁,浪费大量人力物力;
- 副机飞轮端积油,火灾隐患;
- 成为港口国检查的缺陷,甚至被滯留。

因此,必须消除副机飞轮甩油。

# 一、飞轮甩油原因分析

副机飞轮甩油，不外乎副机摇臂油从缸头泄漏滴带飞轮上甩出、曲轴箱飞轮端密封失效、曲轴箱压力过高等三种原因,从简单到复杂,逐一排除。

## (1)副机摇臂油从缸头泄漏滴至飞轮上甩出

虽然该副机飞轮甩油特点有“空载不甩油，负荷越高甩油越严重”,完全可以排除摇臂油从缸头泄漏滴至飞轮上甩出的可能,但为了解除疑虑还是进一步验证,

方法是:

- 清洁所有缸头特别是靠近飞轮端的第6缸残余滑油,用布围挡机架,观察是否还有甩油;
- 短时间停止副机摇臂油供应,观察是否甩油。

结果证实,的确不是副机摇臂油滴至飞轮上甩出。

## (2)飞轮端曲轴密封失效

船舶密封主要有接触式与非接触式两种形式。

该副机飞轮端属于刚性非接触间隙密封,工作原理是:

- 曲轴颈与密封档板间隙小,减少漏泄;
- 曲轴颈与密封档板之间有刚性迷宫式密封圈,截留曲轴颈上的滑油;
- 导油槽和泄油管,泄放截留的滑油至曲轴箱底。

飞轮端曲轴密封失效，只有曲轴颈与密封圈间隙过大、柔性密封圈损坏、泄油管阻塞等三种可能。

### ①曲轴颈与密封档板间隙过大

原因可能有,曲轴颈磨损导致直径减小，曲轴颈跳动超标。

为此，检查曲轴颈,测量跳动量,均正常。

### ②密封圈损坏

间隙式密封圈属非接触式密封,一般不易损坏,但也不能完全排除这种可能。

- 拆下密封圈检查,未见异常;
- 更换新备件,清洁密封环槽。

重新装复,飞轮依旧甩油。

### ③曲轴箱飞轮端密封的回油管脏堵

检查方法:

- 拆下检查,见回油管畅通;
- 压缩空气吹通连接回油管的机体回油孔;
- 在回油孔注入滑油,泄油通畅;
- 拆除问油管的情况下副机重载运行，见飞轮仍然甩油。

至此排除了曲轴密封失效导致故障的可能。

## (3)曲轴箱压力过高

曲轴箱压力过高，原因可能有曲轴箱透气管堵塞和气缸窜气。

### ①曲轴箱透气管堵塞

拆下曲轴箱透气管,用压缩空气吹通试验,正常。

启动副机重载运行，飞轮甩油依旧,排除了曲轴箱透气管堵塞导致故障的可能。

### ②活塞密封不良窜气

曲轴箱透气管没有堵塞，“曲轴箱透气管透气量较大,透气温度偏高"的原因肯定是活寒密封不良窜气。

按常规,运转6000小时吊缸保养,记录表明距上一次吊缸已经有5600多小时，因此决定吊缸检查:

- 活塞环换新;
- 缸套测量,最大磨损量0.25mm,并未超出允许范围(直径260mm,磨损极限0.45mm),也换新以排除疑点:
- 活塞头目视检查,未见缺陷。

最方便的验证的方法，是测量副机空载各缸压缩压力,明显偏小的缸即为窜气的缸。

测量结果,第6缸压编压力3.0 MPa,其它5缸均在3.4 MPa左右，初步判定是第6缸窜气。

为进一步确定:

- 2号副机轻载,第6缸停油,飞轮仍然甩油,但减轻了不少。
- 盘车至第6缸发火位置，从该缸示功考克向缸内吹压缩空气,从曲轴箱检查见窜气明显,漏气严重。

由此可以肯定,飞轮甩油,是第6缸密封不良,曲轴箱压力升高造成的。

# 三、第6缸活塞窜气原因分析

解体第6缸,发现缸套有划痕和金属剥落的斑点，活塞顶部一半干一半湿却未引起足够重视。

换新缸套和活塞环，组装缸头及附件并水压试验后,再次从示功考克向缸内吹压缩空气,从曲轴箱检查发现活塞头冷却滑油的回油孔向曲轴箱窜气。

只能出再次解体第6缸，吊出活塞,用压缩空气向活塞冷却油的回油孔吹气,终于发现原因,活塞顶部与活塞头镶套处有一裂缝,空气就是从这里漏泄的。

镶套处本身就是一道接缝，先前目视检查活塞头表面,根本无法判断缺陷所在。

这时才回想起“活塞顶部一半千一半湿”,就是因为活塞头有裂缝,气缸压力高时燃气向曲轴箱窜气，气缸压力低时滑油也会通过裂缝向燃烧室泄漏，造成活塞顶部部分湿润。

更换新活塞,装复试车,飞轮不再甩油了!消除窜气,滑油压力也从0.6 MPa降至0.49 MPa。

# 四、故障机理

## (1)“空载不甩油，负荷越高甩油越严重”,是因为负荷越高,第6缸窜气越严重。

## (2)“曲轴箱透气管透气量较大，透气温度偏高”，也是因为气缸窜气。

## (3)“滤器易脏堵,滑油压力偏高”:

- 燃气通过活塞下窜至曲轴箱，滑油循环柜压力升高,滑油泵的吸口压力和排出压力升高;
- 下窜的燃气污染滑油,致滑油黏度升高,滑油压力偏高。

# 五、关于分析方法的反思

这次排除副机飞轮甩油故障,采用的是排除法,列出全部可能的故障原因,逐项检查或试验,找出确切的故障原因。

由于需要排除的可能因素很多，做了不少检查和试验,工作量很大,费时费力。

事后想想，曲轴飞轮端轴封结构简单，飞轮甩油“小事”一桩,却花费了那么多时间,有必要反思分析故障的方法。

## (1)针对性的检查和试验,节省人力物力

如果,列出全部可能的故障原因后:

- 细致观察获得故障的全部现象，例如本故障的“空载不甩油，负荷越高甩油越严重”、“曲轴箱透气管透气量较大,透气温度偏高”、“滑油油质较差,滤器易脏堵,滑油压力偏高”;
- 分析故障每一现象的实质，以及各故障现象之间的内在联系,就可以基本确定故障原因是活塞窜气。

例如本故障:

- 空载时副机爆压低,活塞窜气量少,曲轴箱透管足够保证燃气逸出,曲轴箱压力不高,因而滑油不会没吹出曲轴端部密封;
- 负荷高时副机爆压高,活塞窜气严重,曲轴箱透气管不足以保证燃气逸出,曲轴箱压力高,因而滑油被吹出曲轴端部密封，“曲轴箱透气管透气量大，透气温度偏高”。

- 针对故障原因是活塞窜气，只要针对性地解体第6缸,就不难最后判定故障原因。

## (2)认真观察和分析

解体第6缸，只目视检查活塞头表面就认定活塞正常,发现“活塞顶部一半干一半湿”却未引起足够重视,结果没发现“活塞顶部与活塞头镶套处有一裂缝”,空气仍然漏泄至曲轴箱,只得再次解体第6缸,浪费时间。

若当时认真分析“活塞顶部一半干一半湿”的原因,就可以及时发现“活塞顶部与活塞头镶套处有一裂缝”,避免盲目换新缸套以及活塞环以及再次解体第6缸，节省人工。

当然，针对性检查和试验，认真观察以及仔细分析,需要人员具有较高技术素质,包括熟知设备的基本工作原理和结构、观察能力、逻辑思维能力等。

这就需要轮机管理人员努力学习，包括各种设备的原理和结构、观察的方法、逻辑思维的基本方法等。
