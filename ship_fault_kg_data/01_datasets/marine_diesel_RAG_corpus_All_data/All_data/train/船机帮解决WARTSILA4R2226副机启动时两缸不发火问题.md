# 导读

WARTSILA 4R22/26副机在使用某些港口加装的燃油时，经常发生启动时两缸不发火的情况，后续产生这样或那样的损坏故障，给设备安全和航行安全带来极大隐患。

文章分析故障，找出原因，提出解决办法。

# 概述

某轮副机型号为：WARTSILA 4R22/26，气缸数量：4个，缸径：220mm，行程：260mm，启动方式：气动启动、马达启动，额定电压：440V，发电机额定功率：650KVA。

根据说明书规定，此型副机可以使用黏度为 IFO 380cst(50℃)的船用燃料油经过分离净化、加热处理后黏度在8-10cst范围内进行正常启动运转。

然而在美国某港（巴西某些港口也有此种情况）加装使用黏度为 IFO 380cst的船用燃料油后，启动副机时，总有不固定的两个气缸不发火的现象。

由于有两个气缸不发火，此时机器运转粗暴，频率极不稳定，很难并电投入使用；并电后，不发火的气缸开始发火。

该轮曾在一周之内，副机有两只排气阀烧损，给船舶设备和航行安全带来极大隐患。

# 现状调查

笔者收集整理了最近几年来多条装有同类型副机的船舶设备检修记录、加油收据等资料，进行分析研究。

2001年某轮由于启动时两缸不发火，造成副机排气阀一只烧损；

2002年某轮由于启动时两缸不发火，后在运行中造成副机缸套一只裂纹，活塞一只损坏；

2004年某轮由于启动时两缸不发火，造成副机缸套一只裂纹；

2007年某轮也是由于同样原因，造成缸套一只裂纹，活塞头一只损坏；

2009年某轮由于启动副机时两缸不发火，造成排气阀两只烧损。

查看燃油收据中关于燃油品质的各项数据并无明显出入。

拆检气缸时，发现在不发火气缸的活塞顶、缸盖底面、排气阀、排气腔、排气管道等处聚集大量粘性很高的燃油；

另发现在燃油管路泄漏的燃油，冷却后黏度很高，似沥青状。

从上面的记录中可以看出，WARTSILA 4R22/26副机在启动时两缸不发火，并电后发火，对机器燃烧室部件所造成的损坏是十分严重的。

# 原因分析

通过拆检气缸，发现在燃烧室部件上有大量燃油聚集，说明副机启动时，气缸虽不发火，但并不意味着喷油器不向气缸喷油。

由于某些气缸不发火，机器转速不稳定，调速器自动调节供油量，并电所需要的时间越长，喷入气缸的燃油就越多，随着气缸的压缩和排气，大量没有燃烧的燃油就聚集在活塞顶、气缸盖底面、排气阀、排气腔室甚至透平等处；

并电后，不发火的气缸开始发火，之前喷入气缸的燃油也开始燃烧，这样燃烧室部件承受的热负荷就很大，超过设计能力，就会损坏诸如排气阀、活塞、气缸套、气缸盖等部件，严重时对连杆、曲轴造成影响。

通过对采集的数据、现象认真分析，副机在启动时某些缸不发火可能有机器设备本身、设备管理和燃油质量等方面的因素。

## 对机器设备本身是否存在故障进行排查

1. 高压油泵故障，泵油不足。解体高压油泵，并对经常不发火气缸高压油泵的柱塞、套筒换新后，试车，情况如前；

2. 喷油器故障，雾化不良。拆检喷油器，换新喷油嘴并在试验台泵压雾化试验，装复后试车，情况如前；

3. 透平效率不高，扫气不足。解体、清洁检查透平，装复后试车，情况如前；

4. 检查调节燃油系统的背压，以防背压太低，启动时进油不足而影响启动，结果情况与前没有一点变化；

5. 对不发火的气缸进行吊缸检查。活塞、缸套表面检查，无异常；活塞、缸套测量，都在说明书规定的范围内；活塞环全部换新；气缸盖及附件无异常。空载时测量各缸压缩压力，无异常，说明气缸密封状况良好。然而试车情况如前。

## 对设备的管理方面进行逐项排查

1. 按照说明书要求检查，调整进、排气阀间隙；

2. 按照说明书要求检查燃油调节机构调节是否正确，以防某缸油门太大或太小，影响启动；

3. 彻底清洗燃油系统滤器，以防供油不足；

4. 检查调整燃油进机温度，以防由于燃油进机温度低，黏度太大，雾化不良。本次提高燃油进机温度达155℃，黏度达9cst。

以上检查调整，对解决问题均未取得实质性进展。

## 对燃油油质方面进行排查

根据多数港口所加装燃油无此现象，部分港口的燃油有启动时两缸不发火的现象，由于船舶技术条件所限，我们怀疑燃油油质有问题。

特别是沥青质的含量。沥青质是石油结构中最复杂，分子量最大，以芳香烃为主的成分，其含量不应超过8%。

沥青质可使燃油发火性能和燃烧性能恶化。

根据NK统计的事故报告，因沥青质含量超量引发的事故占相当一部分。

然而此种燃油的品质表中无有关沥青质的含量。

尽管沥青质对燃烧影响很大，但在ISO8217燃油规格中也没有明确限制沥青质含量，也没有相应的测试手段。

后来我们取代表性油样交国际上认可的实验室化验，并特别要求检测沥青质含量。

但由于ISO8217中没有对其有要求，化验结果也没有沥青质含量指标，其他各参数都在燃油规格认可的范围内。

于是我们在启动副机前，提前给系统换用轻油，以提高此种燃油的发火性能。

当系统全部换好轻油，启动副机，机器很平稳的运转起来。

后经多次试验使用轻油可正常启动，使用此种规格的重油启动副机，总有不固定的两个气缸不发火的现象。

至此，判断此型副机启动时两缸不发火故障是由于沥青质含量超标导致。

但遇到此种情况时，换用轻油启动，并电后换用重油，也是一种有效的手段。

# 经验教训

1. 如果遇到此类发火性能差的劣质燃油时，启动时有两缸不发火的情况，应在启动副机前提前至少（多次试验得出）或更长一点的时间给系统换用轻油，正常启动副机，并电后重新换回重油；

2. 对燃油分油机、燃油加热器、系统滤器以及燃油伴温管加强管理，使其处于良好工作状态；

3. 主管人员加强学习，钻研业务，严格按照说明书规定对设备进行检查维护保养；

4. 加强燃油管理。加油时尽量避免混舱，即使不可避免需要混舱，最大混油比例不超过3:7，绝对禁止1:1的比例；分油机分油时采用小分离量，并适当提高分离温度；使用合理数量的燃油添加剂。

# 结束语

通过分析WARTSILA 4R22/26副机在使用劣质发火性能不好的船用重油造成副机启动时两缸不发火故障，探索出正常启动副机的工作要领和有效工作程序。

虽然启动副机前换用轻油工作比较繁琐一些，但是这样做，即有利于副机启动，减少在启动时不发火的情况发生，避免对机器设备的损坏，影响航行安全，又为船东的降本增效做出贡献。

更主要的是提高了操作人员的责任心，增强发现问题和解决问题的动手操作能力。
