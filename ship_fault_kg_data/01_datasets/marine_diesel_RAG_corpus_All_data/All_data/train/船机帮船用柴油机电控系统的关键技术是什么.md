# 导读

目前的船用柴油机控制都是选择电控为主，利用电控就可以实现对柴油机转速的稳定控制，这样就可以确保在工况范围之中满足对恢复时间、转速波动率以及调速率等运行参数的调节。

基于船用柴油机系统运行激励的分析，发现其数学模型相对复杂，并且在实际的运行过程中柴油机还会受到冷却水温度、负载以及燃油温度等条件影响，其本身存在明显的时变特性。

所以传统的控制方法已经无法满足柴油机的控制要求，所以就需要利用现代化的控制算法来控制柴油机，进而确保其可以在稳定的参数范围之中运行。

# 一 船用柴油机电控系统概述

了解船用柴油机电控系统的基本概念和优缺点，才可以为后续的技术研究有所帮助。

## 1. 概念

船用柴油机电控系统指的是基于柴油机负荷以及转速的，能够真实反映柴油机实际工况基本信号的一种控制系统。

对于柴油机电控系统产生影响的因素有很多，其包含的环境因素包含了大气压力、水温、油温等，通过分析各种外界因素，就可以对最佳的喷油量、喷油正时进行精准的计算，进而满足电控系统正常运行的要求。

在船用柴油机之中使用电控系统，就可以提升传播的各种输出，并且也可以针对各项数据做好补偿处理。

## 2. 优点

第一，船用柴油机可以提供较大的控制自由度。

电控系统可以基于实际的环境，实现传播喷油参数最优化的控制，并且也可以考虑到各种影响柴油机的因素，确保柴油机能够正常的运转。

第二，控制功能齐全。

船用柴油机的电控系统具有极高的自动化程度，并且自动性较强，本身的控制功能也能够满足船舶运行等需求。

第三，拥有较高的控制精度，并且动态响应较快。

电控系统本身运用了高科技技术，这样就可以满足一键式的电脑控制，并且控制的精度也非常高。

第四，可以将发动机的动力性提高，并且也可以满足排放性和经济性要求。

第五，能够提供故障的诊断功能，满足柴油机可靠性的需求。

## 3. 缺点

在使用船用柴油机电控系统的时候，难免会遇到缺陷。

第一，船用柴油机系统本身对于执行器的要求较高。

因为电控系统本身属于自动化系统，所以对于技术要求高，并且对于执行器的要求也非常高。

第二，需要仔细的研究控制策略。

在控制船用柴油机控制系统的时候，需要做好控制策略的详细研究，才可以满足其要求。

第三，系统优化标定工作本身的难度偏高，并且工作量很大。

# 二 船用柴油机电控系统的关键可靠技术

就船用柴油机电控系统而言，其关键技术主要包含了传感器的冗余技术以及双ECU的备份技术。

同时做好新电控系统架构的完善，这样才可以满足船用柴油机电控系统的整体性要求。

## 1. 关键传感器冗余技术

在高压共轨柴油机中，转角控制是控制参数，如，在准确性控制上，需要获取柴油机转角信息，这对于保护柴油机的安全是非常重要的。

ECU之中的曲轴信号传感器、凸轮轴传感器等关键传感器都需要采用冗余设置。

利用一用一备的模式，就可以提升系统本身运行的可靠性。

同时，基于多种工作模式的设计，这样就可以确保不同工作模式状态下，让ECU准确的获取柴油机的运行信息。

## 2. 双ECU备份技术

舰船级社中提出了相关的规定要求，也就是利用ECU的双倍分技术，在同时运行双ECU的时候，真正驱动系统运行的是获取系统控制权的ECU。

## 3. 新电控系统架构

第一，系统可靠性更加稳当。

因为系统采用的是总线冗余，也就是选择一用一备，当一套设备出现故障的时候，另一套系统就会投入运行之中，这样就可以提升系统运行的可靠性和稳定性，在ECU方面的备份，也有利于系统整体可靠性的提升。

第二，系统的配置灵活性更强。

新电控系统可以满足多缸发动机共轨燃油控制的实际需求，并且系统之中含有的各种控制总线接口也能够对各种通讯技术进行兼容，这样才能拥有更强的适应力。

第三，管理功能更强，系统控制更加完善。

船用的发动机转速控制、喷射控制以及系统故障检测与处理等方面都可以将电控系统的作用发挥出来，并且在管理与控制方面都得到持续的完善，这样就能够确保其满足柴油机更多技术的需求。

第四，拥有良好的环境适应能力。

在结构设计以及元器件选型等方面，电控单元按照相关的标准就可以进行优化设计，这样才能确保系统本身拥有良好的环境适应能力，能够满足船用柴油机运行的要求。

# 三 结语

总而言之，船用柴油机凭借本身热效率高、经济性好、适应力强等优势，成为船舶极佳的推进动力。

因为传统的控制系统已经无法满足现代船舶对于柴油机的需求，并且在实际的运行过程中，各种不同的因素都可能对船用柴油机产生影响，进而提出更高的适应性、稳定性要求。

所以，电控系统的运用，就能符合船用柴油机对于控制系统的实际需求。

真正的掌握船用柴油机电控系统关键技术，这样才能够满足船用柴油机稳定运行的需求，同时也对今后的船用柴油机发展有着重要的现实意义。
