# 导读

柴油机大修是设备管理中的一项重要预防性维修项目，在现代船舶及海上平台，越来越多的船用柴油机维修开始倾向于设备管理者的自主维修。

为了提高自主维修质量，柴油机的大修完全可以按照一个项目来组织管理，涉及物资管理、技术管理、进度控制、资料管理、人员管理等多方面项目管理技术，从做项目的角度出发，做到精细化管理，发掘维修中人、机、技全方位结合方法，实现高标准、高效率、高质量的项目管理目标。

# 一 物资管理

柴油机大修所用物资，包含修理包、故障零部件、工机具。

每台柴油机大修所需修理包是固定的，在制定采购单时只需按照大修手册相关要求进行全面统计即可。

部分柴油机由于更新换代，修理包有升级，可能存在部分必换零部件不匹配或缺少等情况，设备管理员在统计采购单时需向柴油机厂家进行咨询。

同时，为了避免自主维修过程中因操作手法问题发生修理包新部件损坏，可以另外订购一部分修理包作为备用。

在统计柴油机故障零部件时，需要考虑当前柴油机运行状况，包括零部件的腐蚀程度、累计使用时间、工作环境状况等，综合考虑柴油机每个工作系统的运行状况后制定采购单。

此外，查阅上次柴油机大修资料，根据上次备件更换情况以及《下次大修必换备件明细》进行采购统计。

因此，在柴油机维修作业过程中设备管理者需要及时记录下次要换的备件，例如某些零部件存在磨损或腐蚀，但是还可以继续使用并保持可靠状态至下个维修周期结束，这些件需要维修过程中及时记录，否则等柴油机需要大修时再统计，很可能会漏掉备件，导致中期维修过程中另行进行应急采办。

柴油机大修工机具采购，通用工具注意选型，例如扭力扳手的接口形式，外径千分尺的量程等。

专用工具必须按照相关柴油机大修手册进行选型，很多工具为特定型号柴油机专用。

吊索具等工具必须提供配套的符合要求的检验证书。

# 二 技术管理

设备管理者及维修作业人员若不具备相关的维修经验，则需要在作业前期投入大量时间和精力进行学习研究。

柴油机拆卸前设备管理者应组织人员对柴油机进行彻底的断水、断电、放油、排水，进行能量隔离，保障作业安全。

每一步拆卸前安排专人进行拍照和标记，便于后期装配对比。

拆卸的零部件进行分类存放，螺栓类应使用自封袋贴标签的方式进行分类存放，并在标签上注明螺栓的位置、数量等信息，某些零部件螺栓数量较多且长短大小不一的情况，必要时进行画图标识，这个方法对于后期装配有很大的帮助，可以避免返工情况的发生。

在维修作业中注意各项工具的正确使用，作业前对各项工具组织培训教学，讲解工具的使用方法和注意事项，专业工具的使用务必注意工艺要求和步骤，通用工具注意使用细节，例如扭矩扳手注意单位的选择，英寸磅（ft·lbf）和牛米（N·m）一旦选择错误，在给螺栓打扭矩的过程中很可能会出现设备和螺栓故障。

零部件的清洗是柴油机大修作业中的一项耗时费力的步骤，在有条件的情况下建议使用超声波清洗除垢设备，可以达到彻底清洗的目的。

现场没有专业清洗设备的情况下，非电子件建议打磨除锈后使用清洁的柴油进行浸泡清洁，然后使用洁净的面纱进行清洁存放。

如果零部件上有管道，建议使用干燥的压缩空气进行吹扫。

必要时使用专用管道刷进行彻底清洁。

空气系统的零部件务必使用干燥的压缩空气进行彻底吹扫，避免使用时油气进入空气系统发生爆燃。

零部件的测量选用合适量程的量具，零部件的报废标准严格参照大修手册中的数据标准，应该在作业前一天列出第二天作业步骤中所有涉及的零部件数据标准，并打印出来在第二天的正式作业中参照使用。

柴油机装配过程中会有大量的工艺要求，每一项重点工艺作业前必须组织工艺要求的学习，在正式作业中，设备管理者需要带领团队提前了解和研讨重点工艺和步骤，也可以通过网络视频进行学习和了解，建立《重点工艺卡》系统，在《重点工艺卡》上对具体步骤、装配要求、参数标准、注意事项等进行详细说明，便于在现场作业中有据可依，避免工艺遗漏。

装配完毕后应进行手动盘车检查，燃油系统进行手动排气注油。

冷却水系统开启水套加热装置，并对柴油机整体进行详细的“跑冒滴漏”检查。

手动盘车既可以检查出旋转的零部件是否存在装配错误，又可以排除系统的气体，提高冷却液液位显示的准确性。

建议柴油机首次启动前冷却系统使用干净的生活淡水作为临时冷却液，待柴油机调试运行正常后再按照要求更换成防冻液，这样既可然清洗并排除冷却系统内磨合出的残渣，又可以防止调试期间冷却液的流失浪费。

柴油机的启动调试是一项重要作业，作业前应对各个传感器进行功能试验，尤其对电路系统的检测，不得随意通电送电，应提前检查电源状态、开关状态、线路连接等情况，优先选择电阻档进行各个开关的通断测量。

通电后检测各个电气控制部件的工作状态，例如燃油电磁阀的通电动作情况、急停按钮的功能等。

柴油机启动前做好人员应急处置分工，现场进行演练，做好紧急停车准备，对于没有进气停车功能的柴油机建议采用增压器进气口封堵的方法作为紧急停车备用方案。

柴油机启动后保持低怠速运行至少15分钟以上，检查震动和“跑冒滴漏”情况，注意排烟状况的检查。

高怠速运行完全正常后进行各项安保功能试验，例如高水温停车报警、低油压停车报警、超速停车报警等。

安保试验结束后按照发电机组的设计要求进行电力负荷试验。

# 三 进度控制

控制进度的目的是实现整体质量控制，为了保障进度计划的顺利实施，可以采取以下措施：

（1）人员分工明确，责任落实到位。

柴油机大修是一项系统性的工程，人员结构组成应包括项目主管（兼任技术主管）、材料主管、现场装配主管、影像记录员（兼任标记员）、电气主管、进度控制专员、维修工等。

每个成员的责任分工明确，每日根据不同的作业量在《早会工作任务卡》中进行明确说明，并在每天作业结束后及时总结任务完成情况。

对未能按时完成的作业进行分析讨论，查找进度落后因素，针对性的进行控制补救。

（2）制定《项目进度曲线图》，定时检查进度计划执行情况。

进度的控制员负责每日的项目进度曲线绘制，项目主管每日组织分析项目进展情况，对比《项目进度计划表》及时总结影响进度的因素及控制措施。

（3）严格遵从工艺要求，避免返工情况发生。

维修作业中出现返工的情况是工作量变更的一种体现，严重影响施工进度计划。

为了避免返工情况发生，首先，在工艺步骤上要严格遵从大修工艺要求，要求对《重点工艺卡》内容进行反复查证核实，并与专业技术人员或者厂家进行沟通确定。

其次，零部件的装配顺序必须有据可依，避免试验式的安装造成作业量人为加大，因此在柴油机各零部件拆卸前就需要详细做好标识和标注，必要时拍照和画图示意。

另外，工具的使用不当也是造成返工的一项因素，操作前项目主管应对项目成员进行详细的工具使用方法培训，重点提示使用注意事项。

# 四 资料管理

在柴油机大修中，项目主管和影像收集员是资料管理的主要责任人，资料管理包括作业文件管理、影像资料收集、作业工单管理、工艺数据管理等内容。

根据作业阶段的不同，作业文件包含开工文件、施工文件、完工报告等，其中，开工文件主要包括施工方案、进度计划、质量控制方案、JSA风险分析、施工人员清单、工机具清单、应急方案、物料清单等，各文件资料应详实，系统性编制，避免出现互相冲突和矛盾。

施工作业中应及时进行影响资料收集，包括部件拆卸前后的拍照对比、作业中各个标记记录、作业步骤照片记录、作业步骤视频记录、人员作业宣传照片记录、故障部件特写等。

所有影像资料应分类分时段保存。

工艺数据包括装配数据、测量数据、试验数据等，装配数据应与柴油机大修手册中保持一致，并整理成表格，便于施工中参考使用。

原始测量数据和试验数据应保存扫描原件，并制作成电子数据留存。

# 五 人员管理

柴油机维修中一项重要内容就是人员管理，人员管理水平直接影响质量管理和安全管理。

人员管理包括人员资质、人员考勤、作业评价、任务分配、项目激励等内容。

人员管理的目标就是保障作业安全和施工质量的前提下最大程度发挥每个人的价值。

柴油机的大修涉及到电工、钳工、电焊工，项目开展前应对项目施工人员进行资质核查，保证持证上岗。

建立人员组织结构图，设置项目主管、装配主管、技术员、安全员、电气主管、维修员、影像收集员等岗位，项目主管全权负责项目质量、安全、进度、任务分配等工作，是项目的总负责人。

装配主管负责施工作业中的装配管理，协助项目主管进行工艺步骤管理。

技术员负责维修数据收集整理，负责装配数据核实，协助项目主管确定工艺要求。

安全员负责项目风险分析、作业中安全监控与记录、开具作业工单。

电气主管负责柴油机电气系统拆卸、装配、调试。

维修员听从项目主管安排进行维修作业。

影响收集员负责作业中的拍照与录像，记录重点工艺步骤，记录拆卸及装配标记等。

分配岗位时应根据每个人的资质特长、工作态度、性格等因素分别安排最适应的岗位，发挥人员各自特长及技能。

项目开始施工后应建立《人员动态评价表》，每天作业结束后根据项目成员的当天工作量、工作态度、失误及违规情况、安全管理执行情况等进行评分。

对表现优秀的成员进行鼓励，对存在操作失误或者发生不安全行为的成员进行点评。

项目结束后应建立《项目成员贡献度》表格，对每个成员在项目前、中、后期的贡献进行综合评分。

《项目成员贡献度》评定因素包括项目角色、《人员动态评价表》等内容。

《项目成员贡献度》可以作为后期申报奖励、人员评价、项目总结等依据。
