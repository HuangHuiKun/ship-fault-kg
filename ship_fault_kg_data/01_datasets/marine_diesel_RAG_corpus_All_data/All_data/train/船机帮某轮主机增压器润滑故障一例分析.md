# 导读

某集装箱船，四冲程柴油主机型号 MAK 8M552C，变距桨，增压器型号 ABB VTR 454-11。

增压器涡轮端轴承和压气端轴承，都是转子带动齿轮油泵从油池吸油排至轴承润滑。

涡轮端，因环境温度高（常用航速主机废气温度达400 ℃），油池侧壁（蜗壳）由主机冷却淡水冷却（进水约70 ℃），同时也冷却油池里的滑油（油泵溢油飞溅至油池侧壁），保持涡轮端油池油温低于 80 ℃，并装有温度计和温度探头监测。

# 故障

某日开航，码头边主机启动加速，检查增压器见：

涡轮端油位没有下降到正常运行位置；

油泵溢流口无喷射油柱，轴承处无油花飞溅；

油池壁干燥无油迹。

立即停主机，检查增压器涡轮端润滑：

打开底部旋塞放油，见滑油清洁无异常；

打开端盖，见油池壁漆膜剥离明显，油池底部有存油，也沉积有部分漆皮屑。

# 故障原因

油池有油，油泵溢流口无喷射油柱，轴承处无油花飞溅，油池壁干燥无油迹，显系油泵故障未正常泵油。

拆下涡轮端油泵，压缩空气吹通油路见有漆皮屑被冲出，证实漆皮屑阻塞油路。

# 修复

拆解油泵，彻底清洁，组装，灌油，用电钻带动油泵运转，油泵出油正常；清洁油池，装妥油泵，装复端盖，加油至正常刻度，主机冲车试验见油泵溢流口有油柱喷射，油池壁有油迹，轴承处有油花飞溅，故障排除。

# 防范措施

首先是保证油泵技术状况良好，包括使用合格的油泵，定期解体检查，日常及时发现异常及时纠正。

其次，及时发现和清除漆皮屑，包括：

日常值班巡回检查，及时发现并及时清除。本例故障就是没有做到这一点。

定期（主机完车状态）泄放，放出油池滑油和底部沉积的漆皮等杂物。但该型增压器涡轮端油池的放油旋塞开口高于油池底，滑油和漆皮屑不能完全放尽。

若油池内有或疑有漆皮屑，打开端盖彻底清洁油池。

换油，因放油旋塞开口高于油池底，最有效的方法事先打开端盖彻底清洁油池，然后换油。

若没有条件打开端盖彻底清洁油池，一定要用新油冲洗油池，从放油旋塞放尽底部积油和沉积的杂物。

第三，是防止漆皮因过热而剥落。

应保持冷却水：

温度，不超过允许值——需实时监测和调节。

流量，充足——确保压力、流量，且无泥沙或其他固体颗粒沉积阻塞水道（比较增压器涡轮端冷却水出口温度和油池油温可判断冷却水腔是否脏堵）。

水质，无泥沙或其他固体颗粒；保持水处理保证偏碱性不会腐蚀流道，含盐量低不会结垢。

其实，油池壁上的油漆并非增压器运转所必须（只为运输-保存期间防锈），可伺机彻底清除。

# 反思

关键在重视增压器日常检查和维护增压器是高转速运行设备，对拆装要求高，而现代集装箱船班期紧，周期性维修多委托专业厂家；

船员除了换油、清洁压气端滤网、定期冲洗叶轮等，只有日常检查；

而船员可能因增压器探测和报警设备齐全而不重视；

且增压器的位置多不便检查。

这些都可能导致船员忽视日常检查，以致增压器冷却效果差所引起涡轮端油温高也未引起注意；

久之，油温进一步上升，油池壁漆膜剥落导致油泵故障；

若未及时发现、处理则轴承过热。

增压器是高转速运行设备，一旦故障，瞬间就会造成严重的机损事故，维修、更换备件等费用巨大；

而且增压器损坏事故多发生在航行中，船舶的拖带、靠离泊、装卸货、班期等间接损失更大。

船员应认识到，专业厂家定期检修，一般不是全面检修，而是重点检查（必要时更换）增压器喷嘴环、转子、轴承、油泵等，决不可因专业厂家检修而放松日常的监测、检查和维护保养，而应加强日常检查：

充分利用勤看、勤听、勤摸等传统手段和仪表监测，比较参数变化。

利用一切打开增压器的机会检查外观和内部，及时发现异常，及时分析、纠正。

值班检查避免监测盲区。例如监测冷却水，往往偏重冷却缸套、缸头和排气阀一路，忽视冷却增压器涡轮端的一路；而增压器涡轮端的监测，又往往偏重废气进出温度，忽视冷却水温度和滑油温度。

这样，增压器涡轮端冷却水温度和滑油温度就成为监测盲区，易引发油池侧壁漆皮剥落且难以发现。

主机冲车、备车、运行之初，增加检查频次。

主机转速低易于观察，船在码头边有故障也便于检修。

此外，专业厂家检修过的项目，初次使用更要加强检测，切不可盲目轻信。

例如某轮增压器经专业厂家检修后运行才二周，就发现平衡腔室通大气出口渗油；咨询专业厂家，答复正常；但渗油越来越多，更换备件后才恢复正常。

后专业厂家人员也表示，若再拖延可能酿成机损事故。
