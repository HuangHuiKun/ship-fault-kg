# 导读

在主机的安装调试以及管子的制作安装过程中不可避免产生硬质颗粒、焊渣、铁锈、油漆皮、棉纱毛头等各种杂质,它们会对主机喷油嘴、轴承、滚轮、汽缸壁等造成损伤。

所以,采取各种有效措施来保证机内和管子内的清洁是必要的。

串油是最后一道也是最重要的程序,通过串油来保证系统内部的清洁, 从而达到保护主机的目的。

# 一、管道的设计要求

在管道设计时尽可能减少焊接成型弯头,最好采用弯管,所有焊缝必须能够从管端检查和处理。

但为了便于安装和拆卸,单根管子长度不超过2.5m。

所有的管道设计必须保证可以拆下来进行清洗,滤器的布置要保证便于检查和日常清洗。

# 二、管道的储存和加工

所用的管材必须储存在仓库内,最好放在斜架上。

管子制作前检查管子的内外壁的质量,管子焊接前的坡口必须用自动坡口机处理。对接焊缝必须采用氩弧焊接方式。

# 三、管道的安装、清洗和二次安装

分段预装或船台预装时将管子和阀件及滤器等全部安装到位,管支架装焊结束。

在船舶下水前将所有的滑油管系校装完整后,将管系和阀件拆下,送到车间保管,对滤器、冷却器、滑油泵及主机进出口等进行严格的保护。

在串油开始前15天,将滑油管送到冲砂场进行内部表面的冲砂和除锈,用柴油进行清洗,将清洗后的管子放入临时冲洗油盘, 采用滑油进行冲洗。

油盘底部接油管和20μm检查带,接小串油泵 ,接软管对管子内部进行10min /根管的清洗 ,清洗后的管子两端采用塑料薄膜+破布进行保护。

将所有的滑油系统阀件和串油工装管送车间分解,进行打磨除锈和清洗。

串油开始前6天,进行管道系统的安装和密性试验工作。

为了松动管系系统中的一些杂物,在主滑油管系外部加装震动器,间距2m,安装位置尽量靠近焊缝位置, 压缩空气的进口压力不能低于0.4MPa。

# 四、串油前的外界准备工作

船用发电机正常工作;燃油锅炉正常工作;蒸汽、凝水和技术水系统正常使用;滑油分油机及其滑油净化系统准备就位。

滑油注入和输送系统可投入使用;滑油储存舱和澄清舱已经完整,周边不存在尚未结束的动火项目;该舱室必须打磨清洁,用面粉粘干净,并涂清油漆,方可封舱。

主机轴系对中、主机滑油泄放头的安装和密性试验工作等项目对外提交结束。

# 五、主机和主滑油循环舱的清洁准备工作

首先进行主机曲轴箱内部清洁工作,十字头上用较大块塑料薄膜进行完全范围的保护 ,曲轴和连杆以及曲轴箱壁和油底壳采用棉布进行仔细清洁;同时进行主轴承进油管和十字头轴承进油管的安装节流板工作;清洁工作完成后,将滑油泄油口仔细密封保护,进入循环舱处理阶段。

主滑油循环舱必须按照特涂的标准进行清洁,由于船舶从船台到下水时间比较长,不可避免的存在生锈等问题。

所以必须按照下列程序进行操作:

涂装课进入该舱对结构初步冲砂→外业课进入该舱对结构和焊缝进行检查和修补→机装课将透气管、测深管、吸口、浮球、注入管、滑油泵吸口进行最后的清洁和密封保护 →涂装课再次进入该舱进行完工打磨和清洁 →机装课最后用面粉团进行舱室的精清洁,再用船用滑油对舱壁进行保护,最后封舱。

对主机曲轴箱进行最终的精清洁工作,滑油泄油口拆开和清洁 ,用面粉团对所有表面进行严格精清洁。

凸轮轴箱和扫气箱的清洁。

# 六、投油前的要求

滑油的注入顺序:由甲板注入滑油澄清舱,沉淀后直接放到主机滑油循环舱,在主机滑油循环舱的进口安装2个50μm的检查带作为滤器用。

启动锅炉,加热主滑油循环舱;运转主滑油分油机 ,将滑油循环舱的滑油进行不断的循环分离。

投油时不通过主滑油系统的自清滤器。

闷掉主机滑油进口总管,将船厂管子连接临时的橡胶挠性管,尽量在第一缸的防爆门位置进入曲轴箱,为了保护主轴承不会受到串油中杂质的影响,必须要将橡胶管一直伸到曲轴箱底部固定好。

主滑油和中央冷却水冷却器的温控阀都要具备使用条件。

# 七、主机外部管系串油

完成投油前的准备工作,安装好管路、滤器等确保系统正常。

主机滑油循环舱用分油机进行循环分离;滑油温度控制在60～65℃;主滑油冷却器的进出口阀关闭;工装滤器内安装高分子滤纸 380目各一套;管子震动器的安装到位具备使用;开动主滑油泵,请注意开始启动时检查并确定泵转向是否正常。

检查油泵电流、压力,检查管系是否泄漏。

检查机内是否正常; 2台滑油泵轮流实验,状态正常之后开始进行串油。

串油开始时启动主滑油泵,启动管子震动器,启动滑油分油机,关闭主滑油冷却器,保持串油24h,停止串油,打开工装滤器,检查和更换滤纸,视滤纸情况判定是否打开主滑油冷却器。

串油期间每班的值班人员负责将震动器挪位或角度转换一次,每次挪位大约500mm。

注意检查临时滤器前后压差不能过大, 保证在机外管内滑油有较大的流速。

压差大于0.1MPa时就要更换滤纸, 同时也要清洁滤器的本体内壳。

一般24h更换1次,后期可以适当延长周期，要以具体情况来看。

连续投油3天左右,若滤器过滤的杂质还有很多时,应考虑是否前期的清洁工作做得不好,必须立即向上级汇报。

一般在4天左右,经过连续2次对滤器的检查,若滤器上没有发现杂质,毛削等,可通知 检查员,利用检查袋进行2h的投油效果检查 ,自检合格后可向船东代表提交。

# 八、主机滑油整体管系串油

停分油机、停泵、停止串油;滑油泄到循环舱内拆除橡皮管,恢复机外主滑油管系,自清滤器仍然盘通,锁好防爆门,机内外的油管封堵工作在开始串油前已经完成,但仍须再次检查和确认;恢复主滑油机内串油。

主机滑油循环舱用分油机进行循环分离;滑油温度控制在60～65℃;工装滤器内安装高分子滤纸450目各一套;开动主滑油泵开始进行串油,启动滑油分油机,打开主滑油冷却器。

化验要求为ISO4406≤19 /15;每ml油样中的颗粒数必须符合要求:

>5μm的颗粒总数目: 2500～5000;

> 15μm的颗粒总数目: 160～320

# 九、动车前的准备工作

停分油机、停泵、停止串油;打开各缸倒门 ,抽油气;机内冷却,滑油泄到循环舱;循环舱的油通过分油机分到澄清舱。

拆除工装滤器,自清滤器复位,滑油管系完整;机内十字头保护盖拆除,机内所有节流板拆除;机外闷板拆除,进油管接头复位;检查袋拆除。

对油舱进行初清洁后,面粉团精清 ,向船东代表提交后,封舱。

将主滑油从澄清舱通过分油机分到循环舱 ;启动滑油泵,继续串油24h。

# 十、串油结束

将工装滤器和工装管以及橡胶管运到车间内保管,检查质量。

震动器全部回收,进行检查、加油和保养,损坏件保修或报废。

将串油期间消耗的高分子滤纸情况汇总,做定货的准备。

将主机上的闷板、卡套接头、铜管等清点回收。

整理投油情况记录和化验报告,进行归档。

本工艺主要介绍了串油的工艺流程,但是必须注意光靠串油是无法全部保证系统内部的清洁,因为管子内部残存的焊瘤或气孔会在系统运行一段时间后逐步脱落,从而对主机造成损伤。

根本的方法就是对主机保养、管子制作焊接、清洗、串油等进行严格的过程控制。
