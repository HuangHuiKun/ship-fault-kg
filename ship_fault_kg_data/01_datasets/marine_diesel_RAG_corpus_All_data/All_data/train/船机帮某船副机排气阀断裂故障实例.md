# 导读

排气阀作为船舶柴油机的重要工作部件之一，工作条件十分恶劣，一方面要承受使用劣质燃油造成的高温腐蚀,另一方面还要承受很高的机械负荷及冲击性交变载荷,因此其在实际工作中较易发生故障。

本文分析副机排气阀杆断裂故障经过及原因,供同人参考。

# 一、故障经过

某散货船于2013年下水,32 973总吨,载重吨56721.3 t。

船上配备3 台5DK-20e型五缸四冲程副机、缸径200mm、冲程300 mm、转速900r/min，调速器型号UG-10D,增压器型号TPS48F32。

某日该船在正常航行途中,1号副机在吊缸后试机磨合过程中烟囱突然冒黑烟,紧急停机检查发现No.3缸排气阀断裂(见图1)。

# 二、故障分析

## 1、气阀传动机构工作原理

图4 机械摇臂式气阀传动机构

图4是中、小型柴油机一种常见的机械摇臂式气阀传动机构。

它由摇臂﹑推杠和带滚轮的顶头等组成。

摇臂支座固定在气缸盖上,摇臂通过轴销安装在摇臂支座上。

工作时摇臂通过凸轮顶起顶头、推杆,从而绕摇臂轴转动,进而使气阀克服弹簧的弹力并打开。

当滚轮下降到凸轮的基圆时,气阀在弹簧的作用下逐渐关闭。

因而气阀的启闭时刻是由凸轮的安装位置及形状决定的。

对于机械摇臂式气阀传动机构,滚轮在柴油机冷态时落在凸轮的基圆上,此时气阀与摇臂之间存在间隙称为气阀间隙,其目的是满足热态下气阀传动机构和气阀热膨胀的需求。

如果没有气阀间隙，气阀在工作时将因向下膨胀而造成气阀漏气，并可能引起其他故障。

可以通过调节螺钉调整气阀间隙,但是调整时必须要求滚轮落在凸轮的基圆上,顶头、顶杆和摇臂之间保持接触。

## 2、排气阀杆断裂常见原因分析

排气阀杆断裂原因 大致有以下几点︰

(1)排气阀材质差、加工工艺不良、存在制造缺陷、其引起的局部应力集中导致排气阀疲劳断裂;

(2)柴油机所用燃油品质不良，导致燃烧后在排气阀杆、阀盘处形成燃烧产物附着,进而造成阀杆和阀盘产生高温腐蚀,使其机械性能降低;

(3)排气阀杆润滑不良导致阀杆得不到足够有效的冷却,或滑油被氧化形成酸质﹐腐蚀阀杆和阀盘,导致阀杆断裂;

(4)排气阀杆夹锁卡块安装不当,导致柴油机运转时掉入气缸,与活塞发生撞击,进而导致断裂;

(5)排气阀弹簧偏软,导致排气阀在启闭过程中产生共振,启闭失常,使排气阀遭受较大的冲击力而断裂;

(6)排气阀杆导管和阀杆间隙过大,导致排气阀在启闭过程中排气阀杆与导管的中心线发生偏差,进而使排气阀盘受力不均产生断裂;

(7)气阀间隙过大,排气阀在落座时受到的工作冲击力较大造成排气阀断裂;

(8)排气阀盘和阀座温度太高,或排气阀座和缸头刚度太差,导致排气阀座扭曲变形;

(9)缸头及有关部件安装工艺不良,产生弯曲应力,造成排气阀杆断裂。

## 3、故障排查

(1)该柴油机所用排气阀全部采购自厂家正规渠道,检查外表面没有明显制造缺陷,也不存在人为损坏情况，排除质量问题。

(2)拆检其他缸进行比对，发现所有排气阀表面干净，无高温及酸性腐蚀迹象。

燃油及滑油均购自正规渠道，化验记录完整，故可排除油品原因。

(3)检查排气阀的夹锁卡块及排气阀弹簧,未发现明显的安装不当或质量问题。

(4)根据以往各缸排气阀维护保养记录,发现各缸气阀间隙（测量值和设计值均为0.31 mm)及导管与和阀杆间隙(测量值均为0.10 mm,标准值为0.09 ~0.13 mm)均正常。

(5)根据柴油机前3个月的运转记录(排烟温度、负荷等)及拆检结果,发现以往工作状态正常且阀座无明显扭曲变形。

(6)最后将重点放在缸头及有关部件安装工艺不良上,通过询问船上人员发现该船曾在1周前刚对1号副机 No.2及No.3缸进行吊缸维修保养,损坏的活塞头顶部进气阀避让坑处有明显敲击痕迹，初步怀疑为安装不当所致。

(7)进一步查阅副机维护保养说明书,发现活塞头上有4个避让坑,其中排气阀避让坑深8.5mm,进气阀避让坑深6.3 mm。

图5 活塞头

活塞顶部2个进气阀避让坑之间有“F”标记(见图5)，且说明书上有明确标明:

活塞上的“F”标记及连杆上的凸台都应指向发动机前端(如图6)。

图6 活塞、连杆的装配示意

询问当时拆检轮机员，发现其未注意到该条要求,以至将活塞头方向装反(前后对调180°)。

No.2及 No.3缸活塞头装反，导致排气阀和进气阀避让坑对调位置,排气阀下部对应的避让坑相对高出2.2mm。

在运转中排气阀升程略高于进气阀升程,以至试机时No.2和 No.3缸排气阀开启时与活塞头避让坑产生撞击。

同时撞击位置在排气阀底部靠外侧部位,产生弯曲应力,导致根部疲劳断裂。

查找到原因后,对No.2和 No.3缸损坏的排气阀及活塞等相关零件进行更换,并严格按照说明书进行装复,后经试车运转，副机工况恢复正常。

在后续的航行过程中,持续对1号副机进行跟踪关注,均未发现异常，说明故障原因已经找到且被排除。

# 三、结束语

排气阀作为柴油机的重要零件,其工作性能直接影响柴油机正常工作,应予以高度关注。

轮机管理人员要加强对排气阀的日常检查和管理，同时严格按照说明书规定要求定期规范地对柴油机进行维护保养,避免人为原因引起的缺陷故障,确保柴油机稳定可靠地工作。
