# 导读

柴油机高压油泵是燃油喷射系统的重要组成部分，它的工作性能对柴油喷射系统的影响很大，它能够提高柴油的压力，根据发动机工作的时序、负荷，定时定量的向高压油轨内输送高压柴油，因此高压油泵也可以被称为柴油机的“心脏”。

高压油泵正常工作时需要保证泵油压力能够使喷射器的喷射压力和雾化满足要求，高压油泵的供油量精确满足柴油机工作所需的数量，高压油泵的供油量与供油时间还需要能够调节，以保证各个气缸内的均匀供油。

图1 高压油泵结构图

柱塞泵作为常用的高压油泵其结构如图1所示，其组成结构有凸轮轴、柱塞、挺柱、出油阀等。

其中柱塞与柱塞套是一对精密偶件，两者在加工过程中都需要进行精密研磨，配对后不能够进行互换，配对表面有很高的精度和较好的耐磨性，配对间隙通常为 0.002-0.003mm。

由于柱塞副之间的间隙较小，因此高压油泵柱塞副经常会发生柱塞副“咬死”的故障。

一旦发生柱塞副“咬死”的现象，可能会导致一个或多个发动机气缸无法正常运行，甚至会发生严重的机损事故。

为了防止这些事故的发生，对柴油机高压油泵柱塞副“咬死”故障进行了分析，并给出预防措施和改进建议。

# 一、柱塞泵的工作原理

柱塞泵的柱塞圆柱面上开有切槽，该切槽通过柱塞上的径向孔与轴向孔和柱塞顶部连通；柱塞套上开有进油孔与回油孔，二者均与低压油腔连通。

柱塞泵的出油阀是一个单向阀，由于受到弹簧的作用力，阀上部的锥面和阀座紧密配合。

当停止供油时，出油阀可以将高压油路和柱塞副上端的空腔进行隔绝，有效的防止了高压油路的油液倒流回油泵内。

柱塞泵工作时，柱塞在底部凸轮和柱塞弹簧的共同作用下进行上下往复运动，从而实现泵油过程。

进油阶段，凸轮机构处于回程阶段，柱塞向下运动，柱塞上部的空间体积变大，压强减小，产生一定的真空度，当柱塞下行至进油孔打开后，油液通过油路进入柱塞上面的空腔（即泵油室），柱塞运动到最低时，进油过程结束。

在供油阶段，凸轮机构处于升程阶段，柱塞向上运动，燃油压力增大，一部分的油液经过油孔流回到泵油腔，当柱塞运动至上端面挡住柱塞套筒的进油孔上边缘时，柱塞上部的泵油腔成为一个密封油腔，柱塞继续向上运动，泵油腔内的压力迅速升高，当压力达到一定值时，出油阀开启，高压柴油通过出油阀后进入高压油轨，经由喷油器喷入气缸中燃烧。

在回油阶段，柱塞上的油槽与套筒上的回油孔连通，油压迅速下降，在弹簧的作用力下，出油阀迅速关闭，供油停止。

随着凸轮轴的不断转动，柱塞就这样不断的做着上下往复的周期运动。

# 二、柱塞偶件的“咬死”机理分析

图 2 柱塞副结构图

柱塞偶件由套筒和柱塞两部分构成（如图2所示），由上一部分所述可知，柱塞在套筒内上下往复运动产生泵吸作用。

柱塞工作时会产生热量，因此需要对柱塞进行冷却与润滑。

柱塞上部通过泵油腔的燃油进行冷却和润滑，柱塞的中部通过流入的少量燃油进行冷却与润滑，柱塞的下部则通过流入的少量润滑油进行冷却与润滑。

根据实际工作中的经验可知，柱塞偶件“咬死”现象常发生在柱塞中部与套筒内部油槽相配合的环面之间。

该部位如果不能很好的冷却或者有积垢时，就容易发生“咬死”故障。

柱塞偶件的在工作时处于高温、高压的工作环境中，往复运动会产生大量的热量，柱塞套筒是固定在泵体上的，所以柱塞套筒上的热量可以经由泵体传导出去，然而柱塞上的热量则无法传递，若无有效的散热措施，柱塞受热后会发生热变形，柱塞与柱塞套筒之间的间隙很小，柱塞热变形后与柱塞套筒接触，就会发生“咬死”。

# 三、柱塞偶件的“咬死”原因分析

对柱塞偶件不正确的使用会使柱塞偶件发生“咬死”，柱塞偶件之间的配合间隙非常小，在使用过程中，如果没有按照使用要求采用合适的润滑油就会使一些杂质进入套筒与柱塞之间的间隙，造成柱塞偶件的卡阻和咬死。

在对高压油泵的修理与装配过程中，也是柱塞偶件易发生损坏的过程。

柱塞偶件的表面清洁工作要在洁净的柴油中进行，不能用尖锐或锋利的工具对柱塞和套筒表面进行刮削，一旦配合表面被刮伤就会引起柱塞偶件的咬死和卡阻。

对出油阀螺帽进行预紧时，预紧力也不宜过大，如果预紧力过大的话会使柱塞套顶部受到较大的外载荷而发生变形，这样子也会造成柱塞偶件咬死。

柱塞偶件属于精密零部件，对于生产加工有着严格的要求。

一些质量较差的柱塞偶件产品，生产加工时可能未能严格按照加工精度的要求进行生产，造成柱塞与柱塞套之间的间隙比较小，使得在高压油泵的调试阶段就发生柱塞偶件咬死现象。

柱塞偶件的正常工作与良好的润滑条件密不可分，柱塞与套筒之间的微小间隙泄露的柴油即可对柱塞偶件进行润滑，柱塞与套筒进行相对运动，借助柴油的流体动力学特性产生一定的油压与外部载荷相平衡，在柱塞与套筒之间就建立起一层润滑油膜，该润滑油膜的存在保证了柱塞与套筒之间不会因为干摩擦而发生咬死，凡是有可能破坏润滑油膜的因素都会导致咬死故障。

柴油机燃油系统的其他故障也会导致柱塞偶件的咬死现象。

柴油机运行过程中，供油提前角调整不合适就会造成针阀偶件的工作温度过高，针阀偶件会因此咬死在停止喷油状态，高压油泵中的柴油会无法进入气缸，高压油轨内的压力和温度会升高，同样的做往复运动的柱塞顶部所受压力和温度也会增加，柱塞会因此发生变形而导致柱塞咬死故障的发生。

# 四、柱塞偶件的“咬死”的预防措施

柱塞偶件的咬死故障多数的原因是因为在使用过程中，操作和使用不当造成的，只要在日常工作中能够引起重视，认真观察记录高压油泵的工作情况，可以很大程度上减少柴油机高压油泵柱塞偶件咬死现象的发生。

根据上面对柱塞偶件咬死故障原因的分析，可以采取以下措施来避免此故障的发生。

①对高压油泵进行拆装清理时，要在清洁干净的柴油中清理柱塞偶件，特别主要对柱塞表面的保护，不要使其受到任何损伤。

对出油阀的螺帽进行拧紧时用力不能过大，避免柱塞套筒下部的变形，可以有效的降低柱塞偶件咬死故障的发生率。

②采用库存的柱塞偶件进行更换时，要对柱塞偶件认真的清洗，并测试其是否能够正常的上下往复运动，防止因为零件存放时间较长零件自身发生变形，对于达不到产品要求的零件要禁止使用。

③在柴油机启动前要对高压油泵进行检查，确保高压油泵各油路连接正常，检验高压油泵上的齿条是否正常运动，如果发现齿条卡阻时，可以开启出油阀，用一跟小撬棒来回拨动齿条，使齿条能够用手推动为止。

经过这样的调整后，一般的卡阻咬死问题都能解决。

调整齿条的同时要注意不能用力过大，否则会损伤齿条，更不能用撬棒对齿条进行敲击。

④柴油机启动后，让其空载运行一段时间，检测系统的各个参数，如压力、温度等参数，这数据显示正常后再逐步加载运行。

⑤对柴油机高压泵要进行定期的检查、尤其要注重对润滑油的检查，当润滑油的质量达不到要求时要及时更换润滑油，润滑油油质变差最易造成高压油泵的咬死。

除此之外，还要对燃油系统其它的部件进行及时清理，燃油滤器要经常清洗与更换，燃油滤器对阻止杂质进入高压油泵有着重要的作用。

柴油机在正常使用的时候，可能会加入不同产地的燃油，不同的燃油其黏度略有不同，其推荐的进机温度也不尽相同，进入高压油泵的油液黏度不当，会造成柱塞的损伤，磨损产生的金属颗粒也会造成柱塞的咬死。

因此在燃油进入高压油泵之前，要认真做好燃油的分滤工作。

# 五、结论

柴油机高压油泵的柱塞副作为精密的零部件，易发生“咬死”故障，该故障的发生对柴油机的性能有着重要的影响。

引起柱塞件“咬死”问题的原因是多方面的，其直接原因是柱塞表面的损伤和柱塞副配合面之间有杂质，从这两方面入手，分析了柱塞副装配问题、燃油品质问题、燃油系统其它部件的影响等因素，给出了柱塞件“咬死”问题的发生机理。

结合日常柴油机高压泵使用过程中出现的各种情况，从产品质量管理、燃油品质控制、拆修装配规范等方面给出了预防高压油泵柱塞件“咬死”问题的有效措施。

对柱塞件“咬死”问题的分析和探究，有助于工程技术人员合理的使用高压油泵，提高柴油机燃油系统的工作效率。
