# 导读

瓦锡兰4L20柴油机，因为其功率大、体积小、运行稳定等优点，被广泛应用于各种类型船舶上，该机型采用四缸结构，在柴油机底部安装有两个与曲轴旋转方向相反的平衡轴，平衡轴转速是曲轴转速的两倍，由曲轴通过齿轮带动高速旋转，用来抵消柴油机运行时的往复惯性力，以解决振动问题。

如果出现柴油机工况不佳振动过大、平衡轴与曲轴转角的相对位置偏移、摩擦环组螺栓松动、系统滑油压力不足、油品质量下降等情况都会加速磨损，缩短平衡轴的使用寿命。

严重时，会导致柴油机无法使用，造成船舶电力供应紧张的局面。

# 一、故障经过

某轮发电柴油机型号为瓦锡兰4L20，额定功率580KW,额定转速900RPM，缸径200mm,冲程280mm,运行50000小时。

事发时在某锚地抛锚，用船载克令吊卸货。

当日0605启动NO.1柴油发电机，0617并电使用为克令吊供电。

1025分出现NO.1柴油发电机滑油低压报警（0.29Mpa），正常值为0.45Mpa左右，此时滑油温度正常。

值班人员立即将该机从电网解列，停机检查。

主管人员首先拆检滑油滤器，发现大量黄色金属粉末，判断有部件异常磨损。

打开曲轴箱、凸轮轴箱，各传动部位外观正常，手动盘车检查未见卡阻，连杆大端轴承、主轴承等试压检查未见异常。

拆检涡轮增压器，轴承、叶轮等各部位正常未见异常磨损。

将油底壳内滑油全部排出后，检查两根平衡轴，发现平衡轴轴承有较大程度磨损，其中一号平衡轴靠近飞轮端轴承衬套磨损严重，底座开裂，油底壳底部有较多金属粉末，一体式的油底壳和平衡轴整体损坏（见图1）。

# 二、原因分析

该柴油机在四个月前进行过吊缸作业，完工后船员将原来油底壳内的润滑油排空，更换了新油，并对润滑系统进行了清洁，检查平衡轴保护罩固定螺栓、摩擦环组螺栓紧固情况、传动机构齿轮间隙等未见异常，排除因紧固螺栓松动、脱落造成的轴承磨损。

图2 堵塞变窄的润滑油进油孔

该机型在油底壳上有与机架相通的油孔（见图2红色标识），润滑油自该油孔进入，到轴承处的油孔溢流而出，从而起到润滑的效果。

由于该油孔所处位置与机架相连，除非将油底壳拆出，否则在日常维护保养中无法对该进油孔通顺情况进行检查，如果润滑油脏污，会发生最末端的平衡轴润滑油孔堵塞、通道变窄的情况。

通过对本次损坏的平衡轴和油底壳的测量发现，干净的平衡轴润滑油孔为18mm，而损坏的轴承润滑油孔堵塞严重，实际进油孔孔径仅为5mm。

该轮经常使用克令吊装卸作业，柴油机负荷变化大，柴油机的惯性力也随之反复变化，平衡轴和传动轴承受的力也随之改变，润滑油脏污，致使油底壳沉积大量油泥，长期作用下油泥将润滑油进油孔堵塞，失去有效的润滑作用，轴瓦与轴颈发生干磨，最终导致该平衡轴轴承的严重磨损。

综上，润滑油的脏污导致平衡轴进油孔堵塞变窄，使得平衡轴轴承失去有效润滑，是本次故障发生的根本原因。

# 三、解决方案

该型号柴油机平衡轴底座与油底壳为一体式，且损坏严重无法修复，采用更换总成的方案解决故障。

船方在厂家工程师的帮助下，更换新的油底壳总成和平衡轴轴承，按照规定力矩装复各紧固螺栓、调整柴油机和平衡轴定时，拆检滑油泵、离心分离器，彻底清洁润滑系统，更换全部滤芯，保证柴油机润滑系统的洁净畅通。

# 四、注意事项

## （1）加强润滑油的管理

使用符合厂家技术规范，并且与柴油机所用燃油特性相匹配的润滑油，尤其是伴随着低硫燃油的使用，润滑油的粘度碱度等各项性能指标，均需满足要求。

按要求对柴油机的润滑油进行离心净化分离，以去除润滑油中的水分和不溶解物质。

建议使用润滑油厂家推荐的分离温度的最高温度，并且将分油流量设定在额定的20%左右，以达到最佳的分离效果。

柴油机自带的润滑油离心分离器，可以有效的分离油泥，需定期拆检清理，并更换滤纸。

定期对润滑油进行取样化验。

建议在柴油机运行每次间隔500-1000小时，对润滑油进行取样化验，确保粘度、闪点、总碱值、水分、不溶物等指标在正常范围之内。

一般来说，连续化验分析中，各项指标的变化情况和变化趋势，比指标的绝对值更有意义，迅速而突然的性能指标变化，代表系统工作不正常。

在规定的周期内更换润滑油，良好的运行工况、有效的离心净化分离以及符合标准的化验结果，可以适当延长润滑油换油周期。

补充新的润滑油时，建议每次补充不超过10%的新油，一次补充过多，会扰乱正使用润滑油的平衡，比如加速不溶物的沉积等。

总之，使用洁净合规的润滑油，可以有效的减少平衡轴的磨损。

## （2）定期检查平衡轴状况

每次柴油机油底壳换油时，要检查平衡轴状况，包括油底壳有无金属磨屑、平衡轴各紧固螺栓上紧力矩、平衡轴轴瓦外观等。

按照说明书的要求，检查调整平衡轴与曲柄转角的相对位置，并测量轴承间隙。

在补充新的润滑油液位未超过平衡轴轴承高度时，启动预润滑泵，检查轴承的出油量，如出油量变小，需要格外注意。

每运行8000小时，需拆除一只平衡轴轴承衬套检查，状况较差时，检查其它衬套，必要时换新。

由于船舶营运需要以及实际拆装操作的难度，船员可能无法将油底壳与平衡轴一起拆出检查衬套状况，可以结合船舶修船的时机，安排厂家专业人员检查，并对油底壳、润滑通道等进行彻底清洁。

## （3）加强设备的维护保养

按照规范对高压油泵、油头等进行拆检，定期清洗空冷器、调整进排气阀间隙等，保证柴油机各系统处于良好工况，减少因为爆燃、做功不均匀而产生的额外振动。

日常使用中不超负荷运转，避免负荷和转速的剧烈波动，出现异常尽快停车查明原因。

定期检查柴油机的减振块、支架等减振装置，保证对振动的有效支撑，发现振动异常增大需及时查明原因并解决。

# 五、结语

平衡轴可以有效的抵消瓦锡兰4L20型柴油机运行时往复惯性力，减少柴油机的振动，有助于设备的平稳运行。

柴油机工况不佳、润滑效果不良，与曲轴转角的相对位置偏差、摩擦环组件螺栓松动等都会导致平衡轴的磨损，主管人员要加强重视，严格按照要求检查、检修、维护、保养，确保柴油机的可靠运行，从而保证船舶的安全生产。
