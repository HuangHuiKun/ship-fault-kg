# 导读

船舶副机安保系统，出现故障如何查找，从机械电气和控制空气方面入手分析，如何避免故障出现，频繁检查电气设备，定期测试安保系统，定期检查高压油泵齿条及总杆及齿条加油活络，定期检查清洁控制空气系统电磁阀减压阀等。

船舶副机用于船舶发电，保证船舶电网正常工作正常，在船舶中四机一炉中副机至关重要，为了防止副机原动机出现大的事故，避免大的机损，副机安保系统用于异常工况下，实现副机自动停车，防止机损事故发生，安保系统是保护主机的关键屏障，安保系统一旦失效不仅给设备安全埋下隐患，同时也增加了PSC 检查滞留风险，本人通过多年的轮机长工作总结了一些故障案例，分析故障原因及日常维护的注意事项。

# 某客滚轮副机型号

安庆大发6DE-18，安保系统主要有，滑油压力低停车，缸套水冷却温度高停车，及超速停车。

在进行一次安保测试的时候，滑油压力低，冷却水问高，副机均未停车，在副机旁按停车按钮仍然不能正常停车。

# 故障排查方法

明白了停车控制逻辑，解决故障从三个方面入手：

首先机械部分，检查各缸高压油泵齿条在停车位是否为零，油泵齿条是否活络，燃油控制装置活塞是否活络。

油门杆是否卡滞。

副机可以正常停车说明燃油控制装置活塞问题不大。

其次，控制空气方面，能实现自动停车却不能安保停车，控制空气压力低，高压油泵齿条磨损大及控制空气漏气等。

最后电气方面，继电器1K9,1K5-1.1K5-2同时故障可能性不大，再者就是CPU 出现故障不能执行正常的命令。

为了缩小故障排查范围，首先测量安保停车的时候，电磁阀5S.5V的电压，是否正常得电，检查显示电压正常，排除了电气故障的可能，至此基本判断控制空气故障。

首先检查高压油泵齿条后气缸及控制空气管，手动动作5S电磁阀，气路导通为发现各缸气缸及管子无漏气现象，当安保触发的时候，发现燃油控制装置活塞顶动齿条总杆的时候有动作同时有回弹的现象，怀疑气压不够或者燃油控制装置活塞卡滞，拆卸减压阀发现杂质和水分及铁锈。

清洁疏通及控制控制空气气路及放残阀再次试验安保系统正常。

# 故障分析及维护保养注意事项

通过案例分析解决问题的方法，首先看懂图纸，理解副机停车的原理，电气方面，机械方面等逐项排查分析排除法查找故障。

在平时维护管理方面，对电气方面定期检查电箱接线情况防止出现松动及绝缘不好现象，机械方面对油门杆及齿条定期活络检查，安保系统定期试验确保功能完好，及时发现问题，控制空气管路定期放残定期拆解清洁更换密封。

副机安保系统是副机出现异常的时候的重要保护，防止重大事故的发生，同时也是海事及船级社检查的重点，一旦功能故障，很可能带来极大的机损风险和海事滞留后果，无论是滞留还是机损事故，都会带来重大的经济损失，所以船舶管理人员务必引起重视，定期检查测试确保安全。

确保安保系统功能正常是防止副机重大机损和顺利通过海事检查的重要保障，为船舶的安全海上航行打下了良好的基础。
