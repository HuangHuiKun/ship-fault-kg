# 导读

某轮主机(型号为MISTSUI B&W 5L60MCE，最大功率为7200BHP，最高转速100r/min)第4缸存在着爆炸压力高于其它缸约1.8MPa，排烟温度低于其它缸60℃左右的现象，见表1和图1。

为此，主机转速最高只能开到83r/min，如果超出该值，则主机将发生振动过大、透平喘振等现象。

# 一、单缸爆炸压力过高及排烟温度低的原因分析

从表1和图1中可明显看出，第4缸喷油定时太早。

但由于该主机带有可变喷油定时机构，喷油定时过早的原因究竟是由于可变喷油定时机构设定不当造成的还是由于燃油凸轮移位造成的，还需进一步检查才能确定。

本着先易后难的原则，首先检查可变喷油的定时机构。

检查该缸的可变喷油定时齿条(简称VIT齿条，下同)位置，其刻度与其它缸相差不大(见表2)，并已在最晚的喷油定时刻度。

脱开该缸VIT齿条与传动机构的联接，单独推拉该齿条，移动量很少根本无法再往小处调整。

在停航时再检查第4缸高压油泵柱塞升程(TOP LIFT)，其结果与出厂时的数据相差无几，说明该缸燃油凸轮并没有移位。

接着检查高压油泵。

拆去高压油泵顶盖上的一只闷头螺丝，用深度尺从螺孔中测量并计算出各缸高压油泵套筒上平面至泵体上沿之间的距离，发现第4缸比其它缸大9mm左右(见表2)，相当于柱塞升程(TOP LIFT)增加了9mm。

按说明书介绍：柱塞升程每改变1.52mm相当于喷油提前角变化1°，由此计算该缸喷油提前角比其它缸提前了约6°，导致爆炸压力和排烟温度相差这么多。

显然，该缸爆炸压力过高的原因是由于高压油泵套筒上平面至泵体上沿之间的距离太大，以致喷油过于提前造成。

该主机的可变喷油定时机构是根据主机负荷的高低来改变喷油提前角的大小的，当主机负荷高于50%时，可变喷油定时机构开始动作使喷油提前角逐渐增大，到80%负荷时便逐渐减小，以获得最大的有效功率和不使气缸内爆炸压力过高。

喷油提前角的改变则由可变喷油定时机构推(拉)WT齿条，VIT齿条再通过齿圈带动与其内螺纹啮合的套筒沿泵体上下移动来改变柱塞上沿挡住套筒上面的回油孔的时刻，从而改变喷油提前角的大小。

在主机同一工况时，如某缸高压油泵套筒上平面至泵体上沿之间的距离增大，则说明套筒位置降低，柱塞上沿就会较早地挡住回油孔将提前向气缸内喷油，喷油定时就会过早，将造成爆压高排温低的异常现象。

# 二、故障解决方案

整体拆出该缸高压油泵，拆开油泵下部端盖(GUIDE BUSH)检查零部件无损坏，可变喷油定时齿圈与齿条也啮合在记号位置，只是套筒处在最低位置，推动VIT齿条仅能向下移动不到半毫米，向外拉齿条因齿条已到末端也只能拉回到原来的位置。

按测得的数据，VIT齿条每移动1格，套筒位移1mm计算，该套筒现在所处的位置VIT齿条应在9格(满刻度)的刻度，而现在-0.40格的位置，显然套筒装配错误。

拆出齿圈，把套筒向上移动到说明书要求的其上平面距油泵体上沿58.5mm(D-8)的位置。

拆开VIT齿条定位螺帽(UNION NUT)。

把VIT齿条拉到齿条台阶到泵体57mm(D-7)的位置，然后再按记号装复齿圈并装上VIT齿条定位螺丝。

这时把VIT齿条放到零位，再测量套筒上平面至泵体上沿之间的距离为63.3mm，与其它缸基本相符。

可见以前拆检该高压油泵时，没有注意检查套筒上平面距泵体上沿的距离，而在套筒处于最低位置时装上了齿圈以致造成了上述现象。

当高压油泵装复试车无误后，主机在原转速时再测量各缸参数(表3)基本正常，如图2所示。

同时，主机由各缸负荷不平衡造成的振动及透平呼呼的喘振声也基本消失了，并可以正常提速了。

# 三、高压油泵可变喷油定时机构的检修要点

由于该种类型的高压油泵结构比较复杂，使得拆检也比较困难。

之所以拆、装比较困难主要是多了一套为可变喷油定时设置的机构，即VIT齿条、齿圈和与之啮合的柱塞套筒。

在原地拆出油泵柱塞套筒偶件时，必需松开VIT齿条的定位螺丝把齿条拉到图3所示的D-7长度，这时齿圈上的内罗纹才能与套筒上的外螺纹脱开，套筒才有可能拉出。

同理，油门杆的定位螺丝(BUFFER POINTER ASS.)也要拆开并把油门杆拉到图示的D-7长度，否则柱塞底部的丁字头就不能与柱塞座脱开，柱塞也不能随套筒一起拉出。

装回柱塞偶件时两根齿条杆也应保持在拆出时的位置，偶件安装到位后，分别移动两根齿条杆，如果柱塞可灵活转动，套筒也可上下移动，再把VIT齿条放到D-7的长度位置检查测量D-8尺寸，如果正确，说明安装完全正确。

其拆装工艺简图如图3所示。

如果解体油泵下部部件则需要把油泵整体拆下来，拆的时候并不是把四只固定螺丝松开就能拆出，也需要把油门齿条拉到D-7的长度使柱塞丁字头与其座脱开才行。

在解体时要注意两根齿条和齿圈的啮合位置，虽然大多有记号但记号往往不止一个，搞错将会带来很多麻烦。

装配时应先把柱塞套筒偶件装入泵体，使套筒上面的定位槽与泵体上的定位螺孔对齐并调整其上平面与泵体上沿为D-8高度后再带上定位螺丝，注意，该定位螺丝只能使套筒圆周方向定位，轴向不能定位。

因可变定时机构动作时套简要上下移动。因此，能带上定位螺丝并不说明套筒安装位置正确，只有保持在D-8高度的位置时才对。

套筒定位后再把VIT齿条拉到D-7长度的位置，这时再按记号或把齿圈内螺纹的头部对准套筒外螺纹的头部装入齿圈即可，否则不仅造成喷油定时错误还使以后拆检该油泵带来很大的困难。

就像本例，不仅喷油定时过早，而且按说明书中的拆检方法在原地根本不能拆出柱塞套筒偶件，只有把油泵整体拆出后才能解体柱塞套筒偶件。

同时，如D-8尺寸相差过多VIT齿条移动量将会减小或根本不能动作，使整个的VIT机构失去作用。

接下来安装油门齿圈，油门齿圈不仅要作记号不能装错方向也不能装反。

该齿圈正反方向都可以装入且有的两面都有记号，一面一个记号，另一面有两个记号。

一个记号的那面应朝外与油门杆齿条上的记号对准装入即可。

如方向装反，齿圈会松动且易与齿条脱开；位置装错油泵整体将不能顺利地装回原位，如试图用改变油门杆位置的方法强行装入的话，油门在零位时该缸将不会停油。

装好后可按下面的方法进行检查正误：如把油门齿条拉到D-7的长度，柱塞下部的丁字头与其座的长方形孔同向，再把油门杆推到零位，如柱塞头部两侧的直槽与套筒上的油孔基本对齐时即正确，并能顺利地把油泵总成装回原位。

# 四、结束语

主机是推动船舶航行的主动力，是船舶的心脏，其可靠性对船舶来说是可举足轻重、不可代替的。

船舶航行中长期离开陆地，在主推进装置发生故障时很难及时得到陆地人员的支援。

在复杂航行环境和严峻气象条件下，有可能因为船舶失去应有的动力而导致船翻和船毁人亡以及严重的海洋污染事故。

本文通过解析船舶主机单缸爆炸压力过高的原因及解决过程，同时阐述某类型高压油泵可变喷油定时机构的原理及检修要点，为遇到类似问题需要帮助的读者提供参考，但同时也希望通过此文能让大家从内心中进一步认识到工作要认真、仔细、严谨的重大意义。
