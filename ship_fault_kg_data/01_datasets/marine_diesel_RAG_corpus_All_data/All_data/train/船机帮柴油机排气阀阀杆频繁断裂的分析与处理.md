# 导读

船用柴油机的排气阀，大多采用高合金耐热钢制造。

排气阀长期工作在高温及腐蚀的恶劣环境下，所以排气阀主要的失效形式有气阀头部宏观裂纹、烧蚀掉块破碎和气阀杆身断裂等。

本文介绍了柴油机排气阀阀杆频繁断裂故障的分析和处理过程；探讨了各种可能的故障原因；主要从失效零件宏观形态与材料的断裂方式2个方面进行分析，找出气阀断裂原因。

通过故障的实际解决过程，找出处理方法及预防措施，同时为故障原因提供可靠的证据；从而为船舶管理人员提供维修保养经验，保证船舶安全运营。

# 一 查找故障

在某港口，我们与外籍船员交接了1艘杂货船。

在交接班时，交班人员告诉我船二管轮，No.2付机有点问题，一般不要用，但他们也没有彻底查明是什么原因。

因为交接班时间紧迫，就没再仔细追究其原因，于是麻烦就来了。

接船后，由于其他付机需要检修保养，就使用No.2付机，运转一段时间后，No.2付机故障停车，造成全船停电，于是管理人员对No.2付机进行抢修。

该船付机为DAIHATSU柴油机，查阅前期的轮机日志和付机日志时发现No.2付机一直没有使用，可是刚投入运行不久，是什么原因造成No.2付机故障停车?

在记录栏内有这样一段话：

"排气阀阀杆发生过3次断裂，故障原因不明，尽量少用或不用。"

于是对No.2付机进行吊缸检查，发现是由于No.5缸的1个排气阀阀杆断裂，排气阀落入缸内造成No.5缸活塞损坏，致使No.2付机故障停车。

万幸的是，主轴及主轴轴瓦没有损伤，只有该缸的连杆轴瓦、活塞及缸套等受到损坏。

将断裂的排气阀取出，检查损坏排气阀。

如图1所示，气阀内外弹簧4和5与上下弹簧2和3及导套7都较完好；断裂是发生在阀杆1的顶端和哈夫块3的结合处凹槽上缘，断裂后排气阀落入缸内。

仔细观察断裂处，在自然光下观察到断裂气阀杆部严重变形，阀杆断裂处的外周有明显的磨损，杆部断口明显可见疲劳源区多达5处，断裂扩展区贝壳状花纹清晰，具有典型宏观疲劳破坏断口特征。

从失效零件宏观形态分析可知，气阀在使用过程中杆部曾承受较大磨损和严重撞击，载荷方向多变；疲劳过载使断口多发疲劳源，且疲劳扩展区贝纹线间距较大，属于多源低周期疲劳断裂。

一定有更为隐秘的故障原因。

于是换新No.2付机No.5缸的连杆、连杆轴瓦、活塞、活塞环及气阀等，将付机装复。

对No.2付机进行盘车，启动正常，空载运转。

然后打开No.2付机气阀盖，仔细查看No.5缸排气阀的运转情况，发现摇臂上的滑油喷嘴没有将润滑油喷到合适的部位 (润滑油是通过摇臂上的滑油喷嘴喷到摇臂与阀杆顶部，来润滑气阀杆顶部及哈夫块)，并且与其他气缸相比较油量要小；进一步仔细观察，发现锥形螺丝孔的调节螺钉脱落。

而其他气缸排气阀顶部润滑正常，未发现这样的现象。

# 二 故障原因分析

气阀断裂失效与下列原因有关：

1)气阀夹锁 (哈夫块)不当，造成运转时气阀落入缸内，被活塞多次打击。

2)安装不当，导致气阀顶部存在严重附加弯矩。

3)原材料冶金质量缺陷引起的局部应力集中，是气阀杆部疲劳断裂的内在因素。

4)断裂失效气阀杆身严重变形，并发生断掉头，杆部断面存在多个疲劳裂纹源。

5)断裂气阀失效形式属于多源低周疲劳断裂。

6)缺少适当的润滑与冷却，使得运动副磨损严重，以致断裂。

阀杆顶端装设哈夫块的凹槽处，由于这些部位应力容易集中，当应力集中到一定程度，就会发生疲劳断裂破坏。

阀杆顶端装设哈夫块的凹槽处又是气阀的最薄弱部位，若该处凹槽加工工艺不良或闭阀冲击力较重也会产生疲劳断裂。

造成断裂的原因有：

阀杆与导管的间隙过大；阀盘与阀座的变形使局部受力过大；气阀间隙过大，敲击严重疲劳破坏；气阀机构的振动。

查阅付机说明书和付机维修记录，进行深入的分析，No.2付机排气阀杆频繁发生断裂，都发生在阀杆的顶端的哈夫块处。

付机额定转速高达900r/min，摇臂拍打阀杆的次数相对较高，由于震动而使锥形调节螺钉脱落，润滑油就会通过锥形螺丝孔，直接喷到缸头摇臂罩内的其他地方，摇臂上的滑油喷嘴没有将润滑油喷到合适的部位，造成阀杆顶端与哈夫块接触面处严重缺油，使得阀杆顶部得不到充足而有效的冷却和润滑，加剧了该部位的热应力和疲劳应力的集中；阀杆断裂过程为阀杆圆柱表面上的氧化皮层向基体扩展作用不均匀，首先在阀杆表面形成浅沟形开裂，逐渐发展成较深的裂缝，导致付机排气阀阀杆的频繁断裂。

综上所述，失效零件宏观形态属于多源低周期疲劳断裂，材料的断裂方式为磨损疲劳破坏；由于锥形调节螺钉从付机摇臂上脱落，造成了该部位没有足够而有效的冷却与润滑，从而引起气阀杆频繁发生故障。

# 三 故障处理过程

1)更换付机油底壳滑油，保持滑油清洁。

2)清洗油泵吸口滤器和回油滤器，以便清除滑油系统内的金属磨料和含有的水分等杂质，来保证油路畅通和减少接触面的磨损。

3)解体付机轴带滑油泵，更换已磨损的部件，重新调节油泵的安全阀设定压力，以达到说明书要求。

4)拆卸该付机的摇臂油路，反复细致地清洗，确保摇臂滑油管路的畅通。

5)检查上紧摇臂上的各滑油管路接头，杜绝或减少滴漏以保证摇臂滑油的质量。

6)重新调节并锁紧摇臂上的锥形调节螺钉，必要时重新攻丝，保证各接触面的最佳供油率，以达到足够而有效的冷却和润滑。

7)定期分离循环油，更换被污染的摇臂油，缩短摇臂上运动部件的检查周期，由过去的每周检查1次，缩短到每天至少检查1次，一旦发现问题立即解决。

通过以上处理方法，有效地改善了No.2付机阀杆顶端与哈夫块接触面的冷却和润滑效果，No.2付机运转正常，再没有出现阀杆频繁断裂的故障。

# 四 故障的预防措施

排气阀是柴油机的重要组成部分，它的工作性能的好坏直接影响到主机的正常运行。

因此，轮机管理人员必须对排气阀工作予以极大的关注。

要求做到以下几点：

1)航行时认真巡回检查，注意各缸的排烟温度的变化。

如某一缸的排烟温度出现逐渐上升的趋势或声音异常等情况时，应及时正确地判断出故障所在，采取果断措施，有效地控制事故发生，将故障消灭在初发。

2)轮机员必须严格按照船舶柴油机说明书要求，定期检查气阀间隙；避免运转时对排气阀的冲击力过大。

3)定期打开气阀盖，检查摇臂对气阀顶部的润滑情况，确保气阀顶部的润滑和冷却。

4)避免气阀密封面与阀座不同心，增加气阀受力不均匀。

研磨时应尽可能不在船舶航行或抛锚时研磨排气阀，如果条件允许，尽量在码头或专业厂家进行研磨工作。

5)轮机员要注意燃烧室零件的冷却，使零件温度保持在550℃以下，但冷却水温度不能调得太低以免热应力过大发生裂纹。

6)摇臂上的滑油喷嘴供油量可根据润滑面平均直径dm速度参数dmn图2中选择，确保供油量充足。

7)日常要加强对喷油器的维护管理，确保喷油器工作正常。

喷嘴雾化不良使得阀座表面结碳严重，造成阀受力不均匀；同时气阀温度分布不均匀而导致热应力过大，或阀盘 (阀座 )翘曲，使其承受了较大的弯曲应力。

8)在维修中，要严格保证阀杆与导管的配合间隙。避免串烟，导致阀杆温度过高，破坏阀杆的强度和硬度，从而引起高温疲劳断裂。

# 五 结语

由于排气阀顶端的润滑失效，导致柴油机排气阀频繁断裂，致使全船失电，是一起比较严重的机械故障。

为了船舶安全运营和船舶安全，作为1名轮机管理人员，要仔细查找故障原因，彻底解决故障，避免同样的故障发生第2次。
