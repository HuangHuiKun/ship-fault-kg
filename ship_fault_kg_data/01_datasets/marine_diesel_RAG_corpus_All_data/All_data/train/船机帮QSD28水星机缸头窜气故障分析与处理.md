# 导读

柴油机窜气一般分为“上窜气”和“下窜气”两种。

“上窜气”是指汽缸垫老化、缸体及缸盖接触面腐蚀变形引起的缸盖和缸体之间的密封不严、气门密封不严等原因，导致气缸中可燃气体从接触间隙窜到缸盖、缸体周围的冷却水道、油道的现象；下窜气是气缸中可燃气体通过活塞环与气缸的密封处泄漏到曲轴箱中的现象，活塞环窜气是由于缸套与活塞环之间间隙过大,以致活塞环张力不够紧贴缸套，所以柴油机在压缩冲程中有混合气从活塞环间隙中“窜”到曲轴箱,通常又叫曲轴箱窜气。

“上窜气”是柴油机的一种比较危险的故障﹐容易造成柴油机烧润滑油、冒黑烟、功率不足等问题，本文主要针对“上窜气”的故障现象进行分析、讨论并得出解决办法。

# 一、现状介绍

目前引航工作艇是上海港长江口引航作业区 接送引航员的主要交通工具，其中水星机工作艇共有17艘，发生“上窜气”故障（包括更 换缸头床垫后二次发生窜气故障）共计11艘次，现有工作艇总体情况见表1。

# 二、故障现象

从2018年始，在长江口引航作业区的QSD2.8 水星机引航工作艇陆续出现主机缸头窜气故障现象。

缸头窜气的故障表现为:

膨胀水箱冒气泡、水位上升，缸头上窜气冒黑烟，缸头与缸体结合处漏水、漏机油,转速不稳(下降）,机器有异响,机体抖动,无法达到额定转速和功率,最高航速下降等现象。

以29#工作艇为例，该艇建造于2016年1月份，2019年7月份在使用过程中发现进气端有放炮声音，膨胀水箱冒气泡，并伴有缸头冒黑烟和漏机油现象(工作时间1700小时左右)。

主机拆检之后发现气缸内有黑色烟道痕迹,即缸头床垫吹破之后窜气留下的印记。

另外，气缸内有水渍，并且进、排气管都有盐巴结晶出现。

说明空气中盐分含量很大,在气缸和进排气管内经过高温形成盐结晶。

经过对气缸体和气缸盖测量,发现QSD2.8柴油机缸体平面已变形,尤其是缸套台阶处变形大,说明此处长期受到高温腐蚀和盐化腐蚀，造成接触平面凹陷超过标准值，导致气缸体和气缸盖无法紧密压紧气缸床垫,造成了“上窜气”故障。

# 三、原因分析

此前针对“上窜气”故障没有仔细查找原因,简单认为是床垫问题引起的窜气现象，采取的处理方法是单纯更换缸头床垫，修复后使用时工作时间不超过30小时就会再次发生同样的“上窜气”故障，说明仅仅更换缸头床垫无法解决窜气的根本问题。

频繁发生类似故障后，引起大家对此故障的高度重视。

经过认真观察和分析,总结经验,最后判断造成QSD2.8工作艇柴油机“上窜气”故障的主要原因是:

1、高温腐蚀

(a)因海水泵叶轮损坏、热交换器水垢或水泵叶轮碎片进入热交换器导致外循环冷却流量不足等因素，造成机器冷却水高温后还高速航行等情况造成。

(b)引航接送作业过程中，引航工作艇频繁在大船之间靠离、穿梭,工作艇驾驶员操艇暴力操作,导致柴油机持续高负荷甚至超负荷运转,造成气缸高温腐蚀。

2、进气腐蚀

引航工作艇工作区域位于上海港长江口引航作业区,海面上方的空气混合着主要通过蒸发、海洋泡沫、海水飞溅等过程产生含盐量高的水汽，引起工作艇吸入空气中盐分含量高，进入气缸后遇高温结晶对缸体造成腐蚀。

3、盐化腐蚀

与使用环境有关,引航母船在遇到大风浪时会向港内开进入大风浪作业区,使用环境在淡水海水中交替，加速缸体腐蚀,工作艇舱底水也是海水,不及时抽干净也容易产生电化学腐蚀。

4、设计问题

QSD2.8水星机设计当初为了减少维修成本,设计4缸上安装分体式缸盖而不是一体式缸盖，结果导致缸盖、缸套和缸体配合密封面( 6mm)太小,无法承受更大的爆炸压力﹐容易造成床垫被吹﹐形成“上窜气”。

不过分体式缸盖除了有维修成本低的优点,还有利于散热，并减少缸盖因受热不均引起的缸盖变形等优点,如何增加缸盖与缸体的配合密封面，改进缸盖的合理设计也是一个值得探讨的问题。

# 四、处理方法及效果

缸体头部变形主要为高温变形和平面腐蚀为主。

查看说明书，发现缸套台阶要高于缸体平面在（1丝-5丝)之间,受到高温及盐化腐蚀变形,现接触面已超差，变形量超出标准要求,缸体平面需磨下15丝(0.15毫米)才能磨平,达到要求(表2)。

注意事项：

如果重磨一只气缸盖，则其余气缸盖和气缸盖端面承压板也应重磨，磨削量应相同。

制定好修理方案之后，上镗床机对气缸体表面进行机械加工,磨掉15丝,加工精度要求IT6,表面粗糙度要求Ra0.2 。

经过加工，整个燃烧室长度略微变化(缩短0.15mm),根据压缩比计算公式:

ε= Va/ Vc

其中:

活塞处于下止点时气缸有最大容积,用Va表示;活塞处于上止点时气缸内的容积称为燃烧室容积，用Vc表示，压缩比为ε。

经过测算（燃烧室长度缩短0.15mm ),加工后压缩比为16.8左右﹐原压缩比16.5 ,变化不大,符合要求(见表3)。

另外，更换活塞环、缸套、缸盖等配件,对机油路进行清理和更换损坏的配件，对增压器进行清洗和检修，装复后试车正常。

目前,此艇已在引航接送工作中正常使用100小时以上,状况良好。

经过此次维修,以较小的维修代价延长了工作艇的使用寿命,相应降低了运营成本,达到了预期效果。

# 五、改进方法及建议

经过多年对QSD2.8水星机工作艇主机维修保养的实践和经验积累,对该类型主机“上窜气”故障的检查判断总结出了一套行之有效的维修办法。

同时,对于减少和避免该故障的发生也总结提出了相应的改进方法和建议。

(1)避免野蛮暴力操作。

规范工作艇驾驶员操艇方式，避免从怠速急加速至满负荷和从正车不经停顿直接拉倒车操作，避免柴油机长时间满负荷甚至超负荷运转,减少工作艇主机缸内高温。

(2)提高预控管理水平。

缩短海水泵和热交换器的维护保养时间,比规定保养时间提前50工作小时更换海水泵叶轮并清洗热交换器，避免因海水冷却量不足引起主机高温。

(3)减少盐化腐蚀影响。

过滤含盐空气。

在保证进气量的前提下,改变气道进气走向，让进气经过滤网并与气道内隔板多次碰撞接触﹐降低机舱内部空气含盐量。

控制舱内干燥。

经常抽干艇内舱底水，减少舱内含盐水分蒸发,控制相对湿度，保持机舱内空气干燥  [2]  。

(4)改进缸头设计方案。

向水星生产商建议，探讨改进QSD2 .8水星机缸盖的设计方案，设计出—种新型缸盖，既要保留分体式缸盖的优点，又可以增加缸盖、缸套和缸体之间的配合密封面,增加缸盖强度，可以承受更大的爆炸压力和燃烧室温度，减少窜气故障的产生。

# 六、结束语

造成柴油机“上窜气”故障的原因有很多,其中有设计上的缺陷，也有日常保养不到位和使用操作不规范的因素,遇到此类故障需要运用多种方法,综合考虑多种因素,以预控为主，维修为辅的方案,采取最有效的方法,解决此类故障。
