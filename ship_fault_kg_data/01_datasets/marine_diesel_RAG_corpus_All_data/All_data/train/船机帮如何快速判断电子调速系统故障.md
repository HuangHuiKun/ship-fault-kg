# 导读

电子调速系统核心是电子调速器，电子调速器主要通过单相电机运行进行工作，工作原理主要是通过改变接入绕组的电阻和电容等来调节电机的转速，速度的高低对电源供电功率的输出不产生影响，因此这不是一种比较节能的调速方法，但康明斯柴油发电机的电子调速系统却有自动化高，操作复杂的特点。

这对故障的排查也提出了很高的要求，要快速地进行故障排查研究，就要充分了解电子调速系统的工作特点，进行故障研究诊断。

# 一、系统工作原理

康明斯柴油发动机的PT(G)型燃油系统，一般是EFC电子调速器。

调速器EFC运转灵活，可同步运行，也可转速运行，具体的操作控制图如图一所示。

图1 控制电路原理图

飞壳上是电磁转速传感器3，飞轮齿圈用来感应发动机的转速。

PT泵里是执行器2，执行器转动是由电流的变化引起，发动机的转速和功率就这样被改变了。

J5第七格的开关闭合时，J1的第一格会输出24V的电压，PT 泵电磁阀开关开启，EFC调速器4进行工作，又控制器2的转轴转到最大的控油位置，与此同时，CPU 第三脚启动信号到达并启动马达，发动机启动。

启动后，发电机的中点(N)的电压意味者已经启动，若使发动机停止工作，则通过J2第三脚输入CPU控制板来切断J1第三脚的输出信号。

如果这样启动，一次不能成功，10 秒后再次启动，如果这样三次都不能启动成功，发动机会停止启动，故障灯亮。

发动机正常地启动运行后，发动机工作的各种数据会通过J3插座输入到CPU板，由J4发出各种警报，按J5的按钮进行CPU的复位，然后进行各种警报测试，如果警报灯都亮，则警报系统正常，发动机的转速和功率的改变是通过调速器的电讯号和现有的参考点(W2)相比，差压电流信号输出，执行器2来控制进入喷嘴的燃油量。

# 二、故障诊断及解决方法

## 1、发动机不能启动

出现这类故障的原因有些是和电子调速系统的运行和操作是有关的，但是主要还是发动机自身的一些问题，解决措施也比较简单易懂。

一日出现发动机不能启动的状况首先想到的就是邮箱没有油或者是油箱的开关没有打开，解决的措施就是加油或者打开开关。

无燃油进入缸盖也会造成发动机不能启动，发生这种情况在启动马达时松开缸盖上的燃油管，检查止回阀。

第三可能是燃油不能经过油泵上的电磁阀，解决时要手动打开电磁阀，检查控制电磁阀控制电路。

第四是没有燃油通过正常关闭器2，主要检查执行器2的电源，检查控制器4的输入输出电源。

第五是不能正常打开或关闭执行器2，出现这种故障需要更换执行器2或更换控制器4。

还有可能在执行器和控制器都正常的情况下，没有转速传感器信号，这是需要检查线路和传感器的安装位置，或者更换转速传感器3。

## 2、发动机游车

发生此类故障的原因可能是燃油中有空气，解决时在油路中装玻璃管，排除空气即可。

EFC调速器没有调好，按照调速器的调整方法重新调配，或者减少增益。

还会出现执行器2发卡,解决时松开固定螺栓，按要求重新拧紧，或者更换执行器，但是如果执行器本身存在问题，这时需拆下EFC的控制器到执行器上的导线，通过电瓶与执行器直接对接，然后启动发电机，如果此时发电机还以低速运转，就要更换执行器了。

燃油泵有问题也会造成发动机游车，因此就要更换燃油泵。

会有24V的供电系统低于19V，就要向电池充电了，若是向电池充电的发电机没有直接接到电源上，就要及时把发电机电枢线直接接到电源上即可。

## 3、发动机高速运转

发生这类故障的原因也有很多，可能是转速调得太高了，参照正确的调速方法进行转速的调节就可以了。

可能是控制器选择错误，就要看看控制器是否与机型匹配了。

还可能是控制器三、四脚上的输出电压高于19-20伏，检查一下如果导线没有问题，就更换控制器。

若是执行器上的电压高于19-20伏，还是检查一下导线，如果有必要的话，更换一下控制器，还可能是执行器.上的O型圈有问题，检查一下，看看是否需要更换O型圈。

## 4、发动机功率较低

功率低主要还是控制方面的问题，主要故障原因可能是控制器的输出电压低于19-20伏，检查一下，看看是否需要更换控制器。

还可能是燃油泵和喷嘴油调校不正确，需要正确调校燃油泵和喷油嘴，燃油系统有问题也是造成这一故障的原因之一， 需要检查并排除燃油系统的故障。

## 5、发动机低于怠速运转

出现这种故障的可能性比较小，可能的原因是W1或W2没有调试正确，发生故障时，只需重新调试一些就行了。

# 三、系统调整

系统调整主要是运用EC调控器4上的四个电位器。

主要先经过初调然后再进行系统调整。

初调的过程是: W1\W2 分别反时针转动二十圈再顺时针转动十圈，W3刻度至五十度，主要是用来调整灵敏度。

初调好了之后就是主要的系统调整了，这是避免故障和辨别解决一些故障时的关键。

分为怠速调整、转速调整、增益调整、转速降调整、系统调整这几个步奏。

怠速调整是将开关调至怠速位置，启动发动机，调W直到转速在六百至六百五十转每分钟之间。

转速调整是指将发动机开关调至运行位置启动发动机空载运行。

增益调整是加大约四分之一的负载，如果转数稳定，则顺时针调整W，如果转数不稳定则逆时针调整，一直到转数稳定为止。

转数降调整是启动发动机加额定负载，调W4至一千五百转每分钟。

系统调整是上述四部完成之后，再进行第二部的调整，以此反复三四次而达到确定值为止。

# 四、快速诊断故障的实例

一台美产310kW发电机组的CUMMINS发动机，在起动之后转速明显不稳定，但不一会儿起动马达它又重新启动工作，还出现打齿现象，接连自起动三次后，发动机突然熄火。

按开关重新运行，还会出现上述的故障，根据电子调速系统的工作原理来分析情况，发现，电子调速器、发动机、控制电路等都工作正常，故障的原因是发动机控制的中点(N)。

由于在发动后，用万用电表测CPU电板的J2、J3脚电伏都为零，并且导线没有问题，检查后发现是发动机控制中点脱焊，重新焊接之后，故障消除，正常运行。
