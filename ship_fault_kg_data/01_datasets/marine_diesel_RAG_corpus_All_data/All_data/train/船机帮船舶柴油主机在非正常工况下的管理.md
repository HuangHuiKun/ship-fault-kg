# 导读

柴油主机是船舶的心脏部位，它是否正常运转关系到船舶的正常航行及人命财产的安全。

柴油主机的起动、加速、减速、换向和停车，在正常航行工况下操作步骤是简单的，但船舶在航行过程中常常会遇到各种情况即非正常工况下的航行，我们知道非正常工况分:

阻力变化工况(包括系泊试车、船舶拖带、排水量改变、浅水航行、窄水道航行等) ;过渡工况(包括急加速、紧急倒车、急转弯、大风浪航行等) ;特殊工况(部分主机工作——对多主机来说)。

# 一 阻力变化工况

## 1. 系泊试车

这时航速V=0, 船只不动，阻力最大。

例如某船当航速V=0, 主机转速n=420r. p. m时，已接近全负荷，经计算这时负荷与正常工况同主机转速下功率要多1.5倍。

所以船舶系泊试车额定转速n系泊额定= (60-70%) n额定。

这就告诉我们在管理中应注意:

冷却水的排出温度、润滑油温度和排气温度应在主机说明书的范围内;严格控制转速，当提高转速时，要注意在规定参数内运转;最好在码头顺流时试车(如果逆流试车负荷将更大)。

## 2. 船舶拖带

在拖带工况情况下，这时阻力上升，船速下降。

柴油机在正常工况下，有余功区，可利用余功进行拖带。

首先了解被拖船(物)阻力与航速的关系，与本船螺旋浆特性、柴油机工作范围、余功大小、余功使用情况进行比较，尽量在拖带时本船主机不超负荷。

如果船上没有被拖船(物)的航速和阻力关系曲线，可以用本船系泊额定转速n=(60-70%) n额定，同时注意主机排气、油、水的温度及噪音情况，如拖动才能一点点地加速，当最高爆发压力Pz和排气温度接近于额定值时，这时n就是最大拖带转速，同时工作时注意机器的工作状况。

但要注意:如果船不动就不能加速;还要注意风浪影响;拖带的缆绳长短适宜。

过长易缠住自己的螺旋桨上，过短则拖带不稳定或翻船。

## 3. 排水量改变

若排水量增加，水下部份浸水面积扩大，则阻力上升。

排水量增加10%，则主机负荷上升6%，所以满载、超载时，主机不能开到Nh (最高额定转速)。

轻载时，浸水面积减少，主机负荷减轻，应防止在风浪情况下螺旋桨露出水面，造成飞车。

当航道宽度小于20倍船体宽度时，则航行阻力增加，当航道宽度等于10倍船体宽度时，则航行阻力增加10%左右，如果遇到窄且浅的航道(通常航道窄时一般也是浅水)，二个因素同时起作用就更明显了，因此在窄航道中航行时，一定要注意适当降低船速( 即降低主机转速)，防止主机超负荷工作。

# 二 过渡工况

## 1. 急加速

如果主机转速由低速很快加速到额定转速时，但由于船舶惯性大，则使阻力矩增大，船速V一时还上不去，调速器起作用，会使油量加到最大，而形成超负菏，使排气温度大大地上升，最高爆炸压力Pz也大大地增加(使机器强载现象)，由于主机润滑油、冷却水温度一时跟不上，形成热应力迅速上升，润滑情况变差，机械冲击负荷很恶劣，所以使用加速时应注意，不需要急加速最好逐步加上去，等新转速稳定后再加新的转速。

## 2. 紧急倒车

当倒车前高速航行时，由于航速高产生的负转矩也大，要使螺旋桨转速等于零，则刹轴的力量更大，而当倒转时，正航速还很高，水对螺旋桨的转矩和倒车反转矩方向正好相反，所以作用在螺旋桨的反转矩就更大。

又因为螺旋桨迎水面与背面形状不一样，所以在同样转速(航速)下产生的反转矩要比正车消耗转矩更大，所以倒车不能开到额定转速(应在75%~80%额定转速之间)，倒车时主机转速不能加得太大，如要倒车则应在正车负荷减低至50%时再进行换向，最好在低航速下倒车。

如紧急倒车易产生:把主机憋停;离合器、刹车带易消损;油喷的传动套简及卸油螺钉易损坏;倒车后螺旋桨转速上升过快易产生超负荷。

## 3. 急转弯

当急转弯时，则回转半径小，舵打向内侧使水流阻力上升,舵附加阻力转向后,使内侧迎水(多了横向阻力)，所以在回转时船舶总阻力上升，机器负荷增加，船在转向时，水流对向内侧螺旋桨，则对内侧水流速度减慢，而外侧水流速度加大，因此急转弯时要防止螺旋桨超负荷，急转弯时一般控制在主机转速n主机=85- 90%n额定。

## 4. 大风浪航行

当船体在大风浪的作用下将产生剧烈的纵摇和横摇，螺旋桨处于不断变化的斜流中工作，引起螺旋桨转矩和推力的不断变化并使其负荷变重或变轻，螺旋桨有时会部分地甚至全部露出水面然后又深埋入水中，造成了柴油机的突加和突卸载荷，为防止超负荷和可能产生的飞车事故，应当降低转速使用，一般控制在0.8 -0.85 n额定转速。

# 三 特殊情况（有多个螺旋桨，而只有部件螺旋桨工作）

对于部分螺旋桨工作，因为船舶阻力要部分工作的螺旋桨承担。

对不用的螺旋桨刹住或不刹住都会产生附加阻力。

刹住比不刹住产生的附加阻力大4倍，不刹住则根据船速不同，停螺旋桨数不同而变化，一般为船阻力的5%-30%，所以在管理上、在条件允许下应让不用的螺旋桨自由旋转(或脱开离合器)，注意如不能脱开，要正转拖带柴油机，因为要考虑柴油机润滑油水泵的正常运转。

# 总结

通过对柴油机在非正常工况下的分析，使我们对这些问题有个全面的了解，在船舶航行时根据各个工况的特点进行管理，那种不考虑外界条件的变化，而过急地、盲目地增加供油量，轻则会使主机经济性下降，重则会使主机发生超负荷或飞车而受损，为此，轮机人员除了必须掌握柴油机的构造特点、维护保养、检修调整等方面知识的同时，还要熟知有关主机运行的重要特性曲线，达到正确、熟练操纵柴油主机。
