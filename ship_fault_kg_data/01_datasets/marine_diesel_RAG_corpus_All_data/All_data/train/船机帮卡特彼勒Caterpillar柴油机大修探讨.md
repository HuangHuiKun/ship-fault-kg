# 导读

海洋钻井平台是海上油气勘探的利器，但运行费用高昂。

柴油机是动力来源，合理使用、维护柴油机不仅有利于柴油机安全稳定运行，而且能降低维修成本。

绝大多数设备使用者采用生产厂家推荐的累计运行小时数作为柴油机大修周期量化指标，而忽略了厂家另一推荐量化指标——燃油总消耗量。

这一指标对于钻井平台等受限于工况而负载率普遍较低的柴油机来说至关重要，可大幅降低柴油机单位时间内的维修成本。

# 一、确定大修周期的因素

## 1、大修指标分析

柴油机大修有两种判别方式：

一种是计划外修理，观察柴油机的运行状况随机确定大修时间，一般是使用中出现柴油机功率不足、排烟发黑、曲轴箱下排气明显变大等现象，再参考运行时间安排大修。

大修周期可以延长，但周期内故障率较高，甚至可能发生重大故障。

另一种方式是计划内修理，即根据生产厂家建议的运行时间或某些参数达到大修某一指标时安排大修，以在一定程度上降低机器故障率，适用于机器故障会造成较严重后果或较大经济损失的大型设备集成，如航运船、钻井平台等，以下仅对这种情况进行讨论。

美国卡特彼勒公司(Caterpillar，简称CAT)对其生产的卡特柴油机制定了以下大修指标：

(1)总燃油消耗量。

(2)累计运行时间。

(3)润滑油消耗：

润滑油消耗单位为g／kWh，当润滑油消耗量达到正常值的3倍时，预示柴油机大修时间已到。

这需要日常维护时做好记录，统计相关参数才能获得数据。

而且负载高时会明显比负载低润滑油消耗大，对比时只能参照负载相近时的数据，且要排除柴油机异常故障消耗，需要长时间的数据收集和丰富的现场经验判断，难度相对较大。

(4)曲轴箱下排气：

曲轴箱下排气变化可通过压力显示或透气口烟雾判断，下排气增大可能因为缸套、活塞磨损超标；也可能是运转部件异常，引起润滑油温升高。

结合运转时间，排除出气口不畅、传感器故障等异常的因素，方能判断是正常磨损引起还是异常因素作用。

(5)油样分析：

在更换润滑油时取样分析，可以量化润滑油中金属微粒的含量和种类，判断是否存在异常磨损、异常磨损的部位和磨损程度。

但这样的磨损是由于柴油机某一运转部件故障引起还是所有运转部件使用时间较长状况不佳而导致金属微粒含量增加，普通客户是难以判断的，需要专业工程师根据设备运行时间、油样分析中微粒种类、数量作出综合判断，以便决定更换某一运转部件或整机大修处理。

(6)机器振动和噪声变大：

噪声和振动变大预示着运转部件的状况异常，存在运转部件松脱、配合间隙超标、异常磨损等现象，同样需要专业工程师通过运行时间、传感器检测参数分析等判断是正常磨损超限还是故障引起的振动，排除异常故障因素方能作为大修指标。

# 二、合理订购大修备件

(1)卡特柴油机生产厂家只负责技术和生产，维修服务由指定的代理商承担。

代理商所列大修备件清单包含所有可能损坏的备件，部分备件非厂家要求必须更换件，须客户根据现场使用状况逐一核对，确定大修备件清单。

(2)缸套、活塞等高价值备件生产厂家均有详细的书面更换标准，满足再使用要求的缸套、活塞均可以处理后再次使用，不能单纯听从修理厂家要求。

(3)部分增压器、水泵等组件生产厂家不再提供修理包，推荐使用翻新件。

理论上来说，经过厂家翻新的部件检验合格后使用一个大修周期没有问题，实际使用效果需要长期收集统计数据，得出可靠结论。

(4)喷油器厂家推荐的使用寿命是一个顶部大修周期，一台柴油机全部更换新件需要32万元左右，但实际使用至第二个顶部大修周期，大多数喷油器可以正常工作(可能也与钻井平台负荷系数低有关)，仅这一项可节约大量修理费用。

# 三、大修注意事项

(1)柴油机缸盖修理过程中需使用较多专用工具，为了保证修理质量，维修厂家一般会考虑运回厂家车间修理。

这对于钻井平台等海上设施增加了运输工作，延长维修时间。

为此，生产厂家推出了翻新缸盖(回收旧缸盖)，可节省维修时间，费用与缸盖修理相差不大。

(2)翻身大修在具备条件的基础上，尽量回修理厂车间修理。

因为相较现场修理，回修理厂车间检查更全面，油道清洁更彻底。

(3)大修检查和部件更换必须详细记录，可能需在下个修理周期更换的非易损件需注明，申购备件时避免漏订，进口件到货周期较长，一旦漏订将影响修理周期。

(4)大修后的柴油机回装到位后，必须测量曲轴轴向窜动量。

曾有柴油机大修后运转几十小时后曲轴断裂，厂家检查判断是柴油机回装后曲轴受附属设备干扰，无轴向窜动间隙，导致曲轴扭断。

(5)现场修理时，机器的防护非常重要。

例如某平台在两台柴油机中期大修时，由于防护不到位，船厂喷砂除锈的杂质进入润滑油道，导致两台柴油机修复不长时间即相继发生了拉缸事故。

(6)卡特柴油机按生产厂家标准修复后可以达到额定功率，具备试验条件的可以按照额定负载进行负载试验。

# 四、结语

卡特柴油机大修费用高昂，通过合理制定大修周期和选择大修备件，可以节省大量维修费用。

对于因工况所限总负载率较低的柴油机，建议按照燃油消耗量确定大修周期，从而可以适当延长大修周期。

无论是按照总燃油消耗量还是运行时间确定大修周期，都需要避免人为造成的低负载运行。

因为长期低负载运行不仅增加燃油消耗量，而且消耗了柴油机运行时间，相应缩短了大修周期。

钻井平台工况的特殊性决定了其负载率不会太高，但实际使用中发现还存在钻台与机舱沟通不及时造成的人为低负载运行，新型钻井平台、航运船舶等都有一套完善的功率管理系统，在超载时会自动启动备用柴油机并自动并网供电，即使备用机无法立即补充供电，也会自动限制部分设备功率，避免电网过载断电。

这些安全防护措施可以使柴油机大胆运行在较高的负载状态下，降低运行成本也延长了单位时间内柴油机大修周期。
