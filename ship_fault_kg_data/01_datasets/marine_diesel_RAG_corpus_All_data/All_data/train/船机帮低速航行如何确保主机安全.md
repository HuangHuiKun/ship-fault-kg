# 导读

船东为了降低营运成本，纷纷采取降低航速的举措，选用降低负荷来达到降低日燃油油耗量的目的。

船舶大型低速主机降低负荷运转，给船舶轮机的管理带来了新的挑战。

那么，如何解决降低负荷运转可能带来的一系列问题，以及机务管理人员及船员如何使用才能保证船舶的安全运行便成了业界普遍关注的问题。

## 一、低速航行常见问题

实践证明，大多数主机部件不做任何改变，可以在25%至30%额定负荷下稳定运行，但长期运转会影响主机工况，因此需要在管理上采取一定措施，确保机器能够正常运行。

如果主机长期运行在25%额定负荷以下，甚至在10%额定负荷以下，则需要对某些部件进行改造，否则可能会造成主机工况迅速恶化甚至造成机件损坏。

主机低负荷运转时可能遇到的问题通常表现为：

1. 燃烧质量降低造成主机燃烧室部件、增压器喷嘴环和叶片、废气炉烟管和烟囱积炭加重；严重时会造成烟筒着火，可能造成废气炉管子因局部过热变形造成漏水；
2. 主机气缸润滑情况变坏；
3. 主机辅助鼓风机出现故障；
4. 主机轴承润滑不良，磨损量增大；
5. 主机低温腐蚀；
6. 主机扫气箱止回阀损坏；
7. 气缸下部扫气室油渣增加，扫气箱着火；
8. 由于主机长期低负荷运转使运动部件磨损加剧，维修保养周期缩短，增加维修费用和备件费用。

## 二、问题原因剖析

1. 燃烧质量降低造成主机燃烧室部件、增压器喷嘴环和叶片、废气炉烟管和烟囱积炭加重，由于转速低，每个工作循环的注油量少，使得喷油雾化质量变差；同时，由于负荷小，远离废气涡轮增压器的最佳工作点，效率会大幅度降低，增压压力低，从而导致燃烧不充分；低负荷运转时，气缸和排气阀漏气量加大，压缩压力减小，气缸内温度减低也会引起后燃。由于燃烧不好形成积碳在活塞、活塞环、增压器喷嘴环、透平叶轮、和废气管路管子内沉积，加剧了活塞环、活塞和缸套的磨损，影响气缸密封使漏气加剧、主机排出背压加大增压器效率进一步降低，使得主机工况逐渐恶化。
2. 主机气缸过度润滑：对于机械式汽缸油注油器，由于汽缸油的注油率是和转速成正比的，而负荷的减少和转速的三次方成正比，若注油器设定不变，主机低负荷运转时的注油量会超出该负荷下的需要量，这样会显著增加主机燃烧室部件的积炭，增加运动件的磨损。对于ALPHA电子汽缸油注油器，当主机负荷大于25%额定负荷时，汽缸油的注油率随负荷减小而减小；但在主机负荷小于25%额定负荷时，注油率不随负荷减小而减少，这时汽缸油的注油量会偏大。
3. 主机辅助鼓风机故障：当主机低于40%额定负荷运转时，辅助鼓风机可能长期运转，如果保养检查不及时，会使泄放孔堵塞，从而造成马达轴和轴封磨损。如果辅助鼓风机长期在接近停止运转的主机负荷下运转，辅助鼓风机马达工作电流会较大，当主机负荷变化时还可能造成频繁启动，容易造成鼓风机马达绕组因过热而烧坏。
4. 轴承润滑问题：由于转速低，轴承动力润滑油膜建立相对困难，油膜容易被破坏，在低转速下轴瓦的应力点也会发生变化，容易在油楔边沿可能产生疲劳破坏。
5. 低温腐蚀问题：由于低负荷运转时气缸平均温度会较低，如果扫气温度控制不好，会产生冷凝水并和燃烧产物中的SO2反应生成亚硫酸，造成气缸套低温腐蚀。
6. 扫气箱止回阀损坏：低负荷运转时，由于扫气压力低，活塞运行中会产生压力波，可能造成扫气箱止回阀频繁开关，容易使止回阀损坏。
7. 由于低转速运转时未燃烧的碳粒增加，且气缸漏泄加重，加上过量润滑，导致掉到气缸下部的扫气室油性颗粒增加，如果检查和清理不及时，容易出现扫气箱着火事故。
8. 由于长期低负荷运转造成燃烧不良，产生积碳，同时由于转速降低，运动件相对运动速度降低，气缸润滑条件恶化，使活塞、活塞环和缸套的磨损加剧，轴瓦和轴的磨损也会变大，使得保养周期缩短维修费用增加。由于燃烧不好，排温高，燃烧室、增压器喷嘴环和锅炉管子的积碳增加，使高温腐蚀加剧，也会造成机件的寿命缩短。

## 三、正常运转的建议措施

主机在45%额定负荷以上运转时，针对船舶柴油机低负荷运转时可能出现的上述问题，根据我们多年的工作经验及相关理论，建议采取以下方面的应对措施：

考虑选择合适的经济航速，尽量使主机长期运转在45%额定负荷以上，这种负荷下废气量能够使主机涡轮增压器正常运转，主机辅助鼓风机不会启动，而且能够保证辅助锅炉有足够的废气量来产生船舶需要的蒸汽，不必要使辅锅炉点火运行，以免产生额外的锅炉油耗。在这种情况下，主机不需要采取特别措施，只是简单地采取如下运转管理措施就可保证主机正常工作：

1. 适当减少汽缸油注油量，防止过度润滑；定期进行扫气箱污油取样化验，分析污油的剩余减值间接判断汽缸油注油率是否合适；根据扫气口检查结果判断注油量是否合适；
2. 保持扫气温度45-50度，尽量提高冷却水温度，减少低温腐蚀；
3. 每天保证主机在设计工况下运转1-2小时，冲洗增压器和废气炉，防止烟灰沉积；
4. 增加主机和增压器的参数监控频次，注意废气锅炉前后压差的变化，以判断废气锅炉烟管的脏污程度，如压差过大，应及时清洁；
5. 增加主机扫气口的检查次数和清洁次数；
6. 大风浪天航行，主机转速和负荷剧烈变化时，采取措施防止主机辅助鼓风机频繁启动。

主机在30%额定负荷以下运转时，当主机长期运转在30%额定负荷以下时，除了采取上述常规措施外，还应采取如下措施：

1. 经常检查辅助鼓风机的运转状况，尤其是检查泄放孔有没有堵塞，定期检修辅助鼓风机，防止主机辅助鼓风机频繁启动。
2. 气缸润滑：对ALPHA电子注油器，可以使用直径小的活塞或减小柱塞行程，对机械式注油器可以根据扫气口检查结果适当调小注油量。为保证润滑注油率不能太小，汽缸油的剩余碱值就会偏大，尤其是20%负荷以下时，为减少积碳产生又能保证良好的润滑，考虑采用低碱值汽缸油；因为如果汽缸油注油率过大，汽缸油的剩余碱值会偏大，在燃烧室内和排气通道内会增加坚硬的白色沉积物，会加速运动件的磨损率，如果注油率过低不利于气缸良好润滑。
3. 改善燃烧质量：对于有两台以上增压器的主机，可以考虑切除一台增压器，以增加剩余增压器的工作效率，从而增加扫气压力；可以采用变喷嘴环的增压器和废气旁通，增加主机低负荷时的扫气压力；改进喷油器喷油嘴的设计，比如更换直径较小的喷油嘴，改善雾化质量；适当调整喷油提前角，减少后燃的发生。可以考虑在连杆大端增加垫片，提高压缩比；如果长期在低负荷下运转还可以考虑更换增压器改变主机最佳工况匹配点，提高主机整体效率；
4. 增加白合金轴瓦的检查频率，用内窥镜对轴承状况进行附加检查；注意观察轴承温度的变化。
5. 到港后打开废气锅炉道门进行检查，防止烟灰过量沉积，烟灰燃烧，造成锅炉管局部过热而烧毁。经常进行主机扫气口检查和扫气道清洁，尤其注意检查清洁止回阀有无裂纹，开关是否灵活。
6. 主机在低负荷运转时，工况会发生改变，只要采取合理措施就能有效避免主机发生故障，保证主机正常运转。

同时，在不改变机件的情况下，船东应尽量采取保持主机在40%额定负荷以上运转的策略，同时给船舶合理的指导，加强管理，避免因降速航行而对主机产生不良影响。
