# 船机帮气门漏气的原因与防止办法

进排气门都是配气机构的重要零件，它根据柴油机工作过程的要求，定时开启或关闭进排气道，从而完成换气过程。

若进气门漏气，该缸进气歧管温度高一些；若排气门漏气，高温高压气体由此窜出并伴有“吱吱”的响声。

漏气将导致柴油机功率不足，油耗上升，排气冒黑烟，曲轴箱窜气等不良后果。

## 气门漏气的原因与防止办法

1. 气门间隙过小，柴油机保养维修时，气门间隙调整过小，当运行过程中，机器温度升高，致使配气机构受热膨胀，造成活塞压缩行程气门关不严。为此必须定期检查气门间隙，并按规定数值调整。

2. 气门弹簧经过长时间使用，气门弹簧的弹力会逐渐减弱致使气门与气门座不能严密贴合。所以应定期检查并及时更换软化失效的气门弹簧。

3. 气门与气门座的密封面由于磨损，烧坏或变得粗糙产生麻点而密封不严。应重新研磨，必要时更换气门座圈和气门。

4. 缸内积碳严重，若缸内窜机油或燃烧不充分，产生积碳粘附在缸套、活塞、气门与气门座密封面上致使气门关闭不严而漏气。应定期拆下缸盖清除积碳。

5. 配气定时不正确。定时齿轮是配气机构的关键零件，若齿面磨损严重或安装不当，会使配气定时出现偏差，导致气门漏气。应定期检查，正确调整。
