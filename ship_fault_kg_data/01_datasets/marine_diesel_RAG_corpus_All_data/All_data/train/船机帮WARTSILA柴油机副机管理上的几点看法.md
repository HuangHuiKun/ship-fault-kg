# 导读

WARTSILA是世界著名的船用柴油机品牌，前些年在船舶上使用很少，轮机人员对这种柴油机作为船舶副机的认知远不如日本的大发、YANMA等品牌。

近年来，我司船队规模不断扩大，新造船舶不断增加，特别是新接的VLCC型船舶几乎都采用了该品牌的副机。

尽管WARTSILA品牌副机拥有管理方便、技术性能高等优点，但同时也有它固有的缺陷，加上使用时管理维护不善，在某些船舶上也出现了数起因燃油凸轮滑移，机带泵轴断裂，高压油泵柱塞咬死，进排气阀阀杆腐蚀、弯曲甚至断裂而引起的重大机损事故。

为此，笔者结合一些事故的调查结果和厂家的技术要求，以及本人的工作经验，特别归纳出该机型副机的一些管理要点，期望对WARTSILA副机的使用和管理水平能上一个新台阶。

同时，此管理要点也基本适用其他品牌中高速柴油机，大部分原理都是相通的，大家可作为参考。

# 一、启动前的检查

（1）做好启动前的各种检查：

滑油油位是否正常，燃油及冷却水系统管系除气，燃油及高、低温冷却水系统温度是否合适，启动空气压力超过7.5 bar，启动空气放净残水，各控制系统电力、空气供应正常。

（2）当副机停用较长时间或大修刚刚完成后，除启动预润滑油泵润滑外还应首先对空气分配器、调速器的传动机构、进排气阀杆、摇臂机构进行手动注油，并且在预润滑泵运转期间检查确认连杆大端轴承、主轴承、摇臂轴等各关键部位有适量的润滑油供应。

（3）启动前还应盘车，至少要盘车两圈以上，并且在盘车过程中特别注意检查是否有卡阻现象。

盘车有助于提前发现或预防一些事故。

# 二、启动

（1）启动方式分机旁手动启动和遥控自动启动两种方式。

为了安全起见，即使是自动化机舱也应尽量避免在集控室直接启动副机。

启动前还要提前进行冲车，检查示功考克是否有异常吹出物。

（2）在启动副机时，如发现副机不能很快越过共振转速，应马上停车查明原因后再启动，切忌让副机长时间在共振转速范围内运转。

诸如一些凸轮滑移及机带泵轴断裂事故极有可能在此期间发生。

（3）如果机体启动前没有很好预热，启动后必须至少运转15min后方可加至全负荷。

（4）在副机启动完成、一切正常后将控制开关转至自动位置。再进行配载供电。

# 三、日常管理

## 1、备用副机每两天盘车，使曲轴处于新位置

这一基本的要求通常为大多数人所忽略。

但就 WARTSILA副机而言，每两天盘车一次，其作用对于副机的管理和维护至关重要。

（1）每两天盘车一次，使曲轴处于一个新位置，从而避免曲轴始终处于一个位置而引起曲轴产生变形的可能。

（2）因为副机在备用状态下，预润滑油泵运转，总有几个凸轮销的注油量处于最小状态，而且，由于燃用重油（IFO380），凸轮轴油使用系统油，油泵漏油直接进入油底壳，所以副机系统油污染较重，对于长时间处于最小供油量的凸轮而言，其内部油孔很容易堵塞。

经常盘车，对于防止凸轮销油孔堵塞作用很明显，可以最大程度地防止凸轮和滚轮损坏。

（3）由于燃用重油，并考虑高压油泵的结构，处于停机状态下，高压油泵的回油腔内始终存有燃油，在120℃的温度下，这些相对静止的燃油很容易蒸发结炭，从而使柱塞和套筒粘连，造成高压油泵卡阻，轻则造成单缸断油（卡在上死点），严重时损坏凸轮或滚轮。

（4）经常盘车，还可以检查汽缸内的状态（是否有漏油漏水现象），便于及早发现问题，防止事故的发生。

## 2、保持合适的冷却水温度

由于燃用重油，硫分较高，燃气中的硫化物相应较高，如果冷却水温度太低，一方面影响副机的热效率，另一方面容易在汽缸内产生冷凝水，从而与硫化物结合产生硫酸，对缸套、活塞和缸盖等部件产生腐蚀，甚至影响系统油的碱值。

缸套冷却水的温度一定要按说明书的要求控制在90℃左右。

## 3、保持透平增压器和空冷器的正常工作

透平工作的效率如何，直接影响到柴油机工作效率的发挥。

因此，透平的日常维护管理对于柴油机而言至关重要。

透平是高速运转设备，而且工作环境恶劣，一定要严格按照说明书的要求对其维护保养。

对于ABB透平而言，每50h对压气端进行注水清洗（要求副机负荷在60%左右为宜），每250h对废气端进行冲洗，冲洗程序和要求（水量和冲洗间隔）应严格按说明书要求进行操作，防止透平损坏。

另外，WARTSILA副机各缸排烟温度相差较大（服务商称允许在100 ℃的温差范围内使用），除高压油泵和汽缸、活塞的原因外，透平喷嘴环的脏污状态也是影响各缸排烟温度不均的主要原因，特别是在副机空载或小负荷运行状态下尤为突出。

同样，对于空冷器，一定要按要求的周期进行清洗，保证空冷器的冷却效果，从而保证充足的空气供应量和合适的进气温度，使柴油机良好燃烧，充分发挥其效率并减少排气污染。

## 4、对高压油泵的维护保养

高压油泵的维护保养对于一台柴油机而言同样十分重要。

高压油泵工作情况的好坏，直接影响到柴油机的工作状态，同时，高压油泵内结炭、卡阻，还会直接导致凸轮轴损坏，从而使柴油机彻底瘫痪。

高压油泵的维护保养要点：

（1）每次长时间使用后停车，手动按压油门杆，检查其是否活络。如不能自由活动，则说明高压油泵有卡阻，应解体高压油泵检查原因。

（2）定期检查高压油泵滚轮的润滑情况，防止润滑油孔脏堵而引起滚轮销轴和滚轮、滚轮和凸轮轴由于润滑不良产生过度磨损，甚至咬死。

注意，拆检高压油泵时，一定要连同滚轮组件一并拆检，特别注意滚轮组件内部润滑油孔的清通。

（3）高压油泵偶件漏油泄放孔是在泵壳上斜向上开口，这就决定了在停车状态下，当某一个柱塞的密封令处于泄放口的下方时，在套筒内将积聚部分燃油，如果此副机长时间停用，这部分燃油会在120 ℃以上温度的作用下而结炭，从而导致套筒和柱塞的卡阻。

如果在停车状态下，按说明书要求，每两天盘车一次，使各缸柱塞和套筒的位置相应变化，会使可能的结炭硬块破碎，从而有效防止卡阻。

（4）高压油泵停油汽缸的工作情况（主要是密封情况）应受到重视，防止多缸停油汽缸漏气，从而造成不能停车的现象。

（5）摇臂润滑油路是否畅通也会对高压油泵滚轮和滚轮销、凸轮和滚轮的润滑产生影响，如果此油路不通，或者摇臂油量消耗过大，就会影响到滚轮、滚轮销、凸轮的润滑，所以也应引起重视。

## 5、润滑油系统的管理

（1）润滑油应定期取样化验，保证其保持合适的黏度、碱值、闪点、硫分含量等。

（2）滑油细滤器应定期清洗，特别是当滤器脏污后，压差增大到一定数值会使其内部旁通溢流阀打开，滑油将不经过滤直接进入各润滑点，对轴承等部件可能会造成危害。

（3）滑油离心滤器定期换滤芯。

由于副机燃用重质燃油，滑油内燃油和腊质成分较高，所以离心滤器脏污较重。

应根据说明书要求，定期更换，当系统油的油质较差时，更换的周期更应根据实际情况缩短。

（4）对于装配有单独的副机滑油分油器的船舶，管理人员还要加强对系统滑油的分离，并保持在85℃左右的分离温度。

同时主管人员还应根据滑油的使用时间及参考滑油化验结果，决定对系统油的定期更换，确保滑油系统处于良好的工作状态。

这也是确保机械正常运行的基本保障。
