# 导读

调速器是柴油主机的重要组成部分，其好坏直接影响柴油机的运转性能。

若调速器发生故障，可能导致柴油机转速不稳，甚至熄火或者飞车。

某船主机型号为：DOOSAN-WARTSILA 7RTA84T-D，是二冲程7缸十字头涡轮增压柴油机。主机遥控系统采用的是KONG SBERG AUTOCHIEFC20(简称AC C20)遥控系统。

# 一、故障现象

船舶在正常航行中，机舱监视报警系统发出警报显示“DGU SERVO DRIVE UNIT FAIL”和“DGU SERVO POSITIONING UNIT FAIL”。

警报为数字调速单元伺服驱动单元和伺服位置单元故障。

报警几分钟后自动复位，一小时左右又出现同样报警，如此周而复始，并且报警时间间隔越来越短。

警报出现时主机油门杆在停车位置，但是由于船舶的航行惯性，主机实际还有十几转的转速。

Autochief 控制面板(Autochief Control Panel简称ACP)显示DGU故障报警，随即到机旁打开数字伺服控制箱检查DGU模块和伺服控制器，发现伺服控制器上显示故障代码：AC9（见图1）。

# 二、调速控制器及执行器

伺服控制箱（见图2）中的伺服控制器由电源单元和伺服放大单元组成，电源单元包括伺服马达所需的400V电源和24V电源（见图2中的插头2和插头3）。

图2 伺服控制单元控制箱

控制伺服马达的运转速度和运转方向，接收来自编码器的反馈信号和DGU模块传送来的油门位置信号等。

DGU是实现主机的转速和负荷控制而专门设计的分布式处理单元（DPU）模块，它包括4个CAN网络接口和2个RS422/485接口。

在4个CAN网络接口中，2个称为全局CAN网络接口，与同层网络的其他DPU互联，另外2个称为局部CAN网络接口，用于在复杂系统中进行网络扩展。

驾驶台或集控室操作单手柄车钟，发出的正车、倒车、停车、加速、减速信号都通过CAN网络传送给DGU。

在ACP上调速器进行的各种参数设置也是通过CAN网络传送的。

在两个RS422/485通讯接口中，一个连接转速检测模块，直接获取主机的转速值，另一个向油门执行机构(伺服马达)的伺服单元传送调速器的油门位置信号。

电动执行器（见图3）包括一个三相伺服马达和减速齿轮箱。

图3 电动执行机构

伺服马达受伺服控制单元控制，内部装有一个刹车装置，在故障时（如电源故障）执行机构将保持燃油齿条在当前位置上，则主机会按先前转速运行。

燃油齿条位置或执行机构输出位置通过一个直接安装在伺服马达上的绝对编码器进行测量，该测量信号非常准确也非常重要，它既是转速调节器的反馈信号，又是电动执行机构的反馈信号。

# 三、故障排查

根据机舱监视报警系统发出的警报内容和调速器伺服控制器上显示的故障代码AC 9（见图1）及故障现象，再查阅说明书等相关资料，判断可能是伺服控制器与电动执行机构的通讯信号有问题。

如果条件允许可以停航检查；如果不允许停航，则可以先把调速器马达和油门杆脱开（松开油门杆一侧的一圈内六角，见图4），再将主机转到机旁操纵主机运行。

图4 伺服马达与油门杆连接

先把数字伺服控制箱电源断开，包括DGU模块的电源（见图2），再将电动执行机构伺服马达上的各插头（见图3）拔出，清洁插头和插座。

随后插头和电源开关复位，但故障依旧。

检查编码器的电缆连接，从控制箱到三相伺服马达的每个接线点，核对两端线芯连接正常；测量线芯间绝缘良好。

确定编码器电缆连接没有断路、短路或接触不良等故障，也没有电缆接头松动引起开焊的情况。

那么问题大概率是编码器本身故障。

# 四、故障处理

编码器是和伺服马达安装在一起，所以编码器有问题，必须更换整个调速器伺服马达（伺服马达型号为：SGMGH-13Q5A-QM11）。

更换伺服马达后，必须对其进行初始化，具体步骤如下：

1、首先将调速伺服马达与油门杆连接内六角（见图4）松开，使调速器伺服马达可以自动找零位；将伺服马达上的3个插头（见图3）插回复位。

2、将伺服控制箱中的440V电源开关（见图2）、伺服控制器的24V电源插头2（见图2，以下简称插头2），及控制K1继电器（见图2）动作，进而控制刹车装置的电源插头3（见图2，以下简称插头3）全部断开。

3、将插头2复位，观察伺服控制器显示报警代码，如果依然显示AC 9，再去确认一下伺服马达上的3个插头是否插好；或者取出伺服控制器中的3.6V电池（见图1），等待3到5分钟后，再把3.6V电池装回去。

报警代码必须显示为A81或者A83。

4、当报警代码显示A81或者A83后，在伺服控制器（见图1）上通过操作4个按钮（MODE/SET ；向上箭头▲ ；向下箭头▼ ；DATA）完成以下操作：

（1）按MODE/SET键，报警代码显示：Fn000。

（2）按向上箭头▲，直到报警显示报警代码：Fn008。

（3）按住DATA键大约2秒，直到报警显示报警代码：PGCL1。

（4）按向上箭头▲，直到报警显示报警代码：PGCL5。

（5）按MODE/SET键，这时报警闪烁显示：done。

（6）稍等一分钟左右报警显示代码消失，之后又重新显示报警代码：PGCL5。

5、以上完成后，再将插头3（见图2）重新插好复位，440V电源开关重新合上，等待报警显示报警代码：--..bb。

这时伺服马达在找零位，正常情况继电器K1（见图2）打开，刹车装置会动作一下，之后显示报警代码：RUN，最后报警代码显示为：--..BB。

6、将连接油门杆的一圈内六角螺栓（见图4）重新上紧。

随后在集控室和驾驶台分别对主机进行启动运行试验几个小时，系统运行正常，伺服控制器显示代码：..run，故障得以解决。
