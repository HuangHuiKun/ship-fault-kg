# 导读

发动机的气门座有些是用耐磨合金铸铁制成镶圈，镶在汽缸盖上。

这种结构的气门座，磨损后易于更换，而不至于报废整个汽缸盖。

气门座圈压入汽缸盖时会产生一定的装配应力，工作状态下气门座圈（特别是进气门座圈）圆周上的温度分布是不均匀的，因而易产生一定的热应力，而引起座圈的翘曲变形。

所以，在结构上要求一定的壁厚和一定的高度，以增强其刚性，并确保它与气门密封锥面贴合良好。

进气门座圈内孔一般还制成截面渐扩型式，以对进气流起引导作用，减小流阻。

为达到上述要求，气门座圈一般采用中铜（含铜量为0.8%〜1.2%）铬钼合金铸铁材料（S195.D180型柴油机采用）。

S195型柴油机

但随着柴油机的高速化趋向，往往要求采用耐磨性能和热强度更好的高铬（含铬量为12.5%〜14%）合金铸铁材料（S1100A 型柴油机采用）。

S1100柴油机

这两种材料的硬度均须低于气门头部硬度3〜5个洛氏单位，以达到良好匹配，并且使切削性能不至于恶化。

在柴油机使用过程中，气门座会发生松动现象,引起气门间隙的变化，使发动机功率下降，甚至无法工作。

# 气门座松动时柴油机的表现

气门座松动时，会有以下外在表现：

（1）柴油机突然出现异响，汽缸上部有明显的敲击声。着火时出现“缺腿”现象，功率下降、严重者不能工作。

（2）排气管出现有规律的、间断的冒白烟（有时冒黑烟）现象,并多呈雾状。

（3）加大油门或加大负荷作业时,有严重的气门敲击活塞声。

（4）有窜气现象,严重时从曲轴箱通气孔向外窜气。

# 气门座松动故障的判断方法

（1）柴油机工作时，用手触摸进气支管有烫手的感觉，且该缸进气支管比其他缸热,说明进气门座松动。

再对进气支管旁边侧耳听诊，会有“啪、啪”的响声，这是在压缩行程中，可燃混合气体倒流进入空气滤清器的缘故。

（2）侧耳听诊在排气支管处有“扑、扑”的响声，且柴油机在工作时，该缸的排气支管比其他缸的排气支管温度低，则说明排气门座松动。

（3）在小油门工况下，逐缸拧松高压油管，当松开某缸高压油管，冒白烟现象消失,并听到“嚓、嚓”的声音，伴随这种声音的还有一股气流声（柴油机将要熄火时刻听得非常清楚），则可断定该缸气门座松动。

（4）若是该缸气门座松动或脱落，该缸会产生漏气、压缩压力不足、压缩压力比其他缸的压缩压力小，或无压缩力。

在压缩过程中进气或排气支管会出现明显的“嘶、嘶”漏气响声。

（5）熄火进行检查，气门座松动的气门杆常升不到最高点。调好气门间隙后，摇转曲轴复查时,其间隙会出现时大时小，气门在导管内的往返运动有滞涩或发卡现象。

# 气门座松动的原因

（1）气门座严重磨损、下陷量过大，气门座烧损或产生裂纹等都会造成气门座松动;缸盖螺栓扭力不均或柴油机在高温时骤加冷水,使缸盖变形或产生裂纹，也会导致气门座松动。

（2）在生产装配或修理时，选购、更换的气门座圈外径过小，使镶嵌紧度不够，也会造成气门座松动。

维修时,扩铣气门座圈孔座的精度不够（圆柱度及圆度超限）、表面粗糙度不合格等，使座圈镶入座孔后配合紧度不够，接合不牢，造成气门座圈变形、松脱。

（3）柴油机长期超负荷作业或柴油机使用时间较长,经高温高压气体不断冲击，致使座圈与座孔的配合逐渐松动。

另外,汽缸盖上的气门座孔经过多次拆装，座孔口径增大,若配上原来尺寸座圈，气门座圈也会松动。

# 气门座圈的更换

## 拆卸

由于气门座圈与汽缸盖座圈孔是过盈配合，因此，在更换拆卸气门座圈时,要用专用的工具进行拆卸。

若没有气门座圈拉出器,可用旧气门阀在砂轮机上磨削成鑒子后，将旧气门阀分别从进、排气管安装座孔插入气门座圈凸缘或贴合面之间，然后用锤子敲击旧气门阀头部。这样转过几个角度，进、排气门座圈便能卸下。

## 安装

采用加大尺寸法，即重新车制加工气门座圈。只需稍微加大气门座圈的外径尺寸，提高其配合紧度，实际尺寸应根据气门座孔的口径尺寸来确定。

冷镶时过盈量为0.10〜0.15mm,热镶时过盈量为0.2~0.25 mm。

气门座圈其余的尺寸，如高度、内径、斜面、角度等技术要求应和原来的气门座圈相同。

一般采用冷镶法，将气门座圈放正于汽缸盖座孔后，分别用原机型的废旧进、排气门阀头部圆面对准进、排气门座圈（要基本保持同心），然后用锤子平稳地敲击气门杆顶部，就能把气门座圈装上。

也可用胶粘法，即选购原来型号的气门座圈，用磷酸一氧化铜无机胶粘接，具体操作方法是:

①先将缸盖上的气门座孔、气门座圈的脏污、积碳清除干净，然后用脱脂棉沾上丙酮擦去接合面上的油渍。

②制胶时，将固体粉状的氧化铜与液态磷酸，按1mL磷酸溶液加3.5〜4.5g氧化铜粉配比,并按使用说明搅拌均匀。

③将配制的粘胶厚薄均匀地涂在座孔与座圈的接合面上，把座圈装入座孔内，再用小锤轻轻敲击座圈，经过振动使粘胶充分填满缝隙。

④在室温下自然固化3〜4h后，即可较削研磨气门。
