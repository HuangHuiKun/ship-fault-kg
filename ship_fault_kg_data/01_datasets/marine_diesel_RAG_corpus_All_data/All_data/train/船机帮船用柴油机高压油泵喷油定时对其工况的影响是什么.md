# 导读

船舶柴油机正确的喷油定时是保证其正常工作的关键条件之一，所以掌握柴油机喷油提前角的调整是修理中一个很重要的步骤。

# 喷油提前角的调整方法

柴油机的喷油定时一般由喷油提前角决定。

柴油机的高压油泵种类很多，常修理的类型主要为单体式高压油泵和组合式高压泵两大类；

从定时调整方式来分，主要分为始点调节式和始、终点调节式两大类。其中最常见的是单体式高压油泵修理。

始点调节式高压油泵定时的调整，就是对供油提前角的调整。

供油提前角是柴油机活塞到达上止点之前开始向气缸内喷油，此时曲柄相应的位置与上止点位置之间的夹角。

供油提前角的大小，对柴油机工作好坏有很大的影响。

若提前角过大，气缸内气体的压力和温度不足，滞燃期增长，燃烧前气缸内积聚的燃油过多，一旦着火，大量燃油同时爆燃，气缸内压急剧升高，柴油机工作粗暴，容易发生机损事故；

若提前角过小，则燃烧过程延长，燃油来不及完全燃烧就被排出，柴油机工作时就会冒黑烟，排气温度和气缸内工作行程的平均温度就会增高，同时也使气缸润滑性能变差，加剧缸套和和活塞环的磨损。
