# 导读

某轮SULZER 7RT-flex 60C电喷主机,7缸，每缸3只喷油器,采用的WECS-9520电子控制系统(是早期WECS-9500系统软件和硬件的优化升级产品，下称9520系统),人机界面可实时提供诸如燃油喷射曲线、排气阀运动曲线等主机运行参数的曲线和图表。

利用这些曲线和图表诊断主机故障,快速且准确,对主机安全运转大有裨益。

本文介绍利用燃油喷射曲线诊断燃油喷射故障一例，祈指正。

# 一、故障

某轮某日锚地起锚进港,主机运行不久,当时主机转速60r/min(2只喷油器工作),燃油指令(控制系统指令的油量占额定最大喷油量的百分比)22.3%，排烟温差报警,主机SLOW DOWN,警报系统显示No.2缸排温比其他缸低约80C,其他六只缸正常。

怀疑锚泊时更换的No.2缸的三只喷油器不良,停车,换回原来使用正常的三只喷油器,故障依旧，确认故障点不在喷油器,而在喷射控制单元(ICU)。

# 二、燃油喷射工作原理

燃油喷射,由油量活塞左行提供燃油和压力(右行为下次喷射做准备),受控于9520系统控制,通过各缸燃油喷射单元(ICU)实现(工作原理见图1)。

燃油喷射控制,主要包括喷油量、喷油定时、工作喷油器选择等三项。

## 喷油量

燃油流向:

非喷射时,喷射控制阀下位工作,共轨燃油充满油量活塞左侧空间;喷射时，喷射控制阀上位工作，油量活塞右侧的共轨燃油压力推动油量活塞将左侧空间的燃油通过喷油器喷入气缸。

油量活塞的左行和右行，动力是油量活塞两侧的燃油压力差，由喷射控制阀控制:

喷射控制阀下位工作,油量活塞左侧是喷油器的启阀压力,油量活塞右侧是燃油共轨压力，虽然活塞左侧受力面积大于活塞右侧，但燃油共轨压力(900bar)高出喷油器启阀压力(375bar)更多,故活塞左行,燃油喷射;喷射控制阀上位工作,油量活塞左、右两侧都是燃油共轨压力,但活塞左侧受力面积大于活塞右侧,油量活塞右行,燃油充入油量活塞左侧,为下次喷射做准备。

## 喷油定时

喷油定时，9520系统通过共轨电磁阀和喷射控制阀实现:

共轨电磁阀开始上位工作(即喷油始点),控制喷射控制阀上位工作,油量活塞左行，燃油喷射;共轨电磁阀结束上位工作(开始下位工作,停止喷油即喷油终点),喷射控制阀失去伺服油的控制动力并因复位弹簧恢复下位工作,油量活塞右行,共轨燃油充入油量活塞左侧(准备下次喷射)。

喷油终点(即共轨电磁阀恢复下位工作，喷射控制阀也恢复下位工作)的信号,来自油量活塞左行达到设定位置的反馈(来自油量活塞杆右端的油量传感器)。

即，只要油量活塞左行达到设定位置,9520系统就会令:

共轨电磁阀下位工作,控制喷射控制阀也下位工作,油量活塞停止左行。

## 工作喷油器选择

工作喷油器选择,也是WECS-9520电子控制系统根据设定的程序，通过控制共轨电磁阀进而控制喷射控制阀的启闭实现:

大于15%~20%额定负荷(可调),三只喷油器同时工作;12%到15%或20%额定负荷(可调),两只喷油器工作;小于12%额定负荷,一只喷油器工作。

一只或者两只喷油器工作时,三只喷油器定时循环切换交替使用(以均衡热负荷、改善雾化燃烧减少油耗和烟雾排放)。

# 三、燃油喷射曲线 (参见图2)

燃油喷射曲线,横坐标是时间，纵坐标是油量活塞位置，显示油量活塞位置随时间变化。

其中油量活塞的位移由油量信号传感器探测并转换为电流(mA)信号传送到9520系统中心控制器，故油量活塞位置用油量信号传感器输出电流(mA)信号表示。

每个缸每个喷油循环的燃油喷射曲线,自左至右可分为四段:

第1段,左端0ms起的水平直线段(油量活塞无位移,保持4.5mA),是喷油延迟时间(11.9ms,指9520系统核心控制器发出喷油指令但喷射控制阀仍保持下位,油量活塞尚无左移)。

右端即喷油开始时间。

第2段,第1段右端(上行)至油量活塞位移达到峰值。

这一段是喷油阶段，喷射控制阀转换为上位工作,油量活塞位置从4.5mA左移至最大值。

该最大值按9520系统核心控制器发出的喷油指令(本故障时No.4缸是8.2mA)。

这一段的右端,喷射控制阀恢复下位工作,即喷油结束(27.0ms)。

这一段喷射控制阀上位工作(喷油开始至停止)持续时间是决定喷油量的主要因素。(油量活塞位移)达到峰值(设定值)后喷射控制阀立即转为下位工作。

第3段,第2段右端油量活塞从位移最大值(本故障时No.4缸是8.2 mA)恢复到左移前位置(4.5 mA)。

这一段,喷射控制阀恢复下位工作,共轨燃油充入油量活塞左侧空间(左侧面积大于右侧)。

第4段,第3段右端油量活塞位置4.5mA起的水平直线段，喷射控制阀下位工作,油量活塞在止点,准备好接下一喷油循环。

# 四、利用燃油喷射曲线诊断故障

从WECS-9520控制系统的人机界面上截取的No.2缸和No.4缸燃油喷射曲线见图2,No.2缸是故障缸,No.4缸是工作正常的参照缸(其参数值可视为参数正常值)，相应参数对比见表1。

分析No.2缸(对照No.4缸)的燃油喷射曲线和表1，可知NO.2缸的燃油喷射曲线，第1段和第4段正常,而第2段和第3段不正常。

## 第2段分析

第2段是喷油阶段(喷射控制阀持续上位工作),喷油始点(11.9ms)正常;喷油终点只有19.6 ms,油量活塞已经到达指令的最大位置，该喷射的燃油已喷射完毕，不再左移并开始右移。

对照No.4缸数据27.0ms,喷油终点提前了7.4ms，也就是No.2缸在19.6ms时喷射控制阀转为下位工作,此次喷油结束。

油量活塞推动燃油喷射,可视为容积式泵,燃油喷射快(提前喷射完指令的燃油量),表明其背压低。

其背压取决于喷油器漏泄喷油器调压弹簧的预紧力管路漏泄等。

发现故障后,曾“停车漂航，换回原来使用正常的三只喷油器,故障依旧”,可排除喷油器漏泄的可能;调压弹簧预紧力低.燃油雾化燃烧不良,排烟温度必定升高,而故障现象是“No.2缸排温比其他缸低约80℃,排除喷油器调压弹簧预紧力低的可能，故开始检查喷油管路漏泄。

主机运转中，拆下三只高压油管的检漏内六角闷头，发现一根高压油管的检漏孔有油漏出;停车拆检该高压油管,发现其锁紧螺帽处泄漏,重新上紧后主机运行恢复正常,包括喷油曲线正常和排温正常。

锁紧螺帽处泄漏，可能是更换喷油器时没有上紧到要求值;而高压油管有套管保护,若有漏泄从夹层泄放,外管检查很难发现;虽有泄漏报警,但该报警集合了ICU本身泄漏、共轨接头泄漏、高压油管泄漏等原因,一时也难以定位。

故,建议值班巡回检查增加检查高压油管保护套管泄放的漏泄油。

## 第3段分析

第3段是油量活塞从位移最大值恢复到左移前位置,曲线多处波动表明油量活塞移动速度多变。

油量活塞移动速度多次变化的原因有二:

共轨燃油压力波动,或油量活塞运动阻滞。

其他缸没有类似现象,可排除共轨燃油压力波动。

油量活塞运动阻滞，原因可能是油量活塞与油缸间有杂质、油量活塞与油缸间隙过大或共轨燃油至油缸管路阻塞等。

依目前经验,多是油量活塞与油缸间有杂质,故一般是解体清洁ICU,同时测量油量活塞与油缸间隙(若超标，整体更换)。

由此可见,利用9520系统在人机界面提供的相关曲线和参数诊断主机故障,事半功倍。
