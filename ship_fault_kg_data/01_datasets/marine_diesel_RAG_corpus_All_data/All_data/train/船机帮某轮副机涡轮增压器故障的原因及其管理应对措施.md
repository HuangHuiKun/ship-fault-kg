# 一、设备简介

某轮3台发电机柴油机是YANMAR 6N18AL-UV机型,四冲程,缸径180mm,额定输出功率550kW,转速900转1分。

空冷器和滑油采用低温淡水冷却,缸盖和缸套采用高温冷却水冷却,涡轮增压器型号RH133型，该涡轮增压器结构特点:

(1)采用废气增压,没有喷嘴环,废气直接吹动轴流式涡轮机叶轮,由其带动同轴的压气机叶轮;

(2)涡轮增压器轴承是半浮动式轴承，使用的润滑油来自于系统油(机座油)的分支,供油压力0.28MPa~0.4MPa,前面有纸芯滑油滤器,设有滑油低压报警和自动停车装置；

(3)没有冷却水腔。增压器没有设计专用的冷却介质冷却。

# 二、故障现象

由于疫情原因，全体人员在某港全体换班，开航后不久，发现该NO.3 副机透平油压力不稳定，滑油消耗量大，比其他两台每日多消耗30L/D，而且透平油压力不稳定，透平油纸滤芯更换频繁，鉴于此情况，用一备用透平更换，副机滑油消耗正常，拆下的副机透平检查，轴承轴向间隙和径向间隙均已超限。

轴封损坏。到港下地送专业厂家修理。

两个月后，NO.2副机透平，在出港时发现冒黑烟，进而透平滑油压力低报警，随后更换备用透平，拆下的透平手动盘车，发现轴向间隙和径向间隙均已超限。

因船上没有检修包，故下地送专业厂家修理。

# 三、故障原因

从故障现象和根据该柴油机涡轮增压器的构成,分析造成损坏的原因主要有以下几个方面:

(1)柴油机工作异常，导致排气温度高,使涡轮增压器转速超过极限值,导致轴承烧毁;

(2)涡轮增压器组成部件磨损厉害,轴向和径向间隙过大;

(3)润滑油供给油压力不足或过高;

(4)废气涡轮叶轮和压气叶轮结碳,动平衡差,振动厉害;

(5)润滑油油质差或使用滑油型号不对，建立不起润滑油膜;

(6)润滑油滤器破损或安装不对,使润滑油没有得到过滤,导致部件磨损厉害;

(7)没有按照说明书进行规定时间进行检修保养。

# 四、故障分析

追溯历史，追溯操作规程，以下两点是该轮副机涡轮增压器故障的主要原因。

1、由于该轮副机滑油分油机没有专门对每台副机进行循环分离净化的管路，只有一套到滑油沉淀柜的管路系统，该轮副机滑油储存柜仓容只有2M3。

由于该轮跑长航线，加装滑油有些港不方便，所以把副机滑油沉淀柜当做储存柜使用，导致该轮副机滑油长期不能有效地分离净化。

使得副机滑油的粘度和燃烧产物增加。

笔者接班不久后就对副机滑油分油机改装管路，能单独实现对该副机滑油的分离净化。

2、操作规程，检查接班前副机的操作规程，备用副机平时空气启动阀保持关闭，预润滑油泵在停止状态，只是在启动前提前3分钟开启，然后冲车，起动，这对于自带润滑的副机透平来说影响不大，但对于使用系统滑油润滑的涡轮增压器来说是一重大的操作安全隐患问题。

原因是副机在非运转状态，副机压气端叶轮受到风机风筒气流的冲击，叶轮也会转动，但是这时副机预润滑油泵在停止状态，透平油没有压力，就会使副机涡轮增压器轴承长期干磨。

以致出现轴承间隙超限。

# 五、故障启示

严格按照说明书进行维护保养,制定操作规程。

1、每运行400小时检查压气端锁紧螺帽，运行1200小时检查涡轮轴转动情况，运行2400小时测量轴向和径向间隙,4800小时解体,清洁,更换磨损件;

2、安装时一定要测量轴向间隙(0.06~0.12mm)和径向间隙(0.37~0.57mm,容许值0.67mm),保证在间隙值内,否则要更换部件;

3、每200小时压气端用水进行冲洗，柴油机负荷75%以上,冲洗枪专用冲洗药剂一次0.15升,冲洗时间4~10秒,反复冲洗3~4次，然后再用淡水按药剂程序冲洗,冲洗完,关掉放残阀，进气压力会升高;

4、加强对喷油器的检查,保证各缸燃烧充分;

5、对增压器空气吸人滤器勤更换且安装好,尤其是在码头装卸完货物时，滤器要得到及时换,保证有足够空气燃烧和防止灰尘进入吸气系统。

6、加强对副机滑油的分离净化。定时对副机滑油送验化验（没三个月） 按说明书的要求换新换油。

7、副机预润滑油泵始终保持运转，除非是在副机检修时，如果停预润滑油泵，之前必须用帆布罩把涡轮增压器的压气端进气处盖好，防止受气流冲击干磨，损坏轴承。

机械设备的预润滑，尤其是副机的预润滑，轮机人员要高度重视，电站的自动化管理及副机维保以及机旁启动等操作规程一定要把预润滑泵的日常检查，维保要点，操作提示等要明确张贴，加强培训。

下面两个案例就是很好的教材。

## 案例1

某轮配有三台柴油发电机，航行中一般使用一台，两台备用，电站在自动模式，无人值班机舱，某晚，NO.2发电机运行供电，NO.1副机第一备用，NO.3副机第二备用，就寝前老轨到机舱巡回检查时发现该轮NO.1 A/E 预润滑油泵控制箱旋钮放在自动运行位，指示灯显示运转正常，检查预润滑油泵电机运转情况，温升及振动均正常，再检查滑油压力时，发现压力表压力为零，赶紧将电站控制模式NO,1A/E 放在手动位，对其预润滑油泵进行检查，发现该泵弹性联轴节损坏失效，马上组织人员进行修理，修复后将电站运行模式转为自动运行。

如果该故障不能及时发现，在全船断电的情况下，NO.1 A/E 做为第一备用发电机启动，将会造成严重的机损。

## 案例二

某轮配有三台船舶发电机，电站为手动控制模式，三台副机均为手动机旁控制模式，采用准同步手动并电解列，应急照明采用电瓶供电，三台副机预润滑采用手摇泵形式，即副机在冲车，启动前人工手动手摇容积式泵，当润滑油压力达到0.3 Bar时，就可以进行冲车，启动操作了。

某日该轮NO.1 A/E 因机带滑油泵故障，导致滑油低压停车，全船断电。

情急之下，值班人员在没有手摇容积式泵建立预润滑油压力的情况下，冒然启动副机，几分钟后该副机烧瓦机损，由于值班人员在紧急情况下没有遵守操作规程，导致严重机损，给船东造成重大的经济损失，给船员造成了巨大的安全隐患和大量的工作量。

# 六、结论

轮机管理就是尊重机械设备自身的规律，制定可靠可行的操作规程，强化培训，监督有效实施。
