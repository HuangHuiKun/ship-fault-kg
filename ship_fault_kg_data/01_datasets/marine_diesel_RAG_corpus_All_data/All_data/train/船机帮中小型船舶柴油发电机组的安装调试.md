# 一、船舶柴油发电机组安装

## 1. 设备拆箱点件

设备拆点件检查应由安装单位、供货单位、建设单位共同进行，并作好记录；

按照设备供货清单、技术文件，对设备及其附件、备件的规格、型号、数量进行详细核对；

发电机组本体、控制和辅助设备外观检查应无损伤及变形，油漆应完好。

## 2. 安装前的检查

发电机组安装前应进行以下检查：

发电机组应完好，不应有损伤现象。

铁芯、转子等表面及轴径的保护层应完整无锈蚀现象。

水内冷电机定子、转子进出水管管口的密封应完好。

发电机组的附件、备件应齐全无损伤。

## 3. 电机引出线的安装

引出线的接触面应平整、清洁、无油垢，其镀银层不宜挫磨。

引出线的连接应紧固，应注意铁制螺栓的位置，连接后不得构成闭合磁路。

## 4. 滑环和电刷的安装

滑环应与轴同心，其摆度应符合产品的规定，一般不大于0.05mm。

滑环表面应光滑，无损伤及油垢。

接至滑环的电缆，其金属护层不应触及带有绝缘垫的轴承。

电刷架及其横杆应固定牢固，绝缘衬管和绝缘垫应无损伤、污垢，并应测量其绝缘电阻。

刷握与滑环表面间隙应调整为2-4mm。

电刷的安装调整应符合下列规定：

同一电机上必须使用同一型号、同一制造厂的电刷；

电刷的编织带应连接牢固，接触良好，不得与转动部分或弹簧片相碰触，具有绝缘垫的电刷，绝缘垫应完好。

电刷在刷握内应能上下自由移动，电刷与刷握的间隙应符合制造厂规定，一般为0.1～0.2mm；

恒压弹簧应完整无机械损伤，其型号及压力要求应符合产品规定。

电刷的接触面应与滑环的弧度相吻合，接触面积不应小于单个电刷截面的75％；

研磨后，应将碳粉清扫干净。

非恒压的电刷弹簧，其压力应符合制造厂规定。

若无规定时，应调整到不使电刷冒火的最低压力，同一刷架上每个电刷的压力应力求均匀，一般为0.15～0.25kg／cm²；

运行时电刷应在滑环的整个表面内工作，不得靠近滑环的边缘。

## 5. 氢冷电机的安装

电机的引出线应按制造厂图纸及规定包扎绝缘。

氢冷电机必须进行气密性试验，消除定子各处焊口、接合面及定子引出线密封处的漏气，其试验压力应符合制造厂的规定。

## 6. 水内冷电机的安装

安装前应对定子、转子水回路分别进行水压试验。

现场水压试验标准应按制造厂的规定。

试验持续时间为8h，应无渗漏，试验时应将绕组水回路中的空气放尽。

电机的冷却水应是气轮机的冷凝水或经除盐处理的水，其水质要求见表1。

绝缘水管不得碰及端盖和有凹瘪现象，相互间也不得碰触或摩擦。

否则应用绝缘物隔开，并用玻璃丝带扎牢。

电机的捡漏装置应清洁干燥。

水内冷电机的定子、转子安装后应进行正、反冲洗，确保分支水回路畅通。

# 二、质量控制

发电机组至低压配电柜馈电线路的相间、相对地间的绝缘电阻值应大于0.5MΩ；

塑料绝缘电缆馈电线路直流耐压试验为2.4kV，时间15min，泄露电流稳定，无击穿现象。

柴油发电机馈电线路连接后，两端的相序必须与原供电系统的相序一致。

发电机组中性线(工作零线)应与接地干线直接连接，螺栓防松零件齐全，且有标识。

发电机组随带的控制柜接线应正确，紧固件紧固状态良好，无遗漏脱落。

开关、保护装置的型号、规格正确，验证出厂试验的锁定标记应无位移，有位移应重新按制造厂要求试验标定。

发电机本体和机械部分的可接近裸露导体应接地(PE)或接零(PEN)可靠，且有标识。

受电侧低压配电柜的开关设备、自动或手动切换装置和保护装置等试验合格，应按设计的自备电源使用分配预案进行负荷试验，机组连续运行12h无故障。

发电机的试验必须符合本规范表2的规定。

# 三、柴油发电机组的试车与调试

机组安装完毕后，必须先经过启封、磨合、试车检查和调试等程序，符合要求后，才能投入运行。

## 1. 柴油机的启封

为了防止柴油机锈蚀，产品出厂时，其内外均已油封，新机组安装完毕，必须启封才能启动，否则会造成“飞车”的危险。

启封步骤如下：

首先把柴油加热到45～56℃，洗擦除去外部防锈油。

接着将水加热到90℃以上，然后从水套出水口处不断地灌入，由汽缸体侧面的放水开关(或水泵进水口)流出，连续进行2～3h，并间断地摇转曲轴，使活塞顶，汽缸套表面及其它各处的防锈油溶解流出。

最后用清洁柴油清洗油底壳，并换入新机油。

## 2. 机组试机前的检查

首先对柴油机进行试机前检查。

具体项目有：

检查机组表面是否完全清洁干净；

各部件坚固螺栓有无松动；

进气门、排气门和减压机构间隙是否正确；

将各汽缸置于减压位置，看曲轴转动是否自如，并检听各缸机件运转时声音有否异常；

关上减压机构，盘车，检查汽缸是否漏气。

## 3. 新装柴油发电机组的磨合与调试

新装机组在投入运行时前，按要求进行磨合，使运动机件表面更光洁，可延长柴油机的使用寿命。

为保证磨合质量，应遵循以下原则：

负荷逐步增加，转速逐步提高。

安装好的机组调试，可分为柴油机、发电机、控制屏三部分进行。

柴油机的调试项目有：

燃油供给系统输油泵、喷油泵、调整器、供油量、配气机构气门间隙等零部件的检查和调整。

发电机的调试检查项目有：

绝缘电阻测量；

发电机发热或试验检查；

励磁装置的调整；

调差装置的调整；

空气过滤器的检查；

防冷凝加热器的检查。

控制屏的调试较为重要，以重庆康明斯无锡西门子柴油电机组控制屏为例进行介绍。

首先，检查各开关，按钮操作是否灵活，接触是否良好，各元器件安装是否牢固；

检查控制屏一次及二次回路接线是否正确，可靠；

连接好交流发电机的输出线；

交将副控屏刀开关断开，接好电网至副控制屏的电线；

将主控屏至副控屏，机组，自控板各插头插好及各需要连接的端予连接好，将柴油机加热装置与主控屏之间的线缆接通。

检查报警电路是否正常，按下“试报警”按钮，此时，报警电铃应响，“故障报警”灯应亮，发出声光报警信号放开按钮信号立即消失。

当机组自动启动发电时，若发电机出现过载，过流掉闸，柴油机应能自行怠速运行，并发出声光报警信号。

在3min内经人工排除故障后，将开关由“自动”扳去“手动”后，立即扳回“自动”位，机组将自动恢复正常供电；

怠速运行了3min后故障不能排除，机组将自动停机。

在试车过程中出现机油压力过低，水温过高，机组会自动紧急停机并发出声光报警信号。

# 四、日常维护

为保证发电机正常工作，在它附近不应有水，油及污物堆积，不能有腐蚀性气体，以免损伤发电机绕组绝缘。

在防潮防尘的同时，要注意不能影响发电机的正常通风冷却。

要经常清洁通风孔道内的灰尘污物，保持畅通无阻。

冷却空气的温度不得过低，以免绕组及其它导电器件上凝结水珠。

对因故短期停止运行的发电机，集电环可不必包扎保护，但要在电刷与集电环之间垫以绝缘纸板、石腊纸或沥青纸，以免电刷在集电环表面上形成斑点。

船用柴油发电机组的加工面，如果由于油，漆脱落而锈蚀时，应及时除锈，并涂以防锈漆。
