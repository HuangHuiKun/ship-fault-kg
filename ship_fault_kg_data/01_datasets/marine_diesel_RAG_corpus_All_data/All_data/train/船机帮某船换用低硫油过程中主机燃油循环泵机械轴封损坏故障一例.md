# 导读

某船由南非LasPalmas港开往法国Dunkirk港，在进入特殊排放控制区前，燃油系统从高硫重油切换至低硫轻油，在此过程中发生主机No.1燃油循环泵机械轴封损坏漏油引发火警的故障。

经轮机部全体人员共同努力，最终查明故障原因，在较短时间内恢复主机正常运行。

# 一、事故经过

某日1900时，该船主机转速从正常运行时的82r/min逐渐下降至48r/min,并开始按低硫油转换程序进行换油操作;

2130时在检查主机及其附属设备一切正常后,主机转速升高至55 r/min;

2240时机舱发出火警警报,检查发现主机No. 1燃油循环泵有燃油喷出,且泵壳温度较高,达180℃。

考虑到船舶即将进入低硫控制区,轮机人员立即启动No.2燃油循环泵,并在征得驾驶台同意后,于2300时选择一处四周船舶较少的水域临时停车,准备查明原因,紧急抢修主机No.1燃油循环泵。

# 二、事故调查

## 1、加热与伴温管路的检查

燃油系统已开始逐渐切换至轻油,而燃油循环泵温度却异常升高,其首要原因可能是燃油加热与伴温管路加温阀没有关严。

检查并确认燃油加热与伴温管路加温阀已关闭后,此故障原因可基本排除。

## 2、燃油循环泵和马达的检查

运行中的燃油循环泵温度异常升高,可能是由马达过载或循环泵干摩擦等引起的。

拆掉马达风扇叶轮罩壳,用手拨动叶轮,发现无明显卡阻,说明马达和燃油循环泵轴承完全损坏的可能性不大。

由于No.1燃油循环泵轴封已漏油，安排人员对该泵进行解体检修,发现燃油循环泵与马达之间的联轴节橡皮套已烧毁，轴封破损 ，燃油循环泵轴承状况不良。

在换新这些备件后将燃油循环泵装复，试运转检查，开始时泵壳温度不高，但随着时间的延长，温度再次升高，仍达到180℃，显然故障根源仍未查明。

## 3、燃油管路阀件的检查

燃油循环泵安全阀起跳会造成轻油在增压泵进口与出口之间不断急速循环而导致泵壳温度迅速升高,用手触摸燃油循环泵安全阀，该处温度确实非常高。

低硫轻油在许多特性方面与平时使用的重油有很大不同,如润滑性差、黏度低、闪点低等。

为降低使用操作中的风险,除在换油操作前降低主机和副机的负荷外,船舶通常还配有油冷器，通过冷却提高低硫轻油的黏度。

# 三、故障机理

该船在非排放控制区时,主机使用重油，经燃油循环泵增压的燃油无须经过油冷器,燃油循环泵后的三通阀关闭去油冷器的通路,因此燃油也就无须经过阀X去主机。

平时即使阀X未被完全打开，也不会影响燃油循环泵的正常使用,故该阀的开关状况不易被发现。

燃油系统已换用轻油初期,在供油单元感温探头TS2还未检测到该处油温降至某一数值(如60℃)时，系统仍按照重油运行，燃油循环泵后的三通阀也不会打开，即燃油循环泵后的三通阀10. 3(V1)仍保持关闭冷却通路状态，因此该故障未显现出来。

只有在供油单元感温探头TS2检测温度小于60℃,且系统默认管路中低硫油已占很大比例，需要通过油冷器降低油温来提高其黏度时，阀10.3(V1)才打开去油冷器的通路,才会有燃油通过阀X去往主机。

故障发生前，感温探头TS2已检测到该处油温低于60℃,阀10.3(V1)完全关闭直通主机的通路，燃油须经油冷器管路(图1中虚线所示)去主机。

此时阀X是必经之路,但阀X开度不足，使得燃油循环泵出口压力升高，达到安全阀开启压力，安全阀打开造成燃油在循环泵进出口之间快速循环，温度急剧升高而烧毁机械轴封。

# 四、故障教训

不论阀X是否开足或在运行中由于振动而逐渐关小，主管轮机员都要在轻重油转换时，对所主管的设备进行认真检查和梳理，尤其对系统中的常开、关阀门要定期检查确认。

将管路图与实际管路进行对比，清楚各阀件的功用和位置，是每位轮机人员熟悉新上船舶各系统的必经之路。

只有清楚了解机舱的各个系统，才能降低故障发生概率、提高故障排除效率。
