# 导读

随着我国船舶行业的迅速发展，船舶轮机的安全管理工作也逐渐受到了人们的重视。

但是就目前来看，有关船舶轮机安全管理的研究多偏重于船舶设备管理，而有关安全管理的研究比较少。

因此，为了提高船舶轮机的安全管理水平，船舶企业应加大其风险研究，并制定出有效管理策略，提升船舶轮机安全管理水平。

# 一 船舶轮机安全管理风险

船舶轮机的安全管理是船舶管理的重要环节，主要是对船舶轮机设备进行管理、维护、保养，另外，它还包括对轮机人员的管理。

结合实际来看，在影响船舶轮机安全的诸多因素中，人为因素的影响最大，忽略人为因素是无法保证船舶轮机安全管理质量的。

环境因素的变化最大，且是客观存在的。

在实际管理中，只有充分考虑人、设备、环境因素的影响，并将其作为一个整体看待，才能尽可能地提高船舶轮机的可靠性、安全性，从而有效减少船舶轮机安全管理风险的产生。

就目前来看，船舶轮机的安全管理工作现状并不乐观，导致船舶轮机安全管理出现各种风险。

具体表现为：

- 人为因素影响。如轮机管理人员不重视、不了解安全管理工作内容、经常敷衍式工作，且存在侥幸心理，总是采用以往的经验进行轮机管理，导致各种安全管理问题发生。
- 自然因素影响。船舶轮机行使在海上，海上的天气条件恶劣，且容易经常发生暴风、暴雨，影响到船舶的安全行使，增加了船舶轮机的安全管理难度，更容易导致安全问题的发生。
- 设备因素影响。船舶轮机的机电设备经过长期运行，会出现老化、磨损等问题，引发轮机设备运行故障，进而影响到船舶轮机的安全运行。另外，机电设备受到外界不良因素的影响，也会发生故障。

总的来说，若要提升船舶轮机的安全管理水平，杜绝各种安全管理风险，就应采取有效的措施减少各种不良因素对船舶轮机安全管理工作的影响。

# 二 船舶轮机安全管理风险的防范措施

## 加强对“人”的管理

为了真正提高船舶轮机的安全管理水平，消除人为因素给船舶轮机带来的安全管理风险，船舶企业应制定完善的管理措施，提升全员的责任意识，使其重视船舶轮机的安全管理工作，并能依据规范、政策规范开展安全管理工作。

- 充分发挥团队作用，强化船舶轮机的安全管理。实践证明：团队能力要大于个人能力，团队作用要大于个人作用。所以在船舶轮机的安全管理工作中，应组建一支专业的管理团队，并选择一名能力突出、经验丰富的领导。同时，还应保证成员能团结协作，使其紧密地结合在一起，从而有效提升团队的管理水平。
- 应加强船员间之间的交流、沟通，这是管理者、领导人员应学习、掌握的基本能力，毕竟船员之间的关系会影响到安全管理政策、方针的落实。
- 应加强船员与轮机管理人员之间的沟通、协调。轮机管理人员可以为管理人员提供各种数据信息参考，从而有效保障船舶的安全行使。比如机电设备维护情况、检修状态、备件消耗等数据信息，以作为船舶维护、保养、物资采购等管理工作的决策依据。
- 为了进一步提升船舶轮机的安全管理水平，船舶企业还可成立专门的督察小组，做好船舶轮机安全管理工作的监督和检查，尤其是做好船舶安全管理体系的检查、监督，了解其运行情况。对此，一方面，督察小组要加大轮机人员工作态度、政策执行情况、工作成果的检查；另一方面，要重点做好安全管理工作的检查，确认轮机管理人员的安全管理工作是否存在疏漏。另外，督察小组还应对船舶轮机的人员风险进行评估，并采取有效的风险防范措施，从而持续提升船舶轮机的安全管理水平。
- 应定期或不定期地开展轮机人员培训工作，提升轮机人员的管理水平，从而有效降低各种安全事故的发生，提升船舶轮机的安全性。
- 应落实责任制，明确相关管理人员的职责，并完善追责制度，真正提高相关管理人员的责任心。

## 加强对“环境”的防范管理

对船舶轮机安全管理影响最大的环境因素是恶劣天气，如暴雨、浓雾、雾霾等能见度低的都属于不良天气，很有可能造成船舶碰撞、行使困难等事故发生。

- 首先，要高度重视恶劣天气的防范工作，并做好持久工作准备。同时，还应明确组织领导、落实到人，为防范工作的开展奠定良好的基础。
- 其次，要做好恶劣天气的提前预警。比如要持续观察天气情况，并加强与气象部门的沟通，及时了解、掌握航海区域的天气情况，而后依据天气情况，做好相应的安全防范工作。
- 最后，做好轮机的现场监管。比如重点做好下轮机推进装置、辅助装置、管理系统的监督与检测，若发现问题要及时处理。若发生了影响到船舶安全行使的故障，则应立即报告船长。

## 加强对“设备”的防范管理

船舶轮机设备在恶劣环境下长时间运行难免会发生各种故障，影响到船舶轮机的安全运行。

对此，为了有效防范设备风险的出现，船舶企业可采取以下防范措施。

- 首先，应依据船舶轮机结构，划定不同的管理职责，从而有效保证船舶轮机设备的可靠、安全，比如要求大管轮能做好轮机推进系统的检测。如自控装置、安全检测报警装置、变频柜、主机供油单元等。如果检测出故障，则应及时处理。
- 其次，制定日常检修、定期检修制度，做好轮机设备的定期检修。对于部分轮机设备，开展日常的检修工作就可，但是对于一些大型设备，需要每季度或每年进行一次检修。对此，相关管理部门可依据实际制定比较完善的检修制度，进一步提升设备的安全管理。
- 最后，应制定完善的轮机设备故障处理流程，从而及时处理好轮机设备故障。比如为了减少轮机设备柴油机拉缸出现故障，可采取以下防范、处理措施：
  - 合理选择柴油机的润滑油，具体需依据船舶设备的运行情况。
  - 定期更换润滑油，因为在运行一段时间后，润滑油的使用性能会下降。
  - 要认真检查拉缸的运行情况，重点检查其运行温度，以免温度过高造成拉缸故障。
  - 若是拉缸发生故障，则应认真检查；若是机械损伤故障，就应及时更滑。若是操作故障，则应规范相关管理人员的管理行为，同时，应及时上报、记录。

总的来说，只有加强设备的定期检修、维修及故障处理，才能解决设备因素带来的安全管理风险。

# 三 船舶轮机安全管理风险的评估

船舶轮机安全管理风险评估的目的是对可能发生的风险进行预判，并提前制定好风险防范措施，从而降低船舶轮机安全事故的发生率。

- 首先，船舶轮机安全管理风险评估的步骤主要包括：确定风险评估范围、识别并标识风险、分析风险危害程度、制定有效的防范措施、组织并实施风险防范措施。以船舶轮机修理前的风险评估为例，其风险评估范围就是轮机设备。而后可以采用大数据分析、技术检测等手段进行风险评估。若是发现了故障则应及时标识出。比如若是发现油储部门存在安全风险，工作人员则应依据风险等级，采取设置“严谨明火”标识、提醒其他人注意行为规范、更换零部件等防范措施。需要注意的是还应当进行现场确认，明确风险因素，并制定有效的预防措施。另外，工作人员若是无法明确风险，则应及时采用技术研讨、资料搜集等方法，进行风险的识别、判定。
- 其次，应合理选择风险评估方法，常见的有预先危险性分析法、故障类型及影响分析法、工作危害分析法等。具体可依据风险类型、评估目的进行选择，比如对于轮机操作风险可采用工作危害分析法，其应用流程为选择操作过程、分解操作过程、识别每个步骤的危害及后果、风险分析、控制措施、定期评审。在进行危险识别、风险分析过程中，要先拟定操作步骤，而后进行操作任务的分解，并识别每个操作步骤可能产生的危害，同时，对现有的安全措施进行安全评估、风险分析。
- 最后，可建立风险分析评估表，作为风险评估记录文件，并作为以后的风险管理提供参考。风险评估表应当包括危险种类、风险定性评估、采取措施、修正后的风险评估等内容。

总的来说，防范风险的前提是准确评估、分析风险，了解风险的产生原因。在船舶轮机安全管理的风险防控中，也应如此。

# 四 结语

通过有效分析、管理船舶轮机的风险可以提升船舶行使的安全性、可靠性，减少船舶安全事故的发生。

但是新时期，船舶管理的内外形势都发生了变化，在这一背景下，若要预防船舶轮机安全管理的风险，就要制定规范的风险评估、分析流程，深入了解轮机安全管理中存在的风险，再采取有效预防措施。
