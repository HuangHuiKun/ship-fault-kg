# 导读

“润滑”是机械作业中的重要指标，滑油可以传递热量、起到冷却、润滑的作用，同时也能有效保护部件功能，减少故障几率。

滑油管理与改进最近几年被广泛讨论，随着船舶行驶年限的增长，滑油管理直接会影响改变船舶的使用安全和寿命，将船舶副机滑油管理引入到管理研究课题，其研究价值较高、实践作用至关重要。

# 一、“分离净化”功能的延展与丰富

本次研究的船舶副机是直列式筒型活塞柴油机，这类机械燃烧后会出现大量残留物，会影响到副机滑油的纯度，随着使用累加，残留物会进一步污染影响到其他部件油膜，因此滑油管理改进首先就要解决残留物的“分离净化”问题。

滑油管理在“分离净化”方面采用的是间断性、批量分离净化处理，副机停止使用期间，对副机滑油机箱进行分离净化，清洗离心滤器、更换滤芯，油泥厚度超过 0.5cm 的，需要反复分离净化。

但一般情况条件不允许，副机停止时间无法满足规定要求的“分离净化”操作规程，因为处理时间不能影响行驶、也不能有太多的经济成本压力。

为此可以改进“分离净化”处理流程，采用连续、不间断的分离办法，随时监控、观察副机滑油的存量、纯度，行驶进程中，也可使用滤纸、离心滤器对油质进行观察处理。

同时，设置油质监测记录表，统计油泥每增加 0.2cm 大概行驶的时间，加大分离净化的频次，尤其是停机处理时，更需针对性的检验离心滤器的油泥厚度。

# 二、综合多项指标检验精细化管理

滑油黏度可以客观反映出船舶副机的使用情况，如：

TBN、TAN、不溶物、沉淀物、残炭值等指标，经化验检查可测定，副机在使用 1000-1500h 后要更换滑油，超出这个时间范围，滑油指标将会严重偏离正常值。

在分离净化处理时，可参照滑油黏度的各项指标对滑油性质及功能进行判断，一切以实际测量指标为准，不能按照既定数值来判断。

通常情况下，副机、辅滑油分油机同步运行也是残留物分离、分解的过程，经检测，分油机可以延长滑油黏度各项指标的变化时间、帮助管理人员查验副机滑油分离净化效果。

分油机一方面让滑油黏度检查效率提升了，还能促进分离净化工作不间断、连续进行，为船舶日常运行节约几万元的消耗费用。

除了从滑油黏度指标检测加强精细化管理之外，还可以通过滑油离心滤器观察的方式，对副机滑油情况进行排查，如：用手触摸滤器外侧、查验滤器运行过程中有无零部件异样响动；

又如：拆卸滤器后，要查看滤器内的油泥厚度、质量，如果油泥厚度低，则代表滤器分离净化效用显著，如果厚度高，则代表滤器的功能已经无法满足分离净化要求，则要对滤器进行检修。

围绕船舶副机滑油管理需要从多个角度、依据多项指标进行观察和检测，精细化管理的目的就是要细化管理工作、寻找更多的管理依据和指标，从科学的角度出发，以经验分析为主要方法，促进船舶副机滑油管理效率及效果的提升。

# 三、采用多种措施提高分油机的分离效果

副机滑油管理要重视对分油机的功能管控及监督，分油机的分离温度、流量可以反映出分油机的分离效果及表现，分离温度控制90℃、流量控制300-600L/h，分油机的分离效果最佳。

为确保分油机的使用功能达标，结合分油机的使用操作流程，可采取以下措施加强管理。

一是，加强对分油机的自动控制程序管理，延长“置换水”的时间，从原来的 5-9s上调至 15s，置换水的时间延长可以帮助分油机排渣、排渣也是污染物分离净化的方式，所以从侧面能提升滑油的纯度。

从管理实践角度看，通过自动控制程序操控管理，便能够达到提高分油机分离的效果，管理效率还是值得肯定的。

二是，加强副机燃油系统管理，燃油中的杂质会干扰滑油的纯度，副机燃油系统使用完燃油后会将燃烧后的残留物传递到滑油当中，干扰影响油膜，所以提高副机燃油系统的燃烧效率也是提高滑油纯度的方式。

如：采用排气装置，促进系统燃烧充分、降低排除残留物的容量和密度；定期检查副机燃油系统进行功能调解，在常规操作下确保副机燃油启动及运行效果良好。

三是，副机滑油损耗量记录及观察，副机使用滑油量是相对固定的，在一段时间内如果滑油量增加则说明残留物对滑油量的干扰及影响加大了，这时候副机滑油系统的运行也会受到影响。

日常检查办法有：

①用游标卡尺检查副机油位高度；

②通过油量下降高度计算固定时间内滑油损耗量；

③对比副机滑油在正常使用下用量消耗标准；

④根据滑油损耗量减少及改变情况，采取措施缓解过度消耗、损耗情况。

# 四、结束语

总而言之，随着我国贸易事业的进步与发展，船舶运输管理方面的工作受到高度重视，未来船舶副机滑油管理理念和技术会不断提高，配合船舶制造工艺、功能的发展态势，各项改进策略也会在不断实施中纠正、改变不足或问题。

从成本节约角度看，船舶副机滑油管理具有很高的实践意义与价值，一方面，可以降低船舶运输的运营成本，另一方面还能够降低、削弱船舶运输的污染问题，可谓是一项关键的管理任务。
