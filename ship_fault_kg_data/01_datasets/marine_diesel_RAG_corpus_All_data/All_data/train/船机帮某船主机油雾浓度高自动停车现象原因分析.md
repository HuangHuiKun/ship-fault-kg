# 导读

油雾浓度探测器是预防柴油机曲轴箱爆炸的一个重要安保装置。

其主要功能是监视柴油机曲轴箱油雾浓度，预防曲轴箱着火爆炸。

柴油机在运行一段时间后，机件温度升高，主机曲柄箱中的滑油会产生油气，这些油气在曲柄箱中与较冷空气混合会形成油雾。

当油雾浓度超过一定值时，可能会引起曲轴箱爆炸，造成严重的机器损伤事故。

柴油机装有曲轴箱油雾浓度探测器后，一旦油雾浓度超过正常标准，能及时发出声光报警，同时使主机自动降速或停车。

由此可见，主机曲轴箱油雾浓度探测器是实现机舱自动化，保证柴油机安全运行的重要设备之一。

某船采用了某型油雾探测器，该探测器用于保护燃气发动机、柴油发动机和双燃料发动机等大型发动机，避免由于曲轴箱中自发形成的油雾而发生油雾爆炸。

该型油雾探测器是主机安全保护系统的组成部分，用来保护操作人员的生命和安全，并避免严重的连锁损伤。

曲轴箱内的气体由于抽气泵所产生的真空，通过连接箱中的集管进入底板中的分离器，大油滴在离心力的作用下被分离开来并通过导管送至抽气泵排出，防止它们进入测量通道而引起误报警。

经过分离的气体送到测量通道中，由通道两端的光电传感器进行测量。

当油雾浓度因为曲轴箱内部故障而有所升高，阻光度增加到一定程度时，光电流减弱至一定值，测量装置发出报警信号并使主机降速或保护性停机。

流过检测室的气雾最后被抽回曲轴箱内。

# 一、故障现象

某船在开展航行试验性能验证过程中，左、右主机多次出现油雾浓度高报警停机，此时油雾监测装置由充放电板和主机监控同时供电。

开展主柴油发动机因曲轴箱油雾浓度高报警停车现象原因分析时，首先鉴别是真报警还是误报警。

打开曲轴箱目视检查、点测主轴承温度正常，并且更换油雾浓度探测装置空气滤芯，清洁装置内部，重新调整气压。

再启动右主机试车，测量主机各缸爆压，各缸爆压比较平均，运行0.5h后，油雾浓度探测器再次报警，机旁人员应急处置避免了应急停机。

取样检查右主机滑油，发现滑油中含有少量水分。

右机油雾浓度探测器出口空气湿度大，探测器内部有较多凝水，判断该主机并非真正意义油雾浓度升高，而是因为滑油中水分蒸发，油雾中携带的水蒸气触发报警出现报警。

通过分析发现有以下几种情况可能诱发油雾浓度探测器报警：

1. 曲轴箱内滑油水分含量过高，水比滑油更容易蒸发，油雾中携带的水蒸气可能会触发装置出现报警；
2. 船舶航行于高温高湿区域；
3. 油雾浓度探测器因电子元件等老化而导致性能下降；
4. 油雾浓度探测器本身的灵敏度设置得太高，灵敏度设得越高其报警值就越低，于是油雾浓度稍有升高就触发报警；
5. 如果油雾浓度探测器附近因为某种原因存在大量烟雾，烟雾可能经新鲜空气吸口进入检测单元而触发报警。

# 二、原因分析及整改措施

根据故障树分析法，从油雾浓度监测装置外部接口以及装置本身开展全面排查原因分析工作。

## 1. 油雾浓度监测装置外部检查

打开主机曲轴箱盖板，目视检查主轴承、曲轴止推块和连杆大端，未发现零部件表面变色、异常磨损等异常情况；

检查主机连杆大端，连杆大端灵活无卡滞，未发现异常；

打开燃油凸轮轴和进排气凸轮轴盖板，目视检查凸轮轴，未发现零部件表面变色、异常磨损等异常情况；

盘车检查曲轴和凸轮轴，未发现异常；

检查主机曲轴箱透气管路系统，松开水平段管路连接法连，水平管路段未发现大量存油，回装管路并对管路进行清洁处理。

脱开管路系统油雾分离装置排污管，未见堵塞情况；对主机滑油进行取样化验，滑油的化验合格。

## 2. 油雾浓度监测装置本身检查

检查清洁油雾监测装置光感传感器，存在少量油渍，并用酒精进行清洁；

检查油雾监测装置压缩空气进口气水分离滤器，未发现明显杂质，存在少量冷凝水；

将左主机油雾监测装置的控制空气由主机启动空气系统临时改为经过空气干燥器处理的压缩空气控制系统供应，主机空车运行40分钟左右，左右机油雾监测装置雾浓度都显示相对正常；

油雾监测装置控制空气压力调整为6.5公斤左右油雾监测装置油雾浓度显示正常；

油雾监测装置在油雾浓度高报警的状态下，拆除曲轴箱至油雾监测装置光感传感器的管路，油雾浓度高报警未复位。

继续根据油雾监测装置要求，对探测腔内负压进行调整，两台机均调整为要求值-60 mmWs，左机波动接近70%报警值；

检查发现，油雾监测装置在充放电板供电和主机监控供电分别供电时，油雾浓度显示灯存在差异。

充放电板供电时油雾浓度显示相对较高，主机监控供电时油雾浓度显示相对较低。

于是针对供电电源进行排查，油雾监测装置由充放电板和主机监控同时供电，主机空车运行油雾浓度高报警。

油雾监测装置由充放电板与主机监控同时供电，主机备车状态下出现油雾浓度高报警。

油雾监测装置改为单独主机监控供电后，主机油雾浓度高报警消失，主机持续运转，没再出现油雾浓度高报警；

为进一步验证，左机使用充放电板和UPS同时供电，右机仅使用UPS供电，左机出现油雾浓度波动接近70%报警值，关闭左机充放电板电源恢复正常。

再次将左机充放电板电源供上，左机继续出现波动，右机一直正常。

在右主机内部控制箱处增加稳压电源，左机不增加，两台机同时由充放电板和UPS供电。

左主机油雾浓度出现波动并报警，此过程中右主机一直处于正常状态。

充放电板的电压调至26 V、25 V、24 V均未恢复正常，关闭充放电板电源后左主机恢复正常。

左机改用UPS供电后，持续运行未出现油雾浓度高波动报警等异常现象。

## 3. 整改措施及结果

通过对多次故障现象的分析，可以发现左右机多次油雾浓度高报警基本都是同时产生，结合排查情况初步判断故障原因应为两机共同的外部介质影响，影响介质主要为滑油、控制空气和供电电源。

主机滑油取样化验合格，可以排除因滑油品质问题导致油雾浓度高的可能性。

控制空气的影响主要分为三个方面：

一是气压的影响，在排查过程中将油雾监测装置控制空气压力根据设备厂要求调整为6.5公斤左右，但后续仍然复现了浓度高报警；

二是气源品质的影响，在排查过程中将左机从压缩空气改为控制空气，但后续仍然复现了浓度高报警。

三是探测器腔内负压的影响，在排查过程中利用主机厂自带的备件工具将两机探测器腔内负压均调整为-60mmWs，但后续仍然复现了浓度高报警。

本船两台主机由两路电源同时供电，一路为充放电板供电，一路为主机监控UPS电源供电。

首先，在两路电源同时供电情况下，两机都出现了油雾浓度高报警；

其次，将两机均改为UPS供电后，故障消失并且故障没有复现；

最后，将左机使用充放电板和UPS同时供电，右机仅使用UPS供电，左机出现油雾浓度高波动情况，右机正常。

鉴于以上情况，在右主机内部控制箱处增加一个稳压电源装置，左机不增加，两台机同时由充放电板和UPS供电时进行验证。

发现左机出现多次油雾浓度高报警，右机一直正常。

后将左机改为UPS单独供电，左机也再未复现此故障。

# 三、结论

油雾探测器是船舶柴油机安全运行的重要保护装置，某船航行试验过程中多次出现因两台主机油雾浓度高而导致自动停车的现象。

针对该现象开展了详细排查工作，原因定位于充放电板的电压波动引发油雾浓度高报警，进而导致自动停车。

最后通过加装电源隔离模块顺利地解决了该问题。

通过问题原因分析，确认在每台主机控制箱内部加一个稳压电源给油雾浓度探测器单独供电，从而完成整改工作。
