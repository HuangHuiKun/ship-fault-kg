# 导读

ICU 全称为 Injection Control Unit，中文称为喷射控制单元，是瓦锡兰 RT-Flex 系列柴油机重要的组成部件，在高压环境下，各组件进行高速反复的动作，故障率较高，因此在设计制造时，对材质、精度、间隙等要求非常高。

ICU 出现故障的概率很高，船上说明书对 ICU 的介绍却很少。

让柴油机管理人员增加对 ICU 的了解，加强日常管理，减少故障的产生，对船舶的安全运营和节省备件维修费用有十分重要的意义。

下面就以 RT-Flex48T-D 型柴油机为例来分析其 ICU 的结构原理和运行管理，其他RT-Flex 系列机型也可从中借鉴参考。

# 一、ICU 的结构组成

图1 ICU剖面图

如图1，RT-Flex48T-D 型柴油机的 ICU 主要由ICU本体（Injection control block）、1 只燃油量传感器(Fuel quantity sensor)、1 只喷射控制活塞(Injection control piston )、2 只共轨电磁阀(Rail valve)、2 只喷射控制阀(Injection control valve)和相关管路通道组成。

喷射控制活塞缸位于 ICU 本体内，喷射控制活塞在缸内运动的时候，活塞杆的运动量会被燃油量传感器检测到。

燃油量传感器把活塞运动 0~50mm 的位移信号转变成 4~20mA 的电信号并反馈到 WECS-9520 系统。

为了保证油量传感器正常工作，燃油量传感器装在旁边温度较低的传感器壳体内。

本体的两侧分别是燃油端和控制油端，两端是完全分开的，但两端的泄漏通过同一泄漏孔泄放。

喷射控制阀是压力油控制的两位三通阀，通过阀芯的动作给相应的油头提供燃油。

共轨阀是由超快的电液电磁阀，考虑到很高的动作电流以及电池铁芯的热负荷，所阀芯动作很快，大约为 1 毫秒，最多不超过 4.5 毫秒。

为了动作迅速到位，行程也是很短的，大约为 0.3 毫米位移量。

这个共轨阀是双稳态的，即动作到一个位置之后，这个位置会一直保持，直到接到下一个动作指令。

在安装或更换这个双稳态电磁阀之后，其阀的位置是不知道的，为了确保主机停车时，阀一直处于安全位置，WECS-9520 系统会间隔一段时间送出一个复位信号格共轨阀。

# 二、 ICU 的工作原理

图2 ICU工作原理

基本原理如图2，在没有喷油信号的时候，共轨阀工作在下位，喷射控制阀上端油被泄掉，阀芯在弹簧的作用下工作在下位，喷射控制活塞两边都通共轨燃油，但由于活塞左边接触压力油的面积比右边大，活塞向右移动，为喷油作准备。

需要喷油时，首先系统给共轨阀一个喷油脉冲信号，使共轨阀工作在上位，伺服油推动喷射控制阀阀芯，使其工作在上位，共轨燃油推动喷射控制活塞左移，将活塞左边的燃油压如喷油器进行喷油。

燃油量传感器通过测量活塞的位移量来判断喷油量，并把测量结果提供给FCM-20 模块，当喷油量达到时，FCM-20 模块给共轨阀提供一个复位信号，使其工作在下位，为下一次喷油作准备。

所有的喷射阀，都对应着该缸的喷射共轨阀，是分别单独控制的，但却是通过一个共用的喷油量反馈信号进行地。

通常情况下各个喷油器是同时动作的，在一个单行程中将燃油喷入。

在特殊情况下，可仅仅使用一个喷油器将燃油喷入，或者实行喷雾中断方式（多次喷入模式）。

为了改善低负荷情况下燃油雾化质量，在低负荷运行时将会有一个喷油器自动切断。同时为平均热负荷，两只喷油器会定期交替使用。

# 三、ICU 喷射过程的控制

在实际的喷油过程中，无论是喷油只有还是喷油结束后的“返回”指令，在指令下达到实际执行都会有一小段延时。

这个时间称为滞后时间（deadtime），会在WECS-9520 内部进行补偿。

图3 ICU喷油过程控制

如图3，红色的曲线是一根简化的喷油曲线，这根曲线是在一个喷油周期里，通过燃油量传感器得到的。

蓝色的曲线显示的是command timeframe，显示了提供给共轨阀阀芯由喷油到返回的动作命令过程。

在燃油量传感器增加 4%就被认为是喷油动作开始，在喷油指令发出到这一点之间的时间被称为 begin deadtime。

在得到返回指令之后以及 return deadtime 结束之前，燃油量传感器还是继续喷油动作的。

这里的最大喷油量被用来给 WECS-9520 来提供实际的燃油指令。

Injection return overshoot 是用来补偿外部系统的速度调速器，使其调节燃油指令直到达到理想转速。

喷油始点由曲柄转角和可调喷油定时（VIT）通过计算得到，有效喷油始点是根据“喷射控制活塞”移动位置判定的，通过喷射控制活塞行程的大小，测定实际的喷油量。

再将测到的喷油量与速度控制器发出的燃油指令信号经行比较，计算出喷射终点。

根据这次喷油测量到的喷油始点滞后时间，计算出下一次喷油循环的始点滞后时间。

喷油量和时间的测量都有靠燃油量传感器实现，如果遇到故障的燃油量传感器，相应的 FCM-20 会用一个固定的deadtime 来计算喷油提前角和一个人工的斜坡信号来控制喷油量，这样会使受影响的气缸喷油量与正常的气缸相比要少。

# 四、 ICU 的日常管理要点

日常的管理对于延长 ICU 各组件的使用寿命，减少故障发生，做好事故预防，及时消除隐患，保障设备安全有十分重要的意义。

作为船东或船舶设备管理人员，主要可以从以下几个方面着手：

（1）保证燃油质量。

燃油在提炼的过程中会残留具有危害性的催化颗粒（Cat Fines），主要是氧化铝、氧化硅等成分。

这些颗粒进入 ICU 后会对喷射控制阀和喷射控制活塞造成严重的磨损，大的颗粒还有可能直接造成喷射控制活塞和控制阀卡死。

瓦锡兰厂家推荐进机燃油的铝+硅含量不超过15mm/kg。

很多厂家提供的燃油都达不到这一标准，这就要求一方面在燃油采购环节进行控制，另一方面要厉害好船上自身的净化设备。

（2）保持燃油温度稳定。

在日常管理中，共轨燃油的温度要保持在要求的范围内，共轨管的伴热加热要保持良好，防止伴温不好导致的油温变化出现热胀冷缩现象。

伴温效果差会导致燃油粘度变大，影响活塞运动。

通常情况下柴油机持续使用重油，如确实需要更换轻油，温度变化不宜过快。

瓦锡兰公司推荐重油转换成轻油在小于 50%合同最大功率情况下进行。

（3）利用 Flex Viewer 软件监控柴油机状态，及时发现问题隐患。

在 FlexView9520 的检测界面，可以实时监测燃油量传感器传回来的电流，响应时间，喷射时间等参数，可以进行比对，及时发现问题。

故障时里面的报警功能会显示问题所在，为主管人员的判断提供最直接的依据。

在 Flex View 界面的 adjust 子菜单下调整 ICU 的 inject begin offset(喷油角度补偿)，即调整喷油提前角，可以获得比较平均的爆炸压力。

定期检查 Flex View 中的“喷射曲线”，可以通过曲线了解 ICU 的磨损情况。

（4）定期检查 ICU 的泄漏，及时更换易老化的密封件。

ICU 泄漏分几个方面，第一种是外漏，只要保持共轨箱的清洁，就容易发现，如有外漏，拆检相关部位，更换相关密封圈即可。

第二种是喷射控制阀内部泄漏，直接通过泄漏管到溢油舱。

但由于 ICU 泄漏与高压油管泄漏共用一根泄放管，出现报警时要注意排查。

平时应经常检查泄油管的温度和溢油舱的油位，及时发现 ICU 的漏油情况。

第三种情况就是喷射控制活塞的活塞杆轴封不严发生泄漏，这种泄漏不易观察，但燃油既然传感器腔内，会在腔室内形成积碳，使活塞杆移动偏移，导致测量故障。

（5）加强润滑油的管理。

ICU 上的共轨阀采用主机系统油作为伺服油，其温度、粘度、洁净度都影响着共轨阀的运行。

所以要按说明书要求选择滑油的规格和牌号，还要在运行过程中加强净化。

除了主机系统油的过滤，在进伺服油泵时还增加了自清滤器，另外在 ICU 上进共轨电磁阀之前还有一个小滤器。

平时除了要保持润滑油温度稳定在规定范围，经常清洗各个滤器，保证机油分油机正常运行之外，还有定期化验系统油的成分是否符合要求，厂家建议 3000 小时左右化验 1 次。

（6）经常检查电气线路的连接点。

柴油机在运行的过程中会产生一定的振动，这些振动时间长了会影响电子控制单元、电磁阀、传感器等接线点的松动，引发故障，所以需要降低机舱的振动源并经常检查电路连接的可靠度。

（7）如因某些原因需更换 ICU 模块，注意更换后要充分放气，不然容易出现流量活塞卡在末端问题等报警，解除报警后进行各缸功率的平衡操作，运行一段时间后可恢复正常。

另外尽量不要一次更换 2 个以上的 ICU，如果2 个缸试车时同时出现不动作或不发火，会使主机功率严重不平衡，转速出现很大波动。

# 五、故障诊断与排除

ICU 的故障在 RT-Flex 系列柴油机中是比较常见的，当出现 WECS-9520 有关警报，某个缸燃油自动切断，主机自动降速，燃油泄漏报警等故障现象时，都应该检查确认是否是 ICU 故障引起的。

Flex Viewer 软件也可以很方便的帮我们迅速判断某些故障。

总的来说，ICU 故障主要包括以下几个方面：

（1）燃油量传感器故障。

当某个燃油量传感器出现故障时，系统发出“ME injection quantity sensor #nn meas.Fail.”报警，但是主机不停车，不降速。

我们前面提过，传感器故障只会是这个缸的喷油量变少。

燃油量传感器的更换同样不需要停车，只要松开相应的固定螺栓，就可以直接更换。

（2）喷射控制活塞停在某个位置。

出现喷射控制活塞相应的报警，Flex Viewer 上该缸的喷射曲线为一直线，会引起主机降速。

喷射控制活塞停在某个位置不一定是卡死，有可能是在共轨阀的作用下进行的液压锁闭，也有可能是油温突变临时卡住，大多数情况下可以先停车，通过泄压阀泄放燃油共轨压力，然后再重新起动。

如果还不能排除故障，就要考虑更换整个 ICU 模块了。

（3）共轨电磁阀故障。

RT-Flex48T-D 型柴油机每缸有 2 个共轨电磁阀，如果有一个电磁阀故障，在低负荷是照样运转，随着负荷的增高，与别的缸排温就会出现较大偏差，所以一旦有机会，要立即更换损坏的共轨电磁阀。

Flex Viewer 的界面可以看到是哪个电磁阀故障。

停车后，断开轴承油泵，释放控制油中的压力，就可以更换共轨电磁阀了。

（4）喷射控制单元（ICU）某处破裂。

本体的破裂只会引起漏油，通常会出现漏油报警。

这种故障没有别的处理方法，只能更换。

打开共轨箱盖板就可看到哪缸漏油，停车，泄放燃油共轨和伺服油共轨压力，松开相关连接管路进行更换即可。

（5）喷射控制阀故障。

由于劣质燃油的使用，喷射控制阀 ICV 出现的概率相对较高。

而且就算喷油不正常了，也无法从 Flex Viewer 的界面看出异常。

喷射控制阀的故障主要有两种：

一种是阀芯磨损泄漏过大，另一种是阀芯卡阻无法回到原位。

喷射控制阀的泄漏过大会引起主机起动困难，由于 ICU 泄漏管连到溢油舱，当发现溢油舱油位上升较快时，可松开各缸 ICU 泄漏接头，找出哪一缸漏油严重。

如果是阀芯卡阻，会使该缸在共轨电磁阀归位后继续喷油，引起严重后燃，可以从排温和烟色加以判断。

当然要先排除喷油器和气阀故障，也可以在拆除高压油管后盘车看出油口是否冒油。

喷射控制阀与共轨电磁阀是一一对应的，但无法像共轨电磁阀那样判断出哪一只故障，所以通常把故障的一个缸两只喷射控制阀同时更换。

# 六、结束语

ICU 组件是 RT-Flex 系列重要的组成部分，也是最容易出现的部件之一。

轮机人员都应掌握其结构特点和工作原理，熟练使用监控软件和有效进行日常管理，预防故障的发生，延长各组件的使用寿命。

当故障发生时能及时找出故障原因并排除，确保船舶航行安全。
