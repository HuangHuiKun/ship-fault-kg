# 故障实例

某海事单位巡逻艇主机系康明斯NTA855型柴油机，某次航行途中突然出现加载后水温快速上升直至沸腾的情况。

据轮机管理员描述和查阅机电记录簿，发动机此前工作状况很好，各参数正常。

查看发动机，在水箱水面发现有少许油花及黑色粉末。

其余基本正常。

补足冷却液后做系泊试验。

将转速保持在1000r/min，水温快速上升。

在试验过程中，发现膨胀水箱的通气孔处有水泡不停地冒出，并且随着转速的上升，频率加快。

水温达到90℃以后，水泡带着蒸汽大量连续地往外翻腾。

# 原因分析

NTA855柴油机船机的冷却系统主要由膨胀水箱、热交换器、水泵、节温器、水滤器和水道水管等组成，如下图所示。

NTA855柴油机冷却系统及水路

其中热交换器发生堵塞、节温器卡死、水道阻塞、水泵损伤等都会使水温升高。

从图中可以明显看出，会使冷却水中出现大量气泡且使得少量油进入冷却水的，只可能是排气管或缸头部分产生了裂纹等，从而使得气体进入水道并从通气孔冒出来，并带出少许碳末。

# 重点检修

按拆卸顺序，首先拆下排气管做水压试验。试验发现：排气管没有裂纹。

接着拆缸头。

在拆缸头前，应仔细观察比较3个缸头及气缸垫周围的渗油情况，根据各种迹象找出最可能发生故障的1只，以减少工作量。

经观察，发现在第5、第6缸的缸垫周围有一段油迹较多，且有少许渗淌痕迹。

拆下该缸头，发现气缸垫的气缸孔和水孔间的隔料有细微破损，发动机的爆炸气体冲开了一条小通道窜入水道。

更换新缸垫后，发动机故障消失。

# 诊断总结

此例故障是由于采用的气缸垫质量较差，被爆炸气体冲裂后高温气体进入水道引起的。

在察看过程中，由于观察较仔细，觉察到了在沸腾前水箱通气口就不断有水泡冒出，从而为快速解决故障提供了思路。

同样在拆缸头前也能够发现细微的痕迹，提高了速度。

结合上期推文可以看出，柴油机的故障诊断和排除应该遵循从简单到复杂的原则，按照不同的故障现象收集信息、分析信息、重点拆检和修理三个步骤进行。

在诊断和排除过程中还要注意收集故障信息，积累经验。

同型号机器故障的现象和原因有很大的共同点，同一机器的前后故障也有很大的联系，把握这个原则，就能做到排除故障心中有数，排除过程有条不紊。
