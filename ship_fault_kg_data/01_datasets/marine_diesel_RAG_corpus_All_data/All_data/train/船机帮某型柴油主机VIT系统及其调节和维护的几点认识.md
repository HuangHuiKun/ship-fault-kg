# 导读

可调喷油定时系统（Variable Injection Timing System，简称 VIT）应用多年的实践证明，它能够有效地提高柴油机的动力性、经济性、排放等方面的指标，目前已为多种品牌和型号柴油机采用。

为保持该系统的最佳状态，日常管理很重要。

现就MAN-B&W 的 L/K/S-MC 系列柴油机的 VIT 系统谈些使用、维护意见，敬请指正。

# 一、可调喷油定时系统 VIT

VIT 系统的作用是节油和减少废气排放。

## 1、原理

VIT 系统的技术途径是提高爆压（P max ）——某选定的负荷区间（例如50%~85%， 这里的85%被称为转折点，某些型号柴油机设定在75%~78%），令其P max 高于不使用 VIT，且随负荷增加逐渐达到允许的P max 最大值；负荷高于转折点，令P max 不再随负荷增大而升高（保持在允许的最大值），见图1。

图1 P max 、燃油齿条格数、VIT齿条格数等与负荷关系曲线

提高 Pmax 的方法，是加大喷油提前角。

加大喷油提前角， 通过垂向移动高压油泵套筒即改变高压油泵套筒上回油孔的位置来实现，为此：

高压油泵套筒， 与高压油泵本体之间通过螺纹动配合，且套筒外缘有齿圈与 VIT 齿条啮合。

设置 VIT 控制系统——感受柴油机负荷信号-放大-执行机构通过VIT 齿条转动各缸高压油泵套筒改变喷油定时。

## 2、构成

VIT气动控制系统， 由控制空气管路（含节流止回阀6）、柴油机负荷传感器暨放大器（以下简称负荷传感器）、执行机构等组成（见图2）：

图2 VIT 控制系统示意图

空气管路（各缸共用），连接各组件，为系统提供动力。

其中的节流止回阀6的作用，一是防止VIT控制系统过于灵敏（随调速器轻微波动频繁调节而不稳定）；二是防止高负荷区突然大幅减负荷时（负荷传感器输出空气压力大幅突增引起）爆压超限。

负荷传感器（暨放大器，各缸共用），感受并放大柴油机负荷信号，作为指令传送到执行机构。

执行机构（每缸一套），包括位置伺服器、连接杆、定时调节杆、VIT 齿条等，按负荷传感器暨放大器来的指令， 分别拉动各缸VIT齿条以转动各高压油泵套筒， 套筒转动再引起垂向移动以改变套筒上回油孔的垂向位置，从而改变喷油定时。

## 3、爆压按柴油机负荷分三个阶段控制

VIT 控制系统中，爆压按柴油机负荷0~50%、50%~85%、85%~100%等分三个阶段控制，主要通过负荷传感器、受柴油机油门拉杆控制的一个“杠杆”、限位A、限位 B 等实现（见图3，结合图1）。

图3 VIT 控制的三阶段

### （1） 负荷 0 ~ 50%区间

“杠杆”被限位 B 的弹簧拉紧以限位 B 的外壳为支点，受油门拉杆控制，不接触负荷传感器的触点 C；但负荷越高“杠杆”越接近触点 C，待到负荷 50%时“杠杆”才接触触点 C。

所以：

VIT 不起作用（VIT 齿条格数为零）。

VIT 齿条格数为零，则燃油齿条格数和爆压都与没有 VIT 一样地随负荷增减。

### （2）负荷 50% ~ 85%区间

“杠杆” 仍被限位 B 的弹簧拉紧以限位 B 的外壳为支点，上端受油门拉杆拉动向右倾斜，推动触点 C。

负荷 50%，“杠杆”开始接触负荷传感器的触点C，VIT 开始起作用。

负荷大于 50%而小于 85%：

随负荷增加，触点 C 受“杠杆”推动缩进更多，VIT 齿条格数增加。

与没有 VIT 相比， 虽然燃油齿条格数的变化相同，但爆压因 VIT 齿条格数增加而更高。

负荷 85%，“杠杆”同时接触限位 B 和限位 A：

触点 C 缩进达到最大值，VIT 齿条格数也达到最大值。

与 没有 VIT 相比 ， 虽 燃油齿条 格 数 相 同 ，但 VIT 齿条格数达最大值，爆压也达到允许的最大值。

### （3） 负荷85%~100%，“杠杆”以限位 A 为支点：

随负荷增加，其上端被油门拉杆拉动逐渐右移，则限位 A 以下部分相应左移 （下端拉长限位 B 的弹簧），触点 C 因而向左伸出，VIT 齿条格数相应减少。

与没有 VIT 相比， 燃油齿条格数同样增加，但VIT 齿条格数相应减少， 爆压不再升高而是保持在允许的最大值。

VIT 装置，在一定负荷区间（例如50%~85%）提高爆压，在更高负荷区间（例如 85%~100%）又限制爆压，可大幅提高柴油机的经济性并减少废气排放。

# 二、VIT 系统的调节

全面、精确的调节，应由专业技术人员进行，且需要精确的测试设备和充裕的时间。

船上人员测试调节，主要是爆压和节流止回阀。

## （1） 调节爆压，包括单缸调节和总调两种。

调节单缸爆压， 只需改变该缸 VIT 齿条与位置伺服器间杆的长短，即可改变单缸喷油定时。

某些型号的柴油机，可调节位置伺服器的位置改变单缸喷油定时（因其每缸一套）。

总调（同时调节各缸爆压），只需调节负荷传感器（在机旁应急控制台附近）的安装位置（即其与杠杆的相对位置，见图 3），即可同时调节各缸爆压（同增或同减）。

但需注意：

只有燃油性能变化较大或高压油泵磨损很大，才需要同时调节各缸爆压。

## （2）节流止回阀的调节

为使 VIT 系统达到规定的工作质量， 下列情况需调节节流止回阀：

系泊试验或航行试验前（初步调节）；

重载航行，若燃油齿条变化少于±2 格（例如在恶劣海况）时 VIT 齿条也随同变化（再调节）；

VIT 系统某些元、部件（例如不正常漏泄或原调节不良等）检修后，若 VIT 齿条游动（恢复性调节）。

调节步骤如下：

将节流阀全开；

操作应急控制台上的燃油手轮调节高压油泵的油门齿条位置（负荷）到转折点，此时节流止回阀后的控制空气压力表指示值为最大；

逐渐关小节流止回阀同时观察其后的控制空气压力表，直到压力表指示的压力开始下降，再开大节流止回阀一圈，调节完毕。

# 三、维护

VIT 装置，船上基本的维护保养大致有三方面。

## （1） 控制空气，经常检查以保证：

洁净，

压力正确（含及时消除漏泄）。

## （2） VIT 齿条，负荷变化时经常检查以保证：

活络，

各缸基本一致。

## （3） 高压油泵漏泄油泄放通畅

VIT 齿条不够活络（运动阻滞），主要原因之一是高压油泵漏泄油泄放不畅。

因为高压油泵长期工作，内部难免有燃油泄漏；这些燃油因高温焦化会阻塞泄油通道会妨碍高压油泵套筒运动， 使得 VIT 不能及时改变喷油定时，导致爆炸压力过高或过低，且各缸爆压相差过多（即各缸负荷严重失衡）。

发现或怀疑 VIT 齿条不够活络（运动阻滞），应及时疏通高压油泵漏泄油泄油通道。

具体做法（柴油机运行时操作最佳）是打开高压油泵顶盖的罩壳，在固定罩壳的螺丝孔处（该孔与高压油泵的漏泄油泄放通道相通）灌入轻油或燃油添加（分散清净）剂，  约 10 分钟：

若底部泄油孔未出油， 则需连接压缩空气到螺丝孔处吹通；

若仍未畅通， 则需伺停机时拆开 VIT 齿条连接杆，重复上述工作后来回拉动 VIT 齿条使其活络，直到齿条拉动较轻松、泄油孔有油流出来为止。

若高压油泵燃油泄漏过多，还应解体高压油泵，换新失效的全部密封圈
