# MTU396系列高速柴油机拉缸现象

MTU396系列高速柴油机是从德国引进的,其转速高,单缸功率大。

拉缸现象是船用柴油机,尤其是船用高速大功率柴油机在运行过程中产生的一种危害性很大也是很常见的发动机故障之一，它也是造成损失最严重的故障之一。

高速柴油机尤其是MTU396系列的高速柴油机,其转速高,输出功率大,拉缸后造成的后果较低速柴油机更严重。

一般柴油机在正常工作时，活塞环与气缸壁之间有一层油膜，所以磨损很小,而拉缸时磨损产生的磨损量很大,可达到正常磨损的几十甚至几百倍。

柴油机的拉缸根据损伤的程度轻缓不同一般可以分为擦伤、划伤和咬死等几种故障。

前两者是属于轻微的拉缸行为,通常可自行修复。

若及时发现情况，排除故障,可以避免大的漏洞和损失。

若拉缸越来越严重,造成活塞与气缸壁粘连,轻者损坏活塞和气缸，重者咬死活塞,活塞卡死在缸套里,柴油机熄火,摇转曲轴不动,从而拉断活塞或连杆,打坏机器,以致造成重大事故。

例如2006年10月，我司的南X轮”右主机B2缸,因活塞在缸套中拉缸咬死,造成连杆拉断缸套拉爆,气缸头喷油器损坏，油底壳及基体穿孔,曲轴跳动超标，总损失超过300万港币,占新机价格的3/4左右。

我司近年维修MTU16V396TE74L高速柴油机拉缸故障成逐年上升趋势。

因此,分析MTU396系列高速柴油机拉缸故障,找出早期迹象并采取正确的应对措施，正确管理使用MTU396系列高速柴油机,提高可靠性和延长使用寿命,以及提高管理人员对故障的排除应变能力,都具有重要的意义。

# MTU396系列船用高速柴油机拉缸时的迹象

所谓拉缸现象就是在柴油机的运转过程中,活塞环、活塞裙或活塞顶与气缸套内表面之间有杂质，或活塞环与气缸套内表面的油膜不够或无油膜，而产生的气缸套内表面、活塞环、活塞裙及活塞顶过度磨损的故障。

MTU396系列高速柴油机在发生拉缸现象的时候,外部迹象通常表现为:

发动机声音沉闷,且有异常声响;

发动机有不寻常震动现象;

缸套和活塞拉伤,在压缩和做功行程时气缸中发生串气现象,串机油严重,油消耗量增加;

温度异常;

转速不稳定，转速下降，甚至柴油机功率下降;

启动困难;

曲柄箱出口冒烟甚至喷油;

运转无力,功率不足。

在拉缸产生后,将活塞连杆取下，观察气缸壁工作表面,沿活塞运动方向会出现的片状或者条状的蓝色条纹，形成一定面积的拉毛,其表面硬度比原基体组织有所增高,并伴随有变色(暗红或发蓝)的现象,甚至发生活塞环折断、卡死、拉断活塞或连杆、打坏机器。

# MTU396系列高速柴油机拉缸时的一般应急处理

对有经验的操作者来说，在使用MTU396系列高速柴油机过程中,可根据拉缸的种种迹象而采取不同应急措施。

一般正确的操作方法是:

先减速运行,然后逐渐卸去负荷,再过渡到停车状态。

停车后还应在未完成冷却前盘车并加强润滑,防止气缸被咬死,千万不要瞬间将转速同负荷降到零。

一般步骤如下:

立即将机器转速减到1500转以下;

在尽可能的情况下应将机器与齿轮箱分离,减轻主机负荷;

分段将主机转速降到怠速;

待主机排气温度降到规定内停车并强制起动预润滑油泵加强活塞的冷却，以便把活塞的热量部分带走,防止活塞与缸套咬死;

停车后,用手动盘车机盘车5~10分钟。

船上在不清楚故障程度时,切不可乱拆检,尤其是不要更换淡水强缸套的冷却,否则气缸套冷却收缩,把活塞咬死,引发更大事故。

应立即通知专业维修人员检修,并将柴油机故障发生时的各种现象、参数及报警点详细告知专业维修人员。

# MTU396系列高速柴油机拉缸时通常现象及预防对策

产生拉缸的因素是多方面的，就某一具体拉缸的情况也有各种不同的原因，针对这些原因应采取的对策也各不相同,下面举一些典型的情况进行分析。

根据我司多年来的统计及分析发现:

异常磨损、划痕严重,有外界硬微粒成为磨料等状况,可能的原因是:

燃油系统不清洁,如柴油滤器损坏或太脏;

喷油器故障,如漏油,喷油压力不够;

汽缸润滑油系统不清洁,如机油滤器损坏,太脏或有金属粉等杂质;

进气系统不清洁,如空气滤器损坏或太脏；

加速过快;

零件加工阶段清洁处理不好,有缺陷;

金属疲劳、脱落等。

此时建议采取的对策:

维护好润滑系统,防止机械杂质和积碳混入机油和燃油内,在使用中对三滤(机油滤清器、燃油滤清器和空气滤清器)要及时而且正确的维护、清洗和更换;加强装配的清洁度,严防灰尘吸入气缸内;定期检查各活动部件,更换损坏件尤其是超标件。

在很多严重拉缸事故中,我们都发现有活塞环卡死、胶结等情况发生,那么可能的原因是:

活塞环间隙过小;

活塞环严重积碳(气缸润滑油质量不好或柴油喷油器故障);

活塞头部过热(活塞冷却不良);

超负荷工作。

可以采取的对策是:

正确选择活塞环的开口间隙和天地间隙超过规范的就应更换)，使用柴油机生产商指定的润滑油,加装机油分离器并定期更换机油滤器,每天开机前检查液面高度并补充适当,定期更换润滑油并抽样分析检查;定期检查缸套内表面工作情况(如内窥检查,测气缸压缩压力等);改善活塞的冷却条件,清理冷却系统中的污垢(如用蒸留水并在水中加添加剂),保证最好的冷却效果:合理操作使用发动机,不超负荷工作。

另外,注意主机的海淡水,应保持正常的工作温度和工作压力,避免机器长时间超负荷运行。
