# 导读

从一起MAN B&W 5S60MC型主机因更换排气阀致单缸排烟温度高报警自动降速故障出发，分析主机单缸排烟温度高产生的原因，提出主机排气阀液压系统故障预防措施。

# 一、故障情况

某船是一艘载重吨为76000t的巴拿马型远洋散装货船，配备上海沪东重机制造的MAN B&W 5S60MC型主机1台。

主机汽缸5只，缸径600mm，最大持续运转功率（MCR）8833kW，标定最高转速105 r/min，二冲程直流扫气，1台定压增压器，液压排气阀，船龄3年。

某日，船舶满载抵上海港长江口锚地抛锚，计划次日进港。

考虑到港口卸货快、靠泊时间短，船舶根据维保计划在锚地更换到期的No.3缸和No.4缸排气阀。

主机运转4000～6000 h周期性更换排气阀是主机常规维保项目，轮机人员对该项工作熟悉，一般不会出错影响主机运转，完工后主机没有试车。

次日，引航员登船，为赶高潮进港直接要车令“前进三”，即主机转速80 r/min。

此时主机增压器喘振，No.4缸排烟温差大报警、温度高报警，主机自动降速。

轮机长判断上述故障现象因船舶加速过快引起，等No.4缸排烟温度降低后轮机长按下复位按钮复位，再次启动主机缓慢加速到80 r/min，故障现象重复出现。

引航员以航道复杂、船舶故障影响航行安全为由离船。

上述事件造成船期延误一天及租家投诉，在一定程度上损害了船东声誉，并造成直接经济损失3万美元。

因该船船龄仅3年，船公司调查认定该起事件为责任事故，做出通报批评、扣发轮机长业绩工资1万余元人民币的处罚决定。

# 二、液压排气阀及驱动机构工作原理

图1为液压排气阀及驱动机构简图。

图1 液压排气阀及驱动机构简图

液压式气阀传动机构是在气阀、顶头的上端各设液压传动器即液压油缸和凸轮油高压油泵，两者之间通过驱动液压油管相连。

开阀靠液压传动器产生的油压实现，关阀靠空气弹簧的气体压力实现，即液压开启、空气弹簧缓冲关闭。

通过止回阀由凸轮轴油泵向凸轮油高压油泵供油，当排气凸轮由基圆向凸轮运动时产生高油压作用于启阀活塞开阀，同时缓冲气腔内的空气被压缩（空气弹簧的供气单向阀关闭）以减缓气阀的开启速度，减少噪声。

当排气凸轮由凸轮向基圆运行时，启阀活塞上部油压逐渐消失，排气阀在空气弹簧作用下逐渐关闭。

这种机构因具有尺寸小、重量轻、噪声小、拆装方便等优点而普遍用于超长/长行程低速柴油机的排气阀中。

MAN B&W 5S60MC型主机凸轮油高压油泵泵体仅装吸入单向止回阀和安全阀，取消了早期设计中的防气阀敲击节流针阀，启阀活塞设有缓冲装置。

气阀阀盘接近阀座时，启阀活塞上部的缓冲活塞封住进油通道，利用启阀活塞顶部节流空间内残油和缓冲弹簧起缓冲作用，减缓气阀的关闭速度，减轻阀盘对阀座的撞击。

# 三、故障排除与分析

引航员离船后，轮机长决定更换No.4缸排气阀。

由于新船只配备2只备用排气阀，只好装复原来换下的No.4缸排气阀。

试车发现No.4缸排温仍高，检查排气阀阀位指示器发现排气阀开度较小。

排气阀开度不够即启阀活塞行程小的原因应该是排气阀开启供油量/供油压力不足，说明液压系统泄漏。

轮机人员拆检凸轮油高压油泵安全阀和吸入止回阀未见异常，由此推断凸轮油高压油泵活塞环磨损或断裂（排气阀已换回原来排气阀，可排除排气阀启阀活塞环磨损或断裂的可能）。

凸轮油高压油泵解体，拆检测量油泵活塞、活塞环，状况良好。

直到此时，轮机人员才意识到可能是排气阀驱动液压油管内管调整推力衬套松动外移，推力衬套与内部油管端面接触面距离发生变化，驱动液压油管内管端面与凸轮油高压油泵上部垫块结合面或驱动液压油管内管端面与排气阀垫块结合面泄漏导致上述故障。

图2 驱动液压油管端部图

排气阀驱动液压油管两端端部结构如图2所示，液压油管采用内套两层高压管的形式，无缝钢管内管为高压油路，套管中间是回油空间，柔性外管与端面法兰连接外层铺设钢网保护层。

内外套管之间的内漏在外面是看不见的，回油回到驱动油泵内。

拆下驱动液压油管检查发现下部推力衬套松动外移，推力衬套与内部油管接触端面距离变小，游标卡尺测量为14.5mm，调整该距离至说明书规定数据16.0mm装复，试车后故障消失。

全体轮机部人员为此连续工作近20h。

故障机理：

排气阀驱动液压油管拆卸、安装、搬运、放置过程中，油管外管端部法兰扭曲转动，推力衬套松动外移，推力衬套与内部油管接触端面距离变小，油管端面与凸轮油高压油泵上部垫块结合面泄漏，液压油经垫块泄放孔流入凸轮油高压油泵，造成启阀供油量不足和压力降低，排气阀延迟开启且开度过小，导致换气不充分，燃烧恶化，单缸排温急剧升高，单缸排烟高温报警、温差大报警。

换气质量差燃烧不充分，排烟能量大，空气流量小导致主机增压器喘振。

# 四、故障预防措施

驱动液压油管发生故障时主机除排温高外，还会伴随排气阀敲击加大，后果是阀头与阀座过度冲击和磨损，液压管外管变形甚至破裂，影响安全。

此类因驱动液压油管或端面接触面存在间隙或端面接触面状况不良或油管内管破裂或油管法兰螺丝未收紧、安全阀泄漏及启阀活塞环磨损折断的主机排气阀液压系统故障影响主机正常运转的案例还有很多。

主机排气阀液压系统故障预防措施如下：

（1）轮机长和主管轮机员要熟读说明书，熟知检修设备的原理、结构和每一参数。

排气阀检修过程中关键性工作必须亲自把关。

（2）排气阀更换安装完毕，供冷却水、供气，启动凸轮轴油泵检查排气阀驱动高压油管密封状况。

设备检修后尽可能试车，加强检查，注意汽缸排烟温度，仔细听各气阀的声响，触摸排气阀驱动液压高压油管的脉动情况，合上阀位指示器判断阀杆工作状况，以便及早发现问题。

（3）主机运转时观察凸轮轴油压表是否波动。

油压表波动频率与主机转速相同，说明排气阀滑油系统有故障：

①运行中松开排气阀回油管接头，收集回油应少于40L/h，否则可能是启阀活塞环磨损。

②如排气阀接头处垫块外侧密封圈良好，而接头漏油，则压力油将通过内管空间回流至排气阀驱动机构进油端。

运行中可松开接头处闷头检查是否有油漏出，如有说明油管接头密封面泄漏。

③如不是上述两种情况，则可能是凸轮油高压油泵供油止回阀、安全阀泄漏或油泵柱塞活塞环磨损大。

（4）驱动液压油管安装前应检查接头密封面状况，视情研磨，测量调整高压油管两端推力衬套到油管接触端面距离，如MAN B&W 5S60MC型主机该距离为16.0mm。检查接头垫块密封面，视情换新。

上述两部件结合面平面状态均较差且备件缺少时，可用1～2 mm紫铜垫片做合适垫片（外径与垫块上部底平面直径相同，内径稍大于垫块孔径）安装在结合面，推力衬套到油管内管端部接触面距离作对应调整。

液压油管连接法兰螺丝应均匀收紧。

# 五、结束语

这次故障提醒我们，在设备操作和维修保养中，轮机管理人员必须熟读说明书，充分了解各部件的结构、原理和装配要求，才能保证设备安全运转。

即使一个小零部件安装失误也可能导致故障并给排除故障带来困难，进而影响船舶安全生产。

轮机管理人员在维修保养工作中不仅要埋头苦干，更要用心用脑。

故障查找必须有正确的思路，而正确的思路源于坚实的理论知识、认真细致的观察和丰富的经验。

而结合自身实际研读一些船舶机电技术方面的经典案例，通过学习获取别人的经验是提升自身能力的捷径之一。
