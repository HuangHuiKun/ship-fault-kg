# 导读

柴油机故障是指柴油机在规定的条件下，丧失规定的功能。

造成故障的原因多种多样，可能是某个部件磨损严重或卡死; 也可能是密封损坏，管线泄漏; 抑或是环境变化对机体或管线内的水、油、气等介质产生影响。

MAN B&W 作为世界船用柴油机产业的龙头，其生产的船用柴油机在世界上占有一半以上的份额。

在渤海地区的海上油田，MAN B&W 公司的船用柴油机同样占有一席之地。

某平台以两台 MAN B&W 16V32/40 原油主机作为平台主电站的动力源之一，在运行期间发生了几起故障，因故障均具有典型性，本文在此作分析，以期对同仁有所借鉴。

# 一、故障案例分析

## 案例1、压力变送器冰冻损坏

某年1月4日其中一台原油主机突然停车，致使整个油田失电。

关断发生后，维修人员对控制盘进行检查，发现关断发生前高温冷却水压力变送器2PT3170最高压力为0.85MPa( 正常应为0.5～0.6 MPa) 。

对2PT3170 进行拆检，发现取压管线末端与压力变送器连接处结冰膨胀，致使压力变送器测量值突增，超量程损坏，导致该原油主机自动停车。

## 案例2、燃油窜入冷却水中

某年1月28日凌晨4∶05，值班人员发现原油主机喷嘴冷却水处压力安全阀起跳，流出的冷却水混有燃油，同时喷嘴冷却水压力由0.2MPa 升至 0.3MPa 左右，原油主机B1 缸排气温度下降至230℃ ( 正常应为380℃ 左右) ，并有逐渐下降的趋势。

停机后，将喷油器冷却水隔离，拆除 B1 缸喷油器冷却水管线，发现冷却水管线内有燃油流出。

喷油器总成靠后部分与喷嘴连接处直接靠结合面的端面进行密封，在长时间运行后，该端面密封程度下降，由于燃油压力高于冷却水压力，导致燃油窜入冷却水管线内，使得喷嘴冷却水压力升高，安全阀起跳; 同时导致进入气缸燃烧的燃油量减少，因而排气温度下降。

## 案例3、滑油压力低

某年12月2日上午10∶30，原油主机起动带载运行，最初各项参数稳定，半小时后，滑油压力突然下降到0.28 MPa (正常应为0.40MPa左右) ，并且稳定在0. 28MPa。

停机后对滑油管路管线及各部件进行逐项检查，最终将故障源锁定在滑油压力调节阀。

该阀的主要故障表现为:

调节压力调整螺母时，压力无变化。

拆解压力调节阀，发现压紧弹簧的弹珠缺失，导致进油管线与卸油管线直接连通，无法起到压力调节的作用。

在加装新的弹珠后，压力调节作用恢复，重新将滑油管线压力调整到正常范围。

以上所选为原油主机在运行12000h以内的几个典型案例，案例短小，却很有代表性。

通过对案例的解析，可以总结出主机运行期间应注意的几个问题。

# 二、预防性维护应注意的问题

## 1、环境影响

环境对设备的影响不可忽视。

环境温度过低可能导致管线结冰，环境温度过高则有可能导致气缸排气温度过高或主机冷却效果不良等问题;

因此应依据环境温度采取保温及通风冷却等措施，保证主机的稳定运行。

除了环境温度的影响，空气湿度、纯净程度等也会对主机运行产生一定的影响。

## 2、定期对主机进行保养

应严格按照维修保养手册的保养时间及内容，认真按时对重要部件进行保养或更换。

例如进气滤棉，如果不及时更换，容易造成进气不畅，增压器喘振等故障。

## 3、加强人员培训，提高维修人员素质

维修人员良好的专业素质是主机安全稳定运行的重要保障。

只有良好的专业素质才能敏锐及时地发现主机运行期间的问题，排除隐患。

因而，应对维修人员做定期培训。
