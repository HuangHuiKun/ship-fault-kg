# 导读

柴油机在现代船舶中应用广泛，目前以柴油机作为主机的船舶占98％以上，柴油机船总功率占造船总功率的90％以上。

柴油主机正常起动，为船舶提供动力是保障航行安全的必要条件。

压缩空气起动因起动扭矩大、起动迅速且过程平稳、适用范围广等特点，在中大型柴油机中应用广泛。

某双机带单桨船的柴油主机突然同时出现不能正常起动的异常现象，本文针对此起动故障问题进行分析和排除，希望对柴油主机的维护管理人员有所启发和帮助。

# 一、故障现象

某船某次准备启航时，柴油主机完成起动前准备工作后，在集控台按下“起动”按钮，柴油机未转动，起动失败。

轮机人员尝试在机旁控制台进行起动，仍然未成功。

为保证船舶任务完成，轮机人员最后尝试手动开启主起动阀，感受到比往常更费劲，不过最终主机成功起动，后续运行正常。

船舶返航后，轮机人员试图查找起动故障的原因，通过多次起动试验，总结出下面几个现象：

在集控台和机旁控制台按“起动”按钮，柴油机均不能起动；

按下“起动”按钮后，能听到燃油切断阀转换的声音；

经过数次“吹车”后，按集控台或机旁控制台“起动”按钮，柴油机可以起动；

两柴油主机起动现象一致。

# 二、起动原理

该船柴油主机使用压缩空气起动系统，采用单排进气、双排发火的起动方式，图１为起动系统图。

图１ 某柴油机起动系统图

起动空气的压力为1.2～3Ｍpa，控制空气的压力为0.7 Ｍpa，均由一个4.7Ｍpa的主压缩气瓶经减压阀减压后充入起动空气瓶和控制空气瓶。

当柴油机起动时，起动电磁阀通电工作，控制空气经盘车连锁阀后，分为两路：

一路通往方向阀，使燃油切断阀闭合，导通燃油油路；

另一路通往主起动阀，使主起动阀开启，导通起动空气气路。

起动空气通过主起动阀后，分为三路：

一路通往安装在 Ｂ列气缸上的起动阀，待气缸起动阀开启后进入气缸；

一路通往空气分配器，然后按柴油机发火顺序依次至气缸起动阀使其打开；

还有一路通往调速器起动伺服器。

起动空气按发火顺序进入 Ｂ列气缸，推动活塞，带动曲轴旋转，当柴油机转速达到起动转速１时，调速器接收速度（油门）设定信号，迅速加油至起动油门１，随后根据转速调节油门直至柴油机进入平稳运行状态，起动过程起动转速与油门关系图如图２所示。

# 三、故障原因分析与排除

根据柴油机基本工作原理及起动原理，该柴油机起动过程主要涉及燃油供给系统、进排气系统、调速控制系统、监控安保系统及压缩空气系统。

按照“先易后难，由表及里”的故障分析原则，依据轮机人员在起动试验中总结的现象，缩小故障排查范围。

## 初步分析

通过控制方式（集控台或机旁控制台“起动”按钮）起动柴油机失败，但手动开启主起动阀可以起动柴油机，而且起动成功后柴油机运行正常，说明柴油机的气缸起动阀、燃油供给系统、进排气系统和调速控制系统工作正常。

值得说明的是，即使柴油机没有起动成功，遇到柴油机不转动或没达到起动转速１的故障现象时，调速控制系统和燃油供给系统尚未参与工作，应该优先考虑其他系统的故障。

起动时，燃油切断阀能够正常转换，监控安保系统中盘车连锁阀未亮灯，说明控制空气气路中起动电磁阀和盘车连锁阀工作正常，控制空气能够到达主起动阀。

鉴于手动开启主起动阀可以起动柴油机，考虑主起动阀可能存在故障点。

## 主起动阀排查

### 结构与工作原理

图４ 主起动阀结构

控制空气接通后，活塞带动泄放阀向下运动，阀体内主起动空气经泄放口与外界大气导通，压力快速下降，使得作用于主阀外侧的垂向压力能够克服作用于内侧的垂向压力和主弹簧弹力的合力，使主阀向上抬升，从而开启主起动阀。

在此过程中，施加于活塞上的控制空气作用力需能克服导向弹簧弹力和作用于泄放阀向上的气体压力，活塞的受力情况如公式（２）所示。

若手动开启主起动阀，通过转动圆盘施加于顶块的下压力取代控制空气作用力，使泄放阀下移。

Ｆ活塞，控制气＞Ｆ泄放阀，起动气＋Ｔ导向弹簧（２）

### 潜在故障原因分析

由主起动阀工作原理可知，开启主起动阀的关键在于泄放阀能够正常打开，因此依据公式（２），从以下三个方面进行分析：

控制空气压力不足，导致施加于活塞的下压力偏小。

控制空气管路存在漏气点或控制空气接头存在堵塞会导致进入主起动阀的控制气压力偏低。

泄放阀下移阻力增加。

泄放阀与导向衬套之间润滑不良、泄放阀或导向衬套因空气潮湿而生锈会导致泄放阀运动卡滞，严重时甚至卡死。

值得注意的是，若起动空气压力过大，也会导致泄放阀向下运动的阻力明显增加。

导向弹簧压缩困难。

导向弹簧材质为金属，因空气潮湿发生锈蚀，锈蚀产物会阻碍弹簧的正常压缩；循环压缩次数过多，可能产生微裂纹，压缩所需力增大。

此外，弹簧安装不当可能会与周围部件发生干涉，阻碍弹簧的压缩。

### 拆卸检查

经外部检查、主起动阀拆卸后检查泄放阀及导向弹簧，发现：

控制空气管路各连接处连接正常并无泄漏，控制空气接头未被堵塞。

泄放阀能够在导向衬套中灵活运动，导向弹簧无明显锈蚀、表面无明显裂纹。

控制空气气瓶压力正常，但主起动空气气瓶压力超过３Ｍpa，如图５所示。

图５ 起动空气压力表

主起动空气压力高正是轮机人员开启主起动阀感到费劲的原因。

由于控制空气和主起动空气均由压力为4.7Mpa的主压缩气瓶空气经减压阀减压得到，因此故障点基本锁定为减压阀。

## 减压阀排查

### 结构与工作原理

减压阀型号为 Ｑ／ＨＦＪＭ－２０Ａ，实物如图６所示，分为导阀和主减压阀，内部结构见图７。

图６ Ｑ／ＨＦＪＭ－２０Ａ减压阀

图７ Ｑ／ＨＦＪＭ－２０Ａ减压阀导阀（上）和主阀（下）内部结构

导阀主要由调节盖、调节弹簧和调节螺钉组成，主减压阀主要组成元件有：活塞、主阀盘和回位弹簧。

导阀调节盖处于初始位置时，导阀调节弹簧不受压，导阀未打开，主减压阀内活塞上、下腔压力平衡，主阀盘受回位弹簧的压力将主阀通道关闭。

顺时针旋转导阀调节盖，调节弹簧受压后把导阀阀盘打开，导阀输出的压力空气进入活塞上腔，活塞受到垂向下的压力，克服回位弹簧弹力而使活塞下移，同时顶杆向下运动顶开主阀盘，然后高压气源ＰＮ１进入输出腔，产生输出压力ＰＮ２。

同时输出腔的压力空气进入活塞下腔，作用于活塞下部，抵消活塞上部的压力，主阀盘开度减小，直至平衡。

### 潜在故障原因分析

由该减压阀工作原理可知，输出压力的大小取决于主阀盘的开度，开度越大，输出压力越大。

导阀起控制作用，主减压阀自带补偿反馈作用。

因此从以下两个方面进行分析：

导阀设定值异常。

导阀调节盖被误旋紧，使调节弹簧预压缩量增大，或是调节弹簧出现老化、变形等问题，均会导致导阀的输出压力增大，从而影响主阀的输出压力。

主阀动作异常。

回位弹簧弹性模量降低，活塞下行后卡滞，主阀盘与阀座的密封面损伤，或是活塞下腔的引压孔堵塞等问题，均会导致主阀盘的开度大于原平衡位置。

### 故障排除

拆卸减压阀的导阀和主阀，对调节弹簧和回位弹簧进行外观检查和弹力测试，同时详细检查活塞运动的灵活程度及主阀盘密封面，发现导阀调节弹簧出现老化。

更换调节弹簧后，调整导阀调节盖使输出压力为３Ｍpa，重新在机旁和集控测试起动柴油机，柴油机能够正常起动。

轮机人员在起动试验中发现数次“吹车”后可以通过控制方式起动柴油机，实际上是因为“吹车”消耗了压缩空气，主起动空气的压力下降后，控制空气又能够将主起动阀开启。

# 四、结语

本文针对某船柴油主机起动出现异常进行了详细分析和排查，结果表明：压缩空气系统中减压阀的导阀调节弹簧老化使主起动空气压力过高是故障原因。

在此对轮机管理人员提出三点建议：

一是提高日常维护保养的规范性，严格按技术手册和使用说明维护保养各部件及系统；

二是加强对主要零部件内部结构及具体工作原理的学习认识，有助于快速判定故障点位；

三是不能只重视主机而忽视辅助系统对机器可靠性的影响。
