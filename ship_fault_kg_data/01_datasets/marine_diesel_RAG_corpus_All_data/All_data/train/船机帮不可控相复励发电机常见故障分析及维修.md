# 导读

早在二十世纪八十年代中期，西方国家已经对船舶电力系统稳定性开始研究，同时 ABB、Converteam、Siemens 三大公司作为电气设备的主要供应商，也一直致力于电力系统稳定性的研究。

王连喜 [1] 、陈祥光 [2] 、孙艳秋 [3] 、才家刚 [4] 等人针对船舶电力系统、同步发电机调压励磁系统、可控相复励调压装置、发电机出现的问题进行系统分析，给出了合理的处理方式，在一定程度上为排除发电机励磁系统故障时提供参考。

罗晓彬 [5] 对往复式压缩机润滑系统常见故障进行了分析，对保证往复式压缩机润滑系统的安全、稳定运行提供一定参考。

随着船舶技术的迅速发展，更多新型设备在船舶上得以应用，如近海测量船与远洋测量船的主要任务是对海洋环境进行勘测，其过程需使用雷达和声呐，这些设备的工作会使船用负载发生变化，在一定程度上会导致电网的波动，如果波动过大会损坏用电设备，也会缩短电机的使用寿命。

因此，为了保障船舶在海上的正常航行，确保船上的用电设备能够正常稳定工作，分析电力系统易发故障具有十分重要的意义。

励磁系统在电力推进稳定性中扮演着重要的角色，也是船用不可控相复励发电机的重要组成部分，其对全船用电设备的可靠性有直接影响。

# 一、不可控相复励发电机工作原理

## 1、不可控相复励发电机介绍

不可控相复励发电机的核心机制在于：

借助发电机自身的剩余磁通产生的电压实现自激励启动，进而根据所承载的电流大小及其性质，实施相互的反馈激励过程。

这一过程动态地调整励磁电流的水平，旨在维持发电机输出端电压的稳定性 [6] 。

# 二、故障分析处理

## 1、故障现象

某船装备 3 台同容量、同型号的 TJXV-120-4交流同步发电机，其为背包式不可控谐振式相复励自励恒压装置，并车运行时均衡励磁电流的方法为直流均压式。

单机分别单独运行时正常工作，任何 2台并车运行也正常工作；当其中 1台发电机负载转移至另 1 台发电机并解列停车后，有时会出现运行机组的电压 （即电网） 下降到 280 V 左右的情况，因而使电站无法正常工作。

## 2、故障分析

对各发电机的主开关万能式自动空气断路器、线性移相电抗器、相复励变压器、谐振电容器、整流器及其阻容保护器件等进行全面的检查，没有发现问题。

由于故障的偶发性使故障的排除无法进行下去，所以通过发电机并车原理进行分析。

2台具有相同容量、相同型号的发电机组在并联运行的时候，同时在有功功率分配相等的情况下，如果运行过程中出现无功分配不平衡，说明这2台发电机两端的电势不一致，需要调节励磁电流使电势相等。

但是，不可控相复励系统的励磁电流是既定的，一般不具备调节手段，即便设置手动调节器件，也不可能应付无功的变化。

在确保有功功率均衡分配的前提下，若发电机两端的电势保持一致，则能实现无功功率的均衡分配。

由于发电机两端的电势受控于励磁电流，因此调节励磁电流成为关键手段，具体可采用直流均压或交流均压技术。

直流均压法基于同型同容发电机励磁绕组特性的一致性，即相同励磁电流产生相同电势的原理。

通过并联运行发电机的励磁绕组，确保各绕组两端电压相等，从而促使励磁电流相等，进而实现无功功率的均衡分配。

励磁直流均压原理接线图如图3所示。

图3 励磁直流均压原理接线图

由图 3 可知，每台发电机设均压接触器 K1、K2、K3，由发电机开关辅助头控制，开关合闸，接触器动作，把励磁绕组两端接入均压小母线。

2台以上发电机并联，各发电机励磁绕组通过均压小母线均压连接。

励磁直流均压连接只解决有功负载分配平衡时的无功分配平衡。

刚投入的发电机，有功负载接近零，励磁电流只有接近空载所需的励磁电流，但是由于励磁均压，负载发电机的相复励输出加到刚投入发电机的励磁上，使电势上升，吸取滞后的无功电流，负载发电机的负载电流越大，投入发电机的无功电流越大，功率因数越低，刚投入的发电机立即带上无功负载 [8] 。

解列前转移负载，有功负载卸至零，但由于励磁均压，无功负载仍存在。发电机开关带电流分断，励磁均压措施的解决结果不令人满意 [9] 。

## 3、故障处理

由图3可知，该船K1~K3的型号为CT91-50/21，型线圈电压 380 V，主开关 Q 为万能式自动空气断路器，型号为 DW94-400P （额定电流 260 A）。

发电机的励磁电压18~80V， 空载测得励磁电流11.25A，励磁线圈电阻1.6Ω，电感189 mH。

根据以上分析重点检查了 K1~K3和Q，经过多次仔细观察发现 K1~K3在解列时出现不释放现象，而 K1~K3线圈无电压，说明 Q的附助接点释放是正常的，只是 K1~K3断电后衔铁不释放。

对 K1~K3进行修复和换新后，进行试验，故障排除。

# 三、接触器常见的故障及维修方法

在船舶电器中，触点电器使用广泛。

不可控相复励发电机是船舶建造中使用较多的一种发电机，其控制电路中很多有触点的电器 （继电器、接触器等） 会因设备的长期使用或在使用过程中的误操作造成一定程度上的损坏。

接触器常见的故障及维修方法如下。

## 1、通电时接触器不吸合

当接触器接触电源后，触点应该立即闭合，从而使电路接通，如果接通电源后触点无法吸合，其可能原因为：

①接触器发生损坏，内部线圈断线、烧毁；

②虽然接通电源，但是电源没有电压，电源不起作用；

③没有按照正确的配线电路配线；

④按钮的接触不好；

⑤可动部分被异物卡住；

⑥接触弹簧的压力大于吸引力。

如果发生以上的故障，首先，应仔细检查电源是否供电正常；再使用欧姆表验证接触器的线圈是否断路；检查线圈所使用的电压与电源线电压是否相符合；确定弹簧压力是否存在异常等。

## 2、断电时接触器不松开

当接触器断开电源后，接触器的触点在弹簧弹力的作用下，触点应立即发生脱离。

但有时候断开电源后，触点并不会立即分开，其可能是如下原因造成的：

①触点处的弹簧弹力较小，所产生的弹力不足以使触电分离；

②反力弹簧已经失效，出现此类故障时需要重新调整触点的弹簧压力，或直接对反力弹簧进行换新；

③机械可动部分卡住，也可导致触头无法分开，出现此类故障应仔细检查铁芯内是否有异物将动铁卡住，如果检查过程中发现转轴歪斜要将它扶正；

④铁芯剩磁过大也可能导致动、静触头无法分开，此时需要更换铁芯。

另外，有时由于接触时通过的电流过大，从而会产生较大的火花，在电流热效应的作用下会使触点发生融化，导致动、静触点连在一起，当断电的时候，触点不会分离。

如发生此类现象，首先应该将连接在一起的触头分开，并对分开的触头进行打磨处理，使之光滑，或者直接将触头进行换新。

同时需要仔细检查电源的电压是否正常工作，如出现异常应使电源电压满足继电器需要的条件。
