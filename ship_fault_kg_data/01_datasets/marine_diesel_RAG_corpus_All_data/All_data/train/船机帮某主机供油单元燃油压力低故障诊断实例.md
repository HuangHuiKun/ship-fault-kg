# 导读

某客滚船为abb第三代电力推进船舶，有4台MAK9M25型柴油机作为发电机使用，发出的6.6kV交流电经推进变压器转变为690V交流电，驱动2台吊舱式永磁变频电机带动螺旋桨工作。

柴油机由供油单元CRGD2.4A供油（180 cSt燃油），该船共有2套供油单元，每2台柴油机共用1套供油单元，另有2台750 kW的艄侧推器。

# 一、故障现象

当船舶靠离港口、柴油机逐渐增加负荷或定速航行（83%负荷）时，本船广供油单元的燃油压力稳定，基本维持在4.5bar左右，无明显波动迹象;当船舶靠离港口、柴油机突加突减负荷或启动赠侧推器时,广供油单元出现燃油压力低（＜3.0 bar）报警,或循环泵的备用泵启动（燃油压力＜2.8 bar时备用泵启动）现象。

观察燃油压力表的变化情况，与报警相符，排除误报警的可能。

因此种现象仅维持几秒到几十秒，然后压力又自动恢复正常，并且在1个多月内每次靠离港口时均岀现该现象，故笔者分析其原因和排除故障，供同人参考。

# 二、故障分析与处理

供油单元燃油压力瞬间降低，很可能是安全阀在压力脉冲冲击下瞬间起跳造成的。

## 1、供油单元的系统安全阀故障

本船曾出现过供油单元系统压力低的故障，发现是供油单元安全阀关闭不严造成的，故在安全阀前的法兰上加装盲板进行封堵试验。

起初未考虑系统安全阀有问题,但检查时发现安全阀的调节螺栓已经全部旋松,一旦盲板锈蚀，在系统压力的脉冲下安全阀起跳，使压力瞬间降低。

由于船舶在航行途中无法检查盲板，因此旋紧安全阀后进行试验，但靠港启动2台艄侧推器时依然出现压力低报警。

靠泊后，供油泵（HP1、HP2）及循环泵（HP3.HP4）停止运转,拆下盲板检查发现已经腐蚀锈透，再次用盲板进行封堵。

试验发现负荷波动时故障依然存在，故拆除盲板。

## 2、回油筒（HT1）放气电磁阀（M）故障

通过放气电磁阀（M）,可将供油单元回油筒的空气排出到重油日用柜。

若放气电磁阀（M）不能开启，则回油筒中会留存较多空气，对燃油的压力波动产生一定影响。

同时，由于2*供油单元放气电磁阀出口管的温度明显高于1"供油单元放气电磁阀出口管的温度，因此怀疑广供油单元放气电磁阀（M）不能开启，使得回油筒的空气不能排出。

电磁阀的电磁线圈测量正常;拆检回油电磁阀时发现电磁阀膜片老化破损，电磁阀工作不正常，换新电磁阀总成;拆下回油筒（HT1）的放气浮球控制装置，清洁电磁阀的控制浮球;检查控制阀密封面正常，对回油筒进行手动放气。

但靠离泊负荷突变时，压力低报警故障依然存在。

## 3、供给泵旁通管路调压阀（即燃油压力自动调节阀HR1、HR2）及供给泵（HP1、HP2）、循环泵（HP3、HP4 ）的自身安全阀故障

供给泵（HP1、HP2）是三螺杆泵，其压力的调节通过旁通管路调压阀（HR1、HR2）自动调节。

拆检调压阀，检查阀、阀座和调节弹簧，未见异常;拆检供给泵、循环泵,检查螺杆、衬套、安全阀和弹簧，未见异常;将供给泵、循环泵与才供油单元的泵进行互换配对试验，依然出现压力低报警。

根据上述3个方面的分析，发现故障依然存在，并且每项主要工作检修完后，供油单元的燃油压力变化情况分为：

（1）供给泵、循环泵的压力都降低。

（2）供给泵压力不降，但循环泵的压力下降。

（3）开始时供给泵压力不降,循环泵压力降;等循环泵压力慢慢增大后,供给泵压力慢慢降低，随后恢复正常。

# 三、故障排除

某日，笔者在1"供油单元前观察燃油压力变化情况时，在启动輯侧推器的瞬间突然发现流量计（见图2）突然卡滞不动；此时机舱报警系统出现燃油压力低报警，大约5 s后流量计又开始转动，燃油压力逐渐恢复正常。

图2 LC系列椭圆齿轮流量计

于是笔者将流量计旁通阀（10）开启，关闭流量计的进口阀（11）、出口阀（12）,停止流量计的使用。

连续使用3d,未再出现燃油压力低报警，说明整个供油单元压力瞬间低是由流量计故障导致的。

椭圆齿轮流量计由流量变送器与计数机构组成,变送器的主要部分由1对椭圆齿轮转子的计量室与密封联轴器组成。

计量室内由1对椭圆齿轮和盖板构成月牙形空腔，作为流量计的计量单位。

椭圆齿轮依靠流量计进、出口处的压力差推动旋转,从而不断地把进口处的液体经月牙形空腔计量后送到出口处。

椭圆齿轮每转动1周流过的液体总量是月牙形空腔的4倍。

密封联轴器将椭圆齿轮旋转的总数以及旋转的速度传递给计数机构，通过指针显示和字轮累积即可知晓通过管路中的液体数量。

由于供柴油机所需的燃油都要经过流量计，而流量计变送器是个椭圆形的齿轮转子，一旦流量计不转，即椭圆齿轮停止转动，那么就会导致供油中断,燃油进机压力降低。

图3 椭圆齿轮流量计内部结构

拆检流量计时，发现椭圆齿轮流量计内部的轴套（见图3）严重腐蚀，轴套与轴之间间隙过大，造成流量计在运转过程中遇到负荷突变时，就会出现齿轮轴在轴套内窜动，造成齿轮偏磨而岀现短暂卡阻的现象。

在电网负荷的波动下，流量计的椭圆齿轮又开始转动，继续供应燃油，使燃油压力逐渐恢复正常。

换新流量计，后续再未出现过压力低报警和压力突变的现象，故障得到排除。

# 四、经验和教训

造成椭圆齿轮流量计齿轮卡阻或不转动的原因包括:管路内有杂物、被测液体中有杂物、轴套磨损过大造成齿轮运转不正常、被测液体温度过高、流量计变形、齿轮与流量计体相碰等。

轮机员必须每半年对流量计进行清洁、检查并测量间隙,确保工作状态良好。

平时要加强燃油的预处理工作,做好燃油的沉淀和净化工作，定期清洗滤器,并检查滤网是否破损，控制好燃油的温度等。

轮机长必须对设备的维护保养严格把关，履行好提醒和监督的职能,在关键环节上须亲自指导。
