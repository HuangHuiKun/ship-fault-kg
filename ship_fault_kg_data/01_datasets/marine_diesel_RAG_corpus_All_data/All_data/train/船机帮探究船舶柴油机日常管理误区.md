# 导读

船舶的移动离不开柴油机的运转，其提供动力使船舶发生移动，但是在长期的运行过程中，柴油机各个部位的零件都会出现不同程度不同问题的损伤，因此要加强对柴油机的日常管理，进而保证柴油机的正常运转，提高其使用寿命。

因此，详细分析了船舶柴油机日常管理存在的误区，并提出有效的管理措施，进而保证柴油机的正常运转，并有效提高柴油机的使用寿命。

首先，国内船用柴油机企业养成了依靠国外技术的习惯，自主化程度低，高端科研人才缺乏；科研院所相对分散，与企业之间缺乏有效的信息交流平台，很多科研成果和技术专利因种种原因没有得到有效转化，仅仅停留在纸面上、停留在证书中，难以形成核心竞争力，造成了巨大的科技资源浪费。

其次，国内柴油机企业维修服务能力还有待加强。

当柴油机设备出现故障时，不能及时诊断问题、消除隐患、减少故障停机时间，保证柴油机设备的安全、高效运行。

# 三、船舶柴油机日常管理

## 1、柴油机低负荷、低运转，增长使用寿命

如果柴油机是运行状态长期保持低负荷、低运转，会具有以下两个方面的危害：

① 降低柴油机的运行速度和高温油泵的上升速度，从而导致喷油滞后，进而延长了柴油机的燃烧；

② 柴油机没有较高的运行速度，会导致排气能量和增压压力下降，并且气缸空气量的进入也会减少，进而导致柴油燃烧的不彻底，这样所排出气体的温度也比较高。

因此，船舶柴油机如果长期保持低负荷、低运转的运行状态，柴油机气阀、排烟管、活塞等内部零件的损坏程度会进一步增加，同时还会导致燃油得不到彻底的燃烧，将废弃排到大气层中对环境造成污染。

## 2、进气阀、排气阀间间隙越大，动力性能越好

当柴油机进气阀、排气阀间间隙的状态是冷却的时候，那么阀杆顶与摇臂间就会有足够的活动空间。

当柴油机进气阀、排气阀间间隙的状态是不冷却的时候，柴油机正在高速运转，但是因为进气阀、排气阀受热，导致出现阀杆膨胀的现象，进而对进气阀、排气阀的正常运转产生影响，从而对柴油机正常运转压缩压力产生影响。

并且在气阀封面如果有高温气体通过，那么就会出现封面烧灼的现象。

在对进气阀、排气阀间间隙进行设计的时候，如果通过理论原理进行，就算进气阀、排气阀处于发热状态，也可以将它们之间的间隙设置成零。

但是柴油机在实际的工作中，其负荷经常会随着运转速度的变化而发生变化，从而产生的热量值的状态为运动状态。

另外，在对进气阀、排气阀间间隙进行设计的时候还要对柴油机运行过程中其他因素进行考虑。

因此，在对进气阀、排气阀间间隙进行设计的时候要将上述因素进行综合考虑，降低柴油机运行故障发生的概率，从而有效提高柴油机的使用寿命。

## 3、在对柴油机零件清洗的时候使用柴油

管理人员在对船舶柴油机零件进行清洗的时候，通常会选择使用柴油，从而完成对柴油机零件的清洁。

其实柴油在清洁中并不是最好的选择，可以将具有非离子性质的表面活性剂兑到水中，进而调配成水溶液。

用其对柴油机零件进行清理的时候，不仅具有较好的清洁效果，还可以进一步降低清洁成本，减少对柴油资源的浪费。

该水溶液具有较多的优势，如较高的安全性、环保性以及无毒性，目前在船舶柴油机零件清洗中得到广泛使用。

# 四、结语

在长期对船舶柴油机使用的过程中，机器各个部位的零件都会出现不同程度不同问题的损伤，如上所述，船舶工业产品具有复杂性高、技术含量高、研发周期长、任务繁重等特点。
