# 导读

介绍一起副机连杆大端轴瓦的故障经过，提出了在管理中应采取的预防措施。

# 一 事故经过

某船正在大西洋航行，下午1512 时，轮机长在机舱作例行检查时发现3号副机上方的曲柄箱透气管冒出的油气较平时多，便检查机油进机压力，发现机油压力为0.41 MPa,比平时下降了0.02 MPa。

见此，轮机长立即采取措施停止3号副机运行。

15 min后，打开曲柄箱道门检查，发现在每个缸对应的油底壳上都聚积有不少脱落的轴承合金碎末，尤其在第3缸的下部聚积的合金碎末更多。

拆开每缸的连杆大端轴承检查，发现第3缸连杆大端轴承的合金层基本全部脱落，曲柄销表面有小面积拉伤;其余各缸的连杆大端轴承的合金层也有部分脱落,但曲柄销表面未受损伤。

# 二 事故原因

事故发生后，为确定该副机的主轴承是否也受到损坏，将9道主轴承的轴瓦全部拆出检查，主轴承轴瓦均未受到损坏。

检查3号副机的机油泵、机油泵安全阀和机油压力表均正常。

清洗机油双联滤器时，发现一个滤器较脏，有一些合金碎末,另一个机油滤器基本干净。

检查机油压力应急保护装置在0.25MPa动作，功能正常。

根据各缸的连杆大端轴承轴瓦合金的脱落情况分析，各缸的连杆大端轴承合金脱落是首先从第3缸开始的。

而第3缸连杆大端轴承合金脱落的原因可能有两种:

一种是由于曲柄销与轴瓦间的间隙偏大，滑油在轴承两端流失过多，轴瓦面的油膜压力下降，使曲柄销与轴瓦发生接触;同时使轴瓦受到较大交变负荷的冲击，使合金层疲劳脱落。

另一种原因是轴瓦合金受到滑油中的酸性物质腐蚀弓|起脱落。

当第3缸连杆大端轴承轴瓦合金开始脱落时，一方面，轴瓦的有效承载面积减少，使轴瓦合金承受的比压增大,其结果是使轴瓦合金脱落的速度加快;

另一方面，由于轴承合金的不断脱落，轴瓦面的粗糙度下降，使轴瓦面的油膜层减薄造成金属接触。

同时，曲柄销和轴承的间隙变大，滑油流失过多，使轴瓦面的油膜压力下降，也加快了轴承合金的脱落。

当轴瓦合金脱落到一定程度，剩下的轴瓦合金已无法承受活塞工作时产生的冲击力，使剩下的轴瓦合金受到彻底的毁坏。

由于第3缸连杆大端轴承合金的大量脱落，使曲柄销与轴瓦之间的间隙增大，润滑系统中的机油经由第三缸的连杆大端轴承处大量流失，使应分流至其他缸的连杆大端轴承的润滑油减少，各缸的连杆大端轴承因供油不足不能形成良好的油膜润滑，轴瓦面的油膜压力不能承受工作负荷，轴瓦合金与曲柄销发生金属接触，将轴瓦合金拉伤。

# 三 由事故引起的思考

## 1. 机油压力应急保护装置的作用

为了避免运行中的副机因润滑系统失压造成损坏，基本上每部副机都装设有机油压力应急保护装置。

当润滑系统的油压下降到一定数值时，应急保护装置就会动作，停止副机的运行。

可见机油压力应急保护装置是确保副机安全运行的重要装置，必须保证其功能一直处于正常状态。

因此，要求轮机管理人员每半年必须对机油压力应急保护装置进行一次功能试验，确保其功能正常。

一般情况下，机油压力应急保护装置动作的油压数值约为副机运行时的正常油压的3/5。

如副机各轴承的间隙正常，润滑油不会在个别轴承处流失过多，当副机的润滑油压力下降至正常油压的3/5时，各轴承仍能形成良好的全液体润滑; 只要此时机油压力应急保护装置能够及时动作，则不会对副机造成损坏。

但如果副机某一个或几个轴承的间隙较大，润滑油流失过多，当机油系统的油压下降至正常油压的3/5时，因在轴承间不能形成有效的液体润滑，即使副机的机油应急保护装置能够及时动作，也会使副机造成损坏。

在该船3号副机连杆大端轴承损坏事故中，虽然该副机的机油压力应急保护装置功能正常，因该保护装置设定的动作油压为0.25 MPa,而事故发生时的机油压力仍在0.41 MPa;如果没有及时发现，一直到油压下降至油压保护装置动作，事故处理的延误则会造成该副机彻底毁坏。

由此可见，各种应急保护装置只是作为确保副机安全运行的辅助手段，在轮机管理中，不能因为装设有各种应急保护装置或认为各保护装置都处于正常状态就掉以轻心。

另外，对于使用年限较长、各轴承间隙较大的副机、为安全起见，可根据具体情况将机油压力应急保护装置的动作油压值适当调大，但无论在任何时候都不得将机油压力保护装置的动作油压值调小。

## 2. 强化值班人员的责任心

一般情况下，机械设备发生故障前都会有预兆。

只要值班人员认真检查、仔细比较，就有可能发现问题，将故障消灭在萌芽状态。

如该船3号副机在发现问题采取停机措施前的1h里，该副机的机油滤器的压差过大，发出报警。

值班人员立即到机旁检查，见机油压力为0.42 MPa，仅比平时降低了0.01MPa，误认为是由于船舶晃动将沉积在油底壳底部的油泥拌动到滑油系统中，使得机油滤器脏污，就将使用中的机油滤器转换到备用机油滤器。

转换滤器后，该值班人员又到3号副机机旁检查机油压力，见机油压力仍为0.42 MPa，以为没有问题，就回到集控室。

实际上此时该副机的机油滤器压差大报警系统由于第3缸的连杆大端轴瓦合金脱落弓|起机油滤器堵塞，而油压下降是由于第3缸的连杆大端轴瓦合金脱落，使轴瓦与曲柄销之间的间隙增大，机油流失过多所致。

由于值班人员没有发现问题的内在原因，错失了采取措施的机会，导致事故的扩大。

在船舶副机管理中，机油压力是一个非常重要的参数。

当副机运行中机油压力发生变化时，值班人员必须要仔细检查、认真分析，同时，值班人员应记住副机运行时机油压力的准确数值，便于检查时比较。

一般情况下，副机工况正常后，只要机油进机温度不变，其机油压力基本不会变化;如发现机油压力变化较大，应该马上查明原因。

同样，当副机机油滤器压差大报警时，除非已确知报警原因，否则最好停机，查明原因。

## 3. 做好润滑系统的管理工作

润滑系统中的滑油品质好坏不但影响轴承的润滑效果，而且直接影响轴承的使用寿命。

当有水漏入滑油时，会生成酸性物质，使轴承合金受到腐蚀，同时，水漏入滑油中使滑油乳化变质，滑油粘度升高，因流体磨擦阻力增大使轴承发热，也使轴承面的油膜的抗压能力下降。

如该船3号副机因缸套密封圈老化，使冷却水漏人曲柄箱滑油中;同样，因油头水套安装质量不佳，使冷却水漏入滑油中。

由于该船的副机滑油系统无分离装置，使漏人滑油中的水分不能及时分离出去，形成酸性物质，直接腐蚀轴承合金，这也是造成轴承合金脱落的原因之一。

影响滑油品质的因素很多:

滑油本身的氧化、水或燃油漏入滑油中以及副机工作时的燃烧产物漏入滑油中都会使滑油品质恶化。

因此，在副机管理工作中除了要采取措施杜绝燃油、水和燃烧产物漏入滑油中，更主要是要利用过滤、沉淀和分离等处理手段来维持滑油的良好品质。

对于油质变差的滑油要及时更换，有条件的船舶应定期取样化验或利用简易的检验方法来监测滑油品质的变化，对于无分离设备的滑油系统应按说明书要求定期更换滑油。

## 4. 加强曲柄箱内部的检查

在副机的工作部件中，连杆大端轴承的工作条件是较为恶劣的。

由于四冲程柴油机的连杆在工作中有时受压，有时受拉，使轴承承受周期性交变负荷的作用，轴瓦合金长期在交变负荷作用下易于发生疲劳脱落；

而且由于新型柴油机爆炸压力的提高和轴承尺寸的减少，轴承承受的比压也随之增大，使轴承的工作条件更趋于恶化；

现在四冲程柴油机轴承比压及油膜最大压力都比二冲程柴油机大一倍，这也是四冲程柴油机的连杆大端轴承(包括连杆螺丝)和主轴承发生事故较多的原因。

因此,在管理中要加强对曲柄箱内工作部件的检查，因为工作部件损坏都有一个过程，只要加强维修检查，就能及早发现问题，采取有效措施，减少恶性事故的发生。
