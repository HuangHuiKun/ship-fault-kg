# 导读

船舶航行在大海上，由于天气环境的影响存在极高的风险，主发电机一旦发生故障，主配电板失电，应急设备的电力需求就需要由应急发电机来供给，如船舶应急发电机设备失效，并且未及时发现并修理，将有可能造成大的海难事故。

尤其是客船客滚船还担负着旅客的运输，作为船舶管理人员要重点关注哪些方面，根据多年的客船管理经验做以下分析。

# 一、应急发电机常见缺陷

## （一）应急发电机间无加热装置或加热装置故障失效

应急发电机的柴油机滑油系统及冷却水系统的温度需要保持一定值，温度过低导致滑油系统粘度大燃油发火困难等，一般柴油机内置电加热器和空间电热吹风两种加热方式。

柴油机在正常运行时，滑油系统滑油温度一般为55℃左右，当柴油机在低于0℃的冷态下启动时，滑油系统温度较低，滑油粘度大，流动性低导致柴油机内部运动部件润滑效果差，加大运动部件磨损程度，严重时会导致原动机拉缸，定期对滑油系统及防冻液冷却水系统进行检查。

大部分应急发电机柴油机冷却水系统在正常工作时保持在75℃～80℃之间，当冷态启动柴油机有以下几点缺点：

1. 柴油机燃烧室内的温度低，柴油喷入后不能良好的雾化燃烧，部分柴油仍呈雾滴状随废气排出。
2. 燃料燃烧不完全形成黑色微小颗粒，使活塞环槽内产生结碳，进排气阀门处存在结碳导致阀门关闭不严，压缩终了时气缸内压力降低。
3. 燃烧后由于燃油中的硫分生成物在气缸内与冷凝水结合而生成酸性物质，腐蚀汽缸，使发动机磨损加剧。
4. 水温过低使机油温度也降低，滑油粘度增大，流动性变差，滑油泵泵油量减少，泵油压力增高，以致供油不足，润滑性变差，润滑不良。

试验证明，如果冷却水温度从75℃降到25℃，发动机功率约降低8%，耗油增加30%～45%，磨损增大约10倍。

## （二）应急发电机无法自动启动

### 1. 启动装置故障导致无法启动

按照SOLAS公约要求，应急发电机只配有一组电瓶启动的需要设置另外一种启动方式，所以除了电瓶启动方式外，大部分应急发电机采用蓄能方式或者压缩空气方式。

按照这几种方式逐一分析：

一是启动电瓶故障。

由于恶劣的海上环境及船舶剧烈的摇晃，电瓶固定情况不好导致电瓶接线松动，电瓶长时间使用到期未及时更换电瓶导致容量量不足，如主管船员未定期仔细检查试验，未及时发现问题导致应急发电机不能自动启动。

二是启动空气瓶压力不足或者应急手动泵失效。

启动空气瓶内压力要按照要求进行检查及维护保养确保时刻处于可用状态，主管船员进行启动测试后，未按照要求把气瓶充注到规定的压力，或者充注后未按照要求把相关的阀门打开使柴油机处于随时启动状态而导致自动启动失败。

三是蓄能器未调整至规定位置或蓄能器老化弹性变弱导致应急发电机无法启动。

蓄能器需手动进行蓄能操作，应按照说明书将蓄能器储能摇至规定位置，如未蓄能至一定压力，蓄能器则压力不足导致无法启动应急发电机。

### 2. 应急发电机启动马达或者气动控制器故障

应急发电机原动机内部滑油系统、燃油系统、冷却水系统有泄露，压力温度等传感器安全保护动作，启动马达故障或者气动控制系统阀件卡阻等，为了保证自动启动及运转正常需要严格的按照公司管理体系及海事要求对应急发电机设备进行保养，发现问题后及时维修或更换故障部件，防止设备不能正常使用。

### 3. 应急发电机柴油油柜出口速闭阀处于关闭状态导致启动失败

应急发电机的日用油柜出口设有速闭阀，防止应急发电机间出现火灾时及时切断应急发电机燃油供给，主管船员在测试后未正确打开或者忘记把速闭阀打开或者由于船舶震动导致速闭阀关闭未及时发现，柴油机燃油系统无法正常供油导致无法启动。

### 4. 应急发电机控制模式处于手动模式

应急发电机控制板上设有应急发电机自动启动的遥控及手动两种模式，遥控模式为主配电板与应急配电板联络开关断开后45秒应急发电机自动启动合闸供电，手动模式为联络开关断开后应急发电机组不会自动启动，需责主管人员手动启动。

随着环保要求的提升，国际航行船舶安装并使用高压岸电，在船舶靠泊作业使用岸电时使用手动模式，防止船舶使用岸电时主发电机组断电后应急发电机组自动启动，海上航行时必须使用自动遥控模式。

## （三）应急发电机间手提式灭火器未定期检查

应急发电机间配备手提灭火器用于扑灭内部发生的小型火灾，一般放置门口处易于拿到、方便使用的位置，通常为干粉或者CO₂灭火器。

负责应急发电机间的船员或者消防三副应按照公司管理体系保养计划及法规要求进行相关检查，保障灭火器处于可用状态。

## （四）应急发电机间防火要求

客船应急发电机间一般设置在和生活区相邻的部位，应急发电机间与生活区相邻处所，由于船舶建造的墙体隔热性能较差，相邻生活区易燃物多一旦发生火灾如长时间未能扑灭，墙体热量传导有可能导致应急发电机间发生火灾，损坏应急发电机的情况。

因此，与其他相邻的墙壁应按照SOLAS公约要求进行防火A-60材料包扎分隔。对于年份较长的船舶来说，由于船员对于应急发电机间维护保养疏忽可能会出现防火包扎材料破损现象，存在安全隐患问题。

需要及时的修补或者换新防火材料。

## （五）应急发电机燃油储存柜未标识供油36h燃油存量刻度线

应急发电机的燃油储存柜为应急发电机提供燃料动力支持，确保船舶出现紧急情况时应急发电机自动启动并维持工作一定的时间。

SOLAS公约要求客船燃油储存柜内燃油存量至少为发电机工作36h，储油柜满油的状态下供给超过36h，因此油柜上应有明显刻度来标识着油柜内燃油存量低于36h时提醒主管船员为储存柜及时补充。

## （六）应急发电机组燃油储存柜速闭阀故障

燃油储存柜设有外部可以快速关闭的速闭阀，用于应急发电机间发生火灾时在房间外部可以快速切断应急发电机燃油供给，速闭阀可能会出现外部拉环无法关闭或测试过后主管船员未复位的现象以及拉环钢丝绳破损断股等现象。

## （七）应急配电板上绝缘低

应急配电板负载屏分为动力负载和照明负载两种，动力负载为接入380V或440V一些欧洲船舶为690V电压的动力负载，照明负载为接入220V电压的负载，两种负载接入后均需要绝缘接地检测，防止触电事故发生及动力设备短路损坏。

通常绝缘表显示绝缘值为无穷大，一旦出现绝缘故障时绝缘值会下降，因此配电都要求设置绝缘检测报警装置，一般动力负载绝缘报警值设置为1.5兆欧，照明负载绝缘报警值设置为1.0兆欧，当绝缘值下降到报警数值时进行报警提醒，出现绝缘故障需要及时修理。

绝缘低一般有以下几种：

1. 绝缘材料老化或损坏，发电机或者电动及的动力绝缘材料可能随着使用时间的增加而老化或损坏，导致绝缘性能下降。还可能由于高温、潮湿、化学反应等因素引起；
2. 污染或污垢，电机运行环境中的灰尘、油污、湿气等污染物可能会附着在绝缘材料表面，降低绝缘性能；
3. 湿度大，湿度环境可能导致绝缘材料吸湿，降低绝缘性能。特别是在潮湿的气候条件下，应采取措施保护电机的绝缘材料，及时检查绕组的加热线圈的工作状况。
4. 绝缘材料质量问题，如果使用的绝缘材料质量不佳或不符合标准要求，其绝缘性能可能会受到影响；
5. 过载或短路大电流，如果发电机长时间承受过大的负载或发生短路，导致绝缘材料损坏，从而降低绝缘性能。

## （八）应急配电板上电压频率不正常

电压及频率不正常有以下几种：

1. 柴油问题，应急发电机通常使用负20号柴油。

柴油系统滤器脏堵压力不足，可能导致柴油机转速低，导致发电机输出的电压频率低。

2. 发电机负载过大，如果应急发电机供给的负载超过了其额定功率，发电机无法提供足够的功率，导致电压频率下降。

3. 发电机内部故障，发电机的内部部件（如转子、励磁系统等）出现故障或损坏时，可能导致电压频率不正常。

4. 电气连接问题，应急发电机与负载之间的电气连接可能存在问题，如接触不良、线路阻抗不匹配等，这些问题可能导致电压降低。

5. 调节器故障，应急发电机通常配备了自动电压调节器，改变发电机的励磁用于稳定输出电压。

励磁机整流管个别损坏功能降低，可能导致电压不足。

## （九）应急发电机舱室通风

《钢质船舶入级检验规范》明确要求动力操作的通风百叶窗和通风关闭装置应为开启型。

正常情况下关闭动力操作的通风百叶窗和通风关闭装置是可被接受的；但当应急发电机起动/运行时，动力操作的通风百叶窗和通风关闭装置应能自动开启。

需要主管人员对百叶窗和风机定期开关活络和试验，多数船舶的应急发电机舱室通风为手动开启，无法自动开启。

## （十）其他

发电机间通信系统，声力电话及普通电话检查。

# 二、安全管理应急发电机

应急发电机是船舶航行过程中必不可少、重中之重的应急设备，客船尤为重要，不管是海事部门还是船级社检查都是必查项目。

为了确保船舶的安全人命安全维护管理好应急发电机尤为关键，笔者根据多年的客船工作经验建议从以下几方面对应急发电机设备、设施进行维护保养：

1. 加强培训提高船员素质和责任意识

公司应根据安全管理体系要求提高船员应急设备管理维护的培训频次，细化、优化操作细节及安全注意事项，加强落实船员应急设备的检查和维护，及定期考核船员对应急设备的管理能力，总结发现存在的问题，强化纠正、改正，确保所有船员适任、适航。

公司相关安全管理部门查阅汇总船舶案例，针对船舶实际情况结合事故案例总结经验教训，查找船舶管理的弱点，定期安排组织船员隐患排查。

2. 加强督促船长学习公司管理体系规范化管理船舶

船长应仔细研究、学习公司安全管理体系，定期开展船舶应急演练，善于观察发现船员应急演练方面的不足，开展针对性的专项训练。

按照公司安全管理体系组织编写更加具体、通俗易懂的操作规范，严查船员落实情况，严格按照公司的维护保养体系对重要设备进行保养，应急发电机间主管船员须定期对应急发电机间的消防设备、通信设备、应急发电机、油柜储油量、隔热材料等、设施进行检查、试验，如发现老化或损坏设施、设备应及时更换修理，提高船员安全操作意识，防止形式主义只记录无操作行为。
