# 一 船舶电气系统的组成

常见的船舶电气系统主要由船舶电站和船舶电力网两个部分组成。

船舶电站主要由发电机、变压器、原动机和配电板等设备构成，其中船舶电站中最重要的装置就是发电站，它可以将化学能转变为电能。

发电机组产生的电流可以通过配电板来进行分配和控制。

目前船舶电气设备中常用的原动机为柴油机，由单独的柴油机来驱动设置的电机组，为船舶提供运行的动力。

为了使船舶在航运、停靠等不同情况下有持续不断的供电，常见船舶电站主要有主电站、应急电站、靠泊电站以及特殊电站四种，主电站主要是在正常情况下向全船供电，应急电站是作为紧急情况下的供电设备，靠泊电站主要在船处于靠泊状态时发挥作用，特殊电站主要是为船舶上的助航设备供电。

作为船舶电气系统的主要组成部分之一，船舶电站可以为整条船舶提供持续不断的电能。

电气系统除了船舶电站这个重要的组成部分，还包括了船舶电力网这一组成部分。

船舶电力网的主要功能是将电站产生的电流通过电缆运输到相应的用电装置处，因此对于船舶电力网的基本要求就是安全可靠，及时在电力网出现故障的情况下，依然能对相应的用电设备进行供电，并将故障控制在小范围之内，限制故障的进一步发展。

根据供电类型可将船舶电力网分为五种，有由主配的电板供电，供电装置为各类辅机的船舶电力网、主要是为船舶的照明装置提供电力的照明电网等。

# 二 船舶电气系统常见的故障

由上文可知，船舶电气系统的组成十分复杂，导致了发生故障的可能性大大增加。

同时由于船舶电气系统的材料构成以及各部件的装配方法各不相同，在船舶的航行过程中由于航行路线和航行的环境也不同，加上对电气系统的疏忽管理，会使船舶电气系统出现不同的故障，一般来说，船舶航行过程中出现的故障有以下几种：

## 1. 电网系统的常见故障

在电力系统中，主要使用继电器来进行电路的稳定保护，并使电流维持在某一额度，但是在实际的过程中，往往会出现由于没有对继电器的相关设备进行定期维修而出现的松动现象，尽管在这种情形下电网系统仍会运行，但继电器却无法正常工作就无法保护电力传输的稳定。

在照明系统中，如果绝缘电阻低于正常水平的现象没有得到及时的解决，就会造成电路的负荷过大而发生短路。

继电器出现的故障主要表现在电气设备运行过程中触头的温度有一长期工作而发生异常，因此需要及时发现并维修。

当接线盒出现松脱现象时，会发生接地故障，会导致绝缘指示灯的灭灯和亮灯同时发生。

## 2. 电动机的常见故障

维修人员需要格外重视的就是船舶电气系统发电机出现故障的情况，发电机故障会造成电压问题使得电气系统出现短路的现象，这会导致发电机的温度上升，一旦温度上升到电力系统无法承受的能力时，发电机就会出现冒烟现象，导致负载设备在运行中出现堵塞且超出运作设备承受的范围，导致更严重的故障发生。

## 3. 发电机的常见故障

当发电机处于长期闲置的情况时，常常会出现接触不良及励磁机发生故障的现象，这时就会导致电磁场失磁现象的出现，就无法产生励磁电流，也无法使发电机进行自励。

在这种情况下，当发电机运行某一环节的参数发生错误时，就会使发电机设备逆功率问题的出现，在发电机没有经过完好维修的过程中，很容易导致发电机内部的绝缘体发生问题并使发电机受潮，也容易引发绝缘不良的故障。

同时维修人员还要定时关注船舶运行过程中电机线路发生断开的现象，并进行及时维修。

当发电机正常运行时，如果电力设备无法提供足够的电力供给，那么电力系统就很容易发生异常情况，一般表现为电压异常。

## 4. 主配电板的常见故障

如果主配电板处于震动状态时，就证明了电气系统运行正常，当这种震动状态的震动频率较高时，会导致硬件设备发生裂纹甚至开裂，导致主配电板无法正常使用。

尽管工作人员为了避免这种情况会对主配电板采取防尘措施，但是在电板的接线部位依旧会被灰尘所覆盖，这些微小颗粒会妨碍接线两端的串联情况，导致主配电板出现短路的现象。

通常主配电板出现系统故障通常表现为电流流动的不正常，造成电板运行的障碍。

# 三 船舶电气系统故障的维修方法

## 1. 发电机故障的维修方法

通常情况下，在船舶电气设备的维修过程中，经常会出现励磁现象，导致发电机创建磁场障碍，监测部分发现这个情况就会及时反馈，这个故障是由于磁场失磁导致的，维修的方法就是不断按冲磁按钮，使设备恢复磁场减少。

电压问题也是发电机常见的一种问题，通常表现为电压波动较大或电压消失的情况，这种现象会影响集电环电路出现故障，这是需要的检测维修的部分就是集电环、弹簧以及电刷等部分。

而如果不是电压问题引起的逆功率的情况时，需要检修的部分就是电机并车参数，查看参数设置是否准确。

并检查在当时情况下的绝缘性，在日常检修的情况下为防止潮湿等问题造成绝缘性的损坏，就需要加大检修的力度。

当无刷同步发电机为船舶的柴油发电机的情况下时，如果检测到发电机处于空载、轻载状态下时，同时发电机的参数未发生异常情况，导致发电机发生了电压下降的原因就很有可能是发电机承受了很大的负载，而发电机的电流会随着电压下降的持续下降而逐渐增大，最终超出各电缆中电流的承受范围，导致发电机为了电路不受破坏而产生跳闸，出现发电机运行故障。

这时，如果维修人员经过检查并没有发现异常情况，并且频率表使用过程中波动的幅度也不是很大，这时检测人员就可以知道发生故障的部位是励磁系统。

在这种情况下，检测人员要检测的就是发电机的电压，一旦电压处于正常状态下时，需要做的就是检测电机内部的励磁设备，如果出现二极管烧损的情况，需要操作的就是更换上规格相同的二极管，使发电机正常运行，让故障得到及时的处理。

## 2. 主配电板故障的维修方法

由上文我们可以知道，主配电板常见的问题就是跳闸，这主要是由于船舶电气逆功率的影响，这就要求了维修人员定期检查船舶电气设备，观测船舶的电气系统能否正常运转。

如果主配电板的主开关在机械、电气等方面无法正常闭合，就需要对自动同步操作实施修改，必要时可以使用手动操作。

当并联机组出现严重的问题时，可以紧固充电电缆，检测其他功能满足需求时，进行重启，使主配电板的运行恢复正常。

## 3. 电力网故障的维修方法

电力网出现的故障相对较多且十分容易被发现，在电力系统中，绝缘指示灯有暗有亮，主要是由于接电故障引起的。

同时接触器的继电器由于触头处于较热的状态，会导致触头烧毛或电融现象的发生。但是这些状态十分好解决，只需要按时对这些部件实施检查即可排除故障。
