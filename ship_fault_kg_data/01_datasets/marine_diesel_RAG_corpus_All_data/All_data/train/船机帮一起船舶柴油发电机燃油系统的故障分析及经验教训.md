# 导读

柴油机是船舶的重要组成部分，它的运行状态对舰船运行的可靠性和安全性起着决定性的作用。

船舶柴油机燃油供给系统因结构复杂、故障率也高。

据统计，造成柴油机停机故障的原因中，燃油系统的故障占 27.3%，在动力系统的故障中，燃油系统占 25.8%。

笔者曾“有幸”碰到了一次柴油发电机运转中跳电、原动机自动停车，并在燃油管系中放出大量气体来的个例。

从这个个例中可以看出船岸两部门管理方面的漏洞。

下面我就把所遇到的个例与大家分享，希望对广大柴油机管理者有所帮助。

# 一 事情经过

某轮在广州虎门锚地抛锚时，凌晨 02：30 时 2#DG 在无任何明显的征兆时跳电全船失电，同时 2#DG 原动机自动停车。

当值人员通知机舱相关人员后，马上启动 1#DG，可是 1#DG 启动后运行不到半分钟还没来得及向电网合闸供电也自动停车。

相关人员赶往机舱后，再次启动 1#DG 还是发生一起动后自动停车的现象。

于是启动应急发电机开启应急照明，对 1#DG，2#DG 全面检查，发现发电机燃油管系有大量空气放出（燃油滤清器放空气处）；经充分排放空气后启动 1#DG 正常， 并向电网供电。

之后启动 2#DG，启动后在检查柴油机运行参数时，又发生全船失电同时1#DG、2#DG 同时停机，在燃油管系滤器处又可以放出大量气体来。

经分析认为燃油管系大量气体存在是导致 1#DG、2#DG 跳电并自动停车的原因，且问题主要出在2#DG 燃油系统。

启动 1#DG 供电，对 2#DG 全面检查，在对 2#DG 第二缸油喷油器及高压油泵出油阀更换后，启动柴油机运行正常。

# 二 事故原因

燃油系统中容易积气，气体往往聚集在系统的高处。

系统有气后供油压力波动，甚至无法供油而停车。

油柜上都装有透气管，燃油供油系统又是封闭系统，系统中的气体大部分是清洗滤器时进入，也有可能在停车过程中由喷油泵偶件间隙进入；在正常运转情况下一般不会有空气进入燃油系统。

然而 2#DG 在正常运转过程时，燃油系统突然有大量的空气进入，足以说明燃油及其燃油喷射系统有故障。

该轮柴油发电机燃油使用轻油，油从轻油日用柜出发，经过双联滤器后一路经柴油机机带燃油泵增压后送到各缸高压油泵，高压油泵回油又到该泵进口；

另一路经机带油头冷却油泵增压后给各缸油头冷却，冷却回油直接回轻油日用柜。

该轮柴油机燃油喷射系统主要由喷油泵、高压油管和喷油器等组成，其工作质量直接影响柴油机工作过程及整机性能，决定柴油机的经济性和可靠性。

同时它又是柴油机的主要故障源，而其中喷油器故障直接影响燃油喷射质量，使燃烧过程恶化，导致柴油机性能劣化。

该轮全船失电、原动机自动停车就是一起由燃油喷射系统故障而引起事故。

柴油发电机在启动后，短时间内能使燃油系统窜入大量气体，只有和燃油喷射系统相关的气缸中的压缩空气或燃气经过有故障的喷油器通过油头冷却油管或高压油管高压油泵窜入燃油管系。

在对 2#DG 喷油器拔出雾化检查时，发现 2#DG 第二缸喷油器针阀偶件咬死在开启位置，而且第二缸高压油泵出油阀弹簧断裂、出油阀关闭不严。

燃气或气缸中的压缩空气通过咬死在开启位置的喷油器针阀偶件及高压油管，经过有故障的高压油泵出油阀，在高压油泵柱塞处于基园位置时，大量气体窜入燃油系统，导致船舶跳电、原动机停车。

# 三 经验教训

1. 严格把好备件的质量关，船岸共同协作管住源头，杜绝将不合格的备件送上船，船上应严把质量验收关，对于不合格或质量不过关的备件坚决不用退回处理，并通知公司相关部门看是否更换备件供应商。

该轮柴油发电机供应的备件质量不怎么好，船上也经常发生喷油器雾化不良、滴漏等导致排温高及高压油泵柱塞偶件磨损而排温低的情况，更换喷油器及高压油泵柱塞偶件很频繁，归其原因主要因为备件质量不合格。

此类情况不但增加了轮机人员的劳动强度，也给轮机人员在故障初期判断故障原因带来了很多干扰因素。

因此轮机长于对质量不合格批次的备件要拒绝使用。

2. 轮机人员加强专业知识学习，提高职业敏感性，加强巡回检查，燃油系统经常放气。

其实机械故障在其发生前或多或少都存在这样或那样的故障征兆。

就我们这次故障而言，在故障发生前，主管二管轮就发现 2#DG 第二缸排温忽高忽低、燃油系统双联滤器处有时可以放出一些气体出来的异常现象。

由于职业敏感性差，没有引起足够的重视，只是简单地调了调该缸的单缸油门，没有进一步查明原因致使事故的最终发生。

其实这时 2#DG 第二缸高压油泵出油阀及喷油器就已经有问题，导致排温异常。

如果主管人员及时检查第二缸喷油系统就不会出现全船停电等故障了。

# 四 结束语

此次故障是一起备件质量不好，加之船舶管理人员职业敏感性不够，专业知识不精而引起的故障。

加强船岸共同协作管理，提高船员管理和维修水平，提高船员职业敏感性可以避免此类故障发生。
