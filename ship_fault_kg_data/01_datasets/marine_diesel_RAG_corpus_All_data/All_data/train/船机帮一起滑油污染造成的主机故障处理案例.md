# 导读

柴油机检修是一项系统性的工作，在对某船舶主机进行系泊实验时，由于滑油脏污造成轴瓦烧蚀故障。

对柴油机检修，首先确定柴油机受损的范围和程度；然后根据受损情况，制定修复方案；最后按照回装顺序进行回装，并确保滑油系统清洁。

# 一、故障情况

某轮进坞大修，主机为镇江柴油机厂生产，型号6L28/32，2台，六缸四冲程，1988年出厂，功率1320KW/台，通过减速齿轮箱与尾轴相连。

在对主机进行系泊试验过程中，左主机空载转速加到700r/min，运行约 3min，滑油高温报警，自动减速，随手动停车。拆开曲轴箱导门进行检查，发现5#缸连杆大端与连杆轴颈烧伤，连杆轴瓦烧蚀；6#缸连杆大端轴瓦也有拉痕。

# 二、故障分析

对该次事故原因进行调查，发现船厂技术人员在实验主机前未对滑油进行检验，而此次事故正是由于滑油脏污失效引起的。

由于润滑部件多，因滑油受污染的范围和途径也多，污染来源包括：

异种油品的混入，水分污染，固体颗粒的污染，气体污染，微生物侵蚀及其他特殊污染源的污染。

该轮在启动主机前，虽然对滑油进行了分油处理，但净化处理不充分，并且没有对油品进行仔细检查分析，所以造成此次事故。

# 三、检修办法

## 1、确定柴油机受损的范围、程度

拆去汽缸盖，吊出活塞连杆组件，并且解体，检查活塞销孔、活塞销表面、连杆小段的衬套、连杆大端以及连杆瓦。

以上所有零件经过检查，确认合格后，清洗干净，方可重新装上柴油机。

检查曲轴连杆颈的受损情况。

拆装检查2、4、6档的上下轴瓦，检查主轴瓦和主轴颈的受损情况，并且装回主轴承盖，不装上瓦，只装下瓦，上紧200bar,拆除1、3、5、7档的上下主轴瓦，检查主轴瓦、主轴颈、止推片、曲轴止推面的受损情况。

检查凸轮轴，凸轮轴瓦的受损情况。

检查进排气滚轮导筒受损情况，拆掉高压油泵，检查供油滚轮导筒的受损情况。

拆除柴油机上的滑油管，滑油滤器，外围的滑油管路，滑油冷却器等，清理干净，才能重新装复。

打开前端盖上的盖板，清理内腔。

## 2、根据检查的受损情况，制定修复方案

检查曲轴的主轴颈，如无问题，则对曲轴上受损的连杆颈进行现场修复，标准由主机厂家提供。

如果曲轴的主轴颈经过检查，也存在手工无法修复的损伤，则对柴油机进行全面解体，曲轴交厂家进行处理，标准要求由船方和船厂提供。

## 3、回装顺序

柴油机上的滑油分配管和滑油滤清器的进口油管装机时，加装200-240目的铜丝网。

清理干净油底壳，加油，在只装2、4、6 档下瓦，上紧 200bar 的情况下，用滑油预供泵进行串油，冲洗机架的主油道孔，对每一档主轴承进行检查，并注意及时清洗所有的铜丝网。

以上工作检查合格以后，装复所有的主轴承，并且检查主轴承瓦间隙、曲轴止推间隙。

再用滑油预供泵进行串油，冲洗曲轴上的油道孔，加装 200-240 目的铜丝网，并对每一档连杆颈的油道孔进行检查。

注意及时清洗所有的铜丝网并且多次转动曲轴。

以上工作检查合格以后，活塞连杆组才可以装机，并且检查相关间隙，合格后，装汽缸盖等。

柴油机全面恢复以后，再次用滑油预供泵进行串油，检查滑油分配管进机架处的铜丝网，合格后，去除滑油滤清器的进口油管处铜丝网。

继续进行串油，检查滑油分配管进机架处的铜丝网，合格后，去除滑油分配管进机架处的铜丝网。

# 四、润滑油的简易检验

润滑油的质量好坏，必须经过化验分析才能得出正确结论。

目前在大多数船舶上均不具有润滑油的化验分析设备，但技术人员可以通过掌握一些简易方法对润滑油质量进行定性判断。

比较常用的方法是外观检查和滴油实验。

## 1、外观检查

新的润滑油在阳光的照射下，表面会产生蓝色的反光，而用过的旧油，则不会产生反光；用肉眼观察装在玻璃管中的质量良好的油，应当是澄清的，无浑浊现象；无悬浮颗粒，试管底部无沉淀物产生。

## 2、滴油试验

柴油机运转时取出油样，取一根玻璃棒浸入油中，把玻璃棒端部的油滴在滤纸上并在室温下干燥几个小时，把所得的油渍与新油相比较，油渍越黑，说明滑油越脏。

如果中心黑点中有较多的硬沥青质和碳粒，则表明过滤不良，通过加强过滤后的滑油尚可用。

如果黑点较大，黑褐色均匀无颗粒，则表示润滑油已变质，应予以更换。

如果黑点较小，色较浅，四周的黄色油迹较大，则表明滑油尚可使用。此种方法应定期进行，并保存化验结果，来查看滑油污染的变化过程。

另外，还可以根据以下情况判断滑油是否变质：

（1）分油机中出现大量油泥；

（2）润滑油气味变得辛辣而刺鼻；

（3）溅在曲轴箱金属面的润滑油呈棕黑色；

（4）活塞冷却腔内积炭过多等。

# 五、结束语

柴油机检修工作是一项技术性要求非常高的工作，同时要求施工人员具有良好的团队协作能力和服从意识。

柴油机检修工作时间周期长，工作环境恶劣，要求施工人员具备丰富的工作经验。

在施工过程中，需要船厂技术人员和船员紧密沟通，密切合作。

制定科学合理详细的施工方案，船厂工人必须严格按照要求进行施工。

滑油对柴油机的正常运转起着至关重要的作用，无论是日常管理还是进场检修，工作人员都应该认真检查滑油品质，确保滑油清洁，能够起到润滑冷却的作用。
