# 导读

某型船柴油机电子调速器故障在船舶各级计划性修理及临抢修中都成为排故的难点。

为了能够快速、准确定位和排除故障，本文对故障现象、工作原理和处理措施等进行分析总结。

下面针对某型船MTU16V396SE84柴油机计划性修理中出现的电子调速器故障的解决过程进行阐述。

# 一、故障现象

本次调整出现的现象是在某型船计划性修理柴油机回装供电后，１＃、３＃ 柴油机机旁控制箱出现“调速器故障”报警，同时机旁控制箱油门齿条显示“燃油齿条位移”在最大位置，显示20格。

此时打开R082分站面板，对分站内各电路板指示灯进行检查，发现有MPU14-01板１号灯和RG1-01插件板２号灯亮。

# 二、原理分析

## 1、电子调速器

电子调速器是柴油机运行的核心单元，柴油机的转速和喷油量是通过电子调速器来进行控制，并具有可调节的调速特性（静态速度偏差）。

调速器可在负荷变化的情况下通过调节喷油量保持柴油机在要求的转速下运行。

它也可在柴油机启动过程中调节喷油量，并可根据各种运行参数限制最大的喷油量。

某型船MTU16V396SE84柴油机采用R082电子调速器，与之配套使用的有脉冲式转速传感器和操纵燃油齿条用的电磁式执行器，在执行器中包括齿条位移传感器，用这些设备构成转速和齿条位移双闭环调节系统。

R082电子调速器由两个串联的PID调速器组成，也就是一个转速调速器和一个喷油调速器组成。

转速随负载变化时，调速器就根据转速差按比例调节燃油喷射量，同时自行补偿转速偏差值。

转速调速器为主调速器，可从控制台或上级控制系统设定调速器参数值。

转速变化的合成信号作为新的转速设定信号，它同时作为要求的喷油量设定值送到喷油器调速器。

喷油量调速器接受从执行器的电感式齿条位移传感器来的实际喷油量信号。

在喷油量调速器中形成的变化量信号用以控制执行器的电磁线圈，使喷油泵齿条重新定位并调节供油量。

## 2、执行器

执行器即末级控制器（见图１），装在外接体上，而外接体用螺栓固定在喷油泵上。

它包括电磁铁和齿条位移传感器。

电磁铁（工作磁铁）有两个独立线圈，并且是冗余的。

齿条位移传感器和电磁线圈的电气连接是在同一个插座上引出的。

执行器实际是电磁铁，它是由一个100Hz基本频率的脉宽调制的脉冲驱动。

如果供给24V工作电压，在线圈中的电流将由变化脉冲宽度来控制，交变力作用的结果可调节它的位移。

当电源发生故障时，位于控制线圈和弹簧之间的复位弹簧能保证迅速安全的停机。

## 3、齿条位移传感器

齿条位移传感器实际是电感式供油传感器（见图２），它依靠位移传感器连杆，按照电感原理，以燃油齿条位移来反应柴油机实际供油。

位移传感器装由一个初级线圈、两个次级线圈和一个软铁套筒组成的差动变压器。

初级线圈布置在两个次级线圈之间。

初级线圈由一个稳定的交流电压供电，软铁套筒移动，使一个次级线圈产生给定的电压。

电子线路将感应交流电压转换成一个行程成正比的直流电压。

根据位移传感器连杆的位置改变使软铁轴套的位置发生变化，将线圈芯棒的轴向移动转换成一个电压信号。

软铁轴套伸入线圈越多，电磁感应强，感应电势大；反之，感应电势小。

按齿条位置传感器连杆的位置，感应式齿条位置传感器通过电缆连接器，输送一个成比例的电压信号到柴油机电子调速器。

供油传感器提供1V-8V的输出电压，相应的燃油齿条位移为0-20ｍｍ。

# 五、故障排除

(1)在Y19航空插头上连接电缆，其中A脚为10 VDC正极,G为10 VDC负极,B和C脚为齿条位移传感器反馈电压输出;

将10V直流电压加至A和G脚中,B和C脚接至电压表,实时测量反馈电压值。

(2)供油传感器提供1V到8V的反馈输出电压，相应的燃油齿条位移为0～20mm。

如果位移传感器电压不再允许范围之内,也就是说低于1V或高于8V(误差±0.035V),在重复测试后(自行检测),RO82调速器箱认为此时的齿条位移传感器反馈电压值过低,判定为反馈电压值无效,认定传感器故障,输出“调速器故障”信号，并使齿条显示为20格。

(3)在现场对执行器进行重新调校，如图1所示。

打开执行器后端盖,观察齿条位移传感器,用两把10mm 叉扳手,分别叉在在齿条位移传感器连杆的连杆螺母和锁紧螺母,将锁紧螺母松开，用5mm叉扳手固定齿条位移传感器连杆,转动连杆螺母,调节齿条位移反馈电压,使零位发生变化。

(4)用手调整连杆螺母，同时用万用表测量RO82调速箱56X航插的反馈电压G、H,观察电压值变化。

当电压表显示数值在1V时,即可停止调整连杆螺母,使齿条位移传感器连杆长度不再发生变化,紧固锁机螺母。

至此齿条位移传感器反馈电压调整结束。

(5)在实际操作时，由于为手动调整,该数值会有一定误差，反馈电压值一般在1±0.035V 范围内皆就能满足使用要求。

此时用手推动执行器固定挡板，快速松手，使挡板自由复位,同时观察电压表示数，确认示数调整后稳定。

最终将反馈电压值调整到1.035V(1#机)和 1.014V(3#机)。

# 六、调试过程的注意事项

(1)初次运行前必须调节连结杆使齿条位置传感器正好在零位(停机)。

(2)当每调整完执行器位移传感器后，都要用力推动复位弹簧，然后迅速松手,模拟真实的停机状态,使得复位弹簧能够完全释放。

以便于测得位移传感器真实的零位反馈电压。

(3)检查挡板固定螺母是否有松动现象，若松动,复位弹簧复位后通过固定挡板连接到位移传感器，会导致位移传感器零位时的反馈电压偏移。

(4)柴油机高压油泵与执行器连接、回装后，必须重新测量执行器静态零位的反馈电压，避免因高压油泵与执行器连接、回装时造成执行器静态零位偏移，保证执行器静态零位在1士0.035V范围内。

# 七、结束语

通过此次排故发现,出现故障不能急于拆卸排故，可以通过观察监视装置的反馈情况后再排故。

而MTU396SE84型柴油机的R082调速器负责对柴油发电机组的运行情况进行监视、预警，监控系统的报警往往是故障定位的关键线索,通过相应报警指示原因，开展检查排故。

此次排故过程掌握了调速器故障的排故方法，积累了柴油机监控系统的排故经验,提高了该型船的柴油机保障能力。
