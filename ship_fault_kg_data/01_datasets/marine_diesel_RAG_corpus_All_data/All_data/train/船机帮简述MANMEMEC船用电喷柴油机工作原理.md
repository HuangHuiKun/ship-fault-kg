# 船机帮简述MANMEMEC船用电喷柴油机工作原理

## 导读

近年来随着全球对大气环境保护的进一步重视，减小营运船舶的排放以适应当前环保要求已成为大势所趋。

为获得更好的柴油机性能，满足更高的排放要求，传统的MC柴油机显然已力不从心，取而代之的新型电喷柴油机应运而生，ME型柴油机就是MAN公司研发的这种电控型的新型柴油主机，其喷油、排气、空气分配、气缸注油、调速等功能全部是由柴油机本身的电控系统来进行控制。

同传统的MC、MC-C型主机相比优点很多，主要表现在油耗低、排放低、热负荷均匀、操纵灵活等。

## 一、ME电喷柴油机

### 与传统MC柴油机的区别和优势

全电控低速船用柴油机以MC系列低速船用柴油机为基础，采用电子控制液压-机械系统实现燃油喷射；排气阀开启或关闭；起动空气以及气缸注油装置的正时，使柴油机在全负荷段精准和最优化地运行，同时，可在运行中对参数进行调整，具有很高的适应性和灵活性。

MC与ME系列低速船用柴油机的主要区别在ME系列低速船用柴油机上的电控液压-机械系统替代了MC系列低速船用柴油机上的以下零部件：

凸轮轴链传动；燃油凸轮、排气凸轮、示功凸轮及凸轮轴；燃油泵执行机构，包括滚轮导筒及换向机构；传统式燃油泵及VIT装置；排气阀执行机构及滚轮导筒机构；凸轮轴驱动式空气分配器；调速器及其执行机构；调油轴；应急操纵台；机械式气缸注油器。

ME柴油机新增以下部件：

液压供油单元（HPS）；液压气缸单元（HCU）；柴油机控制系统(ECS)；电控起动阀（SAV）；起动与换向程序；电子调速功能；辅助鼓风机控制；电子燃油喷射型线(EPIC)；排气阀执行机构；曲轴位置传感系统(CPS)；电控Alpha注油器（ALS）；机旁控制板（LOP）；系统还可安装PMI系统及CoCos-EDS监控系统。

ME型主机相对于传统的凸轮轴控制的MC型主机有很大的优势，主要体现为：

机械部件大大简化，便于维护；柴油机低负荷（部分负荷）工况技术性能优化，燃油消耗率降低；有效降低NOx排放，并实现了无烟运行；喷油和排气、精确定时控制，使柴油机良好平衡，热负荷始终是均衡的；良好的操作性能，如加速、换向和紧急停车等。

## 二、ME型电喷柴油机的原理

ME柴油机通过液压-机械系统实现燃油以及排气阀的动作。

这些动作的执行由柴油机控制系统（ECS）进行电子控制。

柴油机燃油泵由液压活塞通过增压达到所要求的燃油喷油压力。

液压压力由电控比例阀（FIVA）实现压力控制。

排气阀通过液压开启，与MC柴油机相同，但液压压力不是由凸轮机械控制，它通过电控比例阀控制排气阀执行活塞的动作实现排气阀的开启，排气阀的关闭通过空气弹簧实现。

液压油用柴油机系统滑油做介质，它通过安装于柴油机上的液压供油单元（Hydraulic Power Supply）获得要求液压压力。

启动阀由电控电磁阀实现正时开关，ME柴油机取消了空气分配器的启动阀开关正时系统。

按照曲轴位置通过电子阀的控制，柴油机控制系统完全实现电控控制燃烧作功循环。

系统的灵活性可以通过不同的运行模式（Running Modes）实现。

如低油耗或低排放模式。

整个控制系统运用了大量的电子模块，其中EICU（Engine Interface Control Unit）是柴油机接口控制单元模块，主要起到一个接口控制器的作用；

ECU（Engine Control Unit）是柴油机控制单元模块，它集成了传统柴油机的部分遥控系统和调速器的功能；

ACU（Auxiliary Control Unit）是辅助控制单元模块，它控制主机的一些辅助设备，如辅助鼓风机、伺服油泵、HPS电动泵等；

CCU（Cylinder Control Unit）是气缸控制单元模块，每个气缸一个，控制每缸的喷油、排气、气缸注油以及起动空气等；

MOP（Main Operating Panel）是主操作板，在控制室内，船员通过MOP发送指令，控制整个控制系统；

LOP（Local Operating Panel）是机旁操作板，作为船员在机旁应急操作用。

两条通讯线路将这些控制模块联系起来，实现数据共享传递，这些模块都有自己的ID号，这样就不会造成混乱，数据的交换会更顺利。

设计两条是出于冗余的考虑，即当一条失效时，另外一路网络线仍然可以工作，使得系统不会崩溃，提高了可靠性。

由于柴油机与船侧其他系统的联系都是通过EICU模块来完成的，如图2所示。

图2 ME主机EICU控制关系图

调速手柄发送4～20mA的信号给EICU，然后通过柴油机内部的控制系统实现调速功能；

与遥控系统的联系是通过RS422的通讯线来执行的；

柴油机控制系统内部的报警和停车需求都是通过EICU送至船上报警系统和安全系统，因此，EICU是主机和外界设备的分界。

为了确保主机运行的安全，安全系统的停车命令，除了经EICU传给主机外，还有一组停车命令直接发给了CCU模块和ECU模块，直接命令各气缸的控制单元和主机的控制单元执行停车命令。

确保安全系统发出的停车命令得以可靠的执行。

一般来说，因为采用了电子控制喷油，所以主机最低稳定转速可以低至额定转速的10%～15%，所以主机在超低负荷运行时也很稳定，一般不需要单缸停缸。

但是如果有紧急情况，也可以采用停掉一个或几个缸的方法，使主机在低转速下运行。

由于ME主机采用了单缸直接控制，所以单缸停缸相比传统机型非常容易实现。

### 1、ME柴油机电控液压-机械系统

ME系列低速船用柴油机由电控液压-机械系统取代了MC系列低速船用柴油机的凸轮轴传动正时系统。

由于受凸轮轴机械传动，凸轮形线的局限，MC柴油机在低负荷时往往因为燃油泵泵压不够造成燃油喷射雾化不良，影响排放；

油耗及最低稳定转速（一般为25%~30%MCR转速），反之，在高负荷时引起燃油系统压力过高。

而通过液压-机械系统驱动的燃油泵，不管柴油机在低负荷还是高负荷，燃油都可保持要求的压力，燃油喷射形线设定成最优化模式，从而使柴油机在全负荷范围达到最优化的运行，同时，其最低稳定转速也大为降低（可达10%~12%MCR转速）。

### 2、液压供油单元（HPS）

液压供油单元（HPS）系统，通常位于柴油机的输出端机架上，它将柴油机系统滑油通过增压泵增压至3×104KPa的液压油供气缸液压单元（HCU）用。

它主要由零件：

10µm的自清式滤器、25µm的旁通滤器、电动起动泵和机带轴向活塞式增压泵组成（如图3所示）。

图3液压供油单元（HPS）系统组成图

柴油机起动前，液压系统的液压油通过电动起动泵增压至约2.25×104KPa，等柴油机起动后，机带轴向活塞式增压泵取代电动起动泵运行。

机带轴向活塞式增压泵是电控可变排量泵，一般每台机三个，正常二个工作就能达到所要求的压力，如果某一个泵出现故障，另一个能自动接替，以确保柴油机正常运行。

### 3、气缸液压单元（HCU）

图5气缸液压单元（HCU）布置图

图6气缸液压单元（HCU）结构组成图

从图5，6可以看出，柴油机每个气缸都有一套气缸液压单元（HCU），安装于一个公共底座上。

每个气缸液压单元（HCU）有一个带若干蓄压器的液压分配块，其上装有一个燃油泵；一套排气阀执行机构；一个集成ALPHA注油器以及一个电控比例阀(FIVA)和各种进出油；检测接口。

气缸液压单元之间以及气缸液压单元与液压供油单元（HPS）之间用双层壁管连接。双层壁管上装有压力控制阀和流量报警传感器，万一内管破裂，外管可作为高压管，柴油机仍可应急运行。

### 4、燃油泵（如图7所示）

图7燃油泵原理图

燃油泵由2.25×104KPa左右的液压油通过增压活塞将约800KPa的燃油增压至6×104～1×105KPa经燃油喷油器雾化进入燃烧室燃烧。

燃油喷射正时，喷射形线和喷油量通过电控比例阀（FIVA）进行控制。

燃油喷射的动作是柴油机调谐匹配中最重要的因素之一。

ME型柴油机燃油喷射都是通过机械-液压机构来驱动的，而这些机械-液压机构的执行器是由CCU电子模块通过FIVA电磁阀来控制的，从而实现电子精确控制喷油定时和排气门的开启。

### 5、排气阀执行机构

图8 S50ME-C与S50MC-C排气阀对比图

如图8所示（S50ME-C与S50MC-C排气阀进行对比），排气阀通过液压开启，通过空气弹簧实现关闭，但液压压力通过由电控比例阀（FIVA）控制排气阀执行活塞的动作实现。

排气阀执行机构采用二级活塞结构（如图9所示）。

图9 S50ME-C排气阀执行机构内部结构图

在排气阀刚要打开时，需要克服气缸内的压力，第一级活塞起作用。

然后，第二级活塞完成排气阀的行程。

当排气阀需要关闭时，电控比例阀（FIVA）打开释放液压油压力，排气阀通过空气弹簧关闭排气阀及其执行机构。

图10 S50ME-C排气阀执行机构原理图

从图10可以看出，排气阀的开（关）正时都可用电控比例阀（FIVA）控制并优化。

排气门的动作同样重要，是柴油机调谐匹配中最重要的因素之一。

ME型柴油机排气阀的动作是通过机械-液压机构来驱动的，而这些机械-液压机构的执行器是由CCU电子模块通过FIVA电磁阀来控制的，从而实现电子精确控制排气门的开启。

### 7、起动空气系统

大型柴油机的起动是靠起动空气按照发火顺序依次进入气缸，使曲轴转动，从而起动主机。

如图13所示，ME型柴油机每个气缸起动空气的定时是由各个电磁阀分别控制，电磁阀受控于CCU模块，MC型柴油机是借助传统的机械传动式空气分配器来进行。

这样，柴油机起动空气分配系统就变得非常简单了。
