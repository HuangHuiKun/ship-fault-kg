# 导读

冷却系统在船用发动机中非常重要，其作用就是通过冷却介质把受热部件的多余热量（约有30%）带走，不仅可以发挥出船用发动机的性能，还能对机器部件起到保护作用。

本篇文章就船用发动机冷却系统、系统故障分析和系统故障的处理方法进行探讨，为今后船用发动机的冷却系统故障提出有针对性意见。

工作频繁和承受能力强是船用发动机在使用过程中最大的特点，其在使用过程中对冷却系统的要求较高。

在机器维护时，如果忽视对冷却系统的防护，就容易造成船用发动机冷却系统出现故障，故障就会导致机器的热量没有办法排出去，影响正常的使用，而且机器内部温度太高时，也会使得发动机动力性能降低，由此造成设备故障。

# 一 常规冷却系统

发动机常规冷却系统主要分强制液体冷却和风冷，船用最常用的为强制液体冷却系统，主要分淡水冷却系统和海水冷却系统。

康明斯K19柴油机冷却系统流向示意图

淡水冷却系统中，由于淡水本身水质较好，使用之后不会出现结垢问题，而且传热效果非常好，就目前来讲其使用范围是非常广泛的。

海水冷却系统的缺点是容易使用之后结垢，结垢之后就会影响到该系统的效用；

因此，为了减少腐蚀和结垢情况，设置海水的温度不能超过 45℃，否则就会造成较大的问题，而且目前很多船用发动机都不使用海水冷却系统进行直接冷却，而采用淡水循环冷却，使用淡水对设备进行冷却，方式是闭式循环冷却；

而使用海水对设备进行冷却的时候，使用的方式是开式冷却。

# 二 中央冷却系统

目前，船舶中央冷却系统应用最广泛的有两种基本的形式——独立式中央冷却系统和混流式中央冷却系统。

独立式中央冷却水系统示意图

混流式中央冷却水系统示意图

混流式采用高低温水的混合来调节参数，这种冷却形式通过混合阀将高温淡水与低温淡水联通，根据高温淡水的温度要求，混合阀控制低温淡水进入高温淡水系统的流量，所有淡水的热量由中央冷却器中的海水带走。

因此每套系统仅有一个和海水直接接触的冷却器。

相对独立式冷却形式而言，少了一个高温冷却器，高温水通过低温水来进行冷却，这样进出柴油发电机及中央冷却器的水温控制较难。

在独立式中央冷却系统中，高温水热交换器可用低温水冷却，也可用海水冷却。

船用中央冷却系统是使用不同工作温度的两个单独的淡水循环系统；

高温淡水冷却系统和低温淡水冷却系统，经常使用高温淡水冷却系统来冷却船用发动机等设备，这是因为船用发动机在运行过程中，机器内的温度会逐渐升高，使得各个部件的温度也增高，如果使用常温的冷却系统，那么会出现温度差，太大的温度差直接改变系统内部件的物理性能，从而影响到船用发动机的使用时间。

高温淡水冷却系统主要是由机带的水泵、柴油机缸套、高温冷却机等一些部件组成的循环水回路。

这套回路设备对于冷却船用设备的发动机尤为重要，不仅不会对设备产生副作用，还会实现冷却设备的目的。

循环水回路中提到的缸套预热器就是经常使用的暖缸，暖缸的原理是加入高温度的淡水，使得淡水在缸内持续循环30min，持续循环一段时间之后，然后开启发动机，但是需要注意的是设备生产厂家不一样，那么设备对上述温度要求也就不一样，但是使用目的都是相同的，都是为了让缸内发火，启动设备工作，使得设备处于正常运行状态。

另外一定不能让缸套造成磨损，一旦造成磨损，就会影响到缸壁的热应力。

暖缸在工作期间，设备内的备用泵都处于停泵状态，停泵之后使用止回阀对热量进行隔离，若是此时一旦开启船用发动机，那么暖缸会直接停止工作，由此高温淡水系统的循环泵开始运行。

发动机是高温淡水系统进行循环的动力因素，而且随着发动机的运行，高温淡水系统中的温度也会逐步上升，当温度上升到设置温度时，进行循环的高温水便会从旁边的循环管路中到中央冷却器中进行冷却，冷却之后进行补水，补水是由中央冷却系后的三通温控阀将低温水补入到高温水系统当中，从而达到补水的目的。

# 三 冷却系统故障

## 1. 水温过高

冷却水温过高一般出现在夏季，其发动机系统内温度高，有时温度高达100℃。

水温过高会导致润滑油温度升高，粘度降低，对发动机的润滑效果变差，加剧运动部件的磨损，导致大的机损事故发生。

水温过高首先要排除环境温度影响，再从这几个方面进行分析检查：

冷却系统内部水量过少、水泵无法正常运行、热交换器堵塞、节温器损坏。

## 2. 水温过低

冷却水温过低主要出现冬季，冬天环境温度较低，如果冷却系统使发动机内部的温度过低，可燃混合物点燃困难或燃烧迟缓，造成发动机功率下降；

润滑油也因温度过低，粘度加大，会增加机件运动的阻力，使得机械运行困难，出现燃烧不良情况。

系统出现故障的原因是发动机内部冷却水水垢厚，保温效果降低，使得节温器无法正常运行，一直处于故障阶段。

## 3. 冷却系统中出现锈蚀

船用发动机的冷却系统出现铁锈，最明显的特点是冷却液在散热器中出现变色情况，由正常的颜色变成棕色，这时要更换冷却系统水泵的水封轴承。

一旦设备部件的颜色出现变化，这就说明冷却系统中出现了腐蚀情况，一旦系统出现腐蚀情况，在冷却系统的水泵水封则发生了损坏，设备运行也受到故障，设备遭到磨损。

船用设备出现腐蚀现象通畅是因为冷却系统中进入了有杂质的氧气，有杂质的氧气混到设备内之后，对冷却系统进行破坏，影响船用设备冷却系统的正常运行。

## 4. 冷却系统泄露

冷却系统在运行过程中消耗水量非常大，而且停止之后设备中水流出，这就表明冷却系统出现了漏水情况。

造成漏水的因素有很多，主要有热交换器泄露、水泵的封水圈出现损害或者是变形、气缸出现裂缝、冷却系统内部水管破裂。

船用设备的冷却系统出现漏水，会直接阻碍到系统的正常运行。

# 四 冷却系统故障的处理

## 1. 处理水温过高

冷却水温高的排除方法：

冷却系统在发动机开启之前，必须检查膨胀水箱内的水量是否充足，另外还要检查水管和设备管道的通畅程度；

观察冷却水的压力表指示是否正常，也可用手紧紧握住水管，检查水泵水是否在正常的运行状态，若是设备高速运转时感觉到水管中的水流量增大，那么就说明冷却系统内的水泵正常，反之则水泵出现问题，必须及时将水泵拆解维修。

若是水泵中的销键出现损坏，一定要检查系统中水泵的叶轮，更换时也要注意叶轮的方向；

检查调温器时发现发动机水箱进水位置有大量的水流，那么就说明调温器阀门损坏了；

温度过高，冷却系统中进水管没有水流流出，这就说明系统内的调温器失去了作用，要及时检修；

热交换器堵塞是水温升高最常见的故障，使用高压水枪冲洗，一些比较难冲刷的杂物，需要使用工具进行疏通，要注意不要损伤芯体。

## 2. 处理水温过低

冷却水温低的排除方法：

在冬季使用冷却系统时，一定要在设备水箱位置套上保温材料，而且还要对保温材料进行定期检查，对于水箱内出现的水垢不能随便清洗，必须使用指定清洗液对其进行清洗，清洗之后加入软水重新启用设备。

## 3. 处理冷却系统中出现锈蚀

铁锈的排除方法：

先将冷却系统中的冷却液排除干净，然后检查管道，查看管道是否有堵塞情况，若是有堵塞情况，及时清理，之后清洗热交换器，将冷却系统清除干净。

目前冲洗最为有效的方式对冷却系统进行逆流冲洗，逆流冲洗的方式将水流和冷却运动的方向相反进行冲洗，冲洗过程中可以先使用冷却冲洗机械设备对船用设备的冷却系统进行全方位重新，以保证可以将冷却系统中的铁锈全部冲洗出来。

这里需要注意的是冲洗过程中必须将水和空气在软管的下端输入，将管内的铁锈和其他杂质从软管的上端排除。

最后对冷却系统中的缸体进行冲洗，冲洗该设备必须将调温器拆卸掉，将水和空气压到调温器的出口位置，确保铁锈和杂质可以在水泵的进口位置排除，但是冲洗是水体的压力不能过大，否则会损伤热交换器。

## 4. 处理冷却系统泄露

排除方法：

若是发动机中的热交换器（水箱）出现泄露情况，首先仔细检查热交换器的密封垫圈是否老化密封不严，其次检查热交换器的芯体是否破损泄露；

检查这两个方面的泄露，可制作简易工装，通过气体或者液体进行现场检漏，可对破损的铜管进行临时封堵恢复使用。

小型发动机可将水箱拆下来，使用一些类似橡皮塞的物体将水箱的出口的全都堵死，然后把水箱重新放到水中，充气步骤是使用打气筒在水中进行，凡是水中出现冒气泡的地方，都是水箱漏水的位置，对这些位置进行标记，对标记好的位置进行修补维修，维修工作结束之后再按照之间检测的方式重新进行检测；

若是水泵出现了漏水情况，那么必须检查水泵是出现变形情况，一旦出现变形，必须更换，若是水泵的螺丝出现松动情况，只需要将螺丝重新拧紧；

若是气缸出现裂缝或者设备机体出现裂缝，那么必须将气缸和机体拆除，之后对其进行维护，对于一些裂缝严重的地方，应该使用生铁进行焊接，焊接之后的效果更好；

若是设备中的水管破损或者是水管破裂，及时更换水管并检查水管接头位置是否拧紧。

# 五 结束语

综上可得，船用发动机的冷却系统不仅可以影响到机器功能的发挥，也对机器的保护起着重要作用。

上述中介绍了冷却系统的原理、冷却系统的组成、运行过程中遇到的故障以及对这些故障的处理，给船用发动机的冷却系统防护提出了新的方法，以供借鉴。
