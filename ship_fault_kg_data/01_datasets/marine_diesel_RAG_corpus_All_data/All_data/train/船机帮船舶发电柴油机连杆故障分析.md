# 导读

船舶柴油机连杆是将活塞的往复运动传递给曲轴，对外做功，连杆承受气缸内气体压力、往复惯性力等作用，船舶柴油机连杆不但运动复杂，而且受力也很复杂，很容易产生疲劳而断裂，造成严重后果。

杆裂纹甚至折断是由于材料疲劳和机损事故而发生的，所以为了保障柴油机的正常工作，应定期对连杆、连杆螺栓进行相应的保养与检查。

# 一 故障现象

某轮发电柴油机型号为 Sulzer6AL25/30，功率为 600 千瓦，转速为700RPM，涡轮增压器型号为VTR250N，转速为 11000RPM，此发电柴油机大约运行400 小时连杆在大端螺纹处断裂，在曲轴箱部位出现异常声音，有“嗒嗒”的敲击声，声音越来越大，同时增压器超速，轮机员立即停止此机运转，启动备用发电机，机舱人员立即对故障发电机检查，发现发电柴油机连杆断裂，气缸套破碎，碎片散落，断裂的连杆与曲轴、机体相撞，导致机体与曲轴损坏。

# 二 故障原因

根据检查发现，造成此次事故的主要原因是连杆断裂导致捣缸故障，根据轮机员反应，此台发电柴油机的操作完全是按照说明书技术规范要求，现场情况表明，油底壳有充足的油量，各个部件润滑良好，油底壳也没有铜末，轴承也无咬死现象；缸套与活塞表面光洁，无咬缸现象；增压器也没有发现损坏现象；从以上基本可以判断不是滑油质量以及润滑不良的原因。

从连杆断裂宏观断口外形分析，连杆断裂属于疲劳断裂。

连杆断裂部位仔细观察呈现放射条纹状，并向材料内部延伸，最后产生断裂，引起发电柴油机捣缸故障。

引起柴油机连杆断裂原因主要有以下几个方面：

（1）连杆螺栓上力矩不当，力矩过大会导致连杆螺栓超过屈服极限，产生屈服变形，在载荷的冲击下发生连杆断裂。

如果预紧力不够，柴油机运转过程中，连杆接合面产生缝隙，螺栓受冲击力作用会产生疲劳破坏而断裂。

（2）定期维护保养不到位，维修或者更换曲轴后紧固螺栓预紧力不到位，柴油机准装一定时间，预紧力螺栓松动，没有及时恢复。

（3）材料加工工艺以及热处理不当也会导致连杆断裂。

同时，活塞销质量差，长生裂纹，活塞销会窜出，导致连杆断裂。

（4）柴油机发生“飞车”事故以及活塞在气缸内发生烧死现象，会发生连杆断裂。

# 三 故障排除及预防对策

（1）为防止连杆螺栓断裂事故发生，连杆螺栓安装前必须认真检查，不符合要求及时换新，一般修复难度比较大、费用高，周期也较长。

如果换新，检查零件有无缺陷，用手锤敲打螺栓，听听声音，查看有无疲劳强度与缺陷，尤其是螺栓头部、螺纹与螺纹根部，有裂纹坚决不能使用，选用配套生产的连杆螺栓。

（2）螺帽、螺栓头部与轴承的接触面要完好，螺栓不能轴承孔中松动以及轴承空中有毛刺等，易使螺栓咬死；

螺栓与螺栓孔之间的配合间隙不能过紧，定位销不能松动，否则会发生磨损；

上紧连杆螺栓时要按照拆卸时的标记装复，不能装错；

装复时垫片与轴承表面要清洁，接触良好。

（3）如果柴油机在运转过程中发生螺栓断裂，将发生机毁的重大事故，因此必须按照说明书的要求上紧，如安装预紧力的大小、预紧方法、预紧次序等。

上紧连杆螺栓时要按照拆卸时的标记装复，不能装错；

装复时垫片与轴承表面要清洁，接触良好；

螺栓上紧要用扭力扳手，两边螺栓均匀交替上紧，不能单边紧固；

预紧力不能过大，否则会致使螺栓疲劳。

（4）检查连杆螺栓的伸长量，参考技术要求，如不符合要求，要及时换新，同时中型以下四冲程柴油机连杆螺栓的使用时间为 15000-20000 小时，如果超过使用寿命，即使表面无异状也要换新。

（5）采取螺栓防松措施，正确的固紧与锁紧是避免发生断裂的有效措施。

拧紧后的螺栓要有防松措施，科学的防松措施是依赖螺纹的自锁能力，因此在高速柴油机上采用细牙螺纹，减小导程角，使导程角远小于摩擦角，对螺纹部分镀铜，以增加螺纹间的贴合度及摩擦系数，提高防松效果。

目前在一些新产品中不采取任何防松措施，而是靠提高细牙螺纹的精度，确保预紧力来达到防松目的。

（6）经常检查柴油机日常工作状况柴油机运转过程中，如果发现异常情况，及时停车检查。

当螺杆出现松动或者被拉长，会出现较大的敲击声，立即停车，检查轴瓦，如果轴瓦间隙过大，更换连杆轴承或者加大轴瓦。

定期检查连杆螺栓的紧固情况，查明原因，检查螺栓损坏情况，使用扭矩扳手按照规定上紧。

# 四 结语

通过对 Sulzer6AL25/30 型号发电柴油机连杆断裂事故分析，笔者认为造成连杆断裂原因包括预紧力不均、螺纹表面不清洁、螺纹配合过松或过紧、柴油机发生拉缸或者咬缸事故等，连杆断裂极易引起捣缸和烧瓦，为防止此类事故发生，在操作以及装配过程中必须严格按照技术规范，确保柴油机安全。
