# 导读

连续发生两起主轴承烧瓦事故,引起某轮轮机员及船公司的高度重视。

于是,进行了一系列科学分析判断,找到了烧瓦原因之症结，并作出相应的整改措施，总结了日后对主轴承维护管理之要领，以避免事故的再次发生。

# 一、前言

某轮12300总吨、近20年船龄。

主机为8缸,四冲程柴油机,缸径440mm,冲程485mm,转速580r/min,功率5282kw。

该主机和变距桨搭配使用,并带动1台1520kVA的轴带发电机，用来拖动2台480 kw侧推器，供船舶靠离码头使用。

2004年，该轮在3个多月时间里连续发生两起主机烧瓦事故。

第一起发生在离港动车32分钟后,在前进三时,听到主机异常声,经查,发生主机NO.3缸烧瓦事故。

第二起发生在船舶正由锚地进港，动车十几分钟后主机尚未定速时,(这期间还间隔启动了两台侧推器)发生主机NO.2缸轴瓦烧瓦事故。

第一起事故发生后,对机油系统的油质、压力、油道,NO.3缸连杆大端轴承维护保养时间进行了检查,无发现问题。

在对损坏的轴承座孔进行检查、测量后,发现轴承座孔变形严重(也可能是烧瓦后引起的),为验证轴承座孔变形引起烧瓦的可能性，立即对相对运行时间较长的NO.7缸进行吊缸检查、测量,发现轴承座孔椭圆度达0.23mm，已大大超过0.03048mm的规定值，经分析认为此次机损原因可能是:

由于轴承座孔长期使用引起变形，使轴承间隙改变,润滑油膜难以形成,同时由于座孔变形造成瓦背不服贴、引起轴瓦散热不良最终导致烧瓦事故。

于是，利用停港时间对各缸进行吊缸检查,并测量连杆大端轴承及座孔,其技术数据如表1。

同时更换NO.7缸连杆大端轴承座孔和轴瓦(该机型连杆为上下组合装置)。

8个缸检查工作于7月29日全部结束。

然而,9月初又发生了第二起烧瓦事故。

# 二、造成事故的机理

## 1、启动侧推器对主机负荷的影响

如上所述，该轮配备艏艉侧推器各1台，每台额定功率600kw,额定电流1020A,额定电压415V,功率因素角为0.86。

该轮启动侧推器由轴带发电机供电,从轴带发电机功率表上看出，启动瞬间轴带发电机瞬时功率增加了1100kw。

增加的功率约占主机总功率的25%。

通过爆压表实测该轮单部侧推器在各种车令下的启动瞬时,主机每缸爆压增加1.3MPa,推算两部同时启动(从控制箱布置位置分析,同时启动有先后过程，正常情况下这先后过程约1~2秒),瞬时爆压将增至2.6MPa,以此计算出两部侧推器在各种车令下启动时气缸瞬时的最大爆压数据如表2。

由于侧推器启动的负荷是突加负荷，对主机的轴承瞬间冲击力很大。

从表中不难看到,如果两部侧推器同时启动,瞬时(约2秒内)增加2.6MPa爆压，将近23%持续功率下的爆压，如果在前进一车令以上启动,显然是不允许的。

## 2、主机机油质量的影响

### （1）机油质量分析

该轮主机机油换油记录如下:2003年11月14日换油1次;

2004年4月27日因机损换油1次;

2004年9月13因机损又换油1次。

查看该轮的机油化验每3个月1次,无不良记录。

但吊缸时检查连杆大端轴颈和轴承，各缸轴瓦均有拉痕存在,且各缸轴颈都比较粗糙。

经实船采取简易机油检查法,发现机油杂质多且脏,这也是在机油净油机几乎365天不停地工作情况下测得。

两次因机损,换油间隔都只有4个半月,为什么油还感觉这么脏?

到底原机油化验结论准不准?

于是，从9月份换下的存在“再生柜”中的油取油样，分送原化验机构和，上海高桥加德士润滑油有限公司化验。

化验的结论是:

该油中水份超标(2%),其它指标正常。

上海“润凯”化验单的结论是:

油中含有较多的正常磨粒、粘着磨粒、黑、红色氧化物及非金属污染物。

上海高桥加德士化验单的总结论是“船用机油已存在老化迹象，建议尽快换油”。

综合分析3份机油化验报告,可以认为:

第一,油品本身没什么问题。

第二，但该机油被污染严重(虽然仅使用4个半月)。

一是受海水污染，油中含水2%，含钠72rog/kg；

二是钒含量太高，13mg/kg，说明机油被窜入的燃料油燃烧产物所污染；

三是硅含量太高，12mg/kg,说明机油中含磨料成分太多。

### （2）机油污染途径

一是无十字头的简状主机,一旦燃烧不良，活塞密封不好,炭渣就进入曲拐箱的机油中,污染机油。

所以该轮不宜使用粘度较大的燃料油。

机油被海水污染，是由于该轮机油冷却器铜管曾有破裂引起的。

## 3、轴瓦寿命和使用情况的影响

目前各轴承厂家还没有明确规定轴承的使用时间,一般通过检查测量轴承间隙、查看瓦有无变形、损伤、龟裂,以及观察瓦面有无纵向贯穿的拉痕、曲柄转角60度以，上较严重的瓦面见铜等,如有,一般就要换新。

该轮1986年建造,2000年从国外购进后到2004年初,已把NO.1、NO.8缸的瓦换新，原NO.2.3.4.5.6.7缸的瓦未换,(第3缸机损后，换了NO.3.NO.7 缸)这6付瓦使用多长时间已查找不到记录。

从吊缸时检查瓦面的情况看，瓦面都有不同程度的见铜,且还有拉痕;

有的瓦局部有溶铅痕迹,说明瓦曾有过热熔磨损。

总体判断这些瓦的磨损量已接近使用极限。

检查NO.2轴颈和其它各道轴颈,表面都比较粗糙。

这是由于轴颈表面在长期使用中,磨料磨损或者腐蚀所致。

# 三、事故原因总结与整改措施

## 1、事故原因总结

从以上分析,第二起事故发生的原因已不难看出:

主要原因是第2缸轴瓦状况不好、轴颈表面粗糙,引起轴瓦烧熔。

事故发生时,柴油机处于启动、变速、停止的负荷变化过程中，同时,船要在静止状态下前进,此时油门拉杆在调速器的作用下拉动较大。

再加上启动侧推器，叠加的负荷影响，轴承承受着各种交变冲击负荷,轴承工况恶劣。

而此时轴承润滑有时是处于边界润滑状态，不能保持连续的液体润滑。

这种情况就会使轴和轴承间油膜瞬时间断或使油膜减薄到小于抵抗轴颈和轴承表面粗糙度之和,于是金属与金属直接接触,造成了轴瓦烧熔磨损。

轴瓦烧熔磨损严重时,轴瓦局部强度下降:烧熔部位向四周挤铅，瓦面不平,进一步破坏油膜的形成，导致该缸轴瓦烧熔。

其次机油中含有较多的正常磨粒、粘着磨粒、黑、红色氧化物及非金属污染物，这些磨粒与润滑油一起运动，造成了磨粒磨损,加快轴承合金非正常磨损,加速轴瓦的损坏。

即使这次动车初期没有烧瓦,也可能会在大风浪航行中，随着负荷的突加突卸变化增减油门造成烧瓦。

第一起事故的发生除了上述原因外，还与连杆座孔变形有关。

## 2、整改措施

主机机油已换新，更换了余下的NO.4.5.6.7四个缸的连杆大端瓦,结合吊缸周期，对各缸的气缸组件检查测量，磨损超限的予以换新，以提高各缸的气密,改善燃烧质量,恢复使用较好燃油，保证燃烧质量,恢复使用进口机油滤芯提高过滤效果,加强机油的净化及化验工作,保证机油品质及润滑效果。

启动侧推器时,应考虑到船龄及其它因素，安全的做法是在空车下逐台启动。

该主机今后的管理,要特别注意NO.2道烧瓦后轴颈手磨的质量,通过每3个月的轴瓦检查,如果轴瓦存在较严重的烧熔磨损，要考虑重新采用机械研磨修复轴颈。

每次吊缸或修船时，要注意各缸连杆大端轴颈存在着粗糙度、锥度和椭圆度的处理。

同时还要时刻跟踪主轴承运转情况,确保安全。

# 四、结论

通过对以上两起事故的分析，说明了：

(1)主轴瓦是柴油机的一个至关重要的零部件，也是最为薄弱的,对其管理维护马虎不得。

(2)不能单为了节省成本而盲目地改变船舶柴油机的燃油品质，特别是大龄船舶。

(3)事故的发生及分析处理过程对同类船舶在管理上有一定的借鉴价值。
