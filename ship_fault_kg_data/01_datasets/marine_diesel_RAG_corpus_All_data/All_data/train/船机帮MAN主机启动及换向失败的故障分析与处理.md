# 导读

船舶柴油机操作系统是控制主机启动、停止、换向、调速功能的系统。

在航行中，特别是在机动航行中，一但出现故障，如果处置不当就会导致船舶失控，酿成事故。

文章就一次备车中主机操纵系统出现的故障，详述了现象、排除过程，并对其产生的原因作了分析。

# 一、引言

二冲程低速柴油机以其长寿命、高功率的特点，在远洋船舶主推进动力装置中占据主导地位。

围绕二冲程柴油机的故障维修与管理方面的研究始终是轮机部门以及航运公司关注的重要技术问题。

MAN B&W 6S50MC 为笔者曾工作过的某远洋油轮主机，采用“电-气混合式”遥控操纵系统，用来实现驾驶台或集控室远距离操纵或机旁应急操纵。

气动系统完成主机的换向和启动的执行，电信号完成遥控信号的传递、调速和程序控制。

本文以该主机启动、换向系统的故障现象入手，详细分析了原因并介绍了处理过程。

# 二、故障现象

在中东地区某港锚地接到进港指令后，轮机部顺利备车，在控制室和驾驶台正倒车实验均正常。

起锚过程中，驾驶台操作主机时，正车启动失败，随即短促倒车运行，再要正车时，主机不能换向。

立即转到机舱控制室控制，倒车可以启动，但仍旧不能换向；

转到机侧控制进行测试，依然是正车无法换向，倒车有时不能启动。

# 三、故障查找及排除

在测试过程中，安排一名轮机员在飞轮侧观察发现：

每当 3 #缸在上止点前位置时，就会发生倒车启动失败。打开示功阀，倒车盘车 60°脱开盘车机后，倒车启动成功；

正车换向一直失败。

判断为 3#缸启动阀不能正常开启，立即安排人员准备对 3#缸启动阀进行更换。

在机侧操作主机时，可以听到换向阀 10#、11#阀组有较大的气流泄放噪音。

随后安排两组进行排查，一组对 3#缸启动阀进行更换，这一组进行的比较顺利，对拆除的启动阀进行功能试验时发现启动阀在有控制信号时也不能开启，解体后发现阀盘过度磨损导致卡死；

另一组对换向控制阀组进行解体。

图1 换向控制阀

解体后发现，10#阀阀芯密封圈已经严重老化，中间一道已经缺失。必须对密封圈进行更新或整体换新，但在船上未能找到阀件的备件及修理包。

情况紧急，只能采取其他措施。

观察发现，该密封圈的工作压力为 0.7MPa，其结构特殊：

大多数密封圈截面为圆形，该密封圈截面偏平，厚度只有 2mm，并且压入量较小，普通密封圈无法代替。

船上的密封圈修理箱中也没有相应尺寸的密封圈进行粘结制作。

后大家讨论：

是否可以对内外径尺寸相近的密封圈进行加工，使其变薄以满足尺寸要求，可以采用在砂纸上研磨，先用粗砂快速消除几何形状误差、切去加工余量，使用细砂纸获得精确的尺寸和表面粗糙度。

依法炮制、安装后对主机进行测试，一切正常，完全满足使用要求。

在向公司报告的同时，应急申请一套操纵系统阀件的修理包，随后对整个系统进行的检修，排除故障隐患。

# 四、原因分析

主机 3#气缸启动阀卡死，导致该缸在膨胀行程位置时启动空气无法进入气缸，启动失败。

气缸启动阀为单气路控制式，这种阀结构简单，但是阀盘在关闭时落座速度快，致使阀盘和阀座撞击严重，磨损速度快，易出现故障，如过度磨损、卡死等；

平衡活塞受来自空气分配器的空气控制，在气源不洁，含有水、杂质时易发生锈蚀、卡死等故障。

如图2，原来在倒车运行，现需要正车换向，不论该指令在机侧通过手动换向阀 105#，还是控制室换向车钟 70，驾驶台发出指令使电磁阀 86#（未示出）受控，空气信号都经过多路选择阀 29#使两位三通 10#阀受控并使其导通，控制信号通过 10#阀后分两路：

一路到各个高压油泵的换向气缸，进行喷油定时的换向；

另一路通过 14#阀（防止空气分配器误动作的控制阀，有启动指令时受控导通）到达空气分配器的换向气缸 57，进行空气分配器的换向。

在测试过程中，在三个操作部位测试结果一致，故障的原因集中在三者的共同点 10#阀上，幸运的是 10#阀外观异常（噪音），为故障查找提供了明确信息。

两位三通阀 10#在中间密封圈缺失的情况下，会导致控制空气自此处溢出而不能进入到阀后的气路中，导致高压油泵和空气分配器无法换向。

# 五、几点建议

1）加强对空气系统的管理，定期对启动阀进行保养，避免超期服役导致工作异常；

2）加强船舶备件管理，记录和实际数量要统一，实际存放位置和记录一致，控制系统各阀件除定期保养外，还要有备件在船，至少也应有修理包在船；

3）要加强业务学习，使自己掌握的知识与技术不断更新，每条船都有自己的特点，接船后要迅速熟悉并掌握，出现问题时才能快速的发现并排除故障。
