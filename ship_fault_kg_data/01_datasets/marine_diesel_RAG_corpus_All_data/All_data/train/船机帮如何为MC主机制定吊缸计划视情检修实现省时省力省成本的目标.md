# 导读

根据MAN公司SL2007－484/HRR通函，新型MC、ME型主机已采用一系列新技术设计，主机燃烧室部件有效使用寿命和可靠性已大大提高，并根据多年的工作经验，活塞吊缸检修周期原设定为12000－16000小时（有些说明书推荐8000小时）相对太保守，通过必要的监控手段对活塞进行视情维修，检修间隔延长至32000小时是可能的。

# 一、决定活塞吊缸检修的关键因素

①活塞环的磨损量到极限。

②活塞顶烧蚀量到极限。

③活塞环槽天地间隙超标。

④活塞环熔着（拉缸）、断裂、密封失效。

⑤缸套熔着（拉缸）、磨损超标、裂纹需要修复或换新。

# 二、新技术改进和可监控性决定主机活塞视情吊缸检修的可行性

## 1、新型燃烧室上移式气缸盖

气缸盖高度加大，使缸盖与缸套接触面下移，再加长活塞头长度，燃烧室基本都在缸盖和活塞头组成的空腔内部，缸盖和活塞头材质采用S17MoS高强度耐热合金钢，而且缸盖和活塞头基本没有机械磨，使用寿命较长。

缸盖与缸套接触面的下移，降低了缸套上部承受的机械应力和热应力，与改进前相比，缸套顶部承受的燃气温度下降约100℃，压力下降约20－30bar，而且保护了气缸润滑油膜，减少缸套、活塞环、活塞环槽的磨损和腐蚀。

## 2、新型高顶活塞

即第一道环以上的活塞顶部分加高，将“活塞环带”区域下移使其远离燃烧室，避免承受高温高压燃气的冲击，并有效保护了气缸润滑油膜，减少缸套、活塞环、活塞环槽的磨损和腐蚀。

活塞头允许最大烧蚀量16mm，有效使用寿命在100000小时以上。

活塞头、活塞环槽的烧蚀、磨损程度可以通过扫气口检查和测量。

## 3、新型活塞环

第1道活塞环因承受高温、高压燃气，尤其是活塞环搭口间隙处热负荷最大，新型的第1道活塞环不同于传统的如第2、3、4道活塞环的特点：

①采用重叠式搭口，可有效补偿活塞环磨损量而且保证搭口处密封不会产生燃气泄漏。

②采用CPR活塞环，周围有3道深度为3mm的斜向CL泄压槽可以防止活塞环局部表面压力过高而产生过度变形或断裂，泄压槽的深度可通过扫气口测量，其直接反映出活塞环的径向磨损量，是决定活塞环是否需要换新的重要依据。

③活塞环径向厚度增加至16mm（第2、3、4道活塞环厚度12mm），有效使用寿命长。

④径向外表面镀有0.5mm硬质耐磨合金层使活塞环寿命更长。

第2、3、4道活塞环由于承受高温高压的燃气较少且润滑较好磨损量都大大小于第1道活塞环，使用寿命都较长。

每道活塞环外圆面都有0.1mm氧化铝涂层，形成类似砂纸的粗糙面有利于在新环使用时润滑油的贮存，防止在新环磨合期发生“拉缸”现象，但新活塞环的使用在磨合期间会加速缸套的磨损。

## 4、新型扫气阀采用新型W形排气阀座、Nimonic排气阀

W形排气阀座与排气阀有3个接触面形成2个环形气腔，在压缩扫气行程中2个环形气腔都充注了低温扫气空气，阻止高温高压燃气进入上部2道环密封面从而降低了排气阀及阀座的温度，有效保护了上部2道密封面免受高温燃气的腐蚀和磨损，上部2道接触面较窄类似刀刃，既利于密封和散热，又能比较彻底地清除排气阀上的结碳。

最下部一道密封面承受高温高压燃气，采用非接触式有0.8-1.0mm间隙，一般不会有磨损。

Nimonic排气阀使用特殊材料，提高了耐高温和耐腐蚀性能。

因此，排气阀座、排气阀的有效使用寿命较长，检修周期与主机吊缸周期一致，可延长至24000~32000小时，若吊缸检查时发现排气阀座、排气阀只有少量麻点一般不必用磨阀机研磨，清洁后可继续安全使用。

## 5、活塞清洁环

活塞清洁环也可称为刮碳环，装在缸套最上端与缸盖之间，其内径比缸套内径小但比活塞头大，活塞头通过清洁环部位时，活塞顶部外圆的积碳被清洁环刮除，活塞顶部积炭少就不会与缸套发生磨擦，也不会破坏缸套表面润滑油膜，有效保护了缸套。

## 6、缸套的有效使用寿命

按磨损量来计算，在150000小时以上，按目前中海76000载重吨油轮主机每年运行约5000小时，全寿命期（25年）主机运行最多125000小时，理论上主机缸套在正常运行情况下25年都不需要换新，每次吊缸需要测量缸套的直径并进行跟踪监控，一般不需做任何维修，如果频繁换新活塞环会在磨合期内加速缸套磨损从而缩短使用寿命，缸套的表面情况可以通过扫气口检查，死角部分可通过数码相机拍照检查分析。

# 三、主机活塞视情吊缸检修的目的

①延长吊缸周期，减少吊缸次数。

②节省备件费、维修费用。

③减少船员工作量。

④减少缸套因换新活塞环后在磨合期间额外的磨损，延长缸套有效安全使用寿命。

⑤获得主机最大安全运行小时数。

# 四、主机视情吊缸检修要求

船舶轮机长为MC/MC-C型主机视情吊缸检修的负责人，必须熟悉主机设计生产商的通函和相关要求，熟悉公司船舶主机视情吊缸检修程序及检查要求，完成必要的对主机跟踪检查、测量。

轮机长必须做到对视情吊缸检修整个工作审慎、负责，通过主机扫气箱对活塞、缸套等进行检查、测量、拍照，确认目前状况正常无需吊缸检修，填写《船舶主机视情吊缸检修申请表》报告公司机务主管，每次最高延长1500小时，到期后通过检查、测量，重新申请，每缸累计最长运行时间为32000小时。

船舶管理部门为船舶实施MC/MC-C型主机视情吊缸检修的管理部门，机务主管必须熟悉MAN公司有关MC/MC-C型主机视情吊缸检修的相关要求，负责对船舶轮机长及大管轮进行视情吊缸检修相关操作要求的培训，提供必要的检查、测量工具。

机务主管收到船舶《船舶主机视情吊缸检修申请表》后，必须审核船舶对主机的检查情况，对有怀疑船舶，还应上船亲自检查，确认正常后，批准船舶可延长吊缸检修，发回《船舶主机视情吊缸检修申请表》并在PMS系统中对主机吊缸相关项目检修周期进行修改并作批注。

# 五、实船调查分析

中海油运76000载重吨鲸鱼座轮在运行12000小时后第一次进行常规吊缸2个检查，测量第一道活塞环的泄压槽深度为2.70mm（新环为3.0mm，极限为1.3mm），相对径向宽度为19.9mm（新环为20.2mm，极限为17.2mm），磨损量为0.025mm/千小时，预测第一道活塞环使用极限寿命将超过60000小时，其它指标如活塞环槽、活塞顶、缸套磨损/烧蚀量小到几乎可以忽略不计。

根据第一次吊缸检查情况，对其余4个缸进行跟踪监控进行视情吊缸检修，目前已运行超过18000小时未吊缸检修，从扫气口测量到第一道活塞环泄压槽平均深度为2.68mm，其余各种状态也处于完好状态，以此推算可延长至32000小时吊缸检修是完全可行的。

影响主机活塞、缸套组件磨损的因素很多，是否需要吊缸检修需要进行科学监控和实际情况而定，新技术的应用使燃烧室部件寿命有效延长和活塞、缸套组件可监控性为视情吊缸检修成为可能，但轮机管理人员通过有效的科学监控手段、规范日常管理和维护保养才是保证主机安全运行的关键环节。
