# 导读

注意：具体的柴油机性能要求，请参见有关产品的《柴油机平台跑合，调试大纲》及专利商(MAN B&W、SULZER)提供的有关技术文件或技术要求，本文仅对柴油机性能作判断时要考虑的因素作出提醒，及强调一些必须遵守的操作规范和要求。

# 一 负荷正确性是调整和判断柴油机性能的基础

在每个装置号的首台柴油机性能调试中，柴油机负荷和转速的准确与否是至关重要的，只有在正确的转速和负荷工况下，才能对增压器的配机作出正确的抉择，才能保证性能参数的准确和排放测试的准确，才能保证后续机调整的顺利进行。

判断柴油机负荷和转速的准确性，可通过校验水力测功器，或利用PMI设备，以及对增压器转速和油耗等进行判断。

# 二 爆压(Pmax)和扫气压力(Ps)调整

柴油机在跑合调整过程中，首先应根据专利商(MAN-B&W和SULZER)提供的性能曲线，将爆压(Pmax)调整到要求值，然后对增压器转速和主机扫气压力(Ps)作出评估，判断增压器配机正确与否或决定更换配机元件。

在ISO工况下，爆压调整公差为±3bar，同时应注意实测最大爆压与设计值不要超过6bar，扫气压力(Ps)的调整公差为±0.1bar。

在25%，50%等负荷工况下，爆压值与性能曲线所要求的值的差值可能会超过3bar,在排除调整因素后，这种超差是允许的。

# 三 压缩压力(Pc)调整

压缩压力(Pc)受扫气压力和存气高度的影响，扫气压力和存气高度越高，压缩压力(Pc)就高。

压缩压力(Pc)的控制原则为：

在ISO条件下，任何负荷下的Pmax - Pc ≤ 35bar。

例如，在90%负荷时，爆压(Pmax)的设计值为150bar，则压缩压力(Pc)不能低于115bar。

各缸之间压缩压力最大差值不超过3bar,在扫气压力满足设计要求的情况下，主要通过调整存气垫片厚度(仅对同一装置号的首台机)，或调整排气阀缓冲活塞的桥规值高度来调整压缩压力。

根据经验，存气垫片厚度每增加1mm，压缩压力相应增加1.2~1.3bar;桥规值每增加1mm，压缩压力(Pc)相应增加3bar左右。

这里要强调的是：

一般情况下，存气垫片增加的厚度以3~5mm为宜，最大不能超过8mm，并要检查存气垫片总高度是否超过该机型图纸允许的存气垫片的最大值，超过最大值会产生机械事故;桥规值控制在47~51.2mm之内。

# 四 增压器转速（Nt/c）的校验

对首台机，增压器转速的测量应使用频率仪，并认真比较增压器转速与设计值的差距。

一般来讲，理论值和测量值的修正值之间差值应≤200r/min,超过的话，应认真分析并对测速系统进行检查和校验，再对这种现象进行判断和认可。

对后续机，同一台批机的增压器转速偏差应≤200r/min。

# 六 排气温度的要求

排气阀后的各缸排气温度应控制在320℃-390℃这个范围内(在ISO条件下)，对新机而言，各缸排气温度偏差应≤30℃。

排气温度过低时，要考虑测量是否正确，要检查温度表、保护套和安装位置。

# 七 增压器前排气温度和增压器后排气温度的要求和增压器效率

增压器前后的排气温度和扫气压力反映了增压器的效率，增压器效率影响到油耗这个考核指标值。

增压器前排气温度应控制在380℃~430℃这个范围内，增压器后排气温度220℃~300℃这个范围内。

这里要强调，对高效增压器，增压器后排气温度一般低于250℃，在低负荷时(40~50%)，若温度超过260℃ (修正到ISO条件下)，应引起足够重视。

S46机(含S46)以下，增压器效率64%，50机(含50机)以上，高效增压器的效率，为68%;常规增压器的效率为64%。

# 八 背压和空冷器压降

一般情况下，增压器后排气背压应≤300mmH₂O，柴油机在平台调试时，增压器排气背压应≤270mmH₂O左右(100%负荷)。

扫气空气经过空冷器的压降应≤240mmH₂O，若超过规定值，应检查原因，并与造机所联系空冷器计算书是否正确。

# 九 VIT齿条格数、燃油泵垫片数和燃油泵齿条格数的调整要求

若柴油机配有可变燃油正时系统(VIT)或燃油泵正时用垫片调整时，在调整爆压时，应考虑爆压齿条格数或燃油泵调整垫片的规定值。

对带VIT机构的柴油机，转折点的VIT齿条格数应兼顾到低负荷和超负荷(110%)，即在任何负荷下，VIT机构均能起作用。

一般来说，转折点时的VIT设定空气压力在4~4.5bar为最佳，不能低于3.5bar,若低于3.5bar，说明VIT机构的静态调整和燃油凸轮的正时调整没组合好;

转折点时的VIT齿条格数以5.5~6.5大格为最佳，当然这还要和VIT齿条最大的格数结合起来考虑。

对不带VIT机构的柴油机，在调整油泵垫片数时，应按照图纸要求进行调整，一般情况下，S42MC图纸规定垫片数为6张，S60MCC图纸规定垫片数为9张，并要求做到规定值±1张。

这里要提醒的是，对垫片数较低的柴油机，如S42MC机规定垫片数为6张，则尽量不要低于规定值，可考虑6~8张这个范围。

# 十 增压器进/出口滑油温度的要求

对采用滑动轴承的增压器，一般利用柴油机系统滑油润滑，或采用独立的滑油系统。

增压器滑油进口温度应控制在40℃~50℃，不能超过55℃(为报警值)。

增压器滑油出口温度一般为70℃~85℃。MAN增压器滑油出口温度报警值95℃，MET增压器滑油出口温度报警值85℃。

# 十一 其他

1. 柴油机系统滑油压力和温度，应按各种机型的要求，调整到正常范围之内，活塞冷却油出口和推力轴承温度要经常观察记录。

2. 缸套冷却水出口温度和压力要经常观察记录，控制在正常范围之内，以免冷却水气化。

在负荷超过50%时，缸套冷却水出口温度应在80~85℃，如果不能满足要求，必须在低于50%负荷的情况下磨合，在温度满足要求后，再升负荷。

另外，缸套冷却水的出口温度与进口温度的差值应≤15℃。

3. 燃油压力的调整，首先调整主机燃油系统的背压阀，其调整要求为：

背压阀调整螺栓的螺纹露出其锁紧螺帽1~2牙。在调整好背压阀的情况下，如果燃油压力还是不能满足主机要求，再调整燃油增压泵的旁通阀，使压力处在正常范围之内;

4. 另外，必须检查各缸油头回油管和油泵燃油回油管的单向阀(带VIT机构的油泵没有该阀)，检查其方向是否正确。否则，会导致某些缸不发火，或者引起很强的脉冲。
