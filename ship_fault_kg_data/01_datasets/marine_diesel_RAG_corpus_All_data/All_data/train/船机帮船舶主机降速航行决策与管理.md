# 导读

因航运市场低迷，同时主机排放控制日趋严厉，故船舶燃油成本不断上升。

为节省燃油费用，船舶承租人通常要求主机降速航行，但降速航行必然导致航行时间增加，租金成本提高，因此必须找到燃油费用与租金的平衡点。

笔者某航次接到船舶承租人的指令：在不改变技术参数的前提下，找出主机降速航行的最佳转速，供决策参考。

# 一、主机降速航行最佳转速的决策

查阅相关文献，笔者发现大部分资料均提及船舶经济航速的算法及其考虑因素；查阅主机说明书，也能得到主机油耗与转速之间的关系。

船舶在实际运营中主机状况和船舶状况均发生改变，因此这些计算数据不一定准确。

为确定主机降速航行时的最佳转速，笔者进行一系列测试。

## 1、测试数据

本船主机为 MAN B＆W 6S60MC 低速柴油机，使用 IFO 380 燃油，最大持续运转转速( MCＲ) 为 89r/min，功率为10316 kW，常用持续运转转速(NCＲ) 为 82.6 r/min。

测试航程取Hay Point到Singapore，距离为3937 n mile，船舶状况为满载73000t，平均吃水13.8m，海况良好。

本船最后1次坞修出厂至今约 1.5 a。

主机转速从 68.5 r/min到 82.4 r/min，每隔 2 r/min 运行 1 h 进行测试，得到数据见表1。

## 2、效益分析

## 3、可行性

查阅主机说明书可知，主机转速为 72.3 r/min时，工作负荷为额定负荷的 48% 。

若主机长期在此负荷下运行，则运行期间必须保证辅助鼓风机不启动，否则易导致电网产生冲击载荷、缩短辅助鼓风机的工作寿命。

另外，必须保证废气锅炉的蒸汽压力足够大，使得燃油锅炉不启动，否则将导致额外的燃油消耗。

根据测试，当主机转速为72.3 r/min 时，增压器转速为 9100 r/min，扫气压力为 0.088 MPa，辅助鼓风机的压力设定在 0.043 MPa 启动、0.062MPa停止，可保证辅助鼓风机不启动; 废气锅炉蒸汽压力保持在 0.5 MPa 运行，燃油锅炉不启动。

因此，主机转速设置为 72.3 r/min，可行。

# 二、主机长期低负荷导致的问题

(1) 气缸润滑。

主机长期低负荷运行时必须考虑气缸润滑问题。

一种观点认为主机转速降低，必然使润滑效果变差，应增大气缸油供油量以保证必要的润滑; 而另一种观点认为降速，在燃油的硫质量分数一定的情况下进入气缸的硫总量会降低，应减少气缸油消耗量。

这 2 种观点有待进一步分析。

(2) 积炭严重。

主机长期低负荷运行，燃烧恶化，必然导致燃烧室、排气阀、增压器、锅炉等处积炭严重，特别是排气阀和锅炉的积炭会导致主机工况恶化。

(3) 蒸汽压力。

主机长期低负荷运行，必然导致废气锅炉的蒸汽压力降低，正常航行时通常燃烧重油，必须有足够多的蒸汽。

如果蒸汽压力低于设定值，那么会导致燃油锅炉运行，增加额外油耗。

(4) 辅助鼓风机。

主机转速降低，必然使增压器转速降低，导致扫气压力降低。

当扫气压力低于设定值时，辅助鼓风机将会断续运行，导致发电机负荷增加，并在启动瞬间对电网产生冲击载荷，严重时会导致全船失电。

扫气压力低，还会使燃烧恶化。

# 三、主机长期低负荷的对策

## 1、调节气缸油注油率

(1) 气缸油注油率的基本设定值。本船采用Jensen 机械式注油器，根据主机厂商的说明，在MCＲ时设定的注油率为

Q  MCＲ  = 24B  S  P  MCＲ  /( 1000Cρ) ( 2)

式中:

Q  MCＲ  为设定的注油率，L /d;

B  S  为基本设定值，根据船舶所有人的指示设为 1.1 g /( kW·h) ;

P  MCＲ  为 MCＲ 时的输出功率，当主机转速为 89.0 r/min时功率为 10316 kW;

C 为气缸数量，本船为 6 缸;

ρ为气缸油密度，本船采用 BN 70 气缸油，15 ℃ 时密度约为 0.9343kg /L。

根据计算，注油率 Q  MCＲ  = 48.6 L /d。

(2) 随主机转速改变的注油率。

保持基本设定值不变，气缸油注油率会随主机转速下降而成比例下降，计算公式为

Q  部分  = Q  MCＲ   n   部分  /n  MCＲ  (3)

如果主机转速设定为 72.3 r/min，那么气缸油注油率 Q  72.3  = 39.5 L /d，每天的气缸油消耗量为Q  D  =6Q  72.3  = 236.8 L /d，与实际测定值相符。

(3) 随负荷改变的注油率调整。

目前，部分MAN B＆W 型主机装设随 MEP( 平均有效压力) 调节的气缸油注油器系统，气缸油注油率在 40%～100% MEP 范围内成比例调整。

如果主机没有装设该系统，那么可以手动调节注油率。

根据 MEP 调节的注油率计算公式为

Q  部分  = Q  MCＲ  P  部分  /P  MCＲ  (4)

式中:

P  部分  为部分负荷时的平均有效压力，根据测试，在主机转速为 72.3 r/min 时为 10.7 MPa;

P  MCＲ  为在 MCＲ 时的平均有效压力，根据测试，其值为17.9 MPa。

根据 MEP 调节法，主机转速为72.3 r/min 时，气缸油消耗量 Q  D  为 174.6L /d，即气缸油消耗量可从 236.8L /d 调整到174.6 L /d，但不能低于基本设定值的40% (19.4 L /d) 。

实际上，船上采用较保守的做法，将气缸油消耗量从 240 L /d 调整为 200 L /d。

到港后，根据扫气口检查情况，该注油率仍较大，还可以适当调小。

显然，对减少船舶的运行费用有利。

## 2、减少积炭

为减少积炭，防止燃烧室腐蚀，保证良好燃烧，扫气温度尽量提高至 41～43 ℃ ;

缸套冷却水温度取高限 82～83 ℃ ( 85℃ 报警) ，有利于燃烧和减少腐蚀;

缩短排气阀、喷油器的保养周期，特别是喷油器在低速运行时雾化效果差，必须勤保养以保证良好的燃烧;

主机每天 2 次加速到 82 r/min 运行 1h，以便清洁排气通道的积灰;

主机加速时，加强废气锅炉的吹灰;

同时对增压器废气端干洗，压气端水洗，减少增压器的积炭、积灰。

## 3、控制蒸汽消耗量

控制蒸汽消耗量，关闭无需加热的设备蒸汽管，包括部分燃油管路的伴行蒸汽管;

尽量关小油舱加热阀，保证主、副机燃油系统加热的需求，避免燃油锅炉的启动。

## 4、控制最低扫气压力

控制主机的最低负荷，特别是在轻载情况下，不要让扫气压力低于辅助鼓风机的启动设定值。

必要时可将辅助鼓风机置于手动控制模式，或者调低辅助鼓风机的启动设定值，但可能导致不完全燃烧，应密切关注排气情况。加强辅助鼓风机的日常检测和保养工作。

# 四、结束语

在主机低负荷运行时，要想获得最佳工况，还可以调整压缩比、喷油提前角等，但实际营运船舶不能随意调整主机参数，船舶所有人也不愿意主机长时间低负荷运转。

事实上，在征得船舶所有人同意后，本船从该航次起执行 72 r/min 的经济转速，几个航次的运营结果显示，船舶各运行参数都保持在良好状况。
