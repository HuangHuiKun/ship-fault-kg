# 导读

船舶柴油机作为船舶推进系统的主要动力源，确保其安装质量是保证船舶正常运营的关键因素。

本文主要介绍和分析环氧浇注前 / 后柴油机（整机安装）的安装校中工作。

# 一、柴油机安装校中的准备工作

（1）了解并掌握柴油机安装的所有设计图样及产品安装使用说明书等技术文件，必须按技术文件要求进行安装；

（2）检查柴油机外观是否有缺陷，并检查管路管口、螺纹接头、道门及其他平面连接处的清洁和防锈封堵状态是否合格；

（3）检查所有安装和测量工具等是否齐全。

# 二、柴油机的安装

## 1、整机安装形式

（1）柴油机不带校中螺栓安装

将柴油机放置在硬木块上，木块的摆放按机座轴承支撑的位置进行；木块的高度应调整平直尽可能接近最后的垂直位置，既不扭曲也不下垂；柴油机落座后，应在每处油缸中心线和机座的两端处放置调整楔铁并将木块移走，在机座侧板下面的垂直处（或略带倾斜）放置楔铁，避免机座下平面面板弯曲。

（2）柴油机带有调整螺栓安装

调整四角中的三个校中螺栓到计算好的距离（或50mm），其余的螺栓调短1mm；在落座期间，在柴油机仍被吊车悬吊大约一半的重量时，将其余的校中螺栓用手把紧。

由此，柴油机在大多数情况下以初步的下垂被吊起，但由所有校中螺栓支撑其重量。

## 2、船上安装

将机座落下，校中机座成直线（没有下垂）并检查扭曲情况；随后，根据柴油机制造厂提供的装配图纸吊装所有部件，把紧所有螺栓；最后，在校中前侧推块和端部止推块应焊接结束。

## 3、链条涨紧

在最后校中期间，必须根据柴油机维修说明书中的要求将链条涨紧。

然而，对于较小的 MC 及 MC-C型柴油机而言，主链条会将曲轴拉向一侧，因此在某些情况下，对低于50MC-C机型的柴油机，在校中期间松开链条可能会更好些。

## 4、扭曲测量

（1）当柴油机整机安装时，推荐在最后校中前于干船坞内测量柴油机的扭曲；

（2）当柴油机以分解的状态交付时，推荐在机架落座前于干船坞内在曲轴已安装就位的情况下检查机座的扭曲；

（3）在正常情况下，扭曲检查是在主机机座上平面凸轮轴侧、在NO.1 缸和最后1缸之间进行，测量必须在下水之前进行，船舶下水后该测量工作很难进行；当柴油机在下水后于漂浮中的船上安装时，在柴油机落座在其基座之前，必须注意临时支撑应调平成低于其限制范围；检查扭曲后，测量并记录机座下平面与机座面板之间的距离，以确保在之后的对中调整时能够平行升、降主机。

## 5、安装程序

（1）在主机机座上平面凸轮轴侧，测量 NO.1 缸和最后 1 缸的倾斜度偏差值；

（2）两缸结果的最大差值，允许为0.1 mm/1000 mm。

# 三、柴油机的初步校中

开始校中前，柴油机周围的所有主要焊接工作必须结束，根据主机厂家提供的《推进轴系校中计算书》，进行柴油机与中间轴的校中工作。

（1）检查飞轮（曲轴）与中间轴之间的开口和偏移，并在机座上平面安装钢琴线；为获得令人满意的机座挠度，需要将机座支撑只安装在机座四角，尤其是小缸径和较短的柴油机（如MAN主机S26-K/LS50MC/C型及 5-6-7 缸机）。

但必须注意，仅在校中期间才允许将柴油机四角支撑，在环氧浇注期间柴油机所有缸的下面的支撑必须全部受力。

（2）检查机座挠度：通常选用激光设备检验和钢琴线两种检验方法。

# 四、柴油机与中间轴的连接

当中间轴与主机飞轮连接法兰间的开口和偏移以及主机机座的挠度满足要求后，连接飞轮和中间轴，安装后把紧铰制螺栓。

在多数情况下，由于负扭矩对曲轴的作用，通常需根据经验在连接中间轴与主机飞轮时调好预定的开口，以避免中间轴连接完成后再对柴油机进行调整。

# 五、曲轴拐档差的检查

在服务工况（船舶装载、柴油机热态）下，拐档差值应尽可能接近于零。

由于最后1缸的拐档差受轴安装的影响，故中间轴与飞轮连接后应测量最后1缸的拐档差，并与表1中的数据进行对比，根据经验对主机前端（后端）或左右进行调整，使其拐档差满足目标值，或者调整中间轴承以获得更理想的结果。

根据相同机型、相同船型的经验，也可以对依据连轴前的法兰开口和偏移以及连轴后的最后1缸拐档差的目标值进行调整。

对所有缸的拐档差的最后检查，只能在环氧浇注前进行。

如果主机前端安装有重调频轮，则 NO.1 缸的拐档差允许有较大的范围值。

测量拐档差读数时，应将指针式千分表放置于冲孔标记处，该处距曲轴中心（R+0.05D-10）mm。

对于大多数柴油机尾机船型而言，船舶装载后由于船体变形的影响，所测量的最后1缸曲轴臂的臂距差读数会减小。

因此，通常推荐将柴油机最后1缸的拐档差调整成零到通常最大值之间。

# 六、轴颈轴承顶部间隙的检查

测量最后一个柴油机主轴承的顶部间隙时，由于空间限制，因此只测量该主轴承前端的间隙。

与台架试验时测量的间隙对比，顶部间隙值通常要小0.05mm 左右。

在特殊情况（如在码头校中状态）下，顶部间隙小0.20mm 是可以接受的；但在服务工况（装载或满吃水）下，所在主轴承的顶部间隙不允许有严重的减小，其中用塞尺测量时，其测量精度不会高于0.05~0.1mm。

# 七、轴承负荷的检查

## 1、准备工作

将柴油机轴承顶起之前，应先检查下列工作：

① 柴油机最后两个轴承的顶部和底部间隙是否测量确认, 如果塞尺能够测量到底部间隙，务必准确地测量出该值；

② 最后1缸曲轴臂拐挡差值；

③ 温度测量：推力轴承温度、缸套水温度（冷却端）、海水温度、环境温度、主机滑油循环舱的温度；

④ 船舶首部和尾部的吃水；

⑤ 推荐使用MAN提供的电子测量记录表格，使用手机或电脑直接输入现场数据，并对数据进行整理及判断。

## 2、负荷测量

由于液压拉伸器的活塞与油缸之间存在摩擦力，因此在相同压力下顶起区间的负荷要比下降区间的负荷大，实际负荷可取顶起区间和下降区间平均值。

由于存在着滞后现象，必须确保在顶起期间测量时压力稳定地增加，下降期间测量时压力稳定地减少。

通过液压拉伸器，使轴顶起直到轴承顶部间隙为零，记录油压每上升10bar～40bar时的顶升压力和相应的顶升量；接着油泵缓慢降压，记录油压每下降10bar～40 bar时的压力和相应的下降量，作出压力与轴垂直位移曲线（按 MAN 提供的 EXCEL 软件，直接对数据进行处理）。

## 3、负荷判断

① 对于尾管轴承和中间轴承，第1个拐点一般会出现在顶起0.05mm和0.25mm之间，其大小随拉伸器与轴承中心之间的距离而定；

② 对于柴油机主轴承，第1个拐点会出现在顶起0.03mm和0.10mm 之间；如果拐点出现在顶起0.15mm以后，则可以确定所测量的轴承上负荷为零；

③ 对于柴油机最后1个主轴承，第1个拐点通常出现在顶起的0.03mm和0.15mm之间。

如果第1个拐点出现在顶起0.25mm以后，则可以确定柴油机倒数第2个轴承已经被顶起，柴油机最后一个轴承上负荷为零，因此需重新进行柴油机的调整，并重新建立起负荷。

以上判断方法的精确度很大程度上取决于环境、数据和设备的质量，以及操作者的经验。

通常，负荷越大，精确度就越高。

对于重负荷来说，精确度可达到±15%，这对于大多数用途来说已经足够了。

由上所述，所有柴油机负荷必须按照柴油机厂家所提供的《推进轴系校中计算书》进行。

一般来说，柴油机主轴承的最小静态负荷是最大静态负荷的 5%，最后一个主轴承的最小静态负荷为零。

此外，在主机校中时应将最后一个主轴承负荷调整到比柴油机倒数第二个主轴承负荷低一点。

在检查柴油机轴承负荷的同时，应检查尾管前轴承和中间轴承。

此外，在相同的柴油机 / 船舶的工况下，应在大约相同的时间检查曲轴拐档差和机座下垂（用钢琴线检查）。

如果中间轴承负荷超出了规范要求，有必要抬高或降低柴油机；如果柴油机最后一道轴承的负荷太高，应调整柴油机前端（或后端），直到所有轴承的负荷满足要求。

# 十、小结

船舶柴油机作为船舶主推进系统的重要组成部分，其安装质量制约船舶运行状态，要求安装人员具有较强的柴油机安装 / 校中的专业知识，并严格按施工工艺施工，保证船舶柴油机正常调试运行。
