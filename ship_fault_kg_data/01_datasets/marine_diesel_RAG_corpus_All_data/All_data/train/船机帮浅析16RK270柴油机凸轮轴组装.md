# 导读

16RK270凸轮轴组装分A、B两侧，分别安装在机体的两侧，凸轮轴组装所需的零部件包括五部分：

凸轮轴一种共16节，A、B侧各8节，轴承段五种共18个，A、B侧各9个，轴承座组装五种18个，A、B侧各9个，还包括卡圈一种2个和连接用的螺栓一种共512个。

16RK270柴油机凸轮轴与240柴油机凸轮轴区别于16RK270柴油机凸轮轴与我们以前的240柴油机凸轮轴在结构上就不一样，240凸轮轴组装的时候直接凸轮轴连接凸轮轴，然后再进行调整、测量。

16RK270凸轮轴却不一样，凸轮和支承轴颈是不在同一个凸轮轴上，是分开的两个部分，而且支承轴承段的轴承座在组装的时候也必须一起进行组装，16RK270凸轮轴组装的时候比240凸轮轴组装步骤多，需要考虑的问题也更多，需要调整的地方更多，更麻烦。

直接在柴油机上组装的时候，组装和调试同时进行，难度太大，需要大量的人力和物力保证，而且耗时长，成为了装配的瓶颈工序。

# 一 组装

## 1. 组装前准备

在组装之前，根据组装明细从库房领取所需的所有零部件，然后需要对所有的零部件进行整备，整个凸轮轴的组装过程中凸轮轴和轴承段的端面平面度要求非常高，在组装前要求对所有零件的端面进行打磨，去除高点，以保证组装。

## 2. 预组装

在组装时，首先按照组装图，把相应位置的凸轮轴、轴承段和轴承座摆放到组装平台上面，然后从自由端的轴承段开始连接，先把两侧的轴承段连接上，在每个端面对称的位置上拧上6个螺栓，以40N.m的力矩进行预紧，然后把连接起来的凸轮轴两端的轴承段装配到两侧的轴承座中，在轴段穿入轴承座之前所有轴承座孔中用刷子涂上润滑油，以免在后续的连接和测量中拉伤轴瓦或轴承段。

随后把第二节凸轮轴和第三节轴承段预连接起来，把轴承段装配到第三个轴承座上，把凸轮轴连接到第二节轴承段上面，并预组装，后面的凸轮轴与轴承段都是用同样的方式进行预连接，然后把预连接的凸轮轴与轴承段，按照发火次序把整节凸轮轴连接起来，保证所有的轴承段都被相应的轴承座支承，同时检查每节凸轮轴的发火次序与图纸要求是否一致，如果完全一致，就进行下步工序，如果出现不一致的部位，必须拆解，然后按照图纸要求重新进行预组装和连接，直到连接正确。

## 3. 预装调试

首先旋转凸轮轴，把第一节凸轮轴的油凸轮凹腹面朝上，在平台的基准面上放上组装调试好的百分表，把百分表的针头架在油凸轮的凹腹面上，然后从后往前推表架，看百分表的示数，微调凸轮轴，当表的针头在凹腹面的两个最高点的读数一致的时候，把八面体通过转接盘连接到预装完的第一节凸轮轴的轴承段一端，使八面体的一个平面大致在水平线上，并预紧。

用另一个百分表架在八面体的这个水平面上，然后从后往前拖表架，微调八面体，使百分表的读数始终为同一个示数，最后把紧八面体。

移开两个表架，然后把第一节轴承段和第一节凸轮轴端面的所有螺栓连接上并以80N.m的力矩把紧。

把第二节凸轮轴的油凸轮凹腹面旋转到朝上，架上一个百分表在油凸轮凹腹面上，调整凸轮轴，使表在两个高点时的示数一致，把另一个百分表架在此时八面体处在水平线上的表面上，从后往前拖表架，看表从入口到出口的示数啄值为多少然后对照表格，转换为角度值，看角度值是否超差，如果超差，拧松第二节凸轮轴的连接螺栓，多次微调第二节凸轮轴，同时拖动表架，当表面的示数偏差降到最小，然后连接上所有螺栓并按照力矩把紧所有螺栓。

后面的每节凸轮轴都是用相同的办法：

拧松螺栓，调整凸轮轴，检测表的读数，一点一点的微调，然后把紧螺栓。保证所有的凸轮轴的油凸轮相对第一个油凸轮的相位角在技术要求的范围内。

## 4. 测量、记录

在调整完每节凸轮轴后，重新安装八面体，依照凸轮轴的发火次序从第一位开始，依次检测相位角，把八面体上的百分表的读数都要通过表格换算过来，然后记录到专用的表格中，并留存。

## 5. 外观检查、发送总装

卸下八面体，对整个凸轮进行外观检查，清理在组装过程中留下的灰尘和油污，清整过后，对凸轮轴进行整体防锈处理，并固定住所有的轴承座，用起吊具把凸轮轴调入专用的集装箱，在起吊和放下的过程中必须轻起轻落，以免磕碰，然后发送到总装车间进行装机。

# 二 结论和建议

我们组装完成后，发送到总装车间，我们组装完成的凸轮轴直接安装到机体上面，固定所有的轴承座，通过齿轮盘车检查，角度和升程都在技术要求范围内，保证了整机的装配。
