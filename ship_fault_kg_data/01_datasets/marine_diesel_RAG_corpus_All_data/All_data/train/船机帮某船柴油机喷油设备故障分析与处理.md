# 导读

柴油机燃油系统高压油泵中的柱塞套筒偶件、出油阀与阀座偶件，喷油器中针阀与针阀体偶件是喷油设备中的3对精密偶件。

它们都是在高压燃油中工作，受到高压摩擦和腐蚀等作用，使偶件的配合面极易产生磨损、腐蚀等损坏，故障发生率高。

系统中的水分、杂质甚至油温的突变都将会影响高压油泵、喷油器、燃油系统和柴油机的正常工作。

某船在出海过程中曾先后发生过多只喷油器针阀卡紧咬死、高压油泵柱塞咬死不供油等故障。

本文对柴油机喷油设备的故障实例进行原因分析和探讨，并总结出喷油设备管理的经验做法。

# 一 故障经过

某船在航行过程中，主机串、并联转换装置发生故障，不能正常从串联向并联转换，伴随有增压器喘振，同时烟囱冒黑烟，排气温度升高，后在锚地对主机喷油器进行检查时发现2台主机18只主机喷油器均不同程度出现故障: 喷油嘴积碳严重，台架试验大多是无启喷压力，出现喷油成线形而无雾化状的现象。

经过解体检查发现多只喷油器的针阀在针阀体中卡紧或咬死。

在返航途中，主、辅机18只高压油泵又相继出现了柱塞套筒卡紧、咬死，不能正常供油等现象，造成主机不正常停机，甚至在长江口锚地时2台发电机同时停机造成全船失电 事故，严重影响了船舶航行安全。

在对主机高压油泵拆体分解后发现齿条、柱塞套筒偶件咬死，柱塞用铜棒敲出后发现表面发黑 (黑色可用布擦去一部分) 无严重拉伤，但有纵向拉痕，发电机高压油泵经解体发现状况与主机相似。

高压油泵故障发生时，在对燃油系统检查时发现主机日用油柜中有大量水、底层有大量粘状混浊液; 波尔反冲洗滤器的滤芯上面发现有较多的坚硬颗粒。

# 二 故障机理分析及危害

主机高压油泵中柱塞在套筒中上下运动，燃油对柱塞运动副具有必不可缺少的润滑作用，燃油的粘度较小，随着温度的升高粘性降低，而水的润滑性比燃油的润滑性能更差，一旦燃油中含有的水分超过允许值时，那么偶件润滑作用就会相对恶化降低，引起柱塞运动副中发生干摩擦，进而产生高温，情况更严重时将使柱塞偶件直接过热胀死。

另外，喷油设备中的3对精密偶件的配合面间隙只有0.002～0.003mm，大小不等杂质颗粒一旦进入燃油系统中，部分直径小于 0.003mm硬杂质就可能进入间隙直接影响柱塞偶件产生磨损，在配合面形成拉痕，较大的杂质随着高压燃油的冲刷最后进入到喷油器中，导致针阀偶件卡紧或咬死。

喷油器是整个燃油系统中的最后一个设备，系统中的杂质不得不在这里积少成多，最终影响到喷油器的正常工作。

这也是喷油器故障比高压油泵发生故障早的原因所在。

故障发生后，从每只咬死的油头针阀及油泵柱塞表面都可以发现有大面积的黑色碳膜并伴有沿运动方向的纵向拉痕，这是由于针阀在针阀体中、柱塞在套筒中运行由于缺乏必要的润滑，导致运动件过热引起燃油结胶碳化而成的，这也是油头针阀、高压油泵柱塞咬死的直接原因。

而引起精密偶件过热的原因是油中有水分、机械杂质或偶件材料没有选好。

高压油泵的柱塞卡紧或咬死会引起该油泵停止供油而使该缸停止燃烧。

过度磨损使偶件密封性能下降，造成偶件漏油，喷油压力下降，雾化不良，以致各缸供油不均，转速不稳等。

针阀在针阀体中卡紧或咬死时针阀不能及时启闭或者根本不能启闭，此时该缸发火不正常，甚至单缸熄火，转速下降。

针阀在开启状态咬死时燃油未经雾化直接喷入汽缸中，使柴油机燃烧不良，后燃严重，热负荷增大，排烟温度升高。

排烟温度升高意味着废气能量增加，使增压器转速升高，供气量增多，破坏了柴油机和增压器的匹配关系，导致压气机在高背压、小流量的状态下工作，严重时就会发生增压器喘振。

喷油嘴不但受到燃油的冲刷腐蚀，而且受到缸内的高温燃气的作用，所以喷孔内外由于受到缸内过热而积碳，喷孔积碳不仅破坏了油束与燃烧室的匹配关系，而且此积碳引起火焰逐渐移近喷孔，并加速了喷孔的堵塞形成恶性循环，最后使喷孔堵塞。

喷孔堵塞会使喷射持续期加长，后燃严重并出现二次喷射，造成燃烧性能下降。

由上分析可以得出结论:

喷油设备的故障主要原因是由于燃油中含有了较多的水分、机械杂质，影响了喷油设备正常工作。

同时由于故障不能得到及时处理，以致油泵、油头工作进一步恶化，最终导致了故障连续发生。

# 三 水分、杂质等进入燃油系统中的途径

高压油泵故障发生后，多次从日用油柜中取油样发现油中存在较多的水分和杂质，而日用油柜中的油是通过分油机净化后进入的。

连续对分油机进行跟踪取油样试验，发现从净油出口取来的油样中含有汽泡，静止沉淀后在杯底出现了一层水。

含水量超过了1%，当时分油机是从5#沉淀舱吸入燃油的，5#油舱又是从其它各油舱调驳而来的，其中也包括回油舱驳入5#沉淀舱。

由于该船的管路设计问题，油头冷却柜下冷却油泵区域的地漏按常规应引入机舱舱底，而实际情况是通至回油舱。

这样必然使两侧的空气瓶残水、污物、清洁冲洗水等通过回油舱而进入5# 沉淀舱，最终进入燃油系统中。

同时，拆检分油机时发现根据目前使用的-10#轻柴油而选择的比重环与说明书的要求不符合 (当时使用的是55mm的口径，实际应选用70mm 口径的比重环)，这样当燃油中含水量超过2%时，超过了分油机的分离能力使分离效果不佳，水分就会从分油机的净油出口进入日用油柜中，这是造成 燃油系统日用油柜中水分存在的主要原因。

该船服役时间超过20年，燃油管系锈蚀严重。

在该船中修改造中，虽对各个油舱都进行了油舱清洁处理，但未对整个管路系统进行彻底的清洗 (包括从日用柜至喷油器的机架上的管路)，以至于管路中的油泥铁锈沉积物经加入的柴油浸泡后逐 渐溶解而进入燃油系统中，这是造成燃油系统中杂质存在的主要原因。

从码头拆下的燃油系统管路内壁可以看到沉积着大量的油泥状的污物，波尔反冲滤器的滤芯上也沉积着许多颗粒及污物，转阀经常由于水的存在而生锈卡死不能正常转换。

进一步证实了燃油系统中有大量的水分和杂质存在。

燃油系统中波尔滤器和精滤器也未能起到净化过滤的作用。

在事后的检查中发现波尔滤器上存在严重缺陷:

一是滤芯与底座有缝隙不能形成有效密 封，导致机械杂质不能完全被过滤掉，部分直接通过缝隙而进入油泵、油头中;

二是压缩空气管未按技术要求安装，空气量不够，使得反冲洗的效果不好，滤芯上污物杂质不能被反冲掉，在实际使用过程中经常出现压差显示。

精滤器中修时未彻底修复，未能起到应有的过滤作用。

分油机、波尔反冲洗滤器、精滤器是燃油进入到喷油设备 (高压油泵、喷油泵) 的保护伞，一旦它们同时失去应有的净化功能，必将引起喷油设备的故障。

# 四 故障处理

为了船舶安全并确保喷油设备的正常工作，主要采取了下列措施。

1) 拆检所有18只主机高压油泵、18 只主机 喷油器，48只辅机油泵、48只辅机喷油器进厂检修，更换所有高压油泵柱塞偶件、针阀偶件、出油阀偶件。

2) 拆下所有从主、辅机日用油柜到油头的燃 油管路到专业厂家酸洗，对管路彻底酸洗清洁装复后，并对管路进行了串油作业。

3) 彻底清洁3#、5# 沉淀舱、回油舱、主辅机日用油柜，重新接上3# 沉淀舱至分油机的管路。

分油机吸口接在3#、5# 沉淀舱的高位吸口，保证分油机由2个沉淀油舱轮流使用，使之有足够的沉淀时间。

4) 对燃油分油机进行重新调试，尤其是对比重环重新进行了选择，根据目前使用的轻柴油密度大约在0.84 t /m³ 左右，所以选择了 70mm口径的比重环，而原来使用的是55mm的比重环。

根据分油机的原理，在不破坏水封水的情况下，比重环的口径应选取的大一些，尤其是当油中含水量超过分油机的允许值时，分离的效果好一些。

5) 对波尔滤器进行检修，更换空气管路由 D8改成D12的管路，保证压缩空气量，更换滤芯底座，消除滤芯与底座的缝隙，滤芯由 150目改为250目，保证波尔反冲洗滤器的正常使用。

6) 更换精滤器的滤芯片，重新恢复精滤器在 燃油系统中的使用。

经过以上处理，主辅机的燃油喷油设备在此后的航行中没有发生故障。

# 五 注意事项

在船用柴油机中，喷油设备的工作对燃油的燃烧过程具有重要作用。

因而对喷油设备进行正确的维修保养，使它们在最佳状态下工作是十分重要的。

1) 加强对燃油系统油路管理，保证分油机、波尔反冲滤器、精滤器的正常工作，确保燃油进入系统的质量。

2) 对高压油泵、喷油器的定期检查与调整是 日常工作的重要内容。

对高压油的检查与调整主要包括3个方面的内容:

①密封性检查;

②供油定时的检查与调整;

③供油量的检查与调整。

对喷油设备的检查内容包括:

①启阀压力的检查与调整;

② 密封性检查;

③雾化质量检查。

3) 对喷油设备需要定期进行拆检和试验，查出隐患和缺陷，及时排除。

拆检时须注意清洁，清洗只准使用轻柴油，擦拭时不得使用棉纱。

装复时注意定位，注意各密封面处的结合，注意有关装配记号。

4) 备航时应对各缸高压油泵逐个进行手动泵油，以便润滑柱塞偶件，并观察柱塞及其相关运动件的灵活性。

5) 长期停车后或喷油设备经拆检重新装复后，应注意喷油设备及燃油系统放气。

喷油设备各处不得有燃油渗漏。

6) 运转中应注意高压油管的脉动状态。

脉动突然增强，高压油泵有异常声响发出，则多为喷油器喷孔堵塞或针阀在关闭位置咬死所致;

若高压油 管无脉动或脉动微弱，则多为柱塞或针阀在开启位置咬死或喷油器弹簧折断所致; 若脉动频率或强度不断变化，则柱塞有卡滞现象。

7) 在柴油机运转中如需单缸停油，则应使用高压油泵专门停油机构抬起该油泵柱塞。

不可关闭高压油泵燃油出口阀，以免柱塞偶件断油缺乏润滑而卡死。

8) 应注意喷油器冷却系统的工作状况，确保喷油器可靠冷却，防止过热。

定期检查喷油器冷却油柜的液位情况，如液位上升，则表示喷油器内有漏油现象。

9) 注意缸内燃烧过程的变化，可以从排烟颜色，排气温度、示功图等的不正常变化，判断喷油设备的工作状况，必要时应酌情进行调整。
