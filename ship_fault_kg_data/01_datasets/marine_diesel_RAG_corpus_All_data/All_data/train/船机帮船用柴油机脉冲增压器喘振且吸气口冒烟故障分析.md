# 导读

某轮,B&W 8K67GF柴油主机,二冲程,直流扫气，液压排气阀,8个缸共用一个进气管。

两台脉冲增压器,第1缸和第4缸一组,第2缸和第3缸一组,这4缸连接1#增压器;第5缸和第8缸一组,第6缸和第7缸组,这4缸连接2#增压器。

# 一 故障

某日,靠泊时正常更换第5缸排气阀后离港,海上全速航行约6小时，主机两台增压器突然同时喘振且吸气口冒出大量黑烟,No.1增压器压气机吸气口黑烟很多,No.2增压器压气机吸气口黑烟明显较少。

当值轮机员一时不能判明原因，立即将主机转速降到DEAD SLOW,同时报告驾驶台和轮机长;轮机长立即赶到机舱，见No.1增压器喘振消失,No.2增压器仍然有轻微喘振。

根据经验,两台增压器同时突然喘振,一般不会是增压器故障,燃烧故障引起喘振的可能性更大。

检查柴油机,发现第5缸排烟温度低于其他缸;进一步检查见该缸排气阀不能关闭。

更换第5缸排气阀,故障排除,恢复航行。

# 二 脉冲增压器压气机喘振时吸入口冒烟

如所周知,柴油机废气增压器,包括废气涡轮和离心压气机两部分,且二者同轴。

正是因为二者同轴,废气涡轮产生的能量与离心压气机消耗的能量相等。

增压器喘振,实际是增压器的压气机喘振,是气流在压气机叶轮进口和扩压器叶片内强烈分离及其扩展引起的,是增压器固有特性。

通常,扩压器叶片内气流分离及其扩展引发喘振;叶轮进口处气流分离加剧喘振。

气流强烈分离的原因有二，都是废气涡轮产生的能量与离心压气机消耗的能量失衡:

- 压气机空气流量过小，消耗能量减少。

主要原因可能有:

(排气定时混乱、排气阀漏气甚至不能关闭等致使)扫气过程缸内压力过高,扫气箱着火,增加空气通道阻塞(常见空冷器气路阻塞、口琴阀粘着等),空冷器冷却严重不良温度高导致压力高，等。

- 废气涡轮转速(亦即压气机转速)过高,产生能量过大。

主要原因可能有:

柴油机严重超负荷(缸内燃油过多因而燃烧不良)，缸内燃油后燃严重甚至排气(支)管内燃烧,排气管着火,等。

定压增压，进气通道设有限制气流单向流动的口琴阀,燃气不可能倒流至进气通道;

而脉冲增压,进气通道没有口琴阀,燃气可能倒流至进气通道。

所以,压气机喘振时伴有空气吸入口冒烟,是脉冲增压特有的现象。

# 三 故障原因和排除

压气机喘振和吸入口冒烟，具体原因可能有：

- 排气阀打不开

- 排气阀严重泄漏或根本不能关闭,

- 扫气箱着火，

- 排气道滤网结炭脏堵,等。

燃油燃烧严重不良也可能导致增压器喘振，但一般不会导致压气机吸入口冒烟，不予讨论。

## 1. 排气阀打不开

排气阀因故不能正常开启，缸内废气不能及时从排气阀排出,随着活塞下行,扫气口或进气阀开启,废气会从扫气口或进气阀反窜进入进气通道:

- 进气道压力升高，增压器背压增大,流量下降,导致增压器喘振;

- 废气从进气通道反窜至压气机吸口冒出。

排气阀打不开，故障缸的排烟温度会明显低于其他缸,可通过观察排烟温度检查确认。

排气阀打不开的常见原因有:

- 液压油泵达不到开启排气阀的压力;

- 液压油管破裂或接头松动漏油;

- 顶杆弯曲;

- 排气阀阀桥(若有)断裂或弹出;

- 热胀间隙调节螺丝松动致使间隙过大,等。

查明原因后,可停车检修,或采取相应的临时应急措施恢复柴油机运转。

## 2. (某缸)排气阀严重泄漏或根本不能关闭

某缸排气阀严重泄漏或根本不能关闭(例如本文开头描述的故障，原因就是第5缸排气阀不能关闭)，燃烧室的新鲜空气大部分进入排烟管，导致:

① 留在燃烧室的新鲜空气少,且未经压缩或压缩不充分,压缩终点压力和温度低，喷入气缸的燃油油雾不被点燃或燃烧不充分。

② 不被点燃或燃烧不充分的燃油油雾,从排气阀进入排烟管，遇到高温热源和从燃烧室进入排烟管的新鲜空气后急剧燃烧,造成排烟管内压力异常升高,增压器转速升高，压气机喘振;同时使得与该缸同组的其他气缸(如本文开头例举的第8缸)排气背压也增高，换气不充分,扫气压力即压气机背压升高,加大压气机喘振的可能。

③ 随着活塞下行,缸内压力降低,排烟管中的燃气又反窜到气缸里，再通过扫气口反窜进入扫气箱使扫气箱内压力增大，导致压气机背压升高而喘振，且可能经过进气通道从压气机吸入口冒出。

## 3. 扫气箱着火且火势严重

扫气箱内，若积存较多未完全燃烧的燃油或过量气缸油,一旦遇到高温热源就会燃烧,即扫气箱着火。

若火势严重,扫气箱压力即压气机背压迅速升高,增压空气流量大大降低,则:

- 压气机喘振;

- 扫气箱中的浓烟通过空气冷却器、压气机叶轮和压气机进口滤器反窜冒出。

扫气箱着火可通过下列现象来判断:

- 各缸排烟温度和扫气温度都升高;

- 柴油机转速下降;

- 扫气箱过热,入孔门脱漆变色;

- 打开扫气箱放残阀,会有烟雾和火花喷出。

这时,轮机管理人员应:

- 立即减速或停车;

- 扫气箱灭火,但需保护柴油机部件避免损伤;

- 查明原因,消除缺陷;

- 待扫气箱内火被扑灭并冷却一段时间后，再重新启动柴油机运转。

## 4. 排气管滤网结炭脏堵

采用脉冲增压的大型二冲程柴油机，各缸排气管较短，为防止断裂的活塞环等机械杂物随排气进入废气涡轮损坏喷嘴环及涡轮叶片，一般在各组排气管上都设有一个排气滤网。

若柴油机长时间因某些原因燃烧不良,较多且很硬的积炭堵塞排气滤网，导致与该组排气管相连的各缸排烟温度和排气背压增高,废气能量可能减少,增压器转速降低;但扫气时气缸内压力过高,能够进入气缸的空气量大幅减少,若空气流量减少起主要作用,就会有压气机喘振，部分废气可能从扫气口经进气通道反窜到吸气口,表现为冒黑烟。

何况,自动调速的柴油机因这几缸功率降低为保持给定转速而调高整机油门,废气能量可能并不降低。

这类故障可通过观察各缸排烟温度来判定:

若与某排气管相连的各缸排烟温度都很高且比较接近,而与之相连的增压器转速又比其他增压器转速低，则可断定该排烟管排气滤网堵塞。

可停车,拆下并清通相关滤网,消除故障。

总之，脉冲增压器喘振且压气机吸气口冒烟,只是常见故障,不是增压器出了大问题,不必恐惧。

冷静观察,避免盲目拆检,理智地综合分析,不难判明原因,针对原因检修即可排除故障。
