# 导读

涠洲12-1W井口平台正常生产过程中，使用涠洲电网电源，在涠洲电网失电时，该井口平台的关键、重要应急设备将由本平台上的应急柴油发电机供电。

该平台配备一台应急柴油发电机，能够满足机组持续运行18h，额定持续输出功率630kW，功率因数0.8，电压400V，频率50Hz，三相三线不接地，允许过载10%。

该机组发电机使用的MAX321 AVR两相检测自动调压器，调压率确定为0.5%，具备软启动和持续过励磁保护功能。

应急发电机条件：

1. 电压相等
2. 电压相位一致
3. 频率相等
4. 相序一致，根据厂家指导书要求，应急发电机的电压与电网电压相差不能超过10V，不然会造成应急发电机与网电并网运行时环流偏大而跳闸，无法完成并车。

# 一、应急柴油发电机的基本原理

无刷同步交流发电机与柴油机曲轴同轴安装，就可以利用柴油机的旋转带动发电机的转子，利用‘电磁感应’原理，发电机就会输出感应电动势，经闭合的负载回路就能产生电流。

要想得到可使用的、稳定的电力输出，还需要一系列的柴油机和发电机控制、保护器件和回路。

图1 应急柴油发电机基本结构图

图1是应急发电机的基本结构图，柴油原动机带动发电机转子转动后，永磁发电机PMG产生电源，该电源给电压调节器（AVR）供电，AVR再给励磁发电机供电，为励磁定子提供电磁场，励磁转子在原动机带动旋转下，在励磁转子中产生交流电源，该交流电经过整流桥整流后在主发电机转子上产出转子磁场，旋转的转子磁场使发电机主定子上建立电压，在转速接近额定值时，从主定子输出400V主电源。

通过AVR调节励磁转子的电压，就可以调节主发电机输出电压。

AVR是一种密封电子装置，通过控制低功率的励磁机磁场，调节励磁机电枢的整流输出功率，从而达到控制主机磁场电流，稳定无刷发电机的输出电压要求，它还提供延时的过励保护，在励磁电压过高的情况下对发电机灭磁，并附有并联补偿功能。

# 二、故障现象及原因分析

## 1、故障现象

应急发电机日常测试运行时，发电机的电压出现高低波动，从显示屏可以看到电压波动幅度近30V，电压缓慢下降后，又会缓慢上升，即从370~430V之间波动，无法稳定要400V附近，但是电源频率一直稳定在50Hz。

## 2、原因分析

图2 同步励磁发电机自动电压调节器控制示意图

图2所示，发电机工作时，永磁机定子会输出170～250V电压到AVR板的P2，P3，P4端子上，经AVR内部的二极管予以整流后，通过X，XX（空载时8～9V DC）两个端子到电球的励磁机定子线圈，励磁机转子线圈感应出交流电，经安装在励磁机转子线圈上的6个二极管整流出直流，此直流电流到主转子线圈，主转子线圈在旋转状态下产生一个磁场，主定子线圈感应出交流电。

引起柴油发电机电压不稳定的原因可能有以下几个方面：

1. PMG定子或转子损坏，常见有绕组匝间短路和绝缘低问题
2. AVR板损坏，无法根据采集主电压回路电压反馈值来调节励磁电压
3. 二极管损坏，整流后的在主转子形成不稳定的磁场
4. 励磁机转子或定子损坏
5. 主电机定子或转子损坏
6. P2，P3，P4短路或者断开
7. P6，P7，P8短路或者断开
8. X，XX线短路或者断开
9. 主发电机输出处采集电压的电压互感器PT故障

针对以上各种可能的原因，先是用万用表检查PT、二极管的好坏，检查AVP板上面接线端子有没有什么异常，检查都是正常的，假定是调压版AVR故障，更换新的AVR板，发现问题还是存在。

经过对这些数据的分析，线圈绕组直流电阻值三相平衡，排查线圈匝间短路的问题，但从绝缘测量值可以发现励磁机定子绝缘太低，不符合要求，这个可能就是引起发电机在运行电压波动的原因。

鉴于励磁机定子绝缘较低的情况，维修人员对绝缘低的原因进行了分析，由于柴油发电机是在海上平台工作的，而柴油发电机的励磁机定子是在柴油发电机进风口的前端，潮湿的天气下应急柴油发电机很容易就使励磁机定子线圈受潮，从而出现励磁机定子线圈的绝缘低的现象。

## 3、故障处理及效果

找到励磁线圈绝缘低的问题，维修人员对这种情况进行处理，首先是拆下柴油发电机前端的盖子，用精密仪器清洗剂对励磁机定子线圈进行了清洁，用热风枪对其受潮的部分进行了干燥处理，等完成励磁机定子线圈清洁并处理完受潮问题后，维修人员再对励磁机定子线圈绝缘值进行了测量，测得的绝缘值为5MΩ；

这个绝缘值满足柴油发电机启机的条件，维修人员启动柴油发电机对其进行测试，启动后空载运行参数稳定正常。

稳定后带载测试，应急发电机成功与网电并车，应急发电机带载运行的电压及其他参数均正常，没有出现电压波动的现象。

该应急发电机运行电压波动现象是由励磁机定子线圈受潮引起的，为了彻底处理该问题，避免再次因为励磁机定子线圈受潮而引起发电机输出电压不稳定，在励磁机定子线圈的端盖上面加装了一个220V、60W的加热器，该加热器在应急发电机停机备用状态时保持工作，彻底解决受潮绝缘低的问题。

# 三、结束语

经过整改后的一年运行情况来看，应急柴油发电机未出现励磁绝缘低、电压波动不稳定的问题，输出电压稳定在400V，电压偏差不超过±2.5%，应急发电机未再出现因电压波动导致并车失败的现象。

应急柴油发电机作为海上采油平台生产的关键设备，一旦发生故障必将影响平台生活和安全生产时效，且由于机组系统相对复杂，故障排除费时、费力，难度较大。

鉴于本次应急发电机电压波动原因分析和处理，对今后解决类似的发电机组故障有重要的参考价值，同时也为其他平台解决应急柴油发电机故障提供参考。
