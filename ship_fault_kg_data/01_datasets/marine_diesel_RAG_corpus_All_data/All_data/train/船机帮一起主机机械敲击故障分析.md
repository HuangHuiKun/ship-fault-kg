# 导读

某主机，型号MAN B&W SK90MC，8缸，额定功率36560KW 104 r/min，高压油泵（单凸轮）采用气缸换向装置，韩国HSD制造，2005年5月出厂。

# 一、故障现象

主机转速77r/min低负荷运行，突然：

控制面板上“FUEL CAM AHEAD”灯闪烁。

5#缸机架以上有明显的异常敲击声，节奏和转速一致。

主机转速设定不变，发生敲击前各缸排温与平均温度差依次为+2℃、-5℃、+3℃、+2℃、0℃、14℃、-6℃、0℃，敲击时5#缸排温偏差从0℃迅速降低到-43℃，其它缸排温略有上升。

用听棒探听5#缸，分辨不出发出声音的位置。

主机操纵手柄拉至停车位（停止燃油喷射）：

转速下降初期，敲击未停止也没有明显减轻，且仍然与转速同步。

转速降低到约30r/min，敲击声顿时消失。

停车后，检查主机扫气箱、曲拐箱、凸轮轴箱、排气阀系统等，均未见异常。

重新启动，主机运行再无敲击，直到彻底排除此故障。

# 二、故障分析

故障分析，不少人是先列出全部可能，然后逐一检查（包括内部检查、解体检查）排除，最终能够查明故障原因。

这样做，不仅费力，更重要的是耗时过多影响营运，漂航排障也不安全。

本文试图结合故障现象和工作原理寻找故障点，尽量减少内部检查和解体检查，节省时间和人力。

当然，这样做需要全面细致地搜集故障现象，熟知故障原理，以及较强的逻辑思维能力。

## 1、故障性质

主机有节奏与转速一致的异常敲击声通常被称为敲缸，其实并不确切。

敲缸，顾名思义，是气缸被敲击。

真正意义上的敲缸，是活塞撞击缸壁，故敲击节奏与主机转速一致，称为机械敲缸（冷敲缸）。

后来，节奏与主机转速一致的敲击，都逐渐被称为敲缸。

例如雾化不良缸内冷油积聚过多、燃烧始点过早等爆燃所致的爆炸压力和爆炸声过高，也被称为敲缸，并为了区别于机械敲缸（冷敲缸）被称为热敲缸；

气缸外的机械敲击，例如轴承间隙过大、部件过度摩擦等有敲击，被敲击的不是气缸，但也因节奏与主机转速一致被称为敲缸。

可见，敲缸一词不宜滥用；遇到“敲缸”，必须分清是真正意义上的敲缸，还是缸内爆燃，或气缸外的机械敲击。

据故障现象：

主机操纵手柄拉至停车位，停止燃油喷射，敲击声并未同步消失，可以排除缸内爆燃。

敲击毫无前兆，可以肯定不是机械敲缸，因为活塞与缸套间隙不当引起敲击，必然有个发展过程，例如排温逐渐变化，敲击由轻变重等。

由此可以肯定是缸外机械敲击。

## 2、确定敲击点

故障现象显示，敲击点在5#缸，机架以上。

机架以上部位机械敲击，可能在活塞/缸套、排气阀、排气阀顶升机构、十字头轴承、高压油泵顶升机构等五部位。

活塞/缸套，“故障性质”一段已排除。

排气阀敲击

5#缸排温明显下降，可排除排气阀闭阀时敲击。

因为排气阀闭阀时敲击（例如弹簧空气关阀时液压油阻力降低），则排气阀工作异常导致扫气不良，因而燃烧恶化，排温应该上升而不会降低。

排气阀顶升机构敲击

众所周知，机械零件之间有两种接触——弹性接触和刚性接触。

刚性接触失效，就是断裂或脱离，机器将无法继续运转；

弹性接触失效，机器可以继续运转，但温度、声音、振动、参数等异常。

排气阀顶升机构敲击，只能发生在排气凸轮与滚轮之间，因为只有它们是弹性接触。

若5#缸排气凸轮与滚轮敲击，它们之间必然有间隙，也必然延迟排气阀开启；

而排气阀延迟开启，虽然因推迟排气起始时刻而降低排温，但由此引起的后燃升高排温的作用更大，5#缸排温会比其他缸高。

故障现象显示5#缸排温明显下降，可排除该缸排气凸轮与滚轮敲击。

十字头轴承敲击

轴承间隙过大是导致缸外机械敲击的常见原因。

这种敲击总有由轻变重的发展过程，敲击声随主机转速降低越来越轻，且持续到主机完全停转才消失。

排除这种可能，有下列故障现象支持：

这次敲击毫无前兆，没有由轻变重的发展过程，突然有明显的异常敲击声；

随主机转速降低到停转，初期敲击声未停止也没有减轻，而转速降到约30 r/min敲击声顿时消失；

故障时主机77r/min低负荷运行，仅相当于额定功率的40%，各运动部件（含轴承）受力相应较低，不大可能突然运动部件（含轴承）间隙不正常。

况且该类敲击不可能大幅度的影响排温。

高压油泵顶升机构敲击

排除上述四种可能后，几乎可以判定敲击声来自高压油泵顶升机构。

高压油泵顶升机构（见图1），包括凸轮，滚轮，复位弹簧，以及换向机构的气缸，拨叉、支撑销子等，滚轮靠复位弹簧紧压在凸轮上。

图1 高压油泵驱动部分示意图

与排气阀顶升机构一样，高压油泵顶升机构只有燃油凸轮与滚轮是弹性接触，所以只能是燃油凸轮与滚轮敲击。

况且还有5#缸排温明显降低为佐证，其逻辑是：

燃油凸轮与滚轮之间有间隙→高压油泵柱塞行程减少→（其他条件不变）有效行程减小→每一循环喷油量减少→5#缸排温降低。

## 3、确定故障源

确定敲击点在高压油泵滚轮与燃油凸轮之间后，接下来要分析故障点——滚轮与凸轮间隙从何而来。

滚轮与凸轮间有间隙，有三种可能：

滚轮复位弹簧疲软失效，

高压油泵顶升滑块/导套运动阻滞，

高压油泵柱塞/套筒运动阻滞。

因为主机停车后重新启动运转“再无敲击”，可排除复位弹簧疲软失效，后两者则难以区分。

好在高压油泵与其顶升机构紧邻，便于监视，一同拆检也方便。

这样，没有任何拆装检查就确定了敲击故障源在高压油泵或其顶升机构，且更可能是高压油泵柱塞/套筒运动阻滞，因为它工作条件恶劣。

而顶升机构有滑油润滑，工作条件较好，不易阻滞。

## 4、临时处理措施

鉴于主机重新启动运行再无敲击，且判定敲击点在高压油泵及其顶升机构，认为可继续航行，只需采取下列临时措施：

密切监视5#缸高压油泵及其顶升机构；

稍降低该缸油门格数，使柱塞与套筒的相对位置与上次敲击时的位置错开；

稍降低燃油温度，即稍提高燃油粘度，加大燃油的润滑效果；

制定应急处理方案，等。

采取上述措施，直到靠泊，未再发生敲击。

应急处理方案——当5#缸高压油泵及其顶升机构发生敲击，当值人员：

第一步，立即到凸轮轴处（事先备好矮梯），通过玻璃盖板观察敲击声是否与5#缸高压油泵滚轮撞击燃油凸轮同步，若能很明显看出同步，则可确定敲击点和验证以上分析正确。

第二步，用紫铜榔头（事先备好）敲击5#缸高压油泵燃油齿条以改变油门格数，观察敲击声是否消失。

第三步，若敲击声仍未消失，主机降速到30 r/min，观察5#缸高压油泵燃油齿条格数是否比其它缸大，并再次改变该缸齿条格数，观察敲击声是否消失。

第四步，若敲击声仍在，伺机停车检查。一般情况下，敲击声应在执行第二步后消失。

## 5、验证故障点

靠泊后，拆下并解体高压油泵及其顶升机构，见5#缸高压油泵柱塞根部有两道明显拉痕（见图2），套筒相应部位拉毛，其他均无异常。

换新该偶件后，主机工作便正常了，再没发生类似敲缸。

可知故障点在高压油泵柱塞/套筒的分析正确。

# 四、故障机理

高压油泵顶升机构敲击导致排温降低 5#缸高压油泵：

柱塞下行运动阻滞，滚轮与凸轮之间出现间隙；其后柱塞在复位弹簧作用下克服阻力下行，滚轮就会敲击凸轮。

柱塞下行是油泵吸油过程。

若敲击发生在凸轮上升面，则油泵进油行程和排油行程都减小，（其他条件不变）有效行程减小，就会减少喷油导致排温降低。
