# 导读

排气阀是柴油机燃烧室重要组件之一，也是柴油机换气机构中的重要工作部件，排气阀持续良好的工作对柴油机工作的动力性、可靠性起着重要的作用，同时也影响着船舶柴油机工作的经济性和NOx排放气体指标。

由于排气阀工作条件极为恶劣，是柴油机在工作中易出现故障的零部件之一，轮机工作人员平时要特别关注检查排气阀的工作状态，及时发现问题、排除故障，确保船舶柴油机正常工作，保证船舶安全运营。

# 一 排气阀常见故障分析

## 1. 高温腐蚀

主要是由劣质燃油中含有较高的钒、钠、硫等元素等在燃烧过程中形成的混合物对排气阀的腐蚀，造成在排气阀密封面上形成麻点，引起气阀密封不良而漏气。

## 2. 排气阀烧蚀（烧损）

由于受燃烧室高温燃气直接接触和冲刷，容易造成密封阀面烧损，引起漏气，烧损结果是使气阀密封面出现灼伤、凹陷、局部脱落现象。

## 3. 气阀密封锥面磨损过快

气阀密封锥面与阀座严重磨损，使得密封环带过宽，影响密封性能。主要是由气阀间隙过大、冷却不良、高温腐蚀、气阀变形、气阀材料缺陷等等引起的。

## 4. 气阀卡死

主要是由气阀阀杆与阀杆套管配合间隙过小或阀杆弯曲变形引起气阀卡死现象。

## 5. 气阀弹簧变形、断裂、弹性减弱

主要是气阀弹簧疲劳破坏导致的，或是气阀弹簧材料缺陷引起的。为防止气阀弹簧折断而掉入燃烧室里，通常使用两根旋向相反的气阀弹簧。

# 二 排气阀故障机理

## 1. 受高温高压燃烧产物的直接作用

柴油机工作过程，排气阀直接受到高温高压燃气作用，工作条件差，冷却条件不良。高温降低了排气阀金属材料的机械性能，使得排气阀产生变形。破坏阀的密封性而引起高温燃气对阀面的烧损。

## 2. 受冲击交变载荷的作用

排气阀工作时在惯性力和气阀弹簧力作用下，承受着撞击与交变载荷，使得阀面、阀杆容易发生变形、磨损，甚至排气阀阀杆与套管发生卡死现象。

## 3. 排气阀阀杆与阀杆套管、阀面与阀座容易积炭、磨损

排气阀工作中润滑条件差，阀杆与导管间润滑不良而发生磨损。为了降低船舶营运成本，提高经济性，船舶柴油机通常都是使用劣质燃油，劣质燃油粘度高，雾化不良，燃烧不完全，后燃严重，造成气阀阀面、阀座阀杆、阀杆套管积炭，使排气阀磨损加剧。

## 4. 容易造成高温腐蚀

由于劣质燃油品质差，劣质燃油含有较高的钒、钠和硫，燃烧产物除了一部分排出外，还有一部分对柴油机燃烧组件造成高温腐蚀。

## 5. 气阀弹簧疲劳损坏

气阀工作是不断作往复运动，气阀弹簧支撑着气阀，也随之被反复弹性压缩变形，容易引起气阀弹簧疲劳破坏，造成弹簧裂纹或折断。

# 三 排气阀的检修

气阀发生故障将影响柴油机正常工作，轮机管理人员要加强日常管理，发现问题，及时检修。

## 1. 气阀与气阀套管间隙的测量检查

首先将气阀从套管中提起，使气阀阀面距离气缸盖平面约15mm～20mm。如图1气阀阀杆和气阀套管间隙测量示意图（a）所示。图1气阀阀杆和气阀套管间隙测量示意图。其次将磁性表座固定在气缸盖上，装上千分表，使千分表测头与气阀阀盘边缘轻轻接触，并沿触针方向来回摆动气阀，进行气阀与气阀套管间隙的测量检查。对照说明书技术参数，如间隙等于或超过极限间隙，气阀套管换新。如图1气阀阀杆和气阀套管间隙测量示意图（b）所示。

## 2. 气阀与气阀阀座研磨

拆下气阀，表面除炭清洁，检查气阀与气阀座的密封面，如发现麻点、凹陷等轻微缺陷，可通过研磨的方法进行缺陷修复。

## 3. 气阀阀座的铰削

如发现气阀密封面上有较为严重的麻点和腐蚀等现象，必须在气阀研磨前对阀座进行气阀铰刀铰铣来修复。

## 4. 气阀密封性检验

研磨修复好的气阀要进行密封性的检验。可采用气阀密封锥面铅笔划线检验法和煤油渗漏检验法进行密封性检验。必要时进行再研磨，保证其密封性达到要求。

## 5. 气阀弹簧的检修

主要检查气阀弹簧弹性是否下降、是否出现倾斜变形、弹簧是否有裂纹、折断损坏的迹象，如有应及时换新。

# 四 结语

气阀是柴油机重要的零部件之一，其工作性能状态直接影响柴油机正常工作。轮机管理人员要加强对气阀的日常管理、检查，对气阀的阀盘、气阀阀座、阀杆、阀杆套管等进行检查、测量。视其失效情况，可通过测量调整气阀间隙、阀面与阀座互相研磨、堆焊光车、绞刀铰削以消除缺陷，必要时换新。要及时发现并修复排除故障，以确保柴油机工作的稳定性、可靠性。
