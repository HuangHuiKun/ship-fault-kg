# 导读

文章针对某船在某航次中出现的左主机 3#缸排温突降现象，结合主柴油机的结构、管路和系统等，分析了 MAN B&W 8LM42 柴油机的单缸排温突降故障，提出了排除故障的基本方法。

# 一、故障概述

H2203 轮动力系统采用的是 MAN B&W 8LM42柴油机，2010 年5月21日下午14 时左右，左主机3#缸突然出现排温过低报警，各缸排温曲线如图1所示。

图1 各缸排温曲线图

经过值班人员确认，各缸平均温度为305℃左右，而3#缸排温在不到15h内从308℃降为 250℃ ( A点至 B点) ，偏离最大允许温差值 ( 各缸平均温差 ± 50℃) ，其他各缸排温明显上升。

当班人员采取了降速运行的措施，在转速降至100r/min左右时，3#缸排温回复到正常温差内，当转速提高到150r/min 时故障现象再次出现。

# 二、故障定位

## 1、导致主机排温降低的可能原因

1) 排气阀故障。

排气阀打不开或不能完全打开，排烟不能完全排出，造成排温下降; 排气阀无法关闭，汽缸中的新鲜空气不能被压缩，从而达不到发火温度，燃油不能发火燃烧，排温下降。

2) 喷油器故障。

MAN B&W 8LM42 柴油机为双油头喷射方式，如果其中任意一喷油器卡死在关闭位置或喷油器喷孔堵塞，燃油喷射量就会减少，排温下降。

3) 高压油泵故障。

高压油泵柱塞偶件间隙过大或吸油阀卡死，无法产生使喷油器开启的压力，导致柴油机喷油量减少甚至无法发火而使排温下降。

## 2、故障定位

本着从易到难的原则对以上可能造成排温降低的原因进行排查。

1) 排气阀故障。

MAN B&W 8LM42 柴油机排气阀是带阀壳式排气阀，在排气阀的顶部有一排气阀开关指示器，可以测试排气阀的开关情况。

提起排气阀开关指示器，使其作用，与其他各缸对比，工作正常，可排除此故障。

2) 喷油器故障。

主机停机，拆卸该缸喷油器，对2只喷油器分别进行启阀、喷射方向、滴漏和雾化试验，启阀压力分别为29.5MPa和29.0MPa，正常值为(30.0 ± 2.5) MPa，喷射方向正确，无滴漏或二次喷现象，雾化良好。

以上参数表明，喷油器工作正常。

装复喷油器，启动检查，3#缸排温依然偏低 ( 见图1中D点至F点) 。

3) 高压油泵故障。

装复喷油器后，利用听诊器在高压油泵出口处，对高压油泵进行了认真仔细的检查，发现主机运转时高压油泵存在偶然脉动偏弱现象，频率约为转速的10%左右。

由此判断高压油泵内某部位有卡阻或内漏现象，造成高压油泵运行中供油不足导致排温下降。

# 三、故障原因分析

## 1、高压油泵的结构及工作原理

MAN B&W 8LM42 柴油机的高压油泵为带吸入阀式柱塞泵 (如图2所示)。

图2 高压油泵结构简图

主机运行期间，当燃油凸轮在基圆上时，柱塞泵内充满燃油; 当凸轮转动时，凸轮慢慢使柱塞抬起，柱塞上行首先封住回油孔，柱塞继续上行，套筒内压力升高，当套筒内压力与吸油阀进油孔压力达到平衡时，滑阀在弹簧的作用下下行封住吸油阀进油孔，燃油在吸油阀的中心孔压入高压油管; 当凸轮转至凸圆最高点时，燃油经过喷油器喷入汽缸; 凸轮继续由凸圆顶部向基圆转动，柱塞下行，套筒内压力下降，燃油供给泵的压力在吸油阀进油孔处推动滑阀克服弹簧预紧力上行，吸油阀进口孔打开，燃油被吸入套筒内，凸轮转至基圆，循环以上过程。

## 2、高压油泵内部现状

拆检柱塞泵，发现套筒内含有大量杂质，吸油阀滑阀与本体接触面磨损严重，并有烧蚀和锈蚀痕迹。

清洗滑阀后测量其外径，前后方向顶部为17.96mm，中部为17.98mm，下部为18.00mm，右左方向顶部为17.97mm，中部为 17.99 mm，下部为18.00 mm。

以上数据表明滑阀外表面出现了失圆和锥度。

## 3、滑阀磨损原因

主机自装船以来共运行2万多小时，滑阀在吸油中每分钟上下运动150多次，虽然滑阀与吸油阀本体之间有燃油润滑，但长时间运行也会出现正常磨损。

本次出航以来，在对燃油柜放残时发现，油柜内的水分和杂质明显比以往增多。

当燃油中的机械杂质进入吸油阀与滑阀接触面时，会加剧滑阀的磨损，甚至使滑阀卡死，高压油泵无法建立压力;

当水分进入系统时，部分水分会附着在系统管壁上，对管路产生腐蚀和氧化，管壁上腐蚀氧化的锈渣被燃油冲至吸油阀，对吸油阀滑阀产生更大危害;

当水分进入吸油阀时，随着柴油机喷油结束，高压油泵柱塞下行，压力明显下降，水分的气化温度也随之下降，部分水分会在此处达到气化温度产生气泡，气泡在随后的高压下受到挤压破裂，气泡破裂时释放的能量，一方面对滑阀与吸油本体产生穴蚀加剧滑阀磨损，另一方面气泡破裂释放出的能量径向推动滑阀，使滑阀偏磨不能落座，高压油泵无法建立压力。

若水滴进入吸油阀，部分水分以不饱和状态游离在燃油中，这些水滴进入滑阀时，由于燃油压力突变的扰动，水滴就会破裂，水滴破裂释放出的能量推动滑阀，使滑阀偏磨或卡死，这是高压油管脉动偏弱的主要原因。

综上所述，燃油中含水量的增加是造成滑阀严重磨损、高压油管脉动偏弱、排温下降的主要原因。

对柱塞套筒进行了清洁，更换高压油泵吸油阀，然后按要求安装好高压油泵，冲车试车，柴油机排温恢复正常 (见图3) ，点 A 至点 B 为柴油机更换吸油阀后加速阶段时的各缸排温情况 ( 其中粗线表示3#缸) ，B 点后为柴油机150r/min ( 全速) 时各缸排温情况。

# 四、结束语

通过本次故障的排除，证明只有真正熟知各系统、设备的结构原理和工作过程，面对故障现象冷静认真分析，才能对故障准确定位，及时排除故障，消除故障根源。

为杜绝此类故障的发生，在管理中必须注意以下事项:

①对燃油加注和驳运加强管理，在源头上杜绝水分的进入，同时加强燃油柜放残物的监测;

②加强燃油过滤净化，减少机械杂质对高压泵的磨损;

③定期检查维护系统管路阀件，保持系统清洁，防止管路内壁锈蚀产生机械杂质;

④控制好燃油进口温度。
