# 导读

随着国际和国内对于船舶温室气体排放要求的不断提高，船用发动机对新型低碳燃料的应用的需求也越来越大。

甲醇被认为是一种极富潜力的替代燃料，具有稀燃极限宽、含氧量高、易于运输存储、供应充足、产业成熟等优点。

考虑到船舶动力安全冗余需求、当前船舶甲醇加注设施尚不完备等因素，船用甲醇燃料发动机普遍要求可实现甲醇和柴油两种燃料模式运行。

甲醇燃烧适应性强，既可使用进气道喷射缸内引燃，以预混燃烧为主的方式，也可使用缸内喷射并引燃，以扩散燃烧为主的方式等。

甲醇进气道喷射技术方案对于甲醇燃料供给和喷射系统的应用要求较为友好，产品性价比较高，是当前船用甲醇双燃料发动机主要研究方向之一。

文献中在320mm缸径的单缸机上比较了甲醇进气道喷射在不同平均有效压力的燃烧情况。

文献中研究了空燃比喷射正时等控制参数对甲醇热效率和替代率的影响。

文献中在玉柴、淄柴等多型船用高速发动机上开展甲醇-柴油二元燃料的燃烧和排放研究。

文献中在280mm缸径船用中速机上研究了甲醇进气道喷射对燃烧与排放的影响。

国内外船用甲醇双燃料发动机的研究主要集中在燃烧与排放方面，而两种燃料和不同燃烧方式对缸内热负荷及其分布规律影响方面的研究相对较少，而这一点对于发动机整体性能设计、受热件设计等均具有重要的研究意义。

本文中以某船用甲醇双燃料发动机为对象，通过试验比较了其在甲醇模式和柴油模式下缸内燃烧和缸内热负荷并分析原因，为兼顾两种模式下的产品设计改进提供了技术支撑。

# 二、发动机燃烧试验结果与分析

## 1、缸压和放热率

发动机不同负荷甲醇和柴油模式的最高燃烧压力及其相对偏差如图4所示。

图4 甲醇和柴油模式最高燃烧压力及其相对偏差

甲醇模式下的最高燃烧压力均高于柴油模式，其中在25%~75%负荷范围内高0.5~0.7 MPa。

100%负荷受发动机最高燃烧压力限制降低了甲醇替代率，因此两种模式最高燃烧压力偏差相对较小。

对于循环间的最高燃烧压力相对偏差，甲醇模式要明显大于柴油模式，柴油模式下一般在1%左右，而甲醇模式下普遍都在2%~4%之间。

100%负荷通过降低甲醇替代率使最高燃烧压力的相对偏差降低至0.7%，保证了最高燃烧压力不超过限制值。

基于发动机缸压曲线计算得到缸内放热率曲线并以此来总体分析甲醇和柴油模式的燃烧过程。

将燃烧释放总热量的5%、50%和90%时对应的曲轴转角分别定义为燃烧始点、燃烧重心、燃烧终点。将燃烧始点到重心，燃烧重心到终点分别视为燃烧的前半段和后半段，则甲醇和柴油模式各负荷的燃烧过程如图5所示。

图5 甲醇和柴油模式燃烧过程对应的曲轴转角位置

甲醇模式在25%~75%负荷时燃烧始点均晚于柴油模式，说明甲醇的加入导致滞燃期变长；同时整个燃烧持续期也有不同程度的缩短，尤其是燃烧的前半段，说明预混燃烧比例较高，负荷越低越为明显。

在100%负荷时，甲醇模式与柴油相比燃烧始点反而略微提前，初步分析认为是局部较浓甲醇混合气被直接压燃所致。

同时其燃烧持续期也明显变长，可能是受甲醇缸内蒸发速率的限制，缸内部分甲醇在柴油引燃时尚未完全蒸发，混合气当量比偏低，影响了预混燃烧的速率。

## 2、增压压力和涡轮前排气温度

甲醇和柴油模式的增压压力和涡轮前排气温度如图6所示。

图6 甲醇和柴油模式的涡轮前排气温度和增压压力

甲醇模式的增压压力在25%、50%和75%负荷均略低于柴油模式，但在100%负荷甲醇模式的增压压力比柴油模式高0.019 MPa。

在涡轮前排气温度方面，甲醇模式均低于柴油模式，其中75%负荷相差最大为27°C，100%负荷差距最小为6°C。

涡轮前排气温度可间接反映缸内平均热负荷的情况，说明甲醇模式下缸内热负荷总体是降低的。

# 三、缸盖和缸套温度场试验结果分析

## 1、缸盖温度场试验结果分析

在柴油模式下随着负荷的逐渐升高，缸盖各测点的温度基本也是逐渐提高的，规律比较明显。

柴油模式下缸盖火焰面部分测点的温度测量结果如图7所示，其中缸盖测点位置见图2。

图7 柴油模式缸盖火焰面温度

缸盖火焰面在甲醇模式下的规律不及柴油模式下显著，其在甲醇模式和柴油模式的温度差值如图8所示。

图8 甲醇和柴油模式缸盖火焰面温度差

甲醇模式火焰面温度总体低于柴油模式，两者的差值基本随着发动机负荷的升高而增大，最高可达40°C。

其中靠近缸盖边缘的测点的规律性更强，气门间的测点在25%和100%负荷也有相同规律，但在50%和75%负荷靠近进气门的测点反而是甲醇模式下的温度更高。

从图中可以看出温度升高最多的点是两个进气门中间的测点，增加了42℃，进气门和排气门之间的测点温度也略有增加。

初步分析认为缸内甲醇浓度分布不均，造成缸内放热集中在进气侧和输出端，引起了缸内局部温度的升高。

缸盖水腔侧的测点布置在火焰面靠近气缸中心位置的正上方。

缸盖水腔侧在两种模式下的温度差如图9所示。

图9 甲醇与柴油模式缸盖水腔侧温度差

缸盖水腔侧的温度差也呈现了相同的变化趋势。

甲醇模式温度整体上是降低的，但在50%和75%负荷进气门附近的水腔侧温度是上升的。

水腔侧的温度差与火焰面相比明显降低。

缸盖气门座位置在两种模式下的温度差如图10所示。

图10 甲醇与柴油模式气门座温度差

从图中可以看出气门座温度差总体是下降的，但不同气门和位置的差异较大。

进气门的测点12处降幅最大，最高达到61℃，同一进气门座另一侧的测点13降幅明显减小，最高为26℃。

进气门座的温度下降主要是由进气门背面附着的甲醇蒸发吸热所引起的。

结合分析，同一进气门座的差异主要是由于缸内燃烧分布不均匀，与火焰面的温度不均趋势是一致的。

排气门座不受甲醇附壁的影响，其温度差变化趋势与火焰面变化趋势一致。

通过上述对缸盖温度场的分析可以发现，甲醇模式下缸盖的总体温度是下降的，但在部分负荷的局部位置由于甲醇燃烧集中也会引起温度升高。

进气门座位置由于甲醇附壁在进气门背面，进一步扩大了温度的下降幅度。

随着负荷增高，柴油模式下缸套各测点的温度基本逐渐升高，规律性比较明显。

# 四、结论

(1)甲醇-柴油双燃料发动机在甲醇模式下的最高燃烧压力及其循环相对偏差要高于柴油模式。

在中低负荷时甲醇模式燃烧始点提前，持续期缩短，在高负荷时则相反。

(2)甲醇模式下的增压压力在中低负荷略低于柴油模式，在高负荷则高于柴油模式。

甲醇模式下的涡轮前排气温度均低于柴油模式。

(3)甲醇模式缸盖测点温度总体低于柴油模式，模定工况火焰面温度降低14~40℃。

但甲醇模式的温度场分布规律性不显著，中高负荷进气侧和输出侧的温度偏高，进气阀座温度偏低。

(4)缸套测点温度在甲醇模式下均低于柴油模式。

随负荷的增高平均温度差增大，随测点下移平均温度差逐渐减小。

标定点抗磨环处的甲醇与柴油模式平均温度差最大，可达37℃。

缸套周向上在靠发动机自由端处温度较低。
