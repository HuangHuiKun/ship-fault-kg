# 导读

示功阀是柴油机的重要部件和易损部件。它工作条件恶劣，使用频繁，损坏率高，相关教材也没有专门阐述说明。

本文介绍了柴油机示功阀的作用，分析示功阀损坏的原因，设计制作出修复专用工具，提出示功阀的修理方案，供同行参考借鉴。

# 一 柴油机示功阀的作用

柴油机示功阀，也叫示功考克。

示功阀装在柴油机缸头上，是缸头的主要附件之一。

它具有2个功能：

一是柴油机启动前冲车，将汽缸中的杂质、残水或积油等从示功阀处冲出，借以判断汽缸内是否漏入油、水；

二是用来安装示功器、爆压表，测录示功图、测量汽缸爆炸压力以便观察、判断柴油机汽缸工况，计算分析柴油机的工作性能，保证柴油机在最佳状况下运转，提高其经济性、动力性和可靠性。

# 二 柴油机示功阀损坏的原因

示功阀是柴油机工作条件最恶劣的零部件之一，其阀面和阀座底面受到燃气高温、高压的作用。

柴油机启动、停车、工况测量时，示功阀需要频繁开、关，阀面和阀座底面间产生干摩擦，阀面和阀座上的灰分、炭粒又变成磨料加重了磨损。

燃烧产物对阀头和阀座有腐蚀作用，使阀面和阀座上出现凹坑，造成漏气和烧损。

受高温、高压燃气的冲刷、腐蚀，以及频繁开关产生的摩擦、磨损，一段时间后，柴油机示功阀阀面和阀座容易接触不良，出现漏泄。

# 三 柴油机示功阀修复方法

示功阀损坏率高，需要频繁订购、更换备件。

国外只有个别厂家（如B&W公司）主机出厂时配备了示功阀阀座修理专用工具：平面绞刀、锥面绞刀、研磨阀头（各一把）和一只压盖。

而示功阀阀头修复只能订购阀头备件总成，仅有少数主机结构说明书标明可以单独订购阀头锥体，多数主机、全部副机示功阀损坏均需通过更换新备件来解决。

除非示功阀阀头、阀座烧蚀情况严重必须换新，通常情况下都能够重新加工研磨进行修复，让其再次恢复使用，以达到节省备件、提高效益、保证柴油机安全的目的。

柴油机示功阀一般能够重新加工修复三四次，从而达到降低示功阀更换率的目的。

示功阀密封依靠落在阀头与阀座接触面上宽度为0.3～0.5 mm的阀线实现。

阀线变宽超过规定值或接触面出现磨损、烧蚀凹坑，就会引起燃气漏泄。

示功阀部件小，工作条件恶劣，要求的精度高，所以像研磨主机排气阀密封面一样，采用阀头和阀座分开研磨恢复阀线的方法是修复示功阀理想的维修方案。

## 1. 示功阀阀头的修理

旧的示功阀解体为阀头和阀座两部分。

阀头部分因为阀杆会在压盖内转动且车床卡盘不易夹持，拆下的阀头锥体尺寸小，而无法直接夹持在车床上车削或磨削修理。

图1 阀头锥体夹持工具

如图1所示，可利用一根圆钢棒制作一个简易的阀头锥体夹持工具。

### （1）阀头锥体专用夹持工具的制作

选取一根长度200mm左右、直径比示功阀阀头锥体圆柱部分大5mm的圆钢棒。

将端面车平，车削内圆直径与阀头锥体圆柱直径匹配，车平内圆孔底部，圆孔深度比阀头锥体圆柱长度小2 mm左右（作为锥体冗余磨削量）。

在阀头锥体圆柱底部测量绑固铁丝孔高度，对应圆钢棒内圆孔底部向端面测量相同尺寸位置定位，用电钻钻一通透孔，小孔直径与阀头锥体小孔直径相同。

### （2）阀头锥体的修理

将待修阀头锥体放置在夹持圆钢棒内圆孔内，绑固铁丝穿过钢棒和阀头锥体的固定小孔妥善绑定。

将夹持钢棒装入车床卡盘内，用平锉或粗砂纸裹在铁锉上保持45°角磨削腐蚀面，然后换用细砂布进行抛光，尽可能达到较高的光洁度。

如果阀头锥体表面烧蚀较重，可用合金钢车刀，注意磨好刀角，找准中心点，将阀头以45°角进行光车。

## 2. 示功阀阀座的修理

示功阀阀座形状复杂，车床难以固定夹持。

为解决该问题，可以制作一个示功阀阀座锥面研磨工具和一个阀座上平面研磨工具供修理使用。

### （1）示功阀阀座锥面研磨工具的制作

图2 阀座锥面研磨工具

阀座锥面研磨工具如图2所示，选用适当圆钢棒，用锉刀将圆钢棒上端锉磨为正方形，下部插入一只新的阀头锥体钻孔铁丝绑固。

为加强阀头与阀面密封效果，该阀头锥体可用图1的工具，在车床上将锥面车削或磨削加工为43°角。

研磨手柄可选用合适扁铁，中部钻孔、锉削为正方形与研磨阀头光杆上端正方形匹配制成。

使用报废的示功阀压盖或制作一只新压盖，研磨光杆外径与阀座压盖内径匹配。

### （2）示功阀阀座上平面研磨块的制作

图3 阀座上平面研磨工具

示功阀阀座上平面研磨块如图3所示，可用一根圆钢棒两端面车平，车削外圆直径与阀座上平面直径匹配，对中后焊接在一根与图2相同的阀杆上。

研磨块下端面可在平台简单研磨。

### （3）示功阀阀座的研磨

首先使用阀座平面研磨块（如图3）在阀座上平面涂研磨砂研磨，然后使用阀座锥面研磨工具（如图2）研磨阀座燃气通孔锥形面。

如果阀座锥面状况较好，则该阀座上平面无须研磨。

阀座研磨时，阀杆从上部穿过压盖，压盖旋入阀座螺纹。

压盖起到导向作用，保证研磨阀杆的中心度。

示功阀阀头磨削、阀座研磨后，可用图2研磨工具装上已抛光的阀头锥体，用滑油将阀头与阀座简单对研。

# 四 结束语

经过上述加工修理后组合起来的柴油机示功阀合格率几乎能够达到百分之百，能够有效降低示功阀更换率。

这种修复示功阀的方法任何船舶都可以做到。

使用这样的方法，除了能修复柴油机示功阀外，还能修复柴油机安全阀。

推广使用这种修理方法，对海运公司经济效益和营运船舶安全生产都大有裨益。
