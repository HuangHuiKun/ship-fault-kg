# 导读

某散货船主机型号为MAN B&W 6S50MC-C,额定功率为9450kW ,额定转速为127 r/min。

机舱自动化程度较高,为AUTO-O无人机舱。

# 一、故障经过

某年7月，货船空载从上海外高桥前往墨西哥装运铁矿石。

开航初期船舶设备运行良好,穿过日本对马海峡后，监控系统经常发出主机滑油分油机分油故障警报。

其间,对分油机进行拆解维护,未找到确切的故障点,没能完全修复故障,故依旧经常发出警报。

某日,船舶以12 kn航速航行时综合监控报警系统报警、主机减速,延伸报警单元显示主机故障停车;待轮机部人员紧急赶到机舱时,主机已经停止运转。

# 二、故障分析

主机遥控系统采用挪康的 Autochief-VI,配备主机遥控面板、安保面板等。

安保面板上指示主机故障停车，且滑油失压故障停车指示灯亮。

主机滑油系统见图1。

由图1可知,运营正常的船舶突然滑油失压,其原因主要为:

(1) 滑油系统管路严重外漏;

(2)滑油压力传感器故障;

(3)滑油泵运行故障(过载、泄漏等);

(4)滑油系统滤器堵塞或自清机构损坏;

(5)滑油油位不足。

轮机长迅速将主机操作部位切换至集控室手动操车,并组织检查故障位置。

经检查,事发时主机润滑油油位正常,滑油泵运转良好,也未自动切换至备用的滑油泵。

进而检查滑油管系,重点查看各个压力表,发现滑油管系正常,滑油泵后滑油压力正常,自清滤器后滑油压力迅速下降。由此推断为自清滤器故障。

自清滤器为ALFA-LAVAL公司生产的产品,结构见图2。

该自清滤器分为滑油过滤腔和反冲洗过滤腔两部分。

正常工作时,上部的油马达(转速约为10 次/min)驱动配油轴旋转,实现过滤区块循环,达到自清作用例。

反冲洗后,滑油杂质通过放残阀泄放。

故障发生后，检查自清滤器发现其配油轴没有旋转,但手动仍可以使其转动,判断可能是由于滑油脏污引起上部油马达故障卡阻。

滑油脏污时,油马达阻力加大,无法带动配油轴旋转,致使自清滤器丧失反冲洗功能,滤器脏堵,出口压力急剧下降。

# 三、故障应急处理

拆卸、检修自清滤器较为费时,并且拆卸还需船舶停航。

由于船舶在航行中需要短时应急处理,因此暂不拆卸，临时切换至备用滤器，使滑油进机压力恢复正常,起动、运行主机,保证船舶正常航行。

备用滤器的过滤精度低，会导致直径较大的滑油颗粒杂质进人主机,导致主机阻力增加、磨损增大,必须尽快修复自清滤器。

自清滤器除可以通过油马达带动自动反冲洗外，在油马达无法自动运转的情况下，还可使用扳手手动转动配油轴进行手动反冲洗。

作为应急处理方案,轮机长迅速用扳手转动配油轴进行反冲洗。

大约5 min后，自清滤器使滑油进机压力恢复正常。

切换至自清滤器后,主机运行不到10min,再次故障停车。

检查发现,自清滤器油马达再次卡阻,手动反冲洗约5min后,滤器后的滑油压力处于较低值。

由于油马达阻力大,基本无法转动,滤器很快脏堵。

作为应急预案,组织轮机员每隔5 min摇动自清滤器进行反冲洗;主机滑油分油机也立刻重新检修,以达到较好的分油效果。

次日,转动自清滤器的时间间隔延长到约0.5 h一次;第3日,已基本不用再转动自清滤器,故障消除。

# 四、故障探讨

事发后，轮机长检查主机滑油，发现滑油较为脏污。

经过探讨,总结事故成因为:

主机滑油分油机时常报警,未能完全修复,常在报警后将其停止运行,因此主机滑油分油效果不佳;滑油脏污,导致自清滤器油马达阻滞,无法达到自清效果而脏堵;滑油进机压力低，引起主机故障停车。

# 五、结束语

自清滤器具有自动反冲洗功能,按照规定要求对其进行维护,一般不会脏堵。

此次故障是由于滑油分油机未及时修复,导致滑油未正常分离杂质引起。

故障造成轮机人员需时刻人工转动自清滤器,增加轮机部人员的劳动强度。

此次故障，一方面反映船舶轮机部门按章程管理的重要性，要求轮机员必须严格按照轮机维护保养计划进行设备维护保养,而非发生故障再进行抢修。

另一方面,轮机员要增强责任心,加强自身业务能力,有效落实轮机设备维护保养。
