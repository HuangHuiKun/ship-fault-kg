# 导读

柴油机高压油泵卡咬故障是柴油机运行中的一大难题，这一故障不仅频繁发生，而且往往导致严重的后果，包括柴油机功率急剧下降、运行不稳定乃至完全停机，尤其在特种船，柴油机的稳定运行至关重要。因此，高压油泵卡咬问题不容忽视。

# 一、工作原理概述

常规船用柴油机高压油泵的工作原理可以概述为以下几点：

燃油加压：通过柱塞泵将柴油从低压状态加压到高压状态，这一过程发生在高压油泵内部。

精密配合：高压油泵内部由多个精密配合的部件组成，如凸轮轴、滚轮、柱塞等，这些部件协同工作，确保燃油能够按照设定的压力和时机输送到喷油嘴。

定时定量供油：高压油泵根据柴油机的工作需求，定时定量的向喷油嘴提供高压柴油，这一过程的精准控制对于柴油机的性能和燃油经济型至关重要。

图1 高压油泵示意图

以某型号高压油泵工作原理为例，如图1所示，燃油通过高压油泵进油孔B进入泵体和柱塞套筒之间的进油腔C，通过回油孔A流出进行循环。燃油流过套筒的二个孔，充满柱塞头部与出油阀之间的高压供油腔D。凸轮驱动柱塞向上运动，关闭套筒的油孔时，供油腔中压力上升，出油阀开启，然后至喷油器，直到柱塞螺旋槽开启套筒油孔为止。进油腔C通过油槽、柱塞螺旋槽和套筒上的油孔与高压供油腔D相通。当供油腔压力突降后，喷油器和出油阀也随之关闭，柱塞完成其上升行程，不再供油，燃油流回供油腔。供油行程(套筒油孔关闭时柱塞的行程)随柱塞套筒的角度位置变化而变化，通过拉动齿条，使扇形齿圈转动，即可实现对供油量的调节。高压油泵在调速器的控制下，根据柴油机负荷状态将所需的燃油量供给各个气缸。高压油泵的核心部件是柱塞偶件，柱塞和套筒属于精密偶件，是经过严格加工而成的，以某型号为例，其配合间隙约为8~10μm。

# 二、原因分析和应对措施

基于高压油泵工作原理，结合实际工作经验，常见的导致高压油泵柱塞偶件卡咬的可能原因及应对措施如下。

## 1、柱塞偶件产品质量

柱塞偶件为批量生产产品，不排除偶发的加工尺寸超差，会造成柱塞和套筒间隙过小，在高压油泵运行的过程中可能产生卡阻现象。

应对措施：在工厂装配过程中，需要严格把控柱塞偶件间隙，做好间隙记录，确保柱塞和套筒间隙满足设计要求，以某主机柱塞偶件间隙记录表为例，如图3所示。

若柱塞偶件的实际化学、力学、晶相指标不满足设计要求，在高温高压的环境中，容易导致柱塞发生相对较大的形变而造成卡阻或咬死。

应对措施：应采购满足设计要求的原材料，并要求配套单位提供相应的合格证;对柱塞套的热处理，必须经过检验合格后进入下一道工序，并做好检测记录，如表1 所示。监管方必须对上述工序进行检验，保证柱塞偶件的实际化学、力学、晶相指标合格。

套筒定位螺钉孔若加工不当，定位螺钉孔背面有轻微凸起，致使柱塞偶件的配合间隙变小，润滑油膜无法建立，产生干摩擦而卡阻或咬死。

应对措施：严格工艺控制，在加工过程中，应严格按照设计图纸和加工工艺规程进行操作，确保加工精度和表面质量;加强质量检验，在加工完成后，应对定位螺钉孔进行严格的质量检验，包括尺寸测量、形位公差检查及表面粗糙度测试等，确保所有指标均符合设计要求;建议采用高精度的数控机床和其他加工设备，以提高加工精度和稳定性。

## 2、装配质量

良好的装配质量是确保高压油泵正常工作的基础，对高压油泵的性能与寿命具有深远的影响，它是确保油泵正常运转、维持发动机高效稳定工作的关键环节。精确的装配能够确保高压油泵内部各部件之间的紧密配合，避免由于间隙过大或过小而导致的磨损、卡滞、漏油等问题。压油泵的柱塞和套筒属于精密偶件，要求具有较高的精度、光洁度，以及良好的耐磨性，柱塞和套筒匹配研磨后，应达光顺、无毛刺的效果。如果柱塞外圆或柱塞套中孔存在翻边毛刺等将导致柱塞偶件卡咬，如图4所示。

图4 某高压油泵柱塞偶件头部毛刺检查

应对措施：在安装高压油泵时，必须严格按照安装规范进行操作,确保每一步都达到精确的要求。在装配质量监管中,应该着重监管装配工具的精度、准确对位各部件、合理设置紧固力度等，只有安装装配质量过关，才能确保高压油泵在安装后能够发挥出最佳的性能，为柴油机提供稳定可靠的燃油供给。

## 3、润滑系统质量

良好的润滑是防止柱塞和套筒卡咬的关键，高压油泵的润滑通常依靠柱塞和套筒间的微小间隙所流入的滑油进行,滑油不仅能带走大部分燃油杂质，还能起到冷却和润滑的作用。如果滑油质量低劣或脏污，或者润滑通道堵塞，就会导致柱塞与套筒之间干摩擦，从而发生卡咬。

应对措施：对柴油机滑油定时检测，如超过标准指标，则择机进行换油，柴油机润滑油换油指标要求详见GJB3714--99《舰艇主要润滑油换油指标》。

## 4、燃油质量

燃油质量是影响高压油泵卡咬的重要因素之一，由于柱塞偶件的配合间隙很小，若使细小杂质进入柱塞和套筒之间，会造成柱塞拉毛、卡阻或咬死，对柱塞和套筒造成磨损和拉伤，从而使高压油泵不能满足供油需求。

杂质的影响：燃油中的硬性颗粒(如金属屑、沙粒等)会在高压油泵高速运转时划伤柱塞和套筒的表面，形成拉痕和凹坑。这些损伤不仅加剧了偶件的磨损，还可能成为新的杂质来源，进一步恶化燃油系统的清洁度。

水分的影响：燃油中的水分会在高压油泵内部形成水垢，堵塞油孔和通道，影响润滑和冷却效果。此外，水分还可能腐蚀高压油泵的内部零件，降低其使用寿命。

应对措施：在船舶建造阶段,要求总装厂对柴油机外部燃油管路进行串油，串油后管路内的燃油应做颗粒度检验，使其满足柴油机使用要求。判定标准可参考ISO 4406- 1999《液压传动油液固颗粒污染等级》。在使用过程中，按照滤芯的更换要求，定期对燃油系统中滤器滤芯进行清洁，对管路内燃油定期取样检查，如发现有杂质或者油水混合严重，立即用燃油分油机进行分油。

## 5、使用操作不当

操作不当也是导致高压油泵卡咬的常见原因，在柴油机启动和停车过程中，如果操作不当(如突然加大油门、急停等)，会导致高压油泵内部压力急剧变化，对柱塞和套筒造成冲击和磨损。以油门初始位置设置过大为例，当改变油门大小时，高压油泵油门齿条带动齿圈转动柱塞，以改变柱塞有效供油行程和泄油行程比例(柱塞总行程不变)。较小的泄油行程比例使得在柱塞有效行程内，泄油槽底部获得燃油供应的油量更少，润滑和冷却状况更差，因此油门初始位置较大的高压油泵更容易发生粘咬。又例如加大负载速度过快，柱塞偶件的工作温度过高，燃油温度变化过快，金属在热胀冷缩应力的作用下，同样会破坏柱塞和套筒之间的油膜建立，产生干摩擦而卡阻或咬死。此外，长时间超负荷运行和频繁启动也会加速高压油泵的磨损和老化。

应对措施：根据设备参数及实际使用需求，合理设置油门初始位置。柴油机启动后，空载运转一段时间，待各系统压力、温度全部正常后按程序文件要求逐步增加负载。

# 三、结束语

柴油机高压油泵卡咬是一个复杂的问题，涉及多方面的原因，总体的应对措施可以总结为严抓原材料选用、严控装配质量、加强润滑系统的维护、提高燃油质量、规范操作与维护这五大方面。未来随着柴油机技术的不断发展和高压油泵设计的不断优化，有理由相信，高压油泵卡咬的问题将得到有效的解决。同时也应该持续关注这一领域的研究进展，不断探索新的预防和维护方法，为柴油机的可靠性和使用寿命提供更有力的保障。总之，本文的探讨不仅加深了对柴油机高压油泵卡咬现象的理解，也为今后的预防和维护工作提供了有益的参考和指导。
