# 导读

船舶主推进系统的正常运行是保障船舶正常航行的重要部分，对平台系统的可靠工作意义重大。

对于采用以柴油机作为动力源的主推进系统柴油机，主推进系统的正常可靠运行尤其关键 [1]。

随着电子技术的发展，柴油机装置较多采用电子管理系统，因此，对柴油机运行过程中的各项参数进行监控管理，实现安保和控制相关功能，可以保障柴油机的可靠运行和寿命。

电子管理系统出现故障时，控制和安保将部分或全部失效，影响主推进系统的正常运行或船舶运行安全 [2-4]。

因此，柴油机电子管理系统的可靠运行特别重要。

# 一、主控安保单元

## 电路原理及元器件功能

某船主控单元和安保单元的电源架构见图1。

图1 主控单元和安保单元电源电气原理图

主、备电源通过电源滤波器后分别进入接线箱，功率二极管将主、备电源正极合为一路，通过保险丝后输入主控单元，主、备电源的正极在接线箱内分别串联保险丝，两路电源同时输入安保单元。

主、备电源的负极在进入接线箱后，使用接线端子进行短接，因此，主控单元和安保单元共用电源负极。

主控单元和安保单元电路板电源端口的原理见图2。

图2 主控、安保单元电源防护电路原理图

根据系统的电源架构，主控单元使用主、备电源合并后的电源，并进行实时监测；

安保单元的电源线+24 V_S1连接主电源正极，另一根电源线 +24 V_S2 连接备用电源正极，接地线GND_S1和GND_S2在接线箱处短接在一起。

安保单元内部使用二极管将主、备电源合并为一路电源为其电路供电，安保单元同时对主电源、备用电源和合并后的电源进行实时监测。

为提高柴油机电子管理系统的抗扰度，应对感应雷击、大功率感性负载在电源线上产生的浪涌瞬时骚扰，各控制单元电源入口处均采用瞬态电压抑制器（Transient Voltage Suppressors, TVS）进行浪涌防护。

主控单元中，TVS元器件D57和D61用于电源线对机壳过压防护，D59用于电源正负极之间过压防护；

安保单元中，TVS元器件D57、D61、D77和D81用于电源线对机壳过压防护，D80和D82用于电源正负极之间过压防护。

电源线防护用TVS的型号为SMCJ30CA，最大可承受1 500 W瞬时脉冲，反向击穿电压为33.3 V～36.8 V，钳位电压为48.4 V；

电源正负极间过压防护用TVS型号为5KP33A，最大可承受5 000 W瞬时脉冲，反向击穿电压为36.7 V～40.6 V，钳位电压为53.3 V。

TVS击穿电压均高于电子管理系统工作电压范围（18 V～32 V），板卡保护分析显示配置合理。

电子管理系统通过了线对地1.0 kV和线对线0.5 kV的第三方浪涌抗扰度测试。

# 二、故障现象描述

柴油机主控单元数据出现异常。

检查发现，电子管理系统接线箱内主控安保箱备用电源保险丝熔断，主控安保箱内主控单元、安保单元电源输入端口防护用TVS外壳有明显烧蚀痕迹，烧蚀元件编号为主控单元D57和安保单元D77、D82，见图3中方框所标识的元器件。

图3 主控、安保单元电路板元器件烧蚀

拆卸电路板后，检查发现电子管理系统接线箱内安保单元主电源保险丝熔断，安保单元主电源正极对外壳短路，电路板其他表面无烧蚀痕迹。

更换修复的主控安保箱后，再次进行复装和上电检查，发现电子管理系统绝缘正常，各项参数功能正常。

# 三、故障原因排查

## 1、故障主控单元和安保单元检查情况

检查情况如下：

主控单元D57元件、安保单元D77和D82元件有明显烧蚀现象，其他元件外观正常；

将烧蚀元件拆除，主控单元D57元件焊盘有烧蚀损伤，安保单元D77元件焊盘烧蚀严重并完全从印制板脱落。焊盘损伤情况见图4。

图4 主控、安保电路板焊盘损伤

拆除3处烧蚀元件后，分别对主控单元和安保单元板卡进行功能和性能测试，测试结果显示板卡功能和性能正常。

对3个烧蚀元件进行失效分析，初步分析结果显示：

主控单元正极对地防护TVS（D57）外观损坏严重，内部芯片碎裂且有明显烧伤现象；

安保单元正极对地防护TVS（D77）外观损坏严重，芯片完全碎裂；

安保单元正负极间防护TVS（D82）受热应力影响外壳产生裂纹，内部焊料融化，芯片电性能正常。

## 2、故障安保单元检查情况

安保单元印制板外观无异常烧蚀痕迹，通过测量确认D57的TVS击穿短路。

将D57拆除后，对应焊盘无烧蚀现象，见图5。

图5 安保电路板 TVS 击穿焊盘情况

对安保单元板卡进行功能和性能测试，测试结果显示板卡功能和性能正常。

上述检查结果显示，TVS烧毁的原因并不是电路板内部故障。

# 四、故障原因分析

开展主机电子管理系统输入电压特性检查，对充放电装置的输出电压进行测试分析。

用示波器对充放电板输出电压进行测试，测试结果显示，充放电板输出电压和尖峰电压均满足相应船舶设计规范。

为找到烧蚀的具体原因，进一步开展排查。

根据主控单元和安保单元电路板TVS安装于正极对地与负极对地之间的设计原理，用示波器测量充放电板输出单相对地电压，其峰值电压为38.6 V，超出TVS击穿电压。

分析表明，正极对地和负极对地时可能造成TVS烧蚀。

根据本船设计要求，电力系统为浮地设计，相间电压一般不作考核要求。

单极对地电压成方波的主要原因为充放电板的绝缘监测仪工作产生的脉冲电压。

绝缘仪的绝缘监测工作原理简化图见图6。

图6 直流绝缘监测等效原理图

根据人机交互单元记录的历史数据和充放电板输出电压检查情况，总结如下：

1）安保单元备用电源正负极防护TVS发生过压击穿现象；

2）电源防护TVS击穿为外部原因引起，板卡其他功能正常；

3）安保单元TVS击穿烧毁事件早于主控单元TVS击穿。

根据检查结果分析柴油机主控单元和安保单元TVS击穿的可能原因为：

当电源正极对机壳出现高压时，正极对机壳的TVS首先被击穿，随后正负极之间的TVS被击穿。

由于TVS可承载发热功率小，因此TVS首先被烧毁短路，电源正极串联的保险熔断，正负极之间的TVS从反向击穿钳位状态退出，但是由于时间超出TVS尖峰电压承载周期，能量较大，故发生外壳烧蚀现象。

安保单元备用电源保险丝熔断后，主控单元由系统主、备电源合并后的电源供电，因此任一电源再次出现短时过压时，将会导致电源正极对地TVS的击穿过流烧毁。

综上所述可以推断出，TVS击穿的故障原因是正极对地电压超出元器件的击穿电压。

# 五、TVS 击穿影响分析

电源模块分别对电子管理系统喷射控制单元、主控单元、安保单元、输入输出单元（IO单元）和人机交互单元等单元供电，针对上述单元分析TVS击穿烧毁后对系统功能的影响。

1）喷射控制单元承担燃油喷射等控制功能，电源正极对地TVS击穿烧毁会导致其专用的电源线保险丝熔断，从而板卡失电停止燃油喷射，柴油机停车。

2）主控单元承担增压系统控制、监测和报警，电源正极对地TVS击穿烧毁会导致其专用的电源线保险丝熔断，从而板卡失电无法实现相继增压控制，柴油机将限制工况运行，某些工况下因供气不足导致柴油机停车。

3）安保单元承担柴油机安全保护功能，实现自动停车、降功率报警等功能。

采用主、备2路电源供电，仅1路电源正极对地TVS击穿烧毁后，安保单元仍然可以正常工作，而当2路电源正极对地TVS均击穿烧毁后，安保单元失电失去安保功能。

4）IO单元承担柴油机监测、报警功能，电源正极对地TVS击穿烧毁会导致板卡失电，造成排温、水压等状态信号无法实时监测和显示。

5）机旁人机交互单元承担柴油机的机旁操作、显示和报警，在失电情况下会影响机旁显示、报警功能，同时会对增压、辅助系统控制功能操作产生影响。

6）由于电子管理系统在接线箱内将两路电源的负极进行短接，因此不同板卡电源为共负极设计，当任一板卡电源正极对地TVS击穿烧毁后，电源正极对地短路，使系统绝缘降低。

系统绝缘降低不会影响系统的正常运行。

综上可知，TVS击穿烧毁时，柴油机将停车或只能保持一定程度的运行，运行时将失去相关安全保护或远程控制功能。

因此，可以作以下判断：

停机或失去安保等功能虽然不会对柴油机造成致命损伤或发生其他有害情况，但会影响船舶正常航行。

# 六、解决方案

在充放电板和柴油机电子管理系统中增加隔离电源箱，供电原理图见图7。

图7 隔离电源箱与主机控制系统供电原理示意图

隔离电源箱中核心部件为DC/DC隔离电源模块，该模块的供电输入范围为DC 18 V～36 V，输出电压恒定为28 V，额定输出功率为500 W，输入侧与输出之间绝缘电压为1 500 V，输入对地绝缘电压为1 500 V，满足电子管理系统的供电要求。

针对增加隔离电源箱后的系统供电原理，开展以下单故障模式分析：

1）当隔离电源箱输入侧正极或者负极对地绝缘降低时，由于DC/DC隔离电源采用变压器隔离方案，输入侧电源线对地绝缘异常不影响输出侧绝缘。

2）当隔离电源箱输入侧正极或者负极对地电压小于1 500 V时，由于DC/DC隔离电源采用变压器隔离方案，输入侧电源线对地电压无法施加到输出侧。

3）当隔离电源箱输入电压大于36 V时，DC/DC隔离电源过压烧毁，输出侧无电压输出，电子管理系统不会造成损坏。

4）当电子管理系统对地绝缘降低时，DC/DC隔离模块稳定输出电压28 V，电子管理系统正极对地TVS和正负极间TVS两端电压为28 V，低于TVS击穿电压值。

增加隔离电源箱对供电电源进行隔离，可以避免上述故障模式导致的TVS击穿烧毁。

柴油机电子管理系统允许的输入电压范围为18 V～32 V，隔离电源箱最高允许输入电压为36 V，因此，增加隔离电源箱后，可提高系统的最高输入电压范围，提高系统对外部电压的耐受能力，同时减小外部电源变化对系统的影响，提高系统的可靠性和安全性。

# 七、结论

在船舶主推进系统的电子管理系统各单元模块设计过程中，根据外部供电条件，增加隔离电源箱，对供电电源进行隔离，可以避免上述故障模式导致的TVS击穿烧毁现象。

对于主推进系统、电力系统、损管监控系统等重要系统设备，须重点从保证系统运行安全方面进行设计。

增加隔离电源以减小过电压等因素的影响，增强设备内部各控制板卡的可靠性。

双电源设备须隔离保护，将电源模块与控制板卡分离，提升维修性。

本文针对某船主推进柴油机的主控单元和安保电源TVS外壳烧蚀现象开展了故障排查和原因分析等工作。

原因分析结果表明，故障是主机主控安保箱电路发生TVS击穿引发的。

据此提出了对应的解决措施，开展单故障模式分析，最后在实船上进行了验证，证明了解决措施的有效性。
