# 导读

针对某船用高速柴油机气门出现断裂问题，我们通过对柴油机故障现象、相关损坏零部件宏观和微观方面进行大量分析，找到了导致柴油机损坏的首断件，确定了气门断裂的原因为疲劳断裂，也确定了疲劳断裂的原因是因为气门焊缝位置存在有较大夹渣缺陷，因此需要纠正后期生产缺陷。

# 前言

某 v 型柴油机用于船用发电机组，一直以来工作良好。

在执行某次出海作业任务时，主配电室值班人员听到后辅机舱传来异响，立即遥控停机检查，发现机组用柴油机B1 缸机体下方破损，柴油机报废，损坏位置见图1。

图 1 柴油机B1缸机体下方破损

# 一、柴油机拆检

工程师对损坏的柴油机进行了拆检，发现A1缸排气门断裂，断裂后的阀杆留在气门导管内，进、排气门推杆弯曲，A1 缸缸套、活塞碎裂，活塞碎块掉入油底壳中，A1 缸连杆大端仍在曲轴连杆轴颈上，杆身弯曲变形，卡在机体B1 缸下方破损处，B1 缸缸套下边缘碎裂，活塞裙部被打碎。

通过对曲轴、连杆进行尺寸复查、探伤以及对气缸盖进行水压试验，没有发现异常情况。

# 三、分析与讨论

交变载荷的运动部件最常见的损伤形式是疲劳，柴油机存在交变载荷,故障失效分析的关键是要找出首断件及裂纹起裂部位。

裂纹源在失效件中是关键点,柴油机长期使用后发生故障，首断件断口上存有使用过程损伤积累的特征。

宏观分析，失效排气门杆部上侧断裂位置位于排气门杆部和盘部摩擦焊的位置。

在扇形区域附近能观察到疲劳贝纹线特征,离扇形区域越近贝纹线间距越大。

可以初步推断断裂方式为疲劳断裂，断裂起源于扇形区域的对于位置。

微观分析发现，断裂正好起源于断面黑色扇形区域，位于构件内部。

断口约有80%以上区域为疲劳扩展区，有明显的疲劳辉纹特征。

在漩涡区实现最后交汇，漩涡区为韧窝特征，与其匹配的断口机械损伤严重,摩擦得比较光亮，除摩擦痕迹外未发现其它明显的特征。

在该断口上记录断裂过程中的损伤积累特征，应为首断件。

杆部下侧断口的盘部一侧机械损伤严重,摩擦光亮，未发现明显的断裂特征。

在断口的表面位置都有明显的摩擦痕迹,在断口的中间位置断裂特征比较相近,未发现明显的冶金缺陷。

微观分析，断口处边缘位置有摩擦挤压痕迹外，其它区域均表现为沿晶型韧性断裂特征。

该断裂特征应该为过载断裂，故而该位置不应为首断位置。

活塞断口宏观呈现正常灰白色,有明显的机械损伤和少量塑性变形，微观呈现解理断裂特征。

缸套断口宏观观察没有明显变形，呈现正常的灰黑色，微观呈现解理断裂特征。

活塞和缸套的断裂均属于一次性过载断裂，因此不是首断件。

化学分析发现,排气门杆部的化学成分基本符合技术指标的要求。

力学分析发现，排气门杆部力学性能满足技术指标要求，盘部高温拉伸性能也都满足技术指标的要求。

金相分析发现,排气门无论是断口附近还是远离断口位置金相组织均表现为回火索氏体+颗粒状碳化物。

失效排气门杆部的断口附近和远离断口位置的D类夹杂物级别较低,但是C类夹杂物较严重,并且断口附近的C类夹杂物正好对应于断面中的扇形黑色区域。

通过能谱分析，两处位置的元素分布也较一致,从而可以初步确定，杆部断裂的起源主要是由于夹杂物的存在。

焊缝中夹杂成分与基体夹杂物成分一致，且夹杂物连续分布在基体、热影响区和焊缝中，焊缝和热影响区夹杂物有明显的变形，夹杂物主要为Ca，F等元素。

通过对夹杂物类型进行分析,可以推断焊缝中的夹杂物是由于冶炼过程中引入的夹渣，其在后续处理过程中未完全清除，在摩擦焊时将其从基体引入至焊缝中，从而引起焊缝缺陷。

# 四、结论

根据上面的实验和综合分析讨论可以得出以下结论：

a. 排气门杆部上侧为首断件，排气门下侧盘部、活塞、缸套均为过载断裂，是后断件。

b. 排气门的断裂模式为疲劳断裂，源区位于摩擦焊位置内部的夹渣处。

c. 排气门发生疲劳断裂的主要原因是由于焊缝位置较大夹渣的存在导致其抗疲劳性能下降，从而引发断裂。
