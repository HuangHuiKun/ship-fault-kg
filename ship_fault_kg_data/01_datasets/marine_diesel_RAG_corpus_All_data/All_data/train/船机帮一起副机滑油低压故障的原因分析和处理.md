# 导读

某轮副机，型号安庆-大发6PSHTC一26H，额定输出功率900 kW，滑油系统由自带齿轮滑油泵、多管式冷却器、凹口金属线形双联滤器等组成，使用滑油牌号MOBILGARD300，压力0.2～0.3 MPa，温度50～60℃。

# 一、故障现象

该轮No.3副机厂修吊缸，6月25日出厂后不久，滑油压力异常：

停机时间越长。

起动滑油油压越高(0.4—0.6MPa)；

运行中逐渐降低，启动使用后1小时，压力降到0.2 MPa；

每天2次清洗滤器，油压仍难保持0.2MPa。

# 二、查找原因

9月15日1230，滑油压力0.19 MPa。

停机：

拆洗滑油滤器(当日 0130清洗过)。

见内外表面较干净，外表面粘附极少量金属粉末；清洗装复使用，半小时滑油压力降至0.21 MPa，1小时降至0.2MPa，2小时降至0.19 MPa。

再次停机:

换新滑油调压阀和调温阀后运行，故障依旧，停机待查。

9月16日，检查曲拐箱各部件：

连杆大端轴承和主轴承外观检查。

连杆大端轴承螺栓和主轴承螺栓紧固检查，均未见异常；

拆出六个缸连杆大端轴承下瓦检查。

见轴瓦磨合良好：

手摇泵泵油。

检查曲拐箱及凸轮轴箱各注油点出油情况，未见异常。

9月17日，解体自带滑油泵(齿轮泵)，用压铅法测量，主动齿轮轴向间隙0.7mm，从动齿轮轴向间隙0.41mm，设计值0.1～0.25mm，说明泵浦端向间隙超过使用极限。

9月18日，清洁检查油底壳，确认滑油泵吸入滤器和吸入管路通畅，吸口管路法兰接头紧固。

系统滑油换新、滑油滤器清洗后投入运行，故障依旧。

由此认为，滑油泵过度磨损是故障主要原因。

立即申领滑油泵备件。

9月23日，滑油泵备件供船。

更换后起动该机投入使用，滑油压力调节至0.4MPa运行，10分钟油压降至0.3MPa以下，1小时降至0.21MPa。

为了确证油泵正常,利用滑油泵出口温度表A接口加装压力表D(量程0～1MPa)，指示油泵出口亦即冷却器前滑油压力,滑油压力表B指示的是滑油进机压力亦即冷却器和滤器后压力，如图1。

起动使用该机，观察发现：

压力表B(系统滑油压力表)指示0.35MPa时，压力表D指示0.68MPa;

压力表B降至0.2MPa时。

压力表D压力反而升到0.88MPa。

由此可见,是滑油滤器和／或冷却器脏堵导致滑油低压，原因是滑油严重脏污。

那么，系统滑油脏污为何如此严重呢?

原来是喷油器弹簧断裂造成的。

该机厂修吊缸。

6个缸喷油器弹簧全部换新，使用的是非正规厂家提供的备件，材质差，易断裂，使用寿命一般不超过500工作小时，再度更换这种备件当然还是如此。

喷油器弹簧断裂，喷进燃烧室的燃油雾化不良，除了烟囱冒黑烟、柴油机热效率差、油耗增大外，还导致未燃烧的柴油和未完全燃烧生成物被刮进曲拐箱，污染系统油，高温下产生大量絮状物粘附在冷却器油侧和滤网。

恶化热交换效果(海水温度越低，絮状物越粘稠，冷却效果越差，海水温度低于20℃时，滑油出机温度竞达85℃)，致使滑油进一步升温，加速滑油变质的进程。

终至缩小油流通道，增加阻力，造成滑油低压。

# 三、故障现象分析

## (一)停机时间越长，起动滑油油压越高

停机时间越长。

混在油底壳内滑油中絮状物沉淀越多；副机起动后油泵吸入絮状物，因其粘度大而油压高。

## (二)换新油、清洁油底壳后，仍然滑油低压

清洗滤器，采用轻柴油浸泡清洗后再用压缩空气吹除的方法，清洗不彻底，因为：

絮状物粘附力强，轻柴油浸泡清洗难于溶解，压缩空气吹除效果差；

絮状物呈透明状肉眼难于辩认其清洗效果。

这使得查找故障原因多走不少弯路。

## (三)滤器表面粘附少量金属粉末(白合金)

该机于7月份由于燃油质量缘故飞车机损，主轴瓦、连杆大端轴瓦、曲轴等全部烧毁，所以油底壳残留一些白合金粉末。

# 四、处理措施

## (1)喷油器弹簧全部换新

喷油器偶件弹簧断裂是引发此故障的根本原因。

及时向公司机务部门反馈备件质量情况，申领原装进口弹簧备件。

备件到船后。喷油器偶件弹簧全部换用新品。

## (2)滑油冷却器清洗

冷却器整体拆出清洗：

油侧。

使用AMEROID DC、623C等化学剂，空气泵循环，清除油垢，清水冲清，风干；

海水侧，使用AMEROYAL化学剂，浸泡，软化粘附在热交换表面的水垢。

## (3)滑油滤器清洗，改用623 C清洁剂。

## (4)清洁油底壳，换新系统滑油。

经以上处理，该机供电，滑油压力正常。

再换回原来滑油泵运行。

油压可保持0.28MPa。

但是，滑油进机温度虽然降低20℃，仍高于厂家推荐值，建议以后更换滑油冷却器，因为：

热交换面积，只有9m²，而推荐值是11m²；

解体化学清洗时．碰伤油腔内的部分挡板，减少了流通面积。

# 五、心得

## (1)查找故障原因，要从全局出发

这起故障，查找故障点的最便捷方法，就是安装压力表D：

①若能全面审视副机滑t由系统，很容易得知滑油低压的两个故障点是提供压力的油泵和从油泵到进机的管路；

②只要知道油泵出口压力，就能确定故障点。

这需要考虑整个滑油循环，不能局限于副机本身。

## (2)思维惯性

絮状物，粘附力强，轻柴油难以溶解，浸泡清洗效果不佳，压缩空气吹除效果差；

它又透明，肉眼很难辩识清洗效果。

固守多年的轻柴油浸泡清洗滤器和目视检查清洗效果等传统。使查找故障多走不少弯路。

## (3)建立船舶向公司反馈备件质量的制度

为了公司机务订购备件时正确选择供应商，轮机长及时向机务反馈备件质量情况应成为制度。

若船员及时向机务反馈喷油器弹簧质量问题，公司及时订购优质备件供船。

完全可以避免这起故障以及由此引起大量人力、物力浪费。
