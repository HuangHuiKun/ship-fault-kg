# 导读

了解内燃机的人都知道，燃油系统是内燃机的重要组成部分，针对柴油机来说燃油系统的高压油泵、喷油器中的三大偶件更是组成柴油机心脏的三大支柱。

6135AK-6型柴油机，它的喷油泵是B系列强化喷油泵，带有冬季启动加浓装置，喷油泵的柱塞分为11、11.5、12mm 等多种;出油阀的直径为7mm，喷油器柱塞副有437和435两种，跟B型加浓泵配合的偶件为437，针阀升程为0.45±0.05mm，喷射压力为175+10kgf/cm²，喷束锥角15°~20°。

现在有很多同事及承修单位在校验喷油器压力时一味追求燃油雾化度、燃烧效率及发动机声音好听而将喷油器压力校得过高（校验压力达到220+10kgf/cm²），出现了喷油泵十字连接盘断裂及喷油泵和喷油器使用周期短（即柱塞副早期磨损）等现象。

# 亲身经历谈一下喷油器压力过低的危害

去年5月，在某现场由于操作手反映发动机冒黑烟、油耗增大、曲轴箱润滑油面上升，分析原因可能为喷油器压力低的故障，我带了一组喷油器和30升机油到现场，断缸时发现1、3、5、6缸工作不好，拆卸该发动机6个喷油器后发现1、3、5、6缸偶件均有不同程度的滴漏油情况，其中1、3、6尤其明显，拆卸后此三缸喷油器水套内满是柴油。

对该组喷油器进行校验压力均为140+ 10kgf/cm² 以内，由此可见上述症状就是由于喷油器喷射压力过低，燃油雾化不良，油雾颗粒变粗、滴油甚至成流，单缸或多缸喷油器偶件大量滴油，液态的燃油通过缸套和活塞环的侧隙漏入曲轴箱后造成，在平时巡检及动态时会看到机油液面上升甚至满尺。

同时喷油压力过低造成雾化不良的燃油，射程缩短不能贯穿整个燃烧室从而使燃油与缸内的空气混合不良，导致柴油机排气排黑烟，气缸内积碳增加发动机不易启动等现象。

# 再来看看喷油压力过高的危害

首先喷油器喷射压力过高造成喷油泵供油负荷增加柱塞副间的内漏损失增加：柱塞副正常的配合间隙为1.5～2.5微米，在泵油行程时柱塞副发生弹性变形，副间隙膨胀到4～6微米至6～8微米，若喷油压力过高柱塞副间的弹性变形加剧使柱塞与柱塞套内漏损失增加，油液在柱塞副间运动时的液体冲刷现象增加，可能停留在副间隙间的机械杂质数量增加，在泵油行程结束后柱塞副间隙恢复，加剧柱塞偶件的磨损。

同时还会使高压油泵的滚轮体、调整垫片、凸轮等机件的磨损，凸轮如果磨损过度还会使输油泵活塞往复行程长度缩短引起输油泵供油量的下降。

其次，喷油器喷射压力过高，导致喷油器上部调压弹簧负荷增大，引起弹簧弹力减弱甚至折断，同时针阀与针阀体密封锥面间的机械冲击和油液冲刷现象加剧，加速锥面间的磨损甚至涨裂高压油管（我单位设备多次出现此现象）；

同时针阀体和针阀中部的导向部分内漏损失增加致使喷油器回油量增加喷油量减少从而影响可燃混合气的形成。

第三，喷油量喷油压力高使燃油雾化更细碎便于柴油分子与空气混合形成可燃混合气，但是如果喷射压力过高的话，致使部分燃油直接射至气缸壁反而与气缸内的空气混合不良，导致燃油颗粒不能完全燃烧使发动机出现敲击声，长期如此还会影响缸壁和活塞环的正常润滑。

# 综上所述

6135AK-6柴油机喷油器正常喷油压力应保持在175+10kgf/cm²喷油器喷油的压力调整应依据喷油泵、喷油器和燃烧室的结构形式，以及发动机的工况来综合调整不可随意自行调整过高或过低！
