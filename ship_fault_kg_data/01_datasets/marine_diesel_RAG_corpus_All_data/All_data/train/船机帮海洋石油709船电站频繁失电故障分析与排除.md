# 导读

文章对某电力推进DP动力定位船舶电网经常发生的跳电现象进行了系统分析，并根据故障现象判断出故障产生的原因，提出了改进方案，最终将问题解决。

# 一、故障描述

海洋石油709船为电力推进型海洋石油工程船舶，主电力系统为6 600V中压，3台中压发电机，2台中压变频驱动吊舱式电力推进器，采用SIEMENS的SIMOS PMA71电力管理系统。

1) 709船从2008年4月到2011年5月，共发生11次全船失电故障(单机运行、并机运行都出现过)，给生产带来极大影响，甲方欲停租；

SIEMENS给出的解决方案是系统全面升级改造，费用150万美元，工期45天，施工期间船舶需停航、解租，该船日租金40万元，如按SIEMENS方案经济损失达2千万元，影响工程进度等间接损失难以估量；

2) 这些故障都是发电机主开关跳闸TRIP和原动机急停SHD，两者相伴出现，即主开关跳闸后原动机必停机，原动机紧急停必然伴随主开关跳闸；

3) 并机运行时，如NO.2机因故障主开关跳闸和原动机急停，NO.3也会出现主开关跳闸和原动机急停(如图1所示)。

# 二、故障原因分析

电力推进型海洋石油工程船舶与远洋船舶电站管理系统有非常大的区别。

目前有西门子、ABB等品牌。

出于对原动机的保护，当并联运行主发电机当中某一台发生严重故障时，电力管理系统会发出TRIP(发电机主开关跳闸)和SHD(原动机急停)引起TRIP和SHD的原因很多。

主要有如下几个方面：

根据11次跳闸的PMS记录和分析，我们将709船停机跳闸故障归结为两类：

一类是出现SHUTDOWN：DE—EXITATION、BREAKER TRIP记录：该类故障是由AVR故障引起的，更换AVR即恢复正常，此类故障经西门子工程师多次修理后，情况有所好转；

另一类是出现SHUTDOWN、BREAKERTRIP记录：该类故障出现后，再次启动又正常，警报系统无故障记录。

更换完AVR模块之后出现的4次故障即为这种类型。

根据船舶实际发生全船失电时电力管理系统PMS报警现象，进行全面分析，怀疑是由安保系统引起的原动机紧急停车SHD。

因为报警系统没有引起相关SHD的信号记录，进而确定是发动机安全保护系统出现的误动作。

又因全船失电后短时间内又能再次启动，并且运行正常，所以判断该误动作信号也是短暂的。

因此，我们认为是NO.2机组原动机安全保护系统及其相关电路产生了短暂的原动机紧急停车SHUTDOWN误动作信号，导致了全船多次停机跳闸故障，这是根本原因。

该安全保护信号由发电机安保箱产生，然后送机旁控制箱，在机旁控制箱内又进行了逻辑组合，再分别送PMS和发电机主开关控制电路(如图2所示)。

# 三、故障的排除

根据以上信号流程，首先作如下工作：

1) 检查并紧固SHUTDOWN和BREAKER TRIP的所有信号传递线路；

2) 考虑到在机旁控制箱内K1、K5常闭触点串联产生SHD信号，如果振动使K1、K5常闭触点接触不良，也会产生SHD误信号，故将K1、K5换新，更换时PMS出现SHUTDOWN报警；

3) 检查并紧固NO.1、NO.2,NO.3安保电源箱，发现NO.3安保电源箱有线松动，需紧固；

4) 电子调速器产生BREAKER TRIP信号，但不产生SHUTDOWN信号，对该部分电路进行检查，未见异常。

以上修理后，NO.2发电机再次出现停机跳闸，经反复研究，决定：

在SHUTDOWN信号，传递的终端加装一个2s的时间继电器，以便过滤掉短暂的SHUTDOWN误信号，正常的SHUTDOWN信号会推迟2s起作用。

而后该船电站频繁失电故障得以排除。
