# 同步发电机与晶闸管可控励磁装置配合的常见故障与检修方法

## 解答

随着电子技术的发展和船舶电气设备对船舶电站供电品质要求提高，为了克服不可控相复励调压器控制精度不高的缺点，在20世纪70年代就引入晶闸管励磁装置。

由于半导体器件惯性小、体积小、重量轻、成本低、易于系列化，晶闸管励磁装置是属于闭环调节系统，它的静态性能好，调压精度高。

但由于是先出现电压偏差后调整，因此其动态特性较差。

其晶闸管励磁装置主要有测量比较电路、移相触发电路、晶闸管主电路、起励和保护电路等组成。

其常见故障和检修方法见下表：

## 故障现象

### 发电机转速已达到额定值，但不能建立起电压

#### 故障原因

1. 没有剩磁或剩磁能量不足
2. 励磁回路开路
3. SCR被击穿或开路
4. 控制起压电路故障

#### 处理方法

1. 用外部直流电源进行充磁
2. 检查从SCR到励磁绕组的连接是否有松动或断路及励磁绕组本身是否有断路
3. 检查、更换击穿或开路元件
4. 检查起压电路

### 发电机电压低于额定电压

#### 故障原因

1. 检测回路故障
2. 比较回路故障
3. 触发控制回路，触发脉冲后移
4. SCR有开路
5. 转速太低

#### 处理方法

1. 检查测量回路输出电压
2. 检查比较回路输出电压
3. 用示波器检查脉冲与输入电压关系是否正确
4. 检查SCR的工作状态
5. 提高转速到额定值，并校核频率

### 发电机电压高于额定电压

#### 故障原因

1. 检测回路故障
2. 比较回路故障
3. 触发控制回路，触发脉冲前移

#### 处理方法

1. 检查测量回路输出电压
2. 检查比较回路输出电压
3. 用示波器检查脉冲与输入电压关系是否正确

### 发电机在运行中突然不发电

#### 故障原因

1. SCR被击穿
2. 励磁回路开路
3. 无触发脉冲
4. 灭磁控制回路故障

#### 处理方法

1. 检查SCR，更换损坏的SCR
2. 检查从SCR到励磁绕组的连接是否有松动或断路及励磁绕组本身是否有断路
3. 检查触发控制电路
4. 检查灭磁控制电路

### 当负载增加

#### 故障原因

1. SCR有一相开路
2. 有一相SCR无触发脉冲

#### 处理方法

1. 检查SCR是否有开路
2. 检查触发开展电路
