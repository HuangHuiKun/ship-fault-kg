# 导读

柴油机在工作中不仅应该经济，而且还要耐用，以保证长期运转而不需要修理。

这除了要求本身材质、构造、合理维护外，也决定于所用燃料的品质。

在燃料品质中起决定作用的是燃料的腐蚀性。腐蚀性是指柴油对金属的腐蚀的能力。无论是高速柴油机还是低速柴油机的燃料，应该都不具备腐蚀性，否则会腐蚀到发动机的金属零件，降低柴油发动机的寿命。

# 一 柴油机燃料中引起腐蚀的物质

在柴油机燃料中能引起金属腐蚀的物质主要有含硫化合物、无机酸及有机酸。

不论是普通柴油GB252-2011还是船用燃料油GB/T17411-2012以及ISO8217-2012国家与国际标准中都明确规定不允许含有无机酸，那么引起金属腐蚀的燃料中的主要是硫化物、有机酸、灰分。

# 二 油品中腐蚀性物质对柴油机的影响

## 1. 柴油中的硫含量对柴油发电机的寿命影响最大

随着我国对环保的重视程度越来越高，油品的硫含量控制越来越严，同时对降低柴油机的腐蚀也越来越有利。

柴油中的活性硫化物会直接腐蚀发动机的金属零件，但腐蚀程度随转速与马力的降低而减少。

含硫柴油燃烧产生的二硫化物和三硫化物在气态时对排气系统形成气相腐蚀。

当气态硫的氧化物由汽缸窜入曲轴箱时，与水分将形成亚硫酸与硫酸，又会形成液相腐蚀，强烈腐蚀机件，同时加速润滑油老化变质，加速气缸中积碳的形成，使机械的磨损加重。

当柴油中的含硫量由0.1%增加到1.5%时，积碳的密度可增加15倍，这些积碳敷在零件上，加重机械磨损的同时兼有腐蚀磨损，所引起的后果是十分严重的。

硫化物腐蚀程度还取决于发动机的工作温度。

当汽缸温度低于二硫化物和三硫化物的露点时，比如冷启动、低负荷运转、冷却水温度底等时候，二硫化物和三硫化物与水蒸气作用生成亚硫酸与硫酸，并在气缸内壁上形成 一层含酸的薄膜，附着在汽缸的各个部位上。

当发动机温度逐渐升高时，腐蚀首先逐渐降低，经过一个最低区域后又逐渐上升。

有实验表明，如将冷却水温度从70℃降到35℃时，发动机腐蚀增加了3倍。

但如果保证发动机有适当高的工作温度，就会减少冷凝水的产生，减少硫化物形成酸的条件，进而减少腐蚀。

## 2. 关于如何检验柴油中活性硫以及游离硫的多少对金属的腐蚀程度，国家标准中明确使用铜片腐蚀试验

直接使用规定形状与尺寸、纯度的铜片，在规定温度与试验条件下进入柴油中保持规定时间，取出后对照标准分级判断腐蚀性。

## 3. 柴油的酸度（或酸值）只是表示柴油中非溶性有机酸（主要是环烷酸）的含量，对发动机的功率、供油量有明显的影响

柴油中的酸性物质不仅腐蚀发动机零件，还使喷油柱塞的磨损加剧，加速在喷油嘴周围、喷油嘴头上和燃烧室的积碳，从而导致喷油雾化、降低柴油机功率及增加汽缸活塞组机件的磨损。

用酸度分别为4mgKOH/100ml和50 mgKOH/100ml的两种柴油在同一发动机上运行做实验，50h后发现柴油发动机功率与喷油嘴供油量均有下降，但后者分别是前者的4.6倍和8倍，柱塞和活塞环的磨损量后者也明显大于前者。

环烷酸对铅、锌、镉等有色金属腐蚀性较大，对铜、铁的腐蚀性较小，对铝基本不腐蚀。

有实验表明，集中不同金属片浸泡于环烷酸溶液中在室温下储存3个月后，因为腐蚀而减少的金属质量见表2：

如果油柜中有水垫或燃料中混入水分达到一定浓度时，会对金属产生强烈的电化学腐蚀。

# 三 国内外标准中柴油腐蚀性指标反映出对油品腐蚀性的重视

从前面分析可以看出，油品中硫、非溶性有机酸的含量对柴油机影响很大，因此国内外标准中对硫含量、酸度或酸值作了规定。

从国际标准与国内标准对比看，国外对残渣型船用燃料油硫含量要求“符合法规要求”，主要是从污染排放来控制，在附录中明确指出“法规（即修订的MARPOL附则Ⅵ）规定了控制使用燃料的最大硫含量，或者允许采用技术方法解决，确保符合硫氧化物和颗粒物的排放法规。因此馏分和残渣燃料两者硫含量直接受法规要求的制约。”

因此，燃料使用方根据船舶发动机的设计、排放控制、设备和燃料将要使用区域的现行的法规限制，确定燃料的最大硫含量。

从前面分析得出，不能仅考虑环保要求，同时还要兼顾发动机防腐蚀方面的要求。

国际与国内标准对酸性指标的控制高度一致，就是充分意识到由酸性化合物引起的高酸性的燃料往往会加速船用内燃机的毁坏，因为强酸的存在与燃料腐蚀性之间有相互对应关系，这种毁坏首先发生在燃料注入设备。

# 四 如何减少油品腐蚀对发动机的影响

1. 严把油品质量关，重点关注硫含量、酸度或酸值。从燃油品质入手，从进货根源降低腐蚀影响，选用燃油尽量无腐蚀性，胶质含量要少。

2. 加强燃油质量管理，及时跟踪燃油品质变化，及时清洗滤器、及时处理水分及杂物，避免燃油污染。

3. 更换燃油时，考虑燃油相容性，避免造成絮凝，堵塞分油机、柱塞，加重腐蚀。

4. 控制发动机运行温度，保证进气系统性能良好，尽量避免过量冷凝水产生。
