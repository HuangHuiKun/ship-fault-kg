# 导读

船用柴油机重要零部件的故障情况一直是船舶使用者关注的重点。

某船某型柴油机在运行状态下，机带海水泵突然出现了大量漏水现象。

该故障海水泵为原始装机件，截至故障发生时，已累计运行超过15000h。

在此期间，该泵开展过小修级别的修理和12000 h维护保养，更换过轴承、机械密封、叶轮、易损件等。

故障发生后，现场立即将故障海水泵送原生产厂进行分解检查。

拆检后发现，海水泵泵轴断裂，断裂位置位于叶轮安装孔内，叶轮未见明显损伤。

本文以此次故障为基点，从设计、制造、保养维护等方面对柴油机机带海水泵断轴故障原因进行分析，结合断口处失效分析及海水泵结构剖析，锁定问题原凶并提出相应的解决措施。

# 一、故障原因调查

## 1、设计原因

### (1)图纸设计原因

对该海水泵壳体、水泵叶轮、传动齿轮、水泵轴、水泵密封轴衬垫、水泵进口法兰的设计图纸及相关技术文件资料进行了全面排查。

排查过程中没有发现图纸在设计方面存在问题，图纸的技术状态也未发生变更。

由此，可以排除因设计不合理而导致齿轮轴断裂情况。

### (2)工艺设计原因

某型机水泵所有零部件都由制造厂编制工艺并进行生产。

故障发生后，对工艺文件与产品图纸的符合性进行全面排查。

工艺为成熟工艺，工艺文件编写完善，未发现问题。

制造单位排查了上述零部件加工过程控制与生产工艺的一致性情况，排查的内容包括原材料入厂验收、毛坯锻造、热处理、无损检测、重要尺寸和形位公差、危险截面质量控制、工序流程卡、不合格品评审，均未发现违规问题。

工艺设计原因也被排除。

## 2、制造原因

### (1)零部件制造原因

核查海水泵制造过程的尺寸间隙、热处理、力学性能、功能测试等记录发现，未见异常。

检查结果也符合图纸及技术文件要求。

### (2)装配因素

①核查该机出厂前水泵传动齿轮安装问隙检验报告。

报告显示凸轮轴中间齿轮与水泵传动齿轮间隙为0.25～0.26mm，符合技术文件要求中规定的0.18～0.42mm间隙要求。

②该水泵采用了调心轴承和球轴承的设计，可保证水泵传动轴在使用过程中不会发生严重偏心的情况，且水泵叶轮和罩壳的装配间隙要求为0.22～2.63mm。

传动轴一旦偏心，轮叶表面便会发生异常磨损。而目视观察叶轮表面状况，无异常磨损发生。

③本次海水泵修理过程中更换了轴承、密封、叶轮，更换后的数据见表1。

从表中可以看出，最终的实测尺寸满足安装要求。

## 3、维护保养原因

该船于2020年在修理厂进行了一次维护保养，柴油机运行时间为12000h。

海水泵因维修更换了轴承、密封和叶轮，安装数据正常。

但无泵轴和密封面清洁检查的相关信息，无法排除后续使用过程中密封部件可能发生海水渗漏的现象。

因此，无法排除维护保养的问题。

# 二、失效分析

为进一步查明海水泵断轴的原冈，将故障件送第三方检测机构进行失效分析。

## 1、宏观分析

对水泵轴断口进行宏观形貌检查后，发现断口未见明显塑性变形，可见放射纹收敛于断口中间隐约可见贝壳纹处，贝壳纹收敛指向轴表面，为断裂源区。

观察裂纹源区处轴表面，存在一条黑色腐蚀带，宽度为3～4 mm。

源区位于轴凹槽边缘，可见沿凹槽边缘分布的裂纹，见图1。

依据GB／T 1220—2007对1Crl7Ni2的化学成分进行分析，测得结果符合技术文件要求。

## 7、失效分析结论

(1)水泵轴的材质成分符合技术文件要求。

(2)断裂部位处于叶轮中心孑L内，裂纹源区为轴表面凹槽边缘处，源区周围存在一条黑色腐蚀带，同时可见沿凹槽边缘分布的裂纹，裂纹已和断口连通；

断口未见明显塑性变形，断口中间隐约可见贝壳纹，为典型的疲劳宏观特征。

(3)黑色腐蚀带腐蚀介质中含有S、C1元素，断口源区处和宏观贝壳纹处存在较多的腐蚀产物覆盖，断口放射纹明显区域为沿晶特征，为瞬断区。

通过金相分析可知，裂纹呈树权状，树权状裂纹为应力腐蚀裂纹的典型特征。

(4)水泵轴表面发生局部腐蚀，以应力腐蚀和腐蚀疲劳形式朝芯部扩展，最终水泵轴凶承载面积减小，无法承受T作时产生的应力，发生瞬断。

# 三、故障机理分析

## 1、水泵结构

某型柴油机的机带海水泵为离心泵。

该离心泵固定在机体上平面，并由曲轴齿轮直接驱动工作。

机带海水泵主要由壳体、叶轮、水泵轴、传动齿轮、机械密封、橡胶密封件、密封环和轴承等组成，见图8。

图8 水泵结构

水泵工作时，海水经进口法兰吸人海水泵，沿图示箭头1方向经叶轮离心增压后输送至柴油机内部海水管路。

## 2、故障机理分析

正常运行时，机械密封的动静环和密封圈将海水和水泵轴及后端的滑油、轴承等隔离开。

一旦机械密封或者密封圈失效，海水则会渗漏接触水泵轴。

如海水渗漏量较大，此时海水会从海水泵检漏孔沿图8所示的箭头2方向流出。

海水泵机械密封或者密封圈失效后，少量的海水会滴漏并逐渐腐蚀水泵图8框线圈出的部位。

水泵轴随着腐蚀的逐渐加剧，会形成开放性裂纹并导致轴横截面上的受力面减小，进而导致轴瞬间切断。

# 四、后续对策及措施

(1)柴油机的使用维护需严格按照柴油机维护保养说明书要求对水泵轴及密封件表面进行清洁，并形成特定的质量检查记录。

如维护保养说明书未包含此项内容或对该项内容要求不具体或表述不清晰，则必须及时进行升版补充该项内容。

(2)机械密封或者密封圈的检查应作为质监部门必查项，主要内容包括机械密封的动静环、密封圈的安装尺寸。

另外，还要对泵轴安装力矩进行控制和专项检查，防止遗漏。

(3)泵轴表面在探伤检查后发现异常时，应及时采取修理修复，必要时进行彻底更换。

# 五、结论

(1)海水泵因轴表面局部发生腐蚀，无法承受工作时产生的应力，发生瞬断，是故障的直接原因。

(2)机械密封或密封圈失效是造成轴表面腐蚀的根本原凶。

按照维护保养说明要求进行检查，加强密封件清洁检查力度，能减少此类问题的发生。

(3)发现小问题也需及时解决，不然会造成故障扩展，从小问题变成大问题。

(4)通过对海水泵断轴原凶的调查分析，在解决此次故障问题的同时，为后续同类问题提供经验参考。
