# 导读

随着换气方式由扫气口——排气口弯流换气发展为扫气口——排气阀直流换气，长行程和超长行程二冲程柴油机的换气质量急剧提高，其经济性、可靠性、排放污染性也都得到提高。

对老龄船舶，弯流换气主柴油机扫气箱着火故障司空见惯，气口——气阀直流换气主柴油机则很少发生，后者换气质量好的优势得以体现。

扫气箱着火好比柴油机的老年病，每发生一次就会导致柴油机性能恶化一次，如不及时对症下药修理，发火间隔期就会越来越短，发火持续期就会越来越长，对船舶和船员安全影响就越大，因此老龄船舶主柴油机扫气箱着火问题应引起机务管理人员和船舶轮机管理人员高度重视。

本文以金海轮主机扫气箱着火故障为例查找原因，提出处理措施，为同类型船舶处理相关问题起到借鉴作用。

# 一、引言

金海轮是韩国某造船厂建造的载运400个标准箱的集装箱船。

1996年下水投入营运，定向中国、日本、韩国航线。

该轮主机型号为MAN B&WL35MC扫气口——排气阀直流换气形式，发火顺序为1一5一3一4—2一6。

自2008年4月至10月，主机 NO.4、NO.2、NO.6、NO.1多次发生扫气箱着火，尤以NO.4最严重。

轮机长、大管轮针对该故障也采取过换翻新缸套、翻新活塞、活塞环等措施，但扫气箱着火问题依旧没有解决，并有日益恶化趋势。

有一个缸原先没有着火，吊完缸开航后不久却着火了。

NO.4换翻新缸套、翻新活塞、活塞环后20天又发生着火。

轮机长带领轮机部船员为解决此故障做了很多工作，非但不见效果，反而越做越差，轮机部船员面临巨大的精神压力。

冬天马上就来临了，中、日、韩航线船舶冬季航行经常会遇到大风浪天气，主机扫气箱着火问题将直接影响到船舶和船员安全，如该问题不立即解决将会成为该轮冬季航行的极大安全隐患。

# 二、扫气箱着火原因

火灾发生需具备三要素：可燃物质、助燃物质（氧气）着火点。

扫气箱有充足的氧气，因此扫气箱着火只需要同时具备两个条件：一是扫气箱内积存过多的可燃物质，二是有高温热源达到着火点。

前者主要是由于气缸密封性严重下降从而经气缸套、活塞、活塞环和扫气口漏入的燃烧产物，以及过多的气缸油蒸气；后者主要是由于气缸密封性严重下降导致燃气下窜或扫气压力过低废气倒冲入扫气箱。

总之，扫气箱着火的原因有三个：气缸密封性严重下降、气缸油过多、扫气压力过低。

扫气箱着火也有三种类型：燃烧产物着火、气缸油蒸汽着火和废气倒冲直接着火。

燃烧产物引发的扫气箱着火持续时间长，发生频率少，扫气口应较干净；多余气缸油蒸汽引发的扫气箱着火持续时间短，发生频率多，扫气口应较脏；由于扫气压力过低废气倒冲引发的扫气箱着火应是多缸近乎同时发生，扫气口处应比较干净。

由此可推断出：气缸内只具备气缸密封性严重下降或扫气压力过低一个条件就会导致扫气箱着火，前者导致问题缸燃烧产物着火，后者导致各缸燃烧产物着火；气缸内同时具备气缸密封性严重下降和气缸油过多或扫气压力过低和气缸油过多两个条件就会加重问题缸扫气箱着火，初期气缸油蒸汽着火，后期扩展至燃烧产物着火；气缸密封性严重下降和扫气压力过低两个条件同时具备或气缸密封性严重下降、气缸油过多和扫气压力降低三个条件同时具备更会加重扫气箱着火，前者导致各缸燃烧产物着火、废气倒冲着火，后者导致问题缸气缸油蒸汽着火并向燃烧产物着火扩展。

鉴于金海轮每次扫气箱着火属于个别缸着火，着火持续时间非常短，可排除燃烧产物着火问题和废气倒冲着火问题，该轮应是多余气缸油蒸汽着火。

初期着火原因应是个别缸气缸密封性严重下降和气缸油过多，采取吊缸换新燃烧室部件措施后仍着火原因应是气缸油过多、扫气压力降低、气缸密封性持续下降，这是该轮主机多次发生扫气箱着火的故障原因。

对刚吊缸完毕的气缸来说正常情况下不存在气缸密封性不好的问题，因此原先没着火但吊缸完毕不久即发生扫气箱着火的气缸其原因只有两个，即气缸油过多和安装时各道活塞环搭口方向都近乎在同一侧。

气缸密封性严重下降是柴油机的综合故障，是主柴油机长期运行的必然结果，这应是各缸共性问题，即各缸状况相同情况下应都会发生着火。

金海轮至今仍有气缸没有发生着火，因此该轮个别缸因气缸密封性严重下降而致扫气箱着火应是个性问题，而非共性问题。

该轮采用定压增压，各缸排烟管和扫气箱共用，因此扫气压力太低和扫气压力降低是各缸共性问题，即各缸都具备这个条件。

该轮有的气缸至今没有发生扫气箱着火，因此可排除扫气压力过低问题，仅是扫气压力降低问题。

当前气缸注油润滑特点是：油量可调，定时不可调。因此气缸油过多属于各缸个性问题。

NO.4最先着火，着火次数最多，尤其换新翻新缸套、翻新活塞、活塞环后一段时间没有发生着火现象，20天后又发生着火，该缸初期着火主要原因应是气缸密封性严重下降和气缸油量大。

气缸密封性严重下降原因又有多种，因此应现场具体分析。

NO.4换新燃烧室部件一段时间内没发生扫气箱着火又可以断定气缸内只具备气缸油过多和扫气压力降低两个条件。

后期NO.4扫气箱着火原因应是气缸密封性持续下降、气缸油过多以及扫气压力降低，重点应查找导致该缸气缸密封性持续下降的因素。

2008年10月，笔者与该轮轮机长、大管轮座谈各缸状况和扫气箱着火情况；现场打开主机扫气口检查，发现扫气口脏污，问题缸活塞环污染严重，证实上述分析；查看最近一年船方所测主机示功图、2007年和2008年轮机日志。

笔者得出该轮扫气箱着火故障具体原因：

1. NO.3最高爆发压力低致使NO.4燃烧差波及NO.2、NO.6；
2. 扫气压力降低；
3. 个别缸气缸油过多；
4. 船舶污底；
5. 燃油质量。

## 1. NO.3最高爆发压力低致使NO.4燃烧差，波及NO.2、NO.6

由2008年3-8月船方所测示功图看，NO.3和 NO.4最高爆发压力跟其它缸相比一直偏低。

船方针对最初NO.4扫气和有火已连续采取换新气缸套、活塞、活塞环等相关措施但情况无改观，NO.3和 NO.4的P低必有其原因。

由同年7月1日船方所测P一示功图看，NO.3的P一图头部圆滑。说明缸内燃烧后压力上升缓慢，基本趋于等压燃烧。这是NO.3供油正时晚、供油量少致使P低、排烟温度低的结果。NO.3的P低，发出的功率少，轮到NO.4工作时调速器已将油门调大，供油量、喷油量随之增大，但是废气涡轮增压器还是对应于NO.3的转速。致使扫气压力没有相应提高，结果NO.4油多气少，燃烧不完全，伴随着后燃，P也低，该缸功率也低，进而又影响至NO.2、NO.6。但随着扫气压力相对于NO.4油多排烟温度升高而升高，NO.2、NO.6燃烧逐步改善。

燃烧不完全导致气缸内结炭加重，后燃导致排烟温度升高，两者结合导致气缸套、活塞环槽结炭严重，恶化气缸润滑和活塞环工作条件。活塞、气缸套间磨损加剧降低气缸密封性，活塞环黏着使气缸密封性差燃气下窜加剧，构成扫气箱着火的热源，伴随着后期扫气压力进一步降低逐步诱发并加剧扫气箱着火。

因此NO.3的P低是导致NO.4气缸密封性严重下降进而最先发生着火的主要原因，也是造成NO.4换新翻新缸套、翻新活塞、活塞环后20天又发生着火的主要原因。

NO.2、NO.6、NO.1扫气箱着火主要原因与NO.4类同，都是气缸密封性持续下降造成，但各缸气缸密封性稍好于NO.4，因而扫气箱着火次数稍少。NO.3没有着火缘于供油量少排烟温度低。

## 2. 扫气压力降低

查看轮机日志，得三组数据：2007.11.30和2008.3.4该转速是最低转速，应是船方因大风而降速航行。2008.5.31该转速是最高转速，且此后主机转速再没超过该转速。三组数据油门近似相同，主机转速在531油门稍低转速反而高反映当时船舶阻力小，船舶阻力最大应是2007.11.30，气缸内燃烧状况最差应是2008.5.31。

2007.11.30和2008.3.4两组数据对比，同样油门下，后者主机转速、透平转速高，扫气压力高，扫气温度低，涡轮前温度低，说明后者对应船舶阻力小于前者，缸内燃油燃烧状况因扫气压力高、扫气温度低而好于前者。前者废气温度升高由于扫气温度升高导致。扫气温度高，气缸进气量少，燃烧不完全。此外也与扫气压力降低有关。

扫气压力降低也导致气缸换气质量差，油多气少致使燃烧不完全且后燃。燃烧不完全和后燃两者结合导致气缸密封性降低，活塞环槽结炭严重甚至黏着使密封性差燃气下窜加剧，构成扫气箱着火的热源，伴随着后期扫气压力进一步降低逐步诱发扫气箱着火。

2007.11.30当时无气缸发生扫气箱着火源于各缸气缸密封性优于2008.4。现场实际查看，NO.4活塞环黏着严重，NO.5活塞环无黏着，进一步得以验证。

主机油门近似相同情况下，扫气温度应随海水温度下降而降低，废气涡轮增压器转速应随涡轮前废气温度逐步提高而提高，扫气压力亦应提高，2008.5.31和2007.11.30对比数据则相反。2008.5.31和2007.11.30两组数据对比，前者在船舶阻力小油门稍小、海水温度低扫气温度低情况下，涡轮前温度反而升高、扫气压力相对降低，进一步说明前者气缸内因扫气压力降低导致换气质量差，从而燃烧过程恶化（燃烧不完全伴随后燃），气缸密封性也逐步下降。

此外，废气涡轮增压器转速随涡轮前废气温度逐步提高而降低应与废气侧排气通道堵塞致使涡轮机转速降低有关；废气涡轮增压器增压空气压力随增压器转速逐步提高而降低应与压气机工作状况差、空冷器脏污有关。从扫气温度对比看，可排除空冷器脏污问题。

查看2007年和2008年轮机日志，在同样油门、同样转速、同样气候条件下，扫气压力逐步降低，也说明废气涡轮增压器压气机工作效率逐步降低，废气至烟囱通道逐步堵塞。

扫气压力降低是造成后期多缸着火并逐渐恶化的主要原因。

## 3. 个别缸气缸油过多

气缸注油润滑对现代船舶二冲程主柴油机来说至关重要，它直接决定柴油机能否燃用劣质燃油。气缸油量应调整合适。过少会加剧气缸套、活塞、活塞环间磨损，甚至拉缸、咬缸；过多会造成扫气口污染，活塞环黏着，燃气下窜随活塞环密封性下降加剧，既破坏气缸润滑加速磨损导致气缸密封性下降，也提供了扫气箱着火的热源和可燃物质。个别缸气缸油过多长期作用结果会导致该缸扫气箱着火。

通常，船舶轮机管理人员调整气缸油过多是船舶主柴油机管理通病。因此，在保证气缸润滑情况下，气缸油量应适当减小。船舶轮机管理人员通过船舶停航时主机扫气口检查便可判断各缸气缸油量是否合适。

## 4. 船舶污底

船舶污底随环境温度升高海生物繁殖速度快和生长速度快而加重。船舶污底加重后主机大油门低转速运行。由于主机扫气压力降低，各缸油多气少，致使各缸燃烧恶化，燃烧不完全且后燃，气缸密封性逐步下降。船舶污底是加剧该轮扫气箱着火的原因，但不是导致最初扫气箱着火的原因。

## 5. 燃油质量

低质燃油的使用会加剧燃烧室部件热负荷和机械负荷，加速气缸套、活塞、活塞环间磨损从而导致气缸密封性下降，喷油设备精密偶件磨损加重，雾化质量下降从而影响燃烧质量。提高燃油质量的主要措施之一是使用燃油分油机加强净化处理。

该轮今年上半年曾出现重油舱进水事故，之后轮机管理人员发现燃油分油机分离出大量渣滓沉淀物，即低质燃油进水乳化后会出现不同牌号燃油混舱同样后果，导致喷油设备偶件磨损和气缸套磨损都加剧。该轮因燃油进水导致的燃油质量下降是造成气缸密封性下降的直接原因，是扫气箱着火的间接原因。

# 三、扫气箱着火处理措施

综合上述，提出以下处理措施：

1. 海况稳定时测各缸压缩压力以比较各缸气缸密封性。气缸密封性差且最近有着火记录的气缸应尽快吊缸检修，恢复气缸密封性。
2. 鉴于该轮主机已长期低负荷运转，各缸气缸油量都应调低。各缸扫气口检查，据检查情况适当调低问题缸气缸注油量。
3. NO.3供油正时相对提前，供油量增加。NO.3调整后海况稳定时测各缸P一示功图，重点关注NO.4变化。如NO.4变化不大，也采用NO.3同样措施。
4. 及早安排检修各缸喷油泵和喷油器。如有备用喷油泵应首先换新 NO.3和NO.4。
5. 检查各缸供油正时，如各缸都滞后应重新上紧链条。
6. 废气涡轮增压器压气机叶轮检修恢复性能。排烟总管至烟囱出口除烟灰，废气锅炉吹灰。
7. 船舶坞修适当提前，进坞时清除船舶污底。
8. 加强燃油净化处理，适当减小分油量并缩短排渣间隔期。

# 四、结束语

对现代二冲程船舶主柴油机，扫气箱着火属于综合故障，是管理不善日积月累的结果。任何船舶设备事故的发生都非偶然，轮机管理人员应对可能原因仔细分析，分清主次，以此为依据及早采取针对性措施，杜绝船舶安全隐患。初期发现对症修理就可治愈，治疗方案有问题就会贻误治疗最佳时机，结果越治疗病情就越重。因此，解决该轮扫气箱着火问题的关键是找准原因并及时对照处理。该轮已到了必须彻底解决这个问题的时候了。
