# 一 调速器拆卸

## 1. 注意事项

- 拆卸前必须准备调速器专用工具：尖嘴钳、大号螺丝刀、内六方扳手、套筒扳手、专用摇臂、铜棒（200*φ20）。
- 在操纵机构和连接机构上做好装配记号。
- 拆下固定调速器的四只螺母，把调速器提出双头螺柱，取下安装垫片。
- 搬动或放置调速器的时候，必须谨慎小心，不能撞击传动轴，也不能将传动轴做支承。否则会碰毛轴的端部，损坏轴承和油泵齿轮，影响再次安装。

## 2. 拆卸步骤

(详细步骤请查看调速器维修保养说明书！)

- 放掉调速器内部的透平油。
- 从柴油机上取下调速器（可以取下调速器后再放油）。
- 卸下上盖、伺服电机、电磁阀等。
- 拆卸前盖、壳体组件组件。
- 拆卸壳体、底座组件。
- 拆卸中间体、底座组件。
- 拆卸转子组件、中间体组件。

# 二 调速器的装配

## 1. 注意事项

- 装配注意事项：调速器每次拆卸后都必须按照规定程序进行装配，否则容易漏装零件。
- 所有运动件不能采用挤压或其它强制方式装配。
- 输入传动轴压板螺钉不宜旋得太紧，以免压板弯曲。
- 全部运动件在孔内必须灵活自如。
- 将调速器安装在传动箱体上，花键轴能靠调速器自重滑入花键套，通过止口定位，为使调速器自动对中，四个连接螺栓在盘车或低速运行2-3分钟后均匀拧紧。
- 所有密封垫片和保险丝必须装全。
- 搬动调速器时，不能把输入传动轴做支撑，以免碰毛轴的端部。

## 2. 装配步骤

(详细步骤请查看调速器维修保养说明书！)

- 组装中间体、底座组件。
- 组装转子组件、中间体组件。
- 组装壳体、底座组件。
- 组装前盖、壳体组件。
- 组装上盖、前盖组件。
- 组装伺服电机组件、电磁阀组件。
- 给调速器加入新的调速器专用油。
