# 导读

主机遥控是对主发动机、齿轮箱、螺旋桨等进行的远程操控，主机遥控系统成为现代船舶的关键设备。

主机遥控可分为四种类型：

气动遥控、气动-液压遥控、电气遥控、微机-电动-气动遥控。

为操控被控对象，需要配备各种基本功能模块，一般包括车钟、遥控控制、安全保护等三部分。

下面介绍某船安装的主机遥控系统在使用一段时间之后，主机遥控系统不能遥控的故障分析以及修护，该船是只有驾驶室和机舱两部分的。

# 一、主机遥控系统的组成

本船使用的主机遥控系统采用的是双路冗余的控制器局域网（CAN）总线结构，整个系统的控制命令的传输以及模块之间的通信都是通过数字信号来实现的，同时为了保证通信的稳定性，在通信的接口采用了电气隔离以及抗干扰措施。

整个主机遥控系统的架构如图 1 所示。

图 1 主机遥控系统的架构

主机遥控系统中电动部分是通过车钟系统发送传输命令，阀箱部分控制气流量来实现对主机的控制，整个主机遥控系统的气路原理为：

1 MPa的控制空气经过气源处理板过滤调压后，转换为0.7 MPa3 的控制空气，经遥控/本地控制手柄分配后，送往阀箱单元的气路中。

从气源处理板出来的控制空气，首先经过遥控/机旁的控制手柄，来决定当前控制气路是遥控有效还是本地手动控制有效。

当处于遥控模式时，此时本地控制手柄无效，阀箱控制模块通过 CAN 总线接收来自显控单元的控制命令，驱动对应的电磁阀来执行任务。

当处于机旁控制位置时，通过搬动发动机本体上的调速手柄来控制发动机的转速。

在发动机本体上装有气动执行机构，通常为薄膜气缸执行器。

阀箱控制模块输出电流量控制比例电磁阀的开度来调节薄膜气缸控制气路中空气压力的大小，从而使薄膜气缸执行机构产生一定的位移，拉动发动机供油齿杆来达到对应的转速。

# 二、故障现象分析及修护

该船在某次的航行途中，突然转速控制不了，主要现象就是遥控状态在驾驶室的时候，推动车钟操纵器主机的转速没有变化，将控制权转到机旁之后，手动增加油门主机转速能够变化正常。

前文中简单介绍一下整个遥控系统的构造，从整个系统中不难看出，出现这类问题大致三个方向：

测速回路故障，车钟操纵器故障或气动执行回路故障。

通过在机旁操作主机时，拉动主机的调速器油门杆，主机的实际转速和主机遥控系统测得的转速是一样的，所以这就排除了测速回路的问题。

当控制位置转换到遥控位置时，通过车钟操纵器的时候，看机旁的按钮车钟面板（如图2）上显示的档位和车钟操纵器是不是一致来判断，当在实际操作的时候，两者的档位能一一对应起来，继而也排除了车钟操纵器的问题。

经简单分析，发现是气动执行回路的问题。

系统中有介绍整个气动回路的工作过程，0.7 MPa的控制空气经过气源处理板(如图3)处理过的空气，再经过阀箱的比例阀（如图4）之后，然后进入到主机的气动执行器，控制主机的调速油门杆从而控制主机转速。

图4 比例阀和电磁阀

推测是气动回路的管路出现问题，也可能是管路出现堵塞或者比例阀损坏。

鉴于此，一开始时分段排查问题，查看气源处板上的压力指示表是否正常。

当旋转压力表下的阀时压力表的指示值会发生变化，气源处理板这一部分是正常的，比例阀通过软件发送指令控制看是否会有动作。

当时发送控制命令，发现比例阀不能动作，因此就更换了一个新的比例阀，再重新测试发现仍然不能控制转速。

反复排查一直找不到问题所在，后来将整个回路的阀件都换了之后，重新调试之后发现可以控制主机转速。

换下来的阀件之后，发现比列阀的出气孔有许多杂质把出气口堵住了，电磁阀的出气孔也发生堵塞，查看气源处理板上的滤器情况，发现有清理过的痕迹。

船上人员说里面充满了水及铁锈等，由此可以断定应该就是控制空气中有水及杂物。

当气源处理板上滤器被充满后，空气中的杂质进入到管路中，把阀件的出气孔堵住了，导致遥控状态下没法去控制主机转速。

把控制空气的来源位置改动之后，控制器中没有水等杂质了，整个控制也正常了。

# 三、结论

本次故障主要就是因为船上的控制空气来源有问题，气体中有很多水分及铁锈等。

虽然气源处理板有过滤的功能但滤器充满后也就不起作用，所以就会导致后续的阀件被堵塞或者箱内充满水导致控制板进水烧掉。

从这个故障中发现控制空气一定要是干净没有水的，否则就会再次发生同样类似的故障，严重影响到船舶的正常航行。
