# 一 故障现象

某轮配备CATERPILLAR 3412C型副机，350kW×3 台，V 型，中冷，四冲程柴油机。

锚泊期间，右副机单独运行供电，负荷在 85kW 左右，在没有启动任何大功率设备情况下，右副机出现淡水高温报警、跳闸、停车。

此时实际淡水温度只有 75℃，远低于报警值，据此可以判定故障出现在温度检测、信号转换和处理环节。

# 二 报警控制单元功能简介

该型副机报警控制单元主要包括机带启动、停止控制单元和机旁报警控制单元。

如图 1 所示。

## 1. 机带启动、停止控制箱

该控制箱为卡特公司随机配带，除了具备机旁启动、停车功能外，还具备润滑油低压、冷却淡水高温以及超速自动停车和机旁手动应急停车的功能，但不具备对外延伸报警功能。

## 2. 机旁报警控制箱

该控制箱为满足副机机旁启动 / 停止、报警和方便进行远距离操作、运行状态的监视管理而设计。

具备机旁启动、停车，润滑油低压、冷却淡水高温以及超速停车，润滑油低压，淡水高温、淡水液位低、燃油溢油等报警功能。

通过该控制箱将功能延伸到主配电板和集控台，实现了发电机组的遥控启动停止、报警等自动控制和实时状态的检测与报警。

# 三 故障原因分析

按此报警流程分析，故障点可能在以下几处。

## 1. 温度检测传感器损坏

远低于报警值，拆下温度传感器，进行实地测温试验，经过一番测试判定，测量元件功能正常，可排除此原因。

## 2. 机带启动、停止控制箱 / 报警控制箱故障

根据故障现象，我们把报警控制箱暂时关闭，只使用机带控制箱来暂时管理发电机原动机的运行。

这样做的缺点就是，每次启、停操作都必须到机旁去手动操作，不利于船舶应急情况下的应急运行，也不利于操作者的远距离检测遥控。

在这种情况下运行 48 小时，没有出现副机意外停车事故。

根据以上试验可以排除机带启动、停止控制箱原因，同时可以确定机旁报警控制箱为故障点。

机旁报警控制箱内有2块印刷线路板，其中的一块线路板是 CPU 控制板，而另一块则是继电器板。

为进一步确定具体故障部位，把两块线路板分别与左副机进行更换并进行试验，最后确定CPU 控制线路板故障。

# 四 故障产生的根源

## 1. 使用维护不到位

报警控制箱的清洁维护由电机员负责。

故障发生期间，电机员由于身体原因，将工作暂时交于主管轮机员。

主管轮机员在日常的维护保养过程中没有抓住电气设备维护保养的关键点，没能及时对控制箱的接线和电子元件进行紧固，导致线路板振动和损坏。

这说明，船舶在紧急情况下船员的工作交接方面存在不全不细的问题，轮机长对主管轮机员的工作监督不到位。

## 2. 报警控制箱位置布置不合理

报警控制箱距离副机排烟管太近，高温导致线路板部件损坏。

# 五 故障排除和纠正措施

（1）由于该线路板已停止生产，对该报警控制箱进行改装，把 CPU 线路板和继电器板更换为继电器控制（如图 2）。

图2

（2）对控制箱位置进行转移，使其尽可能远离热源。

改装后，启动右副机带不同负荷运转，水温维持在85℃左右。

至此，故障排除，恢复正常。
