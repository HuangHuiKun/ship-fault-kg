# 导读

某船右主机主润滑油进口温度出现较大范围波动由来已久，由于其温度波动在许可范围内，未引起足够重视，后经故障机理分析，解决了存在达12年之久的问题。

# 一、现象描述

主机主润滑油温度进口值为35～55℃，主润滑油泵从主机循环油舱泵运主润滑油至冷却器和由温度控制器控制的三通调节阀，三通阀可以根据主滑油进口温度的测量值自动调节高温滑油和低温滑油的比例，从而实现经过充分混合后高低温滑油温度的稳定。

自出厂以来，左主机滑油温度稳定，控制汽缸可以保持在中间位置，即保持三通控制阀一定的开度，使经过冷却器冷却的低温滑油与未经过冷却的高温滑油以一定的比例混合，混合后的滑油保持在设定温度（误差≠士C）值，之后经过波尔滤器进入主柴油机。

而右主机主润滑油温度一直处于较高波动状态，温度设定值为44℃，而实际温度范围达到（44土5）℃，经过观测发现，温控阀驱动汽缸不能停止或稳定在某一中间值，按照控制器要求，当设定温度值和测量温度值偏差为0时，控制输出应在60 kPa左右，对应高低温滑油比例控制阀之驱动汽缸应在其活塞行程的中间位置附近，对应调节阀也应处于中间位置附近，这样，才能达到温度的稳定。

而其控制过程实际情况如下：

初始状态测量温度低于设定温度，温度控制器输出值在不断升高，而调节阀门之控制汽缸仍在原来的位置。

测量值（低于）与设定值之差在继续增大，控制压力继续升高。

控制压力到达约140 kPa时，汽缸开始动作，由下死点运行到上死点，此时高温滑油全开，低温滑油全部被切断，控制压力在约2 s内降低到0。

在该状态，滑油温度开始升高，输入值与测量值开始减小，该状态保持大约120s之后，汽缸又迅速回到下死点，回到初始状态，并重新开始循环。

# 二、原因排查

活塞从汽缸上死点运行到下死点或从下死点运行到上死点，时间小于2s说明活塞运行速度太快，运行速度太快会导致汽缸与活塞、活塞杆与联结阀杆的滑靴、弧形阀芯与被控制介质之间的冲击，并容易引起活塞定位的波动（也称为“游车”）。

所以初步认为该现象为控制设定或调节不当所致。

于是从NS7型PID温度控制器开始排查原因，经过与左主机滑油温度控制器对比，设定值基本一致。

控制方式为负反馈，比例设定为0.1，积分（复位时间）设定为0.12 min左控制器微分时间设定为0.05min右控制器无微分设定。

由于此前对控制执行机构（汽缸结构和气路控制结构）、三路控制阀结构不了解，考虑三路控制阀能够根据其阀芯位置不同而调节油温，所以初步将故障定位在温度控制器和阀门控制执行机构。

根据主滑油进入活塞冷却腔的油温度波动特性分析：

周期约180s人为输入一个扰动后，除第一个调节周期，之后被控系统的衰减比为l未出现控制发散现象，说明负反馈的控制方式是正确的。

被控系统出现游车的典型特征，而且比例和积分设定值都明显偏小，符合造成游车的原因，于是调节比例控制，将其值提高到约0.35，将积分设定值提高到0.6 min。

再次观测滑油温度变化情况。

系统稳定后，衰减比仍为1周期延长到约4.6个时间单位（约7min），稳态低温段时间延长到约4.0个时间单位，温度升高段约为0.3个时间单位，高温时段仅出现峰值而无稳定状态，即控制阀门的驱动汽缸活塞较长时间处于下死点位置，控制器输出压力升高缓慢，这说明控制器能够起到控制作用，虽然其控制精度不能确定，控制器故障能被排除。

对于执行机构，从初始的类似正弦的温度曲线说明三通控制阀工作正常，之后低温段曲线延长是由于设定比例值和积分值增大所致，可以基本确定故障部位在阀门的驱动汽缸或其气路。

汽缸供给空气为400kPa在其要求的300～700 kPa范围，控制信号在其要求的20～140 kPa范围，供气压力稳定。

由于主机正在运行，动力管理部门不愿意在此时进行任何影响主机运行的原因排查，包括备用气动执行机构的更换，只能通过观测检查原因。

经过仔细观测、记录及对控制的分析，注意到左右主机及其辅助系统为对称布置，即三通控制阀、滑油冷却器为左右对称布置，而阀本身没有左右之分，若对称布置，势必将控制阀沿其出口轴线回转180°，这样导致控制阀的左右两路进口发生互换，图1为右主机高温滑油和低温滑油进口方向，左主机与之相反。

图1 右主机三通温控阀结构及输入端口图

若按照左主机的负反馈控制方式控制右主机，势必造成右主机滑油温度控制发生发散，即被控系统的温度随着温度的偏差增大而同向增大，也就是测量温度已经高于了设定温度，而控制却继续向温度升高的方向发展。

所以右主机滑油的温度控制方式为正反馈，而不是左主机的负反馈方式。

经过进一步检查，右滑油控制阀驱动汽缸输出端口接反，所以出现了系统能够控制滑油温度的假象，只是温度波动特别大而已。

将右机滑油驱动汽缸控制阀的OUT1和 OUT2端口与汽缸的输入端口进行对调，将控制方式由负反馈调整为正反馈，并重新将比例值设定为0.25、积分值调整为0.6，系统恢复正常。

从活塞油出口温度的实时曲线可以反映出主润滑油进口温度变得非常稳定，波动值在士0.5℃范围内，并且经过主机负荷变化的检验。

# 三、机理分析

图2是右主机滑油进口温度波动消除后查询到的三通控制阀驱动汽缸的原理图。

图2 驱动汽缸原理示意图

当温度控制器设定为正反馈控制方式时，若被控系统的测量温度低于设定温度，控制器输出压力降低，即执行机构的signal端输入值降低，使油膜3、油膜4形成的气腔收缩，体积缩小，带动喷孔下的挡板下移，使喷孔内背压减小，而油膜1侧压力不变，这样油膜1便推动控制阀芯下移，OUT2端口与供给空气（supply）相通，供给空气进入汽缸下部气腔，推动活塞上行，同时OUTl端口与排气口相通，汽缸上部气腔空气从排气口（EXH）排出，以使活塞顺利上行。

活塞上行到一定位置，反馈弹簧由于弹性收缩，作用在输入信号气腔上的拉力减少并使之上移，从而使喷孔与挡板距离缩短，喷孔内背压升高，使油膜2上移，并推动控制阀芯上移，直到油膜1与油膜2上的作用力相等（其压力不等，油膜2面积≥油膜1面积）阀芯逐渐封闭OUT1、OUT2、EXH端口，使汽缸上下腔内的压缩空气封闭在各自的气腔内，使活塞精确地定位。

活塞连杆上行，拖动三通控制阀调节杠杆逆时针方向转动，如图1使低温滑油进入量减少，高温滑油进入量增大，出口滑油温度升高。

同理，当测量值高于设定值时，控制系统按照相反的方式进行。

右主机自出厂以来温度波动，源于错误的负反馈控制方式的设定。

在该方式下，测量值低于设定值，控制器输出压力增大，驱动汽缸活塞杆下移导致低温滑油流入量增大和高温滑油流入量减少，最终导致滑油出口温度的进一步降低，尤其在低工况或低温航行区域，导致滑油温度对于最低要求的35℃，工厂操作人员无法分析出现该现象的原因，于是将驱动汽缸的输入接口进行对调。

其调节过程如下：

在负反馈方式控制下，测量温度低于设定温度，控制器输出压力增大，增大的压力使油膜3上移，喷孔背压增大，导致油膜2上移，并推动阀芯上移，使供给空气与OUTl连通，EXH与 OUT2连通，由于OUT2连接汽缸上部， OUTl连接汽缸下部，活塞杆拉动控制阀转动杠杆逆时针转动使高温滑油输入量增大，同时拉动反馈弹簧上移使作用在油膜3上的拉力减小，拉力的减小进一步减小喷孔与挡板的距离，使背压进一步增大，使活塞继续上移直到工作在上死点位置。

随着滑油出口温度的升高，控制器输出压力降低，油膜3收缩带动挡板下移，喷孔内背压减小，当油膜l的推力大于油膜3时，油膜3推动控制阀芯下移，使供绐空民3OUT2连通，EXH与 OUTl连通，供给空气进入汽缸上部，活塞在压缩空气推动下下移，并推动控制阀阀芯顺时针方向转动，如图1使低温滑油流入，同样，反馈弹簧的力量使喷孔与挡板之间的距离进一步增大，使活塞继续下行，直到下死点。

这样的调节，不能稳定地控制被控系统的温度，只能够在设定值与测量值存在较大偏差情况下进行调节，但这种调节在低温海域是失效的，因为其调节不是根据输入与输出差进行连续调节，而是根据输出压力是否达到140 kPa来进行调节，即控制由原来的模拟量控制改变为开关量控制。

# 四、小结

气动式PD控制系统故障原因分析和排除是船舶管理部门的弱项，应加强该内容的训练。

解决右主机主润滑油输入温度波动情况之后，对其它的气动自控系统进行了检查，也发现一些管理上和安装造成的疏漏：

如左舷发电机淡水温度控制器、海水温度控制器供给空气阀未打开、右舷海水温度三通控制阀“排舷外”指示标牌位置错误、主机淡水高温控制器标牌与制淡装置温度控制器标牌位置错误等，比例设定值都是01最敏感位置，容易造成控制波动。

船舶系统、设备由于多为对称布置，在安装、调试、标定过程中应考虑被控系统的控制方式、接口位置的改变，根据安装的实际情况进行设置和调试，不能盲目按照统一方式进行设置和标定。
