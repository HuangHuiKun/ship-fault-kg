# 导读

船舶柴油机在使用过程中，由于种种原因，造成技术状况不佳或出现故障，动力下降，油耗增加，排气超标污染环境，影响船舶安全、高效营运，所以，当船舶柴油机出现故障时，务必根据其故障现象对故障原因做细致的分析，正确掌握故障检查与排除的方法。

现以某轮6135C柴油机排气冒黑烟为例，总结分析、排除此故障的体会。

# 一、故障现象

某轮6135C柴油机因长期使用而造成动力不足，中速以上发现排气管冒黑烟较严重。

根据故障征兆，决定对该柴油机燃料供给系统进行全面的检查维护。

# 二、6135C 柴油机

## 燃料供给系统的组成与工作原理

（1）柴油机燃油供给系统组成、分布如图 1 所示：

图1 柴油机燃油供给系统组成、分布

柴油机供给系统一般可分为燃油供给系统、配气机构（包括进、排气）两大部分组成。

①燃油系统部分：

包括油箱、输油泵、低压油管、柴油滤清器、喷油泵、高压油管、喷油器和回油管等。

②空气供给部分：

包括空气滤清器和进气管等。

③废气排出部分：

包括排气管和消音器等。

（2）柴油机工作原理是以柴油为燃料，依靠输油泵的作用不断将油箱的柴油吸出，经柴油滤清器去除杂质后输入喷油泵低压油腔，喷油泵将燃料压力提高，按柴油机发火顺序，定时、定量、定压，经喷油器以雾状的形式喷射至气缸燃烧室，并与压缩空气混合形成可燃混合气而自行燃烧。

燃烧后的废气经排气管排入大气。

# 三、故障原因分析

柴油机正常排出的烟色是无色无臭的，而该机排气管冒黑烟，往往是由于喷入气缸的柴油太多，空气太少形成，因为柴油得不到空气的充分混合，柴油燃烧不完全，大量的柴油以游离炭粒形式，随排气管排出，因此看到了黑烟。

通过以上的分析，排气管冒黑烟，是由于燃油燃烧不完全的条件下形成的。

根据柴油机工作原理，我认为柴油机故障的主要原因是：

（1）空气量不足。

若空气滤清器堵塞，使进入气缸的空气量不足，柴油燃烧不完全，排气呈黑色。

（2）燃油雾化不良。若喷油器压力过低，或针阀磨损使柴油雾化不良，油雾和空气混合不充分，燃烧不完全，排气呈黑色。

（3）喷油时间不准确：

①若供油时间过迟，使部分燃油在排气管中燃烧，燃油燃烧不完全，排气呈黑色。

②若喷油时间过早，进入燃烧室内的燃油还没有达到一定的温度就开始着火燃烧，造成柴油机工作粗暴、燃油燃烧不完全就随废气从排气管排出，排气呈黑色。

# 四、故障检查与排除

根据以上分析，采取从外到内，从简到繁，逐项检查、排除的方法：

## 1、检查空气滤清器

首先起动柴油机，当柴油机达到正常工作温度时，观察柴油机在不同转速下排气管的情况，发现低速时排出黑烟不明显，但随着柴油机转速升高，排出黑烟随之严重，于是我将空气滤清器拆卸检查，发现滤网有较多的灰尘堵塞，换新滤网后按上述方法重新试车，发现低速时烟色无改变，中速、高速时排烟有所改善，但该故障仍未完全排除，还需进一步检查。

## 2、逐缸停止供油法测试

利用逐缸停止供油法就是对各缸进行停止供油测试，检查各缸的供油情况。

通过测试发现柴油机的各缸转速在停止供油时动力都有明显降低，但第二缸转速在停止供油时动力无明显降低，根据测试初步判断第二缸工作不正常，其余各缸基本正常。

各缸喷油器安装回气缸，重做逐缸停止供油法试验，各缸转速在停止供油时动力都有明显降低，表明各缸工作基本正常。

（2）喷油提前角的检查。

①拆解第一缸的高压油管，转动曲轴，使第一缸活塞处于压缩冲程的上死点，此时飞轮外壳上的指针对准飞轮上的“0”度刻线。

最后拧紧联轴器主动凸轮盘与主动凸缘盘的两个锁紧螺钉。

调整、检查完毕后起动柴油机，在柴油机达到正常温度后，拉动调速杆使柴油机在低速、中速、高速运转，排气管冒黑烟现象消失，动力性能良好，说明故障已排除。

通过该柴油机检修，其主要故障归结为如下 3 个方面：

（1）空气滤清器堵塞，使进入气缸的空气量不足，故中、高速时排气管冒黑烟。

（2）第二缸的喷油器喷油嘴由于积炭及粉末积聚，使针阀与针阀孔封密不严，造成喷油嘴喷射压力低和雾化不良，排气冒黑烟。

（3）因喷油泵联轴器的两个锁紧螺钉松动，使喷油时间过迟，燃油喷入气缸后部分燃油来不及完全燃烧就随废气排出，使排气管冒黑烟。

# 五、启示

经过这次柴油机故障检查与排除，提高了对柴油机燃料供给系的认识，增强了日常维护保养的意识，从中得到了启示：

（1）定期清洁空气滤清器，确保充足空气进入柴油机气缸。

（2）经常检查、清洁油管接头滤网、柴油滤清器，保证燃油清洁畅通，减少燃油系统故障发生。

（3）经常检查喷油泵联轴器锁紧螺钉，以防松脱而改变喷油泵的喷油正时。

（4）船舶航行中，经常观察、检查柴油机的技术参数，做到“四勤”（即勤听、勤看、勤嗅、勤摸），如发现异常，及时排除。

柴油机排气管冒黑烟故障原因较为复杂，但只要我们细心观察故障现象，耐心分析故障原因，掌握从外到内，从简到繁，逐项检查、排除的方法，就能达到理想的效果。
