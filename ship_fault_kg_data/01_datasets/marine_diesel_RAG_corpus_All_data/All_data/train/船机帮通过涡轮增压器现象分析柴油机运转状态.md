# 导读

现代柴油机基本都用废气涡轮增压技术设计，涡轮增压器的使用，使得同体积的机器能够获得更大的功率，在柴油机中，涡轮增压器在进、排气的通道上，因此，它功能的好坏，对整台机器的运转状态起着至关重要的作用。

我们在平时管理中，能不能通过涡轮增压器运转现象，来判断柴油机运转状态呢，仔细分析，还是可以通过种种现象总结出柴油机的不同状态。

# 一、涡轮增压器的作用和工作原理

涡轮增压器是利用废气的能量，带动废气涡轮转动，废气涡轮带动同轴的压缩机轮转动，提高柴油机的进气量，让柴油机在多供油的情况下，能有足够的空气供给，让燃油能够充分燃烧，充分发挥出燃油的能量，让使用涡轮增压器的机器更有劲。

涡轮增压器的作用可以让柴油机的空气燃油比例在合理的区间，如果空气供给量不足，再增加燃油，除了将黑烟和未燃尽的燃油排到大气中外，不会产生更多的功率。

而且供气量不足的现象，还可能导致柴油机排烟温度过高，长期排烟高温，燃烧不完全，废气也可以让涡轮侧堵塞，转子转速降低，让涡轮增压器进入恶性循环中。

# 二、涡轮增压器的组成部分

四冲程柴油机进气系统上的部件有增压器进口滤网、消声器、增压器叶轮、扩压器、空气冷却器、进气总管、进气阀。

排气系统上的部件有：排气阀、排气支管、排气总管、废气涡轮、排气管、废气锅炉、排气管。

在柴油机的进、排气系统中，可见且起关键作用的涡轮增压器，在进气、排气系统的交集处，两个系统中的故障现象，都可以在涡轮增压器这里体现，因此，更好地分析了解涡轮增压器的现象，能够更好地管理柴油机。

在涡轮增压器上有多种监测设备，有监测涡轮增压器转子转速设备；废气涡轮侧有进、出涡轮排烟温度表，运转中排烟温度有高于或低于正常值的时候。

在涡轮增压器的增压端后，有监测压力表，在空气冷却器后的监测压力表数值也有高于或低于正常值的时候。

# 三、涡轮增压器常见不正常现象及原因分析

## 废气涡轮进口端温度高

废气涡轮进口端温度高，其根本原因是燃烧不充分，存在后燃现象，而后燃产生的热能会转化为转子的动能，使增压器转子转速高于正常值。

在进气系统正常的情况下，可能的原因有：喷油器雾化不好，燃烧不充分；高压油泵的供油定时不正确，供油滞后；排气阀不严，存在漏气现象；燃油质量不好，燃烧不充分；进气系统不正常，扫气压力低，供气量不足，空气燃油比不匹配，燃油没完全燃烧而后燃。

## 废气涡轮端温度低

废气涡轮端温度低，其原因是过早燃烧或少量的供油燃烧，增压器转子会因燃气的动能不足而降转速。

可能的原因有：机器启动不久，低负载运转时；高压油泵的供油定时提前，提前燃烧，有时伴有敲缸现象；喷油器堵塞，单缸不喷油。

## 增压器端空气冷却器后扫气压力过高

增压器端空气冷却器后扫气压力过高，可能的原因有：进气阀不严，气缸内的压缩空气窜到进气总管，扫气温度基本正常；空气冷却器前侧与其后侧中间的密封件不严，扩压管中的高压气体窜到进气总管中，扫气温度会稍高；空气冷却器前的压力高于正常状态，因增压器转子转速高而导致扫气压力高于正常值。

## 增压器端空气冷却器后扫气压力过低

增压器端空气冷却器后扫气压力过低，可能的原因有：空气冷却器脏堵，过空气冷却器的空气量减少；增压器转子转速低，可能原因有：涡轮端动能不足，或转子轴承磨损，阻力大。

## 涡轮增压器转子转速过低

涡轮增压器转子转速过低，可能的原因有：转子轴承损坏，摩擦加重；喷嘴环脏堵，推动涡轮转动的动能不足。

# 四、多重不正常现象下分析柴油机运转状态

以下描述的扫气压力是指空气冷却器后的扫气压力，假定空气冷却器前、后的压力差在正常范围，空气冷却器状态正常。

排烟温度高、低，涡轮增压器转子转速高、低，进气总管内扫气压力高、低，上述多种现象可以形成多种组合形式，下面我们就这些组合形式，来分析柴油机处在什么状态。

排气温度高，增压器转子转速高，扫气压力高。此现象三者间因果关系成立，但每种现象有其各自产生原因，主要问题是分析解决排气温度高的问题，因为排气温度高是增压器转子转速高的重要影响因素。

排气温度高，增压器转子转速高，扫气压力低，此现象排气温度高与增压器转子转速高有因果关系，增压器转子转速高与扫气压力低相矛盾，可查找排气温度高和扫气压力低那个状态不正常。

排气温度高，增压器转子转速低，扫气压力高，此种现象相互间是矛盾的，要逐一检查，先查找到一个正确状态，那么其相反状态错误的可能性就很大。

排气温度高，增压器转子转速低，扫气压力低，此种现象增压器转子转速低与扫气压力低有因果关系，排气温度高与增压器转子转速低相矛盾，可先分析矛盾双方那个不正常，再找问题原因。

排气温度低，增压器转子转速低，扫气压力高，此种现象前两者有因果关系，但增压器转子转速低与扫气压力高相矛盾，首先判断后两者那个状态正常，再分析不正常状态原因。

排气温度低，增压器转子转速低，扫气压力低，此现象三者间因果关系成立，但每种现象有其各自产生原因，要逐一排查每种现象的影响因素，找到不正常状态，再分析不正常状态原因。

排气温度低，增压器转子转速高，扫气压力高，此现象增压器转子转速高与扫气压力高有因果关系，排气温度低与增压器转子转速高相矛盾，要判断矛盾双方的不正常状态，再分析其原因。

排气温度低，增压器转子转速高，扫气压力低，此现象三者间相矛盾，要逐一分析每种现象可能的影响因素，找到错误现象。

# 喘振的原因与解决方法

涡轮增压器在运转中，喘振是更严重的不正常现象，严重的喘振可能损坏涡轮增压器，喘振的产生是因为当进气流道堵塞不畅通时，进气流量减少，涡轮增压器会发生增压器喘振，因为当气体流量减少到一定程度时，在叶片处会产生负压区，气体在叶轮和扩压器上强烈分流，同时产生强烈脉动，并有气体倒流，导致压气叶轮不稳定工作，压气机振动，同时伴有喘息声和吼叫声。

当增压器喘振时，可查找引起供气量不足的影响因素，在进气通道中，从增压器进口滤网逐一检查，着重检查进口滤网和空气冷却器是否脏堵，脏堵的清洁。

涡轮增压器转子动能不足，转子转速降低，压气端叶轮因转速低而提供不了足够的空气，这时要查找导致涡轮增压器转子降速的原因，排烟管上的废气锅炉脏堵，因排烟不畅引起的涡轮降速，清洁废气锅炉内的加热管外表面，让排烟通畅；涡轮侧喷嘴环脏堵，没有足够的废气吹动涡轮转动而降速，拆解涡轮增压器，清洁喷嘴环及排气端部件。

排烟时有脉动，导致涡轮转速忽高忽低，引起压气叶轮端进气脉动，原因有燃油系统中高压油泵供油定时不一致，导致燃烧充分程度不一致而引起脉动，可调整高压油泵供油定时解决。

柴油机突变负载时，也可引起排烟脉动，大风浪时需降负载运转，避免飞车，避免突加突减负载操作。

柴油机涡轮增压器所处的位置极其重要，进、排气通道上由一根转子轴将进、排气系统相关联，因此，我们通过观察涡轮增压器的多种监测数据，可以分析柴油机的运转状态。
