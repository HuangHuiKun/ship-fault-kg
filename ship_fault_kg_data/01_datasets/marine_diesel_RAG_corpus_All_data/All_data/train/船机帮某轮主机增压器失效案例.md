# 拆检原因

该轮在某年11月12日13时从宁波港驶出至厦门途中，在11月13日凌晨05时10分机舱间警报。

经船员自行检查发现，2#主机增压器废气进气涡壳油室冷却水腔连接发兰已经断裂。涡端油室盖板已经变形，柴油机缸头排温升高，增压器失效。

经停机后将2#增压器从柴油机排烟总管到增压器废气入口处封死，柴油机以单台增压器低负荷运行，于11月14日下午15时抵厦门，由ABB上海分公司上船对增压器进行解体。

# 叶轮叶片

转子总成，压气叶轮、导风叶轮与叶轮罩壳磨擦而损坏，其中导风叶轮的一片叶片断裂，断裂面的油灰沉积表明此为疲劳断裂。

导风叶轮叶片断裂，导致相邻两片压气叶轮的叶片受损。

转子轴气封片位与壳体磨擦导致气封片全部消失，转子轴磨损，并有高温发蓝痕迹。

喷嘴环固定螺丝孔变形，喷嘴环罩产生裂纹。

# 叶轮罩壳

压气叶轮罩壳及扩压器，叶轮罩壳与压气叶轮磨擦而受损。

扩压器的叶片被断裂后的导风叶轮叶片碎片、以及受损的压气叶轮所产生的碎片打击所致。

# 废气进气壳

涡轮端轴承冷却水腔的连接发兰产生裂纹，固定喷嘴环的圆法兰已完全碎裂，涡压端油封被转子轴挤压严重变形，涡壳中心的轴气封位有裂纹。

# 废气进气壳内部

涡轮端油封严重受损，壳体油封位及气封位都产生裂纹。

废气进气涡壳用于固定喷嘴环的法兰已经完全碎裂。

# 轴承及油泵

两端轴承及油泵均已损坏。

受损的压气端轴承，减震片严重变形、轴承滚珠严重磨损,轴承滚珠托架保持完整。

# 总结

根据以上照片及实际勘测的结果，我们认为导致该涡轮增压器损坏的原因是:在运转中，导风叶轮的一片叶片首先发生断裂，使转子总成失去动平衡，从而使轴承受损失效，导致增压器其它相关部件的损坏。

导风叶轮叶片的断裂的原因:

叶轮表面因腐蚀所形成的微小凹坑在增压器本身的高频震动下或是喘震作用下、或是在两者的共同作用，逐渐发展成为疲劳裂纹，裂纹逐渐延伸从而导致导风叶轮的叶片在高速运转中因巨大离心力而发生断裂。
