# 柴油发动机是船舶的心脏和动力源

要使船用发动机保持完好的技术状态，以发挥最大的效能，就必须对其进行及时的维护和修理，搞好维修是提高工作效率，保证机械正常运转的重要环节。

柴油机修复后的磨合是延长使用寿命的必要措施，也是柴油机大修中不可缺少的工序。

## 一 磨合的目的

柴油机大修主要摩擦副零件有气缸与活塞、活塞环，曲轴轴颈与轴承等，进行了更换和加工，无论是新件还是加工件，都不可避免地存在着几何形状误差( 位置精度误差等)以及表面微观不平( 加工痕迹形成的凸峰和凹痕) 。

因此，相配合的两个零件实际接触面积较小，而单位面积上的负荷较大，摩擦磨损严重。

此外，由于零件表面的微观不平而不易形成油膜( 被凸峰破坏) ，使磨损加剧。

如果在这种状况下柴油机高速负荷工作，摩擦副零件表面的凸峰严重擦伤或撕裂金属屑成为磨料，使磨损加剧。

严重时造成局部高温熔化变为熔着磨损，形成拉缸与烧瓦。

其次，由于零件表面粗糙，消耗于摩擦的功率较大，此时柴油机大负荷工作即相当于超负荷，也加剧了零件磨损。

因此，柴油机大修后必须在低速低负荷下运转一段时间，并逐渐增加转速和负荷，以使零件表面的粗糙度逐渐磨平，形成有利的表面光洁度和形状，摩擦功基本不变。

这段时间称作磨合期。

磨合期较长，而初期磨合阶段损量较大，因此将此阶段要各位重视，通过合理的规范的磨合，以减少磨损量，延长使用寿命。

此外，通过这一磨合可以检查柴油机修理质量，并发现修理和装配中的缺陷，以便及时排除。

## 二 磨合的方法

磨合的原则是由低速到高速、由无负荷到有负荷、由小负荷到大负荷逐渐加大，以使零件表面接触面积逐渐增加，配合面逐渐能够承受载荷。

磨合一般分为冷磨合和热磨合两个阶段进行。

### 1.冷磨合

冷磨合是由外力拖动，一般由电动机拖动来进行。（在船舶柴油机领域，除了盘车，此工序无条件进行。）

冷磨合又分为无压冷磨合和有压冷磨合。

无压冷磨合是不装气缸盖或喷油器，在无压缩力的情况下进行。

有压冷磨合是在有压缩力的情况下进行。

冷磨时应注意检查机油压力是否正常；

柴油机有无局部过热现象；

有无不正常响声；

是否漏水、漏油等，如有故障应及时排除。

冷磨后检查润滑油中有无过多的、不正常的金属屑；

检查并调整气门间隙和供油提前角，然后更换润滑油进行热磨合。

### 2.热磨合

热磨合是将柴油机发动运转进行磨合。

热磨合分为无负荷磨合和有负荷磨合。

无负荷磨合是不加载荷，在不同的转速下空转磨合，转速从怠速逐渐增加到额定转速。

有负荷磨合是给柴油机加以不同的负荷进行磨合，负荷和转速逐渐增加到额定值或超负荷。

在热磨合过程中应检查如下项目，必要时进行调整和排除：

( 1) 按下起动电钮，在10秒内能顺利起动，如起动不了，隔2分钟再起动，仍起动不了则应检查并排除故障；

( 2)检查并调整机油压力(一般为2.5—4kg／cm)；（不同机器的机油压力有所不同）

( 3) 检查水温(一般为70—85℃) ；

( 4) 查听有无局部过热和不正常响声，发现后立即检查并排除。

( 5) 检查是否漏水、漏油、漏气；

(6)观察排气烟色，一般允许有淡淡的青灰烟；

(7)调整喷油提前角。

热磨合后在热车状态下放出全部润滑油，并检查润滑油中有无不正常的金属屑。

然后用柴油彻底清洗油底壳和机油滤清器等处。

最后更换润滑油进行试验。

## 三 柴油机修理、磨合质量的检查

磨合质量的好坏影响柴油机的使用寿命。

所谓磨合质量好是指：

磨合阶段所需时间短，磨合期零件表面磨损量小，磨合后在正常负荷下使用寿命长。

影响磨合质量的因素：

首先是磨：

合规范选择是否恰当，即磨合时所加负荷和磨合时间是否得当。

磨合规范根据机型的不同，修理条件和修理质量的不同而选择亦不相同( 一般是从实践经验中总结出来)。

其次，磨合时的润滑油对磨合质量有影响。

润滑油应该是油性好(粘附金属表面的能力强) 、流动性好( 能更好渗入零件表面的微观不平内部以带走磨屑和摩擦热) 、导热性好(以降低零件表面的温度防止熔着磨损) 。

最后，零件表面的质量(光洁度／硬度及磨合性) 也影响磨合质量。

热磨合后进行柴油机性能试验，以鉴定修理质量。

在柴油机水温和机油温度正常的情况下：

测定柴油机的功率、扭矩及耗油率；

检查调速性能，在额定转速、额定负荷突然卸去载荷，其调速率不应大于10％，转速稳定时间不应大于10秒。

最低转速不应大于400～500转／分，怠速稳定性不大于±30％；

检查排气烟色及排气温度一般不大于500一550℃) 。

一台修理合格的柴油机应该是：

①起动容易；

②除了轻微的气门响声及均匀的齿轮啮合声外，不允许有其他异常响声；

③机油压力和水温正常；

④不允许有任何漏水、漏油、漏气现象；

⑤排气烟色、温度正常；

⑥高速、低速运转平稳，怠速正常；

⑦外部零件、附件齐全，连接牢固可靠；⑧最重要的是功率、扭矩、耗油率符合标准。

总之，为了发动机更好的工作，无论新机还是大保养，使用前必须有“磨合”的意识，市场上的船机品牌很多，请仔细按照发动机官方使用说明书进行磨合。

## 链接：潍柴200系列发动机的磨合

### 1.新机的磨合

新机使用前，对各种外联接管路进行认真清洗，确认管内无焊渣等异物后才能与柴油机接通，特别是机油管，必须经潍柴服务人员现场确认后，才能通机油。

### 2.大修后的磨合

柴油机经大修调换气缸套、活塞或活塞环后必须进行磨合运转，如果气缸套不需要更换，也要将气缸套进行珩磨。

活塞环槽明显磨损或接近许用磨损极限时有增加机油消耗的倾向，因此，应重新磨槽并装上加厚的活塞环。

即使只有一只活塞换了一套新的活塞环，也必须进行磨合运转。

使用一段时间后的柴油机如果气缸套内表面出现光亮面（存油不足），或气缸套不圆，在装上新的活塞环后必须特别注意磨合运转。

在长期运行后吊出活塞或更换活塞环时，气缸套应在现场室温下进行仔细测量， 如果磨损和椭圆度达到了说明书规定的许可极限，应必须更换。

### 3.低负荷运行后的磨合

长期在低负荷范围内连续运行会引起柴油机内部严重脏污。 

活塞环、进气管可能产生积炭，增压空气管、排气歧管、中冷器、涡轮增压器内会产生油泥，必要时进行清理。

在低负荷情况下，活塞环和气缸套内表面的配合已相适应，如果柴油机的转速升得太快，因低负荷时活塞环和气缸套内表面的适应性突然改变，会引起磨损率增加而且柴油机有发生其它故障的危险（如活塞环窜气，活塞咬住）。

不允许烧重油的发动机长期以部分负荷（低于全负荷30%）运行，必须改用柴油并尽快加以较大的负荷。
