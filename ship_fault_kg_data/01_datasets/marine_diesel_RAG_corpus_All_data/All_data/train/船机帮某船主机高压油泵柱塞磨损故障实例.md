# 一、故障现象

某散货船主机型号为MAN B&W 6S50MC-L,高压油泵为回油孔式(见图1)。

图1 高压油泵

在船舶靠离码头时，该机型主机无须换油。

由于该船在靠码头期间需要对燃油循环泵及增压泵进行拆检，因此在靠码头前将重油换到轻油。

该船离开中国北方某港后，在主机定速换油中发现主机转速达不到额定转速( 只能维持在100 r/min,而主机额定转速为110 r/min),即使加大油门，也无济于事。

检查燃油系统的增压泵和循环泵的压力，检查集油井并进行放残，均未见异常。

主机各缸高压油管均有脉动，烟囱中有少许黑烟冒出，各缸热负荷最大相差达40℃。

# 二、故障排除

在航行一段时间后，船舶主机转速仍不能达到额定转速，且转速有所下降，各缸热负荷最大相差达60℃。

对各缸进行爆压测试，发现各缸爆压值相差很大，随后换油停车检查。

首先检查进气系统。

检查空冷器进气端有无脏堵，并进行化学清洗;清洁各缸扫气箱，检查活塞环的工作状态,未发现任何异常。

其次检查燃油系统。

对各缸油头进行雾化试验,雾化良好;检查燃油供油单元，清洗燃油滤器，对油柜进行放残。

在未发现任何异常情况下试车。

试车时主机可以冲车,但无法启动;查看油门齿条均在正常位;检查各缸高压油管脉动情况,发现在正常启动油门时脉动几乎没有;随后加大油门，可以启动运行。

停车,查看主机说明书,推断故障原因可能是高压油泵停止阀在启动时漏气或高压油泵进油阀卡阻。

拆开相关控制气路，未发现异常;拆检高压油泵进油阀，未发现异常;拆检主机高压油泵，发现高压油泵柱塞套筒精密偶件的间隙过大，且各缸高压油泵柱塞均有不同程度的磨损。

# 三、原因分析

高压油泵柱塞磨损，可能是在轻油换重油时温度调节不当引起的。

由于管理疏忽，长时间未检修高压油泵;柱塞套筒在长时间使用后会有微量磨损,因此没有卡阻。

该船燃油温度检测需要在机旁进行,集控室的温度、黏度检测点早已损坏，而且由于当时船舶出港备车航行,情况复杂，对燃油温度疏忽观察，造成换油时轻油温度过高，与重油温度相差太大，导致高压油泵柱塞磨损严重。

# 四、换油操作

当船舶需要较长时间停泊或燃油管系中某些设备需要拆卸时，应在主机停车前换用轻油，以便把管系和设备中的重油冲洗干净。

此外，当主机处于机动操纵状态时，为使主机具有机动性能(特别是启动性能),最好也使用轻油;船舶在正常航行时可使用重油，以提高经济效益。

换油的基本原则是防止油温突变,避免高压油泵柱塞卡紧或咬死，其应按如下进行。

## 1、轻油换重油

(1)首先对重油日用柜加温，使其温度处于正常值;

(2)主机负荷降低至额定功率的3/4;

(3)调节雾化加热器加温阀或手动调节黏度调节器,使燃油温度上升速度大约在2℃/min,轻油加热最高温度在60~ 80℃;

(4)轻油黏度不能低于2cSt,因为黏度低将很难对泵阀润滑，会造成高压油泵和燃油阀的卡阻;

(5)在换油期间，重油日用柜与加热轻油的温差尽量不要超过25℃;

(6)在达到换油要求时，切断轻油供应阀，同时打开重油供应阀，转换换油三通阀，换油完毕;

(7)当换油阀转换好时，还要注意燃油温度不能上升太快,应使其温度缓慢上升。

## 2、重油换轻油

(1)如果可以，应先加热轻油日用柜;

(2)关闭雾化加热器加温阀;

(3)主机负荷降低至额定功率的3/4;

(4)当重油预热温度高于轻油日用柜25℃时就可以换油,但重油预热温度不要低于75℃;

(5)在转换油后，如果温度降的太快可以适当开一点加温阀，同时注意燃油黏度，直至系统全部换成轻油。
