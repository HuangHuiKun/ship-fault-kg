# 导读

柴油机在实际运行过程中，经常会碰到个别气缸不工作的情况，但是如果当时无法立即修复，还要保证柴油机能够继续运行，也可以采取停止故障气缸工作的措施，这就是减缸运行。

常见筒形活塞柴油机减缸运行的情况主要有两种：

单缸停油减缸运行和拆除活塞、连杆减缸运行。

根据不同的情况，应采取对应的措施。

# 一 常见情况及措施

## 1. 单缸停油减缸运行

如果柴油机在运行过程中某气缸发生故障，而这些故障导致了气缸不能发火，但运动部件还可以继续运转，例如燃油喷射系统故障、气阀卡死、气缸漏气、轻微拉缸等情况。

当时无法及时修复，又要求继续工作，为了能够满足这种要求，可采用单缸停油减缸的运行措施。

在决定对单缸进行停油后，应采取如下措施：

（1）根据具体机型采取适当方式停止喷油泵工作，或打开喷油器回油阀使燃油停止喷入气缸等方式；

（2）避免关闭喷油泵进、出口阀，防止造成喷油泵偶件干摩擦而咬死；

（3）适当减少该缸的润滑和冷却，如有示功阀应定期开启，以避免因滑油积存而引起爆燃等其它问题。

## 2. 拆除活塞、连杆封缸运行

如果柴油机的活塞、缸盖、缸套或连杆产生裂纹等损坏，不能继续使用，且无备件时可以采取拆除活塞、连杆组件的封缸运行措施。

要注意的是此时不但要切断该缸的燃油，也应切断该缸的空气，必要时还需断开润滑和冷却。

在决定拆卸活塞、连杆后，应采取如下措施：

（1）在活塞或气缸套损坏时，将活塞拆除，并拆下连杆，视情对缸套或缸盖进行应急修复；

（2）用专用工具把气缸的进、排气口完全封住，切断气缸油，封住曲柄销润滑油孔，封住活塞冷却液进、排出口；

（3）如果是采用高压空气启动，应拆除该缸启动阀并将启动空气支管封住。

# 二 减缸运行的管理

为了进一步减低减缸运行的危害，使柴油机能够应急运行，应加强使用中的管理，主要注意点如下：

## 1. 降低负荷、减少油门

减缸运行时，应在低负荷下减少油门运转，密切注意柴油机在各缸的喷油量、排气温度等工作状况，严格禁止柴油机超负荷，尽量使柴油机在75%负荷转速下运转。

## 2. 防止异常振动

柴油机的某缸进行停油或拆除运动部件后，整体的平衡性就被破坏了，往往就会导致柴油机振动加剧。

为了确保柴油机还能继续运行，应根据情况，进一步降低负荷，必要时负荷要降低到50~60%以下或更低。

## 3. 防止增压器喘振

由于进排气量改变，柴油机内部空气的流通能力也有所改变，增压器可能会进入喘振区，而喘振现象也是柴油机运行过程中应当规避的，所以还是要采取降速等方式进行消除。

## 4. 保证柴油机运行安全

不论在何种减缸情况下运行，柴油机都是处于一种非正常状况。

要保证柴油机可靠安全运行，还需要加强对操作使用人员的指导，增加检查次数，尽量减少柴油机启动次数。

当柴油机主要工作指标或有关参数异常后，必须立即找出原因并采取相关措施。
