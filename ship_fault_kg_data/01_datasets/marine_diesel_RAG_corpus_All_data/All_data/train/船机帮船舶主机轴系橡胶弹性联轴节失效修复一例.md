# 导读

在船舶修理过程中经常会遇到易损件——橡胶弹性联轴节失效方面的问题。

文中介绍了传递动力的轴系联轴节基本概念，以及橡胶辊失效的原因和修复过程，为相关工程技术人员提供了一例解决方案。

# 一、故障原因

船舶轴系起到传递动力的作用。把两根轴连接在一起的连接件称为联轴节，橡胶弹性联轴节是其中的一种结构形式。

橡胶弹性联轴节的主要优点是具有吸震和缓冲的能力，对轴系的对中要求要比刚性联接低，安装方便。

橡胶弹性联轴节一般使用在长江及内河运输等小型高速舰船上。

某港口作业轮主机与中间轴采用的是橡胶弹性联接，联接的结构见图1所示，由橡胶辊、联接轴法兰、固定盘及两端连接螺栓组成，传递的扭矩较大。

该轮在使用过程中橡胶辊严重倾斜，而且橡胶辊因年久失效，导致有敲击声，中间轴轴承发热，主机工况也不理想。

# 二、解决过程

结合主机修理过程，同时也对弹性联轴节进行解体测量。

通过测量后发现，联轴节法兰连接孔磨损，椭圆度有3mm 之多。

一种方案是更换橡胶辊，但因椭圆度严重超差，即使更换新的橡胶辊也不能满足使用要求。

另一种方案是更换联轴节法兰，但联轴节法兰加工时间长、成本高。

对此进行了论证，决定采用镗孔和更换橡胶辊方案。

在保证中心距不变的情况下，利用数显镗床将联轴节上的连接孔镗大，12 只孔镗成一致尺寸，根据新孔径加工橡胶辊两端的法兰。

由于磨损较大，无标准孔作依据，法兰与孔的配合只能根据一只备用品的原始孔径测量后取得，用同样的方法测得其他孔的配合，把所有的橡胶辊法兰放在数控车床上加工，这样基本保证了尺寸的一致。

## 1、配合方案

橡胶辊自由端法兰凸台与固定盘孔采用过渡配合，橡胶辊凸台与飞轮端孔的配合采用过盈配合，过盈量0.005mm。

不能采用间隙配合，间隙配合会损坏飞轮上与之配合的孔，导致故障产生。

固定盘与联轴节法兰之间的安装间隙值 △＝5～7mm，在主机运转过程中，间隙会发生变化，间隙应预留轴向窜动余量，若间隙 △ 过小，主机在运转时会发生固定盘与联轴节法兰平面的撞击。

橡胶辊长度在加工时应依据测量长度控制在规定范围内，并要求每只橡胶辊的长度保持一致。

## 2、橡胶辊的加工

橡胶辊的弹性取决于其硬度值。

为使橡胶辊与两端的法兰平面胶合牢固，延长使用寿命，两端法兰接触面加工成弧形面，弧形面要求毛糙，可通过在弧形面上加工细的螺纹线，以增加橡胶的粘合力。

橡胶辊在浇铸时两端法兰同心度也要得到保证，否则必须重新浇注，如果不同心，安装时阻力大，便会影响主机的拐挡差。

虽然该弹性联轴节可以抵消一定的轴系偏移量，但在安装前后都要测量主机的拐挡差。

安装后主机的拐挡差要在标准范围内，否则会影响主机的运转，导致拉缸等故障产生。

撬动飞轮转动时要无阻力，说明轴线一致、对中情况符合要求。

试车前还要仔细检查螺栓的预紧力和螺丝的保险是否可靠，以免高速运转产生脱节故障。

数据要依照船检规范，达到检验标准后便可试车观察安装情况。

# 三、结语

轴系中的橡胶辊失效问题产生的原因很多，有轴线对中方面的原因，也有安装方面的问题，要从损伤的形式以及运动部件的构造等方面系统地分析。

按照规定的检修程序和相关项目进行判断、修理，找出根本原因，保证船舶的正常航行。
