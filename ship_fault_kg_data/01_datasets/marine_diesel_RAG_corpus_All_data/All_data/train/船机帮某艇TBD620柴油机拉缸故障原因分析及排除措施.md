# TBD620系列柴油机是引进德国技术生产的高速柴油机

## 曼海姆柴油机TBD620系列

该系列柴油机具有结构紧凑、转速高、油耗低、功率大、寿命长等优点，自动化程度高，运行时能对各种技术参数进行监测并根据所设定范围进行报警或停机。

但作为大功率柴油机，高压泵采用组合式，各缸的排气温度不能监测，油底壳压力高时仅作声光报警。

该系列柴油机较好地补充了国产大功率高速柴油机功率在1000～2000kW的设计选择，已大量在船舶上使用，大型舰船上作为柴油发电机组的动力机械，中小型快艇上作为推进动力。

# 故障现象

某医疗救护快艇，设前、后两个机舱，每个机舱各安装2台主机及其它辅机。

主机为4台TBD620V16型柴油机，额定转速1800r/min、额定功率2030kW。

在执行任务时，4台主机同时在1700r/min的工况下运行，其中1#主机在柴油机曲轴箱压力高报警且随后润滑油压力低同时报警，经人工紧急停机。

停机后马上做检查已无法盘车，打开曲轴检查窗，撬动连杆轴承盖，有6个连杆轴承盖不能轴向移动，同时发现油底壳机油进水，底部有较多轴瓦熔屑。

经对柴油机拆检，发现的故障部位主要有：

(1)拆出气缸盖发现B7缸套有拉缸现象，缸套燃烧室靠橡胶密封圈处有一圈的裂纹，活塞顶损坏严重并有一个烧熔的洞，活塞环断裂，缸盖燃烧室平面撞击出较多凹陷痕迹，气阀被打歪；

B1缸活塞顶上粘结有铁质碎片，活塞顶、缸盖燃烧室平面有轻微凹陷痕迹；

(2)拆卸连杆发现B7缸的连杆轴瓦的轴承合金烧结在连杆轴颈上，连杆轴承盖变色（蓝色）；

A7连杆弯曲变形；

连杆轴瓦全部都有较深的磨痕，无开口张弹力，连杆轴颈划痕明显；

(3)拆卸9副主轴瓦检查，曲轴主轴颈较光滑，没有明显的磨损痕迹，主轴表面均有较深的磨损痕迹；

(4)曲轴进行着色探伤检查，发现17缸的连杆轴颈有较多长约15mm的纵向裂纹，第7缸B7连杆轴颈有一条长约25mm的纵向裂纹；

(5)B列涡轮增压器拆卸后发现有金属屑，涡轮叶轮有较深的撞击麻点，叶片变形，一片叶上有约10mm缺口，转子轴靠涡轮一侧烧蚀变黑；

(6)AN涡轮增压器转子靠涡轮一侧烧蚀变黑；

(7)滑油齿轮泵拆下不能用手转动，拆解发现4个轴承被套烧结在轴上，泵壳体的齿轮端面磨损严重；

(8)抽出油底壳滑油时，滑油有大量的水；

油底壳拆出发现有很多的轴瓦熔屑散落底部；

(9)B7缸气阀顶杆弯曲变形；

(10)缸盖水压力试验，A2缸盖的进气口部位漏水。

# 原因分析

(1)该系列柴油机制造工艺可能达不到设计要求，现使用的TBD620V12型柴油机，已多次出现拉缸的故障。（2014~2015年期间）

这次出现故障的医疗快艇使用时间短，柴油机运行时间少（不足2000/小时），缸盖和运动部件没有拆卸修理过；

(2)前机舱左主机事故判断：

柴油机运行时B7缸负荷过大，活塞冷却不良造成拉缸，继续运行时活塞温度过高而熔化穿孔，燃气漏到曲轴箱引起油底壳压力高报警；

同时，拉缸的缸套温度升高导致缸套在密封胶圈部位的薄弱位置出现整圈的裂纹，大量的冷却水漏到机油中，当水被抽到滑油系统中，由于水粘度低便引起滑油压力低，安保系统的滑油压力低报警，连杆轴瓦和主轴瓦润滑不良做成磨损严重并烧蚀；

(3)曲轴1~7缸的连杆轴颈有较多长约15mm的纵向裂纹，第7缸B7连杆轴颈有一条长约25mm的纵向裂纹，主轴颈却光顺无异常，可能是该柴油机在本次故障停机前由于机油含有大量水份润滑效果差，连杆轴瓦磨损至表面划痕严重，加速裂纹的扩大；

(4)B列增压器损坏是由于B7缸的拉缸、活塞温度高熔化，损坏的活塞、活塞环碎片通过排气管吹入增压器，打烂喷嘴环和涡轮；

由于滑油中含大量水份，润滑不良引起涡轮轴高温变黑；

A列增压器涡轮轴高温变黑原因如前述；

(5)机油泵4个轴承被套全部烧蚀结在轴颈上，泵壳体的齿轮端面磨损严重，可判断是由于滑油中含大量水份，润滑不良引起。

# 故障排除

据其它柴油机修理厂反映，此机型的拉缸现象按常规的修理方法效果不佳，往往修理后在试航或负荷试验时再次出现拉缸。

对此，关键是查明原因，按柴油机拉缸故障的判断，对可能发生故障部位重点修理。

(1)由于整机出舱修理工程太大，在机舱内对柴油机进行零部件分解，零部件（除机架及机架上不需修理的附件）全部拆回车间修理，机架在机舱进行清洁修理。

拆下滑油喷嘴组件进行清洁、检修；

机体主油道清洁干净，采用油泵将干净的柴油连续冲洗一天，再用压缩空气吹洗；

(2)组合高压泵检修，油量均匀度调整至规定要求；

(3)曲轴、增压器、机油泵及损坏件换新，其它零件修复；

(4)润滑油冷却喷嘴安装后进行检查，将每缸活塞盘至下止点，观察喷嘴应准确插入活塞的油孔且不能与油孔边缘相碰；

(5)监控系统检测，效用（模拟）试验，尤其是曲轴箱压力高的报警装置反复多次试验，以确保该报警装置可靠准确。

# 预防措施

柴油机修理后磨合时间相应延长，空车在各档转速内来回磨合3小时（较常规修理要求为1小时），航行试验时间增加，将低负荷试验时间延长，使柴油机各部件尽可能磨合完好；

验收交付后使用初期，派专人重点监测曾经发生事故的柴油机工况，发现异常可作紧急处理。

# 监控系统改进

(1)该系列柴油机监控能对曲轴箱的压力进行监测，当压力增加至设定值时，报警装置发出声光报警讯号，但机舱内两台柴油机（或加上柴油发电机）的噪声大，容易忽略了报警声响。

值班人员收到讯号后，需到机旁控制箱（或集控室操纵台）查看报警的部位，再作出处理的反应，以防故障扩大。

(2)增加一个曲轴箱的压力传感器，压力值比报警传感器高50Pa，当出现轻微拉缸故障时，大量的燃气窜入曲轴箱内压力高于报警传感器设定的压力，发出声光报警，值班人员人工停机处理；

当拉缸故障严重时，曲轴箱压力高于停机传感器设定的压力，直接由控制器自动紧急停机，使拉缸故障发生初期能及时发现，故障较严重时自动停机，避免故障的恶化引起机器其它零部件的损坏。

经修理的柴油机频繁使用在一年半时间没有出现机械故障。

执行任务过程中，另一台柴油机曾经因曲轴箱压力高紧急停机，由于故障发生初期便停止运行，将损坏的缸套和活塞更换后，重新继续使用，避免了故障的扩大。
