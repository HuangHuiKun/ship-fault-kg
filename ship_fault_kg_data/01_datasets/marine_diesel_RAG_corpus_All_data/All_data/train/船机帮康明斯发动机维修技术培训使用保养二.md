# 维修康明斯电控发动机注意事项

本文以康明斯ISL8.9 CM2150SN型电控发动机为例，分享本人在维修过程中总结的4点注意事项。

## 1. 拔插ECM上的连接接头前注意事项

拔插ECM上的连接接头前，必须将点火开关转至off挡（断开系统电源），再进行拔插操作，拔插时注意观察针脚的状况，不可硬插强插，防止将ECM的针脚折弯或折断。测量针脚时需用连接线，不可用万用表表笔直接硬插强插。对车辆进行电焊作业时，必须将ECM从发动机上拆下来，否则将造成ECM损坏。同时，测量任何电阻都不可带电压测量，否则将导致测量不准确，造成误判断。

## 2. 高压燃油系统安全操作

康明斯电控高压共轨发动机的燃油泵、高压燃油管路和燃油油轨中含有压力非常高的燃油，其工作压力最高可达到1600bar，所以绝不可在发动机运转时松开任何管接头，必须在关闭发动机至少10min后，使压力降至较低水平再松开高压燃油系统的管接头，如有可能，使用INSITE康明斯专用诊断软件检测燃油压力，以确保安全。在进行高压泄露的识别/故障诊断与排除时，绝对不能用手或手指直接碰触测试，必须用纸板或其它介质代替，以免受伤。

## 3. 燃油系统清洁维护

维修过程中保持燃油系统清洁非常重要，解体前清理所有燃油系统管接头、管路和部件，确保没有任何污垢或碎屑进入燃油系统元件，以防止污染物进入高压燃油油轨和喷油器，少量的污垢和碎屑就能导致这些元件失效。电控发动机燃油系统工作的滤清要求为微米级，压力侧燃油滤清器不可预充，电控发动机燃油二级滤清器为10um级，具有油水分离功能，三级滤清器Sum级，其额定流量均为6.3L/min。建议不要预充压力侧燃油滤清器，就是为了防止损坏燃油系统中的关键部件。

## 4. ISLe CM2150发动机活塞冷却喷嘴拆卸

ISLe CM2150发动机的所有规格都采用了J形活塞冷却喷嘴，喷嘴有带肩螺栓固定到位，拆卸活塞前必须将其拆下。

在维修发动机时最好先想后做、由简到繁、从表至里，最后根除故障。
