# 一、活塞外圆表面的磨损部位

一般中小型柴油机的筒形活塞裙部外表面容易发生磨损，这是运转中活塞裙部起导向作用和承受侧推力的结果。

活塞的磨损

大型十字头式柴油机活塞运动部件的运动是靠导板、滑块起导向作用和承受侧推力，况且活塞与气缸之间的间隙较大，所以正常运转中活塞外圆面是不会磨损的，只有在活塞运动装置不正和拉缸等异常情况下才会发生。

活塞裙部外表面磨损后，裙部的直径减小，活塞与气缸的间隙增大；

横截面产生圆度误差，纵截面产生圆柱度误差。

这些都直接影响活塞的工作性能和柴油机的功率。

在船上通过测量活塞直径来检验活塞的磨损程度。

通常采用外径千分尺、游标卡尺进行测量。

外径千分尺

测量部位为活塞的上部、中部和裙部的外径，如有减磨环的活塞应测量每道环的外径。

测量每一测量点的横截面上相互垂直的两个直径：平行曲轴方向的直径和垂直曲轴方向的直径。

将测量值记录在表格中，计算出每个横截面的圆度、纵截面的圆柱度，以其中最大值与说明书或标准比较，以确定活塞的磨损程度。

# 二、活塞外圆表面磨损的测量与计算

1. 根据所测活塞的直径选择合适的外径千分尺。

2. 外径千分尺校对零位。

3. 选择测量位置：

对于中小型筒形活塞应自活塞头部活塞环槽向下10~20mm处为一个测量点，由裙部上端10~20mm处为另一个测量点，在其中每隔100~200mm选一个测量点。

每一部位都应沿纵向和横向两个垂直方向（即活塞销中心线方向和与此相垂直的方向）测量，如下图所示：

对于十字头式柴油机活塞，还应测量减磨环纵、横两个方向尺寸，以查明其磨损情况。

4. 测量活塞的直径：

用外径千分尺的一端固定在测量点上，另一端先在活塞上前后移动找最大点，再在最大点处上下移动找到最小点，该点即为直径位置，并重复检查一次。如果测量合适即锁紧，并读出读数。

5. 依次测量活塞上其它各测量点的数值，并将测量的数据填入记录表中，如下图所示：

6. 计算：根据测量记录表中的测量数据，按照圆度和圆柱度的计算公式，计算出圆度和圆柱度。

如果实际活塞的测定值超出规定的极限值，则需要修理或更换活塞。

# 三、活塞外表面磨损的修复

活塞裙部外表面磨损不太严重时，采用光车裙部外圆，消除几何形状误差。

光车后活塞与气缸间隙仍满足要求时可继续使用，否则依活塞材料不同采用不同的对策：

铝活塞采用换新；

铸铁活塞采用热喷涂、镀铁等恢复尺寸；

铸钢活塞采用镀铁、堆焊金属等恢复尺寸。

减磨环过度磨损、严重拉伤或松动时应换新。
