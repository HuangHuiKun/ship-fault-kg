# 导读

船舶副机飞车事故并不是经常发生，但是一旦发生飞车事故，对船舶影响很大，所以无论是航行还是抛锚或者在港内，机舱值班人员都应密切观察发电机的运转情况，特别应注意负荷的变化，滑油压力以及排烟温度，一旦发现异常，立即通知轮机员。

另外，在没有轮机员在场或者操作不熟的情况下不要擅自启动副机。

我轮一号副机飞车事故的起因就是大管轮对启动副机操作步骤不熟，启动前没有润滑和活动油门拉杆，启动后油门拉杆卡死在最大位置而导致副机飞车，飞车发生后由于紧张没有及时切断供油，导致一号副机飞车达五分钟。

所以我们在以后的工作中一定要注意，避免类似的事故的发生。

# 飞车的定义及危害

## 飞车的定义

由于柴油机负荷经常变化，这就要求调速器根据柴油机负荷的变化不断调整供油量，一旦由于某种原因不能及时减少供油量，就会引起柴油机转速急剧上升而超过其最高使用转速，即我们所说的柴油机“飞车”。

## 飞车的危害

柴油机飞车的危害具体表现在以下几个方面:

一是由于柴油机的转速上升，各部磨擦副产生的热量急剧增大，原有的散热规律被破坏，致使轴承严重剥离、烧损及熔化，曲轴的主轴颈和连杆颈以及凸轮轴颈也将受到严重的破坏。

二是由于柴油机转速的超限，配气机构中的摇臂、横臂、气阀弹簧等零部件，将失去其原来的运动规律性，从而导致有关零部件的断裂。

由于进、排气阀和活塞运动规律的紊乱，使气阀和活塞的运动轨迹相交，从而造成气阀杆被顶弯、各活塞顶破损等事故。

三是超速运转将导致燃烧过程的恶化，排气大量冒黑烟，排气温度升高，增压器超速。

四是如果柴油机飞车时间过长，还可能使凸轮轴驱动齿轮错位和凸轮轴弯曲，从而导致喷油定时紊乱。

在事故处理过后，再次起动副机前，要重新调整喷油定时和供油量，以保证供油正确。因此分析柴油机发生“飞车”的原因，采取行之有效的预防措施是非常必要的。

# 副机飞车可能原因及处理

## 飞车可能原因

柴油机飞车是指转速失去控制，大大逾越额定转速，发动机剧烈振动，发出轰鸣声，排气管冒出大量黑烟或蓝烟的故障现象。

飞车不只造成零部件损坏，而且危及人身安全，应引起机舱人员的高度重视。

引起柴油机飞车的原因很多，但基本分为2类:

一是燃油超供;二是窜烧滑油。

两种飞车虽然都表现为柴油机超速运转，但具体表现有差别。

柴油超供引起飞车时，排气管冒黑烟，一般可用切断供油的方法制止;窜烧滑油引起柴油机飞车时，排气管冒蓝烟，这时只切断供油不能有效地制止，必需同时断绝空气供给和急速减压来制止。

现将引起柴油机飞车的原因及其处置方法列出如下:

### 柴油超供引起柴油机飞车的原因:

1. 柱塞调节臂或齿杆调节臂球头未进入调节叉凹槽内，柱塞处于最大供油位置。
2. 油泵柱塞转动不灵。
这是柴油机飞车的罕见原因。柱塞处于最大供油位置，调速器拉不动，以致转速升高，调速器起不到控制油量的作用。
引起柱塞转动不灵的原因有:装配时柱塞被碰伤;油泵内有脏物，使杂质进入柱塞副的间隙中;出油阀座拧紧时力矩太大，致使柱塞套变形;柱塞套定位螺钉上的垫片太薄，定位螺钉顶住柱塞套，使之变形;柱塞套定位螺钉太长或弯曲，装配时顶死柱塞套。
3. 喷油器磨损后使大量接入进气管的回油被吸入气缸，造成气缸燃油过量。
4. 安装调速器时，钢球上涂黄油过多，且黄油太粘稠，造成转速升高时钢球难以飞开。
5. 齿杆齿圈无记号或装错、柱塞装反。
6. 唢油压力低，供给气缸燃油过量。
7. 拉杆与调速器活动部位卡滞。
8. 调速器调试不当。

### 滑油引起柴油机飞车的原因:

1. 空气滤器中滑油过多，被吸入气缸。
2. 油底壳滑油过多，工作时窜入气缸。
3. 曲轴箱通气孔堵塞，气压增高，使滑油被压入燃烧室。
4. 活塞环严重磨损，缸套间隙过大，或活塞环开口对齐时，大量滑油窜入燃烧室。
5. 滑油过稀，很容易窜入燃烧室。
引起滑油过稀的原因有:柴油漏进油底壳;柴油机温度过高;滑油质量不符合要求。
6. 油环及活塞上的回油孔堵塞，使滑油窜入燃烧室。

## 柴油机飞车发生时的处置措施

当我轮出现“飞车”事故时，轮机长果断地采取了如下措施:

1. 切断电源。
为保护船舶电航设备及机舱电器设备，首先将该机与船舶电网应急切断;
2. 切断油路。
试图打开该机各缸喷油器的回油阀，但未成功，继而试图切断燃油滤器出油管，亦遭失败。
与此同时，关闭了燃油截止阀及日用燃油柜速闭阀。
由于断油，迫使1#副机停止了运转;
3. 防止火灾。
由于排烟管温度甚高，加之机舱油气较大，有发生火灾的危险，所以使用1211灭火器对排烟管进行喷洒;
4. 盘车。
由于“飞车"时间较长(约5分钟)，为防止气缸及各部轴承咬死，所以在停车后进行了盘车，发现已无法继续盘车。

# 事故处理过程

## 一号副机吊缸

一是吊缸前的准备工作:主要包括物料，工具，起重设备的准备。

1. 物料准备:发电机备件的准备:如进排气阀，喷油器，缸套胶圈，活塞环及附件的准备等等。
2. 工具的准备:检修吊缸时各种专用和通用工具。

1. 拆除摇臂顶盖和曲拐箱盖。
2. 拆除排烟管和冷却水管。

4. 取下气阀顶杆，摇臂和油头。
5. 卸下压紧螺母，吊出缸头。

7. 清洁进排气阀和油头。
8. 卸下连杆和活塞杆之间的贯穿螺栓，吊出活塞。
清洁活塞头和缸头以及气阀的研磨。

## 拆卸凸轮轴更换凸轮

1. 拆卸缸头上的所有进排气阀摇臂和顶杆。
2. 拆卸所有高压油泵及驱动装置。
3. 拆卸调速器及驱动装置。
4. 拆卸安装在齿轮箱盖上的各种油泵、传动装置及各种附件，拆卸与其相连的各种油、气、水管等。
5. 将燃油凸轮锁紧螺母松开使其可以活动。
6. 打开齿轮箱端盖，查看曲轴齿轮上的“马克”与凸轮轴齿轮上的“马克”的相对位置，并盘车直到曲轴齿轮的“马克”与凸轮轴齿轮的“马克”相对应为止。
7. 拆卸凸轮轴齿轮（注意齿轮两侧垫片的位置要做“马克”)，拆卸凸轮轴齿轮后直到装复前不能再盘车。以免定时错乱。
8. 拆卸机体上相对凸轮轴轴承位置上的定位螺栓（空心进油管)。
9. 拆卸凸轮轴中间的联轴节(凸轮轴一般为2段)，同时查看﹖段凸轮轴轴端上的“马克”(一般为0对0)，此位置相对机体上也要做好“马克”。
10. 参照说明书检查凸轮轴轴承下面是否有固定销，如有拆下。
11. 检查阻碍凸轮轴移动的各个部位特别是凸轮轴轴承是否可以移动。
12. 向齿轮箱侧移动第一段凸轮轴并取出，再移动第二段凸轮轴并取出。
13. 将凸轮轴移至工作间，将进排气凸轮在凸轮轴上的相对位置做好“马克”。
14. 用火烘烤进排气凸轮，同时用榔头敲打凸轮取下进排气凸轮，烘烤凸轮时注意尽可能的不要烧凸轮正表面，同时用水冷却凸轮轴。
15. 组装凸轮轴凸轮时，将进排气凸轮放在机油中加热到400-500度左右，用石棉手套拿起凸轮迅速按凸轮轴上的马克位置组装凸轮。
16. 凸轮轴组装完毕后，按照相对顺序装入机体（注意2段凸轮轴联轴节处的“马克”相对为0对0)。
17. 按照拆卸时的每个环节进行组装凸轮轴轴承及其定位螺栓和其它部件。
18. 安装凸轮轴齿轮时注意曲轴齿轮与凸轮轴齿轮上的“马克”位置相对应，并使凸轮轴中间联轴节（0对0)“马克”与机体“马克”相对应。
19. 所有部件装复后，按照说明书要求调整燃油凸轮定时，然后锁紧燃油凸轮。
20. 检查所有按装部件是否正确，并盘车检查，确认没有问题时对副机进行冲、活车，如冲车时副机不转，可将空气分配器打开,将空气分配器内动盘插头位置转动180度角,然后装复启动副机进行冲、活车，当副机在空气驱动下运转时说明凸轮轴安装定时没有问题。

## 柴油机喷油定时和供油规律的调整

柴油机喷油定时的正确性和每个循环供油量的多少是保证柴油机正常运转和在最佳工况下工作的关键因素，若喷油定时不准确会使柴油机不能启动或启动后工作粗暴、油耗大、功率发挥不正常、效率降低、机械负荷的热负荷大,机械磨损大,经济性能差。

由于柴油机飞车后喷油定时已被打乱，所以在吊缸完成后需要对喷油定时以及供油规律进行重新调整。

### 喷油定时的调整

#### 喷油提前角的检查:

1. 看几何喷油时间:
对单体式喷油泵,其导程筒上一般有一条定时线,泵体上的检视孔也有一条线。
当该缸活塞转至压缩上止点前的喷油提前角位置时,停车检查两刻线是否对齐,如两刻线不对齐说明喷油时间不准;导程筒上的刻线高于泵体上的刻线,表示喷油过早、喷油提前角过大;反之则喷油过迟、喷油提前角过小。
对组合式喷油泵,将第一缸转至压缩上止点前喷油提前角位置,看油泵凸轮轴的规时线与泵体上的规时线是否对齐,对齐说明供油规律正确;如两刻线不对齐,调整第一缸柱塞下面的螺钉,使两刻线对齐,调整其定时。
2. 看高压油管油面波动时间:
此方法船上一般常用,对单体式和组合式喷油泵均适用。
操作方法是:拆下该缸喷油泵上的高压油管,取出出油阀,装上液面指示器(也可直接观察油面),转动曲轴一旦液面指示器波动(在液面波动的瞬时),表示该缸已开始喷油,此时指针所指的飞轮刻度即为该缸喷油提前角。

#### 喷油提前角的调整:

不同结构的喷油泵,喷油提前角的调整方法各不相同,但总的来说由于喷油柱塞是凸轮推动的,凸轮轴是由曲轴推动的,所以,凡是能改变油泵柱塞与喷油凸轮的相对位置或改变凸轮轴相对位置,都能达到调整喷油提前角的目的。

具体调节方法如下:

1. 喷油泵调节螺钉调节法。
喷油泵的传动装置中,顶头处装有调节螺钉,如NVD型柴油机将螺钉上旋改变了柱塞与喷油凸轮的相对位置,柱塞先移动,喷油提前,提前角加大;反之,则喷油延迟。
2. 转动凸轮法:
有些分制式凸轮轴,因凸轮轴分开制造,后组装,故可转动凸轮。
改变凸轮与凸轮轴之间的相对位置,实际上是通过改变凸轮与曲轴的相对位置来改变喷油提前角。
3. 垫片调整法:
单体式喷油泵,在泵体与底座的安装处,往往垫有一定厚度的可供调节垫片,增加垫片则喷油提前角减小;反之则增大。
4. 调整联轴器盘与组合式喷油泵凸轮轴的相对位置,组合式喷油泵是多缸一起总调，调整方法为:将第一缸转至开始喷油角度(用液面波动法),然后松开联轴器上的2个联接螺钉,使喷油凸轮与传动轴脱离,再转动曲轴,此时凸轮轴位置改变,曲轴转至飞轮指示第一缸喷油提前角时,停止转动曲轴,再旋紧联轴器上的2个联接锣钉，喷油提前角得到调整。

### 供油规律的检查与调整

供油规律和凸轮最佳工作段的选择喷入气缸的燃油量随曲柄转角变化的关系称为供油规律。

供油规律不仅影响柴油机的工作粗暴性,而且对柴油机的作功能力和经济性能也有很大影响。

供油规律主要由燃油系统中的凸轮外形来决定,因为不同的凸轮外形决定了油泵柱塞上升的规律和速度,因而一般合理的供油规律应该是开始喷油阶段供油较少,喷油压力降低以减少初期的喷油量,喷油的中期和后期,供油的速度和压力应迅速上升急剧地增加喷油量,提高喷柱的贯穿力和雾化质量,以提高燃烧后期的完善性。

燃烧最高压力较高,工作粗暴,但喷油延续时期短,燃烧速度快,使柴油机做功能力和经济性增高。

因而凸轮最佳工作段的选择与供油始点有关,如始点后移可提高供油速度,增加喷油压力,缩短延续时期,每循环的供量也有所增加。

柴油机其组合油泵缩节轴上与泵壳上有刻线,刻线对准说明油泵柱塞中心线与凸轮中心线夹角确定，其供油规律也确定。

喷油定时对柴油机正常运转影响柴油机喷油开始,经喷油延续时间到喷油结束称喷油定时。

为了使柴油机充分发挥功率,就得使最高爆发压力发生在上止点后约50～30°,因燃油喷入气缸后需与空气混合以后才能燃烧,这样喷入气缸达到最高爆发压力均需一段时间,就需要有一个喷油提前角。

一般喷油提前角约上止点前5～30°曲柄转角,当喷油提前角太小,喷油过迟,喷入气缸的燃油来不及燃烧,活塞已越过上止点下行,气缸内压力及温度降低,形成后燃烧严重,冒黑烟,排温升高,热效率降低,功率下降;

当喷油提前角太大,喷油过早缸内温度未达到燃油自燃温度,直至过了一段时间才达到自燃温度。

由于滞燃期长,聚积的燃油一旦燃烧,气缸内气体的温度、压力急聚上升,柴油机工作粗暴,产生敲缸,机件热负荷和机械热负荷均增加。

同样,喷油延续时间的长短,直接与柴油机的功率、燃油消耗及排烟情况有关,喷油延续时间过短,经济性、冒烟状况均好转,但因燃油靠近上止点，燃烧滞燃期聚积的燃烧多,柴油机工作粗暴。

相反,喷油延续时间过长,柴油机运转虽然柔和,但耗油过多,排气冒黑烟,后燃严重,机器过热。

# 防止船舶发电机飞车的措施及注意事项

## 为预防柴油机发生飞车故障,应做到以下几点:

1. 不要随意调整和拆卸高压油泵，确需调整，应在专门的试验台上进行。
2. 加强柴油机燃油泵的颐养工作，坚持高压油泵的齿杆、扇形齿轮、控制套等机件的清洁，并经常检查扇形齿轮与控制套的配合情况，保证其配合正确，活动灵活。
3. 空气滤器油盘内不能加油过多，并定期更换调速器的润滑油，加注的滑油也不宜过多。
4. 燃油和润滑油质量应符合规定。
5. 对长期停放的柴油机，启动前，应检查调速器有关零件，清除锈蚀后再使用。
6. 用轻油清洗好的滤芯，一定要甩净轻油，并在大气中将汽油充分蒸发后方可装入滤清器内。
7. 及时更换损坏的油封。

## 防止柴油机“飞车”在运用保养方面应注意的事项

1. 经常对供油拉杆的支撑滚轮及喷油泵的供油齿条进行给油保养，使之动作灵活不卡滞。
2. 不得以供油拉杆为支点撬动其它部件，检修柴油机时不准蹬踏供油拉杆。
3. 在柴油机启动前和机车运行中，要按规定检查柴油机调控系统各元件间的连接状态，做到各种销、垫齐全且连接状态良好，发现有松动、裂纹处所及时处理，防止有关零部件断裂、松脱而卡住拉杆。
4. 日常禁止用扳动供油拉杆的方法启动柴油机。在不得已的情况下作为应急处理而须人为扳动供油拉杆时，操作人员必须密切配合，注意柴油机转速的变化，一旦发生转速飞升的迹象要立即使柴油机停机。
5. 定期对超速停车装置进行确认，确认作用良好无卡滞，同时相关连杆连接可靠，并能将供油齿条拉回停车位。
6. 在正常情况下，变换手柄位置时，要同时注意柴油机转速的变化，并在“1”位稍停，柴油机的转速稳定后再回到零位。

## 防止柴油机“飞车”在检修作业方面应注意的事项

1. 在每次中修时测量拉杆系统的总阻力，不能超过“段规”的规定值（在弹性连接处，用弹簧称拉动整个供油栏杆系统，总阻力不大于5公斤，各油泵接入后应不大于12公斤N)﹔测量控制机构总间隙不大于0.5mm。
2. 柴油机修理完毕启动柴油机前，须确认拉杆近旁是否有阻碍拉杆移动的工具、零件和棉丝等异物。
3. 检修调速器时必须保证清洁，所有拆出的零部件要仔细清晰，禁止用棉纱、棉布擦拭。调速器要按规定换油，加油口滤网，防尘帽须完整并作用良好。
4. 供油刻线应符合规定，非检修人员不得随意调整，各喷油泵齿条指针必须固定牢固，供油齿条动作必须灵活。
5. 极限调速器在组装时，严格保证质量，极限调速器飞锤的上方装有拐臂，拐臂的下端装有滚轮，用塞尺测得滚轮与飞锤之间的距离为a=0.3mm~0.5mm，以保证飞锤在旋转中既不与摇臂上的滚轮相碰，又能在规定的转速下(680r/min~760r/min)飞锤甩出时有效地作用在摇臂滚轮上，使停车器动作。

# 总结

上面通过对副机飞车实例的分析和处理,总结了副机故障的诊断及排除方法以及在实际工作中应注意的一些问题，分析了引起发电机飞车的各种原因，产生故障的原因也是多方面的，但是有不少故障是由于人为因素造成的，如操作管理不当等。

因此在船舶副机系统日常维护和管理中,应该严格按照操作规程来进行操作,注意系统的压力和排烟温度等重要参数，经常检查易出现故障部件，发现异常及时采取措施，避免故障扩大或恶化。

在排除故障时，应详细调查研究，认真仔细分析，以便及时准确找出故障原因，确定排除故障的方法。

作为轮机管理人员，除应能熟练运用有关理论知识，并汲取实践经验，总结故障诊断与排除的一般方法外，更重要的是，结合实践经验，注意在日常维护管理工作中，正确操作，严格执行安全技术规程，预防故障的出现，做到防患于未然，保证系统正常可靠的工作。
