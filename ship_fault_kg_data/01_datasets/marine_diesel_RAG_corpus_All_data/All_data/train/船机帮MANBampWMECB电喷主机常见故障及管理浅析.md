# 导读

相比 MC，MAN B&W ME-C/B 船用电喷柴油机由于采用了电子监测，所以能够随时监测机器状态，自动调整喷油量、喷油速率变化等参数，保证机器在整个运行期间处于最佳状态，满足了低排放、低油耗的要求。

正因如此，从 2003 年面世至今，凭借着自身的优良性能和更经济的油耗、低排放、易于操作等特点，得到了市场的高度认可。

但是和所有产品一样，该系列船用柴油机也有其不完美的地方，如果使用或管理不当仍然会出现各种问题。

本文以实船管理中收集的案例为例，通过分析ME-C/B 电喷柴油机在运行过程中常见的问题，提出日常工作中的若干使用和管理要点。

## 一、HPS 单元泵轴断裂

### 1、故障现象及处理

FLH 轮2017年11月5日自釜山开往美国装货港哥伦比亚河道的VANCOUVER港途中，于2017年11月7日1625L（0605GMT）在日本海接近清津海峡口附近（40°59′.0N，139°43.0′E）时，主机发生“large deviation from model curve”和“hyd. press.deviates from set point”“low hydraulic pressure”报警，自动降速。

船舶随后将另外的两台机带液压泵分别设置成主泵运行试验，故障相同。

因在主机停车和刚启车期间，电动液压泵运行时液压油压力正常，故怀疑机带泵系统存在漏泄。

主机停车后，拆检 310 阀组的安全阀，未见异物；用压缩空气吹净后装复试验，故障依旧；更换 310 阀组的电磁阀一只，也未解决问题。

于是船舶将此情况电话报告机务并按其指导启车试验，然后用压力表在机带液压泵本体压力接头处测量压力，结果 1#、3#泵的排出压力基本与其吸入口压力相同；2#泵排压为18MPa，与系统显示的压力相同。

由此不难看出，只有 2#泵工作正常，而 1#、3#泵则处于故障（不工作）状态。

据此判断可能是泵轴连接处出现了问题。

停车后经对 1#、3#泵进行检查，确认泵轴断裂。

3）从后来的调查情况来看，FLH 轮在上个航次从美国回航的途中多次遭遇大风。此次泵轴断裂应和驱动轴较长时间承受交变负荷的高应力扭矩有关。

### 3、避免故障措施

通常，在交变负荷下经过长时间的高应力扭矩会使泵轴内部剪切螺母发生断裂，因此在大风浪天气下要加强对该螺母的检查。

后端链条张紧度不合适会导致泵轴受力不均从而承受过大的附加负荷，因此要加强对链条张紧度的检查。

材质低劣、装配工艺不合要求也会导致泵轴螺栓断裂，因此务必选择质量过关、装配工艺合格的泵轴。

## 二、排气阀行程不正常

### 1、故障现象及处理

2016年12月27日，FXH 轮正常航行中主机出现“Exhaust Valve Stroke Low”报警继而主机降速故障。

船员检查排气阀控制空气压力（0.65~0.75MPa）、控制空气止回阀状况（检查止回阀阀芯、阀座以及弹簧弹力等）正常。

互换排气阀传感器后，报警依旧。

最后更换排气阀整体，故障得以消除。

### 2、故障原因及分析

排气阀没有全开或者没有全关，“Exhaust Valve Stroke Low”报警都会出现。

这个报警不仅涉及排气阀本身，还和控制排气阀的 CCU（Cylinder Control Unit）、FIVA 阀、反馈探头有关系。

涉及机械部分的原因有以下几方面。

1）液压顶杆中有空气，导致排气阀不能全开或者全关；

2）排气阀执行机构补油管路的两个止回阀失效，导致报警，还会敲缸；

3）排气阀杆在导套中运动受到卡阻。

主要原因是排气阀杆在运行的过程中，空气弹簧下部的密封状态不好，滑油漏泄积碳，造成排气阀开关阻力过大。

从后来对换下的排气阀拆检来看，空气缸密封圈老化导致漏气，就是此次故障的原因；

4）空气弹簧进口止回阀脏污堵塞造成进气量少以及安全阀泄漏、开阀压力不足。

### 3、避免故障措施

1）经常通过松开液压油缸顶部放气螺钉放气；

2）经常检查排气阀执行机构补油管路的两个止回阀，确保功能正常；

3）空气缸密封圈老化就会导致漏气。建议经常进行排气阀密封性试验，并和其它缸对比一下时间。

具体步骤是：

Engine stop→Switch to Exhaust valve interface according to the attachment（Troubleshooting-HCU）→Close air supply from engine to Exhaust valve （handle position is at middle platform of main engine）→Watch Exhaust valve current ( CH34 ) and confirm how long will it changed .The judge Point is that the value of CH34 begins to vary；

4）经常检查空气弹簧进口止回阀是否脏污堵塞，安全阀是否泄漏，发现问题及时检修。

## 三、主机活塞杆螺栓断裂

### 1、故障现象及处理

2018年05月07日0359L，FMH 轮在新加坡加油锚地备车航行途中，显示屏出现主机扫气箱泄放柜高位警报。

由于三管轮对该柜三天一驳（从未出现过高位警报），且昨天刚刚驳空，现在出现警报，肯定有不正常的泄漏情况发生。

轮机长查看了电脑显示屏：

主机各项工况参数正常，只有 No.3缸活塞冷却油出口温度高了 3℃多，于是亲自到主机机旁检查，发现主机 No.3 缸活塞冷却油油流观察镜的油，颜色比其它缸的淡；

然后到扫气箱层把该缸的泄放总阀关闭，取来油瓶，打开取油样“考克”，发现有大量的滑油流出。

轮机长由此判断主机 No.3 缸活塞冷却油发生了不正常泄漏，并立刻打电话向船长说明情况。

由于船舶正在机动航行驶往新加坡加油锚地，不能停车检修，只能密切观察主机工况状态，以期进一步采取措施。

0623L，在新加坡锚地抛好锚。

过了几分钟后，轮机长安排人员把主机 No.3 缸扫气箱前后道门打开，并充分通风，经过测氧仪检测正常后进入扫气箱检查（申请表已提前向船长申请并得到许可），发现活塞与活塞杆之间的一根固定螺栓不见了。

孔洞中正向外泄漏着大量的滑油，见图5；之后从扫气箱内找到了丢失的螺栓（螺栓头部与杆体分离散落），见图 6。

### 2、故障原因分析

1）产品质量问题。

厂家可以通过在试验室对断裂的螺栓材料进行磨片检测（主要检测其内部的金属材料成分、强度、热处理等），以确认质量是否达标合格；

2）安装工艺原因：预紧力大小不合适、预紧方法不正确、预紧次序不正确等；

3）另外一个常见原因，可能是活塞杆法兰上端和活塞头的接触面（该处靠 060 垫床密封）平整度不够，以致无法保证连接体的紧密接触。

我们知道在活塞长期往复惯性力以及柴油机长期复杂运转的作用下，凹凸不平的结合面很容易形成间隙，从而导致活塞杆连接螺栓松动。

活塞杆螺栓松动后，柴油机运转时，活塞头、活塞群、活塞杆的配合接触面就会产生敲击磨损，严重时就引起活塞头连接螺栓的断裂，使冷却机油大量地泄漏到扫气箱。

对此可以通过目测松动的螺栓孔附近的接触圈带是否在同一个平面来判断。

不在同一平面，就意味着活塞杆法兰上端和活塞头的接触面凹凸不平。

如果是这种原因，就必须加工车平其接触面，否则尽管把活塞杆的螺栓锁到足够紧，柴油机短时间运转后仍会造成螺栓再次松脱，严重时可造成活塞杆螺栓断裂。

从后来的调查结果来看，发生故障船舶（不只一条船）的螺栓是同一批次的产品。

这说明，故障的发生和螺栓质量欠佳有关。

### 3、避免故障的措施

选择质量合格的活塞杆螺栓，采购原厂件做备件；严格按照说明书的要求对活塞杆螺栓进行安装；确保活塞杆法兰上端和活塞头的接触面平整度达到标准。

## 四、结束语

船舶主机的运行管理，是船舶设备管理中最重要且关键的环节。

由于受到船舶振动、灰尘污染、环境温度等综合因素的影响，经常会导致主机设备部件发生故障。

因此，轮机管理人员不仅要懂得设备的基本结构、原理、操作、检查和维护保养，还要掌握应急故障处理。

随着电喷主机在新造船舶上的大量使用，对主管人员在新技术、新特点方面提出了更高的要求，轮机管理人员必须熟悉和掌握。
