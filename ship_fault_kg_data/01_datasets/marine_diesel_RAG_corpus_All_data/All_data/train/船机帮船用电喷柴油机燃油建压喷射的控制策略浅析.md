# 导读

电喷型船用柴油机较传统船用柴油机而言，是由保留了最低限度的机械部件的往复式原动机本体(传统发动机上的喷油泵、燃/排凸轮、换向伺服系统、机械调速系统、空气分配器等机械部件均被取消）与电子控制的燃油喷射单元、排气阀控制单元等组成的伺服受控系统及由电子集成模块(控制、监测等多种模块)组成的电子控制系统组合而成的能最大限度地按人们的意志、按不同运行模式灵活运转的船用推进主机。

简而言之：通过电子控制系统及各种伺服器件来实现和控制柴油机的燃油喷射、喷射正时、燃油计量等是电喷柴油机的主要特征。

本文就MAN、WCH二大专利公司的电喷柴油机燃油喷射及排气控制的策略进行解析：

# MAN ME电喷柴油机的燃油喷射及排气控制系统

MAN ME电喷柴油机的燃油喷射及排气启闭采用液一电控制方式，既由液压动力单元(HPS)提供的高压液压油作为动力，通过气缸液压单元(HCU)经由FIVA阀控制，驱动燃油升压泵和排气驱动泵，从而实现柴油机的燃油建压、定时喷射、燃油油量控制和排气阀定时启闭的控制，进而实现柴油机的升速、降速等运行模式闭环调节。

ME电喷柴油机的每一气缸布置有一个独立的气缸液压单元(ricu)。

气缸液压单元由、燃油升压泵、排气阀驱动泵、气缸注油器等受控单元和承担控制作用FIVA阀与液压分配器组合而成。

燃油升压泵由液压油通过液压活塞驱动。

# WCH flex电喷柴油机的燃油喷射及排气控制系统

WCH flex电喷柴油机的燃油喷射及排气启闭采用共轨控制型式，既：恒定压力为1000bar的高压燃油和200bar的液压伺服油由独立的供油单元创建并分别输送至燃油共轨管和伺服油共轨管。

而燃油的喷射正时、计量、喷射模式的转换等由受命于柴油机控制系统(WECS一95XX)的燃油喷射控制单元(ICU)来实施，排气阀开启、关闭及正时则由受命于柴油机控制系统(WECS一95XX)的排气控制单元(VCU)来实施。

燃油喷射控制单元(ICU)为每缸一个，安装于燃油共轨管上并通过高压油管与喷油器连接。

排气阀控制单元(VCU)也为每缸一个，安装于伺服油共轨管上并通过高压液压管与排气阀连接。

# 功能实现方式列表

# MAN—ME和WCH—flex电喷柴油机燃油喷射及排气控制方式主要不同点分析

## 喷射压力

MAN—ME电喷柴油机燃油系统采用的是单体泵形式(每缸一泵)，燃油泵通过高压燃油管直接与喷油器连接，喷油器前的燃油压力是随着燃油泵柱塞行程位置的变化而变化，呈周期性的正弦波状(每转一个波型)，虽其压力升速率比常规柴油机高的多，但其波状类同于常规柴油机。

WCH—flex电喷柴油机燃油系统采用的是高压共轨形式，高压燃油以恒定压力(1000bar)储蓄于燃油共轨管内，由燃油喷射控制单元(ICU)计时、计量，经喷油器实施燃油的等压喷射。

较前者而言：

其喷射速率更高、燃油雾化质量更佳，这就更有利于柴油机的燃油消耗率的下降和柴油机排放性能的提升。

## 喷射模式

MAN—ME电喷柴油机受命于控制系统的多通阀的受控对象为“燃油泵”，一个燃油泵通过高压油管连接二或三个喷油器(每一缸的二或三个喷油器始终是同时工作的)，在一个喷油循环中通过多通阀运行模式的转变可实现分次喷射(最多可分二次喷射)。

WCH—flex电喷柴油机受命子控制系统的燃油喷射控制单元(ICU)的受控对象为“喷油器”，并且燃油喷射控制单元(ICU)上布置有二或三个控制阀，每个控制阀能独立地直接控制对应喷油器的喷射。

较前者而言：

在一个喷油循环中，除可实现分次喷射(最多可分三次喷射)外，还可实现预喷射、顺序喷射(二或三个喷油器轮流喷射、单个喷射)等多种喷射模式，可根据柴油机不同工况、最大限度灵活地转换不同的喷射模式。

使柴油机在全负荷实现较底的燃油消耗率。

特别是在柴油机极低转速运转时，由于其能自动的转换为单个喷油器喷射，可有效避免由于燃油喷射压力过低而引起的燃烧不良(排温高、冒黑烟等)和个别气缸发生间隔性息火而造成的转速波动。

柴油机最低稳定转速可低至标定转速的10～12％。

## 排气阀控制模式

MAN—ME电喷柴油机排气阀的开启和关闭由多通阀控制，虽其启一闭速率比常规柴油机高的多，但由于与燃油升压泵合用同一多通阀，排气正时的设计不可避免的受燃油正时的牵制，即排气正时只能与燃油正时进行最佳组合，而不能单独实现最大限度的优化(燃油正时也亦此) WCH—flex电喷柴油机排气阀的开启和关闭采用的是伺服共轨形式，每一排气阀有一个独立的受命于控制系统的控制阀，排气正时的设计不受燃油正时的牵制，能按需单独实现最大限度的优化。

注：MAN的ME—B电喷柴油机，其排气驱动已从HCU中分离，即不再受多通阀的控制，而是改由机械凸轮控制，这就可避免燃油正时与排气正时相互间的的牵制。
