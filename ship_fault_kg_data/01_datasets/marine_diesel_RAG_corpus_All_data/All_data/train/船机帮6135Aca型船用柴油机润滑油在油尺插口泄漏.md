# 导读

当发动机工作时，会有少量的可燃混合气和废气经活塞、活塞环与气缸之间的间隙漏入到曲轴箱内。

漏入曲轴箱内的燃油增发凝结后将使润滑油变稀、润滑油性能变坏。

同时还会引起曲轴箱内压力增高，造成油封和衬垫处漏油。

因此，曲轴箱设有通风装置，将漏入的混合气和废气排出或吸出。

下面结合引言中的论述对6135Aca型船用柴油机润滑油在油尺插口泄漏进行分析。

# 一、润滑油在油尺插口泄漏相关的几个问题

## 1、润滑油尺插孔的结构

润滑油尺插孔是由Ф14mm、长80mm的薄壁钢管和与油底壳一同铸造的圆孔组合而成；薄壁钢管以螺扣形式旋紧在油底壳铸造孔上。

此孔在油底壳侧壁的中部，垂直高度 180mm。

底部留有与油底壳内部相通的孔，润滑油尺通过薄壁钢管上部插口插入此孔。

## 2、润滑油尺的几个刻度线

油尺长160mm；静满长65mm；动满长 45mm；险长12mm。

在柴油机基本保持水平状态下，标尺上的刻线“静满”表示柴油机启动前应有的润滑油面；“动满”表示柴油机运转时应保持的润滑油平面；“险”表示应立即添加润滑油的最低位置。

## 3、柴油机静止和运转工况下润滑油面相对于润滑油尺插孔在高度上的变化

润滑油面在柴油机的静止状态处于油尺静满刻线，在油尺插孔中部，距油尺插孔底部与油底壳内部相通的孔85mm；柴油机运转工况下，润滑油面处于油尺动满刻线，在油尺插孔中下部，距油尺插孔底部与油底壳内部相通的孔65mm；“险”格距油尺插孔底部与油底壳内部相通的孔32mm。

# 二、6135Aca型船用柴油机润滑油在油尺插口泄漏

润滑油在油尺插口泄漏大多发生在累计工作小时较多、作业环境差、技术状况不良、长时间未做维护维修或没有清洗曲轴箱通风装置的柴油机。

在油尺插口发生泄漏时，还会发生油封、衬垫处的漏油。

然而，油封、衬垫处的漏油是少量的，不能在较短的时间内产生大量外泄；润滑油在油尺插口泄漏后果严重，作业过程中不能及时处置会发生大量外泄，造成烧瓦抱轴的严重事故。

润滑油在油尺插口泄漏过程与油封、衬垫处漏油有着共同的因果关系。

这一段阐述虽然没有提到润滑油在油尺插口泄漏问题，但是，其中所阐述曲轴箱压力增高，造成油封和衬垫处漏油过程，同样会导致润滑油在油尺插口泄漏。

因为在曲轴箱压力增高情况下，曲轴箱内部压力高于大气压力，迫使曲轴箱内高压气体寻找薄弱点向压力较低的曲轴箱外部释放。

6135Aca型船用柴油机润滑油在油尺插口泄漏过程，可以综合“润滑油尺插孔结构”以及“柴油机静止和运转工况下润滑油面相对于润滑油尺插孔在高度上的变化”两个问题进行分析：

在柴油机运转过程中，由于可燃混合气和废气不断漏入到曲轴箱，曲轴箱内压力逐渐增高。

这种情况下曲轴箱类似于密闭容器，油封、衬垫、润滑油尺插口则是曲轴箱高压气体向外泄露的薄弱部位。

其中，润滑油尺插口在这几个泄漏点中泄露量最大。

由于曲轴箱内压力高于外部大气压力，润滑油尺插口与油尺插头自身的摩擦力不能承受来自于曲轴箱不断增高的压力，油尺插头被顶离油尺插口，润滑油经油尺插孔底部与油底壳内部相通的孔，再经油尺插孔形成润滑油泄漏通道，润滑油从压力较高的曲轴箱向压力较低的曲轴箱外泄漏。

柴油机中的润滑油由正常运转的动满油面开始泄漏，经“险”格油面，也就是应添加润滑油最低位置（此位置在使用过程中极易发生拉缸、烧瓦、抱轴事故），直至润滑油面低于油尺插孔底部与油底壳内部相通的孔，曲轴箱内高压气体与曲轴箱外部大气相通高压气体得到释放，润滑油停止外泄。

# 三、6135Aca型船用柴油机曲轴箱压力增高的原因

润滑油在油尺插口泄漏过程中“曲轴箱压力增高”是导致润滑油泄漏的直接原因。

然而，工作状况良好的柴油机不会发生“曲轴箱压力增高”现象。

这种状况不能满足柴油机结构要求，也不能保证柴油机的正常运转，并且与柴油机设计要求相佐。

如果柴油机在制造过程中没有设置曲轴箱通风装置，或者，柴油机工作状况出现异常，曲轴箱通风装置发生堵塞，这两种情况都会发生曲轴箱压力增高现象。

因此，6135Aca型船用柴油机在曲轴箱右侧设有通风装置。

它的主要作用是曲轴箱通风，防止曲轴箱压力过高。

同时，还起到空气过滤作用，避免空气中灰尘、杂物等进入曲轴箱，阻止曲轴箱润滑油蒸汽中润滑油释出，减少润滑油损失。

曲轴箱通风装置由通气管和滤芯部件组成。

通气管与下部侧盖冷压为一体；滤芯部件由壳体和滤网组成，安装在通气管内。

曲轴箱通风装置解决了“曲轴箱压力增高”现象，但是，它的作用和结构特点却导致堵塞现象的发生。

由于空气过滤作用，空气中灰尘、杂物以及曲轴箱润滑油蒸汽和燃油混合气中油分子、胶质物等吸附在滤芯部件滤网上，随着作业时间的增长，这一过程不断累积，滤芯部件通气性能下降，直至发生堵塞。

这种情况并非偶然，是一个渐进的过程。

柴油机作业过程中通气管释出可燃混合气和废气逐渐减弱，曲轴箱压力逐渐增高，油封和衬垫处出现漏油现象，这种情况如果不能及时的进行处置将会发生润滑油在油尺插口处的泄漏。

在实际操作中个别操作人员把通气管盖打开，甚至把滤芯部件拿出，避免曲轴箱压力增高现象发生。

其实这一操作方式并非可取，由于曲轴箱通风装置滤芯部件被拿出空气中灰尘、杂物直接进入曲轴箱，导致润滑油污染，加速机件的磨损。

# 四、结论

此故障发生与作业时间、作业环境、技术状况、维护维修有着直接的关系。

在作业过程中加强柴油机的管理，润滑油在油尺插口泄漏是可以避免的。

首先，按技术要求做好维护保养，6135Aca型船用柴油机工作100h要清洗滤芯部件；

其次，根据作业环境变化适时对曲轴箱通风装置进行检查；

其三，作业中发现通气管释出可燃混合气和废气逐渐减弱，或加注润滑油时感觉到滤芯部件重量变化说明滤芯部件发生堵塞；

其四，技术状况较差的柴油机燃混合气和废气泄漏严重，曲轴箱通风装置容易发生堵塞。

其五，维护维修过程中要重视清洗滤芯部件，避免发生堵塞，导致润滑油泄漏现象发生。
