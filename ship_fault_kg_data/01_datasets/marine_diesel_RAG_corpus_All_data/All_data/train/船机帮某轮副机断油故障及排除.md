# 导读

本文介绍某轮副机重力日用油柜进油管设计不当导致经常断油停车故障的处理过程，指出故障处理应当找到真正的原因并消除，不可只采取维持运转的措施而留下重大隐患。

# 故障背景

我于某年被派往某轮临时接替二管轮工作。

接班前就听说，该船经常因副机断油而造成全船失电。

交班的二管轮介绍，副机燃油系统中总有空气，历来如此，不知什么原因。

接班当天也差点发生副机断油停车失电事故。

# 燃油系统描述

副机燃油管路系统如上图。

副机只使用柴油，设有两部柴油输送泵和一个在副机上方约15m高的重力油柜（约0.15m³）。

柴油由柴油输送泵不停地从日用柜被输送到重力油柜，然后靠自压通过滤器等流到各部副机的高压油泵，重力油柜中多余的柴油通过溢流管流回到日用柴油柜。

油管口径最小也有40cm。

# 临时措施与故障现象

为防止副机断油，前几任船员曾在副机燃油流量表前加装一个放泄考克，并经常注意副机柴油压力表，当压力下降到0.07MPa左右（正常大于0.1MPa）或表针抖动厉害时，边打开此放泄考克泄放部分柴油（至油桶，每次约20升），边用塑料榔头敲击流量表上方水平布置的进油管，副机就能恢复正常运行。

有时一两天一次，有时一天一两次。

这段进油管上有很多敲击的痕迹，证明该故障很久以来频繁发生。

清洗柴油滤器时空气全都可以被彻底地放掉，为什么系统中又会有空气呢？

我一时难以判定，决定采取临时措施，用软管把柴油输送泵出口与流量表前的放泄考克直接连通，让柴油从经常发生气塞的水平管的下方进入，一旦管路中有空气，会被驱赶至重力油柜，再从油柜的透气管跑掉。

此后直到我休假离船的几个月，再没有发生因气塞引起的副机断油失电故障，我也没再特别注意此事。

但是，这显然使重力油柜出口速闭阀失去作用，不符合机舱燃油管路的有关规范。

# 后续事件与问题重现

2006年2月，我再次被派往该轮（任轮机长），发现当初我加装的软管被拆除（估计是PSC检查时被要求纠正），却在重力油柜速闭阀出口处加装了一根直径12mm的紫铜管通大气。

据说，采取这一措施后也没有出现过副机断油停车事故。

两天后，船在日本的YOKOHAMA港，DNV验船师上船进行年度检验，发现加装的该铜管，查问后即令必须将此铜管拆掉。

道理很简单，当发生紧急情况需应急停止副机工作时，虽然速闭阀都已关闭，但管路中的柴油仍能维持副机运转相当长的时间。

紫铜管拆除后，船舶频繁进出港口，又接连发生几次副机断油停车失电故障，人心惶惶。

为了防止失电故障再次发生，只能用软管从柴油泵出口接连到流量表前的放泄考克。

# 故障原因查明

稍后，开往美洲途中，彻查故障原因。

为了弄清楚空气到底是怎么进入系统的，检查副机柴油重力油柜，发现其进油管口没有深入到油面以下而在溢流管口上方。

这样，柴油泵泵送进入重力油柜的柴油，从液面上方冲进去产生气泡；由于惯性作用，冲进去的柴油带着气泡继续冲到油柜底部；油柜不大，气泡来不及上浮便经出口阀进入副机供油总管；而后，又在总管中慢慢释放并聚集在水平管或弯头处，造成气塞。

这就是为什么副机供油管路中有空气存在的真正原因。

以前加装紫铜管，就是起到将副机供油总管中释放出来的空气放大气的作用。

# 故障排除与反思

进油管加焊一段钢管，让管口插进到柴油液面以下，就没再出现油管气塞造成副机停车失电事故。

油柜进油管设计错误，造成多次全船失电事故，所幸失电故障都没出现在关键时刻，否则后果不堪设想。

反思故障持续多年的原因，主要是管理人员没有坚持查明原因和消除隐患。

出现故障，一时找不到原因，暂时采取维持运行的措施，并非不可。

但是，临时措施大都不符合规范，潜在不安全因素，一旦发生紧急情况，可能酿成大祸。

所以，对于故障也必须坚持“三不放过”原则，找出故障的根本原因，彻底消除隐患和汲取教训。
