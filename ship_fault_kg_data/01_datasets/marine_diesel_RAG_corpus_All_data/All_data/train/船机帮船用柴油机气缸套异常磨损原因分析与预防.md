# 导读

船舶柴油机运转时，异常摩擦磨损也时有发生。而作为船舶柴油机中最大的一对摩擦副一一气缸套活塞，一旦产生严重的异常磨损，会直接影响船舶机器使用寿命、正常运转和机损事故，甚至引发海难事故，所以我们有必要对船舶柴油机气缸套异常磨损进行分析研究，从而采取有效的维护保养措施，延长柴油机的使用寿命、尽量避免机损事故和海难事故的发生，保证安全航行。

# 一 气缸套工作条件

## 1. 工作环境恶劣

活塞环——气缸套是柴油机中一对重要的具有往复运动的运动副，缸套内壁承受滑动摩擦，气缸套受到高温、高压燃气的作用和冲刷 ，产生很大的机械应力与热应力。

工作表面乘受到腐蚀和严重的摩擦磨损，可谓是工作环境恶劣。

## 2. 润滑油膜难以生成

润滑油膜的形成必备条件之一是：

摩擦表面的之间，必须具有足够高的相对滑动速度。而活塞往复运动速度在行程中点最大、止点位置为零，运动速度不均匀且最低时为零。所以，油膜难以形成。

在恶劣的工作条件和低的运动速度下难于形成理想的液体动压润滑。

一般来说，活塞行程的中部工作表面易于实现液体摩擦，形成液体动压润滑，在上、下止点附近工作表面间形成极薄的边界油膜，实现边界润滑、摩擦比较严重、甚至处于干摩擦的条件下工作、产生黏着磨损。

## 3. 生成的润滑油膜容易被破坏

气缸中的高温不利于液体油膜建立。

因为高温，使润滑油粘度降低或氧化变质，使活塞头部变形影响正常配合间隙，使缸壁上已形成的油膜蒸发、氧化和烧损。

由于固体燃烧产物充当了磨粒，使得在缸壁上生成的油膜容易被这些磨粒划破。

柴油机正常使用过程中,因工作需要难免会出现短时间超速、超负荷运行、或者管理不当等，致使油膜破裂。

# 二 异常磨损原因分析

## 1. 异常磨损的特征

(1)磨损率很高，超过正常磨损率。

一般铸铁缸套磨损率大于0.1mm／kh，

(2)缸套工作表面不干净，有明显的划过的痕迹、擦伤、撕裂等拉缸甚至咬缸现象，或者缸壁内表面发蓝，有明显的过热烧灼现象。

缸套工作表面形貌粗糙。

(3)异常磨损产生的磨损产物颗粒较大。通常正常磨损的磨屑直径小于1给和μm，而异常磨损的磨屑直径高达25～30就μm。

(c)为润滑油脏污其 中机械杂质过多，筒状活塞式柴油机缸套采用飞溅润滑，自下向上布油，造成缸套下部严重磨粒磨损。

(e)为缸套上部因润滑不良引起的异常粘着磨损。

特别是活塞位于上止点时第1道活塞环对应缸壁及其一下相邻位置磨损异常增大，甚至出现大面积拉伤的拉缸现象。

(f)、 (g)是明显的腐蚀磨损。

(f)是燃油含硫量高或柴油机经常冷车起动使缸套上部腐蚀磨损严重，磨损量为正常磨损量的1～2倍。

腐蚀产物脱落引发二次磨粒磨损，使缸套中部磨损加重，磨损量为正常磨损量的4～6倍。

(g)是冷却水温过低导致的缸套下部严重腐蚀磨损。

以上各种情况是典型的，原因是单一的，然而实际上，柴油机缸套磨损情况则是复杂的，原因是多方面的，而且往往多种磨损同时并存。

轮机员在分析缸套异常磨损原因时应依实际运转工况全面考虑，具体分析。

## 2. 异常磨损的原因

（1）燃油和燃烧的质量差

燃油中的含硫量是气缸套产生腐蚀磨损的重要原因，燃油中含硫量超过0.7％～1.0％时 ，磨损急剧增加。

因为含硫量增加使硫酸凝结温度(即露点)升高，在气缸工作条件下容易发生腐蚀。

含硫量高的燃油燃烧时生成较多的炭粒，并促进积炭的形成，加重磨粒磨损。

低质燃料油中含灰分、机械杂质以及燃油裂化使用的含硅、铝的催化剂等以硅酸铝颗粒存在会使缸套活塞以及活塞环部件发生异常磨损。

船用低速柴油机燃用低质燃料油对缸套的磨损较燃用低硫柴油高2～3倍。

燃油燃烧不良，如燃烧不完全、后燃等均会使炭粒增加，磨损加重。

(2)冷却水温的管理不善

气缸套冷却水温控制不佳会使缸套磨损增加。

一般来说冷却水出口温度过低，使缸壁温度过低，硫酸腐蚀加熏；冷却水出口温度过 高，缸壁冷却不良，温度过高，致使缸壁上油膜蒸发，滑油氧化，积炭严重，导致粘着磨损。

同时，缸壁温度过高不仅热负荷增加还影响活塞环的散热，使环的磨损加重。

(3)润滑油的管理不善

对润滑油的管理、使用不当，润滑油品质不良或不适，碱值不当、油压不足、断油、长期使用不化验、不更换以致滑油变质、气缸油注油率不合适、滑油中混有机械杂质、水分过滤分离不彻底等，均会引起缸套异常磨损。

柴油机燃用低质燃油时，气缸油的碱值应与其硫分匹配，以中和燃油燃烧时产生的酸，有效地降低腐蚀磨损。

(4)柴油机的使用和操作不当

(1)对于新造船舶，初次投入营运时，以及营运船舶柴油机吊缸检修中更换气缸套、活塞或活塞环时，未能按照说明书的要求进行合理充分的磨合，造成汽缸套异常磨损。

(2)在机动用车时，频繁起停，长时间低速低负荷运转（润滑油膜不宜生成／燃烧不良)或超负荷 (热负荷太高／润滑油膜易破)运行致使汽缸套磨损加剧。

(3)在备车完车操作时，调整参数不及时，温度、压力忽高忽低造成汽缸套异常磨损、腐蚀加剧。

# 三 减少气缸套磨损的维护措施

缸套异常磨损除注意保证正确的安装配合间隙外，还可以通过加强管理、合理操作和使用来避免的。

## 1. 燃油和燃烧的管理

### (1) 燃油的管理

1)加强燃油品质的选择，不得随意更换燃料油的品牌；

2)加强燃油加装、储存的管理，加油时全程取油样，不同港口不同供油商加的油尽量不混装。(混装的油优先使用)减少燃油混装后变质、更多沉淀物的形成，以减少气缸套 的磨损。

3)加强燃油的净化处理；燃油储存一加热一过滤一一沉淀一一分离一一燃烧。

采用逐层加热逐层净化的方法，减少燃油中机械杂质、水分确保燃油良好燃烧。以减少气缸套的磨损。

### （2）燃烧的管理

影响柴油燃烧的因素很多，要保证良好的燃烧必保证柴油机工作在良好的工况下，有合适的气阀定时、供油定时、合适的扫气温度、扫气压力等，以减少由于燃烧不良引起的缸套的磨损。

## 2. 润滑的管理

1)保证系统油良好品质，及时充分的分离净化，及时取样化验发现问题及时处理。对净油设备及时维护清洗，确保其良好的工作状况，避免因滑油脏污对气缸套与活塞环造成过度磨损(特别是四冲程机)。

2)保证汽缸油品质，对汽缸油品质的选择，对既定的船舶柴油机，汽缸油品牌厂方已确定，作为轮机管理人员只需及时维护供油设备确保汽缸油净化处理，慎防混入其它 品牌油品，因为气缸油的碱值是与所用燃油的硫分相匹配的，一旦失配必将造成异常磨损，任何情况下不得擅自更换汽缸油的品牌、种类，不得使用高碱值的汽缸油。

对不同类型柴油机的不同工况不同转速及时调整汽缸油供油率。

## 3. 气缸冷却水的管理

冷却水的温度太低容易产生低温腐蚀，太高容易导致油膜破裂形成黏着磨损，所以应根据说明书的要求及时调整冷却水温度，使之保持在说明书要求的温度范围内，避免产生腐蚀磨损和黏着磨损，实践证明，适当提高缸套冷却水出口温度，使缸套内表面温度高于硫酸露点(约160℃)，可有效地防止腐蚀，减少磨损。

所以冷却水进口温度不宜低于50-60℃，出口控制在85～95℃时缸套磨损量较小。

按照说明书的要求保持合适的冷却水压力，就可以保证良好的冷却，不至于使缸套内壁因温度过低产生低温腐蚀磨损，也不至于是缸套内壁温度过高油膜破裂造成干摩擦而导致磨损。

## 4. 操作使用注意事项

在机动用车时及时调整各参数(排烟温度、滑油、淡水、扫气进出口温度、压力等)，使之在正常范围内。

使用时尽量避免频繁启停、转速变化过快、长时间低负荷、低转速、超负荷运行。更换气缸套、活塞或活塞环时，严格按照说明书的要求，遵从磨合程序，进行合理充分的磨合。
