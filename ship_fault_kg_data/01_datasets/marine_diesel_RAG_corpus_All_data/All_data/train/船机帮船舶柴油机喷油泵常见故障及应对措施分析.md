# 一 船舶柴油机喷油泵常见故障及故障发生原因

喷油泵又称高压油泵。

是给机械供给高压燃油的装置，它是由凸轮提供动力并且按时定量有条不紊的给需油机械供给高压燃油，然后高压燃油通过它特有的喷油嘴以分散的锥型将燃油射入燃烧室进行燃烧进行机械的供油。

## 1. 柱塞偶件在早期的磨损

柱塞偶件的精度较高。

伴随着使用的时间变长，它的运动表面在磨料以及机械的双重作用下，配合的间隙就会变大，致使供油的压力下降，会让喷油器的喷雾质量下降，这会使发动机的启动变得困难，耗油量变多以及功率不足，在发动机进行低速运转之时，漏油量显著增多。

## 2. 喷油泵凸轮轴滚键

喷油泵的凸轮轴滚键会导致供油的角度改变，对柴油机的工作造成影响，主要原因有两种：

一是因为在生产或使用时造成凸轮轴锥面锥度和油泵花键套内孔锥面不相符，两者的贴合面低于80%，安装完成后的花键套在短期内有松动，形成滚键。

可在未安装 4×16 半圆锥键的时候进行检查：

将油质红丹粉抹在凸轮轴的锥面，仔细核查轴套锥的孔面，贴合面依旧应大于80%。

如不满足要求可换零件。

二是由于油泵花键套锥面长度比凸轮轴锥面长度要短。

按照花键套以及凸轮轴锥度的长度设计尺寸，不管对它如何加工，花键套还让凸轮轴长度都是后者小于前者，这种长度比凸轮轴螺母能将两者紧密的固定在一起。

但在实际生产中却出现不符合这个长度的产物，即便凸轮轴螺母依照要求拧紧，但并未将花键套紧密的固定，轴向间隙依旧发生了攒动，造成花键套外移，最终形成滚键。

## 3. 喷油泵柱塞卡滞

要是有颗粒杂质落入柱塞以及柱塞套间隙，会造成柱塞的卡滞及拉伤，喷油泵柱塞卡滞已成为影响柴油机可靠性一大重要因素。

一旦柱塞偶件卡滞，调速器的工作就会受到影响，造成柴油机的转速不稳，严重时还会引起飞车事故以及柴油机熄火。

喷油泵柱塞卡滞原因有：

装配之时连接件安装的太紧，泵体和柱塞套容易变形，严重之时还会发生破裂；

因为装配的不适合或者落人异物，零件间会发生卡滞现象；

或者是机油有水，机油黏度太大会导致冬季出现运转不灵活等情况，这就会使调速器的性能受到破坏，甚至发生发动机熄火以及“飞车”现象，最终使整机受到破坏。

喷油泵一旦发生破裂或者变形，就必须更换零件。

新喷油泵调试用油不正确也是引起卡滞的原因，如果所用柴油的实际胶质浓度及酸度高，在调试以后会在喷油泵精密偶件配合的表面会附着一层余有的油膜，装机以后也会发生卡滞现象。

如果新喷油泵保管不适，包装存在问题以及防潮防锈材料的漏装或者损坏等，都是卡滞现象发生的原因。

## 4. 齿杆卡滞

单体式的喷油泵齿杆缺乏灵活性，会导致发动机的转速不稳定，严重时引起飞车事故。

导致喷油泵齿杆卡滞的因素有：

安装不严谨引起的漏装柱塞定位套螺钉的小铜垫、垫片厚度不达标以及螺钉过长等原因都会造成在拧紧定位螺钉发生柱塞套的变形以及柱塞转动受阻等问题，最终导致齿杆卡滞。

除此之外，柱塞偶件自身灵活度不足、定位螺钉头部弯曲以及零件的磨损也是引起喷油泵齿杆卡滞的常见原因。

## 5. 调速器前壳体发卡和喷油泵调速器飞球支架

调速器前壳体发卡和调速器飞球支架动机启动时发生超负荷时也易发生“飞车”现象。

该故障发生的主要原因是：

喷油泵凸轮轴轴承的严重磨损、调速器传动轴套的摆动幅度过大以及飞球支架内孔的重度磨损。

# 二 船舶喷油泵常见故障的应对措施

综上所述，船舶喷油泵在整个的使用过程里通常会发生很多可控或者不可控的故障，它的故障不是单一简单的，而是多样并且复杂，而引起故障产生的原因更是千奇百怪相当复杂，许多故障所引起的原因甚至是多个方面综合糅合而形成的。

所以，这就提醒我们，在清查和处理船舶喷油泵故障时需要工作人员十分熟捻的掌握问题发生的可能原因以及足够的应变能力。

针对船舶故障的多样性以及不确定性，我们必须从表现形式上分析着手，按照故障发生后的现象分析并找出该故障发生的原因，逐个排查并除去非主要因素，最后找出基本故障的症结所在。

本文通过对船舶喷油泵的常见故障原因、表现形式以及相关解决方法进行了细致分析以及阐述，给轮机管理人员在日常的值班工作中有效简便的找出故障发生的原因和解决相关的喷油泵故障提供了有利的借鉴。
