# 导读

原油主机的耗油率比柴油机略高，海上油田自产原油，用自产原油作为燃料可以省去燃料运输、储存等环节，这是海上石油平台使用原油主机的主要原因[1]。

与柴油机相比，原油主机增加了原油脱水、脱气、分油机净化、增压单元、供油单元等辅助橇块，系统更加复杂，故障率也高于普通柴油机。

结合实际工作经历，总结原油主机管理要点，为管理好原油主机提供参考。

# 一、燃油系统

原油主机燃油系统分为机体外部燃油系统及内部燃油系统。

外部燃油系统包括原油分油机、增压单元、泵和滤器、MDO柴油供给单元等橇块，要严格按照各设备维护周期进行保养，防止因为附橇故障导致主机被迫停机。

内部燃油系统包括高压油泵、高压油管、喷油器等，因为原油黏度高、品质差，易导致喷油器堵塞、高压油泵磨损等故障，需要结合实际运行状况做好预防性维护工作。

油田自产原油黏度较高，一般需要加热到100~120℃以达到原油主机喷射所需的16~24mm2/s（16~24 cst），超出此范围可能会导致高压油泵柱塞或喷油器针阀咬死，因此要严格控制原油黏度。

在日常维护保养中，要定期对停用主机油门齿条、油门拉杆各接头进行活络润滑，防止各连接部件因原油黏度太高而卡死。

原油主机运行时，在高压油泵、喷油器、高压油管连接处会有正常燃油泄漏，瓦锡兰W16V32机型参考量在30 kg/h左右（带载100%），泄漏量增大预示着高压油泵柱塞偶件磨损、高压油管连接处密封不严，体现在同等负荷下油门尺度增大及启动困难。

原油主机为防止飞车一般都设有油门机械限位（一般设定为40 mm），若泄漏量过大，在启动大型设备时，冲击负荷容易导致油门被限位而停机。

因此要定期测量原油主机的燃油泄漏量并做好记录以便比对，若超过一定数值，要及时更换高压油管或检修高压油泵。

# 二、冷却水系统

## 1、冷却水水质要求

原油主机冷却水一般选取淡水，为了防止冷却水系统各零部件腐蚀、结垢，冷却水中必须加入添加剂。

雨水不宜用作冷却水，因为雨水中含有较多氧和二氧化碳，具有很强的腐蚀性。

一般冷却水中含氯最大允许量为80mg/L，在船舶、海洋石油平台上海水淡化装置制造的淡水通常含氯量较高，不适合做冷却水。

冷却水系统中即使混入少量的海水，也会引起严重的腐蚀。

如遇可能结冰的情况，应联系添加剂供应商选取合适的防冻液，注意防止防冻液与添加剂不匹配。

## 2、冷却水系统维护工作

每周化验冷却水添加剂浓度，要始终高于供应商给定的数值。

建议每3个月在实验室里对冷却水进行分析，检测pH值、总硬度、氯化物含量、悬浮杂质等数据，所有测试结果应做好清晰的记录并予以保存，以便对当前系统的实际状况和发展趋势做出判断和评估。

原油主机冷却水系统附橇较多，有高温水预热器、低温水预热器、低温水循环泵、膨胀水箱等附橇，流程错综复杂，管理人员应该对各流程及设计参数认真学习研究，熟知并且清楚设计原理，这是运行维护原油主机的关键，也是判断故障的基础。

# 三、滑油系统

在燃用原油时建议使用BN30的机油，因为原油中含有较多的酸性化合物，因此机油应保证一定的碱值富裕量。

为了保证发动机的安全运行，建议每隔1000运行小时对机油进行油样分析，要注意下列特性值，并与该牌号新机油的规定值进行比较。

（1）黏度：

100℃时不得超出规定值的25%。

SAE40机油最大允许黏度为212mm²/s（212cst）/40℃或19mm²/s（19cst）/100℃，下限值为70mm²/s（70cst）/40℃或9mm²/s（9cst）/100℃。

（2）闪点：

不得低于规定值50℃，最低允许值（开口）为190℃或（闭口）170℃。

（3）含水量：

不得超过0.3%，若长时间含水量高于0.3%，需要及时检查滑油分油机工作状况，还应考虑更换机油。

（4）总碱值（BN）：

使用原油作为燃料，最低允许值须达到BN20。

一次最多允许添加10%的新机油来补充消耗，加油量过多会扰乱在使用机油的平衡，如造成不溶物的沉淀等现象。

每次加油都要记录加油量，持续上升的机油消耗可能意味着活塞环、活塞和缸套已经磨损，突然增加的机油消耗可能需要吊缸检查。

# 四、监控系统

原油主机上配置了发动机监控系统，对发动机进行监测和控制。

分控单元（DCU）和传感器信号处理单元（SMU）的数量取决于发动机的气缸数，所有安装在发动机上的传感器都接线至分控单元或信号处理单元，与外部系统的信号交换则通过主控单元（MCU）或继电器单元（RM）进行，发动机运行参数在就地控制盘（LDU）上显示。

监控系统故障大多是传感器或变送单元故障。

例如，瓦锡兰W16V32原油主机配置WECS2000控制系统，其传感器采用插接式插头，插头容易因振动而松动或者接触不良，导致故障报警；传感器插头容易被油污染，造成测量数据不准确或出现误报警；中间接线箱的接线端子松动，造成通讯不畅出现报警；传感器受到现场电磁或振动干扰时，有可能出现信号跳变。

目前，新型控制系统采用信号电缆与传感器一体设计，从根本上消除了接触不良带来的误报警或误动作[2]。

# 五、日常巡检及维修

## 1、值班人员的日常巡检

值班人员负责机组运行期间的管理，巡检过程中，在做好自身安全防护的前提下，通过目视、耳听、嗅觉、手摸等方式，观察机组各种运行特征的变化，及时发现问题，告知设备检修人员进行检修，做到不“带病”运行，消除隐患。

## 2、动力小组的维修模式

良好的管理思路和技能水平是原油主机及附橇管理的关键，海上油田维修部门存在着“大而全，不能专而精”的问题，经过实践和探索，成立了针对原油主机的“主机动力小组”，专门负责原油主机的日常管理和维护，逐步深化主机预防性维护及故障处理能力。

小组成立以来，原油主机故障率明显降低。

# 六、结束语

原油主机设备复杂，对管理人员提出了更高的要求。

作为管理人员应该加强值班人员的责任心，及时发现问题；结合实际运行状况，做好预防性维护；建立原油主机设备档案，吸取本设施及其他类似机型事故案例，做到举一反三；深入分析运行参数变化，做到精细化运维管理，逐步降低故障率，保障原油主机安全、可靠、经济地运行。
