# 导读

本文分析了维护船舶电子设备的重要性，并立足船舶电子设备的故障，结合实践经验提出了相关的解决措施，以供参考。

# 一、维护船舶电子设备的重要性

在船舶运行过程中，电子设备有着十分重要的作用，其正常运行对船舶的航行有着关键性的影响。

对于船舶航行的安全来说，只有快速解决常见的电子设备故障才是当务之急，可以说掌握专业的电子设备知识对于检测船舶电子设备故障提供了有效的保障。

作为新时期的船员，一定要丰富自身的专业知识，在实践中不断积累船舶电子设备的维修经验，能够在出现故障时及时做出正确的处理反应，用最快的时间解决电子设备的故障。

可以说，船员工作技能和专业素养的提高，是适应先进电子设备技术的基本要求。

# 二、常见船舶电子设备故障类型

船舶长期处于湿气较大的环境，海水也有较大的含盐量，这些因素导致船舶的电子设备老化速度加快，这也是导致设备故障的主要原因。

船舶电子设备常见的故障大致如下。

## 1、接地线路

接地线是船舶电子设备中增加线路保护的重要方式，接地线可以很好地预防漏电的发生，一般安装在设备的表面。

船舶装置中，一般都是把多余的电排进水中，而接地线则较好地起到保护电子设备的作用，同时，还可以保护船上人员的安全。

但是由于船舶长期处于水中，湿度较大，所以使用寿命不会太长，容易产生故障。

## 2、短路故障

船舶电子设备最常见的故障是短路故障。

电子设备发生短路时，就会阻断电源的电流，导致电子设备的功能不能正常发挥，容易产生并联电路。

电路维护和检测的过程中，要及时判断故障现象。

对于不能在短时间内确定的故障位置，要切断总电源，查找问题。

在通电的状态下，局部会散发较多的热量，容易形成一定的烟尘，或者自行燃耗，切断电源容易判断短路的根源。

## 3、电网故障

电网故障在船舶电子设备中发生的几率非常高。

电网故障主要有电网接地故障、电网绝缘故障。

其中，接地故障会导致船舶出现漏电的安全隐患，而绝缘故障则会造成电气设备发生短路，不能正常开展工作，导致电网的闭合功能出现影响，从而影响整个电子设备的运行。

## 4、电压不稳

船舶的发电机出现故障也是常见性问题，最主要的是发电机无法建立正常的电压，电压过大或者过小都容易影响电压的稳定性，导致发电机产生的逆功率多发于并联发电机组。

船舶长时间在水面工作，容易导致发电机进水受潮，从而不能正常运行。

## 5、主配电板故障

船舶负责电能分配和控制的中心是主配电板，主配电板上有各种开关、仪表、电路和信号指示，这些电子设备都在配电板的运行中起着十分重要的作用。

其中，发电机与配电板主汇流排间的接通和断开的协调工作就是由主开关来完成的。

如果主开关合不上闸，首先要检查脱扣锁钩是否接好过载、失压、分励脱扣器是否复位，然后再检查主开关的半导体脱扣器的控制电路板是否有故障。

如果主开关关闭电网后没有电压，应检查开关动态触点是松动还是断开，主触点是否被烧毁。

例如，一旦主开关突然跳闸可能是负载过大或短路的原因。

由于过载或短路保护动作造成跳闸，也可能是主开关本身造成的误操作。

当主开关失去压力扣钩松动与船舶振动的情况下，因失去的压力剥离器的作用而引起的主开关跳闸，也可能是反向电源继电器线圈烧坏，而影响交流发电机产生逆功率，从而导致跳闸。

# 三、船舶电子设备故障的解决措施

船舶在航行的过程中，当出现电子设备故障时，船舶工作人员要冷静应对，理智地找到故障问题根源。

船舶电子技术人员在查找故障原因的过程中，除了使用工具、仪器外，还要凭借日常的经验和个人感觉，如触觉和嗅觉等。

基本检测方法有电压测量、电流测量、电阻测量、置换、桥接、调整与校准等。

其中，排除故障最为常用的方法是经验排除法、短路实验、替代法。

一般经验排除法是最为常见的一种方法，这就需要工作人员有着极为丰富的经验，可以在工作经验中实现正确归纳和总结，从而在一些常见故障出现时，能够迅速判断，以保障船舶的正常航行。

而短路实验法是利用测试导线和万能表，将线路点连接，进行故障的排除。

需要注意的是，不能在排除故障后拆线，工作人员在这个过程中，要尽量规避系统运行中的危险因素。

## 1、主配电板故障解决措施

主配电板的故障常常是由短路、整定值错误等引起的。

因此，要想解决这个故障，需要制定相应的规范制度并严格遵守，只有在严格的标准规范下，才能保证稳压系统和整定值的稳定和正确，从而使得主配电板可以正常运行。

当船舶正常启动时，配电板会有警报发出，一旦重载，主发电机就会停止运行。

在面对这个问题时，应正确排除发电机故障，检查接线是否有短路问题的出现。

在接线正常的情况下，要利用万能表做好电压的检测。

一旦出现电压不正常的情况，就要检查蓄电池和充放电板之间的电缆是否连接有误。

当电压能够处于一个正常值域时，自动启动控制箱的 PLC，使其实现正常的运行。

## 2、发电机常见故障的解决措施

发电机一旦出现故障，对船舶的正常行驶会产生极大的影响，还存在着一定的安全隐患。

在排除发电机安全隐患的过程中，要从以下几个方面着手：

首先，发电机的绝缘性。

发电机的绝缘性降低是由于维护力度过低，带来机械损伤，从而引发潮湿。

其次，发电机的逆功率。

发电机的逆功率是由于参数的设置不当而引发的，需要检查各个参数的设置，出现问题要及时改正。

再次，电压是否异常。

电压异常问题的出现主要是由于集电环电路问题的干扰，一定要及时检查集电环的引线，出现异常要及时更换。

最后，发电机的磁场。发电机不能励磁主要是因为磁场消磁，应该及时对磁场进行充磁。

在发电机参数正确的情况下，一般是处于轻载或者空载的状态，当发电机一旦出现负载较重的情况，电压会迅速下降，在下降过程中，电流会出现攀升的状态，进而导致开关跳闸，船舶也不能正常运行。

出现这种故障时，要判断发电机是否出现电压较大的波动，考虑是否有励磁系统问题，对AVR电压调整器进行检查，排查故障根源，并解决。

## 3、电压不稳的解决措施

日常的检查和维护中，很容易发现电力网的故障。

因此，我们要加强基础设施的检查力度，这也是解决故障的有效途径和方法。

例如，保护装置提示线路发生单相接地故障，电压表 A 和 C 电压值偏高，电压表 B 电压值偏低。

从故障表现来分析，这个线路发生了 B 相不完全接地故障，因此，在检查此线路过程中，排查线路 B 相绝缘是否发生击穿，对故障点进行绝缘击穿，故障就会得到解决。
