# 导读

电力系统是现代船舶动力设备正常运行的基础。

船舶电力系统由发电机组、配电装置、电网和用电负载组成。

现在船舶电力系统基本采用全自动化控制模式，从发电机组的备用、启动、正常运行、并列、负荷调整到解列、停车都是自动控制，从而既保证了设备安全，又大大节省了人力资源，提升了整个船舶动力装置的可靠性。

柴油发电机组作为整个船舶电力系统的动力源，其是否正常运行直接关系着船舶的安全。

# 一、故障现象

T轮三台发电柴油机型号为YANMAR 6N21L- EV。

一年前开始不能在集控室和发电柴油机间控制屏起动,并且机旁起动也非常困难,需要多次才能起动成功。

实际该轮机舱已处于非无人机舱状态,发电柴油机根本无法自动起动转换，交接班时主管人员也明确交代发电柴油机必须在机旁起动,发电柴油机停止后必须关闭海水进出口阀，否则下一次即使在机旁也起动不起来。

笔者在该轮接任轮机长后，二管轮告知发电柴油机起动非常困难,需要冲车起动反复六七次,不仅浪费大量空气,也严重影响船舶安全。

因此,彻底解决发电柴油机起动故障成为首要任务。

# 二、故障排除经过

开航后,首先对发电柴油机各种参数进行了记录比较。

考虑到三台发电柴油机都有共同的故障现象,就对其共同的附属设备进行检查,发现该轮发电柴油机的海水自动调温阀都已损坏。

由于停车后都是关闭了海水进出口阀,柴油机的缸套水和滑油不再冷却,柴油机起动困难故障应该不是这个原因。

继续检查发电柴油机的暖缸水系统。

合电后发现该系统无法运行,警报器报警。

通过电机员和二管轮的共同努力,查系统,对照电路图,检查每一个电子元件,解体暖缸水循环泵，最终查明故障,将坏掉的电子温控元件利用替代品替代,使暖缸水系统恢复正常运行。

原来该轮备用发电柴油机的缸套水温度一般在45℃左右，接近机舱温度。修复后该轮发电柴油机缸套水设定在63℃。

机旁起动柴油机进行起动试验,每台发电柴油机起动都非常迅速快捷。

继续进行遥控起动实验。

NO.2 发电柴油机和 NO.3发电柴油机能够正常起动,但 NO.1发电柴油机无论在集控室还是在发电柴油机间控制屏都无法起动。

发电柴油机起动过程没有安全系统警报,可以排除安全系统连锁。

经检查,发现 NO.1发电柴油机在机旁起动时起动马达正常运转﹐而当在其他两个位置起动时,起动马达却没有运转。

该轮发电柴油机的气动起动马达是TDI TUR-BOSTART TWo MODEL 45M。

通过研究说明书，知晓起动马达的先导电磁阀正常电压范围在DC9V -32V。

当有起动指令时,起动马达电源模块的先导电磁阀输入电压应该在 DC12V,而我们检测到的电压只有DC3V。

检测NO.2发电柴油机的起动马达电源模块进行对照,当起动信号输入时,测得值为DC12V左右。

查看以前的检修记录,看到曾经将NO.1与 NO.2发电柴油机的起动马达进行过调换使用,也就是说以前主管人员怀疑是NO.1发电柴油机的起动马达有问题,但问题并没有解决。

经过研究说明书电路图,确认机旁起动和遥控起动是并联方式。

既然机旁可以起动,起动马达应该没有问题,问题应该出在遥控系统。

继续检测,发现 NO.1发电柴油机遥控起动时起动马达的输入电压与说明书规定值明显有差距,更加确认是遥控系统的故障。

集控室控制和发电柴油机间控制屏控制都无法起动发电柴油机,那问题就应该在控制屏控制系统和集控室控制系统的并联点以后,因此集控室控制故障也可以基本排除。

检测NO.1发电柴油机电磁阀箱内部的电磁阀和控制屏内的控制电路。

由于该轮设备说明书缺少部分电路线路图,该项工作进展缓慢,经过三天的努力,最终确定是发电柴油机控制模块G/E-CBN CONTROL BOARD 故障。

它的输出电压低于DC12V,查找备件箱找到一块备件。

装复后,测量输出电压 DC12V。

进行遥控起动实验,控制屏起动时发电柴油机应声而起,转到集控室控制,停车、起动各两次,均正常。

至此该轮发电柴油机完全恢复到自动控制的状态。

此后,笔者任职期间,该轮发电柴油机可以随机备用任何一台，机舱也真正又达到无人机舱的状态,充分保障了该轮机舱供电的安全,减轻了日常工作的压力。

# 三、YANMAR发电柴油机起动故障分析

发电柴油机起动故障现象不可一语而概之。

特别现在船舶自动化程度越来越高，一改原来那种纯机械式启动副机的故障,启动故障现象常见如下:

1. 能转动,但是达不到正常转速;
2. 达到启动转速停止启动后,又自行停车;
3. 启动马达不转动。这种现象又根据启动方式分为多种现象:集控室启动无反应、控制间启动无反应、机旁启动无反应、重启动无反应;又会出现像本轮的情况﹐因为这四种启动方式是并联的,因此分析起来比较困难,故障点查出相对复杂。

作为一线管理者可以根据现象特征判断故障原因:

第一种现象原因:启动马达转速不够;跟控制部分无关;
第二种现象原因∶副机本身机械故障,跟启动系统无关;
第三种现象原因:就要根据并联接点梳理,逐个排除。

在每一个并联节点又有一个串联回路，串联回路又有许多个节点组成,要一一检查排除，当然利用测量工具辅助测量可以快速排除非故障源,提高查出速度。

本轮的这次故障比较典型又相当不可预料。

因为遥控回路处故障比较常见,但是船龄仅仅五年不到,按照常识该板在这么短时间不会出现故障,因为平均算下来也不过一年多,出故障的往往是频繁动作的原件,多数人往往会疏忽。

对于没有规律性的故障,要认真观察总结,研究说明书,将理论与实际结合起来。

往往一个螺丝的松动最易造成非规律性的故障发生。

因为船舶本身的摇动和机舱设备的震动,会造成控制组件松动接触不良。

副机机械方面的故障有经验的轮机员往往会容易发现,但是控制系统特别是现在集成电路、微机控制回路原件繁多，线路复杂,随着科技的日益发达,故障率会逐渐降低,但是故障的查处会越来越难。

因此每一位轮机员都要在日常维护中加强管理,将德恚及时排除,避免故障的发生。

备件费用越来越高,船东也不会保持过多的备件存在船上，一旦海上出现故障,船员力量难以保证修复,将严重影响船舶营运甚至危及船舶安全。

通过故障排除,总结该型发电柴油机起动故障排除方法有:

1. 造成柴油机起动故障的原因很多,而柴油机暖缸不足,致使柴油机机体温度较低,使柴油机起动时缸内不容易达到起动发火所要求的温度和压力,造成起动困难。这个故障原因是我们容易忽视的。
2. 机旁起动正常,遥控起动故障时,主要为遥控系统故障。遥控系统包括遥控信号的发出单元,信号传输单元以及信号接收单元。故障查找时,从两端开始检测信号值,能较快较准确地进行故障判断。
3. 对于规律性较差,时断时续的故障现象，在故障排除时,首先应考虑零部件的松动、接触不良，尤其设备或系统处于震动剧烈的工作环境时。

# 四、结论

发电柴油机的起动系统虽然较船舶主机的起动系统简单,但发生起动系统故障也会难以解决，影响船舶营运和安全。

该船发电柴油机起动系统长时间处于故障状态,不能及时修复,充分说明故障的检查排除具有一定的难度,这是船舶轮机主管人员的共识。

检修排除故障时,一定要清楚故障现象,在没有认真分析、确定故障产生的位置和范围时,不要盲目拆卸、自行调整元件,以免造成故障范围扩大和产生新的故障。

在确认故障现象后,根据现象，查询说明书以及其他技术资料,进行分析判断,有时可能故障现象较为复杂,表现为多种故障,这时应从简单的故障着手,由简单到复杂依次处理。
