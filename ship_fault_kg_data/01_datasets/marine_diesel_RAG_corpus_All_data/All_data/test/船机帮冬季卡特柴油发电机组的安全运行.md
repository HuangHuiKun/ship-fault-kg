# 导读

冬季来临，随着北方气温的逐渐降低，如何能够对柴油机发电机组进行防冻保温，并保障其正常运转成为了我们必须考虑的问题。

本文综合柴油发电机组自身油路、气路、电路、机械四方面的因素，根据现场柴油机实际经验和自主加装的革新，简明扼要的阐述了保障卡特3512柴油发电机组冬季安全运行的必要措施和先进的管理经验。

# 一、冬季启停3512柴油发电机组的注意事项

## 1、开机前的准备工作

（1）将附着在机组上的水迹、油迹和铁绣等杂物清除干净。

（2）对机组各装置全面巡视一遍，检查各连接、紧固和操纵部分是否都己装接牢固妥当，各处螺丝螺母是否牢固松脱。

（3）检查是气压否满足需要，气起动马达至少需要690kpa气压气体才可正常工作，最大气压不能超过1550Kpa，要及时排空气路内的积水，积水过多直接影响着气动马达的使用寿命和柴油机组的启动。

（4）检查柴油机进油回油回路是否通畅，（回油关闭会导致高柴油压力，进而可能导致滤座故障或者其他问题），同时要检查机油的液面和品质是否满足需求。

（5）散热水箱内冷却水是否满足需求，观察冷却系统有无泄漏。

（6）检查所有电气部分，各接点应牢固正确，各处供电断路器应处在“断开”位置，检查启动控制屏供电蓄电池是否电压正常。

（7）机组间断一段时间再运行时，必须先将柴油管线内的空气排空会使得部分空气进入到滤座内，须将整个管线内灌满柴油后再做排空处理，其次还必须先用1000V兆欧表测量发电机各绕组和控制系统对地的绝缘电阻，常温下应不低于2兆欧，若绝缘电阻低于上述数值，必须进行干燥处理。

## 2、开机步骤

（1）打开电瓶控制开关，打开气路开关，按下气动盘车按钮。

（2）盘车正常后，打开启动按钮，显示屏油压、气压、压差显示正常后，启动柴油机，如10秒（最多15秒）柴油机仍不能着火启动，则应待1分钟后再作第二次启动，若连续三次仍无法启动则应检查并找出故障原因。

（3）柴油机启动后，关闭气路开关，应密切注意柴油机转速、温升、气压、油压的变化，如仪表不正常指示，应立即检查。

正常工作机油压力为275-600kpa之间，怠速时应为186-344kpa，油滤子最大压差为105kpa。

（4）机组启动后，空载转速逐渐增加到900—1200r/min，（注意不得长时间低速运转），进行柴油机的预热过程后，再将转速提高到额定转速。

待出水温度达到66℃，机油温度达到45℃时，才允许进入全负荷运转。

当机组各仪表指示正常时，即可合上负荷开关向负载送电，随着机组负荷的变化，若频率和电压不在规定范围内，应及时调整频率和电压，使其保持额定值，严禁机组在低转速情况下带负荷，以免损坏设备。

（5）机组投入正常运转后，应随时注意观察水温、油温、油压、压差、左右增压器排气温度的变化以及功率表、频率表、电流表、电压表的读数，发现异常应及时处理。

全载时机油最高温度为104℃，水温一般在88-112℃之间，额定转速时最小柴油压力为275kpa，柴油滤子最大压差为105kpa，最大排气温度在480-590℃之间变化。

## 3、停机步骤

（1）逐渐卸去负荷，断开并网开关。

（工作后立即停车会导致柴油机过热，柴油机磨损加剧，增压器内温度过高会致使机油堵塞）

（2）怠速运转在1000转/分左右的轻载状态下，让柴油机运转3-4分钟，待油温、水温有明显下降时，关闭柴油机。

# 二、3512发动机的日常保养

（1）定期检查发电机起动蓄电池的电压和使用状态，平时及时清理蓄电池上的接线端子和电池卡子上的附着物。

（2）平时多检查发动机的冷却液的质量和液位，如果不足要及时补充。

停止发动机后，在发动机逐渐冷却状态下，慢慢拆下冷却系统加注口盖，以释放全部压力。

将正确的冷却剂混合液注入冷却液加注管。

清洁冷却系统加注口盖。

检查冷却系统加注口盖密封圈的状起动发动机并检查冷却系统是否渗漏。

（3）每天检查空气预滤器，根据需要清除一切脏物和碎屑。

如果经过适当的清洁和检查，滤芯可能会被清洁再用最多达6次。

空气滤清器滤芯每年至少应更换一次。

无论清洁过多少次，使用一年后一定要更换。

（4）及时检查发动机的机油油位，每次换机油时发动机机油滤清器差压。

达到103 kPa（15 psi）时或者机油滤清器滤芯已经使用了1000个保养小时必须及时进行更换滤芯。

（5）及时用卡特彼勒轴承润滑剂来加注风扇驱动轴承的润滑脂加注嘴。

或者，使用含有5%的钼和具有多用途润滑脂NLGI 2级的多用途润滑脂。

（6）正常发动机运行期间燃油滤清器的标称差压大约为60kPa（9psi）。

当燃油滤清器压差达到103kPa（15psi）时，更换发动机燃油细滤器滤芯。

（7）及时清理发动机散热器，可以采用压缩空气在散热器管道平行的方向缓慢移动空气喷嘴。

这将清除在管道之间的碎屑。

加压水也可用于清洗。

清洗用的最大水压必须低于275 kPa。

# 三、自主革新防冻保温装置

## 1、进油口加装滤清器

为了延长卡特3512柴油机缸体的使用寿命，我们致力于提高燃油质量，在柴油机进油管线上加装了一组燃油滤清器，能对柴油起到良好的过滤作用，使用灵活更换方便，进一步提高燃油的质量，提高了柴油机电喷系统的使用寿命，增加了进口滤子的使用时间，大大降低了使用进口滤子的成本。

## 2、进油与回油并联使用

冬天天气寒冷，燃油稠密，容易结蜡，柴油机长时间停用，启动时油泵需要经常多次启动才能将管线内燃油吸入柴油机内，我们采用进油管线和回油管线并联使用，使回油在和进油汇合后再进入燃油管线内，使得燃油的温度得了提高，增加了冬季燃油的流动性，从而最大程度上避免了管线内真空段过长的问题，提高了柴油机油泵的使用寿命，改善了柴油机冬季启动难的问题。

## 3、进油回路上加装高精度绝缘电热装置

为了防止低温天气进油管线结蜡，致使进油管线堵塞，我们在使用低标号燃油的同时，自主创新的在进油回路上加装了绝缘度高的电热筒并在进油管线上缠绕电热带，使进油在管线内得到良好的预热和保暖，使得燃油进油回路通畅无阻，进一步保障了柴油机组的供油。

## 4、在气动马达进气管线上加装液气分离器

冬季寒冷，即使通过空气干燥器，气路管线内难免也会有水气成冰的现象发生，气动柴油机时就容易造成气动马达的卡死甚至损坏，为了延长气动马达的使用寿命，我们在气动马达的进气管线处加装一个小型的液气分离器，从而使管线内的水气和冰碴得到了隔离，从而达到了保护柴油机气动马达的目的。

# 四、综述

冬季为了能够更好的使用柴油发电机组，在提高设备维护保养质量的同时，还要加强岗位监督管理，只有始终贯彻落实严格的设备管理制度，提高设备管理责任心，加强冬季柴油发电机组的巡回检查，才能够真正保障柴油发电机组的正常安全运行。
