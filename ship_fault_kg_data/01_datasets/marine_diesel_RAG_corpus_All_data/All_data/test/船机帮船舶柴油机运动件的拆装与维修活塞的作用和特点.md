# 船舶柴油机运动部件

船舶柴油机的运动部件主要由活塞、活塞环、活塞销、活塞杆及填料函、十字头、连杆和曲轴等部件组成。

二冲程柴油机运动部件刨面图

运动部件的主要作用是活塞承受高温、高压的燃气作用，通过连杆传递燃气膨胀做功的力，再由曲轴对外输出功率，带动螺旋桨或工作机械工作。

活塞可分为筒形活塞和十字头式活塞。

## 一、活塞的作用

1. 组成燃烧室

活塞式燃烧室部件的组成部分，与气缸套、汽缸盖共同组成紧闭的气缸工作空间，在保证密封的情况下完成压缩和膨胀过程。

2. 承受气体力

活塞与连杆、曲轴等部件组成运动机构，将作用活塞的气体力经连杆传递给曲轴。

3. 承受侧推力

在筒形活塞式柴油机中，活塞承受侧推力，起着滑块的作用。

4. 控制气口

在二冲程柴油机中，活塞还起着启闭气口，控制换气的作用。

## 二、活塞的工作条件

1. 高温

工作中的柴油机活塞承受着燃烧气体近400℃的高温，活塞的热负荷和机械负荷很高，而材料在高温下性能下降，所以容易发生裂纹、变形，甚至烧蚀。

2. 高压

活塞要承受气缸内高压气体作用力，质量体往复运动所产生的往复惯性力及侧推力的周期性作用。

3. 摩擦和磨损

活塞在侧推力作用下会与气缸之间产生摩擦和撞击，同时，由于温度高，活塞受燃气冲刷、自身往复运动等，这使它和气缸之间不可能建立完全的液体动压润滑，因此摩擦损失大，磨损较快。

周期性改变方向的侧推力也必将使活塞不断撞击气缸套，引起活塞变形和气缸套振动加剧。

4. 腐蚀

活塞承受高温燃气的化学腐蚀作用。

## 三、活塞的要求

由于活塞对柴油机的动力性、经济性和可靠性影响很大，因此活塞组件必须满足以下要求：

- 强度高、刚度大
- 密封可靠
- 散热性好、冷却效果好
- 摩擦损失小，耐磨损
- 活塞重量轻，惯性小（对中、高速柴油机的要求）

上述各项要求是相互制约彼此矛盾的，所以其材料和结构形式尤为重要。

## 四、活塞的材料

1. 铸铁

合金铸铁材料具有较高的机械强度、较小的热膨胀系数以及良好的耐磨和耐腐蚀性能。

价格低廉、工艺性好，活塞与气缸之间允许有较小的间隙，是应用最多的、最基本的材料。

缺点是密度大，吸热性和导热性比铝合金差。

球墨铸铁具有更高的机械强度。在强载柴油机中，常用这种材料制成薄壁式的活塞结构，以增强其承受热负荷的综合能力。

2. 钢

钢的机械强度高，但耐磨性差，成本较高，主要用于大功率中、低速柴油机活塞头。

耐热合金材料具有更高的机械强度和抵抗热负荷的能力，一般用作组合式活塞的头部材料。

3. 铝合金

铝合金材料的比重小，铝合金活塞比铸铁的要轻30%~50%。

因而能相应地减小活塞组件的往复惯性力，同时导热系数高，但高温强度差、线膨胀系数大。

另外，铝合金成本较高，因此仅用于中小型高速柴油机。

对于大中型柴油机的活塞，为了合理使用材料和方便制造，活塞头和活塞裙分开制造，活塞头通常由铸钢或耐热合金钢制造，活塞裙一般采用耐磨铸铁制造。

中小型机通常将活塞头和活塞裙制成一体，由铸铁制造。

某些高速柴油机为了减轻活塞重量，用铝合金制造。
