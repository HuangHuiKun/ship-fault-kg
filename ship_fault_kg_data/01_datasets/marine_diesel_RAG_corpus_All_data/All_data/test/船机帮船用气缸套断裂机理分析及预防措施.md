# 导读

气缸套断裂是柴油机中的多发事故，造成断裂的原因也十分复杂。

本文分析了缸套断裂的原因，提出了预防措施。

# 一、缸套在生产和制造过程中存在缺陷引起的断裂

## 1、缸套在毛坯制造时存在缺陷

气缸套是柴油机中的一个重要零件,它的工作条件十分恶劣,其内表面承受高温高压,活塞高速摩擦和侧推力作用。

外表面直接和冷却水接触,缸体承受较大温差带来的热应力。

因此,气缸套毛坯材料选择十分重要,目前大多选用硼铸铁、高磷铸铁、铬钼铸铁等合金材料,采用离心铸造工艺制造。

用这几种材料生产出来的缸套在使用性能上各有利弊,硼铸铁中的硼化物硬质相很高,耐磨性能好,但铸造时容易产生偏析,硬质相偏析严重时,是造成缸套断裂的一个重要因素。

磷铸铁成本较低,但耐磨性能不理想,且脆性很大。

而铬钼铸铁在合金元素作用下,石墨细小，基体细化，且有硬质相存在,表面上看这种材料各项指标都能满足生产缸套的性能要求,但在实际使用过程中它发生断裂的频率较其它材料要高。

究其原因,这种材料铸造完成后表层组织中有大量游离铁素体存在,导致硬度值偏低,强度下降。

而且由于铸造工艺等问题致使组织中不同程度的存在E、D型过冷石墨,呈方向性分布的E型枝晶片状巨型石墨,D型过冷石墨都是有害于材料的力学性能的,由于它们的存在会使材料脆性增加。

综上,在铸铁中加入适量的合金元素是可以改善材料中的金相组织，提高其化学性能和物理性能,但这仅仅是影响毛坯质量的一方面因素,另一个方面,影响到产品毛坯质量的因素还有熔炼温度,孕育时间、冷却速度等,以上工艺如果掌握不好,就会造成机体组织晶粒粗大,石墨粗大,或产生过冷石墨，硬质相严重偏析,严重枝晶状,降低了材料强度,造成缸套断裂。

另外由于去应力退火不到位,缸套内部存在较大应力,装机后,随着应力的释放,缸套也会随之变形,这些变形引起受力情况发生改变,导致缸套断裂。

由于这些内部缺陷从外观上是无法发现的,因此,在选择缸套时,应对缸套生产厂家从企业品牌、生产能力、工艺水平、检测手段等多方面加以了解。

尽量避免因材料、铸造工艺等因素造成的缸体内存在缺陷而导致的断裂事故发生。

## 2、缸套在机械加工过程中产生的缺陷

机械加工质量是影响缸套质量的重要因素，由于受机加工设备、工艺装备、操作工水平等多种因素影响,存在加工尺寸误差、形状误差和位置误差,这些误差中有许多和缸套断裂有着直接关系，应引起高度重视,这些尺寸主要是:

1) 气缸套支承肩下端面和缸套外圆连接处设计有退刀槽用圆弧过渡，一般半径为0.5mm。该尺寸非常重要。

如果圆弧半径大于槽深，圆弧将露出槽外,且凸出支承肩下端面,安装时，圆弧凸出部分顶在机体上支承肩孔的端面上,靠外侧部分悬空,在缸盖螺栓压紧力的作用下,极易断裂;如圆弧半径过小，则会产生应力集中。由于气缸套和机体间采用的是间隙配合,缸套装入机体后,其支承肩被气缸盖压紧在机体上。

柴油机工作时,活塞作用于缸套上一交变力,使其下部来回摆动,产生交变应力,导致缸套达到疲劳极限后出现裂纹并逐渐扩大,直至断裂。

2) 气缸套支承肩下端面相对于缸套中心轴线的垂直度是一个关键的位置尺寸,如果该尺寸超差,则缸套实际轴线倾斜理论轴线，即缸套在机体中是倾斜安装的,这样缸套装入机体带来两个严重问题，一方面改变了活塞的运动轨迹,增加了活塞运动阻力,加大了活塞在运动过程中对缸套的径向作用力,使缸套产生振动,是疲劳断裂的潜在因素;另一方面由于下支撑面的阻挡,在支承肩压紧螺栓时,可能直接将支承肩压断。

3) 缸套支承肩高度也是一个重要尺寸,在安装缸套时一般情况要求支承肩高出机体平面0.05~0.15mm,如果加工时产生的误差超过此极限值，当压紧气缸盖螺栓时,可能会出现支承肩断裂。

在安装缸套前,要严格检查上述的几个尺寸,同时还应注意检查圆弧,密封环槽等处的粗糙度，及圆弧和其它面的连接情况，粗糙度低,圆弧和其它面连接不好,都可能产生应力集中,导致断裂。

所以如果发现缸套存在上述问题，一定要经处理后再装机。

# 二、在缸套安装过程中操作不规范引起的断裂

1) 在安装前将缸套及机体沉孔上的毛刺、铁锈、污物清洗干净。

不要在缸套支承肩下表面,或者在机体沉孔上表面涂油漆或者胶,因为清洗不到位或者表面涂刷其它物质都会引起气缸套凸台上平面的位置过高,当气缸盖压在凸台上,拧紧气缸盖螺栓时,会导致缸套支承肩断裂。

2) 在安装前应仔细检查和测量各部分尺寸,特别是配合部位的尺寸，气缸套压入机体后还应仔细检查其形状公差和位置公差,检查气缸垫厚度,确保安装后尺寸,否则任何一处尺寸和公差超过安装规范要求,都可能引起缸套断裂。

3) 在缸套安装前应认真检查缸套封水圈和封水圈与机体的气缸孔的配合间隙。

封水圈应该具备良好的弹性,粗细要均匀,表面无损伤。

为了保证其密封性能，一般要求密封圈装入缸套密封槽后其凸出槽边弧面0.3~0.5mm,间隙过大,难以密封,配合过紧,装配时容易被剪切,严重时导致缸套变形造成缸套破裂。

4) 在正常情况下由于密封圈的作用,退刀槽处应该是干燥无水的,但是如果此处配合过松,冷却水会滲人退刀槽处，而此处接近燃烧室,缸套内外壁温差很大,会产生较大应力,导致缸套断裂。

# 三、在柴油机工作和保养过程中没有严格执行操作规范引起的断裂

柴油机在工作过程中操作不当,或者在保养过程中维护不到位,都会造成缸套断裂,主要表现在以下几个方面:

1) 柴油机在工作一段时间后,要注意复查气缸盖的螺栓拧紧力及每一个螺栓之间力的平衡，避免由于螺栓松动，使气缸套振动频率和振幅增加,导致缸套断裂,同时也要防止因每一个螺栓之间力的不平衡导致的断裂事故发生。

2) 柴油机不要长时间超负荷工作,加速不要太快,油门不要加太大,否则进气量不能满足使用要求,产生“冷爆"现象，显著恶化缸套受力状况，导致薄弱部位产生裂纹。

3) 柴油机在工作过程中，由于润滑系统故障、润滑油粘度等诸多因素导致缸套内壁油膜不能形成,活塞环和缸套内壁形成干摩擦，活塞环和活塞裙部直接胶着,在活塞的作用下,将缸套拉断。

因此，我们在日常保养时要注意润滑系统的维护,同时还应注意不同季节使用不同粘度的润滑油。

4) 柴油机在高温状态下骤加冷却水,或者是由于内部故障导致经常开锅等现象,都会使缸套产生变形,而几乎所有使缸套变形的因素都是造成缸套断裂最根本的原因,在这个问题上，应该引起我们高度重视。

# 四、结语

综上所述,要保证气缸套在正常状态下平稳工作,应该从缸套选购,安装及柴油机的操作和维护保养入手,严格执行操作规范和程序，只有这样,才能避免和减少缸套断裂事故的发生。
