# 导读

近年来公司对承建的5万吨系列船中逐步推广电喷主机，其中ME-B型主机就是一款介乎纯机械与全电喷之间的过度机型。

它的主要特点：

通过电脑程序控制喷油，对柴油机各负荷工况实施定量、定时、定点精准喷油；

对低于55%负荷段，排气阀操纵装置保持机械式凸轮机构；

对高于55%负荷段，排气阀操纵装置采用电控液压油自动操纵，我们称之为半电喷主机。

这款半电喷主机实现了喷油精确准时，使得主机在各种负荷工作中得到合适的燃油喷射压力、喷油量、喷射姿态等，同时排气阀与电喷装置适当配合，使得气缸中的废气尽量排空，并且尽量多的获得新鲜空气，让燃料在气缸中燃烧更充分，将不利燃烧的情况降到最低，从而降低损耗，改善废气排放。

但是这款半电喷型主机其电器部件与机械部件之间的配合并不十分完美，船上调试过程即机电磨合过程中出现了不少问题。

期间我们公司与主机厂共同经历了不少磨烂，至今记忆犹新，本文对这款主机曾经发生的问题进行归纳总结，从中得到不少启迪。

# 一、ME-B主机调试存在的问题

新机型、新技术在应用初期往往会出现许多未知的问题，通过对这些问题的摸索与解决，使新技术逐步完善和成熟。

S50ME-B主机为纯机械式主机向电喷机过度的半电喷主机。

这类主机在调试过程中出现了各种问题，严重影响了主机系泊试验和航行试验周期。

系列船出现的共性问题汇集如下：

(1) MEV阀工作无法正常激活；

(2) 主机倒车起动困难；

(3) ELFI阀无法工作；

(4) 主机加速逾越转速禁区时间过长。

# 二、MEV阀无法正常激活问题分析和处理

MEV阀为主机负荷超过55%时排气阀电控液压油自动操纵机构的关键部件，其工作原理见图1和图2所示。

图1 MEV阀的工作原理图

图2 ME-V阀工作效果图

通过控制ME-V向驱动油腔内注入液压油，即图1中B0-B1-B2行程段，将排气阀执行机构的柱塞推向上行，此时ME-B主机排气阀打开；

当柱塞行至E1-E2行程段时，能够减缓排气阀关闭，延长排气阀开启时间，使得排气更充分，更多新鲜空气进入气缸。

主机正车、倒车、起动、运转等工况ME-V均工作，主机正车运转时，在负荷升至55%以上时，ECS控制ME-V液压活塞正时，从而操纵排气阀的关闭正时。

目前存在的问题是主机负荷升至55%负荷时，经常出现个别缸ME-V不能正常激活，使得这样的气缸排气阀打开时间短于其他缸，燃油在这样的气缸中燃烧不充分，压缩压力和爆发压力比正常燃烧的气缸小很多，造成各缸间功率输出很不平衡，严重影响主机正常工作。

这是主机调试过程中最大的困惑。

我司协同主机厂连续在几条船上做了各种相关实验，均没有解决这个问题。

最终主机厂测量ME-V内各处油压变化后，发现ME-V控制系统有缺陷。

主机倒车运行后，ME-V控制参数不能归零，从而对正车运行时ME-V的控制产生影响，使得ME-V激活控制信号过早结束，造成正时单元活塞驱动油压过早切断，从而不能正常激活ME-V。

问题主要出在控制杆上，如图3所示。

图3 控制杆损坏

通过对控制程序更改，解决了信号过早结束这一问题，同时厂家在出厂前对ME-V活塞增大间隙，减小在油腔内的卡阻。

经过几条船的运行，目前该问题已证实得到解决。

# 三、主机倒车起动困难问题的分析和处理

ME-B主机在进行正倒车起动换向试验过程中发现：

当起动空气压力低于15bar时，经常会出现倒车起动困难的问题，而正车起动最低起动空气压力可以到达10bar以下，起动总次数无法满足试验册要求的正倒车各6次以上性能。

针对此问题，在和主机厂调试工程师对主机的起动油门、喷油转速、起动空气时间等进行了一系列优化调整，均没有很好的解决这个问题。

最终厂家对起动过程中排气阀动作、气缸内压力进行测量，发现在倒车起动过程中，排气阀关闭过早（如图4，正车起动283.6°，倒车起动为275°），造成气缸内压缩压力过高，最终导致低起动空气压力时起动困难。

图4 正倒车起动夹角图

通过更改COCOS程序内的MEV控制参数（需MAN服务工程师授权），将倒车时ME-V的作用时间延后，即在排气阀执行机构柱塞落座后，再向驱动油腔内注入液压油，有效增加排气阀开启时长，通过减少向驱动油腔内注入液压油，如图5，用来增加排气阀开启时长，从而降低气缸内的压缩压力，达到优化倒车起动的目的。

图5 程序修改前和修改后ME-V的工作示图

经过多条船测试倒车起动压力最低可以做到10bar左右，满足的正倒车各6次以上性能要求。

# 四、ELFI阀无法工作问题的分析和处理

ELFI阀就是Electronically Controlled Fuel Injection Valve电子控制燃油喷射阀，也叫多通阀，主要由ECS控制，能够快速、精密地控制燃油喷射量和喷射时间，是柴油机的核心部件。

主机动车前我们均要提前用COCOS程序内模似检查其工作灵敏情况，一切正常后才能动车。

但在调试过程中发现，主机运行时会不时出现ELFI阀不工作现象，主机在试验过程中需要频繁的更换ELFI阀。

在排除由电气故障引起ELFI阀不工作的原因之后，对阀件进行拆检，发现内部柱塞有一些细微的划痕，因此判断为液压系统内有一一些小颗粒物，造成柱塞运行卡阻。

最后厂家要求在主机系泊试验前对每缸ELFI阀液压系统上增加专用临时滤器，见图6，试航后拆除。

经过多条船的试验证明这种方式有效降低了ELFI阀因机械卡阻造成的不工作现象。

# 五、主机逾越转速禁区时间过长问题的分析和处理

ME-B主机逾越转速禁区非常困难，需要3分钟以上才可以通过转速禁区，不满足主机正常工作要求。

为解决这一问题，通过调平船体艏艉吃水，以及延长主机转速禁区前负荷跑合时间，使扫气压力上升并稳定后，再通过转速禁区。

试验证明这种方式对逾越转速禁区有一定的帮助，但不能从根本上解决逾越时间过长的问题。

最后主机厂认为MEB机在降功率使用后存在这一缺陷，主要是排气阀延时关闭后，在通过转速禁区时不能灵活改变，还是一味延时，造成通过禁区时间过长。

通过修改主机控制系统扭矩限制参数来进行弥补，如图7，同时反映在图2ME-V阀延时关闭下方的虚线小方块中。

图7 主机控制系统扭矩限制参数

在多条船的运行论证下，该处理方式将主机逾越转速禁区时间控制在1分钟左右。

# 六、启示

ME-B主机在调试过程出现的问题中，除ELFI阀前需要增加临时滤器进行处理外，其他几个大的问题都是主机本身的问题。

从中可得到一些启示：

① 主机采用电喷，大大提高了喷油效率，但与之紧密相关的排气装置没有很好解决，使得电喷效果不能完全发挥。

② 为了配合电喷需要采用排气阀电控液压油操纵装置，随之带来MEV阀无法正常激活、主机倒车启动困难、主机不能快速通过转速禁区等一系列问题。

这些问题皆由其关键部件MEV阀的控制程序不完善造成，需要一边调试主机，一边改进MEV阀的控制程序。

③ 为解决快速通过转速禁区的问题，又重新用回传统的排气阀凸轮机构，并且将MEV阀的工作起点调整到55%负荷以上，回避转速禁区，55%负荷以下则采用凸轮机构。

④ 这种半电喷机排气阀操纵机构太多，过于复杂，管理十分不便。

⑤ 主机调试过程中暴露的问题说明：这款机生命力不强，需要用操纵简便，方便管理的全电喷机型取代。

# 七、结束语

ME-B主机作为新型主机在使用过程中出现了许多的问题，给生产带来了许多不便，但正是因为这样问题的出现才须不断的去深入研究和学习，通过问题的不断解决和修正，该机型正在日益趋向成熟，员工技术水平和对该机型的熟练程度也在日积月累中提升。
