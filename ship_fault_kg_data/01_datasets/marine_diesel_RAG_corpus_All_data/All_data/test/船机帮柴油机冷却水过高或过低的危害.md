# 柴油机的冷却系统与润滑系统、供给系统一样，对柴油机的可靠性、耐久性、经济性、动力性有着极为重要的影响。

柴油机过热或过冷是依据冷却介质的温度来反映的。

正常的情况下，柴油机在工作时，冷却水温度应该保持在80℃~90℃之间，高于90℃为过热，低于80℃为过冷。

无论过热还是过冷，都会使柴油机的使用性能降低，寿命缩短。

现代柴油机，大多采用闭式水冷冷却方式。

柴油机在工作时，只有温度保持在80~90℃时，燃料燃烧才能更充分，放出大量的热能，此时柴油机可发出最大功率，燃油消耗最经济，机件磨损也不大。

因为柴油机在工作时，气缸内气体温度高达1800℃~2000℃，而燃烧产生的热能中只有40%左右转变为机械能，约有30%被冷却系统带走。

如果冷却系统不能正常工作，造成冷却水温度过高或过低，不仅会影响柴油机的正常使用，甚至会产生故障和事故。

## 冷却水温度过高对柴油机的影响

冷却水温度过高，致使活塞、活塞环、气缸套、缸盖和气门等零件的工作温度升高，导致充气不足，燃烧不正常，容易引起敲缸、爆燃。

同时机油变质和烧损，零件摩擦和磨损加剧，甚至零件卡死、变形或损坏。

柴油机的动力性、经济性、可靠性和耐久性全面恶化。

### 加速零件磨损

冷却水温度过高，是指超过发动机正常使用时的最高温度。

在冷却水温度超过95℃以上时，会使润滑油温度升高而变得过稀、机油压力变低，在增加了机油消耗量的同时，机油上窜至燃烧室被烧掉，还会产生大量的积炭和胶状混合物，久而久之将活塞环槽上的泄油堵塞，气环的开口处被胶结而张不开，从而导致机油上窜更加剧烈，机油消耗得更快，由于积炭而使燃烧室的有效工作容积减小；

气环开口处被胶结又使气缸密封不严而造成压缩不良，导致柴油机工作条件加速不断改进化，动力性、经济性和使用性都急剧下降；

柴油机各润滑部位油膜易被破坏，运动副表面将出现半干摩擦甚至干摩擦；

由于气缸的温度太高，缸壁上的润滑油容易烧焦、积炭，促使零件磨损加快，严重时会造成拉缸、抱轴和烧瓦等事故。

如果温度过高，机油温度变高，黏度下降，压力变低，就不能充分满足增压器所需要的润滑和冷却条件，容易造成增压机内部结胶、积炭，使增压机早期磨损甚至损坏。

### 零件配合间隙被破坏，强度下降

柴油机的金属零件在长时间的高温作用下，强度、弹性和耐磨性会下降；

同时，高温使零件膨胀变形，严重地影响配合零件的正常间隙，甚至卡死。

### 充气量减少，功率降低

零件摩擦产生的热量，不能被冷却水带走，致使气缸内温度过高，使进入气缸的新鲜空气很快膨胀、空气密度降低，导致充气效率下降；

由于空气进气量相对减少，使燃油和空气混合比例失调，使柴油机的燃烧过程不正常，会发生早燃或爆燃现象，从而油耗增加，功率下降，排气管冒黑烟，工作的可靠和耐久性恶化。

### 影响柴油机外观

柴油机温度过高，还会导致机上的一些纸质、橡胶密封件因高温而失去弹性或者密封功能下降，造成柴油机密封件部位向外漏油，极大地影响了柴油机的外观整洁性。

## 冷却水温度过低对柴油机的影响

冷却水温度过低，大量的热量被冷却水带走，造成热量损失增加，柴油机工作粗暴，零件的摩擦和磨损还会因机油粘度的增大而增加。

实践证明，柴油机在过冷状态(冷却水在40℃~50℃以下)下工作，其零件磨损比在正常工作温度(80℃～90℃)下大好几倍。

### 加速零件磨损，输出功率减少

冷却水温度过低是指发动机的水温长时间的保持在低于正常工作的温度范围。

冷却水温度过低，润滑油温度随之下降，机油在低温时粘度较大，流动性差，不仅增加零件磨损，而且由于零件的相对运动表面的间隙阻力增大，使机械能损失增加，输出功率相对减少。

### 腐蚀机体零件，缩短整机使用寿命

柴油机的气缸温度过低，气缸内的水蒸气易凝结于缸壁上，柴油燃烧时生成的产物(二氧化硫)遇到冷凝在缸壁上的水，就会变成强列的腐蚀剂(如亚硫酸、硫酸)粘附在缸壁上，因此缸壁表面就会受到强烈的腐蚀，导致其表面金属组织疏松；

当气缸套与活塞环之间相到摩擦刮削时，会使腐蚀层、表面疏松的金属很快磨损脱落，或在缸套工作表面出现蚀点、凹坑，缩短使用寿命。

### 热损失增加，燃料消耗量增大

柴油机在低温下工作时，大量的热量被冷却水带走，热量和机械能的损失增加；

混合气不能很好地形成和燃烧，燃油消耗量会增加8％~10％；

成液滴状的燃油进入气缸后会冲洗气缸壁上的润滑油膜，并渗入到曲轴箱内，使零件的磨损量增加、冲淡油底壳内的润滑油、增加燃油消耗量和减少功率输出。

### 燃烧恶化，整机性能变坏

一些受热膨胀的零件因温度低而未膨胀到应有的尺寸，从而影响到全机工作性能，例如活塞与气缸间隙太大，密封不好；

气门间隙太大而受摇臂冲击等，并使柴油机不易启动。

在柴油机工作时，压缩后气体的高温是保证燃料着火的必要条件。

当气缸、活塞等零件温度降低时，将造成压缩终了温度下降、着火延迟和燃烧条件恶化，导致燃烧不完全、柴油机工作粗暴和排气冒黑烟。
