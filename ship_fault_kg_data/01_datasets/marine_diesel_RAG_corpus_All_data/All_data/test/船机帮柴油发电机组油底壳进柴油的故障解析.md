# 导读

一台电喷柴油发电机组发生油底壳液面不断上升故障，现场操作人员初步分析为机油中进水，经过多方面排查，故障点无法确认。

机修厂技术人员经过系统排查，对喷油器进行现场修复，故障排除，机组恢复正常运行。

# 一 事件发生过程

2018年10月7日，我公司某钻井队正在施工，该队的1号沃尔沃TAD1241GE柴油发电机组单独为井场提供电力，机组负载 210KW，电流300A，柴油机冷却水温 83℃，机油压力 400kPa。

18:50左右，正在运行的1号TAD1241GE 柴油发电机组逐渐发出间断的爆燃声，排气管排间断黑灰烟，机组电压与频率轻微波动。

当班的发电工见此情况迅速启动2号机组替换1号机组。

1号机组停机后，司机长查看故障诊断代码提示为：7.2，表示该机2号气缸喷油器产生故障，于是他们从库房里找了一只修复的喷油器替换2号气缸的故障喷油器。

喷油器安装好后，启动机组，机组工作恢复正常，随后倒机将其投入使用。

10月8日白天，当班的发电工在日常巡检中，发现该机油底壳的机油液面逐渐上升，且机油压力降低，至20:00交接班时，机油压力表降至为360kPa。

司机长对此进行了以下的检查：

（1）机油油质。
检查结果为机油粘度下降，未变质，嗅闻有柴油味；

（2）燃油输油泵。
检查结果为油封检查孔有泄漏痕迹，无滴漏；

（3）水箱散热器水位。
检查结果正常，无缺少。

根据检查结果，司机长判断油底壳内混入柴油，因未找到明确的故障点，根据经验判定柴油的来源可能是输油泵油封泄漏。

# 二 故障排除过程

10月9日，司机长更换了该机的燃油输油泵。

机组继续带载运行1天后，机油液面继续上升，机油压力降至320kPa。

在问题没有得到解决的情况下，司机长又查看了气缸盖罩壳内的燃油通道与喷油器外观，未发现有燃油泄漏现象。

沃尔沃TAD1241GE柴油机燃油系统图

10月10日，机修厂技术人员到现场排查故障。

根据该机组燃油系统的工作流程，机修工采取“手油泵憋压”的方式对整体气缸盖的燃油系统通道进行试漏检查。

机修工将气缸盖表面擦拭干净，利用手油泵将柴油机燃油系统的压力加到400kPa，这是燃油溢流阀开启的临界点，稳压10分钟后，观察到该机2号气缸的喷油器与座孔接缝处有燃油渗出，其余部位未见异常。

机修工将2号气缸的喷油器拆除下来后，观察到该喷油器的上部O型密封胶圈与胶圈座之间夹杂有金属碎渣，这些金属碎渣导致密封胶圈的密封性能被破坏。

压力试验后渗漏出的燃油

夹杂金属碎屑的密封圈

机修工清理干净O型密封胶圈槽内的杂物，将喷油器进行复装，并更换了机组的机油与滤清器后，启动柴油发电机组带载投入运行。

10月13日，该机组持续运行2天后，油底壳内的机油液面保持恒定，机油粘度正常，机油压力恒定在400kPa，故障排除。

# 三 故障原因

造成此次故障的原因是：

钻井队更换喷油器时，未将喷油器的卫生清理干净，喷油器上部O型密封胶圈与胶圈座之间夹杂有金属碎渣，这些金属碎渣导致密封胶圈的密封性能被破坏，低压燃油由此渗出，最终通过气缸盖回油孔道回流到油底 壳，引起机油的稀释与液面上升。

# 四 事件分析

1.此次故障排除中，机修工巧用柴油机自身燃油系统的憋压功能，对燃油系统进行憋压测试，快速、准确地找出了燃油泄漏的故障点，值得推荐。

2.钻井队司机长更换机件时，粗心大意，未将夹杂在密封胶圈槽内的杂物清理干净，造成故障复杂。

3.油底壳漏油故障排除中，司机长若考虑到更换喷油器前后的对比，即可快速地纠正错误，排除故障。

由此可见，排除故障应联系参考机组近期的运行状态、保养内容、换件质量等因素，这样可以在排除故障中做到事半功倍的效果。

# 五 预防、纠正措施

1.严格落实备件存放条件，保证存放的备件完好、清洁；

2.加强零、部件更换的培训学习，确保零、部件更换的一次性合格率；

3.加强操作人员业务学习，提高自身的故障判断、排除能力；

# 六 故障排除原则与技巧

## 1.故障的诊断原则

诊断故障时，应遵循以下原则：

结合原理，分析结构。
根据现象结合原理、构造，辨别故障的方向与范围，方便查找；

由现象到本质，根据故障的表象，判定出其故障范畴，正确区分后，重点查找，有的放矢；

由表及里，先易后难，故障原因很多，最终只有一个是唯一原因，应花费最短时间，最少精力，坚持由表及里，先易后难的原则；

按系统分段，有些故障排查起来很麻烦，但是如果将某一个系统按照分段分节的方法进行，就能够起到事半功倍的好效果。

## 2.故障诊断的步骤

1）弄清楚故障现象

故障的现象就是柴油机运行时的异常表现。

我们要充分运用实践经验，通过看、听、摸、嗅。

以及有关测试的仪器和仪表，将故障发生时的异常现象搞清楚。

同时还要注意以下几点问题：

①故障发生前柴油机有过什么样的症状。

②故障前进行过哪些维修保养。

③以前是否发生过类似故障。

④周围环境状况发生过什么变化。

2）定位

在弄清故障现象的基础上，诊断故障的原因，确定故障发生在哪个部位或系统上。

3）检查

通过综合分析和初步确定故障部位后，进行具体检查，以确定最后的原因和采取排除的措施。

## 3.故障诊断的方法

1）部分停止法

所谓部分停止法，就是当怀疑故障是某一个部位所引起的，即可停止该部位的工作，观察故障是否消失，如果消失则证明诊断正确。

例如，当怀疑柴油机冒黑烟是由某缸喷油器雾化不良引起，将该缸喷油泵柱塞翘起，停止该缸喷油器工作，此时，如果黑烟消失，则证明诊断正确，如果此时仍有黑烟，则再停止另外其他缸的喷油器工作，直至故障点查出。

2）比较法

所谓比较法，就是比较可能造成故障的零部件，当诊断认为故障可能是由某部件引起，就将该部件予以更换，然后比较更换前后故障的现象。

例如柴油机机油温度高，认为是水泵的流量不足所引起，则更换一个好的水泵，如果柴油机的机油温度恢复正常，则说明油温高确实是由水泵的流量不足所引起的。

3）试探法

这种方法是以改变局部范围的技术状态，来观察故障的变化情况。

例如，怀疑气缸压缩压力低是由于活塞缸套密封变差所引起，则可以向气缸内倒入粘度较大的机油，如压缩压力增加，则证明诊断正确。

如怀疑启动性能不好，是由于柴油机的水温过低引起，则可以向水中通入蒸汽将水加热，若启动性能改善则证明分析正确。

4）拆检法

对怀疑对象进行拆解检查，来分析故障的原因和部位。

例如，怀疑柴油机机油油耗过大，是由于某缸活塞环开口未错开，则可抽出该缸的活塞组检查活塞环的开口位置。

5）仪器诊断法

随着测试技术的发展，利用测试仪器来代替传统的手摸、耳听、鼻闻这些简易的方法，仪器诊断技术已经是越来越完善了。

①仪表检测。
压力、温度、压差等仪表，还有测功器等多种多样的仪表、仪器。

②声震仪检测。
噪声测量仪、振动测量仪、扭振测量仪等， 常见的是手工监听棒。

③磨粒分析（化学分析）。
利用机油中所含金属元素的特性来判断内部磨损情况，有指向性地判断故障所在部位。
