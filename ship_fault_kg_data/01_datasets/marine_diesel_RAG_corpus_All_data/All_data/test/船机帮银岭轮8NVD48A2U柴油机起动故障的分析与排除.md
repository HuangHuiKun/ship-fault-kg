# 前言

8NVD48A-2U柴油机是可逆转、单作用、四冲程、八缸、低增压、筒形活塞式船用柴油机。

该机型以马力适中、性能稳定、操纵灵活等优点著称，广泛应用于我国近海、港口、内河的中小型船舶上。

值得注意的是，虽然该机型的操纵系统结构紧凑、操纵简单，但系统相对复杂，阀件、联锁机构众多，故发生故障时，常常难以迅速找到症结所在。

特别是该系统彻底解体检修时，装复后往往产生各种操纵故障，难以判断，其中最常见的故障就是起动困难。

银岭轮在我厂修理期间，发生的起动困难故障颇为少见，排除的过程也比较曲折，故介绍给大家，供各位同行在修理该机型或类似机型时参考。

# 起动故障及原因分析

银岭轮于2003年11月进我厂排修，主机小修。

进厂试航时，主机起动换向均轻松灵活，故船方决定该机操作系统不作修理项目，由船员自行拆检清洁各阀件及管路。

修理期间曾发现有多缸起动阀压缩环磨损严重，报知船方，全部更换，但并未予以深究，试机时即发生起动困难故障。

该机初次起动是成功的，但经多次起动、换向起动后，就出现起动失灵现象，而且起动困难，一档根本无法起动，加至二档三档才能勉强起动。

对现象进行仔细观察，发现起动压力表压力正常，操作空气压力表正常，开始动车，旋转操作手轮后，起动辅助手柄偏移复位正常，曲轴旋转、然后停下，起动失败。

对观察到的现象进行初步分析：

压力表正常可排除压缩空气来源问题；起动辅助手柄偏移复位正常说明伺服器工作正常，那么控制阀、延时放气阀、顺倒车放气阀、操作轴上摆式凸轮、放气凸轮也应该没有问题；曲轴开始旋转说明已有压缩空气进入各缸，并推动各缸，启动滑阀、主起动阀、起动分配阀、起动阀应该也没有问题；起动时间正常也排除了因延时放气阀调整螺钉开度太大引起起动时间过短致使无法起动的可能。

经排除上述因素后，初步确定可能的故障原因是：

(1) 角尺杠杆复位不灵活或停油杠杆复位不灵活，致使进油控制杆不灵活或进油控制杠杆本身不够灵活，从而不能迅速恢复供油，造成供油时间过短无法起动，可能性较大；

(2) 供气紊乱，起动分配阀定时不准，起动空气定时紊乱，起动阻力大，可能性也较大；

(3) 部分起动阀不正常工作，存在严重漏气或卡死现象。因为本厂钳工已拆检过所有起动阀，并且更换了磨损超标的压缩环，故可能性较小，但不能排除动车后卡死的可能；

(4) 起动阀控制空气放气管路堵塞，使起动阀无法按时正常关闭。询问自修船员，所有拆下清洁的管路回装前均用压缩空气吹通过，可能性最小。

根据上述可能存在的原因一一拆检：

(1) 经拆检，摆式凸轮、起动断油凸轮位置正确，角尺杠杆、停油杠杆、进油控制杆复位快速灵活，不存在问题；

(2) 检查起动分配阀定时，转动飞轮，使起动凸轮的基圆对着起动分配阀挺杆，用手压下挺杆，观察孔上的基准线应与滑阀基准线重合情况，有两缸略有差异，予以调正。但重新试机后，情况并未好转，故障依旧，可见这也不是主要原因；

(3) 再次拆检启动阀，并未发现卡死现象；

(4) 最后，拆检起动阀控制空气放气管路时，竟意外发现放气管途经的交换滑阀C孔被人堵死，真正的原因即在于此。

对找到的故障原因进行进一步分析研究，起动时，高压空气有一路进入各缸起动分配阀，按凸轮轴起动凸轮配时顺序依次进入各缸启动阀顶部顶开主阀，让等候在主管高压空气依次进入各缸并推动活塞；并且按凸轮轴起动凸轮配时顺序依次回到各缸起动分配阀进入放气管，穿过交换滑阀C孔进入到达顺倒车换向阀放气，使各缸起动阀依次复位关闭。

C孔被堵死后，泄放的高压空气逐渐充满放气管，形成背压，使该关闭的起动阀不能迅速关闭；同时又涌入其它缸，将其它不应开启的各缸起动阀顶开，致使起动空气推动力互相抵消，难以起动。

第一次起动时，因为放气管的背压还不高，故仍可起动，但多次起动后，背压形成，故无法起动，这与故障现象也是相吻合的。

# 起动故障的排除

根据上述故障原因，将C孔堵物去除，再起动，一切正常，故障彻底排除。

但是，是谁堵住交换滑阀C孔的呢？

为什么要堵住它呢？

经过船方调查得知：

该机原来一直存在启动困难的问题，故前任轮机长将交换滑阀C孔堵住，并将放气管接头松松地带在交换滑阀C孔接上，从而有效解决了问题。

这又是怎么一回事呢？

分析可知，印证本文开头提到本厂钳工拆检各缸起动阀时曾发现有多缸压缩环磨损严重的情况，可确定原来各缸起动阀一定存在严重的漏气现象，泄漏的大量压缩空气混入起动阀顶部的控制空气通过起动分配阀进入通往顺倒车换向阀的放气管，因顺倒车放气阀来不及泄放而涌入其它缸，将其它不应开启的各缸起动阀顶开，致使起动空气推动力互相抵消，难以起动。

前任轮机长将放气管接头松松地带在交换滑阀C孔接头上，实际是直接与大气相通的，让泄漏的空气迅速排向大气，令其不影响其它缸，起动就正常了。

同时又必须将交换滑阀C孔堵住，否则顺倒车换向阀来换向控制空气将由C孔泄出，使换向无法进行，故前任轮机长的应急处理方法是正确的。

# 结语

正如前言所讲，该机型的操纵系统相当复杂，阀件、联锁机构众多，故发生的故障种类繁多，但只要正确理解该系统的工作原理及各部件机构各自的工作机理，发生故障时，仔细观察各种故障的现象，进行分析推理，找到可能存在的原因，再一一印证，一定可以找到症结所在，予以解决。
