# 共轨技术的特点和发展趋势

柴油机的电喷技术是世界船用柴油机发展的一个新的方向，由于该技术采用了高度自动化智能化的控制单元，使得电喷主机具高度灵活的控制功能，它可以实现很高的喷射压力，达到极佳的燃油雾化效果，并实现理想喷油过程中的压力可调；

同时它可以实现满足各种工况下最低排放要求的多种喷射规律控制以及灵活精确的喷油定时控制，这样就加大了柴油机控制的自由度，使之具有了未来柴油机满足更严格的排放法规要求所必需的发展潜力，为进一步提升柴油机的性能提供了更广阔的空间。

共轨技术的应用使设备轻、尺寸小、结构简单、安装和维护更加方便。

同时，又具有故障自动诊断和自动修复的功能，操作过程可以获取故障代码，然后对代码进行分析，找到对应的维修方法，保障设备的安全运行，并且减少有害气体的排放，降低震动以及噪音，大大改善了人们生活的环境，所以说共轨技术广泛应用到船舶上并且成为主流技术是一种必然的发展趋势。

# 船舶共轨柴油机排气阀故障分析

现在随着机舱自动化的不断完善、柴油机结构的不断改进，在船舶柴油机上，电（力）、液（压）、气（动）融合为一体，他们之间相互配合、相互制约，共同服务于机器，使得机器正常运转。

然而，在船舶柴油机的实际运行过程中会出现一些意想不到的问题，这就需要轮机管理人员根据其原理认真分析，找出故障的原因，进而解决问题，使机器恢复正常运转，保证船舶航行安全。

排气阀是组成柴油机燃烧室的重要部件，其工况直接影响换气过程的质量，影响柴油机的动力性、经济性、可靠性及排气污染，是柴油机工作优劣的先决条件之一。

同时，其工作环境十分恶劣，底面与高温直接接触，容易造成材料的热变形，导致排气阀工作效率下降；

柴油机运行中，排气阀频繁启闭，阀与阀座相互碰撞造成密封面变形或磨损，引起密封不良，造成高温燃气泄露，烧毁排气阀，降低柴油机的工作效率，减少了柴油机的使用寿命，阻碍了共轨技术的直接发展。

共轨柴油机营运中，排气阀由共轨滑油作为开启驱动力，对滑油油质、油压要求很高；

而燃用的是劣质燃油，许多厂家想要获得巨大的经济效益，就出售低价、恶劣的燃用油，一些劣质燃用油粘度低、滞燃期长，并且含有许多的钒、钠、硫，燃烧产物不仅严重威胁到人的身体健康，还会造成严重的环境污染，剩下的残渣在高温的条件下就会生成具有腐蚀性的物质，会破坏一些金属设备的结构，严重影响到设备工作的正常运行。

总的来说，共轨柴油机排气阀常见故障有：

（1）排气阀打不开，一般由于共轨滑油漏泄导致油压不够引起的。

（2）排气阀烧损，一般是排气阀密封不良，造成高温燃气泄漏，烧穿金属材料。

（3）排气阀高温腐蚀，目前航运市场上普遍使用的劣质燃油中含有大量的钒、钠和硫等元素，钒、钠等高温燃烧产物腐蚀排气阀。

（4）阀杆卡紧，气阀间隙过小或气阀导管中沉积物增多会导致阀杆卡住。

（5）阀杆断裂，这种断裂大多由于频繁撞击引起金属疲劳以及高温下金属的机械强度降低造成的。

（6）气阀弹簧断裂，大多是因为振动造成的，也可能是因为材质、热处理不符合要求或在保管中锈蚀所致。

（7）阀壳产生裂纹，通常由于安装时将固定螺栓拧得太紧造成的。

# 排气阀故障排查

排气阀对共轨柴油机来说非常重要，所以要及时做好检查和维护。

首先要选择适合本船的燃油滑油，确保油的质量，对于低价、质量差的燃油要坚决抵制，不能因为贪图便宜就购买质量不合格的燃用油，这样不仅对环境造成污染，还会损害自身的健康。

其次，要加强日常管理，包括对喷油器、排气阀阀杆、弹簧、阀壳等检查，确保各部件工况正常。

喷油器使用前轮机员要严格按照说明书进行试压、雾化试验、密封性等检查，测试其能够正常工作后方可投入使用，避免其工况不良而产生其他故障。

经常检查柴油机振动情况，以免因异常振动造成排气阀过度磨损而引起密封不良，降低运行效率。

此外，要注意柴油机排温的变化，因为温度过高或过低都不好。

所以为了保障共轨柴油机排气阀正常的运行，在排查期间严格按照说明书要求进行，确保其工况正常。

# 小结

虽然共轨柴油机具有许多优点，但在实际营运过程中，共轨柴油机也存在故障方面的诸多问题，尤其是排气阀时常发生故障，所以全面地研究和解决这些问题才能更加完善柴油机的性能，提高柴油机的工作效率。

当前，多点喷射技术让电喷柴油主机的振动降低到了一个新的低点，柴油机的各项指标也有了新的标准。

相信随着世界科技的日新月异，未来不断技术革新的船用共轨柴油机会为全世界的发展进步提供更加绿色、环保、高效的动力保证。
