# 导读

我国某海上油田的生产中心平台，配置有渤海油田首批应用的德国 Mak 品牌 16VM32C 型重型原油发电机组。

该机组以处理合格的地层原油和柴油为燃料，原动机端设计出功8000kW，配置西门子发电机组额定功率7680kW，作为该海上油田区域电站主力机组。

每台主机均有 16 个高压油泵，共 128 台高压油泵。

在该机型的每15000 h 周期大修工作都需要对单机16 台高压油泵进行现场解体拆检，同时高压油泵也是日常故障高发部件，检修频次高、检修任务重。

该油田电站每年需要拆检高压油泵近 100 台次，是主机日常作业的主要维修工作量。

每台高压油泵单台40kg，维修过程复杂，涉及多次翻转、固定和移动，原厂没有配备必要的工装，维修费时费力，并且非常容易发生磕碰，人员操作安全得不到可靠保障。

为提高高压油泵拆检效率、安全性和维修质量，介绍一套自主设计和制作的移动式高压油泵翻转工装，它能够实现一站式拆检维修，提高维修效率，将单个高压油泵维修工时从4个人工时降低到2个人工时，同时可以保障人员操作安全性。

# 一、设计目标

首先从高压油泵维修工艺出发，分析维修工艺过程需要的夹持、翻转、锚固、移动等工序，根据各个功能确定工装设计目标和要素。

考虑的问题主要有如下 4 个：

（1）选用市场上成型的减速箱产品作为翻转传动与锁定机构，实现360°翻转与固定。

（2）结合高压油泵的外形设计拆装夹具，确保高压油泵稳定支撑在工装上。

（3）由于主机房的行车覆盖不到维修区，设计的工装需要随时移动，因此设计一个移动底座和集油盒，将其安装到移动底座上，实现了移动和集油功能，方便行车吊运高压油泵，免去了人力搬运的安全风险和效率降低。

（4）为适应最佳人员操作高度，设计了中部的安装台，匹配最佳维修作业高度。

其次，在设计要素考虑成型后，结合高压油泵的外形尺寸和人机工程学角度，设计各个尺寸参数，用 CAD 制图软件绘制加工尺寸图纸，采购原材料进行焊接加工、制作、安装和调试。

最后，为验证设计的合理性，此次总共设计制作了两台维修工装，分别交付给不同组维修人员使用测试。

经过近一年的使用，完全达到了设计目的，实现了高效、安全拆检高压油泵的目的。

# 二、设计思路

## 1、“一站式”维修工作台

由于高压油泵维修过程需要多个角度翻转、多个零部件拆装、多个螺栓扭矩需要校核，所以要求工装实现包括翻转、夹持、移动、锚固的功能于一体，避免一个维修工作，多个工序在多个地点完成及多次拆装、翻转和固定。

运用“一站式”维修的思路，既是设计目标，也是设计切入点，集中多功能于一体。

## 2、旋转与锁定机构

翻转工装合理选型市场上成型的蜗轮蜗杆传动齿轮箱作为旋转部件，体现了新产品优化利用现有市场可用资源的思路，既可靠又安全地实现了预期转速的翻转和360°任意角度自锁定位，采用了集成设计思想。

## 3、工装夹具设计

在设计夹持工装时候，通过分析高压油泵的外形特点，合理选择了夹持面，既保证了夹持部位稳固、完全满足螺栓扭矩的校核反作用力和，又不损害高压油泵本体。

## 4、移动维修站

为实现移动目的，设计移动底座，将上述工作平台安装到移动底座上，可以轻松实现维修工装的任意位置移动。

# 三、设计成果

## 1、高压油泵的结构和拆装工艺特点

Mak 主机高压油泵的维修工作需要将高压油泵立式固定，逐个拆除内部部件，如高压油泵本体、柱塞偶件组件、回位弹簧、出油阀组件、柱塞偶件固定螺钉、出油阀固定螺钉、柱塞偶件弹簧座、底盖、底盖螺钉等。

拆除过程需要对高压油泵进行翻转，需要将其固定稳固。

在回装过程中，要使本体始终固定在工装上，逐个恢复出油阀、柱塞偶件、弹簧、弹簧座等，并对出油阀螺栓和弹簧底座螺栓扭矩进行校核。

## 2、夹具设计

夹具根据高压油泵外形特点，选择高压油泵底座下部的对称突出平面作为夹持面，在夹具上设计耳板作为支撑点，防止油泵倾斜。

设计平面开口夹持空间，独立的夹持长条，通过螺栓预紧的方式将高压油泵稳固夹持在夹具上。

同时，夹具要考虑和翻转减速箱关联，运用联轴器靠背轮的形式，设计夹具和翻转减速箱输出轴的连接部件，在主体夹具上预留法兰连接孔（图1~图4）。

# 四、结论

该工装以解决原油主机高压油泵维修效率低、维修安全性不可靠为出发点，从维修工艺出发，结合高压油泵的部件外形，合理选择限制自由面，因地制宜设计而成。

通过蜗轮蜗杆传动与锁定机构，满足旋转维修和锁定的要求。

该工装总体设计思路清晰，成品经过使用检验，实现了提高维修效率的目的。

该工装设计思路同样适用于各型原油主机的高压油泵或其他需要翻转维修的设备或部件，只需要按照不同部件的外形尺寸进行修改加工图纸即可，有很高的推广价值。
