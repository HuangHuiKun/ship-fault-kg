# 导读

单体泵技术是当今内燃机领域内燃油喷射技术的重要代表,沃尔沃D12C型电喷发动机主要有德国的博世和美国的德尔福两种类型。

本文主要以博世单体泵为例,来分析单体泵的常见故障类型、故障原因和预防措施。

D12C型发动机单体泵通过驱动摇臂机构、电子控制单元(ECU )和多个传感器等主要部件,来完成其高压喷油过程。

# 二、单体泵故障现象

单体泵常见故障现象主要有:

①发动机起动后出现缺缸现象,即表现为有一个或以上的气缸没有正常工作,并伴有抖动现象。

②发动机起动后车辆动力不足，发动机运转均匀,无高速。

③发动机起动困难,起动后车辆无法正常工作。

④发动机无法起动。

# 三、故障类型与故障原因分析

由单体泵的结构和工作原理可知,针对单体泵主要组成部件,在实际工作过程中,可根据发动机出现故障现象和故障类型分析故障原因,结合结构图2分析如下:

1、因燃油清洁度问题使单体泵电磁控制阀部件⑨磨损或者进、回油道⑥和③堵塞,导致发动机无法正常工作,表现为发动机缺缸或者无法起动现象。

2、因电磁阀⑨内置程序错误或单体泵维修安装时未作记号或者未进行间隙调整,导致单体泵油量调节控制阀⑧关闭不严,达不到最大供油量,导致单体泵供油不足，表现为车辆动力不足,发动机运转均匀,无高速,排气管排气量过少。

3、因单体泵长期使用达到使用极限,其内部密封不严或老化损坏,或者单体泵外壳有沙眼,将会使柴油外漏混入到机油中,影响发动机润滑油润滑效果,加速发动机内部运动构件的磨损,缩短发动机的使用寿命,严重时导致发动机损坏。

4、因不合理使用和保养设备，使柱塞偶件磨损后，单体泵提供的燃油压力不能将喷油嘴打开,表现为发动机启动困难。严重时会使球型接头①和回位弹簧②和损坏，导致单体泵内部柱塞构件卡滞,将会对发动机内部主要构件曲轴造成冲击,表现为发动机无法起动。

5、由于发动机在怠运转时间过长,导致燃烧温度下降,引起燃烧不良,形成积炭或者燃油中有水或脏物造成喷油嘴⑤卡死,造成发动机起动困难。

6、由于设备震动、作业环境等复杂因素,造成连接单体泵电磁阀输入信号虚连或中断，发动机无法正常工作,表现为缺缸或者无法起动或起动后动力不足。

# 四、预防措施

对于电控发动机,做好单体泵的日常保养和防护,对于减少发动机故障率和延长发动机的使用寿命具有重要意义。

主要做到以下几点:

①保证所添加燃油的清洁:

在添加燃油时严禁摘掉过滤网,特别是船舶加注燃油,要注意加注环节及使用期间的控制,严禁把杂质和水等物质加入到燃油系统中。

②做好发动机的保养工作,要定期进行发动机机油及滤芯的更换;定期进行燃油系统和燃油箱的清洗,以确保使用燃油的清洁。

③在维修过程中,一定要注意手、零件、工具的清洁，严格控制维修工艺,避免造成人为故障。

④定期检查、保养与维护:

要定期对发动机控制线路和油路进行故障排查,特别是发动机大修时,要通过专业的单体泵校验平台和设备对单体泵进行效验与调试。
