# 导读

某集装箱海船主机为MAK8M552C，是1995年10月制造的8缸四冲程柴油机，转速为500r/min，功率为6000kW，采用可变螺距螺旋桨。

2001年10月该轮在上海接船后的第一次航行途中发现振动比较明显，但是一直没有找到原因，直至有一次在日本港停泊期间，进行主机臂距差常规检查时，发现主机第一缸臂距差已接近极限，其它各缸还属正常。

考虑到飞轮和橡胶联轴器对曲轴拐挡差的影响，就仔细检查飞轮端，结果发现高弹性橡胶联轴器上有许多裂纹，裂纹深度和长度都非常大，最长有220mm，最短也有60mm，如表1所示。

从该高弹性橡胶联轴器使用3年年限来看，不像是正常疲劳损坏，应该有一个附加应力作用在联轴器上，使联轴器产生异常疲劳破坏。

# 一、高弹性橡胶联轴器产生裂纹的原因

如果轴系对中不良会增大高弹性橡胶联轴器的附加应力，容易造成联轴器疲劳损坏，产生裂纹。

此外，如果轴系和柴油机振动超过设计值，也会增大弹性联轴器的附加应力，同样容易造成联轴器疲劳损坏，产生裂纹。

经检查减速齿轮箱的齿轮，齿轮齿面良好，没发现问题。

如果轴系振动异常，势必影响到减速齿轮箱，造成齿面损伤，看来轴系振动异常应该可排除，如果柴油机曲轴轴系状态不理想，也会使柴油机产生异常振动，造成联轴器损坏。

在拆检主机第1、2道主轴承轴瓦时，没有发现异常。

同时拆下联轴器后，进行柴油机各缸拐挡差测量，发现各缸拐挡差非常正常。

这就可以排除柴油机因曲轴轴系不理想而造成柴油机的异常振动。

在拆除联轴器后，利用双指针-塞尺法进行两端轴对中检验，具体测量数据如表2所示，测量时机舱温度为25℃。

那么两端轴对中不良是什么原因造成的？

一个是新船建造时轴系就没有对中，另一个是船舶营运以后产生的轴系不对中。

查看新船建造时德国劳氏船级社签署的检验报告，偏差值δ=0.15，是符合要求的。

从测量出来的数据可以看出，轴系不对中是由于主机曲轴自由端比较低，也就是整台主机下沉造成的。

那么船舶营运后怎么会造成整台主机下沉呢？

该轮主机底座采用的是弹性底座，在环氧树脂垫块上面垫上高弹性橡胶块。

据测量，环氧树脂垫块并没有发现有明显的变形和损坏，因此主机下沉的问题最有可能出在高弹性橡胶块上，所以初步推断是由于主机底座高弹性橡胶块的受压变形而导致了主机底座下沉，最终导致轴系不对中而使联轴器发生断裂。

接着对主机底脚高弹性橡胶块进行了测量，结果如表3所示。

以上测量数据是在主机底脚螺栓尚未松开，与主机所有连接管系均已脱开，且船体前后吃水完全调平的情况下测得。

所有高弹性橡胶块在受压情况下实际厚度应为测量数据减去高弹性橡胶块上方的挡油板厚度(2mm)。

据说明书上规定高弹性橡胶块厚度应当为81mm±1mm，可看出测量值已经远远偏离了标准值。

看来是由于主机底座高弹性橡胶块长时间受压产生塑性变形，致使高弹性橡胶块的厚度减少，造成主机整体下沉。

至此，高弹性橡胶联轴器出现裂纹的原因是主机底座高弹性橡胶块产生塑性变形，造成主机整体下沉，使轴系对中不良所致。

如果没有及时发现高弹性橡胶联轴器裂纹，就有可能产生更加严重的恶性海损事故。

# 二、整体抬高主柴油机校中轴系的案例分析

虽然轴系失中故障的原因已经知道，但是要想修复轴系失中故障，必须整体抬高主柴油机，使得两端轴中心线偏差值校正到允许范围之内。

整体抬高主柴油机的方法有：

1. 换新高弹性橡胶块后重新浇铸环氧树脂垫块；
2. 换新高弹性橡胶块；
3. 重新浇铸环氧树脂垫块；
4. 加厚高弹性橡胶块上面的挡油板。

当然各种方法各有利弊。

轴系失中故障发生后，VULKAN无锡公司派人到船上进行现场调研，并与德国VULKAN总部商谈，最后给出的结论是，必须采用第一种方法。

毫无疑问，这种方法是修复轴系失中故障最为彻底的，也是最好的。

只不过，这种方法需要从德国进口环氧树脂原料和高弹性橡胶块，再由德国VULKAN总部指定的中国代理厂家进行浇注，同时要将主柴油机整体抬高至足够高的位置才能进行浇铸，不仅技术难度大，费用非常高，而且费时费力。

至于第四种方法，是最省时间、人力和物力，当然效果肯定是四种中最差的。

至于第二、三种方法，其效果正好介于两者之间。

该船的管理公司最终采用的是第四种方法。

这个方案的便利之处就是不需要换新高弹性橡胶块和重浇环氧树脂垫块，在上述四种方案中最为简单，具体操作方法就是：

把主机整体抬高2mm，然后在2mm厚的挡油板上面再垫上厚度为2mm的挡油板，最后把主机整体放下。

虽然第四种方案最为简单，但也要密切必须注意以下几点：

1. 做到均匀地整体抬高主柴油机；
2. 随时测量两端轴的偏移值，确保主柴油机垂直方向上的定位；
3. 随时测量主柴油机的拐挡差，以免曲轴变形损坏；
4. 随时测量侧向止推器的间隙，确保主柴油机的横向定位；
5. 随时测量主柴油机的轴向位移，确保主柴油机的轴向定位。

如果整体抬高柴油机时不均匀，势必造成主柴油机扭转和弯曲变形，曲轴势必会遭到损害。

所以在整体抬高主柴油机时不要一步到位，而是每步都要测量曲轴的拐挡差，避免损伤曲轴。

除了随时注意测量主柴油机的拐挡差以外，还要测量主柴油机侧向止推器的间隙。

在主柴油机整体抬高之前，侧向止推器的间隙如表4所示。

所测得数值是在螺栓松开前测得，括号外的数值表示最大值，括号内的数值表示最小值，该侧向止推器的间隙标准为3mm。

鉴于主机在正常工况下工作会产生纵向和横向的振动，又同时出现轴向位移，振动加剧使联轴器工况恶劣造成破裂损坏。

主机侧向止推器的间隙增大是由于柴油机的横向振动造成的。

所以在轴系校正过程中要随时测量两端轴的垂直和水平方向上的偏移值，确保轴系偏移值在规定值0.20mm之内。

# 三、修复方案的实践检验

船舶大修后的第一次航行，在码头备车时就发现船体振动异常。

船舶离港后定速航行时，主柴油机的负荷逐渐从60%加到95%，随之而来的是船舶振动也逐渐加剧，到95%负荷时，上层建筑剧烈振动，而船速只有12kn。

以前在相同海况和配载的情况下，主柴油机95%负荷时船速可以达到16kn。

当然船速降低原因很多，也有可能是主柴油机本身的故障。

为了排除这种可能性，当时还测了主柴油机各缸的示功图，并没发现异常情况。

很明显，振动加剧消耗了大量的主柴油机有效功率，使得船速达不到16kn。

经过仔细检查，发现主柴油机飞轮端和机舱燃油增压泵等部位振动也非常剧烈。

为了安全起见，并经管理公司主管人员同意后，采取减速航行。

减速航行回来以后，又把主柴油机抬高，抽出两片厚度为2mm的挡油板，换上重新加工的厚度为3mm的挡油板。

经过处理以后，再次航行时，发觉振动比上一个航次减弱，在主柴油机95%负荷时船速也可以达到15kn。

虽然振动比上一个航次好多了，但主柴油机飞轮端和机舱燃油增压泵等局部位置的振动并没有消除。

因为振动没有得到彻底解决，航行时经常振断管子和螺栓，更严重的是主柴油机空冷器紧固螺栓每隔3~6个月必须定期更换，否则就被振断。

综上所述，大修以后船舶产生的振动可以断定是由主柴油机整体抬高所致。

后来该船就没有再进行重新修理，一直凑合航行。

从这次整体抬高主柴油机修复轴系失中的案例中，可以得到许多启发，在处理船机故障时必须综合考虑，权衡利弊。
