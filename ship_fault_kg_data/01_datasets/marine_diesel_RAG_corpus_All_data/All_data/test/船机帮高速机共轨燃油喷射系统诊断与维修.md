# 导读

柴油机共轨燃油喷射系统是集现代传感检测技术、喷油结构与计算机控制技术的一项现代技术，共轨燃油喷射系统在运用过程中，不会沿用以往的柱塞泵脉动供油这一原理，而是通过共轨以间接、或者直接的方式来形成高压燃油，之后输送到各个喷油器之中，并利用集成至各个喷油器中的电磁开关阀的闭合和开启，控制喷油器 喷射到效果最为显著的燃烧比、点火时间以及点火能量。

据调查结果显示，共轨燃油喷射系统喷油压力愈高，那么燃油雾化之后的颗粒就会愈细，所排放的颗粒与有害气体则愈少。

# 高速机共轨燃油喷射系统工作原理及特征

高速机以工程机械柴油机居多，其共轨燃油喷射系统工作原理及特征，主要内容体现如下：

## 工作原理

共轨腔、喷油器、高压油泵、电控单车及传感器等一同构建成为共轨燃油喷射系统，柴油机共轨燃油喷射系统在起初运作时，会包容诸多传感器，且所有的传感器均会收到很多信号，进而利用信号与信号之间的良好传输，来记录运作期间的设备使用参数。

通过计算发动机的实际转速，了解加速踏板的实际角度，则能够明确共轨柴油发动机的主要喷油正时，且也能够依据近期压力与水温等，来检验基本喷油正时，以有效控制误差，将其控制在相对的范围中，之后则能够获得最优的喷油正时，ECU依据蓄电池提供的一些信号，能够调整喷油正时，在满足条件后，则能够启动喷油正时。

影响喷油的主要因素为指令脉冲，且其也会影响到喷油时间，在喷油期间设备与转速的负荷均不存在关系。

开始喷油的时间主要是根据电磁阀的通电时间来明确的，喷油量主要是由电磁阀，经过时间的长与短来实施测量，电子脉冲会对喷油参数产生控制作用，共轨电控喷射系统能够经过曲轴部分传感器实施检测，以了解设备运转的真实状况，在运转期间，为科学控制喷油量那么则能够以观察、了解电磁阀的响应速度来决定，且也能够控制发动机运转期间所产生的波动。

每个缸的实际喷油量是很难控制的，所以为确保共轨燃油喷射系统处在顺畅的运作状态下，则应了解缸之间转速的实际波动偏差，并根据其实际情况，来切实防止颤振情况的出现。

## 特征

在共轨腔中的高压能够用在喷射方面，利于节约增压机构，同时共轨腔中为持续高压，高压油泵需求的驱动力要远比以往油泵需求的少。

运用新型电子控制装置与配备高速开关阀。

运用共轨形式进行供油。

利用高压油泵之中的调节电磁阀能够依据发动机负荷的真实情况与排放性需求及经济性需求等多方面，来合理调节共轨腔中的油压，特别是提高发动机的性能。

高速电磁开关阀在控制时较为灵活，且频响较高。

能够利用电磁阀对喷射定时进行控制，也能够控制喷射速度，科学调节不同情况下后喷射与预喷射的实际喷射量以及喷射时间等。

# 共轨燃油喷射系统诊断与维修

共轨燃油喷射系统诊断与维修，主要内容体现如下：

## 柴油机运行期间自行熄灭诊断与维修

柴油机在运行期间自行熄灭的主要原因，一方面为缺失燃油，另一方面则可能是某个部件存在卡滞情况。

对此，就应针对故障的一些特征与实际情况来实施判断与分析，如果柴油机在运作过程中逐渐无力，直至熄火，那么就需检查在燃油箱之中，是否具备一定量的柴油，以及通气孔是否处在通畅的状态中，还应对低压燃油位置的供应问题进行检查，了解输油泵的实际运作状况，而后再针对不同问题采取相应的应对措施，解决柴油机运作期间熄灭这一使用故障。

如果柴油机在运作期间突然熄灭，那么就需检查传动轴和喷油泵二者之间的连接情况，还需检查柴油机的实际转动状况，以便合理解决问题。

## 熄火前不正常现象诊断与维修

熄火前不正常现象体现在转速不够稳，柴油机渐渐熄灭。

以其诊断方式来说，应将油箱盖打开，拔出量油尺，了解柴油机的使用情况，若发现油箱中无油，那么加满油即可。

再者，还应把油门放置在中位，变速器挂空挡，通过手摇的方式去转动曲轴，根据喷油器喷出油的声音，来判断其问题，如未能听到喷油声，那么则可能为燃油低压油路进入空气而导致，需检查各个接头与输油管是否存在渗漏或破损现象，若将空气排出之后就能够启动，但机车转速不够稳定，那么则表明油路中存在柴油供应不畅以及堵塞现象，在此就应对柴油滤清器进行维护与保养。

除此之外，在冬季如果油中存在水就会结冰，进而就会堵到油路，所以还需疏通与清洗输油管，如果所运用的柴油标号错误，那么也可能致使因蜡质偏多，流动效果偏差，而导致低压油路不够通畅，而后就会产生自动熄灭现象。

若进行曲轴摇转时能够听到喷油声，那么则表明故障极有可能为配气结构方面，对此情况就需开启摇臂室罩盖，了解锁片亦或者气门卡簧是否存在脱落现象，气门座和气门二者之间是否存在松动情况，摇臂轴和摇臂二者之间是否由于烧结而丧失真实作用，以及摇臂推杆存在脱落现象与否，在经过一系列检查之后，才能够进行再次启动，在调整与维修的过程中，还应避免气门入至气缸之中，以防止出现捣缸事故。

以排气管冒白烟这一现象来说，则需先检查好柴油之中是否含有水，开启油箱的螺栓，把全部的水排干净后再进行启动，如果在启动之后还会存在冒白烟的情况，那么就很可能是受到缸垫的影响，导致机体水道之中的冷却水渐渐流入气缸中。

对此，就需了解油底壳机油之中是否含有水，并根据其实际情况来进行机油与缸垫的更换。

在冬季时气温普遍较低，柴油机也会受此影响，在启动之后会徐徐冒出白烟，在这时若马上增大负荷，那么则会致使由于功率较低以及柴油燃烧较差等而产生自动熄灭现象，对于此情况，则应在确保水温上升之后，在投入至正常的运行之中，这样才能够避免因季节因素而影响到柴油机的发动。

## 熄火前未存在不正常现象的诊断与维修

对于熄火前未存在不正常现象，则是由于柴油机燃油，高压油路中存在故障而导致的。

一方面则体现在喷油器未能正常工作。

对于喷油器中的针阀偶件来说，会受到柴油之中酸性与水分等的影响，而出现咬死或发卡现象。

再者，若是封面受到损伤，那么在缸中的可燃气体会进入其中并构成积炭，这样也会卡住针阀。

对于这种问题的维修方式来说，则应停止喷油器喷油，让柴油机能够自动熄灭。

另一方面则体现在喷油器运作较差方面，如果喷油器存在滴油现象，那么就会降低喷油压力，导致喷油时间增加，在这时柴油机的功率也会下降，而油耗则会随之提高，在此情况下，柴油机也极易自动熄灭。

针对此，则应及时检查喷油器运作过程中所存在的问题，而后及时应对问题，从而防止故障问题的产生。

## 柴油机启动困难诊断与维修

对于共轨柴油发动机通常起动发动机3~4 转，就能够着车。

导致柴油机启动困难的原因主要包括油路存在空气，燃油不达标以及燃油系统设计压力较低等。

以柴油机启动困难诊断与维修方式来说，则应先实施自诊断，了解仪表板显示屏中所显示的信息，可通过所显示的信息来了解产生故障的位置，也能够运用解码器来实施检测，以明确故障位置。

共轨燃油喷射系统，对燃油质量有着较高要求，对于燃油污染问题来说也是较为敏感，在选择燃油时，应确保其满足我国相关规定，并根据不同地区的实际环境来运用不同的柴油，通常来说，在夏季时应选择 0 号柴油，在冬季时应选择-10号柴油，若当地的温度为-20摄氏度，那么就需运用-20号柴油。

若温度为-30摄氏度，那么就需运用-35号柴油。

在此情况下，如果运用质量较为差的柴油，那么极易导致油路堵塞以及不畅等现象的发生，柴油机启动就会变得非常困难。

所以说，务必要运用质量高，以及适宜当地环境的柴油。

# 总结

燃油喷射系统为柴油机的重要组成部分，使用电控共轨则增大了维修工作的开展难度，因此，应对其实施良好的诊断，以了解问题的产生原因，而后借助行之有效的维修方式去排除故障。

对此，就要求细致分析柴油机共轨燃油喷射系统运作期间所易于产生的故障问题，而后为故障的排除提供有效保障，从而实现最佳的维修效果。
