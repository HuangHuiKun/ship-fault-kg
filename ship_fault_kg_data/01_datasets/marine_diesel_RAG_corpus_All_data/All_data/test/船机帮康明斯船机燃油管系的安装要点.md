# 船机帮康明斯船机燃油管系的安装要点

## 1. 燃油箱高于曲轴中心线0-1.6m（0-5英尺）

燃油箱高于曲轴中心线0-1.6m（0-5英尺）时，装在柴油机回油管中的止回阀将阻止燃油通过回油管充满气缸。

在燃油箱与燃油泵之间的供油管段应安装燃油截止阀。

## 2. 燃油箱高于曲轴中心线1.6-8m（5-25英尺）

当燃油箱安装位置高出曲轴中心线1.6-8m（5-25英尺）时，应该安装浮动箱或日用油箱。

如果选用浮动箱，就必须足够大，以确保回油不会明显地升高供给柴油机的燃油温度。

使用日用油箱时，在日用油箱与主油箱之间需安装截止阀，这样可对日用油箱加油，然后关断供油。

在上述两种情况下，主油箱与浮动或日用油箱之间应安装燃油滤器，在燃油滤器与主油箱之间安装截止阀，使燃油滤器维修时不至于流出燃油。

所有的辅助油箱（日用油箱或浮动油箱）均需有效气孔和观察玻璃窗。

观察玻璃窗应放在与喷油器同高度的放气管上，如果浮阀一旦失灵或截止阀打开，观察玻璃窗就会有燃油，如果出现这种情况，有可能燃油已进入气缸，此时不可起动柴油机。

如果燃油箱位置高于曲轴中心线1.6m（5英尺），回油管应回到辅助油箱。

回油系统必须至少有一根回油管不被关断，这样能防止所有回油管偶然关闭。

否则，由于PT燃油系统的回油量达到燃烧燃油量的5倍，这将导致燃油消耗增加、气缸压力和温度升高、烟度增加以及燃油泵、喷油器或柴油机出现故障。

如果在回油管中采用选择开关阀，阀的口径至少同回油管内径一样大。

## 3. 燃油箱低于曲轴中心线1.6m（5英尺）或更多

船用康机一般的机带燃油泵最大扬程为6英尺。

如果主燃油箱底部低于曲轴中心线超过1.6m（5英尺），那么任何燃油系统都应安装燃油输送泵将燃油输送至柴油机。

若用浮动箱，则需要一台连续运行的输送泵将燃油以最大55kPa（8psi）的压力输送至浮动箱。

所有辅助油箱必须有放气管和溢流管。

如果浮阀或开关一旦失灵，会使辅助油箱燃油外溢，溢流管可以将燃油输送回主油箱。

## 4. 阀

安装在供油管中的阀应具有低的流动阻力，并能避免空气进入燃油系统。

旋塞阀最适合于这种要求，也可以采用球阀或其它类型的有填料密封的阀，但它们需要定期更换填料以保证气密性。

有些阀门在设计时没有考虑进油管密封作用，所有不能应用在供油管中。

如果有用柴油机手动截止阀，其控制联杆在任何情况下都应能完全打开或完全关闭阀门。

选择阀开关的口径应至少同供油管内径一样大。

用于燃油系统的所有阀门都应清楚地标出它们的功能和位置（开/关）。

燃油管路的布置不得在管内引起压力波。

供油管和回油管的排列都不能出现环路，油管中的任何环路都将导致管内产生压力波，并使柴油机转速不稳定。

无论使用几台柴油机，每台柴油机都应有独立的供油管路和回油管，运行中的两台或多台柴油机使用共同的油管会导致怠速波动和转速不稳定。

某台柴油机回油管中的压力脉冲可能影响它共同使用一根回油管的柴油机运行。

解决该问题的办法是使共用回油管的横截面积等于各独立脚点回油管横截面积的总和。

燃油箱必须装有放气管和回油接头，让空气和其气体能从燃油中充分地分离出来。

另外放气口还必须能防止灰尘和水进入燃油箱。

放气管让回油管中带来的空气和其气体从油箱中放走，同时能平衡油箱内外的压力，防止油箱膨胀或压瘪。

放气管的直径至少是注油管直径的1/3，最小不低于13mm（0.5英寸）。

PT燃油系统的回油量相当大，并有燃烧气体混杂其中。

为了防止热的回油或气体被抽进供油管，回油管应位于油箱顶部并尽量远离供油管。

供油管和回油管的最短距离305mm（12英寸）。

放气管的终端应设置在甲板之上并有防护的位置。

管的端部推荐采用鹅颈式弯头，以防止灰尘和水通过放气管进入燃油箱。

燃油箱可采用镀铅锡钢板或磷化处理钢板、铝合金或玻璃纤维。

在柴油机燃油系统中不能使用镀锌或锌合金钢板制成的油箱或管道。

所有辅助油箱的放气管路中应有一位置高于主油箱可能达到的最高油位，这样可避免一旦浮动箱或日用箱燃油过满外益时意外地淹没舱底。

回油管必须布置到油箱顶部

PT燃油系统的回油中含有一些燃烧气体。

这些气体可能被抽进供油管中，这将会引起柴油机熄灭或性能恶化。

燃油泵前需要安装油水分离器

PT泵均为燃油润滑。

燃油中的水分会减弱润滑效果，并可能导致燃油泵损坏。

喷油器也是由燃油润滑的，也可能由于燃油中的水分而损坏，所以有必要让燃油在到达燃油泵之前利用油水分离器分离出燃油中的所有水分。

## 5. 燃油管路

柴油机与舷侧管路之间的燃油管必须装有柔性段，以允许柴油机与船体间的相对位移。

柴油机振动、热膨胀和大风浪时船体横、纵倾造成船体弯曲变形等都会导致刚性燃油管的破裂损坏。

柔性软管应采用由制造商确定为适合于柴油机燃油的软管类型。

适合于燃油系统的船舶管道材料是铁、钢、不锈钢、铜镍合金、铜以及柔性软管。

在易遭受弯曲和振动的地方，不建议使用铜和铜镍合金管。

燃油管路应予以保护免遭破坏，硬、软管每隔一定距离应有支撑，以免由于负荷过大和振动而损坏，不能用电线捆扎的办法紧固燃油管。

此外，还可以按船舶设计要求安装双联燃油滤器，此配置需向康明斯经销商咨询。
