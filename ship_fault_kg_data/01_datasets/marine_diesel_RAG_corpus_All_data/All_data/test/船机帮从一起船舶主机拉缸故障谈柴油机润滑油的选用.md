# 导读

通过某LPG船一起主机拉缸案例，阐述船舶柴油机润滑油合理选用和管理的重要性，讨论选用润滑油应根据船舶柴油机的型号、燃油品质等具体情况，充分考虑润滑油的黏度等级和碱度。

介绍船用柴油机润滑油国内外主要生产商及其相应的产品牌号。

# 一、某轮主机拉缸故障

某LPG船，日本建造，主机Akasaka 6A-41型，四冲程，6缸，额定功率2427KW，额定转速 230r/min，活塞下部空间与曲轴箱间有隔板，轴系润滑与气缸润滑各成系统， 滑油回油温度设定在44 ~ 45℃。

该轮从事沿海航线运输，2008年6月起，系统油使用 3030 船用中速筒状活塞柴油机油（以下简称中速机油），黏度等级 SAE30，碱值30mgKOH/g；气缸油使用4040中速机油，黏度等级SAE40，碱值 40mgKOH/g；主机一直燃用180cst 船用燃料油。

## 1、故障现象

2008年6~8月：

系统滑油压力低于正常值 0.27 MPa， 船员不得已采用降低滑油进机温度来保证油压 （这种作法无助于甚至不利于轴承和导/滑板润滑）；

多次检查发现多个活塞异常磨损，但均不严重；

2008 年9月（自2008年6月，主机运转1158小时），吊缸检查No.1缸和No.6缸，发现缸壁和活塞表面有较严重磨损划痕，局部表面微小“熔着”，显然是拉缸；相继检查其它各缸，气缸套内壁和活塞表面均有不同程度拉毛。

现场取系统油油样送检（含光谱和铁谱分析）结果显示， 金属颗粒物含量高且与缸套和活塞环材料成分一致，证实主机多个缸拉缸。

## 2、故障原因分析

### （1）机械方面

查对“轮机日志”和维修记录知，1# 和 6# 缸早已过了磨合期，可排除因磨合不充分而导致的拉缸。

2008年9月No.1 缸和 No.6 缸吊缸检查，见活塞组件、气缸组件没有缺损，安装到位，可排除因零部件损坏导致拉缸的可能；冷却水腔和冷却水管无脏堵，吊缸后冷却水系统和燃油系统正常，可排除因冷却系统和燃烧不良引起拉缸的可能。

排除机械原因后，根据故障排他法，只能从燃油质量和润滑油方面查找原因。

### （2）燃油方面

该轮主机一直燃用180cst船用燃料油，供油商包括中国石化中海燃供大连分公司， 以及中国石化中海燃供的宁波分公司和宁波甬石旺泰船舶燃料公司。

这几家公司的燃油理化性能分析见表1，经众多船舶多年使用证明燃油性质稳定，可基本排除燃油的影响。

### （3） 气缸油方面

气缸油总碱值，应与燃油硫含量匹配。

因为燃油燃烧产物例如SO₂和SO₂容易与水结合形成硫酸腐蚀燃烧室部件，是低温腐蚀的主要根源。

尤其是燃用高硫劣质船用燃料油，要求气缸油具有足够碱性以中和燃烧生成的酸性物质。

但由表1可知，该轮在大连加注的燃料油硫含量不到 2%，在宁波加注的燃料油硫含量也只有 2.8%， 选用碱值40mgKOH/g的中速机油作为气缸油基本满足要求。

气缸油黏度等级SAE40，用于润滑高温气缸、活塞及活塞环，似乎偏低。

据该船记录，2008年6月前使用黏度等级 SAE40 的中速机油作为气缸用油，也曾多次发现活塞异常磨损。

### （4）系统油方面

2008年6月更换润滑油供应商，该轮主机所用润滑油质量等级和黏度等级不变，系统油选用黏度等级SAE30、碱值30mgKOH/g 的中速机油，气缸油选用黏度等级 SAE40、碱值40 mgKOH/g 的中速机油。

系统油黏度等级SAE30，滑油压力低于正常值，降低进机温度可提高油压，可能是系统油黏度偏低。

结论：

该轮主机滑油压力低于正常值、拉缸，原因是系统油和气缸油黏度偏低。

## 3、纠正措施及效果

### （1） 系统油从3030中速机油改用4030中速机油

4030中速机油黏度等级SAE40，明显高于3030中速机油的SAE30，有利于改善油压偏低状况。

2008年9月起，采用日常补加的方式，逐渐添加4030中速机油，2008 年11 月厂修时已全部更换。

### （2）气缸油从4040中速机油改用5040气缸油

2008年10月改用5040气缸油。

5040气缸油黏度等级SAE50，明显高于 4040中速机油的黏度等级 SAE40，有利于气缸壁与活塞及环的润滑，碱性储备也略高。

### （3）定期采样检测在用油的黏度、闪点、水分、碱值、不溶物、某些金属和非金属含量等（详见表2），监控系统油质量，从而间接分析主机工作状况（该轮主机构造特殊，无法收集因而无法监控气缸油质量）。

这些纠正措施效果良好：

滑油系统油压正常，主机各轴承摩擦副磨损正常，运转平稳噪音较小，主机操纵更灵活。

三个月后，吊缸检查 No.6缸， 期间主机运转1144 小时，见表面划痕尚在但光滑无毛刺，表明磨损异常没有进一步加剧。

四个月后，从排气口和排气阀等部位检查 No.1缸和No.6缸，见缸壁划痕明显变浅，表明不再拉缸。

至今一年来，整机工况良好。

上例充分说明，必须正确选择润滑油。

# 二、柴油机滑油的正确选用

不同的柴油机，结构、转速、负荷、所用燃油质量（例如十字头式和筒形活塞、转速的高低、负荷高低、增压度）等不同，以及燃油含硫量不同，相应地需要不同品质的润滑油。

若能熟悉润滑油牌号（型号）及其对应的重要品质，选用时只需查阅牌号即可选定所需的润滑油。

船用柴油机油，国外发展较早,壳牌、道达尔、美孚、嘉实多、雪佛龙等几大油公司的产品已系列化，国内具代表性的有中石化长城、中石油昆仑等品牌，见附录。

船舶柴油机润滑油最重要的参数，是黏度和碱值。

船用柴油机油黏度等级主要有SAE30、SAE40、SAE50等几档，以满足不同工作条件使用。

船用柴油机油碱值（即TBN，单位mgKOH/g），通常按柴油转速分类：低速机，系统油总碱值一般低于10mgKOH/g，气缸油总碱值在10~70 mgKOH/g 范围分几档，分别适用于含硫量不同的燃油；中速机油总碱值在10~50mgKOH/g范围分几档，分别适用于不同负荷（强度）及不同含硫燃料柴油机。

为确保设备用油安全，需严格按照说明书的要求选择相应的润滑油。

为方便用户选择，柴油机生产商在设备说明书中通常都会列出润滑油的黏度、质量等级，或直接指定润滑油供应商及润滑油产品名称。

若无说明书可循， 或当地无法加到说明书要求的润滑油产品，可按以下原则选则润滑油。

## 1、低速柴油机

低速柴油机，绝大多数是十字头式、二冲程，低速，分别选择气缸油（润滑气缸）和系统油（润滑轴系等）。

### （1） 系统油

低速十字头式柴油机，虽然燃用燃油多是硫含量高的，但一则燃油燃烧产生的酸性物质被气缸与曲轴箱之间的隔板隔离，系统油不宜被污染（仅在活塞杆填料函失效的故障状态， 燃油燃烧的酸性生成物才可能进入系统油），二则另有专供气缸油，故系统油碱值不必高，其黏度等级通常选用SAE30或 SAE40。

### （2） 气缸油

黏度 ——气缸油黏度等级的选择与柴油机负荷（例如爆压、增压度等）有关。

柴油机负荷越高，缸内温度越高，活塞环与缸套间压力也越高，气缸油需要较高黏度以防其在缸套/活塞间流失。

大型高负荷二冲程柴油机，往往选择黏度等级SAE50的船用气缸油，例如长城5070气缸油。

碱度 ——气缸油的碱度，应与燃油硫含量匹配。

碱度太低，不能有效中和燃烧产物，会造成严重的腐蚀磨损；

碱度过高，又会因高灰分擦伤缸壁/活塞甚至拉缸。

所以，选择气缸油碱度需考虑：

所用燃油的含硫量。

十字头式柴油机，几乎都使用劣质燃油，硫含量高，气缸油的碱度应相应较高。

柴油机负荷（含增压度）。

因为负荷越高，消耗燃油越多，燃烧产生酸性物质越多，气缸油的酸中和能力即碱值就应越高。

对于低增压二冲程柴油机（Pe为7.85 MPa），燃油含硫量不超过3％，可选用 TBN40的气缸油；

而中、高增压柴油机，燃油硫含量大于2％时，就得选用TBN50～70的气缸油。

判断气缸油的碱值是否足够，有一种直观方法——若气缸内壁面注油点间有漆状物， 表明气缸油碱值偏低。

## 2、中速柴油机——中速机油

中速柴油机，筒形活塞，没有像二冲程发动机一样的横隔板将气缸和曲轴箱系统分开， 燃料燃烧产物容易落到曲轴箱中污染润滑油，因此对油品的质量要求较低速十字头式柴油机更高，应选择船用中速机油润滑气缸和轴系等。

选择船用中速机油时要合理结合柴油机的工况：

工况条件和缓（例如爆压、增压度等不高），中速机油碱值和黏度均可较低，反之则碱值和黏度应较高。

润滑油消耗量（即补加量）小，应选择碱值较高的中速机油。

老旧柴油机，轴承与轴等主要摩擦副配合相对变差，润滑条件恶劣，宜相应提高中速机油的黏度等级。

环境温度高或低， 则选择的滑油黏度应相应高或低；环境温度变化幅度大，应选择黏度随温度变化不大的中速机油。

燃油含硫量高，需选用碱值足够高的中速机油。

## 3、高速柴油机

高速柴油机，结构与车用柴油机相似，可按产品说明书选择相应车用柴油机油。

# 三、结束语

船舶柴油机的润滑油，具有润滑、减磨、清洁和冷却等功能。

根据船舶发动机的实际情况，正确选择船用润滑油，合理监控在用油，才能保证柴油机安全运转、延长其零部件寿命和节约润滑油。

在船用柴油机高强化和燃油劣质化的今天，这显得更重要。
