# 导读

轻微拉缸可自行修复，避免较大的损失；若拉缸逐步严重，可造成活塞环与气缸内壁的粘连，轻者损坏活塞头、活塞坏、缸套，重者活塞卡死在缸套里，使柴油机熄火，拉断活塞和连杆，造成重大事故。

因此可通过早期预报，判断柴油机拉缸故障，找出原因，采取恰当措施解决。

# 一、拉缸的迹象表现

拉缸现象是发动机拉缸过程中外部迹象表现。

船用柴油机拉缸通常表现为：

发动机声音沉闷、异常，有时有震动现象；

缸套和活塞环被拉伤，会出现串气、压缩压力和爆发压力降低，燃油油耗偏高；

排温升高，高温水出水温度升高；

缸套外表面油漆面变黄，防锈油变黑；

四冲程机器还伴随着滑油大幅度损耗，有时会出现曲轴箱冒烟。

# 二、拉缸产生的机理

## 1、发动机的摩擦学

摩擦学源于古希腊词汇“tribos”，意思为摩擦。

摩擦学包括摩擦、磨损、润滑和表面工程科学在内的全部科学。

柴油机正常运行中，活塞环与缸套之间是一种滑动摩擦，形成一对摩擦副，滑动摩擦定律 F = μW，摩擦因数 μ。

只有在给定的材料配副和确定的工况条件（温度、湿度、压力和速度），μ 才是一个确定的值。

一般在动压润滑时，厚液膜时 μ 值为 0.001，如超低摩擦层，纯净的冰面；

在混合润滑、边界润滑、金属轻度接触时，μ 值为 0.05～0.1，如飞溅式镀层、低摩擦镀层；

在非润滑高粘合时，μ 值≥0.5，如石墨润滑金属，钢等。

洁净的金属与合金表面表现高粘着特性，洁净表面磨擦阻力大，磨损严重，一般要提高缸套的粗糙度；

合金的磨擦因数要比其纯金属摩擦因数低，如金属中添加钼、锑、镁、钨元素增强金属强度、硬度，从而增加金属的耐磨性。

一般在活塞环增加镀铬层，增加环的缸套耐磨性。

高滑动速度和接触压力将导致接触表面温度急剧上升，变形改变摩擦初始条件，使摩擦过程难于分析和偏离实际情况，因此改变润滑条件，减小摩擦系数。

## 2、拉缸机理

船用柴油机是热能转化为动能的机械，需承受较高的热负荷和机械负荷，活塞、缸套及缸盖等是构成燃烧室的主要零部件，其所处的工作环境是高温、高压及混合油气直接作用于燃烧室组件。

一旦维护不好，拉缸故障时有发生，活塞环与缸套的润滑状态处在混合润滑模型状态。

正常运行的气缸内壁与活塞环工作表面具有一定的硬度和表面粗糙度，在一定温度条件下相互配合工作，气缸滑油起着润滑清洗、高温水起着冷却作用。

若由于某种原因，油膜变薄或遭到破坏，因润滑不良出现干摩擦或半干摩擦，缸套与活塞环的摩擦系数突然增大，造成局部高温粘附磨损的过程。

而活塞与缸套之间的润滑油膜恶化中断，是产生拉缸的必要前提。

由于活塞与缸套之间的润滑油膜一旦中断，则两者表面的金属由原来的液体摩擦变成固体间的干摩擦或半干摩擦，摩擦系数增大，由于摩擦副表面的高速运动产生的摩擦热，热量积累的高温会超过金属的熔点，引起活塞或活塞环与缸套表面发生显微熔化、撕脱，并最终焊接在一起。

活塞运动时，两表面熔焊点又被该力扯断拉开随之冷却，这样就出现了一个表面的材料转移粘附在另一滑动面上，形成坚硬层或脱落为磨料。

如果油膜能及时得到补救恢复，可起到清洗和冷却作用，则温度下降，微小熔着部分脱落而不会扩展；

如果油膜恢复迟缓，熔着扩展将导致大范围异常磨损，缸壁，活塞环急速受到严重损伤，在缸壁表面上呈现熔融流动状态，显出不均匀、不规则边缘的沟痕和褶皱，持续发展而产生拉缸。

气缸滑油和起动空气管路的硬质颗粒也会造成拉缸。

# 三、拉缸故障产生的原因

## 1、拉缸故障产生的原因的概述

船用柴油机拉缸的原因很复杂，各种因素相互影响，相互制约，有时很难分析拉缸产生的原因，需要专业的知识和丰富的经验去综合分析判断、调查、排除，才能查找处根本原因。

拉缸原因有可能是缸套本身自己的原因，也有可能是外界的原因。

要根据拉缸实际状况，拉缸的严重程度去查找原因。

## 2、拉缸故障产生原因

### （1）缸套本身质量问题

缸套本身质量问题造成拉缸是常见的原因之一，常见的原因有缸套本身的材质不过关，铸造后的金相组织到不到要求，铁素体含量超标，较高，石墨聚集现象；

缸套加工的本身粗糙度过高，珩磨纹倾斜不对，缸套硬度太低，达不到图纸要求；

缸套注油口油槽有毛刺和高点，缸套扫气口有凸点或锐边，缸套内径尺寸到不到图纸要求，过大或过小。

### （2）活塞环的质量

缸套与活塞环是一对摩擦副，存在相互制约相互影响的因素，缸套拉伤同时伴随着环拉伤，活塞环的损坏又影响着缸套。

活塞环质量不好会促使拉缸，活塞环硬度不符合要求，活塞环镀铬层极易脱落，尤其是搭扣附近，受力过于集中，脱落的活塞环可导致划伤缸套，剥落区域的环与缸套不能正常通过油膜密封，活塞环在缸套内会产生周向运行，逐渐扩大缸套的恶化区域，缸套与环的相互作用最终造成拉缸。

另外活塞环的变形，在活塞环内出现卡滞，活塞环尺寸不对，环槽间隙过小，受到热膨胀无间隙，也会出现拉缸，活塞环无弹力，也可造成拉缸。

### （3）较差的清洁度

清洁度不好也可造成拉缸，当缸套内壁，气缸滑油孔，油槽粘有硬质颗粒，铁屑在安装前未清理干净，未清洁彻底，柴油机盘车后会造成缸套的硬质划伤，且较深。

气缸滑油管路清有较大的金属颗粒会随着气缸油进入到缸套也对缸套产生拉伤，同样起动管路的一旦有硬质杂物也可会吹到气缸内壁上，造成缸套的损伤。

### （4）气缸滑油的原因

缸套与活塞环一对摩擦副的摩擦系数是通过气缸滑油的油膜来降低的，一旦缺少气缸滑油，不能正常的产生油膜，会造粘着摩擦，最终造成拉缸。

四冲程柴油机气缸滑油和主滑油是同一路油，没有单独的气缸滑油，主要靠飞溅润滑，产生油膜，二冲程柴油机带有十字头，工作环境比较较恶劣，有单独的一路气缸滑油供应。

气缸滑油的的指标要符合要求，劣质的气缸滑油也可造成拉缸，例如气缸滑油的碱值不到标，气缸油硫酸盐灰分太高或太低，润滑油制造商通常在其润滑油产品明细上说明硫酸盐灰分含量，来说明这些灰分来源于各种提高润滑有性能的添加剂，但是润滑油硫酸盐灰分不宜过高，灰分过高会导致燃烧室，活塞头，顶环沉积过多，一些不溶灰分也会造成磨损。

气缸滑油定时不对也可造成缸套拉伤。

气缸滑油在活塞环运行到设定的位置时喷射，过早或过晚都到不到预期的效果，以 WinGD 机器为例，不同的机型气缸滑油定时也不一样，如表 1 所示最佳喷射角度和比例。

以 RT-flex60C-B 机型为例，气缸油分别在当曲轴转角 307°，308.5°与 311°时分别注入至活塞环组上中下，每次脉冲喷射量为定量 900mm³气缸油，其总分配比例为40%，40%与 20%，活塞上行时喷射，一旦气缸滑油定时出现问题，喷射的角度不对，在上行仍没喷到，活塞环和缸套不能形成预期的油膜，造成摩擦阻力增大，温度升高，产生熔着摩擦，拉伤缸套和活塞环。

### （5）装配原因

部件安装原因也会造成拉缸，例如活塞不对中，造成活塞偏磨，甚至活塞裙磨到缸套，造成部分区域拉伤，损伤的缸套又作用于活塞环，恶性循坏会造成拉缸。

喷油器安装错误也可导致拉缸，正常情况下喷油器的喷口朝向活塞头上部中心区域附近，一旦喷油器定位销位置错误反装了180°，这样喷油器的喷口喷向缸套内壁，过热的温度集中在活塞环附近，很难形成油膜，缸套很快会拉伤掉。

### （6）维护保养原因

没有正确的维护保养，可造成拉缸。柴油机参数异常没及时发现，高温水温度过高，冷却效果差，低温水温度过高，造成扫气温度高，排温偏高长期运行可造成拉缸，长时间超负荷运行，也可造成拉缸，长时间用劣质的燃油也可造成拉缸，应该定期检查做好早发现早预防，避免重大损失。
