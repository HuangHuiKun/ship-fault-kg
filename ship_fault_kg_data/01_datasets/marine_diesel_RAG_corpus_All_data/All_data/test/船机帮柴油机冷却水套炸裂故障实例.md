# 导读

2016年3月17日，某远洋船舶从印度尼西亚装煤至印度，由于造水机修理，航次结束时在印度补充淡水350 t。

次日,该船从印度空放至阿根廷装大豆回国。

5月5日，船舶满载航行于(39°26'W ,37°46'S)附近。

当地时间0920时，主机5#缸缸套水套炸裂，随后主机减速。

因海上风大浪急，不适合停车维修，故采取单缸封缸的应急方法。

但封缸减速运行后，船舶实际航速仅约1kn,出事海域距最近港口德班港有近千海里，大风大浪天气要至少1周后才稍有好转，轮机部成员经讨论后决定停车抢修。

将情况上报公司后，获得批准现场修复。

船上有备用水套1个、备用缸头1个。

修复方案是更换水套，分4步进行:

组装备用缸套水套，拆下旧缸套水套，安装备用水套，事故原因分析。

## 一、故障排除

### 1、组装备用缸套水套

组装备用缸头时必须把水套平放于地板上,用行车吊起缸头，安转好密封圈后垂直放下,使缸头下部安装于水套内。

由于水套与缸头下部的安装间隙很小，有一定的安装行程,二者轴线稍有偏差很容易卡住或者损坏密封圈，所以重点考虑如何减少船舶摇摆对安装的影响。

虽然可以不停机，仍保持主机封缸运行状态,通过调节船舶航向稍微减小船舶的摇摆幅度，但用行车吊起缸头后，吊索的长度又加大摇摆幅度。

具体操作:

用前后左右4根钢索尽量把缸头固定在水套上方，使缸头在水套上方最低位置处摆动，然后根据缸头摆动规律，判断最佳时机放下缸头。

经数次尝试后终于组装好缸头，但事后发现这种办法运气成分居多,此次缸头组装就损坏了密封圈。

### 2、缸头吊运

旧缸头的吊出与新缸头的吊人同样困难。

此时船舶已无动力,摇摆幅度更大。

由于缸头质量大,任何方向大幅摇摆都极有可能在惯性作用下拉断钢索。

为保证安全,用前后左右4个各1.5t葫芦吊拉扯，安排4名有经验的船员每人各操作1个葫芦吊，轮机长负责操作行车与协调指挥。

在轮机长的统一指挥下,缓慢地吊运缸头。

在前后吊运缸头到放置平台的过程中，由于距离较远，必须根据缸头实际位置，前后方向更换左右2根钢索与船体的固定点,更增加操作的危险程度。

约1800时缸头安装完成，主机启动运行。

检查发现排烟管下水套有1处约10范围漏水，分析应该是水套组装时密封环损坏。

1930 时定速。

查阅检修记录，发现3﹟缸也发生过水套炸裂事故。

为防患于未然，在主机正常航行时组装1套缸头备用。

由于没有备用水套，决定焊补旧水套。

分析认为:

水套通过4个螺杆连接自由悬挂在缸头下方,受热时可自由伸缩，且水套内部是85℃冷却水，外部是45℃左右机舱环境,一般的焊接强度足以满足使用条件(至少在应急情况下使用是没有问题的)。

由于条件有限，只能采取焊前加热工件、焊后保温的常规手段处理焊接的旧水套。

5月17日，主机2﹟缸水套炸裂;

5月26日,主机4﹟缸水套炸裂。

由于已做好准备工作，机舱人员已有足够多的经验，配合起来更果断熟练，从而高效快速地进行抢修。

从事故发生到主机定速航行用时少于5h,未影响船期。

## 二、原因分析

在20多天时间内连续发生多起水套炸裂事故，绝非偶然。

与上述分析一致,水套通过4个螺杆连接自由悬挂在缸头下方,受热可自由伸缩，内外温差不大，可不考虑安装应力和热负荷。

多次抢修时发现，炸裂的水套内部触水面有水垢和铁锈，缸头的触水面上水垢和铁锈更多,特别在密封圈附近，有些地方生成的块状铁锈厚度超过3mm。

印度大多数港口的淡水喝起来有很重的碱味，说明水的硬度和含盐量超标,由于船上冷却水处理剂在从印度开出后不久就消耗完毕，在以后近1个月的时间内都是使用未经处理的不达标冷却水，导致主机淡水冷却系统结垢严重。

加上平时主机吊缸时未按照检修计划的要求，没有拆捡清洁水套及更换密封圈，导致铁锈水垢堆积。

再考虑到缸头内部结构复杂，附件多,有油头安装孔、启动阀安装孔、示功阀安装孔道等。

为增加缸头强度，冷却水道必须避开这些孔洞，使得缸头上的冷却水道不可能均匀分布,在示功阀安装对应处，肉眼可见水道间距变大(见图1和2)。

由于长时间使用未经处理的高含盐量淡水 ，导致整个冷却水系统积垢严重，部件锈蚀加剧。

水垢增多影响散热，使水套温度升高，冷却水道稀疏的地方温度更高，导致长期以来生成的铁锈受热膨胀 ，继而胀裂外部水套。

这也是短期内接连发生多起缸套炸裂事故且裂纹部位基本致的原因。

将分析结果上报公司，公司机务部广门基本同意此分析。

事实证明分析是正确的，同一批船员在印度吊主机6#缸，清洁检查水套，并未发生事故。

## 三、应对措施及总结

待印度加装的淡水消耗完后，在航行中从柴油机下部放水，少量多次更换冷却水并冲洗系统。

6月10日,在新加坡补充冷却水处理剂并使用;6月18日，利用在港卸货的时间清洁膨胀水箱，冲洗系统。

此后一段时间内再未出现过水套炸裂事故。

主机是船舶动力来源，是保证船舶安全营运的主要设备,对主机一定要严格按照厂家提供的维修手册制定维修保养计划，并严格执行。

本船之所以会多次发生主机缸套炸裂事故,其根本原因是安全管理体系执行不到位。

若在吊缸时清洁检查水套、及时申请水质处理剂并正确使用以及及时发现船舶检修未按要求进行，事故就可能避免。

在船舶管理中一定要加强管理，强化轮机员的责任心,时刻存在危机感，减少人为失误造成的损失。
