# 导读

曲轴的成本大约占整机成本的10%～20%，造价比较高，是船舶柴油机中最贵的零件。

曲轴最常见的损坏是疲劳断裂，保证曲轴有足够的弯曲疲劳强度是曲轴设计的首要问题，做好弯曲疲劳强度可以提高曲轴的使用寿命。

曲轴是发动机上的一个重要的机件，其材料是由碳素结构钢或球墨铸铁制成的，有两个重要部位：主轴颈，连杆颈。

主轴颈被安装在缸体上，连杆颈与连杆大头孔连接，连杆小头孔与汽缸活塞连接，是一个典型的曲柄滑块机构。

曲轴的润滑主要是指与摇臂间轴瓦的润滑和两头固定点的润滑。

曲轴的旋转是发动机的动力源，也是整个机械系统的源动力。

本文通过分析柴油机曲轴的断裂失效的基本情况，为曲轴断裂分析原因提供一定的依据和建议。

# 一 曲轴的结构形式和工作条件

## 1.曲轴的结构形式

曲轴功用：

曲轴是发动机中最重要的部件之一，其作用是把活塞连杆组传来的气体作用力转变为转矩并对外输出。

另外，还用来驱动配气机构及其他各种辅助装置。

整体式曲轴具有工作可靠、重量轻、刚度、强度较高、加工表面较少的特点，中小型发动机中广泛采用，一般配合滑动轴承。

组合式曲轴，当曲轴尺寸较大，曲拐数较多时，采用整体式结构将导致加工非常困难，可采用组合式结构。

## 2.工作条件

由于曲轴工作条件恶劣，因此对曲轴材质以及毛坯加工技术、精度、表面粗糙度、热处理和表面强化、动平衡等要求都十分严格。

如果其中任何一个环节质量没有得到保证，则可严重影响曲轴的使用寿命和整机的可靠性。

工作条件：

要承受周期性变化的气体压力、往复惯性力、惯性力矩、离心力、缺油、高速、轴向窜动。

第一，受周期变化力和力矩作用，重点弯曲交变荷载（80%是弯曲疲劳破坏）；

第二，曲轴形状复杂，应力集中严重；

第三，曲轴轴颈比压大，摩擦磨损严重。

在材料的选择上，用高强度、高冲击韧性、耐磨性材料，主要采用中碳钢、中碳合金钢、稀土球墨铸铁模锻而成。

为提高耐磨性和耐疲劳强度，轴颈表面经高频淬火或氮化处理，并经精磨加工，以达到较高的表面硬度和表面粗糙度的要求。

# 二 曲轴的疲劳断裂

柴油机在运转过程中经常发生曲轴断裂、裂纹、变形等现象，其中发生疲劳断裂现象最多。

曲轴的疲劳断裂是曲轴失效的情况之一，同时也是最严重的情况，是发动机严重的机件故障，断裂一般发生在曲柄销和主轴颈与曲柄臂的连接圆角处或轴颈油孔等应力集中部位。

曲轴的受力情况比较复杂,它承受着气体爆发力、运动件的惯性力,各种振动以及与机体轴承等约束情况有关的反作用力,与被带动装置的反作用力等。

曲轴工作时,轴颈主要受扭转,曲柄臂主要受弯曲，这些载荷是周期性变化的，近似地可看作脉动循环载荷。

当曲柄处于上止点附近承受最大爆发压力时,曲柄臂承受最大弯矩，使曲柄臂与轴颈过渡圆角处产生很大的应力。

当此应力超过曲轴的疲劳极限时，即会导致弯曲疲劳裂纹的出现。

曲轴疲劳断裂的特点有：

第一，疲劳断裂是脆性断裂，是在长期的使用过程中不断磨损造成的，是没有变形的，首先会产生裂纹，然后接下来磨损会加重裂纹，最终演变成曲轴断裂。

第二，疲劳断裂是寿命的断裂，断裂应力水平低于材料抗拉强度。

柴油发电机的曲轴在折断之前发生的裂纹，如果及时的发现轴颈表层的纵向裂纹，在经过磨削之后是可以消除裂纹的，然后曲轴就可以继续使用；

如果是横向裂纹，裂纹会迅速扩大，这时要及时的更新曲轴，以免曲轴突然断裂而造成一些人身安全事故。

# 三 柴油机的曲轴断裂失效原因分析

柴油机曲轴断裂的原因很多，可以从四个方面来分析：

## 1.材料的不合格和热处理不当

曲轴钢材料的致密度差会导致热处理淬火开裂，所以在钢材料的选择上要选择热工艺性较高的钢材料。

曲轴断裂是脆性断裂，这就要求曲轴的原材料脆性比较差，这样能够有效的避免曲轴的早期失效破坏。

曲轴的热处理关键技术是表面强化处理。

球墨铸铁曲轴一般均采用正火处理，为表面处理做好组织准备，表面强化处理一般采用感应淬火或氮化工艺。

在热处理过程中，如果淬火冷却不足，就会形成大量的铁素体和上贝体组织，这样会使曲轴的强度、硬度、冲击韧度降低，造成曲轴的早期失效破坏。

## 2.曲轴铸锻毛坯质量缺陷

曲轴铸锻毛坯的质量影响的是曲轴的强度，毛坯的铸锻中应该有四个方面的保证：

第一，保证铸件的壁厚要合适、均匀。

第二，保证铸造圆角要适当，不会出现尖尖的棱角。

第三，保证铸件的结构简化，要有合理的模斜度，减少分型面。

第四，保证强肋的厚度和分布合理，避免冷却时铸件变形或产生裂纹。

由于毛坯质量的好坏直接影响到曲轴的强度，当强度不够时就会极容易产生裂纹进而产生曲轴断裂，所以在铸锻毛坯时要严格按照规定，一步步铸造出符合质量要求的毛坯。

## 3.外加负荷的变化

船舶柴油机中，柴油机在船舶的使用过程中会受自然条件的影响而发生大幅度的振动，由于自由端处一般没有载荷的作用，在轴系振动加大的情况下就会造成整个轴系的扭振节点集中于此，于是表面应力就会加大，进而就会比较容易产生裂纹，最终导致曲轴的断裂失效。

## 4.润滑条件恶化带来的裂纹的产生

曲轴的断裂不是一瞬间的直接断裂，在断裂前会产生裂纹，如果不对裂纹进行恰当的处理，在接下来的循环磨损中就会演变成断裂。

裂纹的产生主要是由于润滑条件的恶化。

润滑剂受污染、润滑剂老化、润滑剂质量不好、轴承的润滑合理间隙不能保证都会影响润滑的质量，导致润滑条件恶化。

润滑不够会加剧轴颈和轴瓦的磨损，然后就会产生裂纹。

对于裂纹的处理上，如果是纵向裂纹，可以进行相应工艺的磨削消除裂纹，曲轴可以继续使用；

如果是横向裂纹的话就需要进行曲轴的更换了。

# 四 结束语

柴油机曲轴断裂原因是多方面的，既有本身材料或热处理的不规范，也有曲轴铸锻毛坯质量的缺陷、外加负荷的变化以及润滑条件的恶化造成的裂纹，这些原因都会产生曲轴断裂。

曲轴是柴油机中比较重要的一个零件，造价也比较的高昂，当曲轴断裂，曲轴的寿命就终止了，也意味着需要重新换曲轴，这也就增加了成本。

对曲轴在材料的选择、制作中工艺严格要求，以及在使用过程中进行恰当的维护管理，可以适当的提高曲轴的寿命，从而降低成本。

而且，由于曲轴断裂会带来严重的安全事故，进行曲轴断裂分析，在使用的过程中加以注意，可以在一定程度上减少安全事故的产生或降低安全事故带来的影响。
