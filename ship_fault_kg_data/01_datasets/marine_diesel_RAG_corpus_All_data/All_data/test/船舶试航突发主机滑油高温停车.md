# 船舶试航突发主机滑油高温停车

某船在主机100%负荷耐航试验时，右主机先后出现冷却水高温和滑油高温停车报警，导致右主机停车。右主机在起初低负荷工况时，没有出现异常现象。验船师和船东、船厂负责人，获悉情况后开会初步分析可能是滤器堵塞。但抛锚后拆开海水总管滤器，发现滤器里面很干净，并无堵塞现象。倒是在拆开滤器时，发现里面有不少空气。再次进行耐航试验时，依旧是在接近100%负荷时出现同样现象。进一步拆检主机前滤器和主机机带冷却水泵、海水冷却管路，也未发现其它异常，后续耐航试验右主机100%负荷时冷却水高温和滑油高温停车现象依然存在。

## 原因分析

针对这种现象，笔者提出了2点疑问。一是为什么每次主机出现停车，都是先出现冷却水高温，再出现滑油高温停车报警点；二是为什么每次出现问题都是右主机，而且都是高负荷工况才出现，右主机是否有故障。

针对第一个问题笔者分析认为应该是主机冷却水供应出现问题，导致主机滑油没有冷却介质冷却，因而产生滑油高温停车，主机冷却水高温是因，滑油高温停车是果。至于第二个问题的原因，笔者提出采用排除法进行试验，既然右主机反复出现滑油高温停车问题，而左主机未出现，是否可以试试左主机单独做耐航试验，观察情况再做进一步分析。在得到船厂和船东的一致认可后，左主机单独进行耐航试验时，也发现在100%负荷时出现了相同现象。通过初步分析和排查，基本排除了左右主机本身故障的可能性。

进一步思考，笔者认为引起问题的原因多半是在管路设计上。考虑到之前拆检时，滤器和管路都没有堵塞，倒是滤器里面存在大量空气，那么这些空气是怎么产生的，跟主机冷却水高温报警的产生存在什么关联？而且为什么每次都是先右主机在100%负荷附近出现问题？带着疑问，笔者重新将海水冷却管路检查了一遍，发现了因为船舶空间有限，该船的海水总管进口设置在海水箱顶部（见图1），跟以往船舶的常规布置有所不同。一般船舶大都是设置在海水箱的侧面。另外，右主机海水冷却管路同样因空间问题，比左主机管路，多存在一处弯管（见图2）。

综合主机试航时出现的问题和船上海水冷却水管路的布置情况，笔者和船厂质量部门主管提出了一种假设：主机100%负荷时，出现的冷却水高温和滑油高温停车报警，很可能是因为海水进口的布置在海水箱顶部导致。原因分析如下：虽然海水箱顶部已有空气管透气，船舶航行仍有部分空气通过海水箱顶部的海水进口进入管路，尤其是在主机100%负荷航行时，船舶航速明显提高，尤其该船吨位小，吃水浅，破水时容易产生更多的气泡被大量吸入海水箱，加上该船海水箱吸口管路伸入海水箱部分较短，气水混合的海水容易通过顶部海水进口进入主机海水冷却管系。当主机海水冷却管系内的空气积累到一定程度，主机的海水冷却泵已无法抽吸到合适水量的海水冷却主机缸套，因而出现主机冷却水高温和滑油高温停车报警。这也是之前拆开海水阀箱后方的滤器时，发现滤器内存在大量空气的原因。至于为什么每次都是右主机先出现滑油高温停车报警，笔者认为是因为右主机冷却水管进机前存在一处弯管，管阻增加，当冷却水管路中的空气增加导致供水困难时，两台主机会出现抢水现象，右主机因为管阻大，水量最先供应不足。

本着大胆假设，小心求证，笔者考虑既然主机的滑油高温停车报警是由于冷却水供应不足引起，而冷却水管路系统上有一路应急冷却水（由消防总用泵提供，如图3所示），可以考虑进行验证试验，再次进行耐性试验，待主机出现冷却水高温报警时，再打开应急冷却水供给，验证主机冷却水高温报警是否可以消除，滑油高温停车是否不会出现。最终上述的分析和假设在后续的耐航试验中，得到充分验证。

经过初步试验，关于主机滑油高温停车报警是由于冷却水供应不足的推论得到验证，不过是否由于海水进口布置问题产生主机滑油高温停车报警，还未有实际证据验证。考虑该船已经下水，再重新上排修改会延误交船日期和增加额外费用，另外船舶空间太过紧凑，已无法在海水箱的侧面开口引出海水总管，再者主机滑油高温停车报警的最终原因也有待验证，后续如何解决需要自信考虑。

## 解决措施

笔者和船厂质量部门主管根据前述的原因分析和初步试验结论，综合该船海水管路的实际布置情况，建议在管路的高点增加透气管引至主甲板以上，并增加截止阀，以实现主机运行时海水管路内的空气溢出到甲板上，不再堵塞海水管路。该布置原理上类似于海水箱的透气管。出于谨慎考虑（对于未经验证的方案，尽量先不做较大改动）和便于验证之前的理论分析，笔者和船厂建造部门主管商议决定先用塑料管替代钢管进行验证试验，观察该方案的效果，根据试验结果再最终落实修改方案。试验方案布置如图4所示。在后续的耐航试验使用该方案时，初期当主机功率较低，在船舶航速不高，可以观察到透明水管内的液面基本平稳，气泡不明显，但当主机负荷慢慢升高，航速明显增加时，透明水管内的液面波动很大，同时有大量气泡冒出，与此同时主机100%负荷的试验过程再也没出现主机滑油高温停车报警的情况。通过该方案的试验，明确证实了之前的理论分析是可信的，且该方案可以有效解决主机滑油高温停车报警问题。后续船厂根据该方案将塑料透气管修改成钢质管路，并进行了耐航试验，再没有出现主机滑油高温停车报警，顺利完成了主机耐航试验，圆满完成交船任务。

## 结论

沿海小船、内河船（如高速船、拖轮、游艇等），由于船舶吨位小、吃水浅或者机舱结构紧凑，很多时候可能会将主机和辅机的冷却水进口布置在顶部，针对这种情况，设计人员在船舶设计初期，应该考虑到类似问题，尽量避免将冷却水进口布置在海水箱顶部，如不可避免，则应在管路的高点设置装有截止阀的透气管引至露天甲板，防止冷却水管路积聚大量空气导致主辅机无法获得冷却水，进而产生滑油高温停车现象。
