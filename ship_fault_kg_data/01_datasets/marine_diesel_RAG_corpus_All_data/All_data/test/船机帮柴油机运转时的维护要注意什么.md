# 船机帮柴油机运转时的维护要注意什么

## 船用柴油机运转时的维护

1. 柴油机起动后，应进行暖机运转，淡水和机油的出机温度达到35~40℃以后才允许逐步增加负荷运转，达到全负荷的时间应为15~20分钟。在紧急情况下也不应少于5分钟。

2. 新柴油机、更换了主要零部件或修理后的柴油机，必须分别在25%、50%负荷下运转2~3小时后方可加负荷到标定的功率。第一次起动后运转0.5~1小时后应停车打开曲轴箱门盖，检查各运动部件及主轴承螺栓的情况。

3. 在柴油机运转期间，必须随时注意仪表读数和机器工作情况，并按时作好记录。

4. 柴油机正常工作时，转速不宜超过规定的转速值。作船用主机时，在船体附有海生物和船体转向时，柴油机有可能过载，这时应根据排气温度将转速适当降低。排气温度在标定功率和最大功率时均不许超过1.4的规定。

5. 柴油机在按持续转速运转时，机油压力应为0.35~0.45MPa（3.5-4.5 kgf/cm2）。低于规定值时应立即检查，决不允许继续运转。柴油机在低转速运转时，机油压力应不低于0.20MPa(2kgf/cm2)。机油滤器前后的压力差应不大于0.098MPa(1.0kgf/cm2)，否则应清洗滤芯。为了尽快提高机油温度，起动后可利用冷却水系统中的旁通阀门暂时旁通机油冷却器中的冷却水。但任何情况下均不允许机油温度接近或超过报警值。

6. 冷却水应保持一定的压力，以保持冷却水的畅流。如果由于某种原因失水使柴油机严重过热，则应立即停车处理。此时不允许急剧放入冷却水，以免受热零件骤冷而损坏。

7. 检查燃油日用油柜、调速器和增压器的油位。检查机座油池中的油位，及时添加机油。油位下降，主要是由机油系统中泄漏所至；油位上升，则可能是冷却水或燃油渗入。此时应停车检查或化验机油，不合格的机油应立即更换。

8. 每1~2小时检查排气温度一次，不应高于400℃。

9. 经常观察排气烟色是否正常。观察呼吸器的油雾情况。

10. 定期打开各缸示功阀，检查各缸的燃烧情况。

11. 注意辨听柴油机的运转声音，遇有敲缸、轴承过松的敲击声以及其他不正常的振动和噪声，都应立即停车检查并消除。

12. 用手触摸各档曲轴箱门盖的温度，如有不正常的高热现象应立即停车检查并消除之。

13. 注意所有外露件的工作及紧固、锁紧情况。

14. 检查燃油系统情况，如高压油管有剧烈振击及发热现象，可能是喷油器堵塞或气缸过载，应立即检查并消除之。

15. 注意柴油机转速的均匀性，当突然有很大的转速波动出现时，应立即辨明原因，必要时停车检查。

16. 应记录好渗漏和密封不好的地方，以便尽快消除。

17. 空气瓶应经常保持足够的压力。

18. 应经常打开空气冷却器下方的放水旋塞，排除冷凝水并检查空气冷却器有无漏水现象。

19. 在柴油机使用期间，应定期检查滑油质量，特别是粘度和含水量。如滑油被燃油稀释，应予以更换，否则将严重影响机油粘度等性能，严重的易在曲轴箱内形成易爆混合气。更换滑油时，失效油必须排除干净，循环油路应仔细清洗，但禁止使用棉纱和破布。滑油应按下述规定加以更换，但滑油质量若无显著变化，其工作期限允许适当延长。初次工作100小时后为第一次更换机油，继续工作300小时后为第二次更换机油，以后则定期对润滑油进行取样分析（每500小时一次），如滑油特性分析值达不到以下标准，应及时更换或补充。

润滑油控制标准：（柴油机用轻柴油时）
- 粘度：不超过新油粘度＋25%或－15%
- 闪点：≥180℃
- 总碱值（mgKOH/g）：≥2.5
- 强酸值：不允许
- 水份：≤0.2%
- n-戊烷不溶解成分：≤2.5%
- 盐份：不允许
