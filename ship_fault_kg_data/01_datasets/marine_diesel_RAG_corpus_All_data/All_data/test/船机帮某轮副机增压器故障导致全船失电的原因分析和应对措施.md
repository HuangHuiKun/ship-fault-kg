# 导读

某轮是2004年8月由日本KOYODOCKYARD CO.，LTD建造的载重量为18万吨的散货船。

主机型号：MAN B&W 6S70MC-C 一台；

副机型号：YANMAR 6N18AL-EV 三台；

副机增压器型号：IHIRH143。

航行时只用一台副机，即单机航行。

## 一、故障现象

航行中NO.2副机排烟管突然冒出浓烟(当时仅NO.2副机在用)，随即跳闸,全船失电。

## 二、故障原因分析

检查NO.2副机，发现增压器转子卡死不能旋转。

解体该增压器,两个半浮动轴承磨损严重、涡轮端叶轮与涡壳摩擦、燃气叶轮边缘磨损超标、涡轮侧燃气密封环已由原来的一小矩形活塞环磨损成一圆环(拆卸时断成两节)。

由此可以判断该故障是由于该燃气密封环过度磨损不能有效密封,燃气进入透平轴承室使轴承室内的润滑油变质、结炭,致使两个铜质半浮动轴承磨损,透平转子下沉,转子上涡轮叶片接触到涡壳、发生摩擦,而致使增压器不能正常工作、副机脱闸发生跳电事件。

联想到中海香港航运“峰”字号船舶也经常发生副机增压器故障而造成全船失电等紧张局面,其副机增压器型号也是日本IHI生产的RH133，两者都属于IHI的RH..3系列,结构、原理基本上都是一样的,对此我通过仔细阅读其说明书、分析其结构原理发现了它结构上的一点特征,现写出来与大家共同探讨。

下面首先简述该增压器的基本工作原理。

RH133、143型增压器采用的是废气涡轮增压系统中的脉冲涡轮增压。它把副机(6缸)的1、2、3缸的排烟管组成一组,4、5、6缸的排烟管组成另一组,把副机燃气导入增压器的涡轮端;高温燃气带动固定有涡轮叶片的转子旋转并从涡室端部排出;透平转子由两个半浮动轴承(RH133是全浮动轴承)和一组推力轴承支撑、定位;转子的输出端再带压气机叶轮;空气经空气滤网罩、消音器由压气机叶轮带动压缩,并排入副机空冷器冷却,再进入扫气总管供各缸工作用。

如图1。

涡轮室的燃气与轴承室的分隔由一密封环来完成,如图2。

轴承室的润滑由副机系统油来润滑,没有单独的供油泵和滑油系统。涡轮端、压气端产生的轴向力由安装在轴承室近压气侧的推力轴承来平衡。

正常状态下,该增压器工作平稳、高效,但从其结构上我们可以看出其燃气与轴承室的分隔是一薄弱环节,仅由一小密封环来密封,该环安装在转子的环槽中,与涡轮室的一个小台阶和转子环槽内面形成密封面。

由于它工作环境的恶劣,又没有润滑,加上它本身机构上的简单、脆弱,使它变成一极易损坏的部件。

而它的工作不正常、不能有效密封就会导致更严重的隐患的产生:

使轴承室的滑油变质、炭化，使铜质浮动轴承产生过度磨损,而致转子下沉、涡轮叶片与涡壳和压气机叶轮与压气机室间隙变小,甚至直接接触,进而影响转子的正常旋转与压缩空气,严重的会导致整台增压器的报废。

## 三、应对措施

(1)缩短其检修周期,以减少故障发生率。

每次使用前都要检查一遍;每天做一次外观检查,看有无松动、漏油、漏气,有无异常噪音;副机在使用时要连续分离、洁净系统油,当油质变差时要及时更换,滑油滤器及时清洗;每隔400小时检查一次各紧固部件,看有无松动;每720小时检查一次转子转动情况,拆下空气滤器罩、消音器,用手转动转子看是否平稳、有无摩擦声音;每2160小时拆检增压器一次,解体、清洁、检查,更换磨损元件。

(2)及时订购易损部件,以便在检修中发现超耗部件时能及时更换。特别是燃气侧密封环1009和浮动轴承7001,基本上要有3套在船作备用。

(3)培训轮机部人员,多动手。

有部分轮机员会觉得增压器是很精密、复杂的设备而不敢动手去拆。

实际上这种副机增压器每用2~3月就必需拆检一次,清洁、检查、更换磨损元件。

因此我们轮机员都必须学会正确拆装该增压器。

第一次拆检时,最好对照说明书中的分解图一步一步来进行,每拆一步都要考虑到怎样装复。

在整个拆装过程中有几点要特别注意:

在拆涡室与轴承室的螺栓4004时,涡室和轴承室间要先准确做好记号,如没装正确则在安装到副机上时排烟管会装不上或发生扭曲;

拆螺栓3003时压气室和轴承室间也要做好记号,也是没有定位装置可旋转,如装不正则装上副机后不能密封其排气口;

螺栓4004是耐高温的,有时较紧拆不下来,而且位置有限,不好用力,这时就不能大力硬拆,以防打滑损坏螺栓而致解体不了,应用锤子和铁棒敲打该螺栓头部,震松一下再拆;

压气机叶轮2001是锁紧在转子轴上的,拆时不能直接拿下,这时应用火加热叶轮,使其受热膨胀,这样就可很轻松的直接用手拿下了,装复时只要清洁好后把反牙锁紧螺母1008上到标定扭矩(32.4N.m)就可以了;

装复时燃气侧密封环1009和压气侧密封环1010要注意使其开口朝上;

浮动轴承的定位环5002在安装时要注意使它光滑的那面与轴承接触,燃气侧轴承的卡环的开口(从透平侧看)要向左,压气侧轴承的卡环的开口要向右(从压气侧看);

装复后再检查转子是否转动灵活自如,并测量其轴向间隙(0.06~0.12mm)和径向间隙( 0.37~0.57mm)。
