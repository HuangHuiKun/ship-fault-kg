# 导读

发电柴油机是船舶重要的设备之一，驱动发电机为船舶提供充沛的电力，保障船舶安全航行，由二管轮负责维护、管理。

经常由于二管轮缺乏责任心，对柴油机维护管理不到位而引起种种机损事故，特别是拉缸、咬缸最为严重，利用厂家配套的专用工具几乎不能拆除缸套、活塞。

如果缸套之前长时间没有更换过，水腔积垢又很严重，只能另辟蹊径自制工具采用非常规的方法拆除损坏的活塞、缸套。

本文以大发ＤＫ－２６柴油机为例，研究探讨拆除损坏活塞、缸套的方法。

# 一、现象

某日，某轮的二管轮检修完柴油机的油头后准备试车，柴油机冲车后再启动却发现柴油机纹丝不动，进一步检查发现第三缸活塞、缸套咬死。

# 二、制定方案

按照说明书的步骤先后拆卸完排烟管与缸头之间的连接螺栓、缸头附件、连杆大端，拆卸缸头螺栓后吊起缸头。

针对活塞与缸套咬死在一起的现象，准备了三套方案：

方案一：利用起吊活塞的专用工具在吊起活塞的同时一起拉出缸套；

方案二：先用煤油浸泡咬死的活塞、缸套，再用锌棒锤击活塞使其与缸套分离，最后利用专用工具分别吊起活塞和缸套；

方案三：利用自制工具和油压千斤顶从下面顶出活塞、缸套组件。

# 三、执行方案

事实证明第一、第二两套方案根本行不通。

由于此台大发ＤＫ－２６型柴油机已经有５年时间没更换过缸套，也没有按照要求处理冷却水，水质较硬，气缸冷却水腔积垢严重，同时咬缸发生时，活塞对缸套的冲击力过大，缸套已经变形卡在机体里，试着利用葫芦、起吊活塞的工具拉缸套，无论用多大的力拉葫芦，活塞、缸套都纹丝不动。

由于活塞与缸套紧紧地咬合在一起，煤油虽然能渗进两者之间的空隙，但是却不能使其脱开，只能试用第三套方案。

## １、自制工具

### （1）测量

先测量缸套底部与曲拐箱底部之间的距离，４吨油压千斤顶无受力状况时的高度（根据船舶配备千斤顶的规格选取适合的油压千斤顶，最好挑选４吨或者２吨的千斤顶，１吨或者０.５吨无法顶起缸套），再算出制作工具的高度，实际制作时，工具的高度最好比计算的高度稍微低一厘米左右，便于安装调整。

### （2）选材和制作

①倒“工”字型工具

切割φ５０ｍｍ×２.５ｍｍ 的钢管作为承受向上作用力的中间支撑，切割规格为１００ｍｍ×１００ｍｍ×１０ｍｍ 的钢板一块作为工具的底座。

选取缸套专用工具中的底板作为工具的顶部支撑。

把三者焊接起来做成一个倒“工”字型的工具，如图１所示。

②“门”型工具

切割 φ２５ｍｍ×３.４ｍｍ 的钢管两根，１０﹟工字钢一 段，３０×３０×２三角铁一段，焊接成一个“门”型的工具，工具的顶部与缸套底部配合的部分要求打磨成圆弧状，如图２所示。

## ２、实施

盘车使第三缸的曲柄销置于水平右舷位置，从左舷曲拐箱道门处塞进倒“工”字型工具、和油压千斤顶，千斤顶放置于曲拐箱底部。

调整倒“工”字型工具使其与气缸套底部良好配合，再调整千斤顶的位置使其刚好位于工字型工具正下面，大发ＤＫ－２６柴油机曲拐箱底部并非是水平的，为了调整千斤顶使其垂直，可以在千斤顶下面塞锲型块，如图所示３。

向下缓慢压千斤顶的手柄，观察缸套是否有向上移动的迹象，如果千斤顶油封漏油或者手柄已经压不动了，缸套仍然没有移动的痕迹，停止拆卸，切记不要野蛮施工，也免造成机体损坏或者曲拐箱底部产生裂纹，造成额外的损失。

可以采用化学溶液松解水垢的方法，先使水垢松散，再拆卸缸套。

## ３、化学松解水腔水垢

如果采用上述方法不能拆卸气缸套，可能是水腔严重积垢造成的，柴油机冷却水腔的水垢成分复杂，大致分为三种类型：碳酸盐、硫酸盐、磷酸盐。

只有清楚水垢的化学成分后才能有针对性的选择化学试剂，远洋船舶条件有限不能化验水垢的化学成分，但是可以利用现有的条件做简单的实验。

打开缸套冷却水腔观察孔，取出三块水垢样品，分别放置于三个玻璃瓶中，然后分别向三只玻璃瓶中添加稀盐酸、碳酸钠溶液和苛性钠溶液，观察水垢的溶解程度，选取反应最快的化学试剂。

配置化学溶液，通常稀盐酸的浓度是２.５％~５.０％，添加０.５％ －１％的福尔马林（甲醛）、骨胶、干血清等作为抑制剂，保护零件不受腐蚀。

磷酸酸钠的浓度是０.３％－０.５％。

封堵柴油机第三缸冷却水进出通道，通过气缸套顶部的水流通道向水腔里灌注化学溶液，由于缸套顶部水腔通道孔径较小，灌注时要特别小心谨慎，保持透气孔畅通，勿飞溅。

待２４小时后水垢与化学试剂充分反映后，再利用自制的工具、千斤顶向上顶缸套，如果缸套还是不能松动，还可以采用热胀冷缩法。

## ４、热胀冷缩

排除气缸套冷却水腔里的化学溶液，用氧乙炔在气缸套内壁烘烤，火焰温度调到500℃左右，待烘烤到气缸内壁出现灰色为止，缸套受热膨胀挤压水腔里的水垢，使其变得松散，然后再用二氧化碳灭火器喷射烘烤过的气缸内壁，如果船舶二氧化碳灭火器船东不让用，可以到伙食冰库里收集冰块，冰块一定要及时地塞满整个气缸套，缸套遇冷收缩促使已经松散的积垢开始脱落，如此反复几次，最后再用自制工具和千斤顶向上顶压缸套，大多能压出气缸套。

事实表明，第三套方案采用化学反应水垢结合热胀冷缩再利用自制工具向上顶压缸套的方法是有效可行的。

# 四、注意事项

（１）当用化学试剂松解水垢时，一定要严格遵守公司质量管理体系的相关规则，操作者戴耐酸碱的橡胶手套，戴口罩、护目镜，开启机舱风机彻底通风，如果化学试剂不慎溅到皮肤、眼睛等处，一定要用大量的清水冲洗，严重者立即送医治疗。

（２）使用氧乙炔火焰烘烤缸套内壁时，火焰温度调到500℃左右即可，不可调到过高，以免烧融缸套，要提前清理现场的易燃物，如：破布、棉絮、油迹等，准备灭火器材，指派专人看火。

（３）使用二氧化碳灭火器冷却缸套之前，一定要预先通知三副，盘点库存量，不能因为缺货而影响PSC检查（港口国监督)。

使用时开启机舱通风机，必要时在施工现场布置两台移动式送风机换气，总之一定要保持操作现场通风良好。

（４）不能蛮干，当用千斤顶顶缸套时，要采用循序渐进的方式，首先采用０.５吨的千斤顶，再依次换用１吨、２吨、４吨的千斤顶，一般情况４吨千斤顶不能顶出缸套，就不能换用更大的千斤顶了，因为曲拐箱 的空间不足以容纳较大体积的千斤顶。

（５）使用化学试剂浸泡过的机体、零部件，一定要用清水冲洗干净，作业时，可在机体下面用橡胶皮做成一个简易漏斗把水引导出机体外面，避免污染滑油造成不必要的损失。

另外在用自制工具顶气缸套时，要用帆布或者胶皮包扎曲柄销，避免碰上曲柄销表面。
