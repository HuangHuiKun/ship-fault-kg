# 机型介绍

CW200ZC/XCW200ZC系列船用柴油机按照德国MAN公司技术制造。

功率覆盖:330kW-1200kw。

转速:720r/min~1000r/min。

该机型秉承了德国MAN——噪音低、振动小、油耗低、可靠性高的技术特点,具有机型结构合理,性能指标先进,运行可靠,操作维修简便等优点。

排放满足国际海事组织MAPRPOL 72/78公约要求。

该系列产品得到中国船级社和中国渔检总局型式认可。

通过ISO9001:2000体系认证。

广泛用于客船、渔船、中小型运输船、滚装船等船舶推进主机、大型船舶辅机。

# 型号识别

柴油机型号由四部分组成，首部由新机型代号、企业代号组成，中部由缸数、气缸布置 形式、冲程符号、缸径组成，后部由结构和用途特征组成，尾部为变型代号（变型代号用阿拉伯数字）和旋转方向代号。

后部与尾部之间可加一短横线。

# 结构优势

机体——矩形箱式结构,具有变形小(从而缸套磨损少)、强度高等特点。进气管内置在机体内,维修少。

曲轴——煅钢曲轴具有连续纤维组织结构,抗疲劳强度、抗弯曲刚度和扭转刚度均优于铸铁曲轴,表面经气体软氮化处理,大大提高了耐磨性,可靠性高。

曲轴每拐装有平衡快,使质量得到很好的平衡。

自由端还装有筒式弹簧减振器。

柴油机的一阶和二阶残余惯性力力矩为零。

气缸盖——气缸盖和摇臂罩设计为一个整体,结构简单,维修方便。

无挺杆结构设计——进、排气门摇臂直接由凸轮轴驱动,减少了运动件。

缸套——缸套采用高耐磨,耐腐蚀材料制造,使用寿命60000小时以上,抗变形好,磨损率低,强制冷却,形成良好润滑条件,防止低温腐蚀。

活塞——活塞裙部冷态横截面为椭圆形,轴纵剖面为腰鼓形(中凸变椭圆活塞),热态时为圆形。

此结构活塞与气缸套间隙小,导向作用好,易于保护油膜,润滑良好,机械磨损小,柴油机机械效率高,油耗低。

连杆——采用优质钢模锻而成,连杆大头轴承沿水平方向剖分,用四支螺栓紧固,使接合面得到充分利用,提高了大头轴承的承载能力。

# 性能优势

可靠性好——曲轴、连杆选用优质钢模锻,凸轮轴各种传动齿轮采用合金钢制作,从而保证柴油机在使用过程中不会发生断轴、断连杆等问题,缸套三点支撑结构,刚性好,受热均匀,磨损量小,通过800小时耐久试验测定,大修期超过3万小时。

维修方便

顶置凸轮轴,没有挺柱、顶杆零部件,减少了故障的发生。

减震器为筒式弹簧,在柴油机使用过程中不需要维修。

油耗低——CW200系列柴油机最低燃油消耗率在标定功率的80~90%工况点,为195~200g/kW.h,是船舶长期运行点；

机油消耗为1.0g/kW.h,同时油耗性能曲线平坦,在常用工况下均有良好的经济性。

两级中冷——采用二级中冷,大大降低了进排气温度,增大了进气量,使燃烧充分,排放达到国际海事组织IMO标准,并经CCS认可,由于进气温度低,从而降低了柴油机的热负荷,提高了可靠性。

低排放——由于采用脉冲增压,二级进气深度中冷,所以柴油机在整个工况过程中烟度较淡,低于欧II排放标准,排气烟度船标规定≤2.5RB(波许),实测值为0.55RB。

# 选配齿轮箱

CW200ZC系列柴油机用于船舶推进主机时,可根据船舶设计要求的螺旋桨旋向和转速,配置联轴节和倒顺离合减速齿轮箱。

该机所配齿轮箱多为GWC,J900,J1200A系列,输入轴与输出轴同心,减速比为2-5.5。

也可按需求选配其他型号的齿轮箱。
