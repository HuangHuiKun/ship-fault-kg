# 船机帮船用柴油机调速器的维护与保养十飞车故障

柴油机飞车非常危险，必须高度重视！

遇到此类故障，应检查以下因素：

- 检查针阀开度，不能小于1/8圈。
- 供油联接机构、高压油泵是否有阻卡。
- 高压油泵“0”位油量过大。
- 调速器驱动轴是否扭断。
- 喷油泵齿条的零油量位置、全油量位置与调速器内动力活塞的行程是否相对应。调速器加减油方向与喷油泵是否一致。
- 调速器灵敏度差，即动态调速率大，需重新拆装调整。
- 调速器连接错误，运转方向不对。
- 传感器无信号或失灵，控制器接收不到。

## 友情提示

由于调速器结构复杂、零件较多，保养维修后性能都有所变化，建议只要拆卸、重装了调速器，最好再上一次试验台进行复试，保证调速器的性能及可靠性，防止柴油机出现飞车现象。

所以提示大家维修调速器最好找原厂服务。

## 其它故障排除

- 负荷变化时恢复时间长——调节针阀开度（大）
- 瞬时调速率超大——调节补偿位置（小）
- 转速波动值超大——针阀（小）补偿（大）
- 转速调节失效——重点查离合器电机、各齿轮等
- 柴油机不能停车——检查调速器“0”位是否与高压油泵“0”位相符合，并检查停车电磁阀及仪表箱电源电压。
