# 导读

有朋友提问：

船舶柴油机的油耗是怎么算出来的？

先说结论。

柴油机的油耗不是算出来的，而是测出来的！

但是我们也可以根据经验估算油耗，如果方法得当估算的还可能挺准。

## 汽车油耗表上的数是怎么来的

朋友们可能还有个疑问：

为什么船舶上没有像汽车上那样的油表，可以实时显示油耗？

回答这个问题，我们要先知道：

汽车仪表盘屏幕显示的油耗是哪里来的？

是汽车根据ECU提供的喷油量，ABS/ECU提供车轮的转速，也就是里程，计算出来的。

## 船舶上能不能也这么算

对不起！不能。

因为船用柴油机的发展相对车用发动机来说落后的不是一点半点，整整差了好几代。

目前，汽车发动机甚至拖拉机采用的都是比较先进的高压共轨燃油系统。

大部分船用柴油机采用的依然是比较传统的机械供油系统，根本就没有什么ECU之类的东西。

没有啊！亲——

## 柴油机燃油消耗率

柴油机的燃油消耗率是反映柴油机经济性能的重要指标，它是指单位时间内每千瓦所消耗的燃油量。

在柴油机试验台上，通过测量柴油机的功率和单位时间内的燃油消耗量，可以计算出该柴油机的燃油消耗率，单位是g/kWh。

柴油机的燃油消耗率是一个相对指标，在同等条件下，燃油消耗率越低，表示该柴油机的经济性能越好，越省油。

## 船舶油耗估算与测量

在船舶运行过程中，如果要计算船舶的燃油消耗，可以找发动机厂家要主机功率曲线、主机燃油消耗率曲线，这样就可以估算出不同转速下的油耗了。

上图为某柴油机的推进特性油耗曲线图。

我们可以计算柴油机在1000转/分运转时，工作24小时的燃油消耗：

200g/kWh×300kW×24h=1440000g=1440kg

注意：计算数据为理论数据，与实际可能会有一定的偏差。

因为船舶载重不一样，机桨匹配不一样，同一转速下实际的主机功率、燃油消耗率与曲线上数值也有偏差。

如果需要准确的油耗值，可以进行实测。

柴油机日用柜上一般都有液位计，可以在不同转速下，通过记录燃油舱内燃油消耗和运行时间，计算出不同转速下实际油耗。
