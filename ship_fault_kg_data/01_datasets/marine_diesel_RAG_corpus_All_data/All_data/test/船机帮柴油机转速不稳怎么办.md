# 船机帮柴油机转速不稳怎么办

船用柴油机正常运转时，依靠调速器的自动调节作用，其转速是稳定的。波动值只有几转，波动率在0.5%以内。

## 一．当转速不稳时的现象

1. 柴油机有规律的忽高忽低。通常所说的“游车”、“喘气”。此种情况多发生在柴油机低速运行工况。

2. 柴油机运转无规律的忽高忽低。

## 二．造成转速不稳的原因如下

### 1. 供油系统原因

转速太低，供油不足或供油提前角不对；

燃油系统内有空气、水，气阻和水租均可造成供油不稳；

喷油器雾化不良，喷油不稳，隔次喷油或断续喷油；

喷油泵柱塞出油阀磨损过大，供油不稳；

喷油泵齿条卡滞，喷油器针阀卡滞；

喷油器弹簧、出油阀弹簧、喷油泵弹簧断裂；

喷油泵油量调节齿圈松动；

各缸供油量严重不均匀。

### 2. 调速系统原因

调速器内滑油太多；

调速器弹簧变形、断裂或刚度减小；

调速器飞铁衬套磨损严重；

调速器运动件卡滞或磨损严重。

调速器非专业人员不建议打开，他的机械构造比较复杂，以后会有专题推送相关内容。

### 3. 增压中冷系统原因

增压器效率下降；

空气滤清器不清洁，排气背压过高；

中冷器阻塞，进气减少。

### 4. 外部原因

齿轮箱接合不良，应考虑船、机、浆的匹配合理性；

工作负荷工况严重不稳，突加突泄；

工作区域海拔太高或环境温度太高。
