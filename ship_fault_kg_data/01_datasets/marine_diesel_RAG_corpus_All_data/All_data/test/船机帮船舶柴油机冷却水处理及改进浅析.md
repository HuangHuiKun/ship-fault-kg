# 导读

目前，我国船舶柴油机的冷却水处理主要使用的是淡水，淡水主要是通过自来水管道运输的，除此之外还可以使用蒸馏的方式将海水进行蒸馏操作获得。

河流中的淡水中含有较多杂质，一部分是不可溶杂质，可以通过过滤的方式将其除去，但是对于那些可溶的物质，单纯过滤的方式是无法将其除去的，进行处理柴油机后会在柴油机表明产生水垢等物质，对柴油机的正常运行造成很大的影响；

另外对于蒸馏水来说，虽然其中不含有杂质，但是在其蒸馏的过程中会将氧气进行溶解，再对柴油机进行冷却处理的时候会对柴油机金属造成严重的损坏，所以，我国目前对柴油机的冷却水处理方式还存在一些问题，下文对船舶柴油机冷却水处理的淡水选用进行分析和选择，进而提出一些改进的措施和对策。

# 一 淡水水质对冷却水系统的影响

通过对我国船舶柴油机冷却水处理的现状进行分析，总结出淡水对船舶柴油机进行冷却处理之后会对柴油机造成两种危害：

第一，在柴油机表面形成水垢；

第二，对柴油机金属造成腐蚀。

下面对这两种情况分别进行分析。

## 形成水垢等物质

对于淡水中存在的可溶性物质来说，最主要的是碳酸钙，碳酸钙是一种难溶于水的物质，在对柴油机处理后会在柴油机表面形成厚厚的一层水垢，不仅影响美观，还对柴油机的散热效果有很大的影响。

## 对柴油机金属腐蚀

对淡水进行蒸馏处理的时候由于温度过高，将水蒸发，水蒸气遇到冷空气后会凝结成水，在凝结成水的同时将一部分氧气也混到蒸馏水中，当用蒸馏水对柴油机进行冷却处理的时候，温度过高会将氧气释放出来，氧气遇到金属且在高温的情况下会发生氧化反应，进而对金属造成一定的腐蚀。

所以说在蒸馏水处理柴油机的时候需要注意将水与金属分隔开，进而减小金属被腐蚀的程度。

# 二 柴油机冷却水处理剂

一般来说，淡水中都含有部分钙离子和镁离子，在对柴油机进行冷却处理之后会在柴油机表面形成不可溶的水垢面，其对差柴油机的正常运行有很大的影响。

针对上述问题，我们可以加入一些无机盐缓蚀剂或者乳化防锈油，这些水处理剂可以有效抑制不可溶碳酸盐的产生，进而保证柴油机的正常运行。

无机盐缓蚀剂可以抑制不可溶碳酸盐的产生，并在金属表明形成一层氧化膜，降低电腐蚀现象的发生，被广泛的使用在柴油机的冷却水处理中；

而乳化防锈油可以在金属表明形成一层保护膜，将蒸馏水中的氧气与金属分隔开，降低了氧化反应的速率，对大小低速柴油机的活塞冷却水处理有很大的帮助。

# 三 冷却水处理的问题及影响

通过上述对船舶柴油机的冷却水处理中淡水对冷却水系统造成的影响以及柴油机冷却水处理剂对柴油机造成的影响进行分析，总结出我国船舶柴油机的冷却水处理还存在以下几个问题：

第一，淡水的选择不到位，导致柴油机进行水处理之后在柴油机表明形成水垢或在对柴油机金属造成严重的腐蚀。

第二，无机盐缓蚀剂虽然可以有效的抑制不可溶碳酸盐的生产，进而减少水垢的产生，但是无机盐缓蚀剂中的亚硝酸钠对海洋造成严重的污染。

第三，乳环防锈油是一种可溶于水的物质，其对柴油机金属进行保护的同时会对水造成很大的污染。

第四，柴油机冷区水系统未设置管路系统排污装置，导致冷却水处理剂对海洋造成严重的污染。

# 四 改进措施

针对上述我国船舶柴油机冷却水处理过程中存在的问题，本文提出一些改进的措施和对策，希望可以有效的提高柴油机冷却水处理的效果且减少水处理剂对海洋环境造成的污染。

第一，选用一些环保的水处理剂，既能有效的抑制水垢的产生和降低对金属的腐蚀，还能避免其对水质造成的污染。

第二，淡水输送系统以及管路系统应该设置过滤装置，对淡水中的杂质以及冷却后的水垢等进行过滤。

第三，在冷却水系统中设置排污装置，对水处理剂进行及时的排污处理，有效的降低其对水质造成的污染。

第四，加强船舶技术人员的技术管理，由于一些轮机人员不按照水质处理的要求去做，导致在对柴油机进行冷却水处理之后将其随意排放到大海中，对水质造成严重的污染，所以一定要加强相关人员的管理力度。

综上所述，随着我国船舶使用越来越广泛，其正常运行对人们的生活以及工作的重要性越来越大，而船舶柴油机的冷却水处理对船舶的正常运行有很大的影响。

本文通过对我国船舶柴油机冷却水处理的现状进行分析，对于冷却水处理过程中存在的问题进行改善，提出完善我船舶柴油机冷却水处理的一些方法和对策，有效的提高船舶柴油机冷却水处理的效果，进而保证船舶的正常运行，此外也加强对水处理剂的选择，减小了水处理剂对海洋环境造成的污染。
