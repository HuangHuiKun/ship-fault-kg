# 导读

现代船用主机普遍采用增压系统为燃油燃烧提供足够空气,增加喷入气缸的燃油量，以提高柴油机的输出功率。

本文通过对一起油轮主机增压器受损事故的深入解析,详细探讨了导致主机排温异常升高、冒黑烟的根本原因。

事故发生后，通过对主机运行参数、冒黑烟、振音等多个方面的综合分析,判断故障源头为增压器问题。

文中详细总结了事故现象及其原因，在总结中,提出了未来维护工作中需重点关注的振动与共振效应等潜在因素。

通过本文深入的技术分析,读者能够更清晰地理解增压器受损的机理,以及如何有效预防类似事故,确保船舶设备的长期安全、可靠运行。

# 一、故障现象

该轮总长99.80米，型宽16.00米，型深6.20米，总吨2998,搭载G8300ZC16B型号主机，功率为2000KW;增压器型号: VTR321-2P,生产厂家:重庆ABB江津涡轮增压系统有限公司。

事故发生前，主机的各个运行参数都处于正常范围,冷却水温度以及排气温度均无异常。

事故发生时，该轮在岙山锚地抛锚等待装货计划,接到调度指令后备车,在试车过程中主机排烟管冒黑烟、主机增压器有振音、主机排温偏高，于是机舱人员通知驾驶台要求停车，抛锚检查故障。

# 二、现象及原因分析

## 1、主机冒黑烟

主机出现冒黑烟，长期冒黑烟会出现喷油咀积碳、气阀积碳引起的密封面不严、活塞缸套磨损加剧等故障，减少主机使用寿命。

主机冒黑烟有多种原因，有的是柴油机本身的设计问题，比如:配气相位设计不合理、气门升程设计不精准、气道不顺畅等;有的是柴油机安装匹配不当或保养不及时，如:排气管道布置不合理导致排气背压大、进气阻力大导致进气不足等。

总之，主要原因在于燃料在缸内没有充分燃烧,导致大量碳颗粒物的生成。

图1 主机冒黑烟故障树

造成燃烧不充分的原因主要包括:

进气量不足、喷油嘴雾化效果差、燃油品质不佳、高负荷以及燃油喷射量与空气供应不匹配等因素。

## 2、主机排温异常偏高

发生排气温度高会造成气阀高温腐蚀，将导致活塞、缸盖、气门、燃气涡轮等受热零部件的热负荷增大、强度下降、磨损增加、诱发裂纹等物理损坏。

主机排气温度过高的原因主要是由燃烧系统、燃油系统以及进排气系统所引起的。

柴油机的正常排气温度取决于其燃烧过程的正常进行，而正常的燃烧需要一定量的燃油,在良好的雾化状态下与充足的空气充分混合。

所以任何达不到这些条件的因素,都会引起排温过高。

图2 排气温度高故障树

### (1)进排气系统

#### 1)进气系统的阻力大

进入柴油机的空气量不足时，会导致燃油与空气的混合质量下降,无法实现完全燃烧,进而导致排气温度上升,同时也会影响到排气效果。

引起原因:

空滤器脏污、压气机脏污、缸盖进气道脏污。

#### 2)进气压力低

一方面是漏气,比如:

①进气系统中的管路存在漏气，使空气不能有效进入气缸中;

②排气系统管路存在漏气,将使主机排气能量减小，导致增压器做功减少,进而减少了向缸内供气。

另一方面是增压器故障,增压器的任何故障都使增压压力降低,减少了向缸内供气和影响扫气效果,从而引起排温升高。

#### 3）排气阻力大

排气系统的阻力加大，降低了增压涡轮的增压压力，减少了进入缸内的空气，造成空气供给不足，而在同等功率的输出下，需要加大供油量，才能使混合气浓度加大，从而产生排气温度高、冒黑烟的现象。

引起原因：

主机消声器污堵、排气管太长、太细、拐弯多，缸盖排气道脏堵。

#### 4）气门间隙不对

如排气门间隙小，则排气门早开，使缸内燃烧气体膨涨不充分就被排出；

如排气门间隙大，则排气门晚开、早关，排气时间缩短，排气不完全；

如进气门间隙过大，则进气门晚开、早关，进气时间缩短，进气不充足和扫气效果不良；

如进气间隙过大，又会因气门重叠、废气倒灌，使进气充量中废气高；

这些因素均会造成燃烧不充分，导致排气温度过高。

排气阀密封不良泄露也会造成排气温度过高。

### (2)燃烧系统

气缸密封状态差，如果气缸密封状态差，压缩冲程压缩压力就会变小，导致压缩终点温度变低，使燃烧延迟而产生后燃。

引起原因：

气阀漏气（特别是排气阀因烧蚀很容易出现漏气）；

活塞环因严重磨损或断裂漏气。

### (3)燃油系统

#### 1）供油角过晚

提前角太小，则会使主要燃烧阶段后移，最大爆发压力降低，并使后燃增加，燃油燃烧不完全，热效率降低，排温升高。

#### 2）燃油品质差

燃油品质直接影响柴油机的燃烧过程，如果采用不符合质量要求的燃油，燃油在整个燃烧或者化合过程中，由于不能够充分利用和完全燃烧，会导致柴油机的排烟温度过高。

#### 3）超负荷运行

柴油机的排气温度与运行负荷成比例，运行负荷越大，排气温度越高。

所以柴油机超负荷运行造成排温过高是在情理之中的事情。

#### 4）喷油器雾化不良或者滴漏

这种情况会导致燃烧室内的滞燃期延长，燃油燃烧不完全，产生粗暴燃烧现象，进而增加后燃效应，排气温度上升。

在特定情况下，未完全燃烧的燃油甚至可能在排气管中进行二次燃烧，造成柴油机工况变得更加恶劣。

### (4)其他原因

环境温度高，中冷进水温度过高，中冷器后的空气温度高；

还有环境温度偏高、空冷器脏堵、环境气压偏低，均可能造成进入气缸的空气量减少，燃烧不充分，排气效果变差，从而排温升高。

如遇到大气压力太低，或环境温度太高，则应降低主机负载运行。

## 3、增压器有振音

增压器有振音，原因可能是增压器内部有异物，异物与高速运转的增压器叶片撞击产生振音。

常见增压器进入异物情况：

主机维修期间维修人员大意落入进气的螺栓、螺母；

主机燃烧工况差，导致气阀、活塞烧蚀，甚至气阀断裂，产生的碎片进入增压器。

# 三、故障原因分析

该轮在船厂进行过增压器解体维修，并对轴承、内接头进行了换新，根据轮机日志记录，维修后增压器运行时间为1637小时。

该型增压器为独立润滑油系统，据轮机长描述，滑油按照2个月换新一次，滑油为美孚透平油VG46。

主机同时出现冒黑烟、增压器有振音、排温偏高现象，一般情况下，在没有高负荷运载下，是不会引起冒黑烟、排温异常偏高，也不会引起出现增压器有振音。

通过综合分析，事故原因可能是增压器进入异物，异物与增压器叶片高速撞击产生振音，同时导致增压器叶片受损，主机进气压力降低、进气量减少，造成排温高和冒黑烟。

# 四、故障修理

通过故障原因分析，初步得出结论，由增压器故障引起，维修人员对增压器进行拆解。

增压器拆解后，发现增压器叶轮之间有大块铁皮，进一步检查，发现叶轮间铁皮来自排烟管膨胀节内壁金属圈脱落，金属圈脱落后进入增压器涡轮端，高速运转的叶片与铁皮撞击，导致增压器受损。

图7 涡轮叶片受损

涡轮叶片数量53片，叶片稍部可见挤压及打擦、挤压卷曲受损，观察转子轴轴颈状况良好，未见明显受损。

为判断转子轴受损情况，对受损转子轴进行检验，转子轴轴颈状况良好，轴颈区域未见异常抱轴，发热等受损情况。

经过对53片进行换新，喷嘴环、喷嘴罩及轴承部件进行换新，转子轴校正平衡，并对排气管膨胀节换新后，完成事故修理。

# 五、总结

本起事故，因排气管膨胀节内壁金属圈的脱落，金属圈进入增压器造成增压器受损，引起主机排温高和冒黑烟。

虽然增压器进入异物是一种相对较为常见的情况，但本次事故膨胀节内壁脱落的情况相对少见，这应该引起重视，提醒大家在日常保养维护中，除了常规防范，还要特别注意潜在的其他可能引起增压器损坏的原因，在维护和检查工作中，要加强全面检查，以排除潜在的风险因素。

潜在的其他因素包括但不限于振动与共振效应：

检查整个排气系统的振动和共振效应，特别是在高负荷或异常工况下，振动可能导致管道和波纹管疲劳和损坏。

通过全面考虑和细致检查，可以更好地预防未来类似的增压器损坏事故，以确保船舶设备的安全、可靠运行。
