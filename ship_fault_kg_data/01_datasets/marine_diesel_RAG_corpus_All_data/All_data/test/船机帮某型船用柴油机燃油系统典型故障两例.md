# 导读

本文针对MAN公司6L16/24型和6T23/30LU-4E型柴油机两例典型燃油系统故障，详细分析了两例故障的故障现象及故障处置，并结合笔者日常工作积累经验进行了故障分析与举一反三。

# 一、故障案例一

## 1、故障现象及处置

某船MAN公司6L16/24型发电柴油机组，某日在码头系泊实验过程中发现高压油泵发烫，进油及回油管发热，温度高达60℃左右，于是立即卸负荷停机检查原因。

通常高压油泵发烫时是由于回油不畅，工作人员围绕回油管路展开检查：

(1) 由于6L16/24柴油机燃油进油及回油管接块组上装有节流塞，怀疑节流塞可能堵塞。

但拆下接块组检查，发现节流塞没有堵塞。

(2) 怀疑船上燃油回油管路系统可能有问题，导致燃油回油不畅。

工作人员首先将柴油机的燃油管路阀门关闭，检查压力是否卸掉，结果发现压力下降不明显，由此判断燃油回油有堵塞现象。

顺着回油管路检查，发现燃油系统回油管路上安装了1只调压阀，该调压阀在系统中起到稳压作用，正常情况下，回油调压阀是不需要调整，出厂时已设定好。

怀疑该调压阀压力设定值是否过大，导致回油压力不能开启。

现场对三台柴油机回油管路调压阀进行调整压力试验，发现压力变化不明显，由此判断调压阀有问题，拆开三台机回油阀后发现阀芯柱塞卡死。

经检查，是对燃油管系窜油清洗时，管路中的杂质进入调压阀导致阀芯卡死。

由于调压阀阀芯卡死导致回油管路堵塞，回油不畅，高压油泵发烫。

将调压阀零件清洗后装复，并对压力进行重新调整，经开机试验，检查高压油泵进油和回油温度，发现温度均已正常。

如果出现此现象不及时排除，会造成高压油泵柱塞偶件磨损加大，甚至会造成高压油泵柱塞抱死。

## 2、故障分析

一般情况下，在柴油机运行时高压油泵发烫是由于燃油回油不畅或者进机温度高所引起的。

从燃油进油总管的进入柴油机的流量要大于实际消耗量，通常为3—5倍，多余的燃油通过回油管回到日用油柜，一方面起到稳定燃油系统压力的作用，另一方面带走高压油泵工作时产生的热量。

柴油机运行时，会有微量的燃油从高压油泵柱塞偶件配合间隙中泄漏掉，这泄漏的部分燃油起到润滑柱塞的作用，当回油不畅或燃油进机温度偏高时，会导致高压油泵温度升高发烫，回油温度升高，燃油的黏度随之下降，对高压油泵柱塞偶件之间的润滑作用下降，当超过一定温度时会造成偶件磨损加剧甚至咬死（此现象是指在系泊实验阶段燃用轻柴油而言，当柴油机正常燃用重油时，因重油需加热才能使用，高压油泵表面温度高属于正常）。

回油不畅的原因可能有：

外接燃油输送泵容量不够、管路布置不合理、管路堵塞、调压阀压力设定不正确或阀芯卡滞等。

在系泊试验时，要注意观察柴油机燃油进、回温度，燃用轻柴油时的进机温度不要超过40℃，进、回油温差小于约10℃。

如果发现燃油温度异常，要查找原因，并在排除故障后才能继续开机。

如果燃油进机温度超过40℃，在所有可能存在的故障排除后燃油温度仍然较高（特别是在夏天），则需要在燃油进油管路加装冷却器，保证燃油进机温度正常。

# 二、故障案例二

## 1、故障现象及处置

某船主机是MAN公司6T23/30LU-4E型柴油机，某日主机出现转速上不去，航速下降，燃油三通转换阀漏油关不死的现象，经检查发现，主机还未到最高额定转速时，供油量却已到了全负荷的供油量，排温上升，同时燃油压力在短时间内下降很快，与出厂试验记录有较大的出入，这很不正常。

进一步对喷油器检查，发现喷油器雾化不良，油嘴堵塞严重。

拆开高压油泵检查，发现柱塞偶件磨损严重并有拉痕。

故障原因是船舱内主机日用油柜的出油口位置开在油柜的底部，正确的出油口位置应该是开在离底部30公分以上，这样就可以避免油柜里的杂质及沉淀物进入到主机燃烧系统。

由于日用油柜内的大量杂质流到燃油滤器，使燃油滤器短时间内经常堵塞，压力下降，在滤器经常堵塞时，并没有查找原因，而是图方便来回转动燃油滤器三通阀，进行反冲洗处理。

在反冲洗阀来回转动时，阀芯与燃油中的铁屑摩擦，导致阀芯严重磨损，杂质随燃油进入高压油泵，随后进入喷油器，造成喷油嘴堵塞，供油量加大而转速上不去，主机功率下降。

原因找到后，纠正了主机日用油柜的出油口位置，对燃油系统进行全面清理和调整。

## 2、故障分析

喷油器的堵塞通常是由于管路清洁度不够，管路中有杂质所引起的，有的船厂在安装燃油管系时管子没有经过充分窜油及清洁度检查，有少量的铁屑、焊渣、氧化皮等杂质残留在管子内部，柴油机运行时，杂质随燃油进入高压油泵和喷油器，导致喷油器的堵塞，雾化不良，柴油机功率发不出。

另外，燃油系统中某些小零件由于制造质量差或安装不当，在受到震动和压力后破损，形成细金属颗粒，这些金属颗粒随燃油进入高压油泵和喷油器，造成高压油泵和喷油器的损坏。

在系泊试验开机前，应对船上燃油进机管路的清洁度进行检查，将铜丝网安装在外接进油口处，通油后检查铜丝网上是否有杂质，如果有，则要求船厂重新窜油冲洗管路，直到干净后方可开机进行试验。

# 三、结语

燃油系统在船舶柴油机中起到关键的作用，燃油系统出现故障将引起柴油机发火不良、做功不畅，最终导致柴油机停车，危害严重。

因此在日常使用和管理中，船员要重点加强对燃油系统的巡视检查和维护保养，确保柴油机燃油系统正常运转，确保船舶远洋航行期间动力保障稳妥可靠。
