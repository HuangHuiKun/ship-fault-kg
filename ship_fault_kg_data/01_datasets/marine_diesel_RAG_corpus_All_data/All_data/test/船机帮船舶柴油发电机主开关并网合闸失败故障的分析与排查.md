# 导读

救助船舶在海上值班待命期间，船舶电力系统的可靠性尤为重要，然而船舶电站为全船提供电力保障。

这包括动力电和照明用电，所以船舶电站系统是船舶的血脉，为海上救助提供安全保障。

某救助船舶电站搭载 3 台530KW的中船动力公司的MAN 柴油发电机（简称柴发，其型号为6L16/24）和2台2,400KW 轴带发电机（简称轴发），3 台主柴油发电机之间可以长期并联、自动调频调载，而主柴油发电机与轴带发电机之间仅可以短时并联用于负载转移，如图。

通常情况下，主柴油发电机负责全船的小功率的动力用电和照明用电，轴带发电机主要用于拖缆机与侧推用电。

在日常海上抛锚待命时，只利用主柴油发电机为全船供电。

镇江赛尔尼柯电器有限公司为船舶电站提供整套的电站管理系统（英文简称 PMS，其型号为 JZB-2400），PMS通过对电网的参数监视和电站运行负荷来实现发电机组的自动起动、并网，电压及无功功率的自动调整，并联运行中的功率自动分配、转移和电网频率的自动调整，重载询问，运行状态显示与故障监视等。

该电站的配电板上提供手动、半自动、自动3种管理模式，可通过“PMS 模式”选择开关来选择。

在手动模式下，轮机员根据电网负荷和柴油发电机的工况手动对发电机进行启动，并网与解列。

MAN 柴油发电机操作通讯设备较多，包括发电机传感器与执行器，中央控制报警单元的机头箱，柴发扩展箱，泵类控制柜，主配电板的柴发控制屏及集控台监测报警。

它们之间关系密切，如下图2。

柴油发电机体有执行器和传感器，对接受的执行命令做动作和信息反馈。

柴发机头箱（安装在柴油发电机体上）是柴发的大脑，采用了曼恩公司的 SaCoSon 电气控制系统，在运行参数检测、运行控制及运行安全方面具有强大的管理功能与可靠的安全性能。

柴发扩展箱（安装在柴油发电机附近的墙壁上）是连接机头箱与主配电板的桥梁。

主要负责对柴发机头箱信号进行转换处理，然后传递给集控室的监测报警系统与主配电板，为柴发主开关合闸并网提供控制信号；与此同时，主配电板的操作指令转化成 PLC 通讯，通过扩展箱转给机头箱，让柴油机来执行调节。

# 一、故障现象

船舶停靠在码头上，全船电网负荷处于150KW 左右，发电机 DG1 承担着全船负荷。现准备对保修后的柴发 DG2 进行并网试验，在正常启动柴发 DG2 后，其操作控制屏显示一切正常，轮机员对该柴发进行半自动并网时，按下“同步运行”指令时，发现 PMS 报出发电机合闸失败报警。

消警后改为手动并网，柴发 DG2 主开关依然无合闸动作，无法正常并网。

# 二、故障机理

## 1、主开关自身合闸故障

柴发 DG2 出现主开关合闸失败故障，因此不能排除主开关自身原因。

并且该柴发因为吊缸维护保养，主开关已长时间未动作，主开关的蓄能器可能无法蓄能而导致故障发生。

而主开关蓄能分手动蓄能和电动蓄能，一般情况下是通过电动蓄能，让主开关合闸。如果电动蓄能器故障，无法执行合闸指示信号进行合闸。

其次是主开关蓄能马达控制系统出现故障，如图3 所示，要满足蓄能马达工作，控制线圈MN与XF必须同时得电，若二者有其一故障断开，蓄能马达将无法工作，主开关就不能合闸。

因此，这两种原因最终结果都会导致蓄能器无法蓄能，从而主开关无法合闸。

例如，该船某次在海上值班待命期间，在电网未超负荷情况下，柴发的主开关自动跳闸，导致全船失电，经过排查发现主开关控制分闸线圈 MN 断线，后面更换该控制线圈后，故障恢复。

## 2、主配电板异常动作

主配电板异常动作原因可分为人为违规操作和控制设备故障。

根据上图三可知，主开关合分闸线圈MN与合闸线圈XF能否得电，取决于主配电板上的控制信号，控制信号主要包括两类：

第一类是合闸指令，就是在主配电板上的合闸按钮或 PLC 控制的合闸指令；

第二类为分闸信号，即为各种报警信号（如 DG2 逆功率、PLC 异常脱扣、安全停车、岸电互锁与汇流排C失电）与分闸指令（手动按钮和 PLC 输出信号）。

若不存在报警或分闸指令时，分闸线圈始终处于得电状态，在按下合闸指令按钮后，合闸线圈 XF 得电，蓄能马达工作，主开关合闸。

倘若在主配电板上的中间继电器故障或者所连接信号的其他设备故障都会导致分闸线圈 MN 失电，进而蓄能马达无法工作。

## 3、柴油发电机故障

柴油发电机故障也会引起主开关无法正常合闸，如上图二与图三可知，柴油发电机有一个“安全停车”的连锁报警信号串联在分闸线圈 MN 当中。

当柴油因某些故障或者人为操作不当导致柴发非正常停车时，机头箱就会发出“非安全停车”报警，该报警信号通过扩展箱传递给主配电板，驱使控制分闸线圈 MN 信号触点断开。

# 三、故障分析和处理

## 1、故障排查

轮机员对柴油发电机 DG2 的主开关无法正常合闸故障进行分析排查，通过对操作面板进行检查未发现人员误操作的可能。

### （1）对主开关进行检查。

主开关为施耐德电气公司生产的 NW08-63 型，需要利用摇把把主开关摇出断电。

在规范拆解后，对其蓄能马达进行测量未发现问题，然后利用万用表对主开关的控制分闸线圈 MN 与 XF 进行测量，依然正常，接着查看主开关的电脑板的电池和相关参数，一切正常。

并对人为强制对分闸线圈 MN 与合闸线圈 XF 进行通电，发现主开关可以正常手动合闸，排除主开关本身的故障的可能。

### （2）对配电板的柴发控制屏的器件和模块进行检查。

重点检测与主开关合闸信号的相关中间继电器和模块输出信号，依然未发现任何问题。排除配电板器件故障导致主开关无法正常合闸的可能。

### （3）通过对柴发机头箱的报警界面进行检查，未发现柴发有任何异常报警，重新对柴发进行正常停车后，然后再次正常启动柴发，待其稳定运行状态，观察机头箱的安保报警界面，依然未发现任何报警，由此排除柴发非正常停车导致主开关无法合闸的可能。

## 2、故障定位与处理

轮机员分析梳理可能是其他原因导致主开关控制线圈MN和XF失电。

因为该线圈得电的条件较多，为了更稳妥的排除故障，轮机员把主配电板上的主开关的控制电路的保险丝断开进行点对点的查找。

利用万用表的欧姆档对串联在线圈 MN 的控制信号触点进行通断测量，发现在串联控制信号电路中，有一个 “安全停车”报警触电处于断开状态。

根据上图二的柴发设备通讯系统关系简图可知，扩展箱是连接主配电板与柴发机头箱的桥梁，说明柴发的“安全停车”信号是通过扩展箱传递给主配电板上的。

若扩展箱存在问题，会导致“安全停车”信号断开。

于是对柴油发电机的扩展箱进行检查，发现有一个控制报警信号的中间继电器线圈处于非正常闭合状态，通过查询有关说明书，确定该继电器正是控制主配电板上的分闸线圈 MN 的“安全停车”触点。

在正常状态下该继电器线圈是断开的，控制分闸线圈 MN 的触点处于常闭状态，主开关可以正常合闸。

由此可以断定该继电器出现故障，需要对其进行更换。

# 故障恢复操作步骤：

（1）对柴发 DG2 进行正常停车；

（2）关闭扩展箱的控制电源；

（3）把故障继电器拔下来更换成新的继电器，打开扩展箱的控制电源；

（4）重启柴发 DG2 到正常并网运行状态，对扩展箱进行报警确认，观察新的继电器处于断开状态；

（5）测量主配电板发电机控制屏的主开关线圈 MN 控制信号触点处于闭合状态（原来故障时触点处于断开状态）；

（6）合上控制电路的保险丝，主开关控制线圈MN 正常通电；

（7）在配电板的同步屏的操作模式切换到半自动状态；

（8）按下柴发 DG2 同步运行指令按钮，主开关正常合闸蓄能，柴发 DG2 正常并网运行。

经过一周的正常分闸与合闸操作，未发现柴发 DG2 的主开关无法合闸，并且发电机在网运行一切正常。

# 四、结论

（1）在拆解主开关之前一定要把主开关断电摇出，以免发生不必要的麻烦。

主开关属于精密设备，拆解过程要规范，在测量控制线圈通断时，一定要断电测量。在配电板的控制电路中，测量线路的通断要把该线路的电源断开，这样测量的结果更安全可靠。

（2）在更换故障的中间继电器时，要注意断电更换，并且确保更换过程中不会影响其他设备的正常运行。

在跟换结束后，进行再次通电检查，若存在报警，则第一时间进行报警确认，确认之后，再次观察是否有报警继电器处于非正常状态。

（3）若该故障无法及时恢复，要保证另一台停车的柴油发电机处于第一备用状态，能够正常起动并网，并把电站切换到自动模式。
