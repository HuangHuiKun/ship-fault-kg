# 导读

CAT3516B是7025型绞吸式挖泥船生产动力核心，其运行状况的良好与否直接影响挖泥生产进度、安全、质量、效率及生产成本。

因此就要求轮机管理人员和操作人员做好船舶主机管理维护工作，及时排除故障，保证设备完好率，使其高效平稳安全的运行。

# 一、7025型挖泥船所使用的柴油机的性能参数、结构

7025型绞吸式挖泥船是由荷兰HC公司设计，船上专门配套3台卡特皮勒柴油机组，两台CAT3516B(一台用于水下泵电动机配套，一台用于甲板泵机配套)、一台CAT3512型（用于船舶液压系统，负荷较小，故障率较少，故不做讨论）。

主机基本性能参数如下:

排列型式: V型360°/6,防冻液内循环，ω型直喷式，中间冷却，高增压，缸径×行程=170mm×180mm；

气缸数: 16个；

压缩比: 13,额定转速1500r/min,最大功率约1600kw,额定功率约为1040kw，实际工作时燃油耗率约为0.265~0.345L/kW.h。

最小干式重量是7795;

最小长度是3349mm;

最大长度是3725mm;

最小高度是1753mm;

最大高度是2091mm;

最小宽度是1703mm;

最大宽度是2053mm。

# 二、7025型挖泥船主机常出现的故障及解决方法

由于7025型挖泥船属非自航船舶，长时间使用过程中船舷两侧的散热管内附着大量的海生物。

造成换热效果不好，特别是夏天容易出现高温报警。

如某航浚7号柴油发电机组冷却方式为海水冷却，CAT3516舷外冷却器，总散热面积12.5m²，使用64个月。

该船在天津港地区使用中发现，当主机负荷超过60%时易发生冷却水高温报警，报警时间点跟潮位、季节、水温、海水清晰度不同而发生变化，特别是高温天气较多的夏季问题更为严重，为了降低柴油机冷却水的温度，经机务部门会同有关专家协商，将舷外两侧的散热片组改为内循环，即由该船内部的压载舱海水对散热器进行冷却。

经改造后在天津港临港高沙岭作业区施工时，主机功率为890~1050kw，水温90℃左右、油温95℃左右,实际测量的冷却液进口温度保持在29-34℃，出口温度维持在75~88℃左右，完全控制在温升范围内，即使是在炎热夏季(室外温度高达27~30℃)，但主机冷却水温度始终控制在标准范围之内，冷却效果良好，达到了预定效果。

机油消耗过大时可能的原因如下:

一是油底壳液位过高。

这时，多余的润滑油会被带入燃烧室烧掉，造成机油消耗量过大;

二是主机曲轴箱内气体压力高于正常值时,会导致主机滑油消耗量过大,即透气管口末端的金属网罩被油垢封堵,致使曲轴箱内气体不能从透气管中排出,引起曲轴箱内压力升高;

三是涡轮增压器和进气管之间的油封密封受损，造成烧机油;

四是气门导管磨损，间隙过大。

气门导管磨损，产生蹿气，用于润滑摇臂和气门的机油就会通过气门导管和气门杆之间过大的间隙进入气缸燃烧，造成机油的消耗量增加;

五是活塞环受损、卡死或折断，不起刮油作用。

正常情况下，曲轴旋转溅起的，用来润滑气缸内壁的机油，常被活塞环刮下流回油底壳。

当活塞环磨损、卡死或折断后，刮油性能下降或不起刮油作用，使机油进入燃烧室燃烧，导致机油消耗量增加。

如某航浚7*、1"主机，在该主机运行至10 000h左右时发现机油压差数值增长过快，约1.3kPa/h，机油消耗率约为8.5Lh。

柴油机的水温(89°±2)、油温(95°±1)、机油、燃油压力(388kPa±5）等数值均在正常范围内。

在对柴油机的运转状态进行查看后，发现排烟总管排烟烟色发蓝,初步判断可能为增压器故障导致烧机油。

随后停机对增压器进行拆检，拆下来的增压器从表面看没有异常现象，增压器的废气端及压气端叶轮正常，且在增压器压气口和进气管没有油迹。

故排除增压器问题。

再次对电子数据及运转参数和工况进行检查，推测可能是柴油机某缸活塞及活塞环或缸套磨损异常导致大量机油进入燃烧室参与燃烧或者是燃烧室窜气导致机油损耗量异常。

经拆解发现，第4缸的活塞头部及缸盖烧蚀异常严重，该缸的缸套磨损也很严重,活塞环已经全部断裂，活塞环槽也不再光滑平整。

结合柴油机的工作状况，分析其原因是:

活塞与缸套之间过度磨损导致活塞与缸壁之间的间隙过大，引起活塞沿缸壁上下运动时发生偏摆。

偏摆的活塞在运动过程中对活塞环产生挤压，造成活塞环与气缸壁的适应性变差，引起活塞环在环槽内发生不规则的轴向、径向运动和扭曲变形,从而导致气缸的气密性下降，最终导致活塞环断裂，对进入燃烧室的机油无法起到刮油的效果，同时燃烧室窜气到油底壳导致烧机油。

CAT3516B型主机机油压力过低时，一般第一步应检查油底壳内油量是否充足，是否存在机油泄漏问题。

第二部检查机油是否有其它油品混入（如柴油）。

当油底壳内有柴油出现时，首先用断缸停油的方法来判断出哪个缸出问题，再者检查问题缸的喷油器是否能够正常工作，如喷油器工作良好，那么就需要检测配气机构的使用情况，方法是通过测量该汽缸的最高压缩压力，进而可以判断该汽缸的密闭情况。

假如是喷油器故障，首先应检查并调试喷油器的耦合件，进而将故障排除。

假如是因为汽缸、活塞环磨损严重超标、活塞环折断、对口、卡死失效故障，须马上对汽缸、活塞环、活塞等进行修理或换新;如果是阀座间隙过大的问题，应调整气门脚间隙，排除故障。
