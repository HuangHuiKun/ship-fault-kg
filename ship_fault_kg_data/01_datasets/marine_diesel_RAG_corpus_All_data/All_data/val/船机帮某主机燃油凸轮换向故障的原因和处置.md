# 一、故障现象

某轮靠泊即将结束，主机由正车换向到倒车时，燃油凸轮位置不正常报警（FUEL CAM POSITION ABNORMAL），同时燃油凸轮位置指示灯不亮，主机控制空气压力较快下降。

立即检查主机燃油凸轮正车换向控制阀（10号），发现泄放孔大量漏气；随即与驾驶台联系，将主机由倒车位置换为正车位置，发现倒车换向空气阀（11号）泄放孔也大量漏气。

所幸当时已可不用车，随即关闭主机控制空气。

# 二、换向装置

该主机换向采用单凸轮式，各缸分别由换向活塞（位移100mm）上的拔叉拨动高压油泵滚轮，使之移动一定角度，实现燃油凸轮换向并自锁（见图1）。

图1 换向装置示意图

换向活塞杆有一延伸段，在高压油泵下部露出，用以指示换向是否到位（正车向前伸出，倒车后缩）。

换向动力是控制空气，正车和倒车，分别由换向空气控制阀10号和11号控制。

正车位置，11号阀通大气，控制空气通过10号阀进入各缸燃油凸轮正车气室，驱动换向活塞位移。

倒车位置，10号阀通大气，控制空气通过11号阀进入各缸燃油凸轮正车气室，驱动换向活塞位移。

控制台设有换向声光报警。

各缸换向活塞组件中有一磁性环，气缸体外部对应于磁性环位移两端装有2个磁性开关。

当换向动作全部完成，即换向活塞位移到位，全部同向（正车或倒车）磁性开关接通并处于“与”状态，主机操纵台上相应燃油凸轮位置指示灯亮。

如果其中任何一缸换向不到位，换向指示灯不亮并发出警报信号。

具体是哪个或哪几个缸换向不到位，需查看主机高压油泵下部换向活塞杆延伸部分的位置。

# 三、处置

靠妥码头，立即查找原因和修理。

根据现象分析，故障部分仅限于主机高压油泵燃油凸轮换向控制部分，即换向空气控制阀10号和11号以及6个缸的换向活塞组件。

逐一关闭1~6缸换向气缸的控制空气，查找泄漏空气出处。当关至第二缸时，漏泄停止。

正倒车盘车，检查其它各缸换向气缸动作均正常，确认No.2缸换向装置故障。

解体No.2缸换向装置，发现换向活塞紧固螺帽松动并全部脱出，造成换向气缸正倒车腔室互通，从而导致正车换向控制阀10号在主机倒车位置时漏气，倒车换向控制阀11号在主机正车位置时漏气。

所有部件，按说明书的要求，清洁涂油，装复，盘车检查，No.2缸换向动作正常。

# 四、几点体会

换向不到位，主机仍可维持运行在50%负荷以下，等到适当时机停车检修，不必紧张失措。

按主机操纵系统的工作时间和服务年限，定期保养所有操纵系统控制阀件（一般每2~3年检查，5年更换易损件）。需备有必要的工具和备件。

组装换向活塞组件上的紧固螺帽，要用专用胶水，以防松动。
