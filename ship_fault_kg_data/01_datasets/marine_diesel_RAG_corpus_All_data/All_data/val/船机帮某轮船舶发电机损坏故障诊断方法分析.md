# 导读

在船舶众多组成设备中，发电机可以说是重中之重，仅次于船舶主机，无论船只在行进中还是在锚泊状态都发挥着重要作用。

因此，如何对发电机进行前期故障预防，故障发生时如何进行快速检测、诊断、和排除，是避免发生重大事故，保证船舶安全航行的关键。

笔者在本文中以一个案例的形式来探讨发电机损坏故障的诊断方法，以便和同行进行相关问题处理方法的交流，避免类似情况的再发生时处理不当造成严重事故。

某起重工程船，主发电机型号：S6U-PTK，功率：1000KW，转速：750rpm。

## 发生故障情况描述

该船在某港口进行起重吊装作业的时候，突然发生主发电机跳闸的情况。

经检查确认，发电机盘车正常，但有少量烧焦味道，经过对主要部件也就是发电机轴承进行温度测量发现，测量温度高于正常温度。

从表面来看，发电机轴承出现异常磨损，轴承下有少量碎片和粉末出现。

# 如何进行故障诊断

解决问题的第一步是要发现问题产生的原因。

通过对故障情形的判断，技术人员对关键部件发电机进行检查后确认了故障原因：

发电机拆机后发现，发电机轴承内的滚珠因为滚珠架的碎裂而产生分布异常，连带导致发电机转子下沉，继而缩小了定子和转子之间的空隙，增大了两者之间摩擦，磨损加重，从而引发短路。

因为故障起因较难察觉，且故障产生时间较短，因故障导致的摩擦产生的异味尚未被值班检查人员发现，系统已经启动自动保护功能，因此出现跳闸。

# 如何进行故障排除

需要更换发电机轴承滚珠架和维修定子绕组，送修理厂进行维修。

修理更换部件后，将原发电机安装至船舶上进行调试，调试结果显示各项使用功能均为正常，各项指标都达到规范要求，本次故障问题得到正确的解决。

# 如何进行故障预防

为了杜绝类似事件的发生，需要分析清楚产生这种故障的原因是什么，以后才能够杜绝类似事件的再次发生。

本次事件，既有发电机组本身结构的问题，也存在人为的技术管理层面的疏漏问题。

因此后期建议从以下几个方面采取防范措施。

(1)本次故障发生和发电机轴承本身结构有很大关系，因此如果可以，提议对发动机轴承进行完善升级，将原有的轴承替换成滑动轴承，就可以从根本上杜绝此类故障的发生。

滑动轴承对于发电机其它组件的适配性更强，对于后期使用过程的维修管理都有益处。

(2)发电机轴承因为其在船舶配件中的地位较为重要，在平时保养使用过程中需要加强对它的维护。

在日常使用过程中，对于发电机轴承保养应当注意以下几点。

①应当按照规定按时对发电机轴承温度进行测量、记录；

②对发电机轴承声音进行倾听；

③按时更换轴承用机油，在使用超过规定时限(本次故障型号发电机一般建议为2万小时)后，需要更换轴承或者更换轴承机油，防止因轴承使用时间过长产生老化造成轴承疲劳和可靠性下降。

同时需要注意的是，对发电机转子、定子需要加强日常维护，保持清洁，定期检查其绝缘值。

(3)除日常检查外，每年需要对发电机按时进行大规模检修。

(4)在确保发电机使用安全的情况之下，将发电机的失压保护值提高。

根据行业操作的基本方法，“当实际使用电压降至额定电压值的70％一35％时(本区间是可以通过设定来确认的)，应经系统选择性保护要求的延时后动作”。

打个比方，一个发电机的额定电压为300v，他的失压保护为65％，也就是195v。

因发电机输出功率和电压值的平方和电流值都成正比，电机实际电压偏低，电机额定输出功率又不变，那就必须提高电流，通过这种方式来满足输出功率的稳定，这就会产生因电流过大导致电动机被烧。

同样，操作规范中规定，“当供电电压下降到额定功率的50％时，逆向功率或者逆向电流不应失效”，因此，提高失压保护值与逆向功率或者逆向电流对发电机自身也起到一定的保护作用。

(5)对于运行中的发电机的温度监控，可以参考其它现有的对于主机进行温度监控的设备，也就是需要给发电机装配可以进行温度实时监测的设备，能够实现对发电机的随时监测。

# 背后的原因探讨

船舶发电机事故的预防工作，关键不是在问题发生阶段，这个时候只能是去处理问题已经对于预防问题于事无补了，相关从业人员应当将工作的重心放在对于发电机的日常管理工作中，也就是要严格按照技术标准在日常管理中对发电机进行检查和维护，确保发电机处于一个比较正常可控的状态，且对于发电机的基本情况有一个总体了解，出现问题的时候才能更快的找出问题症结所在，从而快速解决问题。

这次的事故暴露出来的问题主要有以下几个方面。

(1)船员队伍中有相当数量的外聘人员，这部分人员不仅专业素养不到位，同时也因为工作的临时性质缺乏必要的责任心，在工作中存在消极怠工的现象，因此疏于对设备的监测，更不要说日常的维护和保养。

(2)从大环境上来讲，整个行业都不太景气，大部分公司的经营状况都不是很好，许多公司处于负债经营阶段，公司无法实现盈利或者盈利很少不能满足公司正常运营的费用。

为了使公司还能够维系下去，许多公司“开源节流”，于是将设备的日常维护取消掉了，只是为了减少维护的费用。

(3)值班人员对于异常问题的处理不及时，和监测的频率、方法、细心程度都有很大的关系。

监测人员的工作到位了对于问题能否被及时发现和解决起到至关重要的作用。
