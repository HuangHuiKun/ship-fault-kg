# 导读

文章通过介绍一起船舶使用的意大利进口的依维柯C87ENT M62柴油机故障案例，详细地分析了产生故障现象的原因，并详述了排故过程，供有关人员在实际工作中借鉴参考。

# 一、概述

近年来，海事系统相继配备了一批12米级玻璃钢快艇，主要用于满足海事巡逻、执法、航标巡检、应急反应等需求，其主机采用意大利进口的依维柯C87ENT M62柴油机，匹配新西兰Hamilton(汉密尔顿)喷水推进装置。

机舱机电设备的运行技术参数，在驾驶室操纵台的显示面板上均有显示。

该类型快艇配置的主要机电设备大都为进口设备，设备维修和使用手册等资料相对简单，给船机管理工作带来了困难。

# 二、主要故障现象

该艇在高速正常航行途中，轮机值班人员定期巡视机舱时，突然发现柴油机膨胀水箱中的冷却液没有了，驾驶员立即降低船速。

当时，驾驶台仪表没有故障报警，机器油压正常，水温表显示温度也只有73℃。

轮机值班人员随即仔细观察设备状况，机舱里面没有柴油机冷却液外泄痕迹，船尾排气口略微有冒白烟现象。

停机后检查柴油机机油，柴油机油底壳油位没有升高迹象，油质粘度及颜色正常。

过了一些时间以后，给机器添加冷却液，发现膨胀水箱中的冷却液有明显下降现象，同时油底壳油位逐渐升高。

# 三、故障产生原因

根据故障现象，采用常规的诊断方法，从两方面着手。

一是针对柴油机油底壳油位升高现象进行分析，初步认定可能存在以下原因：

气缸套封水圈损坏而漏水；

气缸套与机体结合面漏水；

气缸套因穴蚀穿孔而漏水；

气缸盖衬垫损坏而漏水；

淡水泵轴密封圈处或封水橡皮圈损坏漏水；

机油冷却器芯子损坏而漏水；

气缸盖裂纹而漏水；

湿式排气岐管故障；

中冷器故障。

二是根据船艇航行中船尾排气口略微有白烟现象，可能存在以下原因：

柴油机气缸盖裂纹；

气缸套穴蚀穿孔漏水；

气缸盖衬垫损坏；

湿式排气岐管故障。

# 四、故障处理过程

该玻璃钢快艇机舱空间极其狭小，人在机舱不能站立工作。

因此，解体柴油机不是一件容易的事情。

本着修理工作先简后繁原则，我们首先拆卸了与排气管连接的废气涡轮增压器，发现了异常现象：

涡轮机叶轮前的涡轮壳凹槽内积有机器的冷却液。

图2 涡轮增压器水套的外壳水密检查

该进口柴油机废气涡轮增压器的结构与以往接触过的涡轮增压器不一样，它的外壳自带冷却水套。

在先前学习过的书本上，没有介绍过这种类型的增压器。

该机设备说明书也未提及该部件结构情况。

我们对拆下的涡轮端带水套的外壳进行了认真检查，并进行了水密试验，发现水套腔体注满清水后其水位明显下降。

由此，判定涡轮端带水套的外壳内腔已经漏水，因此决定更新柴油机涡轮增压器外壳。

之后，船艇经航行试验，该柴油机工作状况恢复正常。

# 五、故障处理总结

1)船艇航行中发现柴油机异常现象时，驾驶台没有出现故障报警，水温表显示温度仅为73℃，是由于轮机值班人员勤于机舱巡回检查，在柴油机增压器外壳水套内部出现裂缝，引发膨胀水箱冷却液漏泄下降，机体中冷却液还未达到高温报警状态时，就被发现异常，然后船艇人员果断采取了合理措施，从而避免了柴油机出现严重的缺水状况；

2)轮机人员在船艇柴油机停车后立即检查油底壳油位，没有发现油位升高现象，是由于柴油机在停车前，涡轮增压器外壳水套漏泄的冷却液随柴油机废气排出了舷外，故船艇慢速航行中船尾排气口发现略微有白烟现象；

3)停车一段时间以后，给柴油机添加冷却液，发现冷却液有明显下降现象，同时油底壳油位逐渐升高，是因为依维柯C87ENT M62柴油机为6缸直列式4冲程涡轮增压柴油机，不管柴油机曲轴停在那一位置，始终会有某缸的排气阀处于打开状态，由于冷却液膨胀、水箱位置较高，新加入的冷却液便通过排气管气道，经开启的排气阀逆向流往燃烧室，而后进入柴油机的油底壳。

# 六、故障案例对船机管理工作的启示

这起柴油机冷却液进入油底壳的故障，是由废气涡轮增压器外壳水套漏泄引起，故障的实际情况与常规的故障诊断分析发生了差异，其原因是对新建船舶进口设备的结构不熟悉造成的。

通过该起故障案例，应清楚地意识到，船舶管理人员和操作人员对新设备使用管理水平，目前还难以与船舶现代化的管理要求相匹配。

仅以以往掌握的知识去管理新的设备，就会显得捉襟见肘。

因此，在今后的工作中，只有不断吸收新的知识，掌握新设备的技术性能、结构特点，才能满足新时代的工作要求。

同时，管理人员的工作责任心，也是避免机电设备出现故障的重要保障。

日常工作中只有全面、细致地做好设备维护工作，才能熟悉和掌握船舶设备的技术状况，及时消除隐患，延长机电设备使用寿命，节约维修费用，保证设备长期可靠和经济运行。
