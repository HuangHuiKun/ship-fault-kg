# 导读

随着航运事业的飞速发展，船舶的周转频率越来越快，尤其是集装箱船舶班期要求十分严格，安全、高效己成为船舶管理中激烈竞争的主旋律，机舱作为船舶的心脏重地，管理工作更具挑战性。

本文以一起主柴油机气缸注油枪胶圈老化引起的冷却水系统故障为例，介绍对此故障的分析思路和排除方法供借鉴。

# 一、故障的形成

某轮为早期建造的集装箱船舶，航区拟为冷带航区。

主机采用日本制造的6UEC37/88H二冲程柴油机，变螺距调节桨;冷却水系统为缸套、油头冷却水混为一体的闭式循环冷却系统（见图1)。

图1

该轮在营运若干年后，出现主柴油机冷却水压力波动且膨胀水柜有油现象。

此时主机常用负荷为85% MCR，冷却水压力波动范围在0.16 ~0.18 MPa之间，(正常情况下该机冷却水压力应稳定在0.18 MPa内)，当然在这种负荷下主机尚能工作。

但随着航运界竞争加剧，要求船速加快，因而主机负荷提高，由原来的85%加至93%，这时冷却水压力波动愈加严重，乃至降到0.1MPa以下，出现低压报警，(低压报警点为0.1 MPa)。

显然一台冷却水泵供水已经不能使主机正常工作，需要增开一台备用泵，尽管如此，冷却水压力还是不能恢复正常，仅能维持在0.12 MP左右，同时还要经常在水泵处进行放气，否则水泵由于吸入冷却水系统中的气而使压力进一步下降，显然这一故障已严重影响主机正常运行,并将可能使船舶停航。

# 二、故障的查找与排除

根据此故障，按照先常规、先简单的原则进行如下分析与排除。

(1) 检查水泵轴封、进口处及管路，无漏气。

(2) 主机运行中分别打开各缸示功阀，燃烧情况正常。

(3) 停车期间，保持冷却水泵运行以建立水压，打开扫气箱门，从各缸扫气口观察，未见漏水迹象，用起动空气冲车未见缸内有水分。

(4) 排除油头冷却水是否有油漏入的可能，设想将油头冷却水分开，(诚然油头冷却水与缸套冷水混为一体严格讲也是不妥的，因为油头冷却水中很难保证没有油漏入，而缸套水中有油是十分有害的，因此也确实有必要应该分开）然而要做到这一点，必须增设油头冷却器，同时还要进行这一系列的改装工程，且不说增设油头冷却器和改装工程需要花不少费用，还得要停航进行，为了不影响船舶正常营运，轮机人员因地制宜地对冷却水系统进行改装，将原油头加热器改造为冷却器，冷却水源就近取自于缸套水进出水管，见图2。

图2

再将油头水柜与缸套水柜连通的各类管隔开，另外再引一路管用作油头水柜的透气和溢流，这样油头水系统就完全独立了。

为了提高油头的冷却效果，将油头冷却水压力整定为0.35 MPa，以提高水流速度，这样做实际运行中油头冷却效果令人满意，油头进口水温65 ℃，出口水温82 ℃，满足该机说明书要求。

但主机故障没有明显改善。

(5) 进一步考虑缸头、缸套是否有裂缝。

无论是检查缸头或缸套故障，都需吊缸，其工作量较大，况且一时又无法确诊哪只缸。

集装箱船周转快，船期紧，倘若所有的缸都进行吊缸检查，时间显然不允许，也是不可取的。

因此采用单缸冷却水与系统水脱开的方法，为此制做了单缸缸头专用出水管，专用出水管上装有两只阀及一只温度表，见图3。

图3

并逐缸试验查找，观察系统水压力波动程度的变化，同时看单缸出水中的含油量。

结果表明，各缸确有程度上的差别，说明故障确系来源于缸套。

(6) 根据柴油机结构进一步分析认为，很可能是穿越冷却水腔的气缸注油枪与缸套连接处的胶圈老化，使得缸套内的高压燃气连同气缸油一起倒冲入冷却水中。

于是决定抽拔各缸气缸注油枪，更换胶圈，故障得以消失，很显然故障原因确系气缸注油枪胶圈老化所致。

# 三、故障原因分析

故障排除后，对该船柴油机气缸注油枪胶圈老化的原因分析认为，胶圈老化除了质量问题和使用时间超过允许时间极限外，冷却水温差太大，水质处理不当，尤其是水中长期带油运行是造成胶圈老化的主要原因。

# 四、管理中注意事项

(1) 油头冷却水与缸套冷却水必须分开，以避免缸套水中混油;

(2) 缸套水必须经常化验，投药处理，保持水质正常;

(3) 克服冷却水温度忽高忽低的现象;

(4) 停车时保持水泵继续运行半小时以上;

(5) 停车期间保持副机冷却水经主机暖缸。

采取以上管理措施后，该船主柴油机冷却水系统运行一直正常。
