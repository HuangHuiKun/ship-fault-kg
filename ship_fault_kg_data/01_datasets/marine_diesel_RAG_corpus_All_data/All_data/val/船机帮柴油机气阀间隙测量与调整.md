# 导读

应多位读者朋友要求，小通将柴油机如何调整检测气阀间隙的相关内容分享给大家。众所周知，任何品牌的柴油机在组装好后或配气机构检修后，都要进行检查和调整各气阀间隙；柴油机在工作过程中，由于配气机构各零件的磨损及调整螺钉的松动，都会引起气阀间隙的变化，所以定期检查和调整柴油机各缸的气阀间隙是柴油机的日常维护使用过程中必不可少的一个环节。

# 气阀检查调整的方法

下面我们以6170系列柴油机左机左转为例，跟大家分享一下具体方法。

## 第一种：逐缸调整法

我们首先将各缸的汽缸盖罩壳拆开取下，然后按照柴油机曲轴的工作转向去顺向转动飞轮，注意观察靠近飞轮的第六缸进排气阀的推杆，当发现两推杆同时上下移动时，就表示第六缸处于进排气阀重叠角的状态，这时我们停止盘车。此时第一缸活塞处于压缩冲程的过程，进排气阀都处在关闭状态。这时我们由此判定，即可用塞尺检查和调整第一缸进排气阀间隙。有关于气阀间隙的具体参数要求详见您的柴油机使用手册或者说明书。

判断气阀关闭和开启状态的方法还有以下两种：

1. 我们可以通过高压喷油泵泵体上的直槽观察孔，打开丝堵后进行顺向盘车能够观察到油泵柱塞或导程筒正在上行的过程中，这时油泵对应的该缸气阀处于关闭状态，这是我们来判定从第一缸或者第六缸进行检查调整。

2. 我们还可以打开机体侧面的凸轮箱盖板观察顶柱滚轮落在凸轮基圆上，气阀处于关闭状态。这是我们来判定从第一缸或者第六缸进行检查调整。

通过以上两种方法判定好第一缸或者第六缸的气阀处于可调整状态之后，按照柴油机发货顺序（1-5-3-6-2-4）可检查下一可调整汽缸的进排气阀间隙。在飞轮转动两圈内可按顺序完成对六个气缸的进排气阀间隙的逐缸检查和调整。

## 第二种：两次盘车调整法

我们来顺着柴油机的工作转向盘车转动飞轮，使第一缸活塞处于压缩冲程的上止点附近；其判断方法与逐缸调整法第一步相同，在观察高压油泵第一缸油阀和第六缸油阀的供油瞬间来判定第一缸或是第六缸处于气阀进排气可调状态。（此办法建议我们用一根手指按压住第一缸或是第六缸的油阀口进行感知判定较为准确）同样是按照柴油机发货顺序（1-5-3-6-2-4）的原则在飞轮转动两圈内可按顺序完成对六个气缸的进排气阀间隙的检查和调整。

通俗点来讲就是：

自第一缸开始检查调整六个汽缸的顺序依次是进排、进、排、进、排；自第六缸开始检查调整六个汽缸的顺序依次是排进、进、排、进、排。无论先从第一缸还是第六缸进行检查调整，依次调整好各缸气阀间隙后，第二次盘车转动飞轮一圈（360˚）即可进行第二次的顺序调整。

对于大多数般六缸柴抽机来讲，我们可以遵循“前进后排、本缸调进排”的原则完成整机的检查调整过程。具体方法是：按各缸发火顺序进行，先于发火的缸号可以调整进气阀间隙；后于发火缸的缸号可以调整排气阀间隙，正在发火的气缸，进排气阀均可调整；进排气阀在重叠角的气缸，进排气阀均处于不可调整状态。

# 调整过程中工具使用方法

小通建议选用梅花扳手和螺丝刀搭配使用，将摇臂端的调节螺栓上的锁紧螺母旋至松动状态。

用柴油机具体规定的气阀间隙厚度的塞尺插入摇臂与气阀杆头部之间，用螺丝刀拧动调节螺钉，同时往复拖动塞尺，当塞尺移动感到稍有阻力但又不太紧时，表示间隙值合乎该款柴油机规定的气阀间隙要求。然后用螺丝刀止住调节螺钉进行定位，使之不能转动，把锁紧螺母拧紧，再拖动塞尺复验一下松紧程度是否有变化，直到完全合格为止。
