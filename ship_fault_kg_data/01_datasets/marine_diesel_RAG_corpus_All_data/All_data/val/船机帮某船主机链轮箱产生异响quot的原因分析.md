# 导读

主机的凸轮轴与曲轴通过链条连接并实现传动功能，链轮是用螺栓固定在推力块的一侧，链轮传动是通过张紧的链条和支撑长链条的导轨来实现的。

为了达到良好的机械运转效果，润滑冷却是必要的。

某船厂承建了一艘82000 DWT远洋散货船，该船主机为MAN B&W 6S60ME-C MK8.1低速柴油机，额定功率14280kW,额定转速105 r/min。

该船在航行试验主机磨合阶段,轮机员在机舱底层巡查中监听到自由端链轮箱发出明显的“异响”，怀疑内部有机械磨损，于是马上停车进行检查，经服务工程师确认没有发现任何异常，再次启动主机，声音依然存在。

根据船东监造组的意见，为了船舶安全可靠性,主机厂家邀请了MAN Diesel & Turbo的工程师上船进行检查，得出的结论是“链轮箱内部件的安装满足MAN B&W的相关技术要求，声音来源于链轮和滚珠的磨合，是二冲程柴油机运行中的正常声音”。

基于上述检查的结论，船东同意在专家监控下进行主机后续项目试验，但要求返回码头后彻底消除异响。

顺利完成主机航行试验项目返回码头后，船厂再次邀请工厂、主机厂等的技术专家进行诊断，基于航行试验数据均满足技术要求，且安装检测数据也满足标准，均认为声音不会影响船舶主机性能。

但考虑到船东的强烈要求和完工交船事宜，主机厂提出以下方案:

(1)再次邀请MAN的专家上船对主机前链传动系统做全面的检查，对主机的声响进行评估。

如MAN专家发现主机质量有问题，则必须做相应的修正;如MAN专家认为该声音为正常的声音，船东则认可这个结果;

(2)邀请船东代表到主机制造工厂对其它正在台架磨合试验的MAN主机进行实地考察和调研，以确认这种声音是链轮链条正常的啮合声音;

(3)安排对前端链传动系统的所有零部件进行拆检，根据图纸对部件的尺寸进行确认，对不符合图纸的部件予以修复/更换。

如所有零部件经检查符合技术要求，而重新装复后该声音依旧存在，船东能够认可这个结果;

(4)对该前端链条延长适当时间的保修期。

但船东坚持该声音必须消除，主机才能接受，理由是系列其他船主机前端链传动并没有这种声音。

# 一、初步处理方案

基于该系列其他船主机的运行监测结果无类似声音和满意客户要求的宗旨，船厂坚持消除船东的疑虑，于是结合MAN专家、船厂与主机厂家的综合研究意见，实施了以下具体处理方案:

## 1、重新检查链轮箱附件安装状态及数据

(1)扭振装置的可视检查:打开检查盖观测弹篑装置正常位置，且泄放油孔处于塞紧状态，减震装置的功能状态良好;

(2)自由端链条张紧度检测:链条的张紧必须根据MAN B&W的相关技术要求，因此实施的范围是有限的。

根据经验，在理论参考值压紧弹簧±3mm范围内可接受，而张紧力应该在理论值16500N ( 弹簧标识长度为242.4 mm)附近，实测弹簧长度为242.0 mm,弹簧张紧力适中;

(3)链轮导轨平行度检查:根据推荐的安装要求，导轨与链条的橡胶压缩量要求控制在0 ~2mm内,实测数据在规定范围内，满足技术要求;

(4)平衡重块的安装检测:

平衡重块根据规格书安装间隙为0.2-0.5 mm，而实际安装数据在0.25-0.45mm间，完全符合要求。

连接在机架上轴的拉紧力矩也根据规格书830 N.m进行了重新校核;

(5)链条运行痕迹检查:通过检查连接曲轴、平衡轮、偏心轮的链条表面痕迹，链条齿牙两侧有相同尺寸和形状的运行痕迹，链条的运行完全处于正常条件，同时没有发现链条有任何缺陷。

通过上述系列检查后重新运行主机，异响未能消除，可以排除安装精度问题。

## 2、更换首部链轮箱内全部零部件

更换全部零部件后零部件的安装数据满足MAN B&W的相关技术要求且试验结果表明，主机前端链传动系统的声音与零部件更换前该系统发出的声音基本相同，证明零部件的质量与安装不存在问题。

## 3、调节链条张紧力

船东代表建议通过对链条的张紧度做多次调整试验进行筛选，以求链条链轮啮合传动达到最佳状态。

通过将链条的标准涨紧弹簧长度由242mm分别调整至244.5 mm、243.5 mm、240 mm、242.5 mm的长度，分别做了动车试验，试验结果再次表明，啮合的声音仍然存在而且基本相同。

考虑到链条过度地涨紧和松弛都会对主机零部件造成有害的影响，没有做进一步调整。

# 二、原因分析及初步结论

关于产生“异响"的原因通过系列的检查和排除，始终没有找到满意的答案。

表面上看，整个处理过程是合理的，异响的产生无外乎来货质量和安装质量两类,系列的排查也仿佛证明了专家的意见:响声是零部件正常磨合的声音。

但船东专家在现场体验的结果还是有所犹豫。

于是，专家对更换的零部件进行了结构分析，认为声音是链轮滚珠在运行过程中串动产生。

# 三、“异响”的消除

结合众多技术专家的分析意见，在准备提交最终检测书面意见时，一个现场服务工程师不经意的提醒了一句:

既然设备与安装都没有问题，那为何不从管路上检查呢?

正是这一提醒，在经过对链轮箱内部管子的布置进行检查和效用时，发现链条扫气箱侧的喷油嘴没有正对链条，而是直接喷在链条的外侧。

为此，现场马上对喷嘴方向进行了调整，重新动车运行，则“异响”完全消除了。

由此可知，原来是管路的布置走向引起主机链轮箱内部异响，那么是什么原因导致专家进入误区迟迟没有找到原因呢?

这主要是因为:

(1)链轮箱的管路主要是滑油管，一定油压的滑油主要有润滑和降温的作用。

由于内部喷头布置多没有指定集中点，运行过程中注油效果是通过温度来监控的，所以安装没有对管路布置提出明确技术要求。

(2)此“异响”是有规律的，且各项安装与性能指标没有异常，因此主观认为是正常的，且有权威技术专家的书面意见。

(3)在内部运行检查时，由于整个箱体内均有油气且机械零部件润滑状态良好，加上潜意识中机械声音应该是零部件的摩擦所致，仅仅从安装上进行了核查，缺乏进一步的分析。

# 四、结束语

一个小喷头布置的不合理导致主机如此繁琐的拆检处理，这是一次损失，但更是一项宝贵经验。

根据上述分析，对于主机的安装，只要各安装数据满足相关技术标准，且功能检测符合工艺技术要求，则可以认为主机的正常运行不会受到明显的影响。

但是我们更应该认识到，主机的任何零部件都有着存在的合理性，非核心部件的布置同样会影响主机综合性能，今后应进一步理解主机的结构布置与安装要求。
