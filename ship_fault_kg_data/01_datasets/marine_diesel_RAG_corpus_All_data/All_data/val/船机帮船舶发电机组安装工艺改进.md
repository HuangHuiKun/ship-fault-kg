# 导读

船舶发电机组的安装质量直接影响其运行可靠性，为此船检规范或设备厂商对在建船舶发电机组的安装提出严格的安装检验要求。

为有效减振，大型船舶发电机组一般采用弹性支撑来承载发电机组重量，弹性支撑通过调整垫块与船体基座相连接，用于补偿船体基座的水平误差，也用于调节各个弹性支撑的压缩量，以确保各弹性支撑变形符合厂商要求，船体基座和调整垫块需专门拂配，耗费现场打磨工时。

此外，调整垫块厚度与弹性支撑压缩量及船体基座高度有关，一般需在吊装发电机组后进行反复的厚度试凑与拂配，劳动强度大，工时长。

另一方面，发电机组吊装后施工空间狭小，工装不易摆放和操作，进一步增加施工难度。

因此，发电机组安装是船舶舾装的难点之一。

有学者研究了发电机安装变形对其性能的影响；

有学者提出在吊装发电机组后直接测量弹性支撑的压缩高度，并通过简单计算确定调整垫块的补偿厚度，减少了人工调整和测量的工作量；

有学者将激光测量技术应用于大型水轮发电机组的安装测量工作中，一定程度上提高安装工作效率；

有学者通过有限元对弹性支撑压缩量的影响因素进行了分析。

本文针对船舶发电机组常规安装工艺过于依赖工人技术、效率低、过程繁琐等问题，利用发电机组基座平面度测量及弹性支撑压缩量计算等手段，在吊装船舶发电机组前就预先确定调整垫块厚度，形成新型发电机组安装工艺，并通过实际应用评估其施工效果。

# 一、船舶发电机组的安装要求和常规安装工艺

## 1、安装要求

在船舶发电机组安装过程中，有以下安装要求。

1) 为保证发电机组底座处于同一平面，柴油机曲轴拐档差须满足规定冷态范围内的要求。

2) 为避免弹性支撑长期工作在不良工况，发电机组弹性支撑压缩量及载荷应处于合理范围。

3) 为防止弹性支撑与垫块之间相互干涉，弹性支撑螺栓与垫块之间的间距应适当。

## 2、常规安装工艺

船用柴油发电机组安装的常规工艺流程图见图1。

图 1 常规安装工艺流程

在基座拂配完成后，首先在工装支撑下进行发电机组吊装，之后对调整垫块的尺寸进行确定，由于调整垫块尺寸必须基于吊装完成后弹性支撑与基座之间的实际间隙，因此，调整垫块尺寸确定需要在发电机组吊装完成并静置 48h后进行。

其次，弹性支撑与船体之间的实际间隙需要利用工装弹性支架调整弹性支撑压缩量，期间需要工人进行多次反复调整和测量，直到压缩量满足要求。

最后，根据弹性支撑与基座之间的实际间隙对调整垫块进行加工、拂配和安装。

在常规安装工艺中，调整垫块尺寸确定阶段的操作尤为繁琐。

首先，确定调整垫块尺寸环节需要明确每个弹性支撑的压缩量，这一过程的难点在于弹性支撑压缩量调整环节，各个弹性支撑是相互耦合而非相对独立，调节其中一个弹性支撑的压缩量时，其余弹性支撑的受力会受到影响，从而导致整个发电机组安装姿态发生改变，这使得整个调整过程耗时耗力，弹性支撑压缩量的调整需要反复进行才能使压缩量满足要求。

其次，现场实际安装过程中，还需要通过调节每个弹性支撑底座上四个紧固螺栓来控制发电机组的水平度和垂直度，以及让弹性支撑底托面与船体基座留有一定的间隙空间。

最后，弹性支撑与船体基座之间的间隙高度的数据需要反复使用外卡钳取点测量，并借助千分尺读取卡钳测量的数值。

此外，由于发电机组的重量和尺寸通常较大，导致船舶甲板上的施工空间狭小，在现场收集数据和加工调整垫块的困难程度增加。

从吊装发电机组到测量垫块数据再到加工完垫块的整个过程通常占据了发电机组安装工期的 70%，且过于依赖工人的经验和技能。

# 二、船舶发电机组的新型安装工艺

新型安装工艺见图 2。

图 2 新型工艺安装流程

调整垫块厚度通过测量基座平面度和计算所有弹性支撑压缩量两个前置步骤直接确定，简化了常规工艺中需反复进行的垫块调整和测量工序，消除了因耦合关系引起的垫块厚度确定难度；调整垫块加工、安装工序前移至吊装发电机组前，降低了因吊装发电机组导致的操作空间狭小而带来的操作难度；吊装发电机组及静置工序后移，减少对辅助工装的依赖。

## 2、船体基座平面度测量

船体基座平面度测量可采用瑞典 DamaliniAB公司制造的 Easy-laser 激光几何测量设备。

该设备包含激光发射器、激光接收器及显示器三个部分，其主要依赖于激光技术、图像处理技术及最小区域算法得到基座平面度。

首先建立坐标示意图(见图4)，每个待测点都有相应坐标(X i ,Y j )，其中( i =1,2,3,4; j = 1,2,3,…,8)。

该设备在使用前需要将激光发射器固定在某一位置不动，并将激光接收器依次放置在被测范围区域内三个不同角度的位置 1、位置 2和位置 3 处，确保光束能够打到激光接收器上，激活发射器内置的最小区域算法计算出理想平面。

接收器将这些光信号经过转换和处理，转变为数字信号，显示接收所有信号并显示出高度信息，测量过程中显示器反馈的高度值都是该被测点与理想平面相比较得出的结果。

# 四、结论

1) 利用发电机组基座平面度测量和弹性支撑压缩量计算，提出了一种新型船舶发电机组安装工艺，通过实例验证其可行性和有效性。

2) 新安装工艺缩短发电机组安装周期，较常规工艺工期缩短了 58%，同时降低安装工人技能的要求，避免了工装使用。

3) 本文所提出的新工艺并不局限于船舶发电机组安装，也可为其它有垫片调整的船舶设备安装场合提供参考。
