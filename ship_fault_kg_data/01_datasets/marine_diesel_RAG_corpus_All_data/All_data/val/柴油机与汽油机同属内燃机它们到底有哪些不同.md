# 什么是内燃机

内燃机是通过燃料在机器内部燃烧将其热能直接转换为动力的一种动力机械，通常所说的内燃机是指活塞式内燃机，常见的有柴油机和汽油机。

蒸汽机就是一种外燃机，它利用燃料燃烧加热循环工质（如水）使热能转化为机械能。

# 柴油机和汽油机的区别

汽油机是火花塞点燃的，工作时进行的是奥托循环；柴油机是压燃的，工作时进行的是狄赛尔循环。二者看似一字之差，实际千差万别，是两种截然不同的工作方式。

# 柴油机的工作原理

柴油机是采用压缩发火的方式使燃料在缸内燃烧，以高温高压的燃气做工质在气缸中膨胀推动活塞往复运动，并通过活塞——连杆——曲柄机构将住复运动转变为曲轴的回转运动，从而带动工作机械。

记住两点：压缩点火；一个工作循环历经：进气、压缩、做功和排气这四个过程。

# 柴油机的分类

柴油机的分类方式有很多种，按照不同的分类方法可以分成不同的类型，咱们先看几种常用的分类方式。

# 四冲程与二冲程的区别

四冲程柴油机，活塞走四个行程完成一个工作循环，曲轴转2圈；二冲程柴油机就比较牛啦，曲轴只需转1圈，活塞走两个行程就完成一个循环啦！

相对而言，二冲程机油耗高、排放差，各有优缺点吧。

# 柴油机常用术语

冲程，也叫行程，是活塞从一个极限位置到另一个极限位置的距离，要理解冲程就要了解柴油机的几个常用术语。

上止点：当活塞向上运动到最高位置，即活塞顶部距离曲轴旋转中心最远的极限位置

下止点：当活塞向下运动到最低位置，即活塞顶部距离曲轴旋转中心最近的极限位置

曲柄半径：曲轴旋转中心到曲柄销中心之间的距离

活塞行程：上、下止点之间的距离

气缸工作容积：活塞在上下止点间运动所扫过的容积

气缸总容积：活塞位于下止点时，其顶部与气缸盖之间的容积

燃烧室容积：活塞位于上止点时，其顶部与气缸盖之间的容积

压缩比：气缸总容积与燃烧室容积之比

# 柴油机的总体结构

柴油机虽然大小各异，形态万千，但一般柴油机都是由运动件、固定件、五大系统及其它附件构成。

运动件：活塞组、连杆组、曲轴飞轮组、齿轮组等

固定件：机体、机座（油底壳）、气缸盖等

五大系统：滑油系统、燃油系统、冷却系统、进排气系统、操纵系统

# 柴油机的主要技术指标

评价柴油机的好坏主要看这几个技术指标：

动力性指标：功率、转速、平均有效压力、活塞平均速度；

经济性指标：燃油消耗率、机油消耗率；

重量和外形尺寸指标：如比重量；

排气污染指标：目前船机执行的是IMO（国际海事组织） TⅡ和国一（GB15097 一阶段）。

# 柴油机命名

船用柴油机的命名不像汽车发动机的命名花样那么多，一般都是由数字和字母构成，汉字命名鲜有。

为了便于内燃机的生产管理和使用，国家标准《GB/T725－2008 内燃机产品名称和型号编制规则》中对内燃机的名称和型号作了统一规定，但是由于这个标准是推荐标准，不是强制标准，所以各生产厂家并不一定按标准执行。
