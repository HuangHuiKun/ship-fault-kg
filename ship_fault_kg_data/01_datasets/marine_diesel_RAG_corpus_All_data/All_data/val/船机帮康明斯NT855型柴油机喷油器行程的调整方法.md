# 燃油供给系统结构

重庆康明斯NT855型柴油机在船舶领域大多用于小型船用主机、辅机发电动力及砂泵传送动力等，该柴油机采用齿轮泵低压供油、喷油器高压喷射的PT燃油供给系统。

齿轮泵将燃油输入喷油器，当柴油机凸轮轴（与柴油机进、排气门共用1个凸轮轴）转动时，通过顶杆、调整螺栓和摇臂顶动喷油器针阀，将喷油器内燃油喷出。

喷油器工作原理如图1所示。

PT燃油供给系统每个工作循环的供油量取决于进入喷油器内的燃油量，进入喷油器内的燃油量取决于低压油路向喷油器内供油的压力，以及喷油器进油口计量孔打开、关闭的时间。

PT燃油供给系统第1个字母P代表喷油压力（Pressure），第2个字母T代表喷油时间（Time）、PT燃油系统通过压力和时间的协调配合，使燃油喷射正时和燃油供给量满足柴油机各种工况的需求。

喷油器进油计量孔打开、关闭由其针阀控制，调整喷油器针阀行程，使计量孔打开、关闭时间达到维修手册要求，即可保证该柴油机燃油供给系统的供油量。

# 喷油器行程调整方法

PT燃油供给系统喷油器行程调整力一法包括常规和简易2种，如下所述。

## 常规调整方法

PT燃油供给系统喷油器的针阀由摇臂推动，摇臂尾端设有行程调整螺栓，摇臂、行程调整螺栓位于柴油机气门室处，通常喷油器与气门间隙同时调整，如下图所示。

该柴油机前端的传动胶带轮上设有A、B、C标记，齿轮室盖上设有箭头，喷油器要按照这些标记逐缸进行调整，如下图所示。

先顺时针转动柴油机曲轴（从柴油机前面观看），当看到胶带轮上标记与齿轮室盖上的箭头对准时，可对喷油器和进、排气门进行调整。

相关标记对正时，喷油器行程调整和气门调整顺序如下表所示。

喷油器行程调整和气门调整顺序

以A点对准为例，可调整Ⅲ、IV汽缸喷油器行程及V、 Ⅱ汽缸进、排气门间隙。

常规调整方法需根据喷油器型号，选用康明斯NT855型柴油机专用百分表进行调整。

调整方法如下：

首先，将百分表测点放在喷油器顶端的摇臂处。

其次，拧动调整螺栓使喷油器针阀下降至最低点，直到喷油器摇臂行程达到规定值（5.79±0.01）mm，即针阀的行程为（5.79±0.01）mm，再将行程调整螺栓锁紧螺母拧紧，拧紧力矩为40～45 Nam。

再次，手动将摇臂上、下摆动2～3次，检验调整的行程值是否正确。

然后，转动柴油机，找准下1个汽缸喷油器行程调整位置，按照以上方法调整该缸喷油器行程。

再依次循环调整所有一喷油器的工作行程。

最后，启动柴油机，运转20min后，拨动加速杆，观察柴油机运转情况，若运转正常，调整即可结束。若运转不正常，再视情况重新调整。

这种调整方法在专用百分表齐全或在维修车间内调整较为适宜，如果没有专用百分表则无法调整，在野外维修作业条件差，在调整过程中较易将油泥污垢掉入柴油机配气室内，调整质量也不能保证。

## 简易调整方法

根据在实践中总结出简易调整方法如下：

转动柴油机，将传动胶带轮上的A、 B、C标记与齿轮室盖上的箭头对准后，辨识并确定喷油器行程调整顺序。

当确定某个汽缸可以调整行程时，用扳手将该汽缸喷油器行程调整螺栓的锁紧螺母拧松，用平口改锥将行程调整螺栓向下拧（顺时针旋转），使喷油器摇臂压动喷油器针阀向下运动。

当该汽缸调整螺栓拧到底后（即针阀落入针阀座底部），再将调整螺栓拧紧至20～30Nom。在调整螺栓端面外沿做1个记号，用平口改锥将调整螺栓逆时针旋转2 1/2～2 3/4圈。用扳手拧紧锁紧螺母，即可完成该喷油器行程的调整。

将调整螺栓逆时针旋转2 1/2～2 3/4圈是基于喷油器摇臂结构经计算得出的，摇臂结构如图3所示。

经测量，喷油器行程调整螺栓为美制细牙螺纹（UNF），该调整螺栓的螺距为每英寸20牙，折算成公制为牙距为1.27mm，若旋转调整螺栓2省圈，其行程尺寸为3.175mm。摇臂轴至行程调整螺栓的距离为40.75mm，摇臂轴至喷油器的距离为74.25mm、 2去圈调整螺栓行程折算到喷油器针阀行程为5.79mm。

用平口改锥将调整螺栓逆时针旋转2 1/2～2 3/4圈，可保证针阀的行程达到规定值（5.79±0.01）mm。

将调整螺栓拧到底后（针阀落入针阀座），再将调整螺栓拧紧至20～30 N·m，是为了将喷油器阀体空腔中的燃油挤压干净，使针阀确实落入针阀座。

在调整螺栓端面外沿做记号是为了反向旋转调整螺栓时做参照，防止多拧或者少拧行程。由此可知，这种调整方法可以满足喷油器行程调整需要，调整的量符合维修手册要求。

该简易调整方法，可缩短维修时间，提高维修质量，减少所需工具器械，维修人员经过简单培训就可掌握该调整方法。
