# 导读

滑油的主要功能是防止运动部件直接接触，减少摩擦，对运动部件起着密封、冷却、防止腐蚀等作用。

因此滑油质量直接关系到机械设备的安全运转。

所以船舶在营运中，轮机管理人员要密切关注柴油机润滑油的油质变化，定期对系统滑油进行检验，了解滑油的质量变化，从而掌握柴油机运转情况。

在影响滑油质量的各种因素中，滑油清洁是其保证机械设备正常运转的必要条件之一。

据统计，机械设备的故障有50％以上是由于润滑油污染而造成的。

作者曾碰到一起主柴油机润滑油系统中混入水份，造成柴油机振动和部分构件损坏的案列。

# 一、案例

某新造首制船从船厂开航前往秦皇岛港，该轮主柴油机型号为5S60ME，额定转速97r／min。

途中主机加速到75r／min时，整个机舱及船体开始出现振动，之后随着主机转速增加振动情况也随之加剧，同时主机带动凸轮轴的链条 (柴油机链传动机构 )处出现较大的敲击声，当主机加速到85r／min时，由于振动，主机1、4、5缸缸盖冷却出水管相继发生破裂，修理后主机开到71r／min至秦皇岛港。

翌日主机厂家对碎裂的链条导轨进行了更换，该轮继续航行到另一目的港黄骅港。

在航行过程中振动加大，停车检查发现减震器轴与轴套磨损严重，主机厂家的技术人员上船后更换了减震器轴与轴套，对减震器轴跳动量调整至满足规定范围值。

修理完后，该轮前往下一目的港上海港，在航行过程中，当主机加速到97r／min时，工作正常。

翌日主机又开始发生振动，此时主机转速 90r／min，振动更加严重，呈现有主机敲缸的情况，主机突然停车。

经检查发现主机角度编码器轴松动，重新拧紧后继续行驶，主机依然振动，抵达目的港后，主机厂家技术人员上船拆开角度编码器检查，发现轴与轴套磨损，更换了进油轴与轴套，并对进油轴及角度编码器轴进行调整对中后满足要求，主机厂家技术人员随船进行航行试验，主机振动问题依然存在。

最后船东联系主机厂家、船厂及验船师一起对该故障进行了分析，从上述过程来看，每个问题的出现都伴随着主机振动，究其原因，一致怀疑是滑油的问题。

最后更换全部主机滑油，主机振动消失，船舶状况良好。

# 二、原因分析

通过对主机滑油进行取样分析，该轮主机润滑油含有水分，但实船的船员并没有发现该轮滑油循环柜的油位出现明显的上升，也没有发现主机膨胀水箱的水位出现不寻常的下降，说明滑油系统中含有水分但进水量不是很多。

从柴油机出现的上述振动情况来看，柴油机振动时好时坏、振动时大时小，此时主机滑油情况也是时好时坏，滑油质量情况与柴油机振动时大时小相关联，主机滑油时好时坏的情况以及滑油检测结果说明滑油中的水分分布的不均匀，滑油中水分进入主机则出现主机振动情况，滑油中水分没有进入主机则主机运行平稳。

其次，柴油机没有出现拉缸等情况，没有造成严重的影响，对主机润滑油进行分析，再一次证实润滑油进水量不多且分布不均匀。

船东、船厂和主机服务商并没有发现有漏水的情况，船舶自换完滑油以后，情况良好，没有出现振动情况。

综上所述，该轮滑油系统中含有水分的情况唯一可能是由于该轮在建造过程中由于工人的马虎使水流入滑油舱，在对滑油系统注入滑油时船厂也没有发现系统中存在水分，从而使滑油中含有少量水分产生上述振动结果。

# 三、后续船预防措施

鉴于首制船出现上述振动且造成柴油机部分构件损坏的情况，在后续姊妹船的建造过程中主要从以下几个方面来重点检验：

## 1、滑油冷却器的检查

该主机滑油冷却器采用海水冷却，冷却器管内流动的是润滑油，管外流动的是海水，正常航行时由于滑油压力大于海水侧，水不会流入到滑油系统，当停航时，润滑油泵停止工作，润滑油冷却器海水泵虽然停止工作，但由于海水静压也有可能使海水通过损坏的冷却器管束渗入滑油。

现场进行建造检验时，须重点查看滑油冷却器是否有损坏，是否有滑油泄露的情况。

## 2、活塞杆填料函检查

连杆填料函是安装在气缸体底板 (或称横隔板)中心孔内的密封装置，具有密封气缸扫气空气、刮除连杆上的油污和将气缸与曲柄箱分隔开的作用。

如气缸缸套、缸盖或扫气箱漏水，填料函密封又不好，可能会导致水漏入曲拐箱。

在进行完航行试验以后，进行抽缸检验时，重点对连杆填料函进行检查，检查其周围情况和密封情况，是否有水的迹象。

## 3、滑油舱检查

在对滑油循环舱进行水压试验时，如在其四周设有隔离空舱，打开隔离舱的人孔门，观察是否有水渗出。

并且确保对隔离舱进行封舱时没有水，对循环油柜测量管、透气管进行校验时核查是否有水进入的可能性，现场进行检验过程中严格按照上述要求进行，均不应发现异常。

## 4、滑油管系的检查

在进行润滑油管系密性试验的时候，对润滑油管系和法兰连接处、垫片进行检查，查看是否有泄漏的地方。

同时，当进行航行试验时再重新对润滑油管系和法兰连接处、垫片再次进行检查，尤其应关注舱底部分的润滑油管系。

## 5、滑油分油机检查

在对滑油分油机进行交验以及航行试验中重点关注以下内容：

首先检查滑油分油机的蒸汽加热器，启动滑油分油机。

拆开蒸汽加热器端盖，检查蒸汽加热管束是否有油漏出，如有油漏出说明蒸汽加热管束有泄漏，如没有发现有油泄漏，说明蒸汽加热器工作正常；其次检查滑油分油机工作是否正常及是否有水跑入油中。

核查滑油分油机工作时高置水柜内的水是否明显减少，同时要求船厂对分油机净化后的滑油进行化验，看是否是满足要求，最后对分油机去主机循环油柜各管系和阀门进行检查，核查管系是否有损坏和泄漏的情况。

# 四、避免产生润滑油脏污

主滑油系统进水或脏污将造成柴油机配合件的磨损，加剧和其它故障，如造成主轴承、十字头轴承、连杆大端轴承和各种轴承的损伤和轴颈的磨损，破坏润滑油膜，引起抱轴、拉缸等故障发生。

因此，船厂应严格按照施工工艺进行建造检验，增加现场的巡检频率，同时要求船厂对此项工作制定专门的方案，从造船角度来消除柴油机滑油进水的可能性。

另外，鉴于主滑油系统进水或脏污所造成的严重后果，在后续的营运过程当中应注意柴油机滑油的管理，可从以下几个方面进行考虑：

1) 让船员从思想上引起重视，特别是对于老旧船舶，机舱人员认为小漏很正常，没有引起大家足够重视，结果会酿成很严重的后果。

2) 大型船舶柴油机的滑油泵、分油机、滑油冷却器等设备体积大，结构复杂，船员很少对其内部进行维护保养。

平时，只进行外部的检查，看有没有泄漏，已经使用几年而没有对其进行内部检查，容易出现故障。

加强对设备维护保养，定期对柴油机重要部件进行内部检查。

3) 在柴油机运行中，如若发生故障应立即进行降速处理，避免造成更大的损失，在没有排除故障之前但又必须航行的情况下，应始终注意润滑油压力的变化，柴油机各运行参数的变化，确保其能够处于安全状态。

# 五、结束语

柴油机润滑油进水或脏污对柴油机部件都会产生一定的危害。

轻则缩短滑油的使用寿命或加剧润滑部件的机械磨损，重则会造成机损或发生爆炸等重大事故。

本人从建造的首制船营运过程中出现的柴油机润滑油进水进行分析，总结出后续姊妹船建造检验有关问题的预防措施，同时也提出了对营运中船舶滑油系统的维护建议。
