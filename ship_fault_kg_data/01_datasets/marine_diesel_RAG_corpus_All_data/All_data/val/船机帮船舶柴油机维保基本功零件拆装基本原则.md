# 船舶柴油机维保基本功零件拆装基本原则

船舶柴油机运转一段时间后要定期进行保养检修，必须要按正确的程序进行拆卸、清洁、检查和修理。

拆检工作的好坏，直接影响修理成本、修理周期和修理质量。

如果拆卸操作不正规，技术不熟练，把本来不需要拆卸的零件拆了下来，甚至将零件损坏，这都会给修理工作带来麻烦，影响修理进度。

如果装配不当，还可能使机器产生严重的故障。

特别是远洋船舶轮机工作人员，要在远离陆地、人员少、备件和物料不能及时供应、海洋气候恶劣等条件下，完成紧急拆装检修任务，保证船舶安全正常航行，必须具备熟练的拆装基本功。

今天我们讲讲关于零件拆装的基本原则。

为了保证拆卸质量、避免拆卸不当，拆卸时应遵循下列基本原则和要求：

## 1. 确定拆卸范围

拆卸前，通过阅读设备的说明书、结构图、以及拆装指导书，对拆装的设备要有所了解，做到心中有数，不能盲目进行。

再根据机器存在的故障确定一定的拆卸范围，需要拆的一定要拆，可不拆的尽量不拆，不要随意扩大拆卸范围。

这是因为不必要的拆卸将会增加检修人员工作强度，还可能会破坏机件良好的配合精度，增加零件损伤，出现安装误差。

## 2. 正确的拆卸顺序

不同的机器结构，其安装与拆卸的顺序也不相同。

因此，拆卸前应仔细阅读说明书，充分掌握机器的结构特点，了解拆装要求、随机拆装专用工具及使用方法等，以便顺利拆卸，严格按拆卸要求和步骤进行拆卸，以保证人身和设备安全。

一般来说，机器的拆卸顺序是：

- 先拆上部零件，后拆下部零件
- 先拆外部零件，后拆内部零件
- 先拆轻巧零件，后拆笨重零件
- 先拆除附属件，再拆除主要件
- 先拆总成部件，再将总成拆解

## 3. 正确选用工具

针对拆装对象的零部件合理选用工具。

拆卸时，有专用工具的，应优先选用专用工具；若无专用工具，可选用通用工具或自制专用工具。

使用通用工具时，应首先选用梅花扳手和套筒扳手，其次选用开口扳手，最后选用活络扳手。

一般同规格的螺母数量多则选用梅花扳手，拆内部的零件选用套筒扳手。

选用活络扳手拆螺母时应注意，拆小螺母应用尺寸小的扳手，因为用大扳手拆小螺母往往会因为用力过大而将螺栓拆断，重要部位上紧时应选用扭力扳手。

## 4. 保证零部件原有的精度

拆卸过程中应尽量不要损伤零件，保证零件的尺寸精度、形状与位置精度，尤其是要保护配合件的工作表面。

特殊情况时允许在保护大件、重要件精度的前提下牺牲小件、不重要件，以完成拆卸工作。

重要的或精密的部件一般不要在现场进行拆解，应在船上专门的工作台解体修复。

## 5. 保证能正确装复机器

机器拆卸前应考虑到拆卸后的装配复原，不加思考地动手拆就可能装不上。

所以，应对所拆卸的机器结构有充分的了解，拆卸过程中通过细心的观察、作记号、系标签、画图、照相和必要的文字记录等方式，了解正确的装配顺序和安装位置，确保后期顺利进行装配。
