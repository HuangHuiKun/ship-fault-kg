# 导读

柴油机内部的高压油泵是其柴油机设备的关键部位，在高压喷油泵的带动下，柴油机会定时、定量、定压的得到供给油。

所以，柴油机的工作性能是否达到标准直接受到了高压喷油泵的影响。

此外，高压油泵还对柴油机设备的动力特性具有很大的影响。

若柴油机的高压喷油泵在运行的过程中发生了卡滞，则会使得柴油机的发动机设备的转速变得不稳定，并导致柴油机的发动机发生熄火的现象，严重的甚至会引起飞车事故。

所以，柴油机的高压喷油泵对于柴油机的安全、稳定运行具有至关重要的作用，所以我们需要在生产的过程中加强对柴油机的高压喷油泵的事故进行预防，并在第一时间排除柴油机的故障，进而使得柴油机能保持稳定的工作状态不被破坏。

这样不单单可以使得190系列的柴油机的维修费用大大减少，还能使得190系列的柴油机的工作效率有所提高，进而有效的保障机械设备的正常运行。

# 一、190系列柴油机高压油泵发生卡滞故障的原因分析

经过大量的实践经验得出机械设备所使用的190系列的采油机高压喷油泵发生卡滞故障的主要原因是：

1. 190系列的柴油机高压油泵中若发生柴油过滤不好，并导致一些机械杂质混入到设备中的柱塞之间时，会使得设备中的柱塞之间的柱塞套的表面被严重的拉损，进而使得设备中的柱塞发生卡滞现象。

2. 190系列的柴油机高压油泵中的定位螺钉的长度过大，则会使得柱塞和螺钉相互顶压过紧，进而导致设备的柱塞套不能处于正常的位置，最后引起柱塞发生卡滞的故障。

3. 若设备中的柱塞的弹簧出现故障，比如，弹簧发生扭曲变形、弹簧断裂等，也会使得柴油机发生油泵卡滞的现象。

4. 在长时间的运行过程中，若齿杆发生变形，进而使得齿杆在设备槽中的卡滞堵塞，引起齿杆以及齿圈等发生损坏，最后导致齿杆和齿轮发生咬齿进而使得柴油机的高压油泵发生卡滞的现象。

5. 若技术人员在进行喷油泵的更换时，没有使齿轮的台肩和泵内的台肩保持相互平行的状态，则会令齿轮的台肩发生转动不灵活的情况，最后导致柱塞也发生故障。

6. 若在高压喷油泵上端的柱塞套的支撑面不平整，就会使得柱塞套发生歪斜，最后导致柱塞套和高压喷油泵不处于一个中心，进而使得柴油机的卡滞现象发生。

7. 此外，若高压喷油泵的出油阀的紧座上的扭矩不在规定的范围会使得柱塞被卡死，高压喷油泵的润滑不良等也会使得柴油机发生卡滞现象。
