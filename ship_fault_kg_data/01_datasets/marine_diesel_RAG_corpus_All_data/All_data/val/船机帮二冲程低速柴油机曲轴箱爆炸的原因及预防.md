# 导读

有的柴油机虽然经过船级社的批准，安装了合格的安全设备，但仍然出现了一些问题。

以 MAN B&W 二冲程柴油机为例，近几年内发生了多起曲轴箱爆炸事故。

经研究初步发现，大量的曲轴箱防爆门虽然经过船级社检验合格，但船级社的检查仅限于对释压阀的检验，仅考虑了释压阀的开启压力，对火焰熄灭器没有足够的重视，而火焰熄灭器在使用过程中往往不能正常工作。

# 一、曲轴箱爆炸的原因及危害

## 1、曲轴箱爆炸的原因

曲轴箱爆炸往往是因为曲轴箱内存在热源或别处的热源导入曲轴箱。

比如轴承过热，可导致润滑油蒸发，形成油气。

油气流动到温度稍低的地方，凝结成油雾。

油雾是一种极易爆炸的物质，遇到火源便很容易发生爆炸，而过热的轴承恰恰成为火源。

表1为已查明原因的MAN B&W 等品牌二冲程低速柴油机曲轴箱爆炸事例及具体原因。

## 2、曲轴箱爆炸造成的后果

许多曲轴箱爆炸的事故是致命性的，事故中至少有两起由于在检修机器时使用了未经许可部件而造成人身伤亡。

当曲轴箱发生爆炸时，在压力波的作用下，大量的油雾将从曲轴箱进入到机舱。

如果油雾在曲轴箱外发生爆炸，危害将更加严重。

机舱风机虽然可以将这些油雾吹散，但由于柴油机的运转，大量的油雾会被废气涡轮增压器的压气端吸入。

油雾从曲轴箱到达增压器这一路线上，如果遇到火源，极可能被点燃。

所以，柴油机排气管的隔热层保持良好的状况，没有裸露的热的排气管尤其重要。

当然，最大的危险来自于火焰熄灭器的不正常工作。

在这种情况下，曲轴箱内的火焰本身就是火源，如果火焰熄灭器不能将其阻断，火焰将蔓延到机舱，将机舱内的油雾点燃。

在大多数情况下曲轴箱爆炸对设备的损害仅限于柴油机本身，但如果在曲轴箱外发生爆炸，爆炸可导致机舱内其他设备的损坏，主要破坏电器设备。

如果机舱比较狭窄，压力波还可以破坏机械设备，机舱舱门，甚至有时候爆炸使地板脱落。

# 二、曲轴箱爆炸的预防

由于曲轴箱爆炸的原因各种各样，因此应根据不同的情况采取相应的预防措施和监测系统。

## 1、维护

按照说明书的要求检查机器部件，尤其注意对轴承的检查，使机器保持良好状态。

很多事故仅仅是因为螺栓上紧方法不当而造成的，按照说明书的要求去维修机器十分重要。

对于厚壁轴瓦要特别注意，使用垫片仔细调整轴瓦顶部间隙。

轴瓦顶部间隙过小，滑油流量不足，导致轴承过热，这种情况已经出现多次。

## 2、使用许可的部件

许多曲轴箱爆炸，有的还造成人身伤亡，是由于使用了未经许可的部件。

其中有一次事故是因为使用了未经许可的活塞杆填料函弹簧而导致的。

因为弹簧的尺寸不对，绷得过紧，导致活塞杆过热，最终引起了曲轴箱的爆炸，两人丧生。

造成这一事故的主观原因是误认为填料函弹簧不是非常重要的部件，对柴油机的工作影响不大。

## 3、检查

视觉检查对于故障隐患的早期发现十分重要，尤其要注重对曲轴箱内白合金碎片的检查。

通过检查可以及时发现轴承故障，避免进一步恶化而成为曲轴箱爆炸事故。

因此，轮机人员每一次进入曲轴箱时都要检查有没有白合金碎片，如果有，立即检查相关轴承。

另外，注意对安全设备及其相关部件的检查。

曾经发生过这样一起事故，因为防爆门火焰熄灭器的机械故障而导致曲轴箱爆炸的火焰蔓延到机舱，造成机舱起火。

## 4、监测

对曲轴箱的监测包括油雾浓度监测和轴承温度监测，船级社要求可以任选其一。

但从安全性和可靠性方面来看，两种监测手段同时使用非常必要。

## 5、曲轴箱爆炸的抑制

可以通过安装防爆门释放爆炸产生的压力有效地保护柴油机免于损坏。

曲轴箱爆炸时，迅速传递的压力波把大量的油雾携带到机舱，火焰的传递速度比压力波的速度小很多，防爆门上的火焰熄灭器可以将火焰熄灭，从而可以避免曲轴箱外着火。

尽管可以避免机舱内的着火，但巨大的压力波仍然可以对人员生命安全和机舱内设备造成极大的危害。

当油雾浓度探测器监测到曲轴箱内油雾浓度过高时，通常柴油机会先降低负荷，从而降低油雾产生的速度。

但是，这样却不能达到立竿见影的效果。

因为即使减少了负荷，旋转的螺旋桨存在惯性不能马上停止，所以在负荷减少的过程中，曲轴箱爆炸的危险依然存在。

曲轴箱爆炸抑制系统的目的就是减少曲轴箱爆炸的危害和破坏作用，使人员免于受到伤害。

当油雾浓度探测器监测到曲轴箱内油雾浓度过高时，曲轴箱爆炸抑制系统将开始工作。

有的柴油机通过使用惰性气体来降低氧气的浓度从而来阻止火焰的传播和扩散，达到抑制爆炸，延缓爆炸速度，降低爆炸威力的作用。

对于大型柴油机，使用后的惰性气体积存于曲轴箱内难以彻底排除，又对人员产生新的危害。

# 三、水雾型曲轴箱爆炸抑制系统

## 1、喷射水雾型曲轴箱爆炸抑制系统

图1为水雾抑制效果的比较试验。

图1 水雾对爆炸抑制效果的比较试验

在特定的试验条件下，将两种不同的混合气分别在容器内进行爆炸试验。

一种混合气是甲烷和空气，另一种是甲烷、空气和水雾。

特定试验证明，空气和甲烷的混合气爆炸可产生0.32MPa的压力，而加入水雾以后，压力不足0.MPa，大大延缓了爆炸的速度，消除了爆炸所产生的压力波的破坏力。

2001年初出现一种利用水雾取代惰性气体的曲轴箱爆炸抑制系统—喷射水雾型曲轴箱爆炸抑制系统。

在油雾监测系统的控制下，喷射水雾型曲轴箱爆炸抑制系统将压力为1.5MPa温度为180℃的水经一特殊的喷嘴喷射入曲轴箱。

在喷嘴出口，水汽化变成蒸汽。

在曲轴箱内凝结形成直径小于10μm的小液滴。

用水雾系统代替惰性气体系统完全排除了由于缺氧带给人的危害，并且水可以方便地被分油机除去。

水雾虽然不能阻止爆炸，但可大大降低爆炸的强度。

## 2、注射水雾型曲轴箱爆炸抑制系统

使用喷射水雾型曲轴箱爆炸抑制系统时，一定要时刻注意水的压力和温度，并且要维持足够的流量以保证整个曲轴箱都能被水雾覆盖。

最近又出现了一种注射水雾型曲轴箱爆炸抑制系统。

这种系统利用油雾产生的原理来产生水雾，而不是像喷射水雾型曲轴箱爆炸抑制系统那样依靠喷射高温高压的水来产生水雾。

当油雾浓度探测器探测到曲轴箱内产生大量油雾时，在滑油进入柴油机之前，将相当于滑油体积流量1%～5%的水加入滑油。

因为水的沸点低于油的沸点，水比油先蒸发。

由于水的汽化潜热非常高，热源被冷却，减少甚至避免了油的蒸发。

另外，对于安装了轴承温度监测设备的柴油机，水仅注入温度过高的个别轴承就可以了。

当然，这种装置将更加复杂。

采用了注射水雾型曲轴箱爆炸抑制系统以后，无论任何时候产生过热现象，无论任何地方产生油雾，水总是能够及时伴随出现。

水的蒸发可带走热量，阻止油雾的继续产生。

# 四、结束语

曲轴箱爆炸是一种非常严重的事故，要加强对柴油机的运行监测和管理，严格按照说明书的要求进行维修，杜绝使用不规范或未经许可的备件，积极推广新技术，确保人身和设备的安全。
