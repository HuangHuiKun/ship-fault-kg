# 船机帮船舶柴油发电机组升级改造

柴油发电机组负责整条船舶的电力供应，是船舶操作控制的基础，属于船舶的重要设备。

在船舶航行或拖带作业时，若柴油发电机组出现故障，将导致全船失电，船舶控制系统瘫痪，会造成非常严重的后果。

另外，一些船龄在20a以上的船舶在使用过程中，其柴油发电机组每年都要定期停航大修两次，更换重要的零部件，既增加维修成本又影响船舶生产作业。

## 一 问题

“秦港15”轮发电机组采用的是上柴 6135ACAF’型柴油机。

该机型由于投入使用时间比较早，而且属于非增型柴油机，存在启动困难、油耗偏高、尾气排放超标、设备运行不稳定等问题，随着使用时间的延长，设备保障问题越来越突出。

因此，结合实际使用情况和特点，计划对部分船舶的柴油发电机组进行升级改造。

发电机组吊舱后，原机组的位置留下一个2.5mX1m的空间，由于新发电机组尺寸较原机组体积小1／3，如果直接安装新发电机组，那么新发电机组将会直接坐到船舶底板上，发电机组将不能运行。

因此，采用原位置新基座的方法，在原发电机组空出的位置采用15mm的钢板封住凹坑，从上面打孔安装新发电机组的基廊，将机组和船体肋骨牢靠地固定一起。

然后将新发电机组通过机舱天窗整体吊入到新基座上，安装定好。

这样既节省机舱内空间，又满足相关的技术规范要求。

燃油管路连接采用燃油专用软管，将柴油机的进油口和原有的供油管路连接，充分利用原有管路，既节省安装时间，又安全可靠。

发电机组的启动是采用气动马达，启动空气管路是为气动马达提供动力的。

改造过程中，在马达进口处加装一个直通电磁阀，这样可以通过发电机组监视仪按钮来启动发电机组，既安全又方便。

在冷却水管路的改造中，拆除原有直径为40mm的全部海水管路，更换为直径是60mn的管路，将冷却海水量加大，可以使冷却效果提高。

排气管路则是全部利用原有管路，将新机组的增压器出口直接和排气管路连接。

既充分利用原有资源，又节省了安装时间，安装效率提高。

## 二 改造实施

根据“秦港15号”主配电板网纸，以及实船电缆布线情况，并结合新发电机组的接线端口、监视仪位置等因素，以合理利用现有资源为原则，尽量保留使用原船电缆线（电源线、数据线、报警线等）来接新发电机组，同时将发电机组配电板上弃用的元器件进行拆卸，在原位置上安装新发电机组需要的元器件。

首先在1﹟发电机组电饭上安装微动调压器和微动调速器，即调压微动可调电阻、调速微动可调电阻。

在发电机组配电板右下角合适位置，钻孔安装微动调压器，原调压线保持不变，将1﹟发电机组的调压微动可调电阻接在182和183触点上。

拆除原发电机组配电板上的充放磁开关，利用原有位置安装微动调速器，可以从原处接线。

将1﹟发电机组的调速微动可调电阻接在180和181触点上。

从拥绑在一起的原电缆线中找出调压线和调速线。

并将标记好的调压线接入1﹟发电机组后部控制箱内部的调压板。

然后将接调速线接入监视仪侧面的控制箱D33、D34处。

发电机组的报警线分为“滑油低压”报警、“淡水高温”报警，将每组报警线D21“油压低压”触点上和D22“水温高温”触点上。

1﹟发电机组配电板转换开关上选择线号为156﹟和157﹟的两根线，将156﹟、157﹟线作为发电机组主电源正负极。

把156﹟线与电屏电源正极153﹟线相连，把157﹟线与电屏电源负极154﹟线相连。

调节转速时，一边调节电位器，一边观察监视仪显示的转速，当怠速调整至1000 r／min、高速调整至1500 r／min时，到1﹟发电机组配电板上观察频率表，利用左下角的调速器将频率调至50Hz。

将1﹟发电机组配电板上的调压器调整至中间位置，然后使1﹟发电机组处于高速状态下运转，在1﹟发电机组后部控制箱内调压板上进行调节，调整电位器，并观察配电板上的电压表数值，使电压调节至400V。

“秦港15号”的2台柴油发电机组改造完成后，立即投入生产使用。

经过实船运转了500h后，对发电机组进行测试，发电机组运行正常，各项数据指标均正常范围内。
