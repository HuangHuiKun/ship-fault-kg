# 导读

蓄压器（Accumulator)，这个名字大家都不陌生，应用于工业各个领域，更多的应用于液压系统，用于储存液压能量，吸收压力脉动与冲击力的液压附件，它主要有三种类型：弹簧式、重力式和充气式。

而充气式蓄压器在船舶上应用最多，船舶上，氮气通常作为蓄压器的使用介质，因为氮气稳定性好、价格不高及容易获得，也是比较安全的气体。

现将氮气蓄压器的结构，工作原理及充注方法简介如下，供同仁参考。

# 1. 氮气蓄压器按结构来分

氮气蓄压器按结构来分，主要可分为气囊式蓄压器、隔膜式蓄压器和活塞式蓄压器。

## 1-1. 气囊式蓄压器

气囊式蓄压器具有较大的容积，常见的容积可达450升，并且能承受高达100公斤的工作压力，其最高工作压力与预充气压力之间的比值通常不超过4，气囊式蓄压器的特点是低磨损，长寿命，可更换气囊，在实际应用中非常普遍，如船上遥控液压阀泵站、救助艇吊艇机等（如下图）。

## 1-2. 隔膜式蓄压器

隔膜式蓄压器，工作容积通常在0.7-10升之间，能够承受的工作压力可超过350公斤，其压缩比一般不超过8，并且其动态相应特性通常优于其它类型的蓄压器。

但隔膜式蓄压器的压缩比受到隔膜变形能力的限制，通常应用于船上MAN主机液压气缸单元HCU（Hydraulic Cylinder Unit）、液压动力单元HPS（Hydraulic Power Supply)及气缸注油器液压动力单元，主机液压顶撑等（如下图所示）。

## 1-3. 活塞式蓄压器

活塞式蓄压器，由于其没有变形部件，其压缩比在理轮上可以非常高，从而获得更高的能量密度。

但由于其受到外壳材料强度的限制，其最高工作压力大约为800公斤，最大容积可为1200升，它的特点是制造成本较高，对与活塞相接触的内壁表面粗糙度有严格的要求。

另外，由于活塞密封件与缸体内表面的磨损，可能导致泄漏，因此需定期检查，这种蓄压器船上不多见。

# 2. 氮气蓄压器的工作原理

氮气蓄压器是根据理想气体定律的原理工作的，对于同一理想气体，在不同压力、体积、温度下的比较，根据PV/T=n*R,（n为气体摩尔数，R为常数8.31），同一理想气体系统，n是不变的，所以对于同一气体来说，PV/T=定值，故P₁V₁/T₁=P₂V₂/T₂,而对于同一蓄压器而言，V又不变，因而有P₁/T₁=P₂/T₂,其中P为气体压力，V为气体体积，T为气体温度，P₁和P₂分别代表气体的初始压力和最终压力;T₁和T₂分别代表气体的初始温度和最终温度，气体的压力P随着温度T的升高而增大的。

# 3. MAN MC主机气缸注油器氮气蓄压器的检查和充注

MAN MC主机气缸注油器氮气蓄压器的检查和充注只有在主机停止和液压压力释放的情况下才能进行，主机专用工具配备一只氮气蓄压器检查和充注工具，MAN MC主机每个缸气缸注油器有两只氮气蓄压器，进口侧一只，容积为0.7升，压力维持在25-30公斤，出口侧一只，容积为0.16升，压力维持在1.5公斤左右，测量和充注出口侧氮气蓄压器必须拆下蓄压器。

停止2台油泵，关闭气缸注油器进口阀，打开气缸注油器上的平衡阀，安装压力检查和充注的工具，在氮气瓶上安装一个减压阀，在压力检查和充注的工具上安装一个0-60公斤压力表检查进口蓄压器（0.7升），而检查出口蓄压器（0.16升）在压力检查和充注的工具上安装一个0-10公斤压力表，将压力检查和充注工具分别安装在蓄压器和氮气瓶上。

安装之前，清洁蓄压器和氮气瓶的螺纹接口，并涂上少许牛油润滑接口螺纹，安装后检查C和F是否关闭（如上图），用专用内六角扳手打开E内的内六角螺栓，检查压力表的读数是否在规定的范围内，如果蓄压器压力不足，需要重新充注氮气，打开阀A，调节减压阀B至阀C的出口压力比蓄压器规定的压力高1-2公斤，打开阀C直至蓄压器被充满至正确的压力为止，关闭阀C,用专用内六角扳手关闭E内的内六角螺栓至规定的扭矩，打开放气阀F释放管道内残余的压力，取下压力检查和充注的工具后再重新拧紧蓄压器上的内六角螺栓至规定的扭矩（30Nm)。

# 4. MAN ME电喷主机液压气缸单元(HCU)和液压动力单元(HPS)的氮气蓄压器

氮气蓄压器应用在MAN ME-C主机液压气缸单元HCU和液压动力单元HPS高压液压管路中，维持压力稳定，平衡压力脉动，如果压力不足，会引起燃油压力增压泵（F.O Pressure Booster) 供油压力不足，气缸喷油器喷油量不足，雾化不良，排温降低，导致排气阀行程短，会激发主机自动降速Slow Down,因此要特别主机检查氮气蓄压器的工况。

一般情况下，新造船下水一星期后，检查蓄压器氮气压力，如不足，需及时补充，4个月后再次检查蓄压器氮气压力并作记录，随后每6个月进行氮气压力检查，对比以前记录的压力，即可判断蓄压器性能好坏。

如压力不足补充，如隔膜损坏，及时修理更换，氮气蓄压器微小泄漏是正常的，经验表明每个月压力下降2-5公斤是正常情况。

当然充注氮气压力取决于系统的工作压力和蓄压器的温度。

MAN ME-C电喷主机的气缸注油器所需的液压动力整合在液压气缸单元HCU，每个缸有一只容积为10升的氮气蓄压器，而液压动力单元HPS有三只容积为4升的蓄压器，分别安装在3台机带液压泵上，蓄压器内氮气的压力随作温度的增加而增大。

一般情况下，温度每升高1摄氏度，压力增大0.6公斤，对于300公斤的液压系统来讲，蓄压器在200C时的压力大约为136公斤。

MAN ME主机氮气蓄压器一般有两种类型，分别为：Leduc / SGPT Type, TSP / Daeshin Type, 检查压力和充注氮气之前要释放液压系统内残余的压力，MAN ES也提供了一套蓄压器压力测量和充气的专用工具。

检查和充注之前，清洁蓄压器和氮气瓶的螺纹接口，并涂上少许牛油润滑接口螺纹，安装压力测量和充注的工具，安装后检查阀A和D是否关闭（如上图），安装充气压力软管至蓄压器螺纹接口上，使用压力测量和充注工具上的母牙接口E,此时可以在数字压力表C上读出蓄压器内实际的氮气压力，用点温计测量此时蓄压器本体温度，一定的温度对应一定的氮气压力，确认氮气蓄压器是否需要充注氮气。

如果需要充注氮气，打开阀A, 调节减压阀B至数字压力表的压力高于当时温度下氮气压力 1-2公斤，保持阀A打开直至氮气蓄压器压力至规定的数值，等待5分钟使蓄压器温度稳定，再次检查数字压力表C的压力是否满足规定的压力，关闭阀D,拧开母牙接口E，用肥皂泡沫检查蓄压器充气接口处是否漏气，如正常，复原保护螺纹帽。
