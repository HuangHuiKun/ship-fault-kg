# 导读

船舶柴油机由于在各种动力机械中热效率最高，功率范围宽广，启动迅速，维修方便，运行可靠，使用寿命长，因而在运输船舶上得到了广泛的应用。

废气涡轮增压器工作原理是利用柴油机废气的能量驱动增压器的涡轮旋转，同时带动同轴上的压气机转子旋转，将空气压缩并送入柴油机燃烧室。

由于废气涡轮增压系统与柴油机之间无任何机械传动，同时涡轮增压系统利用的又是柴油机废气的能量，既提高了柴油机动力性，又提高了柴油机的经济性，所以获得了广泛的应用。

通过本人多年来的船舶工作经验，同时结合轮机管理的要求，对废气涡轮增压器的结构特点、工作原理进行了简要介绍，并且通过工作中的观察与分析，结合实际情况，对废气涡轮增压器喘振的原因与预防提出了一些分析与措施。

# 一、废气涡轮增压器的原理及特点

## 1、增压器的工作原理与结构特点

图1：废气涡轮增压器简图

上图1增压器属于 TPL 系列，是 ABB 公司在上世纪九十年代后期开发的，主要用在大功率船舶主柴油机上，是定压、轴流式内支承式滑动轴承增压器，比较 ABB 公司设计生产 VTR 系列传统增压器有很大改进。

该增压器由一个轴流的涡轮机和一个径流的离心式压气机组成。

轴流式涡轮机由废气进气壳、喷嘴环、废气涡轮、涡端扩压器、涡轮叶片、废气排气壳等组成；

离心式压气机主要由进气消音器、压气机进气壳、压气机叶轮、扩压器、空气排气壳等组成。

运行中，涡轮机在排气能量的推动下，带动压气机工作，实现进气增压。

如上图１所示，主机的废气经由进气壳，涡轮的喷嘴环，涡轮机转子，排气壳，将废气能量转化为转子轴的动能，从而驱动了压气机工作。

与此同时，新鲜空气依次通过压气机进气壳和消音器，压气机叶轮，扩压器，排气蜗壳，最终被压缩的新鲜空气通过中间冷却器和进气管，进入主柴油机的气缸。

这一过程使进入气缸的空气密度增加，从而可以增加喷入气缸的燃油量，从而大幅度的提高柴油机的功率。

当主机在低负荷运行或者刚启动时，排气管压力低。

废气能量较少，使涡轮机发出的功率满足不了压气机所需的功率，因此要在此种情况下，要在主机边设有辅助风机来满足其低负荷时的扫气需要。

# 二、预防废气涡轮增压器喘振的措施

## 1、增压器喘振的原因

增压器产生喘振的根本原因是压气机的实际流量小于该转速下引起喘振的限制流量，造成气流与叶片的强烈撞击与脱流。

其中增压系统流道堵塞是引起增压器喘振最常见的原因。

主要部件有压气机叶轮和扩压器、空气冷却器、气缸进气口和排气口、涡轮的喷嘴环和叶轮。

此外，柴油机本身的某些故障或者由于装载、顶风、污底、环境温度的变化等原因，或者由于轮机员操作不当以及在大风浪天航行，都可能导致柴油机和增压器匹配不良，引起喘振。

## 2、预防增压器喘振的措施

（1）根据引起废气涡轮增压器喘振的原因可知，在日常的增压系统维护保养中，首要的预防措施是保证废气涡轮增压器的清洗。废气涡轮增压器的清洗主要是涡轮机的干洗和压气机的水洗。

具体如下图2（增压器涡轮机干洗系统）（增压器压气机水洗系统）；

要求每 24-50 小时在全负荷下进行涡轮机的干洗，在全负荷下进行压气机的水洗。

图2 增压器涡轮机干洗系统气机水洗系统

（2）废气涡轮增压器运行中的清洗，不可替代的定期的拆检和清洗增压器。

（3）空气及废气通道不畅，也易引起喘振，因此消音器、空冷器需要定期清洁以洗去压气机冲洗下来的积垢，喷嘴环要随着增压器的拆检需要定期清洁。

（4）除了废气涡轮增压器的清洗，在日常的管理中还应注意柴油机和增压器的运行失配。这时只要排除了柴油机的故障，也就消除了喘振。

（5）当船舶满载、顶风、逆流、涌浪较大、螺旋桨缠着异物以及污底严重时，柴油机在低转速高负荷下运行，这也容易引起增压器和柴油机匹配不良而出现喘振，此时降低油门即可消除喘振。

（6）若轮机人员操作不慎，可能使增压器与柴油机暂时失配而发生喘振，但不久又能恢复匹配关系，喘振即自动消失。

如高速下停车和急速降低主机转速等情况，尽量避免就可。

# 三、总结

增压器的喘振不单纯是单一原因，还可能是多个原因的叠加，是综合性的；

所以就要求我们分析问题时要综合考虑各项因素，全面分析。

所以，对增压器的日常管理重点关注以下几点：

气体流道的清洁、畅通，保障空冷器对空气的良好冷却；

冷却器的空气面必须定期用化学剂进行清洗，海水冷却面要定期人工清洁，保证冷却良好；

在拆装增压器时应保证正确的安装间隙，防止变形和安装不正。

作为一名船舶轮机管理人员，首先我们在日常管理中，要对主机增压器的主要运行参数定期进行检测记录，如各缸排烟温度、涡轮前后的温度、增压器的转速、空气滤器和空冷器的压降、扫气压力等等一些重要参数及时检查分析，发现问题，及时解决。
