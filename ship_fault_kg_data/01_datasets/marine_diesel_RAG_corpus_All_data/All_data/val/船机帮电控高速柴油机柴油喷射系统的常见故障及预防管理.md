# 导读

近年来，由于柴油机技术的不断进步与发展，电控柴油机作为一种改进型的机械动力能源，逐渐在工程机械中得到了广泛的应用，如美国卡特彼勒公司、日本的五十铃公司、瑞典沃尔沃公司、康明斯公司、德国的博士公司等，已经将电控发动机应用在了船舶、工程等领域上。

然而，因为船舶、工程机械工作环境的恶劣、反复大负荷工作和操作人员相对的不固定，保养和检修不确定性因素很多，对新时代的操作手素质和机械设备管理水平，提出了更高的要求。

现从工程机械柴油机电控燃油喷射系统性能特点、常见故障及预防管理措施、电控燃油喷射系统维修管理等方面，简要分析如何使用和管理好工程机械电控柴油机，使其发挥更大的经济效益。

# 一、电控柴油喷射系统性能特点

电控柴油喷射系统的应用，使发动机实现了喷油量、喷油压力和喷射正时完全按最佳工况运转，提高了柴油发动机的动力性能和经济性能，减少了废气排放，降低了噪声污染。

现代工程机械发动机燃油系统常用的有三类，依次为高压共轨柴油喷射系统、电控单体泵系统和电控泵喷嘴系统，都属于电控高压喷射之列，其共同特点是：

（1）喷射压力高，柴油喷射压力由10MPa提高到200 MPa。

（2）喷孔更小。

（3）实现了快速断油和最小油量控制。

（4）独立的正时喷射和可变的预喷射控制。

（5）供油系统的供油压力不依赖转速和负荷，实现了独立控制。

电控柴油喷射系统的常见故障主要两种：机械故障和电气故障。

# 二、常见机械故障来源分析

柴油由油箱进入燃烧室的过程中，对柴油泵和喷油器来说，还起到非常重要的润滑作用，但如果燃油中含水或其他颗粒物，就会加剧喷油泵磨损。

越高的喷射压力，对柴油清净性要求也就越高。

机械故障主要有高压柴油系统部件的磨损，电磁阀或喷油嘴阀芯的粘滞、堵塞、泄漏而引起机械动作失效。

## 1、故障来源

（1）喷射压力高，柴油中过量水分和杂质导致供油泵、单体泵、泵喷嘴柱塞、泵体和喷嘴容易非正常磨损。

当发动机运转时，柱塞在泵体中进行往复运动产生高压燃油，当柱塞和泵体之间被残存的粘胶物卡塞时，或柴油中含过量水分，而破坏了柴油润滑油膜时，活塞就会发涩或拉伤，燃油因内泄而无法建立高压，致使到达喷嘴的燃油压力下降，喷嘴针阀打开滞后或无法打开，喷嘴无法正常工作；柴油中含有过量的水分，还会导致喷嘴的早期磨损，造成喷油嘴在压力油路的施压下，不断向燃烧室内泄漏柴油。

以上故障都会导致燃油雾化不良，发动机出现无力、提速困难、难以启动甚至热车时无法启动等症状。

（2）喷嘴喷孔小，易堵塞。

燃油中进入杂质容易堵塞喷孔，当燃油雾化不良、燃油不能完全燃烧时，生成积碳多，也容易而堵塞喷孔，造成喷嘴工作失效，发动机无法正常运行。

（3）电磁阀或喷油嘴阀阀芯粘滞故障。

电控柴油机只所以能实现快速断油和最小油量控制，供油控制电磁阀的动作快与慢，起到了关键的执行作用。

在电脑发出喷油信号后，电磁阀通电后产生磁吸力，由于阀芯与阀座的运动间隙被残存的粘胶物卡塞，电磁吸力小于卡塞产生的阻力时，电磁力无法有效带动阀芯升起，或喷油嘴阀芯达不到开启速度，或当电脑发出停止供油时，阀芯由于卡塞而无法立即关闭，都会影响喷油时间或喷油量，发动机出现怠速不稳、难以启动、提速困难等症状。

## 2、机械故障的防治管理措施

产生机械故障的主要原因，是柴油质量差、柴油滤清器更换不及时而引起的，柴油作为发动机燃料，工程机械柴油消耗量较大，单台班消耗油量多在200～350L之间。

设备加注柴油时应注意清洁，尽量选择氧化安定性好、热稳定性强、硫含量少、清洁度高的柴油。

在使用中，应严格按照规定工作时间及时更换柴油滤清器和油水分滤器。

设备操作人员要加强柴油油路和油箱的保养，要经常排放油水分离器里的水，定时更换合格的油水分离滤芯和柴油滤芯，定期清洗油箱，确保燃油的清净。

# 三、常见电气系统故障及预防管理措施

电控柴油机电控系统由三个基本组成部分：输入（开关和传感器）、对输入信号进行分析的 ECU 系统和按照输出信号动作的执行器（电控单体式喷油器）。

## 1、电器系统的常见故障

当开关和传感器将信号提供给控制器ECU 时，ECU 对信号进行运算，计算出合理的喷油时间（喷油量）和正确的喷油始点（喷油正时），并由此制定出各种控制指令，输出相应的控制信号，驱动相关执行器，实现了快速断油、最小油量控制、正时喷射、和可变的预喷射控制，使发动机按最佳状态运行。

因此，当电器系统的任何部位故障时，都会造成发动机的性能改变。

（1）输入（传感器或开关）故障。

输入故障主要因传感器无信号输出（断路）或信号错误所致，包括压力传感器、温度传感器、转速传感器等。

因为工程机械工作环境恶劣，尘土和雨水较多，发动机工作环境温度较高，振动较大等，传感器外接线路疲劳弯曲损伤，常有断路现象。

（2）控制器（ECU）故障。

控制器又叫电子控制单元（ECU-Electronic Control），ECU 内部任何电气部件的损坏，都会影响到发动机的控制，使发动机工况变差和无法运转。

在日常的使用中，应保持控制器良好的工作环境，保持通风，避免高温，防止灰尘和水进入。

（3）执行器故障。

主要是喷油嘴电磁线圈的断路、短路和线圈的老化。

## 2、电路故障的防治管理措施

电控柴油机在使用过程中，应保持电路系统的清洁，严禁任意更改线路的连接方式。

拆卸喷嘴时，应避免损坏内部的电磁线圈。

拆除电插头时，应先关闭点火开关，防止瞬间过电压烧坏电磁线圈和电脑内部电子器件。

检修喷嘴电路时，应使用高阻抗数字万用表或电脑分析仪，严禁采用划火方式，以免烧坏喷嘴的电脑控制电路。

喷嘴电路故障检测时，可选择在每个喷嘴体上都听到频率与间隔不变、声音大小一致的阀芯落座声，声音单调而均匀，说明喷嘴工作正常。

# 四、电控柴油喷射系统的维修管理

电控柴油机是一种具有新型燃油喷射系统的发动机。

要诊断并排除一个可能涉及微机系统的柴油机故障，首先应按照普通柴油机的故障诊断方法，查找可能引起的故障原因，确定故障与微机有关后，再利用电控单元自诊断系统进行故障诊断，这也是对电控柴油机故障诊断与检修的基本原则。

电控柴油机电气控制系统检测时。不可随意乱动或用一般电路故障的检查方法进行检查，检查时应主意以下几点：

（1）当发动机出现故障或报警时，应停机检查，通过自诊断系统将故障码及有关资料信息调出，诊断出故障原因。

（2）按照查出的故障码，检测相应的故障电气部件。

（3）检测时避免打开计算机。

（4）在检测出故障原因进行检修时，应关掉点火开关，拆下蓄电池搭铁线。但在调出故障码之前，不能将蓄电池从电路中断开，以免丢失故障码信息。特别严禁在发动机高速运转时切断蓄电池线路，以防产生瞬变过电压将计算机和传感器损坏。

# 四、结束语

柴油的品质好坏，对电控柴油机喷射系统的使用寿命影响较大，为延长其使用寿命，提高柴油机的经济性能和动力性能，要树立科学的管理、运用、保养和修理设备的观念，才能提高设备的综合经济效益。
