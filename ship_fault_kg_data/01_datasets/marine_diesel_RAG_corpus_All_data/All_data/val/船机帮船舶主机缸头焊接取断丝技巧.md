# 导读

通过对船舶主机缸头断裂双头螺栓采用焊条电弧焊的方法，确定精准的工艺参数及操作技巧取出，保证了船舶的正常航行。

为船舶在海上安全航行对焊接技术的应用技巧进行了探索，提供了一种保证修复有效可行的方法。

# 一 问题的出现

某轮为国际航线集装箱船，船舶主机型号 MAN－B＆W 7K98MC－C，主机功率39970kW。

该轮航行于黄海中部，东风5级，浪高1.5m。

晚 8 时三管轮发现第5个缸头有水渗出，膨胀水柜水位下降明显。

经检查，发现11点钟处缸头的螺栓断裂，该机缸头螺栓有8根，均为双头螺栓，如图1所示。

图1 缸头螺栓

断裂处位于螺栓根部，下头全部螺纹均在螺孔内，因受力不均导致缸套冷却水泄漏。

# 二 情况分析

经分析，可行方法有2种：

（1） 坚持行船到锚地抛锚，将缸头吊下，在断裂面中心钻孔，再楔入端部带坡面的钢棍，拧动钢棍将断丝带出来。

这样做是比较稳妥的办法，但是主机要带病工作20h，且需要降速航行。

这样操作对于第5缸的其他7根缸头螺栓来说亦会因受力不均而造成二次伤害，具有很大的不确定性。此外，吊缸流程繁琐，工作量也很大。

（2）立即停车漂航。

准备 M16 螺母一只，将其焊到断裂面上，拧动螺母，将断丝旋出。

这样做节省时间，修复后主机可全负荷正常工作。

缺点是工作位置受限，需要加长焊条，且不易观察熔敷铁液的流向，螺母不容易焊牢固。

由于天气及海况条件良好，经与船长商议，决定采取第2套方案———船舶漂航取断丝。

# 三 准备工作

## 1.焊条的连接加长

由于船舶主机缸头的双头螺栓较长，长度达1200mm，为保证焊接时的准确性、平直， 除掉焊条端部10mm长的药皮，用直径2.5 mm 的焊条，将直径3.2 mm的焊条进行点固焊加长，而不采用绑扎的形式。

## 2.对内螺纹的保护

用水将钛白粉调成膏状，然后涂抹在外露的内螺纹上，确保在焊接过程中不粘上飞溅物，这也是采用焊接方法取断丝是否成功的关键，然后用氧乙炔气焊枪进行烘干处理。

# 四 焊接工艺

## 1.焊前分工

焊接过程由 3 个人配合操作，一人在断裂处放置M16的螺母，要平整且保证螺母与断裂的螺杆中心重合，固定好，如图3所示。

图 3 焊接位置

另外一人听笔者指令负责电焊机的开关通断。

先调整出合理的焊接工艺参数，把加长的焊条用焊钳180°夹持，焊条钢芯的端部放在M16螺母内螺纹与断面接触线上（焊机此时不通电）。

焊接电源为交流，所用电焊机为BX－400型，焊条E4303 （J422），直径3.2 mm，焊接电流 95～100A，满足焊接工艺性好的要求。

## 2.焊接

在一切准备工作做好后，通知负责焊机的人员给焊机通电，延迟1～2s 后迅速向上提起焊条，产生电弧，并保持2～3s 时间后断弧，清理熔渣并检查螺母是否点固焊、位置是否正确，检查合格后继续相互配合焊接4～6s，完成塞焊，保证一次成功。

焊后清理熔渣和钛白粉保护层，检查断裂处内螺纹是否有损伤。

用T形加长特制套管扳手套在 M16 螺母上， 向外拧出断裂螺栓。

# 五 总结

通过本次对主机故障的排除发现，焊接技术在船舶管路设备维修及应对紧急突发故障等方面会起到非常关键的作用。

掌握一定的焊接技术与技巧，能够在最短的时间，以最高的效率，用最可靠的手段保障船舶的安全航行。

由此建议一些年轻的船员尽可能地多掌握一些焊接技术，这不但能够大幅提高工作技能，增加上船就业的机会，而且还会赢得尊重，提高工作自信心。
