# 船机帮船用柴油机活塞环的认识

## 活塞环的作用

根据所起的功用不同，柴油机活塞环有压缩环（也称密封环或气环）、刮油环（也称油环）两种。

压缩环安装在活塞头部，在十字头式柴油机和筒形活塞式柴油机上均设有压缩环。

压缩环（气环）的主要作用：

1. 密封——密封气缸，防止气缸中的高温、高压气体漏入曲轴箱。
2. 导热——将活塞头部的大部分热量传递给气缸壁，将热量传递给冷却水，保持活塞正常的工作温度。
3. 辅助刮油、布油。

筒形活塞式柴油机气缸采用飞溅润滑，甩到缸套表面的滑油较多，因此在活塞上还转有刮油环。

刮油环（油环）的主要作用：

1. 刮油——刮油环把气缸壁面上多余的润滑油刮下，防止滑油进入燃烧室。
2. 布油——刮油环使气缸壁面上的润滑油均匀分布，形成薄层油膜，减少气缸套的摩擦磨损。

十字头式柴油机气缸采用注油润滑，一般只装压缩环。

在活塞裙比较长的十字头式柴油机活塞上，裙部还装有承磨环，是专为十字头式柴油机活塞与气缸的磨合而设置的。

## 活塞环的工作条件

活塞环的工作条件十分恶劣。

1. 高温高压

第一道活塞环直接受到高温高压燃气的作用，其它活塞环由于燃气经环的搭口、气缸壁面和环槽处的漏泄，也受到燃气不同程度的作用。

2. 运动复杂

由于受到气体压力、活塞环往复运动的惯性力和与气缸套间产生的摩擦力、活塞横向振动和气口挂壁等作用，活塞环在环槽中产生十分复杂的运动，如轴向运动和轴向振动、径向运动和径向振动、回转运动、扭曲振动等。

3. 摩擦磨损

由于气缸套在磨损后上下有一定的圆柱度误差，使活塞环在上下往复运动过程中在自身弹力作用下产生张合、收缩的交变运动。

在这种严重的摩擦与磨损、振动、弹性张缩，以及与气口挂碰等作用下，可能使活塞环产生裂纹与折断。

4. 密封差

柴油机在运行中，还会因燃烧不良、滑油过多将活塞环黏着在环槽中，使活塞环失去密封作用，造成燃烧室窜气而烧损活塞环。

## 活塞环的材料要求

因为活塞环的工作条件差，所以对活塞环的要求是：

1. 活塞环应有良好的密封性能；
2. 要耐磨，特别是抗熔着磨损的性能要好；
3. 要有适当的弹性；
4. 有足够的强度和热稳定性。

因此，活塞环的材料要弹性较好、摩擦系数小、耐磨、耐高温，要有良好的初期磨合性、贮油性和耐酸腐蚀能力，一般可采用合金铸铁（加硼、高硅）、可锻铸铁、球墨铸铁。

活塞环的工作表面硬度要比气缸套硬一些。

为了提高活塞环的工作性能常采用的结构措施和制造工艺有：

- 表面镀铬以提高耐磨性；
- 松孔镀铬以提高表面贮油性加快磨合；
- 内表面刻纹以提高弹性；
- 环外表面开设蓄油沟槽以利润滑；
- 环外表面镀铜以利磨合；
- 环外表面喷钼以降低黏着磨损等。

或者总结如下：

- 提高耐磨性：镀铬、氮化
- 改善初期磨合性能：镀铜、磷化、渗硫
- 以防粘着磨损：喷钼
