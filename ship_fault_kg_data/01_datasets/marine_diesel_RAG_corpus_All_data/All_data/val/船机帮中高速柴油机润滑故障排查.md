# 船机帮中高速柴油机润滑故障排查

对于柴油机机油压力、机油温度异常现象，我们要高度警惕，准确分析，正确判断，及时排除，否则极易发生严重机损事故。

## 一、机油消耗量过大

柴油机在正常运转时，机油正常消耗一般控制在0.5~2.5g/Kw.h，约为燃油消耗的1%左右，若超过额定消耗量的标准，则表明为过量消耗。

机油消耗量一般随着发动机转速、温度、运转模式及新旧程度的不同而发生变化。

机油不正常损耗的原因主要有：

1. 机油渗漏

曲轴前后油封损坏、油底壳出现裂纹、油底壳与机体接合面密封损坏以及正时齿轮室密封不良等，都会使机油漏失，损耗增加。

2. 曲轴箱气阻

在柴油机工作时，总会有一部分废气从气缸间隙中窜入曲轴箱，严重时会使曲轴箱内的机油上窜到燃烧室和气缸盖罩，甚至产生机油飞溅，导致机油损耗增加。

3. 烧机油

- 活塞环过度磨损
- 活塞环边间隙与开口间隙过大
- 活塞环弹力弱或卡死在环槽内
- 油环上的孔道堵塞
- 缸套密封不好
- 气门杆与气门导管配合间隙过大
- 油底壳油面过高
- 机油温度或压力过高
- 主轴承和连杆轴承间隙过大

以上原因都会使机油过多地进入燃烧室，排气管排出大量的蓝色浓烟，机油损耗过大。

另外，使用的机油牌号不对、粘度不合适，或者机器老化，也会造成机油损耗过大。

## 二、机油平面上升

在日常维护时，有时会发现油底壳油位上升的现象。

引起这类故障的原因：

- 一是冷却液漏入油底壳中

如汽缸盖或气缸体的水堵泄漏或产生裂纹、气缸垫水孔损坏、缸套的橡胶水封损坏等，都会使冷却系的水泄漏到油底壳中；

- 二是燃油的渗漏

比如输油泵的泄漏、活塞环失效、活塞或缸套出现裂纹拉伤、喷油泵柱塞严重磨损等情况，将会使燃油系的柴油渗漏到油底壳中。

## 三、机油压力低

柴油机的正常机油工作压力应该在0.3~0.4Mpa左右。

其中新机或刚启动时会高一些，旧机或运转时间长后压力就低一些；

如果机油压力低于0.2Mpa，说明问题严重，应立即停机检查，否则将会造成烧瓦抱轴的机损事故。

引起机油压力偏低的原因：

1. 机油泵出油量不足

机油泵经长期使用磨损后，齿轮或转子的径向及端面间隙增大，泵的出油量就会减少，从而造成机油压力下降。

机油泵安装时应先灌满机油，以免泵内有空气而吸不上油。

另外，机油泵与吸油盘的连接处必须密封，否则，也会导致油压偏低。

2. 机油滤清器堵塞引起压力偏低；

3. 回油阀损坏引起压力偏低；

一般回油阀开启压力在0.28~0.32Mpa之间。

4. 机油散热器漏油或堵塞引起压力偏低；

5. 曲轴与轴瓦间隙过大；

曲轴与连杆瓦或曲轴与主轴瓦的配合间隙每增加0.01mm，机油压力便下降0.01Mpa；

6. 机油牌号不对、粘度下降、乳化变质等。

## 四、机油压力偏高

柴油机刚启动后常常机油压力偏高，待预热一会儿后油压就会降至正常值。

如果持续油压偏高，就应该检查调整。

油压偏高的原因：

1. 机油牌号不对

选择机油牌号要根据机型、环境因素、使用工况等情况综合考虑；

2. 油路不畅或堵塞

机油的循环遇到阻塞或不能流通，致使油压偏高，影响机件的润滑，甚至会出现烧结现象，应及时清洗油路。

3. 限压阀和回油阀弹簧压力调整过大

这样不仅会增加滑油消耗，还可能会涨破油管，应按技术要求正确调整。

4. 主轴承或连杆轴承的间隙过小

间隙小会使机油不易压入，应按主机厂家要求调整。

## 五、机油压力不稳定

一般来说，机油压力在大油门时比小油门时高，但有时会发生反常现象，油压忽高忽低，压力表指针来回摆动。

出现这种故障的原因：

1. 油底壳机油量不足；

2. 机油过脏过粘，堵塞吸油盘；

3. 回油阀弹簧变形或折断，开闭不灵。

## 六、机油温度过高

柴油机工作过程中温度一般保持在65~80℃之间为宜，绝不允许高于90℃。

机油温度过高的危害：

- 会使机油变稀，使排气管窜机油，增加机油消耗；
- 因机油粘度下降，产生润滑不良，机件磨损加剧，机油压力下降；
- 会失去滑油系统冷却作用；
- 会失去密封作用，使气缸与活塞间漏气。

机油温度过高的原因：

1. 冷却系故障

如缸体、缸盖水套的水垢太多、太厚，散热不良，发动机温度升高，引起机油热负荷加重，从而使油温过高。

此时，应彻底清除水垢，加注软水使用。

机油散热器若不能正常工作，也会使油温升高。

2. 润滑系不清洁，机油太脏，油路堵塞

如机油粗滤器堵塞，阻力增加，使部分甚至全部机油不能通过粗滤器及散热器而直接从安全阀进入主油道，造成机油温度过高。

这一般是由于维护保养不认真、不及时，或使用了不符合规定的劣质机油、牌号不对的机油、或机油脏污等原因而造成的。

因此，应定期更换机油滤芯。

3. 压缩系漏气，高温气体窜入曲轴箱

此种情况在曲轴箱处能清晰地听到类似敲缸的声音，并有大量气体冒出。

漏气的直接原因是：

- 活塞环与缸壁不密合，在工作行程开始的瞬间，部分高温气体窜入曲轴箱；
- 活塞环弹力不足，或开口间隙过大，或装配时造成各环开口重合，造成漏气；
- 气缸壁因摩损而导致与活塞及活塞环配合关系恶化，造成不密封而漏气。

4. 其它原因

柴油机长时间超负荷运转，或机油泵损坏，或主轴承及连杆轴承的间隙过小，机油油面过高，曲轴箱通气口堵塞，油温表失灵等。

由于柴油机工作环境恶劣，一定要按期进行保养维护，保持机体和油底壳的清洁。

曲轴箱的油泥过多

质量差的机油和机油滤芯坚决不能用，要经常观察润滑油的变化，及时更换润滑油。
